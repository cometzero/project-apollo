# Apollo integration

Use root AGENTS.md for source boundaries and build entrypoints.
For cross-domain source discovery, consult [project map](references/project-map.md);
confirm local build configuration rather than copying its baseline snapshot.

Trace the affected hardware/firmware contract using the relevant Zena guide
section, owning sources and matching runtime artifacts. Select domain specialists
only for independently useful work. Do not require a whole-platform build for a
documentation or isolated tooling change.

Completion means the requested change and proportionate evidence, with explicit
unimplemented behavior. QBox boot/login markers alone are not driver or full
post-login qualification.
