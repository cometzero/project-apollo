ea25d49의 핵심 구조

  • • host_router 하나가 system, AP, SMD, SI0, SI1의 대부분 MMIO와 CPU memory path를 함께 decode
  • • RSE만 별도 32-bit rse_router를 가지고 ATU/MHU로 shared host_router에 연결
  • • machine_contract, request context, domain별 정책 router는 아직 없음

AP topology

  • • AP enable 시 QBOX_APOLLO_NUM_CPUS 범위는 1..16, qbox-platform 내장 기본값은 16
  • • CPU index는 4 cores/cluster의 MPIDR Aff2/Aff1로 변환되지만 명시적 4x4 topology 상수는 없음
  • • AP view router는 live CL0 통합 시에만 생성되고 전체 52-bit 범위를 host_router로 passthrough

Reset 및 격리 한계

  • • SI0의 AP cluster/core PPU window는 존재하지만 ea25d49에서는 AP CPU reset에 직접 연결되지 않음
  • • SI0/CL1 CPU와 GIC, peripheral은 독립 local router 없이 host_router에 직접 bind
  • • 주소 우선순위 mutation과 broad passthrough에 의존하므로 domain isolation이 구조로 고정되지 않음
