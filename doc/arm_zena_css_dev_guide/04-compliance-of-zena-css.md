# 4. Compliance of Zena CSS

<!-- Source PDF page: 9 -->

Zena CSS complies with, or includes components that comply with, the following specifications:

•   Arm® Architecture Reference Manual for A-profile architecture
•   Arm® Generic Interrupt Controller Architecture Specification, GIC architecture version 3 and version
4
•   AMBA® 5 CHI Architecture Specification, issue G
•   Arm® Base Boot Requirements, version 2.2, issue I
•   AMBA® AXI Protocol Specification, issue K
•   Arm® System Memory Management Unit Architecture Specification, SMMU architecture version 3
•   Arm® CoreSight™ Base System Architecture 1.0 Arm Platform Design Document
•   Arm® Power Policy Unit Architecture Specification, version 1.1, issue E
•   Arm® Power Control System Architecture, issue D
•   Arm® Debug Interface Architecture Specification ADIv6.0
•   Arm® System Monitoring Control Framework Architecture Specification
