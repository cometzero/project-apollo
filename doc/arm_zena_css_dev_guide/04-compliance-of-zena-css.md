# 4 Compliance of Zena CSS

Zena CSS complies with, or includes components that comply with, the following specifications:

- [Arm® Architecture Reference Manual for A-profile architecture](https://developer.arm.com/documentation/ddi0487)
- [Arm® Generic Interrupt Controller Architecture Specification, GIC architecture version 3 and version 4](https://developer.arm.com/documentation/ihi0069)
- [AMBA® 5 CHI Architecture Specification, issue G](https://developer.arm.com/documentation/ihi0050/g)
- [Arm® Base Boot Requirements, version 2.2, issue I](https://developer.arm.com/documentation/den0044/i)
- [AMBA® AXI Protocol Specification, issue K](https://developer.arm.com/documentation/ihi0022/k)
- [Arm® System Memory Management Unit Architecture Specification, SMMU architecture version 3](https://developer.arm.com/documentation/ihi0070)
- [Arm® CoreSight™ Base System Architecture 1.0 Arm Platform Design Document](https://developer.arm.com/documentation/den0068)
- [Arm® Power Policy Unit Architecture Specification, version 1.1, issue E](https://developer.arm.com/documentation/den0051/e)
- [Arm® Power Control System Architecture, issue D](https://developer.arm.com/documentation/den0050/d)
- [Arm® Debug Interface Architecture Specification ADIv6.0](https://developer.arm.com/documentation/ihi0074)
- [Arm® System Monitoring Control Framework Architecture Specification](https://developer.arm.com/documentation/Den0108)
