# FMU_ERRDEVARCH, Device Architecture Register

Source: <https://developer.arm.com/documentation/107612/0001/Programmers-model-for-MHU-320AE/MHU-FMU-register-summary/FMU-ERRDEVARCH--Device-Architecture-Register>

### FMU\_ERRDEVARCH, Device Architecture Register

Provides discovery information for the component.

### Configurations

This register is available in all configurations.

### Attributes

Width
:   32

Component
:   MHU FMU Register Block

Register offset
:   0xFBC
