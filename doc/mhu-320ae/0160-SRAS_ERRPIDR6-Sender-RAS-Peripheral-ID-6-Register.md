# SRAS_ERRPIDR6, Sender RAS Peripheral ID 6 Register

Source: <https://developer.arm.com/documentation/107612/0001/Programmers-model-for-MHU-320AE/MHU-Sender-registers/MHU-Sender-RAS-register-summary/SRAS-ERRPIDR6--Sender-RAS-Peripheral-ID-6-Register>

### SRAS\_ERRPIDR6, Sender RAS Peripheral ID 6 Register

Returns byte[6] of the peripheral ID for Sender RAS page.

### Configurations

This register is available in all configurations.

### Attributes

Width
:   32

Component
:   MHUS.SRAS

Register offset
:   0x0FD8
