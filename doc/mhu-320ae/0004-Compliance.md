# Compliance

Source: <https://developer.arm.com/documentation/107612/0001/Overview-of-MHU-320AE/Compliance>

### Compliance

MHU-320AE complies with various AMBA specifications and standards.

This product is compliant with:

- [Message Handling Unit Architecture version 3.0](https://developer.arm.com/documentation/aes0072/aa)
- [AMBA® AXI-Stream Protocol Specification](https://developer.arm.com/documentation/ihi0051/b)
- [AMBA® AXI Protocol Specification](https://developer.arm.com/documentation/ihi0022/j)
- [AMBA® APB Protocol Specification](https://developer.arm.com/documentation/ihi0024/d)
- [AMBA® Low Power Interface Specification](https://developer.arm.com/documentation/ihi0068/d)
- Arm® RAS-architecture compliant error reporting. For more information about RASv1.1 architecture, see the RAS System Architecture chapter of the [Arm® Architecture Reference Manual for A-profile architecture](https://developer.arm.com/documentation/ddi0487)

This document must be read with these specifications. Information from these specifications is not reproduced in this document.
