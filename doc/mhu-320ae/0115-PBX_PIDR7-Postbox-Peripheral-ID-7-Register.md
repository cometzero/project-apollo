# PBX_PIDR7, Postbox Peripheral ID 7 Register

Source: <https://developer.arm.com/documentation/107612/0001/Programmers-model-for-MHU-320AE/MHU-Sender-registers/MHU-Sender-Postbox-register-summary/PBX-PIDR7--Postbox-Peripheral-ID-7-Register>

### PBX\_PIDR7, Postbox Peripheral ID 7 Register

Returns byte[7] of the peripheral ID for Postbox page.

### Configurations

This register is available in all configurations.

### Attributes

Width
:   32

Component
:   MHUS.PBX

Register offset
:   0x0FDC
