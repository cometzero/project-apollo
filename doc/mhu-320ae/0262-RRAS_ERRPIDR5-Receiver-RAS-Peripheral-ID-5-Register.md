# RRAS_ERRPIDR5, Receiver RAS Peripheral ID 5 Register

Source: <https://developer.arm.com/documentation/107612/0001/Programmers-model-for-MHU-320AE/MHU-Receiver-registers/MHU-Receiver-RAS-register-summary/RRAS-ERRPIDR5--Receiver-RAS-Peripheral-ID-5-Register>

### RRAS\_ERRPIDR5, Receiver RAS Peripheral ID 5 Register

Returns byte[5] of the peripheral ID for Receiver RAS page.

### Configurations

This register is available in all configurations.

### Attributes

Width
:   32

Component
:   MHUR.RRAS

Register offset
:   0x0FD4
