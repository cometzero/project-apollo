# MBX_PIDR5, Mailbox Peripheral ID 5 Register

Source: <https://developer.arm.com/documentation/107612/0001/Programmers-model-for-MHU-320AE/MHU-Receiver-registers/MHU-Receiver-Mailbox-register-summary/MBX-PIDR5--Mailbox-Peripheral-ID-5-Register>

### MBX\_PIDR5, Mailbox Peripheral ID 5 Register

Returns byte[5] of the peripheral ID for Mailbox page.

### Configurations

This register is available in all configurations.

### Attributes

Width
:   32

Component
:   MHUR.MBX

Register offset
:   0x0FD4
