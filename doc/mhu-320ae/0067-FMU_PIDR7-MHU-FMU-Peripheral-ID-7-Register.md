# FMU_PIDR7, MHU FMU Peripheral ID 7 Register

Source: <https://developer.arm.com/documentation/107612/0001/Programmers-model-for-MHU-320AE/MHU-FMU-register-summary/FMU-PIDR7--MHU-FMU-Peripheral-ID-7-Register>

### FMU\_PIDR7, MHU FMU Peripheral ID 7 Register

Returns byte[7] of the peripheral ID for MHU FMU page.

### Configurations

This register is available in all configurations.

### Attributes

Width
:   32

Component
:   MHU FMU Register Block

Register offset
:   0xFDC
