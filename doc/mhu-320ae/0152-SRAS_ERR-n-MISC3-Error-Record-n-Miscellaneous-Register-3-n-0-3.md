### SRAS\_ERR<n>MISC3, Error Record <n> Miscellaneous Register 3, n = 0 - 3

Records additional information on reported error.

### Configurations

This register is available in all configurations.

### Attributes

Width
:   64

Component
:   MHUS.SRAS

Register offset
:   (64 \* n) + 0x0038
