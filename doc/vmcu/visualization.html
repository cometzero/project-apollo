0x510

종합 상태 · MCU → 차량

32 byte. SI epoch, MCU cookie, 상태·fault, GPIO, PFDI bitmap. 5초 및 상태 변화 시 보고합니다.

0x600

제어 명령 · 차량 → MCU

24 byte. op·arg와 epoch/cookie/sequence를 검사합니다. 상태, AP ping, PMIC 조회, AP 복구·종료·wake를 요청합니다.

0x601

명령 응답 · MCU → 차량

24 byte. 결과·상태·값을 반환합니다. 동일 요청 재전송은 캐시 응답만 반환하며, 오래된 요청은 실행하지 않습니다.

전송 계층 구분

UART: 28-byte frame + CRC32. GPIO: GP8 8-byte snapshot. CAN endpoint: CAN1 92-byte frame + CRC32/epoch/token.
세 경로의 포맷은 별개입니다. SIL Kit ACK는 물리 CAN ACK slot 또는 상대 애플리케이션 처리 완료를 의미하지 않습니다.

./run_qbox_yocto.sh --bsp --sil-kit

차량 CAN의 AP 제어 명령을 허용하려면 --sil-kit-allow-actuation을 추가합니다. 이 옵션은 자동 동작을 시작하지 않습니다.

남은 범위

PMIC rail 차단·PGOOD/retention, SoC 전체 cold-off·SC7, 독립 always-on watchdog, SPI/Ethernet 보드 링크, CAN 물리 중재·오류 timing, 공통 virtual time/FTTI, DBC/ARXML와 차량 안전 정책.
현재 검증된 전원 범위는 AP 코어 OFF + SYSTOP/SI/RSE/PMIC 유지입니다. 설정 전압 readback을 측정 전압이나 전원 차단의 증거로 해석하지 않습니다.
