# Compliance

Source: <https://developer.arm.com/documentation/102482/0000/DMA-350-overview/Compliance>

### Compliance

The DMA-350 interfaces are compliant with the following Arm specifications and protocols:

- AMBA AXI5 protocol, see the [AMBA® AXI and ACE Protocol Specification](https://developer.arm.com/documentation/ihi0022/)
- AMBA APB4 protocol, see the [AMBA® APB Protocol Specification](https://developer.arm.com/documentation/ihi0024/)
- AMBA AXI4-Stream protocol, see the [AMBA® AXI-Stream Protocol Specification](https://developer.arm.com/documentation/ihi0051/)
- AMBA Low Power Interface protocol, see the [AMBA® Low Power Interface Specification](https://developer.arm.com/documentation/ihi0068/)
