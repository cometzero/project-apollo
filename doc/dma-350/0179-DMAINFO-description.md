# DMAINFO description

Source: <https://developer.arm.com/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description>

### DMAINFO description

DMA Unit Information Register Frame.

For an overview of the frame, and a list of constraints that apply to this block, see [DMAINFO summary](/documentation/102482/0000/Programmers-model/Register-summary/DMAINFO-summary?lang=en "DMA Unit Information Register Frame.").

- **[DMA\_BUILDCFG0](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/DMA-BUILDCFG0?lang=en)**
   The DMA Build Configuration register 0 is used to provide information about the configuration parameters of the DMAC.
- **[DMA\_BUILDCFG1](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/DMA-BUILDCFG1?lang=en)**
   The DMA Build Configuration register 1 is used to provide information about the configuration parameters of the DMAC.
- **[DMA\_BUILDCFG2](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/DMA-BUILDCFG2?lang=en)**
   The DMA Build Configuration register 2 is used to provide information about the configuration parameters of the DMAC.
- **[IIDR](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/IIDR?lang=en)**
   The Implementation Identification register provides information about the implementer of the DMAC.
- **[AIDR](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/AIDR?lang=en)**
   The Architecture Identification register provides information about the architecture revision supported by the DMAC.
- **[PIDR4](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/PIDR4?lang=en)**
   The Peripheral ID4 register returns byte[4] of the peripheral ID.
- **[PIDR0](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/PIDR0?lang=en)**
   The Peripheral ID0 register returns byte[0] of the peripheral ID.
- **[PIDR1](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/PIDR1?lang=en)**
   The Peripheral ID1 register returns byte[1] of the peripheral ID.
- **[PIDR2](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/PIDR2?lang=en)**
   The Peripheral ID2 register returns byte[2] of the peripheral ID.
- **[PIDR3](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/PIDR3?lang=en)**
   The Peripheral ID 3 register returns byte[3] of the peripheral ID.
- **[CIDR0](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/CIDR0?lang=en)**
   The Component ID0 register returns byte[0] of the component ID.
- **[CIDR1](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/CIDR1?lang=en)**
   The Component ID1 register returns byte[1] of the component ID.
- **[CIDR2](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/CIDR2?lang=en)**
   The Component ID2 register returns byte[2] of the component ID.
- **[CIDR3](/documentation/102482/0000/Programmers-model/Register-descriptions/DMAINFO-description/CIDR3?lang=en)**
   The Component ID3 register returns byte[3] of the component ID.
