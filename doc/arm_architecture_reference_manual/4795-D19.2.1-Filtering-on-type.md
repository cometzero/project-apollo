##### D19.2.1 Filtering on type

I FSNVG
:   The [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) can be filtered by independently enabling the generation of the following types:

    - Exception.
    - Exception return.
    - Direct Branch with link.
    - Indirect Branch with link.
    - Return from subroutine.
    - Indirect Branches.
    - Conditional Direct Branches.
    - Unconditional Direct Branches.
