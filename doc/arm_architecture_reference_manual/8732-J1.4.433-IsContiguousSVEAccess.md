##### J1.4.433 IsContiguousSVEAccess

```
// IsContiguousSVEAccess()
// =======================
// Return TRUE if memory access is contiguous load/stores in an SVE mode.
func IsContiguousSVEAccess(accdesc : AccessDescriptor) => boolean
begin
    return accdesc.acctype == AccessType_SVE && accdesc.contiguous;
end;
```
