# ​D6.4.5 External mode and MPAM

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode/-D6-4-5-External-mode-and-MPAM>

##### D6.4.5 External mode and MPAM

R SFTXK
:   If [FEAT\_MPAM](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_mpam) is implemented, [FEAT\_TRBE\_MPAM](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_trbe_mpam) is not implemented, and the Trace Buffer Unit is using External mode, then accesses made by the Trace Buffer Unit to the trace buffer use the Default physical PARTID and Default PMG values, and the PARTID space corresponding to the trace physical address space defined by [TRBMAR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-19-TRBMAR-EL1--Trace-Buffer-Memory-Attribute-Register?lang=en#reg_ext_trbmar_el1).PAS, regardless of the value of [MPAMn\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mpamn_elx).MPAMEN.

R GJFRD
:   If [FEAT\_MPAM](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_mpam) and [FEAT\_TRBE\_MPAM](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_trbe_mpam) are implemented and the Trace Buffer Unit is using External mode, then accesses made by the Trace Buffer Unit to the trace buffer use one of the following:

    - If [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1).EN is 0, the Default physical PARTID and Default PMG values, and the PARTID space corresponding to the trace physical address space defined by [TRBMAR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-19-TRBMAR-EL1--Trace-Buffer-Memory-Attribute-Register?lang=en#reg_ext_trbmar_el1).PAS, regardless of the value of [MPAMn\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mpamn_elx).MPAMEN.
    - If [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1).EN is 1, then the [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1).{PARTID, PMG, MPAM\_SP} MPAM values.

I JRQWG
:   The external debugger can choose any PARTID and PMG values from the selected the MPAM\_SP PARTID space.

I QSRZX
:   System register access to [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1) is also provided, to allow software to save and restore the register over powerdown. [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1) is not used in Self-hosted mode.

R ZXFRR
:   The IMPLEMENTATION DEFINED authentication interface controls which MPAM\_SP PARTID spaces can be used.

R VVWKG
:   If the authentication interface prohibits invasive debug of the Security state corresponding to the MPAM\_SP.PARTID space selected by [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1).MPAM\_SP, or [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1).MPAM\_SP is set to a reserved value, then when the Trace Buffer Unit receives trace data from the trace unit, no trace is written to the trace buffer and all of the following occur:

    - A trace buffer management event is generated. This sets [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).IRQ to 1.
    - If [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).S is 0, then all of the following occur:

      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).S is set to 1, [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1).
      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).EC is set to `0x00`, other buffer management event.
      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).BSC is set to `0b000000`, *access not allowed*.
    - The other fields in [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1) are unchanged.
