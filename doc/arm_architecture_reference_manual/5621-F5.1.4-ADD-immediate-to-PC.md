# ​F5.1.4 ADD (immediate, to PC)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-4-ADD--immediate--to-PC->

##### F5.1.4 ADD (immediate, to PC)

Add to PC adds an immediate value to the Align(PC, 4) value to form a PC-relative address, and writes the result to the destination register. Arm recommends that, where possible, software avoids using this alias.

This is a pseudo-instruction of [ADR](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-10-ADR?lang=en#isa_adr_a32). This means:

- The encodings in this description are named to match the encodings of [ADR](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-10-ADR?lang=en#isa_adr_a32).
- The assembler syntax is used only for assembly, and is not used on disassembly.
- The description of [ADR](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-10-ADR?lang=en#isa_adr_a32) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-4-ADD--immediate--to-PC-?lang=en#isa_add_adr_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-4-ADD--immediate--to-PC-?lang=en#isa_add_adr_iclass_t1) and [T3](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-4-ADD--immediate--to-PC-?lang=en#isa_add_adr_iclass_t3)).

###### A1

![](images/5621-F5.1.4-ADD-immediate-to-PC-img01.svg)

###### Encoding for the A1 variant

```
ADD{<c>}{<q>}  <Rd>, PC, #<const>
```

is equivalent to

```
ADR{<c>}{<q>}  <Rd>, <label>
```

###### T1

![](images/5621-F5.1.4-ADD-immediate-to-PC-img02.svg)

###### Encoding for the T1 variant

```
ADD{<c>}{<q>}  <Rd>, PC, #<imm8>
```

is equivalent to

```
ADR{<c>}{<q>}  <Rd>, <label>
```

###### T3

![](images/5621-F5.1.4-ADD-immediate-to-PC-img03.svg)

###### Encoding for the T3 variant

```
ADD{<c>}{<q>}  <Rd>, PC, #<imm12>
```

```
ADDW{<c>}{<q>}  <Rd>, PC, #<imm12> // (UInt(Rd) < 8 && UInt(i :: imm3 :: imm8) < 256)
```

is equivalent to

```
ADR{<c>}{<q>}  <Rd>, <label>
```

<c>

    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<q>
:   ​
    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<Rd>
:   ​

    For the “A1” variant: is the general-purpose destination register, encoded in the “Rd” field. If the PC is used, the instruction is a branch to the address calculated by the operation. This is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).

    ​

    For the “T1” and “T3” variants: is the general-purpose destination register, encoded in the “Rd” field.

<const>
:   ​

    An immediate value. See [Modified immediate constants in A32 instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-7-General-information-about-the-T32-and-A32-instruction-descriptions/-F1-7-7-Modified-immediate-constants-in-T32-and-A32-instructions?lang=en#babhdajf) for the range of values.

<imm8>
:   ​

    Is an unsigned immediate, a multiple of 4, in the range 0 to 1020, encoded in the “imm8” field as <imm8>/4.

<imm12>
:   ​

    Is a 12-bit unsigned immediate, in the range 0 to 4095, encoded in the “i:imm3:imm8” field.
