##### H3.6.2 Pseudocode description of OS Unlock Catch debug event

The [`CheckOSUnlockCatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-78-CheckOSUnlockCatch?lang=en#asl_func_checkosunlockcatch_0)`()` function is called when the OS Lock is unlocked.

The [`CheckPendingOSUnlockCatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-81-CheckPendingOSUnlockCatch?lang=en#asl_func_checkpendingosunlockcatch_0)`()` function is called before an instruction is executed. If an OS Unlock Catch is pending, it generates the debug event.
