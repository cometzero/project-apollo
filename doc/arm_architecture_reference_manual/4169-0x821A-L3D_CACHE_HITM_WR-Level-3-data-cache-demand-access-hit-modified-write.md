##### `0x821A`, L3D\_CACHE\_HITM\_WR, Level 3 data cache demand access hit modified, write

The counter counts each cache access counted by [L3D\_CACHE\_HIT\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81CA--L3D-CACHE-HIT-WR--Level-3-data-cache-demand-access-hit--write?lang=en#event_l3d_cache_hit_wr) that accesses a previously modified cache location.
