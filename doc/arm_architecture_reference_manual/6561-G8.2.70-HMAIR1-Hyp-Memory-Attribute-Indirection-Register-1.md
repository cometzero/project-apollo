# ​G8.2.70 HMAIR1, Hyp Memory Attribute Indirection Register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-70-HMAIR1--Hyp-Memory-Attribute-Indirection-Register-1>

##### G8.2.70 HMAIR1, Hyp Memory Attribute Indirection Register 1

The HMAIR1 characteristics are:

Purpose
:   Along with [HMAIR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-69-HMAIR0--Hyp-Memory-Attribute-Indirection-Register-0?lang=en#reg_aarch32_hmair0), provides the memory attribute encodings corresponding to the possible AttrIndx values in a Long-descriptor format translation table entry for stage 1 translations for memory accesses from Hyp mode.

    AttrIndx[2] indicates the HMAIR register to be used:

    - When AttrIndx[2] is 0, [HMAIR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-69-HMAIR0--Hyp-Memory-Attribute-Indirection-Register-0?lang=en#reg_aarch32_hmair0) is used.
    - When AttrIndx[2] is 1, HMAIR1 is used.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch32 System register HMAIR1 bits [31:0] are architecturally mapped to AArch64 System register [MAIR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-127-MAIR-EL2--Memory-Attribute-Indirection-Register--EL2-?lang=en#reg_aarch64_mair_el2)[63:32].

    This register is present only when FEAT\_AA32EL2 is implemented. Otherwise, direct accesses to HMAIR1 are UNDEFINED.

Attributes
:   HMAIR1 is a 32-bit register.

###### Field descriptions

When TTBCR.EAE == '1':
:   ![](images/6561-G8.2.70-HMAIR1-Hyp-Memory-Attribute-Indirection-Register-1-img01.svg)

Attr<n> , bits [8(n-4)+7:8(n-4)], for n = 7 to 4
:   The memory attribute encoding for an AttrIndx[2:0] entry in a Long descriptor format translation table entry, where:

    - AttrIndx[2:0] gives the value of <n> in Attr<n>.
    - AttrIndx[2] defines which MAIR to access. Attr7 to Attr4 are in MAIR1, and Attr3 to Attr0 are in MAIR0.
