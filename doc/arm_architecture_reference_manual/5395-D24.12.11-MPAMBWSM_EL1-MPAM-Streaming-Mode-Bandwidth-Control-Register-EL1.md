# ​D24.12.11 MPAMBWSM_EL1, MPAM Streaming Mode Bandwidth Control Register (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-11-MPAMBWSM-EL1--MPAM-Streaming-Mode-Bandwidth-Control-Register--EL1->

##### D24.12.11 MPAMBWSM\_EL1, MPAM Streaming Mode Bandwidth Control Register (EL1)

The MPAMBWSM\_EL1 characteristics are:

Purpose
:   Enables software to configure a maximum fraction of memory bandwidth that the PE is permitted for SME memory accesses labeled with values from [MPAMSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-14-MPAMSM-EL1--MPAM-Streaming-Mode-Register?lang=en#reg_aarch64_mpamsm_el1).

Configuration
:   This register is present only when FEAT\_MPAM\_PE\_BW\_CTRL is implemented and FEAT\_SME is implemented. Otherwise, direct accesses to MPAMBWSM\_EL1 are UNDEFINED.

Attributes
:   MPAMBWSM\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5395-D24.12.11-MPAMBWSM_EL1-MPAM-Streaming-Mode-Bandwidth-Control-Register-EL1-img01.svg)

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    Accessing this field has the following behavior:

    - When MPAMBWIDR\_EL1.MAX\_LIM == ‘00’, access to this field is RW.
    - When MPAMBWIDR\_EL1.MAX\_LIM == ‘01’, access to this field is RAZ/WI.
    - When MPAMBWIDR\_EL1.MAX\_LIM == ‘10’, access to this field is RAO/WI.

Bits [60:32]
:   Reserved, RES0.

MAX, bits [31:0]
:   When MPAMBWIDR\_EL1.HAS\_HW\_SCALE == '1' and MPAMBWSM\_EL1.HW\_SCALE\_ENABLE == '1':
    :   ![](images/5395-D24.12.11-MPAMBWSM_EL1-MPAM-Streaming-Mode-Bandwidth-Control-Register-EL1-img02.svg)

    MAX, bits [31:0]
    :   Maximum memory bandwidth allocated to the partition selected by [MPAMSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-14-MPAMSM-EL1--MPAM-Streaming-Mode-Register?lang=en#reg_aarch64_mpamsm_el1).PARTID\_D.

        The value is represented as a multiplier of the available bandwidth for the PE. The value is represented in base-2 fixed-point format.

        Bits [31:16] represent the integer part of the value.
