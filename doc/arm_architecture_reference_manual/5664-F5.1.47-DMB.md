##### F5.1.47 DMB

Data Memory Barrier is a memory barrier that ensures the ordering of observations of memory accesses, see [Data Memory Barrier (DMB)](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-3-Definition-of-the-memory-model/-E2-3-5-Memory-barriers?lang=en#aa32chdcifhj).

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-47-DMB?lang=en#isa_dmb_a32_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-47-DMB?lang=en#isa_dmb_a32_iclass_t1)).

###### Assembler Symbols

<c>
:   ​

    For the “A1” variant: see [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf). Must be `AL` or omitted.

    ​

    For the “T1” variant: see [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<q>
:   ​
    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<option>
:   ​

    Specifies the limitation on the Memory Effects ordered by the barrier operation, and is encoded in “option”.

    > #### Note
    >
    > The instruction supports the following alternative <option> values, but Arm recommends that software does not use these alternative values:
    >
    > - SH as an alias for ISH.
    > - SHST as an alias for ISHST.
    > - UN as an alias for NSH.
    > - UNST as an alias for NSHST.

    For more information on whether a Memory Effect is before or after a barrier instruction, see [Data Memory Barrier (DMB)](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-3-Definition-of-the-memory-model/-E2-3-5-Memory-barriers?lang=en#aa32chdcifhj).

    All reserved options have the same behavior as SY, but software must not rely on this behavior.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    var types : MBReqTypes;
    case option[1:0] of
        when ‘00’ => types = MBReqTypes_All;
        when ‘01’ => types = MBReqTypes_Reads;
        when ‘10’ => types = MBReqTypes_Writes;
        when ‘11’ => types = MBReqTypes_All;
    end;
    DataMemoryBarrier(types);
end;
```
