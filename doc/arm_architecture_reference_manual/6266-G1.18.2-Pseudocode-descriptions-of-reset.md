# ​G1.18.2 Pseudocode descriptions of reset

##### G1.18.2 Pseudocode descriptions of reset

The [`AArch32_TakeReset`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-40-AArch32-TakeReset?lang=en#asl_func_aarch32_takereset_1)`()` pseudocode procedure describes how the PE behaves when reset is deasserted.

The [`AArch32_ResetGeneralRegisters`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-115-AArch32-ResetGeneralRegisters?lang=en#asl_func_aarch32_resetgeneralregisters_0)`()` pseudocode function resets the general-purpose registers.

The [`AArch32_ResetSIMDFPRegisters`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-116-AArch32-ResetSIMDFPRegisters?lang=en#asl_func_aarch32_resetsimdfpregisters_0)`()` pseudocode function resets the SIMD and floating-point registers.

The [`AArch32_ResetSpecialRegisters`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-117-AArch32-ResetSpecialRegisters?lang=en#asl_func_aarch32_resetspecialregisters_0)`()` pseudocode function resets the Special-purpose registers, and the debug System registers [DLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-29-DLR--Debug-Link-Register?lang=en#reg_aarch32_dlr) and [DSPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-30-DSPSR--Debug-Saved-Program-Status-Register?lang=en#reg_aarch32_dspsr), which are used for handling Debug exceptions.

The [`AArch32_ResetSystemRegisters`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-118-AArch32-ResetSystemRegisters?lang=en#asl_func_aarch32_resetsystemregisters_1)`()` pseudocode function resets all System registers in the (`coproc == 0b111x`) encoding space to their reset state as defined in the register descriptions in [AArch32 System Register Descriptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions?lang=en#autogen_registers_aarch32).

> #### Note
>
> The [`AArch32_ResetSystemRegisters`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-118-AArch32-ResetSystemRegisters?lang=en#asl_func_aarch32_resetsystemregisters_1)`()` function only resets the System registers. It has no effect on memory-mapped registers.

The [`ResetExternalDebugRegisters`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-494-ResetExternalDebugRegisters?lang=en#asl_func_resetexternaldebugregisters_1)`()` pseudocode function resets all external debug registers to their reset state as defined in the register descriptions in [External Debug Register Descriptions](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions?lang=en#autogen_registers_debug).
