# ​G8.2.112 MAIR1, Memory Attribute Indirection Register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-112-MAIR1--Memory-Attribute-Indirection-Register-1>

##### G8.2.112 MAIR1, Memory Attribute Indirection Register 1

The MAIR1 characteristics are:

Purpose
:   Along with [MAIR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-111-MAIR0--Memory-Attribute-Indirection-Register-0?lang=en#reg_aarch32_mair0), provides the memory attribute encodings corresponding to the possible AttrIndx values in a Long-descriptor format translation table entry for stage 1 translations.

    AttrIndx[2] indicates the MAIR register to be used:

    - When AttrIndx[2] is 0, [MAIR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-111-MAIR0--Memory-Attribute-Indirection-Register-0?lang=en#reg_aarch32_mair0) is used.
    - When AttrIndx[2] is 1, MAIR1 is used.

Configuration
:   MAIR1 and [NMRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register?lang=en#reg_aarch32_nmrr) are the same register, with a different view depending on the value of [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).EAE:

    - When it is set to 0, the register is as described in [NMRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register?lang=en#reg_aarch32_nmrr).
    - When it is set to 1, the register is as described in MAIR1.

    When EL3 is using AArch32, write access to MAIR1(S) is disabled when the **CP15SDISABLE** signal is asserted HIGH.

    When EL3 is not implemented or EL3 is using AArch64, AArch32 System register MAIR1 bits [31:0] are architecturally mapped to AArch64 System register [MAIR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-126-MAIR-EL1--Memory-Attribute-Indirection-Register--EL1-?lang=en#reg_aarch64_mair_el1)[63:32].

    When EL3 is not implemented or EL3 is using AArch64, AArch32 System register MAIR1 bits [31:0] are architecturally mapped to AArch32 System register [NMRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register?lang=en#reg_aarch32_nmrr)[31:0].

    When EL3 is using AArch32, AArch32 System register MAIR1 bits [31:0] are architecturally mapped to AArch32 System register [NMRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register?lang=en#reg_aarch32_nmrr)[31:0].

    When EL3 is using AArch32, AArch32 System register MAIR1 bits [31:0] are architecturally mapped to AArch32 System register [NMRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register?lang=en#reg_aarch32_nmrr)[31:0].

    This register is banked between MAIR1 and MAIR1\_S and MAIR1\_NS.

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to MAIR1 are UNDEFINED.

Attributes
:   MAIR1 is a 32-bit register.

    This register has the following instances:

    - MAIR1, when EL3 is not implemented or FEAT\_AA64 is implemented.
    - MAIR1\_S, when FEAT\_AA32EL3 is implemented.
    - MAIR1\_NS, when FEAT\_AA32EL3 is implemented.

###### Field descriptions

When TTBCR.EAE == '1':
:   ![](images/6603-G8.2.112-MAIR1-Memory-Attribute-Indirection-Register-1-img01.svg)

Attr<n> , bits [8(n-4)+7:8(n-4)], for n = 7 to 4
:   The memory attribute encoding for an AttrIndx[2:0] entry in a Long descriptor format translation table entry, where:

    - AttrIndx[2:0] gives the value of <n> in Attr<n>.
    - AttrIndx[2] defines which MAIR to access. Attr7 to Attr4 are in MAIR1, and Attr3 to Attr0 are in MAIR0.
