##### C8.2.489 NOT (predicate)

Bitwise invert predicate

This instruction performs a bitwise invert of each active element of the source predicate, and places the results in the corresponding elements of the destination predicate. Inactive elements in the destination predicate register are set to zero. This instruction does not set the condition flags.

This is an alias of [EOR (predicates)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-135-EOR--predicates-?lang=en#isa_eor_p_p_pp). This means:

- The encodings in this description are named to match the encodings of [EOR (predicates)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-135-EOR--predicates-?lang=en#isa_eor_p_p_pp).
- The description of [EOR (predicates)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-135-EOR--predicates-?lang=en#isa_eor_p_p_pp) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
NOT  <Pd>.B, <Pg>/Z, <Pn>.B
```

is equivalent to

```
EOR  <Pd>.B, <Pg>/Z, <Pn>.B, <Pg>.B
```

and is the preferred disassembly when `Pm == Pg`.

###### Assembler Symbols

<Pd>
:   ​

    Is the name of the destination scalable predicate register, encoded in the “Pd” field.

<Pg>
:   ​

    Is the name of the governing scalable predicate register, encoded in the “Pg” field.

<Pn>
:   ​

    Is the name of the source scalable predicate register, encoded in the “Pn” field.
