# ​D21.1.3 Memory system resource partitioning

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-1-About-MPAM/-D21-1-3-Memory-system-resource-partitioning>

##### D21.1.3 Memory system resource partitioning

R DDGSM
:   Each MPAM MSC implements zero or more *MPAM resource controls*.

I GPWRB
:   Each MPAM resource control has settings for each PARTID.

I DTCTY
:   When an MPAM Requester sends a request, the [PARTID space](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-2-PARTID-spaces?lang=en#mpam_partid_spaces) and [PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-?lang=en#mpam_partition_identifiers) in the [MPAM information bundle](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-1-About-MPAM/-D21-1-2-MPAM-information-bundles?lang=en#mpam_mpam_information_bundles) are used as an index into a table in the MPAM MSC, to select the entry that holds the settings for that partition. Those settings configure how the shared partitionable resource is apportioned to that partition.

I MHDHR
:   See also:

    - [MPAM PE-side Maximum bandwidth limit injection control](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-8-PE-side-Maximum-bandwidth-limit-injection-control?lang=en#mpam_pe_injection_control) for MPAM PE-side bandwidth regulation controls.
    - For more detail, *Arm® Memory System Resource Partitioning and Monitoring (MPAM) System Component Specification*.
