# ​G8.4.15 PMOVSSET, Performance Monitors Overflow Flag Status Set register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-15-PMOVSSET--Performance-Monitors-Overflow-Flag-Status-Set-register>

##### G8.4.15 PMOVSSET, Performance Monitors Overflow Flag Status Set register

The PMOVSSET characteristics are:

Purpose
:   Allows software to set the unsigned overflow flags for the following counters to 1:

    - The cycle counter [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr).
    - The event counters [PMEVCNTR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-10-PMEVCNTR-n---Performance-Monitors-Event-Count-Registers--n---0---30?lang=en#reg_aarch32_pmevcntrn).

    Reading from this register shows the current unsigned overflow flag values.

Configuration
:   AArch32 System register PMOVSSET bits [31:0] are architecturally mapped to AArch32 System register [PMOVSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-14-PMOVSR--Performance-Monitors-Overflow-Flag-Status-Register?lang=en#reg_aarch32_pmovsr)[31:0].

    AArch32 System register PMOVSSET bits [31:0] are architecturally mapped to AArch64 System register [PMOVSSET\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-20-PMOVSSET-EL0--Performance-Monitors-Overflow-Flag-Status-Set-Register?lang=en#reg_aarch64_pmovsset_el0)[31:0].

    AArch32 System register PMOVSSET bits [31:0] are architecturally mapped to AArch64 System register [PMOVSCLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-19-PMOVSCLR-EL0--Performance-Monitors-Overflow-Flag-Status-Clear-Register?lang=en#reg_aarch64_pmovsclr_el0)[31:0].

    AArch32 System register PMOVSSET bits [31:0] are architecturally mapped to External register [PMOVSSET\_EL0](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-46-PMOVSSET-EL0--Performance-Monitors-Overflow-Flag-Status-Set-Register?lang=en#reg_pmu_pmovsset_el0)[31:0].

    AArch32 System register PMOVSSET bits [31:0] are architecturally mapped to External register [PMOVSCLR\_EL0](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-45-PMOVSCLR-EL0--Performance-Monitors-Overflow-Flag-Status-Clear-register?lang=en#reg_pmu_pmovsclr_el0)[31:0].

    AArch32 System register PMOVSSET bits [31:0] are architecturally mapped to External register [PMOVS](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-44-PMOVS--Performance-Monitors-Overflow-Flag-Status-register?lang=en#reg_pmu_pmovs)[31:0].

    This register is present only when FEAT\_AA32 is implemented and FEAT\_PMUv3 is implemented. Otherwise, direct accesses to PMOVSSET are UNDEFINED.

Attributes
:   PMOVSSET is a 32-bit register.

###### Field descriptions

![](images/6718-G8.4.15-PMOVSSET-Performance-Monitors-Overflow-Flag-Status-Set-register-img01.svg)

C, bit [31]
:   Unsigned overflow flag for [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr) set. On writes, allows software to set the unsigned overflow flag for [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr) to 1. On reads, returns the unsigned overflow flag for [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr) overflow status.

    The reset behavior of this field is:

    - On a Cold reset:
      - When FEAT\_PMUv3\_EXTPMN is implemented, this field resets to an architecturally UNKNOWN value.
    - On a Warm reset:
      - When FEAT\_PMUv3\_EXTPMN is not implemented, this field resets to an architecturally UNKNOWN value.

    Accessing this field has the following behavior:

    - Access to this field is RAZ/WI if all of the following are true:
      - FEAT\_PMUv3p9 is implemented
      - EL0 is the current Exception level
      - EL1 is using AArch64
      - PMUSERENR\_EL0.UEN == ‘1’
      - PMUACR\_EL1.C == ‘0’
    - Access to this field is RO if all of the following are true:
      - FEAT\_PMUv3p9 is implemented
      - EL0 is the current Exception level
      - EL1 is using AArch64
      - [PMUSERENR\_EL0.UEN, PMUSERENR\_EL0.CR] == ‘11’
    - Otherwise, access to this field is W1S.
