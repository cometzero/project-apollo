##### `0x8329`, REMOTE\_CACHE\_HITM\_RD, Remote cache demand access hit modified, read

The counter counts each cache hit on a remote device counted by [REMOTE\_CACHE\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8328--REMOTE-CACHE-HIT-RD--Remote-cache-demand-access-hit--read?lang=en#event_remote_cache_hit_rd) that accesses a previously modified location.
