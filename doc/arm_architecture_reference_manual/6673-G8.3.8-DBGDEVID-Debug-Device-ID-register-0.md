##### G8.3.8 DBGDEVID, Debug Device ID register 0

The DBGDEVID characteristics are:

Purpose
:   Adds to the information given by the [DBGDIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-11-DBGDIDR--Debug-ID-Register?lang=en#reg_aarch32_dbgdidr) by describing other features of the debug implementation.

Configuration
:   This register is required in all implementations.

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to DBGDEVID are UNDEFINED.

Attributes
:   DBGDEVID is a 32-bit register.
