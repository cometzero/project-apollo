# ​C6.2.304 PACDB, PACDZB

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-304-PACDB--PACDZB>

##### C6.2.304 PACDB, PACDZB

Pointer Authentication Code for data address, using key B

This instruction calculates and inserts a Pointer Authentication Code for a data address, using a modifier and key B.

The address is in the general-purpose register that is specified by `<Xd>`.

The modifier is:

- In the general-purpose register or stack pointer that is specified by `<Xn|SP>` for `PACDB`.
- The value zero, for `PACDZB`.

###### Integer

###### (FEAT\_PAuth)

![](images/0986-C6.2.304-PACDB-PACDZB-img01.svg)

###### Encoding for the PACDB variant

Applies when `(Z == 0)`

```
PACDB  <Xd>, <Xn|SP>
```

###### Encoding for the PACDZB variant

Applies when `(Z == 1 && Rn == 11111)`

```
PACDZB  <Xd>
```

###### Decode for all variants of this encoding

```
if !IsFeatureImplemented(FEAT_PAuth) then EndOfDecode(Decode_UNDEF); end;
var source_is_sp : boolean = FALSE;
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
if Z == ‘0’ then // PACDB
    if n == 31 then source_is_sp = TRUE; end;
else // PACDZB
    if n != 31 then EndOfDecode(Decode_UNDEF); end;
end;
```

###### Assembler Symbols

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Xn|SP>
:   ​

    Is the 64-bit name of the general-purpose source register or stack pointer, encoded in the “Rn” field.

###### Operation

```
if source_is_sp then
    X{64}(d) = AddPACDB(X{64}(d), SP{64}());
else
    X{64}(d) = AddPACDB(X{64}(d), X{64}(n));
end;
```
