# ​C6.2.155 EOR (immediate)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-155-EOR--immediate->

##### C6.2.155 EOR (immediate)

Bitwise exclusive-OR (immediate)

This instruction performs a bitwise exclusive-OR between a register value and an immediate value, and writes the result to the destination register.

![](images/0837-C6.2.155-EOR-immediate-img01.svg)

###### Encoding for the 32-bit variant

Applies when `(sf == 0 && N == 0)`

```
EOR  <Wd|WSP>, <Wn>, #<imm>
```

###### Encoding for the 64-bit variant

Applies when `(sf == 1)`

```
EOR  <Xd|SP>, <Xn>, #<imm>
```

###### Decode for all variants of this encoding

```
if sf == ‘0’ && N != ‘0’ then EndOfDecode(Decode_UNDEF); end;
let d : integer{} = UInt(Rd);
let n : integer{} = UInt(Rn);
let datasize : integer{} = 32 << UInt(sf);
var imm : bits(datasize);
(imm, -) = DecodeBitMasks{datasize}(N, imms, immr, TRUE);
```

###### Assembler Symbols

<Wd|WSP>
:   ​

    Is the 32-bit name of the destination general-purpose register or stack pointer, encoded in the “Rd” field.

<Wn>
:   ​

    Is the 32-bit name of the general-purpose source register, encoded in the “Rn” field.

<imm>
:   ​

    Is the bitmask immediate. For encoding information, see [Logical (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-5-Data-processing---immediate/-C3-5-3-Logical--immediate-?lang=en#chdbgeib).

<Xd|SP>
:   ​

    Is the 64-bit name of the destination general-purpose register or stack pointer, encoded in the “Rd” field.

<Xn>
:   ​

    Is the 64-bit name of the general-purpose source register, encoded in the “Rn” field.

###### Operation

```
let operand1 : bits(datasize) = X{}(n);
let operand2 : bits(datasize) = imm;
let result : bits(datasize) = operand1 XOR operand2;
if d == 31 then
    SP{64}() = ZeroExtend{64}(result);
else
    X{datasize}(d) = result;
end;
```

###### Operational Information

This instruction is a data-independent-time instruction as described in [About PSTATE.DIT](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-5-Software-control-features-and-EL0/-B1-5-6-About-PSTATE-DIT?lang=en#beiccddab3).
