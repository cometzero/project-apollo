##### H9.3.20 TRCDEVAFF, Trace Device Affinity Register

The TRCDEVAFF characteristics are:

Purpose
:   For additional information, see the CoreSight Architecture Specification.

    Reads the same value as the [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1) register for the PE that this trace unit has affinity with.

Configuration
:   This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCDEVAFF are RES0.

Attributes
:   TRCDEVAFF is a 64-bit register.

:   Reserved, RES0.

Aff3, bits [39:32]
:   Affinity level 3. See the description of Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

:   Reserved, RAO/WI.

:   Affinity level 2. See the description of Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

:   Affinity level 1. See the description of Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

Aff0, bits [7:0]
:   Affinity level 0. The value of the [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).{Aff2, Aff1, Aff0} or [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1).{Aff3, Aff2, Aff1, Aff0} set of fields of each PE must be unique within the system as a whole.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
