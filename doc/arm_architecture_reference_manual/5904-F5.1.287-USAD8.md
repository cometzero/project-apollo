##### F5.1.287 USAD8

Unsigned Sum of Absolute Differences

Unsigned Sum of Absolute Differences performs four unsigned 8-bit subtractions, and adds the absolute values of the differences together.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-287-USAD8?lang=en#isa_usad8_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-287-USAD8?lang=en#isa_usad8_iclass_t1)).


###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let absdiff1 : integer = Abs(UInt(R(n)[7:0])   - UInt(R(m)[7:0]));
    let absdiff2 : integer = Abs(UInt(R(n)[15:8])  - UInt(R(m)[15:8]));
    let absdiff3 : integer = Abs(UInt(R(n)[23:16]) - UInt(R(m)[23:16]));
    let absdiff4 : integer = Abs(UInt(R(n)[31:24]) - UInt(R(m)[31:24]));
    let result : integer = absdiff1 + absdiff2 + absdiff3 + absdiff4;
    R(d) = result[31:0];
end;
```
