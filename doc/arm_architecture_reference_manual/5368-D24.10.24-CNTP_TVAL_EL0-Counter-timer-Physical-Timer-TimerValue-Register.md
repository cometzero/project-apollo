# ​D24.10.24 CNTP_TVAL_EL0, Counter-timer Physical Timer TimerValue Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-24-CNTP-TVAL-EL0--Counter-timer-Physical-Timer-TimerValue-Register>

##### D24.10.24 CNTP\_TVAL\_EL0, Counter-timer Physical Timer TimerValue Register

The CNTP\_TVAL\_EL0 characteristics are:

Purpose
:   Holds the timer value for the EL1 physical timer.

Configuration
:   AArch64 System register CNTP\_TVAL\_EL0 bits [31:0] are architecturally mapped to AArch32 System register [CNTP\_TVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-18-CNTP-TVAL--Counter-timer-Physical-Timer-TimerValue-register?lang=en#reg_aarch32_cntp_tval)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTP\_TVAL\_EL0 are UNDEFINED.

Attributes
:   CNTP\_TVAL\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5368-D24.10.24-CNTP_TVAL_EL0-Counter-timer-Physical-Timer-TimerValue-Register-img01.svg)

Bits [63:32]
:   Reserved, RES0.

TimerValue, bits [31:0]
:   The TimerValue view of the EL1 physical timer.

    On a read of this register:

    - If [CNTP\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-22-CNTP-CTL-EL0--Counter-timer-Physical-Timer-Control-Register?lang=en#reg_aarch64_cntp_ctl_el0).ENABLE is 0, the value returned is UNKNOWN.
    - If [CNTP\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-22-CNTP-CTL-EL0--Counter-timer-Physical-Timer-Control-Register?lang=en#reg_aarch64_cntp_ctl_el0).ENABLE is 1, the value returned is ([CNTP\_CVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-23-CNTP-CVAL-EL0--Counter-timer-Physical-Timer-CompareValue-Register?lang=en#reg_aarch64_cntp_cval_el0) - [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0)).

    On a write of this register, [CNTP\_CVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-23-CNTP-CVAL-EL0--Counter-timer-Physical-Timer-CompareValue-Register?lang=en#reg_aarch64_cntp_cval_el0) is set to ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) + TimerValue), where TimerValue is treated as a signed 32-bit integer.

    When [CNTP\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-22-CNTP-CTL-EL0--Counter-timer-Physical-Timer-Control-Register?lang=en#reg_aarch64_cntp_ctl_el0).ENABLE is 1, the timer condition is met when ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) - [CNTP\_CVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-23-CNTP-CVAL-EL0--Counter-timer-Physical-Timer-CompareValue-Register?lang=en#reg_aarch64_cntp_cval_el0)) is greater than or equal to zero. This means that TimerValue acts like a 32-bit downcounter timer. When the timer condition is met:

    - [CNTP\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-22-CNTP-CTL-EL0--Counter-timer-Physical-Timer-Control-Register?lang=en#reg_aarch64_cntp_ctl_el0).ISTATUS is set to 1.
    - If [CNTP\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-22-CNTP-CTL-EL0--Counter-timer-Physical-Timer-Control-Register?lang=en#reg_aarch64_cntp_ctl_el0).IMASK is 0, an interrupt is generated.

    When [CNTP\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-22-CNTP-CTL-EL0--Counter-timer-Physical-Timer-Control-Register?lang=en#reg_aarch64_cntp_ctl_el0).ENABLE is 0, the TimerValue cannot be read but continues to decrement. When the timer is enabled, the TimerValue represents the elapsed time whether that time was spent enabled or disabled.

    > #### Note
    >
    > The value of [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) used in these calculations is the value seen at the Exception level that the [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) register is being read or written from.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing CNTP\_TVAL\_EL0

When the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, without explicit synchronization, accesses from EL3 using the accessor name `CNTP_TVAL_EL0` or `CNTP_TVAL_EL02` are not guaranteed to be ordered with respect to accesses using the other accessor name.
