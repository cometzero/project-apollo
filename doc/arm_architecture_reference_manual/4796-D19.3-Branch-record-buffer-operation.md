# ​D19.3 Branch record buffer operation

#### D19.3 Branch record buffer operation

R LKWNB
:   The Branch Record Buffer Extension operation is controlled by the [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1), [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2), and [BRBFCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-3-BRBFCR-EL1--Branch-Record-Buffer-Function-Control-Register?lang=en#reg_aarch64_brbfcr_el1) registers.

R PYBRZ
:   Generation of [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is *paused* when [BRBFCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-3-BRBFCR-EL1--Branch-Record-Buffer-Function-Control-Register?lang=en#reg_aarch64_brbfcr_el1).PAUSED is 1.

R YDZNK
:   When generation of [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is [paused](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-3-Branch-record-buffer-operation?lang=en#brbe_paused), [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) are not generated.

R NXCWF
:   If EL2 is implemented, a BRBE freeze event occurs when all of the following are true:

    - [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).FZP is 1.
    - Generation of [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is not [paused](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-3-Branch-record-buffer-operation?lang=en#brbe_paused).
    - [PMOVSCLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-19-PMOVSCLR-EL0--Performance-Monitors-Overflow-Flag-Status-Clear-Register?lang=en#reg_aarch64_pmovsclr_el0)[([MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN-1):0] is nonzero.
    - The PE is in a BRBE Non-prohibited region.

R GXGWY
:   If EL2 is implemented, a BRBE freeze event occurs when all of the following are true:

    - [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).FZP is 1.
    - Generation of [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is not [paused](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-3-Branch-record-buffer-operation?lang=en#brbe_paused).
    - [PMOVSCLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-19-PMOVSCLR-EL0--Performance-Monitors-Overflow-Flag-Status-Clear-Register?lang=en#reg_aarch64_pmovsclr_el0)[([PMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-8-PMCR-EL0--Performance-Monitors-Control-Register?lang=en#reg_aarch64_pmcr_el0).N-1):[MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN] is nonzero.
    - The PE is in a BRBE Non-prohibited region.

    This applies even when EL2 is disabled in the current Security state.

R PKTXQ
:   If EL2 is not implemented, a BRBE freeze event occurs when all of the following are true:

    - [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).FZP is 1.
    - Generation of [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is not [paused](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-3-Branch-record-buffer-operation?lang=en#brbe_paused).
    - [PMOVSCLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-19-PMOVSCLR-EL0--Performance-Monitors-Overflow-Flag-Status-Clear-Register?lang=en#reg_aarch64_pmovsclr_el0)[([PMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-8-PMCR-EL0--Performance-Monitors-Control-Register?lang=en#reg_aarch64_pmcr_el0).N-1):0] is nonzero.
    - The PE is in a BRBE Non-prohibited region.

R LDMVK
:   If [FEAT\_PMUv3\_ICNTR](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_pmuv3_icntr) is implemented, then a BRBE freeze event occurs when all of the following are true:

    - [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).FZP is 1.
    - Generation of [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is not [paused](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-3-Branch-record-buffer-operation?lang=en#brbe_paused).
    - [PMOVSCLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-19-PMOVSCLR-EL0--Performance-Monitors-Overflow-Flag-Status-Clear-Register?lang=en#reg_aarch64_pmovsclr_el0).F0 is 1.
    - The PE is in a BRBE non-Prohibited Region.

R LBQZR
:   If [FEAT\_PMUv3\_SS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_pmuv3_ss) is implemented, on a successful Capture event, then a BRBE freeze event occurs when all of the following are true:

    - [FEAT\_BRBE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_brbe) is implemented.
    - [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).FZPSS is 1.
    - Either EL2 is not implemented or [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).FZPSS is 1.

      This applies even when EL2 is disabled in the current Security state.
    - Generation of [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is not [paused](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-3-Branch-record-buffer-operation?lang=en#brbe_paused).
    - The PE is in a non-Prohibited Region.

I YTVCC
:   Where a branch instruction, exception, or Debug state entry or exit causes a change to whether execution is in a Prohibited region and this change results in the conditions for a BRBE freeze event to be met, it is IMPLEMENTATION SPECIFIC whether the instruction, exception, Debug state entry or exit generates a Branch record before the BRBE freeze event occurs, or does not generate a Branch record because the BRBE freeze event has already occurred and branch record generation is paused.

    This means the Branch record might or might not be captured before the BRBE freeze occurs.

R BHYTD
:   On a BRBE freeze event:

    - [BRBFCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-3-BRBFCR-EL1--Branch-Record-Buffer-Function-Control-Register?lang=en#reg_aarch64_brbfcr_el1).PAUSED is set to 1.
    - The current timestamp is captured in [BRBTS\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-11-BRBTS-EL1--Branch-Record-Buffer-Timestamp-Register?lang=en#reg_aarch64_brbts_el1).

R QKQZL
:   The source of value of the timestamp captured in [BRBTS\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-11-BRBTS-EL1--Branch-Record-Buffer-Timestamp-Register?lang=en#reg_aarch64_brbts_el1) is selected by the combination of programming of [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).TS and [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).TS. See [Table D19-11](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-3-Branch-record-buffer-operation?lang=en#tbl_mdtbl_brb_ts_summary) and [`BRBETimeStamp`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-13-BRBETimeStamp?lang=en#asl_func_brbetimestamp_0)`()`.

    The timestamp is a choice between:

    - Physical time, which is defined by the physical count value returned by [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()`.
    - If [FEAT\_ECV](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_ecv) is implemented, offset physical time, which is defined as the value of [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()` minus a physical offset.

      If any of the following are true, the physical offset is zero:

      - EL2 is not implemented.
      - [FEAT\_ECV\_POFF](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_ecv_poff) is not implemented.
      - [CNTHCTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-2-CNTHCTL-EL2--Counter-timer-Hypervisor-Control-Register?lang=en#reg_aarch64_cnthctl_el2).ECV is 0.
      - EL3 is implemented and [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).ECVEn is 0.

      Otherwise the physical offset is the value of [CNTPOFF\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-18-CNTPOFF-EL2--Counter-timer-Physical-Offset-Register?lang=en#reg_aarch64_cntpoff_el2).
    - Virtual time, which is defined as the value of [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()` minus a virtual offset.

      If any of the following are true, the virtual offset is zero:

      - EL2 is not implemented.

      Otherwise, the virtual offset is always [CNTVOFF\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-27-CNTVOFF-EL2--Counter-timer-Virtual-Offset-Register?lang=en#reg_aarch64_cntvoff_el2), including when a read of [CNTVCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register?lang=en#reg_aarch64_cntvct_el0) at the current Exception level would treat the virtual offset as zero.

I RMGDV
:   The architecture does not define when PMU events are counted relative to the instructions that caused the event. Events generated by an instruction might be counted before or after the instruction becomes architecturally executed, and events might be counted for operations that do not become architecturally executed. This means that events can be counted speculatively and/or out-of-order regarding the simple sequential execution of the program. Events might also be counted simultaneously by other event counters when the overflow occurs, including events from different instructions. In addition, multiple instances of an event might occur simultaneously, meaning that an event counter unsigned overflow can yield a nonzero value in the event counter.

    Furthermore, the [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) are generated only for architecturally executed operations. See [RKXTKS](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-8-PE-speculation?lang=en#kxtks).

    These properties mean that, unless otherwise stated, on a BRBE freeze event, it is CONSTRAINED UNPREDICTABLE whether the branches that define the basic block containing the instruction causing that event are captured in the Branch record buffer.

    An exception to this relaxation applies for the [BRB\_FILTRATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x811F--BRB-FILTRATE--Branch-Record-captured?lang=en#event_brb_filtrate) event.
