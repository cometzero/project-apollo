Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-52-TRCPIDR0--Trace-Peripheral-Identification-Register-0>

##### H9.3.52 TRCPIDR0, Trace Peripheral Identification Register 0

The TRCPIDR0 characteristics are:

Purpose
:   Provides discovery information about the component.

    For additional information, see the CoreSight Architecture Specification.

Configuration
:   This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCPIDR0 are RES0.

Attributes
:   TRCPIDR0 is a 32-bit register.

###### Field descriptions

![](images/7056-H9.3.52-TRCPIDR0-Trace-Peripheral-Identification-Register-0-img01.svg)

Bits [31:8]
:   Reserved, RES0.

PART\_0, bits [7:0]
:   Part number, which is selected by the designer of the component and stored as follows:

    - For a component with a 12-bit part number:
      - [TRCPIDR1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-53-TRCPIDR1--Trace-Peripheral-Identification-Register-1?lang=en#reg_ext_trcpidr1).PART\_1 contains part number bits [11:8].
      - [TRCPIDR0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-52-TRCPIDR0--Trace-Peripheral-Identification-Register-0?lang=en#reg_ext_trcpidr0).PART\_0 contains part number bits [7:0].
    - For a component with a 16-bit part number:
      - [TRCPIDR1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-53-TRCPIDR1--Trace-Peripheral-Identification-Register-1?lang=en#reg_ext_trcpidr1).PART\_1 contains part number bits [15:12].
      - [TRCPIDR0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-52-TRCPIDR0--Trace-Peripheral-Identification-Register-0?lang=en#reg_ext_trcpidr0).PART\_0 contains part number bits [11:4].
      - [TRCPIDR2](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-54-TRCPIDR2--Trace-Peripheral-Identification-Register-2?lang=en#reg_ext_trcpidr2).REVISION contains part number bits [3:0].

    When a 12-bit part number is used, [TRCPIDR2](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-54-TRCPIDR2--Trace-Peripheral-Identification-Register-2?lang=en#reg_ext_trcpidr2).REVISION indicates revision information.

    The choice of using a 12-bit part number or 16-bit part number is specific to the designer of the component.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
