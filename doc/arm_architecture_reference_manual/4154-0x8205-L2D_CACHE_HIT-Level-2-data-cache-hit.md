##### `0x8205`, L2D\_CACHE\_HIT, Level 2 data cache hit

The counter counts each access counted by [L2D\_CACHE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0016--L2D-CACHE--Level-2-data-cache-access?lang=en#event_l2d_cache) that hits in the Level 2 data or unified cache.
