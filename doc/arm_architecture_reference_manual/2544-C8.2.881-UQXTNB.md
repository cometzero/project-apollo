# ​C8.2.881 UQXTNB

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-881-UQXTNB>

##### C8.2.881 UQXTNB

Unsigned saturating extract narrow (bottom)

This instruction saturates the unsigned integer value in each source element to half the original source element width, and places the results in the even-numbered half-width destination elements, while setting the odd-numbered elements to zero.

###### SVE2

###### (FEAT\_SVE2 || FEAT\_SME)

![](images/2544-C8.2.881-UQXTNB-img01.svg)

###### Encoding

```
UQXTNB  <Zd>.<T>, <Zn>.<Tb>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SVE2) && !IsFeatureImplemented(FEAT_SME) then
    EndOfDecode(Decode_UNDEF);
end;
let tsize : bits(3) = tszh::tszl;
if !(tsize IN {‘001’, ‘010’, ‘100’}) then EndOfDecode(Decode_UNDEF); end;
let esize : integer{} = 16 << HighestSetBitNZ(tsize);
let n : integer = UInt(Zn);
let d : integer = UInt(Zd);
```

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let elements : integer = VL DIV esize;
let operand1 : bits(VL) = Z{}(n);
var result : bits(VL);
let halfesize : integer{} = esize DIV 2;
for e = 0 to elements-1 do
    let element1 : integer = UInt(operand1[e*:esize]);
    let res : bits(halfesize) = UnsignedSat{halfesize}(element1);
    result[(2*e + 0)*:halfesize] = res;
    result[(2*e + 1)*:halfesize] = Zeros{halfesize};
end;
Z{VL}(d) = result;
```
