# ​G8.7.10 CNTHV_CVAL, Counter-timer Virtual Timer CompareValue register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-10-CNTHV-CVAL--Counter-timer-Virtual-Timer-CompareValue-register--EL2->

##### G8.7.10 CNTHV\_CVAL, Counter-timer Virtual Timer CompareValue register (EL2)

The CNTHV\_CVAL characteristics are:

Purpose
:   Provides AArch32 access to the compare value for the EL2 virtual timer.

Configuration
:   AArch32 System register CNTHV\_CVAL bits [63:0] are architecturally mapped to AArch64 System register [CNTHV\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-13-CNTHV-CVAL-EL2--Counter-timer-Virtual-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthv_cval_el2)[63:0].

    This register is present only when FEAT\_AA32 is implemented and FEAT\_VHE is implemented. Otherwise, direct accesses to CNTHV\_CVAL are UNDEFINED.

Attributes
:   CNTHV\_CVAL is a 64-bit register.

###### Field descriptions

![](images/6768-G8.7.10-CNTHV_CVAL-Counter-timer-Virtual-Timer-CompareValue-register-EL2-img01.svg)

CompareValue, bits [63:0]
:   Holds the EL2 virtual timer CompareValue.

    When [CNTHV\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-9-CNTHV-CTL--Counter-timer-Virtual-Timer-Control-register--EL2-?lang=en#reg_aarch32_cnthv_ctl).ENABLE is 1, the timer condition is met when ([CNTVCT](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-24-CNTVCT--Counter-timer-Virtual-Count-register?lang=en#reg_aarch32_cntvct) - CompareValue) is greater than or equal to zero. This means that CompareValue acts like a 64-bit upcounter timer. When the timer condition is met:

    - [CNTHV\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-9-CNTHV-CTL--Counter-timer-Virtual-Timer-Control-register--EL2-?lang=en#reg_aarch32_cnthv_ctl).ISTATUS is set to 1.
    - If [CNTHV\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-9-CNTHV-CTL--Counter-timer-Virtual-Timer-Control-register--EL2-?lang=en#reg_aarch32_cnthv_ctl).IMASK is 0, an interrupt is generated.

    When [CNTHV\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-9-CNTHV-CTL--Counter-timer-Virtual-Timer-Control-register--EL2-?lang=en#reg_aarch32_cnthv_ctl).ENABLE is 0, the timer condition is not met, but [CNTVCT](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-24-CNTVCT--Counter-timer-Virtual-Count-register?lang=en#reg_aarch32_cntvct) continues to count.

    If the Generic counter is implemented at a size less than 64 bits, then this field is permitted to be implemented at the same width as the counter, and the upper bits are RES0.

    The value of this field is treated as zero-extended in all counter calculations.

        AArch64_AArch32SystemAccessTrap(EL2, 0x04);

        AArch64_AArch32SystemAccessTrap(EL2, 0x04);
    elsif EffectivelyAtEL0InHost() && IsCurrentSecurityState(SS_Secure) && IsFeatureImplemented(FEAT_SEL2) then
        R(t, t2) = CNTHVS_CVAL_EL2();
    elsif EffectivelyAtEL0InHost() && !IsCurrentSecurityState(SS_Secure) then
        R(t, t2) = CNTHV_CVAL_EL2();
    else
        R(t, t2) = CNTV_CVAL();
    end;
elsif PSTATE.EL == EL1 then
    if EL2Enabled() && IsFeatureImplemented(FEAT_AA64EL2) && !ELUsingAArch32(EL2) && IsFeatureImplemented(FEAT_ECV) && CNTHCTL_EL2().EL1TVT == '1' then
        AArch64_AArch32SystemAccessTrap(EL2, 0x04);
    else
        R(t, t2) = CNTV_CVAL();
    end;
elsif PSTATE.EL == EL2 then
    R(t, t2) = CNTV_CVAL();
elsif PSTATE.EL == EL3 then
    R(t, t2) = CNTV_CVAL();
end;
