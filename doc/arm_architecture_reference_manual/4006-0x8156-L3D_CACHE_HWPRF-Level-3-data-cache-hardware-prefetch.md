##### `0x8156`, L3D\_CACHE\_HWPRF, Level 3 data cache hardware prefetch

The counter counts each access counted by [L3D\_CACHE\_PRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8286--L3D-CACHE-PRF--Level-3-data-cache--prefetch-hit?lang=en#event_l3d_cache_prf) that is due to a hardware prefetch.

The hardware prefetch is generated by a hardware prefetcher at the Level 3 data or unified cache.
