# ​D24.10.8 CNTHP_TVAL_EL2, Counter-timer Physical Timer TimerValue Register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-8-CNTHP-TVAL-EL2--Counter-timer-Physical-Timer-TimerValue-Register--EL2->

##### D24.10.8 CNTHP\_TVAL\_EL2, Counter-timer Physical Timer TimerValue Register (EL2)

The CNTHP\_TVAL\_EL2 characteristics are:

Purpose
:   Holds the timer value for the EL2 physical timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch64 System register CNTHP\_TVAL\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [CNTHP\_TVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-5-CNTHP-TVAL--Counter-timer-Hyp-Physical-Timer-TimerValue-register?lang=en#reg_aarch32_cnthp_tval)[31:0].

    This register is present only when (HaveEL(EL3) || (((!HaveEL(EL3)) && HaveEL(EL2)) && (!IsFeatureImplemented(FEAT\_SEL2)))) && IsFeatureImplemented(FEAT\_AA64). Otherwise, direct accesses to CNTHP\_TVAL\_EL2 are UNDEFINED.

Attributes
:   CNTHP\_TVAL\_EL2 is a 64-bit register.

###### Field descriptions

![](images/5352-D24.10.8-CNTHP_TVAL_EL2-Counter-timer-Physical-Timer-TimerValue-Register-EL2-img01.svg)

Bits [63:32]
:   Reserved, RES0.

TimerValue, bits [31:0]
:   The TimerValue view of the EL2 physical timer.

    On a read of this register:

    - If [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ENABLE is 0, the value returned is UNKNOWN.
    - If [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ENABLE is 1, the value returned is ([CNTHP\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-7-CNTHP-CVAL-EL2--Counter-timer-Physical-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthp_cval_el2) - [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0)).

    On a write of this register, [CNTHP\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-7-CNTHP-CVAL-EL2--Counter-timer-Physical-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthp_cval_el2) is set to ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) + TimerValue), where TimerValue is treated as a signed 32-bit integer.

    When [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ENABLE is 1, the timer condition is met when ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) - [CNTHP\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-7-CNTHP-CVAL-EL2--Counter-timer-Physical-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthp_cval_el2)) is greater than or equal to zero. This means that TimerValue acts like a 32-bit downcounter timer. When the timer condition is met:

    - [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ISTATUS is set to 1.
    - If [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).IMASK is 0, an interrupt is generated.

    When [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ENABLE is 0, the TimerValue cannot be read but continues to decrement. When the timer is enabled, the TimerValue represents the elapsed time whether that time was spent enabled or disabled.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing CNTHP\_TVAL\_EL2

When the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, without explicit synchronization, accesses from EL2 using the accessor name `CNTHP_TVAL_EL2` or `CNTP_TVAL_EL0` are not guaranteed to be ordered with respect to accesses using the other accessor name.
