#### D14.5 Meaningful combinations of common events

The meaningful combinations listed in this section comprise a numerator event and a denominator event.

In many cases, the definition of the numerator event, <EVENT\_NUMERATOR>, is defined such that it counts each event <X> counted by the denominator event, <EVENT\_DENOMINATOR>, when some condition <COND> is true.

This means that there is a meaningful ratio between between <EVENT\_NUMERATOR> and <EVENT\_DENOMINATOR> that describes the proportion of <X> counted by <EVENT\_DENOMINATOR> for which <COND> applies.

This does not mean that there is a requirement that if <EVENT\_NUMERATOR> is implemented that <EVENT\_DENOMINATOR> is also implemented.

A *meaningful combination* means that any microarchitectural conditions that affect the counting of events apply equally to all the events. This typically means that they are counted at the same place in the pipeline, so that, for example, they are equally affected by pipeline flushes to discard speculatively executed operations following a mispredicted branch.
