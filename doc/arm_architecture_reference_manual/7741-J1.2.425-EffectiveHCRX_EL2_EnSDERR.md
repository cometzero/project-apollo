# ​J1.2.425 EffectiveHCRX_EL2_EnSDERR

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-425-EffectiveHCRX-EL2-EnSDERR>

##### J1.2.425 EffectiveHCRX\_EL2\_EnSDERR

```
// EffectiveHCRX_EL2_EnSDERR()
// ===========================
// Return the Effective value of HCRX_EL2().EnSDERR
func EffectiveHCRX_EL2_EnSDERR() => bit
begin
    if !IsHCRXEL2Enabled() then return ‘0’; end;
    if ELIsInHost(EL0) then return ‘0’; end;
     if (IsFeatureImplemented(FEAT_ANERR) && GetADERRErrorMode() == ErrSignalMode_TiedToPeer &&
           HCRX_EL2().[EnSDERR, EnSNERR] == ‘10’) then
        return ‘0’;
    end;
    return HCRX_EL2().EnSDERR;
end;
```
