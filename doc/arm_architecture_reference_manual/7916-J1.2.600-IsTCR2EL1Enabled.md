# ​J1.2.600 IsTCR2EL1Enabled

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-600-IsTCR2EL1Enabled>

##### J1.2.600 IsTCR2EL1Enabled

```
// IsTCR2EL1Enabled()
// ==================
// Returns TRUE if access to TCR2_EL1 register is enabled, and FALSE otherwise.
// Indirect read of TCR2_EL1 returns 0 when access is not enabled.
func IsTCR2EL1Enabled() => boolean
begin
    if !IsFeatureImplemented(FEAT_TCR2) then return FALSE; end;
    if HaveEL(EL3) && SCR_EL3().TCR2En == ‘0’ then
        return FALSE;
    elsif (EL2Enabled() && (!IsHCRXEL2Enabled() || HCRX_EL2().TCR2En == ‘0’)) then
        return FALSE;
    else
        return TRUE;
    end;
end;
```
