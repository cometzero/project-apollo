# ​F5.1.34 CMN (register)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-34-CMN--register->

##### F5.1.34 CMN (register)

Compare Negative (register) adds a register value and an optionally-shifted register value. It updates the condition flags based on the result, and discards the result.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-34-CMN--register-?lang=en#isa_cmn_r_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-34-CMN--register-?lang=en#isa_cmn_r_iclass_t1) and [T2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-34-CMN--register-?lang=en#isa_cmn_r_iclass_t2)).

###### A1

![](images/5651-F5.1.34-CMN-register-img01.svg)

###### Encoding for the Rotate right with extend variant

Applies when `(imm5 == 00000 && stype == 11)`

```
CMN{<c>}{<q>}  <Rn>, <Rm>, RRX
```

###### Encoding for the Shift or rotate by value variant

Applies when `(!(imm5 == 00000 && stype == 11))`

```
CMN{<c>}{<q>}  <Rn>, <Rm> {, <shift> #<amount>}
```

###### Decode for all variants of this encoding

```
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let (shift_t, shift_n) : (SRType, integer) = DecodeImmShift(stype, imm5);
```

###### T1

![](images/5651-F5.1.34-CMN-register-img02.svg)

###### Encoding

```
CMN{<c>}{<q>}  <Rn>, <Rm>
```

###### Decode for this encoding

```
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let shift_t : SRType = SRType_LSL;
let shift_n : integer = 0;
```

###### T2

![](images/5651-F5.1.34-CMN-register-img03.svg)

###### Encoding for the Rotate right with extend variant

Applies when `(imm3 == 000 && imm2 == 00 && stype == 11)`

```
CMN{<c>}{<q>}  <Rn>, <Rm>, RRX
```

###### Encoding for the Shift or rotate by value variant

Applies when `(!(imm3 == 000 && imm2 == 00 && stype == 11))`

```
CMN{<c>}{<q>}  <Rn>, <Rm> {, <shift> #<amount>}
```

```
CMN{<c>}.W  <Rn>, <Rm> // (<Rn>, <Rm> can be represented in T1)
```

###### Decode for all variants of this encoding

```
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let (shift_t, shift_n) : (SRType, integer) = DecodeImmShift(stype, imm3::imm2);
// Armv8-A removes UNPREDICTABLE for R13
if n == 15 || m == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

<Rn>
:   ​

    For the “A1 Rotate right with extend” and “A1 Shift or rotate by value” variants: is the first general-purpose source register, encoded in the “Rn” field. The PC can be used, but this is deprecated.

    ​

    For the “T1”, “T2 Rotate right with extend”, and “T2 Shift or rotate by value” variants: is the first general-purpose source register, encoded in the “Rn” field.

<Rm>
:   ​

    For the “A1 Rotate right with extend” and “A1 Shift or rotate by value” variants: is the second general-purpose source register, encoded in the “Rm” field. The PC can be used, but this is deprecated.

    ​

    For the “T1”, “T2 Rotate right with extend”, and “T2 Shift or rotate by value” variants: is the second general-purpose source register, encoded in the “Rm” field.

<amount>
:   ​

    For the “A1 Shift or rotate by value” variant: is the shift amount, in the range 1 to 31 (when <shift> = LSL or ROR) or 1 to 32 (when <shift> = LSR or ASR) encoded in the “imm5” field as <amount> modulo 32.

    ​

    For the “T2 Shift or rotate by value” variant: is the shift amount, in the range 1 to 31 (when <shift> = LSL or ROR) or 1 to 32 (when <shift> = LSR or ASR), encoded in the “imm3:imm2” field as <amount> modulo 32.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let shifted : bits(32) = Shift{}(R(m), shift_t, shift_n, PSTATE.C);
    let (result, nzcv) : (bits(32), bits(4)) = AddWithCarry{32}(R(n), shifted, ‘0’);
    PSTATE.[N,Z,C,V] = nzcv;
end;
```

###### Operational Information

This instruction is a data-independent-time instruction as described in [About the DIT bit](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-5-About-the-DIT-bit?lang=en#beiidceg).
