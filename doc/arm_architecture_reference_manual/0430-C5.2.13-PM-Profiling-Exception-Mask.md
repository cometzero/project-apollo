# ​C5.2.13 PM, Profiling Exception Mask

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-13-PM--Profiling-Exception-Mask>

##### C5.2.13 PM, Profiling Exception Mask

The PM characteristics are:

Purpose
:   Allows access to the Profiling exception Mask bit.

Configuration
:   This register is a Special-purpose register.

    This register is present only when ((IsFeatureImplemented(FEAT\_EBEP) || IsFeatureImplemented(FEAT\_SPE\_EXC)) || IsFeatureImplemented(FEAT\_TRBE\_EXC)) && IsFeatureImplemented(FEAT\_AA64). Otherwise, direct accesses to PM are UNDEFINED.

Attributes
:   PM is a 64-bit register.

###### Field descriptions

![](images/0430-C5.2.13-PM-Profiling-Exception-Mask-img01.svg)

Bits [63:33]
:   Reserved, RES0.

PM, bit [32]
:   PMU Exception Mask.

Bits [31:0]
:   Reserved, RES0.
