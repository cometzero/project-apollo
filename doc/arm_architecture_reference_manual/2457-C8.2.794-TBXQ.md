# ​C8.2.794 TBXQ

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-794-TBXQ>

##### C8.2.794 TBXQ

Programmable table lookup within each quadword vector segment (merging)

This instruction reads, for each 128-bit destination vector segment, each element of the corresponding second source (index) vector segment and uses its value to select an indexed element from the corresponding first source (table) vector segment. The indexed table element is placed in the element of the destination vector that corresponds to the index vector element. If an index value is greater than or equal to the number of elements in a 128-bit vector segment then the corresponding destination vector element is left unchanged. This instruction is unpredicated.

TBXQ  <Zd>.<T>, <Zn>.<T>, <Zm>.<T>
```

```
if !IsFeatureImplemented(FEAT_SVE2p1) && !IsFeatureImplemented(FEAT_SME2p1) then

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let segments : integer = VL DIV 128;
let elements : integer = 128 DIV esize;
let operand1 : bits(VL) = Z{}(n);
let operand2 : bits(VL) = Z{}(m);
var result : bits(VL) = Z{}(d);
for s = 0 to segments-1 do
    for e = 0 to elements-1 do
        let idx : integer = UInt(operand2[(s * elements + e)*:esize]);
        if idx < elements then
            result[(s * elements + e)*:esize] = operand1[(s * elements + idx)*:esize];
        end;
    end;
end;
Z{VL}(d) = result;
```
