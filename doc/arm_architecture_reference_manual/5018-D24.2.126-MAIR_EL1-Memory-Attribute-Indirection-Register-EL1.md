# ​D24.2.126 MAIR_EL1, Memory Attribute Indirection Register (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-126-MAIR-EL1--Memory-Attribute-Indirection-Register--EL1->

##### D24.2.126 MAIR\_EL1, Memory Attribute Indirection Register (EL1)

The MAIR\_EL1 characteristics are:

Purpose
:   Provides the memory attribute encodings corresponding to the possible AttrIndx values in a Long-descriptor format translation table entry for stage 1 translations at EL1.

Configuration
:   When TTBCR.EAE == ‘0’, AArch64 System register MAIR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [PRRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-122-PRRR--Primary-Region-Remap-Register?lang=en#reg_aarch32_prrr)[31:0].

    When TTBCR.EAE == ‘1’, AArch64 System register MAIR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [MAIR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-111-MAIR0--Memory-Attribute-Indirection-Register-0?lang=en#reg_aarch32_mair0)[31:0].

    When TTBCR.EAE == ‘0’, AArch64 System register MAIR\_EL1 bits [63:32] are architecturally mapped to AArch32 System register [NMRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register?lang=en#reg_aarch32_nmrr)[31:0].

    When TTBCR.EAE == ‘1’, AArch64 System register MAIR\_EL1 bits [63:32] are architecturally mapped to AArch32 System register [MAIR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-112-MAIR1--Memory-Attribute-Indirection-Register-1?lang=en#reg_aarch32_mair1)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to MAIR\_EL1 are UNDEFINED.

Attributes
:   MAIR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5018-D24.2.126-MAIR_EL1-Memory-Attribute-Indirection-Register-EL1-img01.svg)

MAIR\_EL1 is permitted to be cached in a TLB.

Attr<n> , bits [8n+7:8n], for n = 7 to 0
:   Memory Attribute encoding.

    When FEAT\_AIE is implemented and stage 1 Attributes Index Extension is enabled and AttrIndx[3] in a Long descriptor format translation table entry is 0, or when FEAT\_AIE is not implemented, AttrIndx[2:0] gives the value of <n> in Attr<n>.

    When FEAT\_AIE is implemented and stage 1 Attributes Index Extension is enabled and AttrIndx[3] in a Long descriptor format translation table entry is 1, see MAIR2\_EL1.Attr

###### Accessing MAIR\_EL1

When the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, without explicit synchronization, accesses from EL3 using the accessor name `MAIR_EL1` or `MAIR_EL12` are not guaranteed to be ordered with respect to accesses using the other accessor name.
