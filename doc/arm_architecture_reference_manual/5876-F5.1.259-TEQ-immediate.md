##### F5.1.259 TEQ (immediate)

Test Equivalence (immediate) performs a bitwise exclusive OR operation on a register value and an immediate value. It updates the condition flags based on the result, and discards the result.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-259-TEQ--immediate-?lang=en#isa_teq_i_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-259-TEQ--immediate-?lang=en#isa_teq_i_iclass_t1)).

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let (imm32, carry) : (bits(32), bit) = (if a32 then A32ExpandImm_C(imm, PSTATE.C)
                                                   else T32ExpandImm_C(imm, PSTATE.C));
    let result : bits(32) = R(n) XOR imm32;
    PSTATE.N = result[31];
    PSTATE.Z = IsZeroBit{32}(result);
    PSTATE.C = carry;
    // PSTATE.V unchanged
end;
```
