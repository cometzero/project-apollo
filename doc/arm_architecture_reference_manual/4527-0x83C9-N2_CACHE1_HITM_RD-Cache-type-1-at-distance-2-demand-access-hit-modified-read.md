##### `0x83C9`, N2\_CACHE1\_HITM\_RD, Cache type 1 at distance 2 demand access hit modified, read

The counter counts each demand read counted by [N2\_CACHE\_HITM\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83C1--N2-CACHE-HITM-RD--Cache-at-distance-2--demand-access-hit-modified--read?lang=en#event_n2_cache_hitm_rd) that accesses a previously modified location in a first cache type at distance 2.

The definition of cache types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
