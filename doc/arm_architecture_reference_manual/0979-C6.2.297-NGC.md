##### C6.2.297 NGC

Negate with carry

This instruction negates the sum of a register value and the value of NOT (Carry flag), and writes the result to the destination register.

This is an alias of [SBC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-352-SBC?lang=en#isa_sbc). This means:

- The encodings in this description are named to match the encodings of [SBC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-352-SBC?lang=en#isa_sbc).
- The description of [SBC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-352-SBC?lang=en#isa_sbc) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the 32-bit variant

Applies when `(sf == 0)`

```
NGC  <Wd>, <Wm>
```

is equivalent to

```
SBC  <Wd>, WZR, <Wm>
```

and is always the preferred disassembly.

###### Encoding for the 64-bit variant

Applies when `(sf == 1)`

```
NGC  <Xd>, <Xm>
```

is equivalent to

```
SBC  <Xd>, XZR, <Xm>
```

and is always the preferred disassembly.

###### Assembler Symbols

<Wd>
:   ​

    Is the 32-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Wm>
:   ​

    Is the 32-bit name of the general-purpose source register, encoded in the “Rm” field.

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Xm>
:   ​

    Is the 64-bit name of the general-purpose source register, encoded in the “Rm” field.
