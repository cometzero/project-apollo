##### J1.4.201 SHA256hashSIGMA1

```
// SHA256hashSIGMA1()
// ==================
func SHA256hashSIGMA1(x : bits(32)) => bits(32)
begin
    return ROR(x, 6) XOR ROR(x, 11) XOR ROR(x, 25);
end;
```
