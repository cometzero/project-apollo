##### C6.2.310 PACIB171615

Pointer Authentication Code for instruction address, using key B

This instruction calculates and inserts a pointer authentication code for an instruction address, using two modifiers and key B. The address is in X17. The 64-bit value of modifier1 is the value in X16. The 64-bit value of modifier2 is the value in X15.
