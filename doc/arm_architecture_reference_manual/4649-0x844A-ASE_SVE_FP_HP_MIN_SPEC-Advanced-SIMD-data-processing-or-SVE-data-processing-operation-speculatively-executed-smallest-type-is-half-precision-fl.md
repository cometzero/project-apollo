##### `0x844A`, ASE\_SVE\_FP\_HP\_MIN\_SPEC, Advanced SIMD data processing or SVE data processing operation speculatively executed, smallest type is half-precision floating-point

The counter counts each Advanced SIMD or SVE data-processing operation counted by [SE\_FP\_HP\_MIN\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8452--SE-FP-HP-MIN-SPEC--Advanced-SIMD--SVE--or-SME-data-processing-operation-speculatively-executed--smallest-type-is-half-precision-floating-point?lang=en#event_se_fp_hp_min_spec) due to an instruction where the smallest type was half-precision floating-point.
