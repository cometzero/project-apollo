##### `0x81CD`, L2D\_CACHE\_HIT\_RW, Level 2 data cache demand access hit

The counter counts each demand access counted by [L2D\_CACHE\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8148--L2D-CACHE-RW--Level-2-data-cache-demand-access?lang=en#event_l2d_cache_rw) that hits in the Level 2 data or unified cache.
