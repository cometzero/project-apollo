##### `0x8297`, DSNP\_HIT\_REMOTE\_PRF, Snoop hit in remote cache, data prefetch

The counter counts each snoop generated by the PE in response to a data prefetch instruction, or by a data hardware prefetch counted by [DSNP\_HIT\_PRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8294--DSNP-HIT-PRF--Snoop-hit--data-prefetch?lang=en#event_dsnp_hit_prf) that hits in a cache on a remote device.

The event is counted by the PE generating the snoop, not the PE being snooped.
