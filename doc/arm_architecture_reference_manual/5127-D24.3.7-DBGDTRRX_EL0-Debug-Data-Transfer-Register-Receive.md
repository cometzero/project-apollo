# ​D24.3.7 DBGDTRRX_EL0, Debug Data Transfer Register, Receive

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-7-DBGDTRRX-EL0--Debug-Data-Transfer-Register--Receive>

##### D24.3.7 DBGDTRRX\_EL0, Debug Data Transfer Register, Receive

The DBGDTRRX\_EL0 characteristics are:

Purpose
:   Transfers data from an external debugger to the PE. For example, it is used by a debugger transferring commands and data to a debug target. See [DBGDTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-6-DBGDTR-EL0--Debug-Data-Transfer-Register--half-duplex?lang=en#reg_aarch64_dbgdtr_el0) for additional architectural mappings. It is a component of the Debug Communications Channel.

Configuration
:   AArch64 System register DBGDTRRX\_EL0 bits [31:0] are architecturally mapped to AArch32 System register [DBGDTRRXint](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-17-DBGDTRRXint--Debug-Data-Transfer-Register--Receive?lang=en#reg_aarch32_dbgdtrrxint)[31:0].

    AArch64 System register DBGDTRRX\_EL0 bits [31:0] are architecturally mapped to External register [DBGDTRRX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-6-DBGDTRRX-EL0--Debug-Data-Transfer-Register--Receive?lang=en#reg_ext_dbgdtrrx_el0)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to DBGDTRRX\_EL0 are UNDEFINED.

Attributes
:   DBGDTRRX\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5127-D24.3.7-DBGDTRRX_EL0-Debug-Data-Transfer-Register-Receive-img01.svg)

Bits [63:32]
:   Reserved, RES0.

DTRRX, bits [31:0]
:   DTRRX. Reads of this register:

    - If RXfull is 1, return the last value written to DTRRX.
    - If RXfull is 0, return an UNKNOWN value.

    After the read, RXfull is cleared to 0.

    For the full behavior of the Debug Communications Channel, see [‘The Debug Communication Channel and Instruction Transfer Register’](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register?lang=en#babhhaae).

    The reset behavior of this field is:

    - On a Cold reset, this field resets to an architecturally UNKNOWN value.
