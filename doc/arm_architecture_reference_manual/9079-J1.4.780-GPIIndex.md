# ​J1.4.780 GPIIndex

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-780-GPIIndex>

##### J1.4.780 GPIIndex

```
// GPIIndex()
// ==========
func GPIIndex(pa : bits(NUM_PABITS)) => integer
begin
    case DecodePGS(GPCCR_EL3().PGS) of
        when PGS_4KB =>  return UInt(pa[15:12]);
        when PGS_16KB => return UInt(pa[17:14]);
        when PGS_64KB => return UInt(pa[19:16]);
        otherwise => unreachable;
    end;
end;
```
