##### `0x822F`, DSNP\_HITM\_REMOTE\_RW, Snoop hit in remote cache, demand data access, modified

The counter counts each snoop generated by the PE in response to a demand [Memory-read operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caceiega) or demand [Memory-write operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caccfcjj) counted by [DSNP\_HIT\_REMOTE\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x819F--DSNP-HIT-REMOTE-RW--Snoop-hit-in-remote-cache--demand-data-access?lang=en#event_dsnp_hit_remote_rw) that accesses a previously modified cache location.
