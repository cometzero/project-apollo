##### `0x83AE`, N3\_CACHE1\_HIT\_PRFM, Cache type 1 at distance 3 software prefetch hit

The counter counts each software prefetch counted by [N3\_CACHE\_HIT\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83A6--N3-CACHE-HIT-PRFM--Cache-at-distance-3--software-prefetch-hit?lang=en#event_n3_cache_hit_prfm) due to a software prefetch accessing a first cache type at distance 3.

The definition of cache types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
