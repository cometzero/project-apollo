##### B1.4.8 ZA storage

R FFWLL
:   A PE with [FEAT\_SME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_sme) has *ZA storage*.

D JBVYJ
:   There are the following terms for the number of elements in a vector of SVL bits:

    SVL B
    :   The number of byte elements, SVL ÷ 8.

    SVL H
    :   The number of halfword elements, SVL ÷ 16.

    SVL S
    :   The number of word elements, SVL ÷ 32.

    SVL D
    :   The number of doubleword elements, SVL ÷ 64.

    SVL Q
    :   The number of quadword elements, SVL ÷ 128.

R SSXPL
:   ZA storage is architectural register state consisting of a two-dimensional ZA array of [SVLB × SVLB] bytes.
