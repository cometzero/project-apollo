# ​D24.10.5 CNTHPS_TVAL_EL2, Counter-timer Secure Physical Timer TimerValue Register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-5-CNTHPS-TVAL-EL2--Counter-timer-Secure-Physical-Timer-TimerValue-Register--EL2->

##### D24.10.5 CNTHPS\_TVAL\_EL2, Counter-timer Secure Physical Timer TimerValue Register (EL2)

The CNTHPS\_TVAL\_EL2 characteristics are:

Purpose
:   Holds the timer value for the Secure EL2 physical timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch64 System register CNTHPS\_TVAL\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [CNTHPS\_TVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-8-CNTHPS-TVAL--Counter-timer-Secure-Physical-Timer-TimerValue-Register--EL2-?lang=en#reg_aarch32_cnthps_tval)[31:0].

    This register is present only when EL2 is implemented, FEAT\_SEL2 is implemented, and FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTHPS\_TVAL\_EL2 are UNDEFINED.

Attributes
:   CNTHPS\_TVAL\_EL2 is a 64-bit register.

###### Field descriptions

![](images/5349-D24.10.5-CNTHPS_TVAL_EL2-Counter-timer-Secure-Physical-Timer-TimerValue-Register-EL2-img01.svg)

Bits [63:32]
:   Reserved, RES0.

TimerValue, bits [31:0]
:   The TimerValue view of the EL2 physical timer.

    On a read of this register:

    - If [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ENABLE is 0, the value returned is UNKNOWN.
    - If [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ENABLE is 1, the value returned is ([CNTHPS\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-4-CNTHPS-CVAL-EL2--Counter-timer-Secure-Physical-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthps_cval_el2) - [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0)).

    On a write of this register, [CNTHPS\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-4-CNTHPS-CVAL-EL2--Counter-timer-Secure-Physical-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthps_cval_el2) is set to ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) + TimerValue), where TimerValue is treated as a signed 32-bit integer.

    When [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ENABLE is 1, the timer condition is met when ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) - [CNTHPS\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-4-CNTHPS-CVAL-EL2--Counter-timer-Secure-Physical-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthps_cval_el2)) is greater than or equal to zero. This means that TimerValue acts like a 32-bit downcounter timer. When the timer condition is met:

    - [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ISTATUS is set to 1.
    - If [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).IMASK is 0, an interrupt is generated.

    When [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ENABLE is 0, the TimerValue cannot be read but continues to decrement. When the timer is enabled, the TimerValue represents the elapsed time whether that time was spent enabled or disabled.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
