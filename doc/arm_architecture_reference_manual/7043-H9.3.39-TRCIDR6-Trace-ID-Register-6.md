##### H9.3.39 TRCIDR6, Trace ID Register 6

The TRCIDR6 characteristics are:

Purpose
:   Returns the tracing capabilities of the trace unit.

Configuration
:   External register TRCIDR6 bits [31:0] are architecturally mapped to AArch64 System register [TRCIDR6](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-41-TRCIDR6--Trace-ID-Register-6?lang=en#reg_aarch64_trcidr6)[31:0].

    This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCIDR6 are RES0.

Attributes
:   TRCIDR6 is a 32-bit register.
