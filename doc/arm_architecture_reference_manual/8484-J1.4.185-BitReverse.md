##### J1.4.185 BitReverse

```
// BitReverse()
// ============
func BitReverse{N}(data : bits(N)) => bits(N)
begin
    var result : bits(N);
    for i = 0 to N-1 do
        result[(N-i)-1] = data[i];
    end;
    return result;
end;
```
