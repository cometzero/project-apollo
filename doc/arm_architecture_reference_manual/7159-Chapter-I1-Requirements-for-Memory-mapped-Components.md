### Chapter I1 Requirements for Memory-mapped Components

This chapter provides some additional information about memory-mapped components defined by the Armv8 and Armv9 architectures. Arm also recommends that memory-mapped components designed to support the Armv8 and Armv9 architectures use this section as guidance, other than where a conflicting behavior is required by some other standard that the component is designed to support.
