# ​D17.7.3 Effect of stage 2 translation

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-3-Effect-of-stage-2-translation>

##### D17.7.3 Effect of stage 2 translation

R DQTTB
:   If the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr) has stage 2 translations, the stage 2 process of the following is identical to that for any other intermediate physical address generated by the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr):

    - Translating the stage 1 output intermediate physical addresses.
    - Translating the stage 1 attributes to a physical address and attributes.
    - Checking for MMU faults.

R MXRVQ
:   If stage 2 translates an address and stage 2 Overlay permissions are used, then the effect of [FEAT\_S2POE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_s2poe) stage 2 Overlay permissions apply to the memory access and the Statistical Profiling Unit indirectly reads [S2POR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-166-S2POR-EL1--Stage-2-Permission-Overlay-Register--EL1-?lang=en#reg_aarch64_s2por_el1).

> Example D17-7
>
> The intermediate physical addresses are translated to physical addresses by stage 2 translation, and checked for stage 2 MMU faults.
>
> - If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).nVM is 1, meaning stage 1 translation is disabled, and the resulting IPA is translated by a stage 2 Block or Page descriptor with the AssuredOnly attribute set to 1, then the access translated by that descriptor generates a stage 2 Permission fault. See [RWWYDL](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-2-Translation-process/-D8-2-7-Translation-Hardening-Extension?lang=en#wwydl) in [Assured translation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-2-Translation-process/-D8-2-7-Translation-Hardening-Extension?lang=en#mdsec_assured_translation).
> - The attributes from stage 1 are combined with the attributes from the stage 2 translation to generate the physical memory attributes.
> - If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).DC in the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr) is 1, then stage 1 translation is disabled and the memory type produced by stage 1 is Normal Non-shareable, Inner Write-Back Cacheable Read-Allocate Write-Allocate, Outer Write-Back Cacheable Read-Allocate Write-Allocate, regardless of the values of [SCTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-174-SCTLR-EL1--System-Control-Register--EL1-?lang=en#reg_aarch64_sctlr_el1).C and [PMBMAR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-3-PMBMAR-EL1--Profiling-Buffer-Memory-Attribute-Register?lang=en#reg_aarch64_pmbmar_el1).
