# ​C8.2.523 PRFH (scalar plus immediate)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-523-PRFH--scalar-plus-immediate->

##### C8.2.523 PRFH (scalar plus immediate)

Contiguous prefetch halfwords (immediate index)

This instruction prefetches contiguous halfword elements from the memory address generated by a 64-bit scalar base and immediate index in the range -32 to 31 that is multiplied by the vector’s in-memory size, irrespective of predication, and added to the base address.

The `<prfop>` operand specifies the prefetch hint as follows:

- Access type:
  - PLD for prefetch for load.
  - PST for prefetch for store.
- Target cache level:
  - L1 for Level 1 cache.
  - L2 for Level 2 cache.
  - L3 for Level 3 cache.
- Policy:
  - KEEP for retained or temporal prefetch, allocated in the cache normally.
  - STRM for streaming or non-temporal prefetch, for data that is used only once.

> #### Note
>
> Arm strongly recommends the following for this instruction:
>
> - A PE does not perform a prefetch as a result of Inactive elements.
> - Software uses the predicate operand to suppress prefetches from unwanted addresses.

###### SVE

###### (FEAT\_SVE || FEAT\_SME)

![](images/2186-C8.2.523-PRFH-scalar-plus-immediate-img01.svg)

###### Encoding

```
PRFH  <prfop>, <Pg>, [<Xn|SP>{, #<imm>, MUL VL}]
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SVE) && !IsFeatureImplemented(FEAT_SME) then
    EndOfDecode(Decode_UNDEF);
end;
let esize : integer{} = 16;
let g : integer = UInt(Pg);
let n : integer = UInt(Rn);
let level : integer = UInt(prfop[2:1]);
let stream : boolean = (prfop[0] == ‘1’);
let pref_hint : PrefetchHint = if prfop[3] == ‘0’ then Prefetch_READ else Prefetch_WRITE;
let scale : integer = 1;
let offset : integer = SInt(imm6);
```

<Pg>
:   ​

    Is the name of the governing scalable predicate register P0-P7, encoded in the “Pg” field.

<Xn|SP>
:   ​

    Is the 64-bit name of the general-purpose base register or stack pointer, encoded in the “Rn” field.

<imm>
:   ​

    Is the optional signed immediate vector offset, in the range -32 to 31, defaulting to 0, encoded in the “imm6” field.

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let elements : integer = VL DIV esize;
let mask : bits(PL) = P{}(g);
var base : bits(64);
if AnyActiveElement{PL}(mask, esize) then
    base = if n == 31 then SP{64}() else X{64}(n);
end;
for e = 0 to elements-1 do
    if ActivePredicateElement{PL}(mask, e, esize) then
        let eoff : integer = (offset * elements) + e;
        let addr : bits(64) = base + (eoff << scale);
        Hint_Prefetch(addr, pref_hint, level, stream);
    end;
end;
```
