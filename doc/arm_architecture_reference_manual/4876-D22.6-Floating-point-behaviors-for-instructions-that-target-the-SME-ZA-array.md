# ​D22.6 Floating-point behaviors for instructions that target the SME ZA array

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D22-The-Scalable-Matrix-Extension/-D22-6-Floating-point-behaviors-for-instructions-that-target-the-SME-ZA-array>

#### D22.6 Floating-point behaviors for instructions that target the SME ZA array

D HTZVK
:   Unless stated otherwise, the behaviors in this section apply to SME and SME2 floating-point instructions that place their results in the ZA array, except the SME BFloat16 instructions `BFMOPA` (widening), `BFMOPS` (widening), `BFDOT,` and `BFVDOT`, for which, see [BFloat16 behaviors for instructions that calculate sum-of-products](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-11-BFloat16-behaviors-for-instructions-that-calculate-sum-of-products?lang=en#babjjeica4).

The instructions:

R WLPHB
:   - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{FZ, RMode, FZ16, AH, FIZ}, unless specified otherwise in [Flushing denormalized numbers to zero](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-6-Flushing-denormalized-numbers-to-zero?lang=en#chdbdeij) or [Alternate BFloat16 behaviors](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-10-Alternate-BFloat16-behaviors?lang=en#babffgghg6).

R RKHHZ
:   - Generate the default NaN, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).DN is 1.

R TGSKG
:   - Produce the expected IEEE 754 default result but do not update the [FPSR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-10-FPSR--Floating-point-Status-Register?lang=en#reg_aarch64_fpsr) cumulative exception flag bits.

R FSWYW
:   - Disable trapped floating-point exceptions, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{IDE, IXE, UFE, OFE, DZE, IOE} are all 0.

R BWKKQ
:   The SME instructions that accumulate dot products of pairs of adjacent half-precision elements in the source vectors into single-precision elements in the ZA array:

    - Perform a fused sum-of-products without rounding of the intermediate products, but rounding the single-precision sum before addition to the accumulator tile or multi-vector operand element.
    - Generate the default NaN as intermediate sum-of-products when any of the following are true:

      - Any multiplier input is a NaN.
      - Any product is infinity × 0.0.
      - Both products are infinity of differing signs.
    - Generate an intermediate sum-of-products of the same infinity when there are products that are infinity all with the same sign.

R RPSLK
:   If [FEAT\_AFP](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_afp) is implemented, the instructions honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{AH, FIZ}, in which case:

    - When [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).AH is 1, the sign bit of a generated default NaN result is set to 1 instead of 0.
    - When [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).AH is 1 and [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).FZ is 1, a denormal result, detected after rounding with an unbounded exponent has been applied, is flushed to zero.
    - When [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).AH is 1, the [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).FZ control does not cause denormalized inputs to be flushed to zero.
    - When [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).FIZ is 1, all denormalized inputs are flushed to zero.

R TCLRM
:   - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).RMode, supporting all four IEEE 754 rounding modes.

R VVVNR
:   - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).FZ.

R TXKVK
:   - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).FZ16.

R JRRMJ
:   Those instructions that multiply single elements from each source vector and accumulate their product into the ZA array perform a fused multiply-add to each accumulator tile or multi-vector operand element without rounding of the intermediate products.
