# ​C3.2.13 LoadLOAcquire/StoreLORelease

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-2-Loads-and-stores/-C3-2-13-LoadLOAcquire-StoreLORelease>

##### C3.2.13 LoadLOAcquire/StoreLORelease

The LoadLOAcquire/StoreLORelease instructions support only one addressing mode:

- Base register with no offset.

See [Load/store addressing modes](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C1-The-A64-Instruction-Set/-C1-3-Address-generation/-C1-3-3-Load-store-addressing-modes?lang=en#chdiiibb).

The LoadLOAcquire/StoreLORelease instructions can remove the requirement to use the explicit [DMB](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-150-DMB?lang=en#isa_dmb) memory barrier instruction. For more information about the ordering of LoadLOAcquire/StoreLORelease, see [LoadLOAcquire, StoreLORelease](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-11-LoadLOAcquire--StoreLORelease?lang=en#beijdijg).

If FEAT\_LSE2 is not implemented, then the LoadLOAcquire/StoreLORelease instructions require natural alignment, and an unaligned address generates an Alignment fault.
