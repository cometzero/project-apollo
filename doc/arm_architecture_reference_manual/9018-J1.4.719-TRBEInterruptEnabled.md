##### J1.4.719 TRBEInterruptEnabled

```
// TRBEInterruptEnabled()
// ======================
// Return TRUE if the TRBE interrupt request (TRBIRQ) is enabled, FALSE otherwise.
func TRBEInterruptEnabled() => boolean
begin
    return EffectiveTRFCR_EL1_EE() == ‘00’;
end;
```
