##### H9.5.5 CTIAUTHSTATUS, CTI Authentication Status register

The CTIAUTHSTATUS characteristics are:

Purpose
:   Provides information about the state of the IMPLEMENTATION DEFINED authentication interface for CTI.

Configuration
:   CTIAUTHSTATUS is in the Debug power domain

    This register is OPTIONAL, and is required for CoreSight compliance.

Attributes
:   CTIAUTHSTATUS is a 32-bit register.

###### Field descriptions

![](images/7123-H9.5.5-CTIAUTHSTATUS-CTI-Authentication-Status-register-img01.svg)

Bits [31:28]
:   Reserved, RES0.

Bits [27:24]
:   Reserved, RAZ.

Bits [23:16]
:   Reserved, RES0.

Bits [15:12]
:   Reserved, RAZ.

Bits [11:8]
:   Reserved, RES0.

Bits [7:4]
:   Reserved, RAZ.

NSNID, bits [3:2]
:   If EL3 is implemented, this field holds the same value as [DBGAUTHSTATUS\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-1-DBGAUTHSTATUS-EL1--Debug-Authentication-Status-Register?lang=en#reg_ext_dbgauthstatus_el1).NSNID.

    If EL3 is not implemented and the implemented Security state is Secure state, this field holds the same value as [DBGAUTHSTATUS\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-1-DBGAUTHSTATUS-EL1--Debug-Authentication-Status-Register?lang=en#reg_ext_dbgauthstatus_el1).SNID.

NSID, bits [1:0]
:   If EL3 is implemented, this field holds the same value as [DBGAUTHSTATUS\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-1-DBGAUTHSTATUS-EL1--Debug-Authentication-Status-Register?lang=en#reg_ext_dbgauthstatus_el1).NSID.

    If EL3 is not implemented and the implemented Security state is Secure state, this field holds the same value as [DBGAUTHSTATUS\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-1-DBGAUTHSTATUS-EL1--Debug-Authentication-Status-Register?lang=en#reg_ext_dbgauthstatus_el1).SID.
