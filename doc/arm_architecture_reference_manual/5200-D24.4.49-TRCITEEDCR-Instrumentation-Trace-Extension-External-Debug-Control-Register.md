# ​D24.4.49 TRCITEEDCR, Instrumentation Trace Extension External Debug Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-49-TRCITEEDCR--Instrumentation-Trace-Extension-External-Debug-Control-Register>

##### D24.4.49 TRCITEEDCR, Instrumentation Trace Extension External Debug Control Register

The TRCITEEDCR characteristics are:

Purpose
:   Controls instrumentation trace filtering.

Configuration
:   AArch64 System register TRCITEEDCR bits [31:0] are architecturally mapped to External register [TRCITEEDCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-46-TRCITEEDCR--Instrumentation-Trace-Extension-External-Debug-Control-Register?lang=en#reg_ext_trciteedcr)[31:0].

    This register is present only when FEAT\_ETE is implemented, System register access to the trace unit registers is implemented, and FEAT\_ITE is implemented. Otherwise, direct accesses to TRCITEEDCR are UNDEFINED.

Attributes
:   TRCITEEDCR is a 64-bit register.
