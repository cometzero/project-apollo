Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H1-About-External-Debug/-H1-3-Required-debug-authentication>

#### H1.3 Required debug authentication

A PE implements the debug authentication interface defined in this section. The debug authentication interface controls:

- Whether halting the PE and entering Debug state is allowed or prohibited.
- Whether some aspects of non-invasive debug are allowed or prohibited.
- Some legacy aspects of the AArch32 self-hosted debug model.

The pseudocode functions shown in [Table H1-1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H1-About-External-Debug/-H1-3-Required-debug-authentication?lang=en#tbl_chdicaej), and the conditions that follow that table, define the architectural requirements for debug authentication.

The following conditions always apply:

- If [`ExternalInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-18-ExternalInvasiveDebugEnabled?lang=en#asl_func_externalinvasivedebugenabled_0)`()` is FALSE, then [`ExternalSecureInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-25-ExternalSecureInvasiveDebugEnabled?lang=en#asl_func_externalsecureinvasivedebugenabled_0)`()` is FALSE.
- If [`ExternalNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-20-ExternalNoninvasiveDebugEnabled?lang=en#asl_func_externalnoninvasivedebugenabled_0)`()` is FALSE, then [`ExternalSecureNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-26-ExternalSecureNoninvasiveDebugEnabled?lang=en#asl_func_externalsecurenoninvasivedebugenabled_0)`()` is FALSE.
- If [`ExternalInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-18-ExternalInvasiveDebugEnabled?lang=en#asl_func_externalinvasivedebugenabled_0)`()` is TRUE, then [`ExternalNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-20-ExternalNoninvasiveDebugEnabled?lang=en#asl_func_externalnoninvasivedebugenabled_0)`()` is TRUE.
- If [`ExternalSecureInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-25-ExternalSecureInvasiveDebugEnabled?lang=en#asl_func_externalsecureinvasivedebugenabled_0)`()` is TRUE, then [`ExternalSecureNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-26-ExternalSecureNoninvasiveDebugEnabled?lang=en#asl_func_externalsecurenoninvasivedebugenabled_0)`()` is TRUE.

If [FEAT\_Debugv8p4](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_debugv8p4) is implemented, then all of the following apply:

- [`ExternalNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-20-ExternalNoninvasiveDebugEnabled?lang=en#asl_func_externalnoninvasivedebugenabled_0)`()` always returns TRUE.
- [`ExternalSecureNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-26-ExternalSecureNoninvasiveDebugEnabled?lang=en#asl_func_externalsecurenoninvasivedebugenabled_0)`()` returns the same value as [`ExternalSecureInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-25-ExternalSecureInvasiveDebugEnabled?lang=en#asl_func_externalsecureinvasivedebugenabled_0)`()`.

If [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is implemented, then all of the following apply:

- If [`ExternalInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-18-ExternalInvasiveDebugEnabled?lang=en#asl_func_externalinvasivedebugenabled_0)`()` is FALSE, then [`ExternalRealmInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-21-ExternalRealmInvasiveDebugEnabled?lang=en#asl_func_externalrealminvasivedebugenabled_0)`()` is FALSE.
- If any of [`ExternalInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-18-ExternalInvasiveDebugEnabled?lang=en#asl_func_externalinvasivedebugenabled_0)`()`, [`ExternalSecureInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-25-ExternalSecureInvasiveDebugEnabled?lang=en#asl_func_externalsecureinvasivedebugenabled_0)`()`, or [`ExternalRealmInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-21-ExternalRealmInvasiveDebugEnabled?lang=en#asl_func_externalrealminvasivedebugenabled_0)`()` are FALSE, then [`ExternalRootInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-23-ExternalRootInvasiveDebugEnabled?lang=en#asl_func_externalrootinvasivedebugenabled_0)`()` is FALSE.
- [`ExternalRealmNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-22-ExternalRealmNoninvasiveDebugEnabled?lang=en#asl_func_externalrealmnoninvasivedebugenabled_0)`()` returns the same value as [`ExternalRealmInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-21-ExternalRealmInvasiveDebugEnabled?lang=en#asl_func_externalrealminvasivedebugenabled_0)`()`.
- [`ExternalRootNoninvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-24-ExternalRootNoninvasiveDebugEnabled?lang=en#asl_func_externalrootnoninvasivedebugenabled_0)`()` returns the same value as [`ExternalRootInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-23-ExternalRootInvasiveDebugEnabled?lang=en#asl_func_externalrootinvasivedebugenabled_0)`()`.

If EL3 is implemented, then all of the following apply:

- If [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is not implemented, then [`ExternalSecureInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-25-ExternalSecureInvasiveDebugEnabled?lang=en#asl_func_externalsecureinvasivedebugenabled_0)`()` determines whether halting is allowed or prohibited at EL3.
- If [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is implemented, then [`ExternalRootInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-23-ExternalRootInvasiveDebugEnabled?lang=en#asl_func_externalrootinvasivedebugenabled_0)`()` determines whether halting is allowed or prohibited at EL3.

Arm recommends the use of the interface described in [Recommended authentication interface](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-3-Recommended-authentication-interface?lang=en#babiideg) to provide this debug authentication. The pseudocode functions in [A-profile Architecture Pseudocode](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode?lang=en#chap_pseudocode), which are linked to by the entries in the [Pseudocode function](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H1-About-External-Debug/-H1-3-Required-debug-authentication?lang=en#chdcifid) column of [Table H1-1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H1-About-External-Debug/-H1-3-Required-debug-authentication?lang=en#tbl_chdicaej), assume that this interface is implemented.
