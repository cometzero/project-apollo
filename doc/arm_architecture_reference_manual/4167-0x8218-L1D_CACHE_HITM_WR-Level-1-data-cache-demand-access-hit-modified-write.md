##### `0x8218`, L1D\_CACHE\_HITM\_WR, Level 1 data cache demand access hit modified, write

The counter counts each cache access counted by [L1D\_CACHE\_HIT\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81C8--L1D-CACHE-HIT-WR--Level-1-data-cache-demand-access-hit--write?lang=en#event_l1d_cache_hit_wr) that accesses a previously modified cache location.
