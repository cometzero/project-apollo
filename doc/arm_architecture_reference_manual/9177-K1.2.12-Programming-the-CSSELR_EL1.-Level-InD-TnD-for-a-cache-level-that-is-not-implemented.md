# ​K1.2.12 Programming the CSSELR_EL1.{Level, InD, TnD} for a cache level that is not implemented

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors/-K1-2-AArch64-CONSTRAINED-UNPREDICTABLE-behaviors/-K1-2-12-Programming-the-CSSELR-EL1--Level--InD--TnD--for-a-cache-level-that-is-not-implemented>

##### K1.2.12 Programming the CSSELR\_EL1.{Level, InD, TnD} for a cache level that is not implemented

If the [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1).{Level, InD, TnD} is programmed to a cache level that is not implemented, then a read of [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1) returns an UNKNOWN value in [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1).{Level, InD, TnD}.

If [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1).{Level, InD, TnD} is programmed to a cache level that is not implemented, then on a read of [CCSIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-31-CCSIDR-EL1--Current-Cache-Size-ID-Register?lang=en#reg_aarch64_ccsidr_el1) an implementation must perform one of the following behaviors:

- The [CCSIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-31-CCSIDR-EL1--Current-Cache-Size-ID-Register?lang=en#reg_aarch64_ccsidr_el1) read is treated as a NOP.
- The [CCSIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-31-CCSIDR-EL1--Current-Cache-Size-ID-Register?lang=en#reg_aarch64_ccsidr_el1) read is UNDEFINED.
- The [CCSIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-31-CCSIDR-EL1--Current-Cache-Size-ID-Register?lang=en#reg_aarch64_ccsidr_el1) read returns an UNKNOWN value.

When [FEAT\_CCIDX](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_ccidx) is implemented, [CCSIDR2\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-30-CCSIDR2-EL1--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch64_ccsidr2_el1) is implemented. If [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1).{Level, InD, TnD} is programmed to a cache level that is not implemented, then on a read of [CCSIDR2\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-30-CCSIDR2-EL1--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch64_ccsidr2_el1) an implementation must perform one of the following behaviors:

- The [CCSIDR2\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-30-CCSIDR2-EL1--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch64_ccsidr2_el1) read is treated as a NOP.
- The [CCSIDR2\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-30-CCSIDR2-EL1--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch64_ccsidr2_el1) read is UNDEFINED.
- The [CCSIDR2\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-30-CCSIDR2-EL1--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch64_ccsidr2_el1) read returns an UNKNOWN value.
