##### `0x83FF`, N4\_MEM3\_PRFM, Access to type 3 memory at distance 4, software prefetch

The counter counts each software prefetch counted by [N4\_MEM\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E7--N4-MEM-PRFM--Access-to-memory-at-distance-4--software-prefetch?lang=en#event_n4_mem_prfm) to a third memory type at distance 4.

The definition of memory types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
