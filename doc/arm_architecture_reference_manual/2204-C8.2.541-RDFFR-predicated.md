# ​C8.2.541 RDFFR (predicated)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-541-RDFFR--predicated->

##### C8.2.541 RDFFR (predicated)

Return predicate of successfully loaded elements

This instruction reads the first-fault register (`FFR`) and places active elements in the corresponding elements of the destination predicate. Inactive elements in the destination predicate register are set to zero. This instruction does not set the condition flags.

This instruction is illegal when executed in Streaming SVE mode, unless FEAT\_SME\_FA64 is implemented and enabled.

###### Not setting the condition flags

###### Encoding

```
RDFFR  <Pd>.B, <Pg>/Z
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SVE) then EndOfDecode(Decode_UNDEF); end;
let g : integer = UInt(Pg);
let d : integer = UInt(Pd);
let setflags : boolean = FALSE;
```

###### Assembler Symbols

<Pd>
:   ​

    Is the name of the destination scalable predicate register, encoded in the “Pd” field.

<Pg>
:   ​

    Is the name of the governing scalable predicate register, encoded in the “Pg” field.

###### Operation

```
CheckNonStreamingSVEEnabled();
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let mask : bits(PL) = P{}(g);
let ffr : bits(PL) = FFR{}();
let result : bits(PL) = ffr AND mask;
if setflags then
    PSTATE.[N,Z,C,V] = PredTest{PL}(mask, result, 8);
end;
P{PL}(d) = result;
```
