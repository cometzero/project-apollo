##### F6.1.14 SHA256H2

SHA256 hash update part 2.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-14-SHA256H2?lang=en#isa_sha256h2_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-14-SHA256H2?lang=en#isa_sha256h2_iclass_t1)).

```
SHA256H2.32  <Qd>, <Qn>, <Qm>
```

```
if !IsFeatureImplemented(FEAT_SHA256) then Undefined(); end;

```

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

###### Assembler Symbols

<Qd>
:   ​

    Is the 128-bit name of the SIMD&FP destination register, encoded in the “D:Vd” field as <Qd>\*2.

<Qn>
:   ​

    Is the 128-bit name of the first SIMD&FP source register, encoded in the “N:Vn” field as <Qn>\*2.

<Qm>
:   ​

    Is the 128-bit name of the second SIMD&FP source register, encoded in the “M:Vm” field as <Qm>\*2.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    CheckCryptoEnabled32();
    let X : bits(128) = Q(n>>1);
    let Y : bits(128) = Q(d>>1);
    let W : bits(128) = Q(m>>1);
    let part1 : boolean = FALSE;
    Q(d>>1) = SHA256hash(X, Y, W, part1);
end;
```

###### Operational Information

This instruction is a data-independent-time instruction as described in [About the DIT bit](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-5-About-the-DIT-bit?lang=en#beiidceg).
