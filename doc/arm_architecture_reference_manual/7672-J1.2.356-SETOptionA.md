##### J1.2.356 SETOptionA

```
// SETOptionA()
// ============
// Returns TRUE if the implementation uses Option A for the
// SET* instructions, and FALSE otherwise.
func SETOptionA() => boolean
begin
    return ImpDefBool(“SET* instructions use Option A”);
end;
```
