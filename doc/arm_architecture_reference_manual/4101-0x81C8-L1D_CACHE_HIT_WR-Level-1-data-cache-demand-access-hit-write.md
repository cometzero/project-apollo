##### `0x81C8`, L1D\_CACHE\_HIT\_WR, Level 1 data cache demand access hit, write

The counter counts each demand write counted by [L1D\_CACHE\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0041--L1D-CACHE-WR--Level-1-data-cache-access--write?lang=en#event_l1d_cache_wr) that hits in the Level 1 data or unified cache.
