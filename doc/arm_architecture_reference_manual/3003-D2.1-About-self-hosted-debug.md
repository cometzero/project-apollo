#### D2.1 About self-hosted debug

Self-hosted debug supports debugging through the generation and handling of *debug exceptions*, which are taken using the Exception model described in [The AArch64 System Level Programmers’ Model](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model?lang=en#chdjhjjc). This section introduces some terms that are used in describing self-hosted debug, and then introduces the debug exceptions. See:

- [About debug exceptions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-1-About-self-hosted-debug/-D2-1-3-About-debug-exceptions?lang=en#bcgcbjai).
