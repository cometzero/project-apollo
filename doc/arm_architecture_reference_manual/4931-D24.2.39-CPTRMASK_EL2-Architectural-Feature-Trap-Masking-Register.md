##### D24.2.39 CPTRMASK\_EL2, Architectural Feature Trap Masking Register

The CPTRMASK\_EL2 characteristics are:

Purpose
:   Mask register to prevent updates of fields in [CPTR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-37-CPTR-EL2--Architectural-Feature-Trap-Register--EL2-?lang=en#reg_aarch64_cptr_el2) on writes.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    This register has no effect if EL2 is not enabled in the current Security state.

    This register is present only when FEAT\_SRMASK is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to CPTRMASK\_EL2 are UNDEFINED.

Attributes
:   CPTRMASK\_EL2 is a 64-bit register.
