##### C6.2.391 STCLRH, STCLRLH

Atomic bit clear on halfword, without return

This instruction atomically loads a 16-bit halfword from memory, performs a bitwise AND with the complement of the value held in a register on it, and stores the result back to memory.

- `STCLRH` does not have release semantics.
- `STCLRLH` stores to memory with release semantics, as described in [Load-Acquire, Store-Release](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-10-Load-Acquire--Load-AcquirePC--and-Store-Release?lang=en#beihchef).

For information about addressing modes, see [Load/Store addressing modes](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C1-The-A64-Instruction-Set/-C1-3-Address-generation/-C1-3-3-Load-store-addressing-modes?lang=en#chdiiibb).

This is an alias of [LDCLRH, LDCLRAH, LDCLRALH, LDCLRLH](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-202-LDCLRH--LDCLRAH--LDCLRALH--LDCLRLH?lang=en#isa_ldclrh). This means:

- The encodings in this description are named to match the encodings of [LDCLRH, LDCLRAH, LDCLRALH, LDCLRLH](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-202-LDCLRH--LDCLRAH--LDCLRALH--LDCLRLH?lang=en#isa_ldclrh).
- The description of [LDCLRH, LDCLRAH, LDCLRALH, LDCLRLH](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-202-LDCLRH--LDCLRAH--LDCLRALH--LDCLRLH?lang=en#isa_ldclrh) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the No memory ordering variant

Applies when `(R == 0)`

```
STCLRH  <Ws>, [<Xn|SP>]
```

is equivalent to

```
LDCLRH  <Ws>, <Wt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Encoding for the Release variant

Applies when `(R == 1)`

```
STCLRLH  <Ws>, [<Xn|SP>]
```

is equivalent to

```
LDCLRLH  <Ws>, <Wt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Assembler Symbols

<Ws>
:   ​

    Is the 32-bit name of the general-purpose register holding the data value to be operated on with the contents of the memory location, encoded in the “Rs” field.

<Xn|SP>
:   ​

    Is the 64-bit name of the general-purpose base register or stack pointer, encoded in the “Rn” field.
