# ​I2.3 Memory-mapped timer components

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components>

#### I2.3 Memory-mapped timer components

This part of the Arm Generic Timer specification defines an optional memory-mapped timer component. This can be implemented as part of any programmable system component that does not incorporate a System register mapped Arm Generic Timer, to provide that system component with the timer functionality of an Arm Generic Timer.

The memory map consists of up to eight timer *frames*. The base address of a frame is [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea), where *N* numbers from 0 up to a maximum permitted value of 7.

Each [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) timer frame:

- Provides its own set of timers and associated interrupts.
- Is implemented in its own [memory page](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegjhbgi) or [memory protection region](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegbgjhc).
- Is implemented at a base address, identified as [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea), that is aligned to the size of the [translation granule](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegiahdd) or [memory protection region](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegbgjhc).

For each implemented [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) frame the system can optionally provide an unprivileged view of the frame, described as the EL0 view of the frame. The base address of this second view of the [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) frame is [CNTEL0BaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegecbbg).

> #### Note
>
> In the naming of the registers associated with a [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) or [CNTEL0BaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegecbbg) frame, the value of *N* is represented as <n>, for example [CNTACR<n>](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-1-CNTACR-n---Counter-timer-Access-Control-Registers--n---0---7?lang=en#reg_ext_cntacrn).

If a [CNTEL0BaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegecbbg) frame is implemented:

- Is implemented in its own [memory page](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegjhbgi) or [memory protection region](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegbgjhc) and is aligned to the size of the [translation granule](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegiahdd) or [memory protection region](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegbgjhc).
- All registers visible in [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea), except for [CNTVOFF](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-18-CNTVOFF--Counter-timer-Virtual-Offset?lang=en#reg_ext_cntvoff) and [CNTEL0ACR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-4-CNTEL0ACR--Counter-timer-EL0-Access-Control-Register?lang=en#reg_ext_cntel0acr), can be visible in [CNTEL0BaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegecbbg).

  - Control fields in [CNTEL0ACR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-4-CNTEL0ACR--Counter-timer-EL0-Access-Control-Register?lang=en#reg_ext_cntel0acr) determine whether each register is visible.
- The offsets of all visible registers are the same as their offsets in the [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) frame.

In addition to the implemented [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) and [CNTEL0BaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegecbbg) frames, the system must provide a single control frame at base address [CNTCTLBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-1-The-CNTCTLBase-frame?lang=en#tbl_bgbihgid). [CNTCTLBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-1-The-CNTCTLBase-frame?lang=en#tbl_bgbihgid) must be implemented in its own [memory page](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegjhbgi) or [memory protection region](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegbgjhc) and is aligned to the size of the [translation granule](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegiahdd) or [memory protection region](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#cegbgjhc).

The system defines the position of each frame in the memory map. This means the values of each of the [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea), [CNTEL0BaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegecbbg), and [CNTCTLBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-1-The-CNTCTLBase-frame?lang=en#tbl_bgbihgid) base addresses is IMPLEMENTATION DEFINED.

> #### Note
>
> The Arm architecture requires memory-mapped peripherals to be little-endian, and therefore the memory-mapped timers are little-endian.
