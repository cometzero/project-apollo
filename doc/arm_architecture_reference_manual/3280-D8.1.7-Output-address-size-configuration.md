# ​D8.1.7 Output address size configuration

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-1-Address-translation/-D8-1-7-Output-address-size-configuration>

##### D8.1.7 Output address size configuration

R QQQSJ
:   For a translation stage that uses the VMSAv8-64 translation system, the maximum OA size that can be described by translation table entries is one of the following:

    - For a translation regime controlled by [TCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr_elx), if the 4KB or 16KB translation granule is used, then one of the following:

      - If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr_elx).DS is 0, then 48 bits.
      - If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr_elx).DS is 1, then 52 bits.
    - For any translation regime, if the 64KB translation granule is used, then one of the following:

      - If [FEAT\_LPA](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_lpa) is not implemented, then 48 bits.
      - If [FEAT\_LPA](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_lpa) is implemented, then 52 bits.

R LWWHG
:   For a translation stage that uses the VMSAv9-128 translation system, the maximum OA size that can be described by translation table entries is 56 bits.

R MRYSR
:   The name of the [TCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr_elx).{I}PS field is one of the following:

    - If the register is [TCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-193-TCR-EL1--Translation-Control-Register--EL1-?lang=en#reg_aarch64_tcr_el1), then the field is [TCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-193-TCR-EL1--Translation-Control-Register--EL1-?lang=en#reg_aarch64_tcr_el1).IPS.
    - If the register is [TCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-194-TCR-EL2--Translation-Control-Register--EL2-?lang=en#reg_aarch64_tcr_el2), then one of the following:

      - If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 0, then the field is [TCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-194-TCR-EL2--Translation-Control-Register--EL2-?lang=en#reg_aarch64_tcr_el2).PS.
      - If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, then the field is [TCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-194-TCR-EL2--Translation-Control-Register--EL2-?lang=en#reg_aarch64_tcr_el2).IPS.
    - If the register is [TCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-195-TCR-EL3--Translation-Control-Register--EL3-?lang=en#reg_aarch64_tcr_el3), then the field is [TCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-195-TCR-EL3--Translation-Control-Register--EL3-?lang=en#reg_aarch64_tcr_el3).PS.

I MNZFV
:   The [TCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr_elx).{I}PS field is three bits and has the same encoding as the three least significant bits of [ID\_AA64MMFR0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-87-ID-AA64MMFR0-EL1--AArch64-Memory-Model-Feature-Register-0?lang=en#reg_aarch64_id_aa64mmfr0_el1).PARange.

R CLPQT
:   The OA size from a translation stage cannot be larger than the implemented PA size. If the OA size represented by [TCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr_elx).{I}PS is larger than the implemented PA size, then the OA size is treated as being the same as the implemented PA size.

I PKBTM
:   Arm strongly recommends that software avoids configuring [TCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr_elx).{I}PS to a value greater than the implemented PA size.

I HGDWP
:   If a translation stage is enabled and the translation stage OA has nonzero address bits above the implemented PA size, then an Address size fault is generated at the lookup level in the translation stage that generated the OA.

R BZHGM
:   If all of the following apply, then a stage 2 Translation fault is generated:

    - Two address translation stages are used.
    - Stage 2 address translation is enabled.
    - The stage 1 OA does not generate a stage 1 Address size fault.
    - The stage 1 OA has nonzero address bits above the specified stage 2 translation IA size.
