##### `0x819A`, DSNP\_HIT\_FAR\_WR, Snoop hit in far local cache, demand data write

The counter counts each snoop generated by the PE in response to a demand [Memory-write operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caccfcjj) counted by [DSNP\_HIT\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8198--DSNP-HIT-WR--Snoop-hit--demand-data-write?lang=en#event_dsnp_hit_wr) that hits in a cache outside the local PE cluster on the same device.

The event is counted by the PE generating the snoop, not the PE being snooped.
