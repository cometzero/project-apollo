# ​C5.2.8 FPCR, Floating-point Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register>

##### C5.2.8 FPCR, Floating-point Control Register

The FPCR characteristics are:

Purpose
:   Controls behavior of the floating-point instructions.

Configuration
:   It is IMPLEMENTATION DEFINED whether the Len and Stride fields can be programmed to nonzero values, which will cause some AArch32 floating-point instruction encodings to be UNDEFINED, or whether these fields are RAZ.

    This register is a Special-purpose register.

    AArch64 System register FPCR bits [26:15] are architecturally mapped to AArch32 System register [FPSCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-55-FPSCR--Floating-Point-Status-and-Control-Register?lang=en#reg_aarch32_fpscr)[26:15].

    AArch64 System register FPCR bits [12:8] are architecturally mapped to AArch32 System register [FPSCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-55-FPSCR--Floating-Point-Status-and-Control-Register?lang=en#reg_aarch32_fpscr)[12:8].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to FPCR are UNDEFINED.

Attributes
:   FPCR is a 64-bit register.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Stride, bits [21:20]
:   This field has no function in AArch64 state, and nonzero values are ignored during execution in AArch64 state.

    This field is included only for context saving and restoration of the AArch32 [FPSCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-55-FPSCR--Floating-Point-Status-and-Control-Register?lang=en#reg_aarch32_fpscr).Stride field.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    When an implementation implements FPSCR.{Stride, Len} as RAZ, access to this field is RAZ/WI.
