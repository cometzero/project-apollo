# ​D11.4.2 Using the exception return protection features

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-4-Exception-returns/-D11-4-2-Using-the-exception-return-protection-features>

##### D11.4.2 Using the exception return protection features

S MQBXD
:   Arm notes that the use of [`ERETAA, ERETAB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-158-ERETAA--ERETAB?lang=en#isa_ereta) for an exception return is unlikely when [`GCSPOPCX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-162-GCSPOPCX?lang=en#isa_gcspopcx_sys) is used to validate the exception return state. This is because a prior [`GCSPUSHX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-166-GCSPUSHX?lang=en#isa_gcspushx_sys) instruction will have pushed an exception return address without a pointer authentication code to the Guarded Control Stack, and a [`GCSPOPCX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-162-GCSPOPCX?lang=en#isa_gcspopcx_sys) will need to validate this exception return address without a pointer authentication code. Therefore, the authentication would need to be performed before the [`GCSPOPCX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-162-GCSPOPCX?lang=en#isa_gcspopcx_sys) instruction.

    Exception handling software needs to be aware of the Guarded Control Stack for scenarios where an exception return does not return to the point where an exception was taken from, since this might require modification of the exception return state held on the Guarded Control Stack.
