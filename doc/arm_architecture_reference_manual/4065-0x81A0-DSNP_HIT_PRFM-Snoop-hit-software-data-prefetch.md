##### `0x81A0`, DSNP\_HIT\_PRFM, Snoop hit, software data prefetch

The counter counts each snoop generated by the PE in response to a data prefetch instruction counted by [DSNP\_HIT\_PRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8294--DSNP-HIT-PRF--Snoop-hit--data-prefetch?lang=en#event_dsnp_hit_prf) that hits in a cache outside of the cache hierarchy of this PE.

The event is counted by the PE generating the snoop, not the PE being snooped.
