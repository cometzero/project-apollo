# ​D24.10.4 CNTHPS_CVAL_EL2, Counter-timer Secure Physical Timer CompareValue Register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-4-CNTHPS-CVAL-EL2--Counter-timer-Secure-Physical-Timer-CompareValue-Register--EL2->

##### D24.10.4 CNTHPS\_CVAL\_EL2, Counter-timer Secure Physical Timer CompareValue Register (EL2)

The CNTHPS\_CVAL\_EL2 characteristics are:

Purpose
:   Holds the compare value for the Secure EL2 physical timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch64 System register CNTHPS\_CVAL\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [CNTHPS\_CVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-7-CNTHPS-CVAL--Counter-timer-Secure-Physical-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch32_cnthps_cval)[31:0].

    This register is present only when EL2 is implemented, FEAT\_SEL2 is implemented, and FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTHPS\_CVAL\_EL2 are UNDEFINED.

Attributes
:   CNTHPS\_CVAL\_EL2 is a 64-bit register.

###### Field descriptions

![](images/5348-D24.10.4-CNTHPS_CVAL_EL2-Counter-timer-Secure-Physical-Timer-CompareValue-Register-EL2-img01.svg)

CompareValue, bits [63:0]
:   Holds the EL2 physical timer CompareValue.

    When [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ENABLE is 1, and TimerConditionMet is TRUE for the Secure EL2 physical timer, the timer condition is met and all of the following are true:

    - [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ISTATUS is set to 1.
    - If [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).IMASK is 0, an interrupt is generated.

    TimerConditionMet is defined by [‘Operation of the CompareValue views of the timers’](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-2-The-AArch64-view-of-the-Generic-Timer/-D12-2-4-Timers?lang=en#chddaeaj).

    The CompareValue view of the timer acts like a 64-bit upcounter timer.

    When [CNTHPS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-3-CNTHPS-CTL-EL2--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthps_ctl_el2).ENABLE is 0, the timer condition is not met, but [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) continues to count.

    If the Generic counter is implemented at a size less than 64 bits, then this field is permitted to be implemented at the same width as the counter, and the upper bits are RES0.

    The value of this field is treated as zero-extended in all counter calculations.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
