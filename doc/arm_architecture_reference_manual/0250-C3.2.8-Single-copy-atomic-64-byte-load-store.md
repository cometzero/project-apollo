# ​C3.2.8 Single-copy atomic 64-byte load/store

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-2-Loads-and-stores/-C3-2-8-Single-copy-atomic-64-byte-load-store>

##### C3.2.8 Single-copy atomic 64-byte load/store

If [FEAT\_LS64](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_ls64) is implemented, the following instructions are implemented:

- [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b).
- [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b).

If [FEAT\_LS64\_V](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_ls64_v) is implemented, the following instructions are implemented:

- [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b).
- [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b).
- [ST64BV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-384-ST64BV?lang=en#isa_st64bv).

If [FEAT\_LS64\_ACCDATA](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_ls64_accdata) is implemented, the following instructions are implemented:

- [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b).
- [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b).
- [ST64BV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-384-ST64BV?lang=en#isa_st64bv).
- [ST64BV0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-385-ST64BV0?lang=en#isa_st64bv0).

[LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b) and [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b) can only target Device or Normal Non-cacheable memory unless [FEAT\_LS64WB](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_ls64wb) is implemented.

The single-copy atomic 64-byte load/store instructions support one addressing mode:

- Base register only.

See also [Load/store addressing modes](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C1-The-A64-Instruction-Set/-C1-3-Address-generation/-C1-3-3-Load-store-addressing-modes?lang=en#chdiiibb).

The memory location accessed by the instructions is required to be aligned on a 64-byte boundary, otherwise an Alignment fault occurs.

If an [ST64BV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-384-ST64BV?lang=en#isa_st64bv), [ST64BV0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-385-ST64BV0?lang=en#isa_st64bv0), or if [FEAT\_LS64WB](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_ls64wb) is not implemented an [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b) or [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b), attempts to access a memory type that is not one of the following, then a Data Abort with DFSC code `0b110101` is generated:

- Normal Inner Non-cacheable, Outer Non-cacheable.
- Device-GRE.
- Device-nGRE.
- Device-nGnRE.
- Device-nGnRnE.

It is IMPLEMENTATION DEFINED which of the following approaches is used to provide this check:

- The check is performed at each enabled stage of translation, and the fault is reported for the first stage of translation that provides an inappropriate memory type. In this case, the value of the [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).DC bit does not cause accesses generated by the instructions to generate a stage 1 Data abort,
- The check is performed against the resulting memory type after all enabled stages of translation. In this case the fault is reported at the final enabled stage of translation.
- The check is performed against the resulting memory type after all enabled stages of translation. In this case the fault is reported for the first stage of translation that provided an inappropriate memory type. The value of the [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).DC bit does not cause accesses generated by the instructions to generate a stage 1 Data abort.

If [FEAT\_LS64WB](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_ls64wb) is implemented, then [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b) and [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b) are also supported and 64-byte single-copy atomic for [Conventional memory](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babifjhi) that is Inner and Outer Write-Back Cacheable, Shareable. In this case, if an [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b) or [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b) attempts to access:

- A memory region that is Inner and Outer Write-Back Cacheable, Shareable, but the target memory location is not in [Conventional memory](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babifjhi), then it is IMPLEMENTATION DEFINED whether:

  - A stage 1 Data Abort with DFSC code `0b110101` is generated.
  - The access succeeds but is not guaranteed to be single-copy atomic above the byte level.
- A cacheable type of memory other than Inner and Outer Write-Back Cacheable, Shareable, then it is IMPLEMENTATION DEFINED whether:

  - A stage 1 Data Abort with DFSC code `0b110101` is generated.
  - The access succeeds as a 64-byte single-copy atomic operation.

For behavior when [FEAT\_LS64WB](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_ls64wb) is implemented and an [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b) or [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b) targets Tagged memory that is Inner and Outer Write-Back Cacheable, Shareable, see [Tag Check Faults](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D10-The-Memory-Tagging-Extension/-D10-7-Tag-Check-Faults?lang=en#mdsec_tag_check_faults).

If the target memory location does not support the [LD64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-179-LD64B?lang=en#isa_ld64b) or [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b) instructions, then one of the following behaviors occurs:

- A stage 1 Data Abort with DFSC code of `0b110101`, is generated.
- The instruction performs the memory accesses, but the accesses are not single-copy atomic above the byte level.

If the target memory location does not support the [ST64BV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-384-ST64BV?lang=en#isa_st64bv) or [ST64BV0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-385-ST64BV0?lang=en#isa_st64bv0) instructions, then the register specified by <Xs> is set to `0xFFFF_FFFF_FFFF_FFFF`.

Regardless of the memory type:

- The memory access generated by an [ST64BV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-384-ST64BV?lang=en#isa_st64bv) or [ST64BV0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-385-ST64BV0?lang=en#isa_st64bv0) instruction is not merged with any accesses.
- The memory access generated by an [ST64B](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-383-ST64B?lang=en#isa_st64b) instruction is not merged with any accesses generated by store instructions appearing in program order after the instruction.
