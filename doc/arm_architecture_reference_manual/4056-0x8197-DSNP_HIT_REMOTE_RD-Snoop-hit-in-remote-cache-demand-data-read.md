##### `0x8197`, DSNP\_HIT\_REMOTE\_RD, Snoop hit in remote cache, demand data read

The counter counts each snoop generated by the PE in response to a demand [Memory-read operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caceiega) counted by [DSNP\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8194--DSNP-HIT-RD--Snoop-hit--demand-data-read?lang=en#event_dsnp_hit_rd) that hits in a cache on a remote device.

The event is counted by the PE generating the snoop, not the PE being snooped.
