##### H8.5.4 External debug interface register access permissions summary

For accesses to:

- IMPLEMENTATION DEFINED registers, see [IMPLEMENTATION DEFINED registers](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-5-External-debug-interface-register-access-permissions/-H8-5-5-IMPLEMENTATION-DEFINED-registers?lang=en#cihgaade).
- OPTIONAL registers for CoreSight compliance, see [Management registers and CoreSight compliance](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance?lang=en#cihcdhda).
- Reserved, unallocated, or unimplemented registers, writes to read-only registers, and reads of write-only registers, see [Reserved and unallocated registers](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-5-External-debug-interface-register-access-permissions/-H8-5-6-Reserved-and-unallocated-registers?lang=en#cihfaaib).

For all other external debug interface, CTI, and Performance Monitor registers, [Table H8-3](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-6-External-debug-interface-registers/-H8-6-1-Access-permissions-for-the-External-debug-interface-registers?lang=en#tbl_cihghdic), [Table H8-4](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-6-External-debug-interface-registers/-H8-6-1-Access-permissions-for-the-External-debug-interface-registers?lang=en#tbl_cihjbadj), [Table H8-6](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-7-Cross-trigger-interface-registers?lang=en#tbl_cegfebge) and [Table I3-2](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I3-Recommended-External-Interface-to-the-Performance-Monitors/-I3-1-About-the-external-interface-to-the-Performance-Monitors-registers/-I3-1-4-Access-permissions-for-external-views-of-the-Performance-Monitors?lang=en#tbl_i3cegfebge), show the response of the PE to accesses by the external debug interface.
