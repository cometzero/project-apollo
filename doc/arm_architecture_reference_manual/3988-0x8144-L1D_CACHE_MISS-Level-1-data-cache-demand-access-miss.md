# ​0x8144, L1D_CACHE_MISS, Level 1 data cache demand access miss

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8144--L1D-CACHE-MISS--Level-1-data-cache-demand-access-miss>

##### `0x8144`, L1D\_CACHE\_MISS, Level 1 data cache demand access miss

The counter counts each demand access counted by [L1D\_CACHE\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8140--L1D-CACHE-RW--Level-1-data-cache-demand-access?lang=en#event_l1d_cache_rw) that misses in the Level 1 data or unified cache, causing an access to outside of the Level 1 caches of this PE.
