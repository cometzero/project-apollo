##### H9.2.18 EDDEVAFF1, External Debug Device Affinity register 1

The EDDEVAFF1 characteristics are:

Purpose
:   Copy of the high half of the PE [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1) register that allows a debugger to determine which PE in a multiprocessor system the external debug component relates to.

Configuration
:   When FEAT\_DoPD is implemented, EDDEVAFF1 is in the Core power domain. Otherwise, EDDEVAFF1 is in the Debug power domain

Attributes
:   EDDEVAFF1 is a 32-bit register.

###### Field descriptions

![](images/6968-H9.2.18-EDDEVAFF1-External-Debug-Device-Affinity-register-1-img01.svg)

Bits [31:8]
:   Reserved, RES0.

Aff3, bits [7:0]
:   Affinity level 3. See the description of [EDDEVAFF0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-17-EDDEVAFF0--External-Debug-Device-Affinity-register-0?lang=en#reg_ext_eddevaff0).Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
