# ​D11.4.1 Pushing and popping exception return state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-4-Exception-returns/-D11-4-1-Pushing-and-popping-exception-return-state>

##### D11.4.1 Pushing and popping exception return state

I KLWLQ
:   A set of instructions is provided to operate on the Guarded Control Stack specifically for exceptions and exception returns, to allow software to add entries and check entries.

    - [`GCSPUSHX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-166-GCSPUSHX?lang=en#isa_gcspushx_sys)

      This instruction creates a new [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record) on the Guarded Control Stack containing the values of the [ELR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#elr_elx) and [SPSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#spsr_elx) for the current Exception level and the LR value. The intent is that such data is the contents of the [ELR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#elr_elx) and [SPSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#spsr_elx), pushed soon after taking an exception. This instruction is more limited in its usage than [`GCSPUSHM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-165-GCSPUSHM?lang=en#isa_gcspushm_sys), only allowing the [ELR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#elr_elx), [SPSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#spsr_elx) and LR to be pushed. This instruction also avoids the exception return state being moved to general purpose registers before adding to the Guarded Control Stack, further reducing the attack surface.
    - [`GCSPOPCX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-162-GCSPOPCX?lang=en#isa_gcspopcx_sys)

      This instruction pops a [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record) from the top of the Guarded Control Stack and compares the values popped with the [ELR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#elr_elx) and [SPSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#spsr_elx) for the current Exception level and the LR value. If the values mismatch, a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception) is taken. The intent is that this instruction is used just before an exception return, to validate that the intended exception return state is the same as that which was pushed to the Guarded Control Stack on exception entry.
    - [`GCSPOPX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-164-GCSPOPX?lang=en#isa_gcspopx_sys)

      This instruction pops a [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record) from the top of the Guarded Control Stack. If the record is not a [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record), a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception) is taken. This instruction is intended to be used to remove a [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record), when modification of such a record is needed.

S SLHZY
:   Exception handling software can use the [`GCSPUSHX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-166-GCSPUSHX?lang=en#isa_gcspushx_sys) instruction to save the exception return state to a memory location that is protected by the GCS permissions in stage 1 translations.

    - A typical preemptible operating system might employ a kernel stack for kernel execution on behalf of a thread. Software can create a Guarded Control Stack for each kernel stack and these instructions can be used to save the exception return state in the Guarded Control Stack that corresponds to the kernel stack of a thread.
    - An interrupt handler might have its own stack that is different from the kernel stack of any thread. Software can create a Guarded Control Stack that corresponds to the interrupt stack and these instructions can be used to store the exception return state in that Guarded Control Stack.

I CCMMC
:   PSTATE.EXLOCK is provided to allow software to ensure that the exception return state that is pushed to the Guarded Control Stack is the state of the PE when the exception was taken, and to ensure that once the exception return state is checked before an exception return that the values in [ELR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#elr_elx) and [SPSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#spsr_elx) are unable to be changed. When enabled, PSTATE.EXLOCK prevents `MSR` instructions from modifying the state of the [ELR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#elr_elx) and [SPSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#spsr_elx), by causing such instructions to generate an [EXLOCK Exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_exlock_exception). When enabled, execution of an exception return instruction which targets the current Exception level will check PSTATE.EXLOCK and will set PSTATE.IL to cause an Illegal exception return.

I RZZFL
:   The [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record) pushed by the [`GCSPUSHX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-166-GCSPUSHX?lang=en#isa_gcspushx_sys) instruction contains a doubleword with the value `0x0000_0000_0000_0009`. This value allows a [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record) to be distinguishable from a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record), and allows the PE to ensure that an exception return does not use a procedure return address or a procedure return does not use an exception return address.

    - When a [`GCSPOPCX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-162-GCSPOPCX?lang=en#isa_gcspopcx_sys) or [`GCSPOPX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-164-GCSPOPX?lang=en#isa_gcspopx_sys) instruction is attempted where the top record on the Guarded Control Stack is a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record), the [`GCSPOPCX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-162-GCSPOPCX?lang=en#isa_gcspopcx_sys) or [`GCSPOPX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-164-GCSPOPX?lang=en#isa_gcspopx_sys) instruction detects the value in the lowest-addressed doubleword is not `0x0000_0000_0000_0009`, and takes a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception).
    - When a procedure return instruction is attempted where the top record on the Guarded Control Stack is not a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record) and therefore the bits [1:0] of the doubleword are not `0b00`, the procedure return will return to this location then take a PC Alignment exception.
    - When a [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl) instruction is attempted where the top record on the Guarded Control Stack is not a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record) and therefore bits [1:0] of the value popped are not `0b00`, the [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl) instruction takes a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception).
