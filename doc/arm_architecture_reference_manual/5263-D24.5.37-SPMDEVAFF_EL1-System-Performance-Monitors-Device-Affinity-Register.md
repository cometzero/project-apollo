# ​D24.5.37 SPMDEVAFF_EL1, System Performance Monitors Device Affinity Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-37-SPMDEVAFF-EL1--System-Performance-Monitors-Device-Affinity-Register>

##### D24.5.37 SPMDEVAFF\_EL1, System Performance Monitors Device Affinity Register

The SPMDEVAFF\_EL1 characteristics are:

Purpose
:   For additional information, see the CoreSight Architecture Specification.

    For a System PMU that has affinity with a single PE or a group of PEs, SPMDEVAFF\_EL1 is a copy of [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1) or part of [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1):

    - If the System PMU has affinity with a single PE, then the affinity level is 0 and SPMDEVAFF\_EL1 reads the same value as [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1), and SPMDEVAFF\_EL1.F0V reads-as-one to indicate affinity level 0.
    - If the System PMU has affinity with a group of PEs, then the affinity level is 1, 2, or 3, parts of SPMDEVAFF\_EL1 reads the same value as parts of [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1), and the rest of SPMDEVAFF\_EL1 indicates the level.

    For example, if the group of PEs is a subset of the PEs at affinity level 1, then all of the following are true:

    - All the PEs in the group have the same values in [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1).{Aff3,Aff2}, and these values are equal to SPMDEVAFF\_EL1.{Aff3,Aff2}.
    - SPMDEVAFF\_EL1.Aff1 is nonzero and not `0x80`, and SPMDEVAFF\_EL1.{Aff0,F0V} read-as-zero, to indicate at least affinity level 1. The subset of PEs at level 1 that the System PMU has affinity with is indicated by the least-significant set bit in SPMDEVAFF\_EL1.Aff1. In this example, if SPMDEVAFF\_EL1.Aff1[2:0] is `0b100`, then the System PMU has affinity with the up-to 8 PEs that have [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1).Aff1[7:3] == SPMDEVAFF\_EL1.Aff1[7:3].

    Depending on the IMPLEMENTATION DEFINED nature of the system, it might be possible that SPMDEVAFF\_EL1 is read before system firmware has configured the System PMU and/or the PE or group of PEs that the System PMU has affinity with. When this is the case, SPMDEVAFF\_EL1 reads-as-zero.

Configuration
:   This register is present only when FEAT\_SPMU is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to SPMDEVAFF\_EL1 are UNDEFINED.

Attributes
:   SPMDEVAFF\_EL1 is a 64-bit register.

###### Accessing SPMDEVAFF\_EL1

Reads of SPMDEVAFF\_EL1 are not affected by the value of [VMPIDR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-218-VMPIDR-EL2--Virtualization-Multiprocessor-ID-Register?lang=en#reg_aarch64_vmpidr_el2) at any Exception level.

SPMDEVAFF\_EL1 reads-as-zero if any of the following are true:

- System PMU <s> is not implemented.
- System PMU <s> has no affinity with the PE or cluster of PEs.
