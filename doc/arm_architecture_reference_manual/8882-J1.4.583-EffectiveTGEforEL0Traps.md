##### J1.4.583 EffectiveTGEforEL0Traps

```
// EffectiveTGEforEL0Traps()
// =========================
// Returns the Effective value of HCR_EL2().TGE for direct accesses to system or special-purpose
// registers, and execution of system instructions, that may trap when either
// EffectivelyAtEL0NotInHost() or EffectivelyAtEL0InHost() is TRUE.
func EffectiveTGEforEL0Traps() => bit
begin
    if !EL2Enabled() then
        return ‘0’;
    end;
    return HCR_EL2().TGE;
end;
```
