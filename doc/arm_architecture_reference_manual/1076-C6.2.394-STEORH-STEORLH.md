##### C6.2.394 STEORH, STEORLH

Atomic exclusive-OR on halfword, without return

This instruction atomically loads a 16-bit halfword from memory, performs an exclusive-OR with the value held in a register on it, and stores the result back to memory.

- `STEORH` does not have release semantics.
- `STEORLH` stores to memory with release semantics, as described in [Load-Acquire, Store-Release](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-10-Load-Acquire--Load-AcquirePC--and-Store-Release?lang=en#beihchef).

For information about addressing modes, see [Load/Store addressing modes](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C1-The-A64-Instruction-Set/-C1-3-Address-generation/-C1-3-3-Load-store-addressing-modes?lang=en#chdiiibb).

This is an alias of [LDEORH, LDEORAH, LDEORALH, LDEORLH](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-206-LDEORH--LDEORAH--LDEORALH--LDEORLH?lang=en#isa_ldeorh). This means:

- The encodings in this description are named to match the encodings of [LDEORH, LDEORAH, LDEORALH, LDEORLH](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-206-LDEORH--LDEORAH--LDEORALH--LDEORLH?lang=en#isa_ldeorh).
- The description of [LDEORH, LDEORAH, LDEORALH, LDEORLH](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-206-LDEORH--LDEORAH--LDEORALH--LDEORLH?lang=en#isa_ldeorh) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the No memory ordering variant

Applies when `(R == 0)`

```
STEORH  <Ws>, [<Xn|SP>]
```

is equivalent to

```
LDEORH  <Ws>, <Wt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Encoding for the Release variant

Applies when `(R == 1)`

```
STEORLH  <Ws>, [<Xn|SP>]
```

is equivalent to

```
LDEORLH  <Ws>, <Wt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Assembler Symbols

<Ws>
:   ​

    Is the 32-bit name of the general-purpose register holding the data value to be operated on with the contents of the memory location, encoded in the “Rs” field.

<Xn|SP>
:   ​

    Is the 64-bit name of the general-purpose base register or stack pointer, encoded in the “Rn” field.
