##### D18.2.2 Context packet

Purpose
:   Provides context information for the record.

Attributes
:   Multi-part packet comprising:

    - 8-bit header.
    - 32-bit payload.

###### Context packet header

Figure D18-7 Context packet header

:   This field reads as `0b01`.
