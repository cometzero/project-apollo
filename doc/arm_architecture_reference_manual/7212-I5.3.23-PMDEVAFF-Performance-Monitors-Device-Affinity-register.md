# ​I5.3.23 PMDEVAFF, Performance Monitors Device Affinity register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-23-PMDEVAFF--Performance-Monitors-Device-Affinity-register>

##### I5.3.23 PMDEVAFF, Performance Monitors Device Affinity register

The PMDEVAFF characteristics are:

Purpose
:   Copy of the PE [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1) register that allows a debugger to determine which PE in a multiprocessor system the Performance Monitor component relates to.

Configuration
:   If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, this register is in the Core power domain. If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, this register is in the Debug power domain.

    This register is present only when FEAT\_PMUv3\_EXT64 is implemented.

Attributes
:   PMDEVAFF is a 64-bit register.

The value of the [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).{Aff2, Aff1, Aff0} or [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1).{Aff3, Aff2, Aff1, Aff0} set of fields of each PE must be unique within the system as a whole.

    Access to this field is RO.

###### Accessing PMDEVAFF

If [FEAT\_PMUv3\_EXT32](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pmuv3_ext32) is implemented, then the same content is present in the same locations, and can be accessed using PMDEVAFF0[31:0] and PMDEVAFF1[31:0].

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT64 is implemented
:   Accessible at offset `0xFA8` from PMU

    - When FEAT\_DoPD is implemented and !IsCorePowered(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RO.
