    - It is IMPLEMENTATION DEFINED how AttrIndx[2:0] is used to index into [AMAIR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#amair_elx).

R YJLRL

    - If AIE is enabled and AttrIndx[3] is 1, then AttrIndx[2:0] holds the value *n* used to select the 8-bit field in all of the following registers:

      - [MAIR2\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mair2_elx).Attr<*n*> that specifies the memory region attributes of the descriptor OA.
      - [AMAIR2\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#amair2_elx).Attr<*n*> that specifies the IMPLEMENTATION DEFINED memory region attributes of the descriptor OA.

I FVLFZ
:   For the memory region specified by a Block descriptor and Page descriptor, the [MAIR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mair_elx).Attr<*n*> or [MAIR2\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mair2_elx).Attr<*n*> field selected by the descriptor AttrIndx[2:0] field defines all of the following:

    - The Device or Normal memory type.
    - For Device memory, all of the following:

      - One of the Device-nGnRnE, Device-nGnRE, Device-nGRE, or Device-GRE Device memory types.
      - If [FEAT\_XS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_xs) is implemented, then the XS attribute.
    - For Normal memory, all of the following:

      - For both Inner and Outer Cacheability, one of the Non-cacheable, Write-Through, or Write-Back attributes.
      - For Write-Through Cacheable and Write-Back Cacheable regions, the Read-Allocate and Write-Allocate hints, each of which is Allocate or No Allocate, and the Transient allocation hints.
      - If [FEAT\_MTE2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-6-The-Armv8-5-architecture-extension?lang=en#feat_feat_mte2) is implemented, then the Tagged attribute.
      - If [FEAT\_XS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_xs) is implemented, then the XS attribute.

    For more information, see [XS attribute modifier](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-7-Other-descriptor-fields/-D8-7-4-XS-attribute-modifier?lang=en#mdsec_xs_attribute_modifier) and [Memory region tagging types](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D10-The-Memory-Tagging-Extension/-D10-3-Memory-region-tagging-types?lang=en#mdsec_tagged_memory).
