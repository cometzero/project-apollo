# ​J1.2.701 AArch64_SettingAccessFlagPermitted

##### J1.2.701 AArch64\_SettingAccessFlagPermitted

```
// AArch64_SettingAccessFlagPermitted()
// ====================================
// Determine whether the access flag could be set by HW given the fault status
func AArch64_SettingAccessFlagPermitted(fault : FaultRecord, fault_perm : FaultRecord) => boolean
begin
    if fault.statuscode == Fault_None && fault_perm.statuscode == Fault_None then
        return TRUE;
    elsif fault.statuscode == Fault_Alignment || fault_perm.statuscode == Fault_Permission then
        return ConstrainUnpredictableBool(Unpredictable_AFUPDATE);
    else
        return FALSE;
    end;
end;
```
