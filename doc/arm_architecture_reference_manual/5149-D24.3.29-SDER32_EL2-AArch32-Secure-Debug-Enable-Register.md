# ​D24.3.29 SDER32_EL2, AArch32 Secure Debug Enable Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-29-SDER32-EL2--AArch32-Secure-Debug-Enable-Register>

##### D24.3.29 SDER32\_EL2, AArch32 Secure Debug Enable Register

The SDER32\_EL2 characteristics are:

Purpose
:   Allows access to the AArch32 register [SDER](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-36-SDER--Secure-Debug-Enable-Register?lang=en#reg_aarch32_sder) from Secure EL2 and EL3 only.

Configuration
:   When EL3 is implemented, AArch64 System register SDER32\_EL2 bits [63:0] are architecturally mapped to AArch64 System register [SDER32\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-30-SDER32-EL3--AArch32-Secure-Debug-Enable-Register?lang=en#reg_aarch64_sder32_el3)[63:0].

    AArch64 System register SDER32\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [SDER](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-36-SDER--Secure-Debug-Enable-Register?lang=en#reg_aarch32_sder)[31:0].

    This register is present only when EL2 is implemented, FEAT\_SEL2 is implemented, FEAT\_AA32EL1 is implemented, and FEAT\_AA64 is implemented. Otherwise, direct accesses to SDER32\_EL2 are UNDEFINED.

Attributes
:   SDER32\_EL2 is a 64-bit register.

    When Secure EL1 is using AArch32, the forms of non-invasive debug affected by this control are:

    - The PC Sample-based Profiling Extension. See [About the PC Sample-based Profiling Extension](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H7-The-PC-Sample-based-Profiling-Extension/-H7-1-About-the-PC-Sample-based-Profiling-Extension?lang=en#babjgbhj).
    - When `SelfHostedTraceEnabled()` == FALSE, processor trace.
    - When EL3 is implemented, Performance Monitors.

    When Secure EL1 is using AArch64, this bit has no effect.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

SUIDEN, bit [0]
:   When EL3 is implemented:
    :   Secure User Invasive Debug Enable.

    else

    end;
elsif PSTATE.EL == EL2 then
    if !IsCurrentSecurityState(SS_Secure) then
        Undefined();
    elsif HaveEL(EL3) && MDCR_EL3().TDA == '1' then
        AArch64_SystemAccessTrap(EL3, 0x18);
    else
        X{64}(t) = SDER32_EL2();
    end;
elsif PSTATE.EL == EL3 then
    if SCR_EL3().EEL2 == '0' then
        Undefined();
    else
        X{64}(t) = SDER32_EL2();
    end;
end;
