# ​I5.7.14 CNTSCR, Counter Scale Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-14-CNTSCR--Counter-Scale-Register>

##### I5.7.14 CNTSCR, Counter Scale Register

The CNTSCR characteristics are:

Purpose
:   Enables the counter, controls the counter [effective frequency](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_frequency) setting, and controls counter behavior during debug.

Configuration
:   It is IMPLEMENTATION DEFINED whether CNTSCR is implemented in the Core power domain or in the Debug power domain

    For more information, see [‘Power and reset domains for the system level implementation of the Generic Timer’](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-1-About-the-Generic-Timer-specification/-I2-1-1-Registers-in-the-system-level-implementation-of-the-Generic-Timer?lang=en#ceghaiaf).

    This register is present only when FEAT\_CNTSC is implemented. Otherwise, direct accesses to CNTSCR are RES0.

Attributes
:   CNTSCR is a 32-bit register.

###### Field descriptions

![](images/7303-I5.7.14-CNTSCR-Counter-Scale-Register-img01.svg)

ScaleVal, bits [31:0]
:   Scale Value

    When counter scaling is enabled, ScaleVal is the average amount added to the counter value for one period of the frequency of the Generic counter as described in the [CNTFRQ](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-7-CNTFRQ--Counter-timer-Frequency?lang=en#reg_ext_cntfrq) register.

    The actual rate of update of the counter value is determined by the [counter resolution](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#counter_resolution).

    ScaleVal is expressed as an unsigned fixed point number with an 8-bit integer value and a 24-bit fractional value.

    CNTSCR.ScaleVal can only be changed when [CNTCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-2-CNTCR--Counter-Control-Register?lang=en#reg_ext_cntcr).EN == 0. If the value of this field is changed when [CNTCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-2-CNTCR--Counter-Control-Register?lang=en#reg_ext_cntcr).EN == 1:

    - The counter value becomes UNKNOWN.
    - The counter value remains UNKNOWN on future ticks of the clock.

    The reset behavior of this field is:

    - On a Timer reset, this field resets to an architecturally UNKNOWN value.

###### Accessing CNTSCR

In a system that supports the Realm Management Extension, the CNTControlBase frame, which includes this register, is implemented only in the Root physical address space.

In a system that supports Secure and Non-secure physical address spaces, the CNTControlBase frame, which includes this register, is implemented only in the Secure physical address space.
