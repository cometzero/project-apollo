##### J1.4.549 EffectiveSCR\_EL3\_FIQ

```
// EffectiveSCR_EL3_FIQ()
// ======================
// Returns the Effective value of SCR_EL3().FIQ.
readonly func EffectiveSCR_EL3_FIQ() => bit
begin
    if !HaveEL(EL3) || ELUsingAArch32(EL3) then
        return ‘0’;
    end;
    return SCR_EL3().FIQ;
end;
```
