##### `0x8003`, ASE\_SVE\_INST\_RETIRED, Instruction architecturally executed, Advanced SIMD or SVE

The counter counts each [architecturally executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacciiig) instruction counted by [SE\_INST\_RETIRED](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x835B--SE-INST-RETIRED--Instruction-architecturally-executed--Advanced-SIMD--SVE--or-SME?lang=en#event_se_inst_retired) that is classified as an Advanced SIMD instruction or an SVE instruction.

See [ASE\_INST\_RETIRED](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8001--ASE-INST-RETIRED--Instruction-architecturally-executed--Advanced-SIMD?lang=en#event_ase_inst_retired) and [SVE\_INST\_RETIRED](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8002--SVE-INST-RETIRED--Instruction-architecturally-executed--SVE?lang=en#event_sve_inst_retired) for these classifications.
