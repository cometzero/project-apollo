##### J1.4.98 ExtRegZeroEventCounters

```
// ExtRegZeroEventCounters()
// ==========================
// Zero all the event counters.
// Called on an external PMU write to PMCR_EL0 that writes ‘1’ to PMCR_EL0.P.
func ExtRegZeroEventCounters(addrdesc : AddressDescriptor)
begin
    ExtRegZeroPMUCounters(Zeros{33} :: Ones{31}, addrdesc);
end;
```
