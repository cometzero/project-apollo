##### G8.2.52 ELR\_hyp, Exception Link Register (Hyp mode)

The ELR\_hyp characteristics are:

Purpose
:   When taking an exception to Hyp mode, holds the address to return to.

Configuration
:   This register is a Special-purpose register.

    AArch32 System register ELR\_hyp bits [31:0] are architecturally mapped to AArch64 System register [ELR\_EL2](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-6-ELR-EL2--Exception-Link-Register--EL2-?lang=en#reg_aarch64_elr_el2)[31:0].

    This register is present only when FEAT\_AA32 is implemented. Otherwise, direct accesses to ELR\_hyp are UNDEFINED.

Attributes
:   ELR\_hyp is a 32-bit register.

###### Field descriptions

![](images/6543-G8.2.52-ELR_hyp-Exception-Link-Register-Hyp-mode-img01.svg)

ADDR, bits [31:0]
:   Return address.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing ELR\_hyp

ELR\_hyp is accessible only at Hyp mode and Monitor mode.
