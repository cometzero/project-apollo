##### J1.4.222 ClearPendingVirtualSError

```
// ClearPendingVirtualSError()
// ===========================
// Clear a pending virtual SError interrupt.
func ClearPendingVirtualSError()
begin
    if ELUsingAArch32(EL2) then
        HCR().VA      = ‘0’;
    else
        HCR_EL2().VSE = ‘0’;
    end;
end;
```
