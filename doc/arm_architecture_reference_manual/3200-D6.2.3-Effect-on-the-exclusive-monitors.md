# ​D6.2.3 Effect on the exclusive monitors

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer/-D6-2-3-Effect-on-the-exclusive-monitors>

##### D6.2.3 Effect on the exclusive monitors

R DCVBN
:   If an operation between Load-Exclusive and Store-Exclusive instructions is traced, and the trace data is written to an unrelated address, then the write has no effect on the exclusive monitors.

R NWSKV
:   If the Trace Buffer Unit writes to the marked address of an exclusives monitor in the Exclusive Access state, then there is a CONSTRAINED UNPREDICTABLE choice of one of the following occurring:

    - The write has the same effect on the exclusives monitor as a store by the PE or any other Observer to that address.
    - The write has no effect on the exclusives monitor.
