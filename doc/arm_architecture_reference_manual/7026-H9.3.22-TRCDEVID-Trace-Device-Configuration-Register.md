##### H9.3.22 TRCDEVID, Trace Device Configuration Register

The TRCDEVID characteristics are:

Purpose
:   Provides discovery information for the component.

    For additional information, see the CoreSight Architecture Specification.

Configuration
:   External register TRCDEVID bits [31:0] are architecturally mapped to AArch64 System register [TRCDEVID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-27-TRCDEVID--Trace-Device-Configuration-Register?lang=en#reg_aarch64_trcdevid)[31:0].

    This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCDEVID are RES0.

Attributes
:   TRCDEVID is a 32-bit register.

###### Field descriptions

![](images/7026-H9.3.22-TRCDEVID-Trace-Device-Configuration-Register-img01.svg)

Bits [31:0]
:   Reserved, RES0.

###### Accessing TRCDEVID

External debugger accesses to this register are unaffected by the OS Lock.
