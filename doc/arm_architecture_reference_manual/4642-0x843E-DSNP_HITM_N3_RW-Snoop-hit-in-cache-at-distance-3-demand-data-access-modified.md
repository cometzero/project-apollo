##### `0x843E`, DSNP\_HITM\_N3\_RW, Snoop hit in cache at distance 3, demand data access, modified

The counter counts each snoop generated by the PE in response to a demand [Memory-read operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caceiega) or demand [Memory-write operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caccfcjj) counted by [DSNP\_HIT\_N3\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x840E--DSNP-HIT-N3-RW--Snoop-hit-in-cache-at-distance-3--demand-data-access?lang=en#event_dsnp_hit_n3_rw) that accesses a previously modified cache location.
