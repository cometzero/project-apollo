# ​G1.11 Process state, PSTATE

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE>

#### G1.11 Process state, PSTATE

Process state or PSTATE is an abstraction of process state information. All of the instruction sets provide instructions that operate on elements of PSTATE.

PSTATE includes all of the following:

- Fields that are meaningful only in AArch32 state.
- Fields that are meaningful only in AArch64 state.
- Fields that are meaningful in both Execution states.

PSTATE is defined in pseudocode as the [PSTATE structure](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-630-PSTATE?lang=en#asl_global_pstate).

The PSTATE fields that are meaningful in AArch32 state are:

The Condition flags
:   N
    :   Negative Condition flag.

    Z
    :   Zero Condition flag.

    C
    :   Carry Condition flag.

    V
    :   Overflow Condition flag.

    [Process state, PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch) gives more information about these.

The overflow or saturation flag
:   Q
    :   See [Process state, PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch).

The greater than or equal flags
:   GE[3:0]
    :   See [Process state, PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch).

The PE state controls
:   J, T
    :   Instruction set state. See [PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch). J is RES0. On a Warm reset to AArch32 state, T is set to an IMPLEMENTATION DEFINED value. On taking an exception to:

        - A PL1 mode using AArch32, T is set to [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).TE.
        - EL2 using AArch32, T is set to [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).TE.

    IT[7:0]
    :   IT block state bits. See [Process state, PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch). On a Warm reset or taking an exception to AArch32 state, these bits are set to 0.

    E
    :   Endianness of data accesses. See [Process state, PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch). If an implementation provides both Big-endian and Little-endian support, then:

        - On a Warm reset to AArch32 state this bit is set to the IMPLEMENTATION DEFINED reset value of:

          - [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).EE if the highest implemented Exception level is not EL2.
          - [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).EE if the highest implemented Exception level is EL2.
        - On taking an exception to:

          - A PL1 mode using AArch32, this bit is set to [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).EE.
          - EL2 using AArch32, this bit is set to [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).EE

    IL
    :   Illegal Execution state bit. See [The Illegal Execution state exception](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-5-The-Illegal-Execution-state-exception?lang=en#chdffbac). On a Warm reset or taking an exception to AArch32 state, this bit is set to 0.

    For information on how the J, T, IT[7:0], E, and IL fields can be accessed, see [Accessing the PE state controls, the Execution state bit, and the Undefined Instruction exception injection bit](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-1-Accessing-PSTATE-fields?lang=en#chdjifab).

The asynchronous exception mask bits
:   A
    :   SError mask bit.

    I
    :   IRQ interrupt mask bit.

    F
    :   FIQ interrupt mask bit.

    For each bit, the values are:

    0
    :   Exception not masked.

    1
    :   Exception masked.

    On a Warm reset to AArch32 state, these bits are set to 1.

    On taking an exception to AArch32 state, one or more of these bits are set to 1.

    For more information, see both:

    - [Asynchronous exception masking controls](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-16-Asynchronous-exception-behavior-for-exceptions-taken-from-AArch32-state/-G1-16-3-Asynchronous-exception-masking-controls?lang=en#cihdjfdc).
    - [PE state on exception entry](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-13-Handling-exceptions-that-are-taken-to-an-Exception-level-using-AArch32/-G1-13-5-PE-state-on-exception-entry?lang=en#beidgbih).

The mode bits
:   M[4:0]
    :   Current mode of the PE. [Table G1-5](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-9-AArch32-state-PE-modes?lang=en#tbl_cihghdgi) lists the permitted values of this field. All other values are reserved. [Illegal changes to PSTATE.M](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-3-Illegal-changes-to-PSTATE-M?lang=en#chddfige) describes the effect of setting M[4:0] to a reserved value.

        M[4] is:

        M[4], Execution state
        :   The current Execution state:

            0
            :   AArch64 state.

            1
            :   AArch32 state.

            > #### Note
            >
            > This is consistent with the use of M[4:0] in previous versions of the architecture.

        On a Warm reset to AArch32 state, M[4:0] is set to:

        - `0b10011`, meaning Supervisor mode, if the highest implemented Exception level is not EL2.
        - `0b11010`, meaning Hyp mode, if the highest implemented Exception level is EL2.

        On taking an exception to AArch32 state, M[4:0] is set to the target mode for the exception type.

        For more information about the PE modes, see:

        - [AArch32 state PE modes](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-9-AArch32-state-PE-modes?lang=en#cihbgjdi).
        - [PE state on exception entry](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-13-Handling-exceptions-that-are-taken-to-an-Exception-level-using-AArch32/-G1-13-5-PE-state-on-exception-entry?lang=en#beidgbih).

Inject Undefined Instruction exception bit, if [FEAT\_UINJ](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_uinj) is implemented.
:   UINJ
    :   On a Warm reset, this bit is set to 0. On taking an exception, this bit is set to 0.

    For information on how this bit can be accessed, see [Accessing the PE state controls, the Execution state bit, and the Undefined Instruction exception injection bit](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-1-Accessing-PSTATE-fields?lang=en#chdjifab).

Access control bits, from Armv8.1
:   PAN
    :   *Privileged Access Never* (PAN) state bit, see [About the PAN bit](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-6-Memory-access-control/-G5-6-2-About-the-PAN-bit?lang=en#cchhabfe).

Timing control bits
:   DIT
    :   *Data Independent Timing* (DIT) bit. For more information, see [About the DIT bit](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-5-About-the-DIT-bit?lang=en#beiidceg).

        This bit is implemented only when [FEAT\_DIT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_dit) is implemented.

        On a Warm reset to AArch32 state, this bit is set to 0.

Speculation control bits
:   SSBS
    :   *Speculative Store Bypass Safe* (SSBS) bit. For more information, see [AArch32 Speculative Store Bypass Safe](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-3-Definition-of-the-memory-model/-E2-3-4-AArch32-restrictions-on-the-effects-of-speculation?lang=en#aa32_ssbs).

        This bit is implemented only when [FEAT\_SSBS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-6-The-Armv8-5-architecture-extension?lang=en#feat_feat_ssbs) is implemented.

        On a Warm reset to AArch32 state, this bit is set to an IMPLEMENTATION DEFINED value.
