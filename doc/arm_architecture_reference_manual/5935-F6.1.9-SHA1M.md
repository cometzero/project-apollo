##### F6.1.9 SHA1M

SHA1 hash update (majority).

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-9-SHA1M?lang=en#isa_sha1m_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-9-SHA1M?lang=en#isa_sha1m_iclass_t1)).

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

###### Assembler Symbols

<Qd>
:   ​

    Is the 128-bit name of the SIMD&FP destination register, encoded in the “D:Vd” field as <Qd>\*2.

<Qn>
:   ​

    Is the 128-bit name of the first SIMD&FP source register, encoded in the “N:Vn” field as <Qn>\*2.

<Qm>
:   ​

    Is the 128-bit name of the second SIMD&FP source register, encoded in the “M:Vm” field as <Qm>\*2.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    CheckCryptoEnabled32();
    var x : bits(128) = Q(d>>1);
    var y : bits(32) = Q(n>>1)[31:0]; // Note: 32 bits wide
    let w : bits(128) = Q(m>>1);
    for e = 0 to 3 do
        let t : bits(32) = SHAmajority{}(x[63:32], x[95:64], x[127:96]);
        y = y + ROL(x[31:0], 5) + t + w[e*:32];
        x[63:32] = ROL(x[63:32], 30);
        let yx : bits(160) = ROL(y::x, 32);
        (y, x) = (yx[128+:32], yx[0+:128]);
    end;
    Q(d>>1) = x;
end;
```
