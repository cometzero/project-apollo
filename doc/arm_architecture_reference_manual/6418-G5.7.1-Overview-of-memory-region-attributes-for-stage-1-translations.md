# ​G5.7.1 Overview of memory region attributes for stage 1 translations

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-1-Overview-of-memory-region-attributes-for-stage-1-translations>

##### G5.7.1 Overview of memory region attributes for stage 1 translations

The description of the memory region attributes in a Translation descriptor divides into:

Memory type and attributes
:   These are described either:

    - Directly, by bits in the Translation Table descriptor.
    - Indirectly, by registers referenced by bits in the Table descriptor. This is described as *remapping* the memory type and attribute description.

    The Short-descriptor translation table format can use either of these approaches, selected by the [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).TRE bit:

    TRE == 0
    :   Remap disabled. The TEX[2:0], C, and B bits in the Translation Table descriptor define the memory region attributes. [Short-descriptor format memory region attributes, without TEX remap](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-2-Short-descriptor-format-memory-region-attributes--without-TEX-remap?lang=en#cacdjged) describes this encoding.

        > #### Note
        >
        > With the Short-descriptor format, remapping is called *TEX remap*, and the [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).TRE bit is the *TEX remap enabled* bit.

        The description of the TRE == 0 encoding includes information about the encoding in previous versions of the architecture.

    TRE == 1
    :   Remap enabled. The TEX[0], C, and B bits in the Translation Table descriptor are index bits to the remap registers, that define the memory region attributes:

        - The Primary Region Remap Register, [PRRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-122-PRRR--Primary-Region-Remap-Register?lang=en#reg_aarch32_prrr).
        - The Normal Memory Remap Register, [NMRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register?lang=en#reg_aarch32_nmrr).

        [Short-descriptor format memory region attributes, with TEX remap](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-3-Short-descriptor-format-memory-region-attributes--with-TEX-remap?lang=en#beibejbe) describes this encoding scheme.

        This scheme reassigns Translation Table descriptor bits TEX[2:1] for use as bits managed by the operating system.

    The Long-descriptor translation table format always uses remapping. This means that when the value of [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).EAE is 1, enabling use of the Long-descriptor translation table format, [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).TRE is RES1.

    [VMSAv8-32 Long-descriptor format memory region attributes](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-4-VMSAv8-32-Long-descriptor-format-memory-region-attributes?lang=en#chdjegcd) describes this encoding.

Shareability
:   In the Short-descriptor translation table format, the S bit in the Translation Table descriptor is used in determining the Shareability of the region. How the S bit is interpreted depends on whether TEX remap is enabled, see:

    - [Shareability and the S bit, without TEX remap](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-2-Short-descriptor-format-memory-region-attributes--without-TEX-remap?lang=en#beihhgag).
    - [Determining the Shareability, with TEX remap](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-3-Short-descriptor-format-memory-region-attributes--with-TEX-remap?lang=en#beigahgh).

    In the Long-descriptor translation table format, the SH[1:0] field in the Translation Table descriptor encodes the Shareability of the region, see [Shareability, Long-descriptor format](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-4-VMSAv8-32-Long-descriptor-format-memory-region-attributes?lang=en#chdicddi).

    > #### Note
    >
    > Shareability is one of Non-shareable, Inner Shareable, and Outer Shareable. However, when using the Short-descriptor translation table format without TEX remap, VMSAv8-32 does not support any distinction between Inner Shareable and Outer Shareable memory, and a memory region is either Non-shareable or Outer Shareable.

registers, or the [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr) or [HTCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-76-HTCR--Hyp-Translation-Control-Register?lang=en#reg_aarch32_htcr) registers, or in the translation tables, have the XS attribute set to 1, unless they are Inner Write-Back Cacheable, Outer Write-back Cacheable, which have the XS attribute set to 0. This includes any memory types that are treated as Write-Back Cacheable as a result of IMPLEMENTATION DEFINED choices in the architecture.
