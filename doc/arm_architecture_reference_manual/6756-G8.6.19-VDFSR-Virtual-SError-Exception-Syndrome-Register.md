# ​G8.6.19 VDFSR, Virtual SError Exception Syndrome Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-19-VDFSR--Virtual-SError-Exception-Syndrome-Register>

##### G8.6.19 VDFSR, Virtual SError Exception Syndrome Register

The VDFSR characteristics are:

Purpose
:   Provides the syndrome value reported to software on taking a virtual SError exception exception to EL1, or on executing an `ESB` instruction at EL1.

    When the virtual SError exception injected using [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).VA is taken to EL1 using AArch32, then the syndrome value is reported in [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr).{AET, ExT} and the remainder of [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr) is set as defined by VMSAv8-32. For more information, see [The AArch32 Virtual Memory System Architecture](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture?lang=en#chdbceda).

    If the virtual SError exception injected using [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).VA is deferred by an `ESB` instruction, then the syndrome value is written to [VDISR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-20-VDISR--Virtual-Deferred-Interrupt-Status-Register?lang=en#reg_aarch32_vdisr).

Configuration
:   If EL2 is not implemented, then VDFSR is RES0 from Monitor mode when [SCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-126-SCR--Secure-Configuration-Register?lang=en#reg_aarch32_scr).NS == 1.

    AArch32 System register VDFSR bits [31:0] are architecturally mapped to AArch64 System register [VSESR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-18-VSESR-EL2--Virtual-SError-Exception-Syndrome-Register--EL2-?lang=en#reg_aarch64_vsesr_el2)[31:0].

    This register is present only when FEAT\_RAS is implemented and FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to VDFSR are UNDEFINED.

Attributes
:   VDFSR is a 32-bit register.

###### Field descriptions

![](images/6756-G8.6.19-VDFSR-Virtual-SError-Exception-Syndrome-Register-img01.svg)

Bits [31:16]
:   Reserved, RES0.

AET, bits [15:14]
:   When a virtual SError exception is taken to EL1 using AArch32, [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr)[15:14] is set to VDFSR.AET.

    When a virtual SError exception is deferred by an `ESB` instruction, [VDISR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-20-VDISR--Virtual-Deferred-Interrupt-Status-Register?lang=en#reg_aarch32_vdisr)[15:14] is set to VDFSR.AET.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bit [13]
:   Reserved, RES0.

ExT, bit [12]
:   When a virtual SError exception is taken to EL1 using AArch32, [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr)[12] is set to VDFSR.ExT.

    When a virtual SError exception is deferred by an `ESB` instruction, [VDISR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-20-VDISR--Virtual-Deferred-Interrupt-Status-Register?lang=en#reg_aarch32_vdisr)[12] is set to VDFSR.ExT.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bits [11:0]
:   Reserved, RES0.

###### Accessing VDFSR

Direct reads and writes of VDFSR are UNDEFINED if EL3 is implemented and using AArch32 in all Secure privileged modes other than Monitor mode.

If EL2 is not implemented, then VDFSR is RES0 from Monitor mode when [SCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-126-SCR--Secure-Configuration-Register?lang=en#reg_aarch32_scr).NS == 1.

Accesses to this register use the following encodings in the System register encoding space:

        Undefined();
    end;

    R(t) = VDFSR();
elsif PSTATE.EL == EL3 then
    if SCR().NS == '0' then
        Undefined();
    else
        R(t) = VDFSR();
    end;
end;
