# ​F5.1.182 SEL

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-182-SEL>

##### F5.1.182 SEL

Select Bytes selects each byte of its result from either its first operand or its second operand, according to the values of the [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).GE flags.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-182-SEL?lang=en#isa_sel_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-182-SEL?lang=en#isa_sel_iclass_t1)).

###### A1

![](images/5799-F5.1.182-SEL-img01.svg)

###### Encoding

```
SEL{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
if d == 15 || n == 15 || m == 15 then UnpredictableProcedure(); end;
```

###### T1

![](images/5799-F5.1.182-SEL-img02.svg)

###### Encoding

```
SEL{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
// Armv8-A removes UNPREDICTABLE for R13
if d == 15 || n == 15 || m == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

:   ​

    Is the second general-purpose source register, encoded in the “Rm” field.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    R(d)[7:0]   = if PSTATE.GE[0] == ‘1’ then R(n)[7:0]   else R(m)[7:0];
    R(d)[15:8]  = if PSTATE.GE[1] == ‘1’ then R(n)[15:8]  else R(m)[15:8];
    R(d)[23:16] = if PSTATE.GE[2] == ‘1’ then R(n)[23:16] else R(m)[23:16];
    R(d)[31:24] = if PSTATE.GE[3] == ‘1’ then R(n)[31:24] else R(m)[31:24];
end;
```
