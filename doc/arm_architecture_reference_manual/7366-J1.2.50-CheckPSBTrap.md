# ​J1.2.50 CheckPSBTrap

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-50-CheckPSBTrap>

##### J1.2.50 CheckPSBTrap

```
// CheckPSBTrap()
// ==============
// Checks whether PSB should trap to EL2.
func CheckPSBTrap()
begin
    if (IsFeatureImplemented(FEAT_FGT) && IsFeatureImplemented(FEAT_SPEv1p5) &&
          PSTATE.EL IN {EL0, EL1} && EL2Enabled() && !IsInHost() &&
          (!HaveEL(EL3) || SCR_EL3().FGTEn == ‘1’) && HFGITR_EL2().PSBCSYNC == ‘1’) then
        let target_el : bits(2) = EL2;
        let iss : bits(25)      = 0x3[24:0];
        AArch64_OtherInstrTrap(target_el, iss);
    end;
end;
```
