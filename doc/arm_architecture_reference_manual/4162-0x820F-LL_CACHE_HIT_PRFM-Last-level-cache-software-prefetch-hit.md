##### `0x820F`, LL\_CACHE\_HIT\_PRFM, Last level cache software prefetch hit

The counter counts each software prefetch counted by [LL\_CACHE\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8299--LL-CACHE-PRFM--Last-level-cache-software-prefetch?lang=en#event_ll_cache_prfm) that hits in the Last level cache.
