# ​J1.2.207 AArch64_PARFaultStatus

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-207-AArch64-PARFaultStatus>

##### J1.2.207 AArch64\_PARFaultStatus

```
// AArch64_PARFaultStatus()
// ========================
// Fault status field decoding of 64-bit PAR.
func AArch64_PARFaultStatus(fault : FaultRecord) => bits(6)
begin
    var fst : bits(6);
    if fault.statuscode == Fault_Domain then
        // Report Domain fault
        assert fault.level IN {1,2};
        fst[1:0] = if fault.level == 1 then ‘01’ else ‘10’;
        fst[5:2] = ‘1111’;
    else
        fst = EncodeLDFSC(fault.statuscode, fault.level);
    end;
    return fst;
end;
```
