##### H6.6.8 Debug behavior when the OS Lock is unlocked

When the OS Lock is unlocked, the PE sets [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).OSUC to 1 if the OS Unlock Catch debug event is enabled and the PE is in Non-debug state, meaning the OS Unlock Catch debug event becomes pending. See [OS Unlock Catch debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-6-OS-Unlock-Catch-debug-event?lang=en#babcchic).
