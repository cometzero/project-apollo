##### `0x8176`, LSE\_ST\_SPEC, Atomic memory Operation speculatively executed, store

The counter counts each Atomic memory operation counted by [LSE\_LDST\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8177--LSE-LDST-SPEC--Atomic-memory-Operation-speculatively-executed--load-or-store?lang=en#event_lse_ldst_spec) that does not return a value to the PE.
