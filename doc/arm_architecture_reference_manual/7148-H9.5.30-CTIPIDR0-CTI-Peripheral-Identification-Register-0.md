##### H9.5.30 CTIPIDR0, CTI Peripheral Identification Register 0

The CTIPIDR0 characteristics are:

Purpose
:   Provides information to identify a CTI component.

    For more information, see [‘About the Peripheral identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-4-About-the-Peripheral-identification-scheme?lang=en#babdfhah).

Configuration
:   CTIPIDR0 is in the Debug power domain

    This register is present only when FEAT\_CTI\_PIDR is implemented. Otherwise, direct accesses to CTIPIDR0 are RES0.

Attributes
:   CTIPIDR0 is a 32-bit register.

###### Field descriptions

![](images/7148-H9.5.30-CTIPIDR0-CTI-Peripheral-Identification-Register-0-img01.svg)

Bits [31:8]
:   Reserved, RES0.

PART\_0, bits [7:0]
:   Part number, which is selected by the designer of the component and stored as follows:

    - For a component with a 12-bit part number:
      - [CTIPIDR1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-31-CTIPIDR1--CTI-Peripheral-Identification-Register-1?lang=en#reg_ext_ctipidr1).PART\_1 contains part number bits [11:8].
      - [CTIPIDR0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-30-CTIPIDR0--CTI-Peripheral-Identification-Register-0?lang=en#reg_ext_ctipidr0).PART\_0 contains part number bits [7:0].
    - For a component with a 16-bit part number:
      - [CTIPIDR1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-31-CTIPIDR1--CTI-Peripheral-Identification-Register-1?lang=en#reg_ext_ctipidr1).PART\_1 contains part number bits [15:12].
      - [CTIPIDR0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-30-CTIPIDR0--CTI-Peripheral-Identification-Register-0?lang=en#reg_ext_ctipidr0).PART\_0 contains part number bits [11:4].
      - [CTIPIDR2](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-32-CTIPIDR2--CTI-Peripheral-Identification-Register-2?lang=en#reg_ext_ctipidr2).REVISION contains part number bits [3:0].

    When a 12-bit part number is used, [CTIPIDR2](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-32-CTIPIDR2--CTI-Peripheral-Identification-Register-2?lang=en#reg_ext_ctipidr2).REVISION indicates revision information.

    The choice of using a 12-bit part number or 16-bit part number is specific to the designer of the component.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
