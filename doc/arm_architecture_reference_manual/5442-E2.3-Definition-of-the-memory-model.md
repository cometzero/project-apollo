For more information on endpoint ordering of memory accesses, see [Reordering](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-8-Memory-types-and-attributes/-E2-8-2-Device-memory?lang=en#aa32chdibdaj).

In the memory model, the Shareability memory attribute indicates the degree to which hardware must ensure memory coherency between a set of observers, see [Memory types and attributes](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-8-Memory-types-and-attributes?lang=en#aa32chddaiha).
