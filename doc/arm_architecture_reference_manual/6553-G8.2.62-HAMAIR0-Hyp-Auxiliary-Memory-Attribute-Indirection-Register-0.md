# ​G8.2.62 HAMAIR0, Hyp Auxiliary Memory Attribute Indirection Register 0

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-62-HAMAIR0--Hyp-Auxiliary-Memory-Attribute-Indirection-Register-0>

##### G8.2.62 HAMAIR0, Hyp Auxiliary Memory Attribute Indirection Register 0

The HAMAIR0 characteristics are:

Purpose
:   Provides IMPLEMENTATION DEFINED memory attributes for the memory attribute encodings defined by [HMAIR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-69-HMAIR0--Hyp-Memory-Attribute-Indirection-Register-0?lang=en#reg_aarch32_hmair0). These IMPLEMENTATION DEFINED attributes can only provide additional qualifiers for the memory attribute encodings, and cannot change the memory attributes defined in [HMAIR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-69-HMAIR0--Hyp-Memory-Attribute-Indirection-Register-0?lang=en#reg_aarch32_hmair0).

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch32 System register HAMAIR0 bits [31:0] are architecturally mapped to AArch64 System register [AMAIR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-18-AMAIR-EL2--Auxiliary-Memory-Attribute-Indirection-Register--EL2-?lang=en#reg_aarch64_amair_el2)[31:0].

    This register is present only when FEAT\_AA32EL2 is implemented. Otherwise, direct accesses to HAMAIR0 are UNDEFINED.

Attributes
:   HAMAIR0 is a 32-bit register.

###### Field descriptions

![](images/6553-G8.2.62-HAMAIR0-Hyp-Auxiliary-Memory-Attribute-Indirection-Register-0-img01.svg)

If an implementation does not provide any IMPLEMENTATION DEFINED memory attributes, this register is RES0.

IMPLEMENTATION DEFINED, bits [31:0]
:   IMPLEMENTATION DEFINED.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
