# ​D11.5.2 Security states

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-5-Stage-1-permission-model/-D11-5-2-Security-states>

##### D11.5.2 Security states

I FYTRK
:   A [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) generated in Secure state that is marked in the first stage of translation as being Non-secure generates a Permission fault.

I FDCRS
:   A [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) generated in Secure state is allowed to access Non-secure memory as determined by [Memory access control](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control?lang=en#mdsec_memory_access_control).

I RSDVG
:   When [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is implemented, during execution at EL3, a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) to physical memory other than the Root physical address space causes a stage 1 Permission fault.

I HGYTX
:   If execution is using the Realm EL2 or Realm EL2&0 translation regime, a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) to physical memory other than the Realm physical address space causes a stage 1 Permission fault.

I THLDW
:   If execution is using the Realm EL1&0 translation regime, a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) is allowed to access physical memory that is not from the Realm physical address space.
