##### D9.7.1 Ordering of memory accesses from GPT walks

I CLGHP
:   If [FEAT\_ETS2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_ets2) is implemented, and a memory access RW1 is [Ordered-before](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-9-Definition-of-an-Architecturally-Allowed-Execution?lang=en#chdgejgh) a second memory access RW2, then RW1 is also [Ordered-before](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-9-Definition-of-an-Architecturally-Allowed-Execution?lang=en#chdgejgh) any translation table walk generated by RW2 that generates any of the following:

    - A Translation fault.
    - An Address size fault.
    - An Access flag fault.

    For more information, see [Ordering of memory accesses from translation table walks](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-2-Translation-process/-D8-2-6-Translation-table-walk-properties?lang=en#mdsec_ordering_of_memory_accesses_from_translation_table_walks).

R CKTPD
:   If [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is implemented, and a memory access RW1 is Ordered-before a second memory access RW2, then RW1 is also Ordered-before any GPT walk generated by RW2 that generates any of the following:

    - A GPT walk fault.
    - A GPT address size fault.
