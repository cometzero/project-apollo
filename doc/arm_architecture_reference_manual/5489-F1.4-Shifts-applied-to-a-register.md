#### F1.4 Shifts applied to a register

A32 register offset load/store word and unsigned byte instructions can apply a wide range of different constant shifts to the offset register. Both T32 and A32 data-processing instructions can apply the same range of different constant shifts to the second operand register. For details, see [Constant shifts](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-4-Shifts-applied-to-a-register/-F1-4-1-Constant-shifts?lang=en#babfaehf).

A32 data-processing instructions can apply a register-controlled shift to the second operand register.
