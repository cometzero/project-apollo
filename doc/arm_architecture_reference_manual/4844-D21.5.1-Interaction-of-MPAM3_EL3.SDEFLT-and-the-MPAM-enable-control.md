# ​D21.5.1 Interaction of MPAM3_EL3.SDEFLT and the MPAM enable control

##### D21.5.1 Interaction of MPAM3\_EL3.SDEFLT and the MPAM enable control

R CBRSV
:   In MPAMv0p1 and from MPAMv1p1, if the *Secure Default* control [MPAM3\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-4-MPAM3-EL3--MPAM3-Register--EL3-?lang=en#reg_aarch64_mpam3_el3).SDEFLT is implemented:

    - When the [MPAM enable control](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-1-About-MPAM/-D21-1-6-The-MPAM-enable-control?lang=en#mpam_mpam_enabled_control), MPAMEN, is 0, the MPAM PE Requester sends the [Default physical PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-/-D21-3-2-The-Default-PARTID?lang=en#mpam_default_partid) and the [Default PMG](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-4-Performance-Monitoring-Groups--PMGs-/-D21-4-2-The-Default-PMG?lang=en#mpam_default_pmg) with all requests to the memory system.
    - When MPAMEN is 1 and SDEFLT is 0, all requests from all Security states produce the PARTID and PMG from the [MPAMn\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mpamn_elx) registers.
    - When MPAMEN is 1 and SDEFLT is 1:

      - All requests from Secure state produce the [Default PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-/-D21-3-2-The-Default-PARTID?lang=en#mpam_default_partid) and the [Default PMG](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-4-Performance-Monitoring-Groups--PMGs-/-D21-4-2-The-Default-PMG?lang=en#mpam_default_pmg).
      - All requests from all other Security states produce the [PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-?lang=en#mpam_partition_identifiers) and [PMG](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-4-Performance-Monitoring-Groups--PMGs-?lang=en#mpam_pmg) from the [MPAMn\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mpamn_elx) registers.
