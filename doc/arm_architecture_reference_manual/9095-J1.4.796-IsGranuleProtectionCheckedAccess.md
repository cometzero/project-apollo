##### J1.4.796 IsGranuleProtectionCheckedAccess

```
// IsGranuleProtectionCheckedAccess()
// ==================================
// Check if the access should be subject to Granule protection check returns
// true if it is, false otherwise
func IsGranuleProtectionCheckedAccess(accdesc : AccessDescriptor) => boolean
begin
    if accdesc.acctype == AccessType_DC then
        return ImpDefBool(“GPC Fault on DC operations”);
    end;
    return TRUE;
end;
```
