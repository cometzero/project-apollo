# ​G8.3.29 DLR, Debug Link Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-29-DLR--Debug-Link-Register>

##### G8.3.29 DLR, Debug Link Register

The DLR characteristics are:

Purpose
:   In Debug state, holds the address to restart from.

Configuration
:   This register is a Special-purpose register.

    AArch32 System register DLR bits [31:0] are architecturally mapped to AArch64 System register [DLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-13-DLR-EL0--Debug-Link-Register?lang=en#reg_aarch64_dlr_el0)[31:0].

    This register is present only when FEAT\_AA32 is implemented. Otherwise, direct accesses to DLR are UNDEFINED.

Attributes
:   DLR is a 32-bit register.

###### Field descriptions

![](images/6694-G8.3.29-DLR-Debug-Link-Register-img01.svg)

ADDR, bits [31:0]
:   Restart address.
