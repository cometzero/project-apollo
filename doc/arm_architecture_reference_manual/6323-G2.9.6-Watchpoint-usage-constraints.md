If a watchpoint is programmed with one of these reserved combinations:

- The watchpoint must behave as if it is either:

  - Disabled.
  - Programmed with a combination that is not reserved, other than for a direct or external read of [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).
- For a direct or external read of [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn), if the reserved combination:

  - Has no function for any execution conditions, the value read back for each of SSC, HMC, and PAC is UNKNOWN.
  - Has a function for execution conditions other than the current execution conditions, the value read back is the value written. This permits software to save and restore the combination so that the watchpoint functions for the other execution conditions.

The behavior of watchpoints with reserved combinations of SSC, HMC, and PAC might change in future revisions of the architecture. For this reason, software must not rely on the behavior described here.

###### G2.9.6.2 Reserved DBGWCR<n>.LBN values

For Linked watchpoints
:   A Linked watchpoint must link to a context-aware breakpoint. For a Linked watchpoint, any [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).LBN value that is not for a context-aware breakpoint is reserved.

    If a Linked watchpoint links to a breakpoint that is not implemented, or that is not context-aware, then reads of [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).LBN return an UNKNOWN value and the behavior is CONSTRAINED UNPREDICTABLE. The Linked watchpoint behaves as if it is either:

    - Disabled.
    - Linked to an UNKNOWN context-aware breakpoint.

    If a Linked watchpoint links to a breakpoint that is implemented and is context-aware, but that is either not enabled or not programmed as a Linked Context breakpoint, it behaves as if it is disabled.

For Unlinked watchpoints
:   For Unlinked watchpoints, [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).LBN reads UNKNOWN and its value is ignored.

###### G2.9.6.3 Programming dependencies of the BAS and MASK fields

When programming a watchpoint, a debugger must use either:

- The MASK field, to program the watchpoint with an address range that can be eight bytes to 2GB.
- The BAS field, to select which bytes in the doubleword or word starting at the address contained in the [DBGWVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-28-DBGWVR-n---Debug-Watchpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgwvrn) the watchpoint must generate Watchpoint exceptions for.

If the debugger uses the:

- MASK field, it must program BAS to be `0b11111111`, so that all bytes in the doubleword or word are selected.
- BAS field, it must program MASK to be `0b00000`, so that the MASK field does not indicate any address ranges.

If an enabled watchpoint has a MASK field that is nonzero and a BAS field that is not set to `0b11111111`, then for each byte in the address range, it is CONSTRAINED UNPREDICTABLE whether or not a Watchpoint exception is generated.

###### G2.9.6.4 Reserved DBGWCR<n>.BAS values

The BAS field must be programmed with a value [`Zeros`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-1-Standard-library?lang=en#asl_standard_library_zeros) `(8-n-m):` [`Ones`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-1-Standard-library?lang=en#asl_standard_library_ones) `(n):` [`Zeros`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-1-Standard-library?lang=en#asl_standard_library_zeros) `(m)`, where:

- `n` is a nonzero positive integer less-than-or-equal-to 8.
- `m` is a positive integer less-than 8. `m` is permitted to be zero.
- `n+m` is less-than-or-equal-to 8.
- If [DBGWVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-28-DBGWVR-n---Debug-Watchpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgwvrn)[2] is 1, then `n+m` is less-than-or-equal-to 4.

All other values are reserved.

> #### Note
>
> [`Zeros`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-1-Standard-library?lang=en#asl_standard_library_zeros)`{0}()` is an empty bitstring.

If [DBGWVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-28-DBGWVR-n---Debug-Watchpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgwvrn)[2] is 1, [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).BAS[7:4] are RES0.

If a watchpoint is programmed with a reserved BAS value:

- It is CONSTRAINED UNPREDICTABLE whether the watchpoint generates a Watchpoint exception for each byte in the doubleword or word of memory addressed by the [DBGWVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-28-DBGWVR-n---Debug-Watchpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgwvrn).
- A direct or external read of [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).BAS returns an UNKNOWN value.

Software must not rely on these properties as the behavior of reserved values might change in a future revision of the architecture.

###### G2.9.6.5 Reserved DBGWCR<n>.MASK values

If a watchpoint is programmed with a reserved MASK value:

- The watchpoint must behave as if it is either:

  - Disabled.
  - Programmed with an UNKNOWN value that is not reserved, that might be `0b00000`, other than for a direct or external read of [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).
- A direct or external read of [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).MASK returns an UNKNOWN value.

###### G2.9.6.6 Other usage constraints

For all watchpoints:

- [DBGWVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-28-DBGWVR-n---Debug-Watchpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgwvrn)[1:0] are RES0 and are ignored.
- If [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).MASK is nonzero, and any masked bits of [DBGWVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-28-DBGWVR-n---Debug-Watchpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgwvrn) are not 0, it is CONSTRAINED UNPREDICTABLE whether the watchpoint generates a Watchpoint exception when the unmasked bits match.
- A watchpoint never generates any Watchpoint exceptions if [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).LSC is `0b00`.
