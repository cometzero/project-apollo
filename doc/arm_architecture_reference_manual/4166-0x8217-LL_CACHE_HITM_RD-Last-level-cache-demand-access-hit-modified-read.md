##### `0x8217`, LL\_CACHE\_HITM\_RD, Last level cache demand access hit modified, read

The counter counts each cache access counted by [LL\_CACHE\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81C7--LL-CACHE-HIT-RD--Last-level-cache-demand-access-hit--read?lang=en#event_ll_cache_hit_rd) that accesses a previously modified cache location.
