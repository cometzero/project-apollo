# ​G8.6.20 VDISR, Virtual Deferred Interrupt Status Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-20-VDISR--Virtual-Deferred-Interrupt-Status-Register>

##### G8.6.20 VDISR, Virtual Deferred Interrupt Status Register

The VDISR characteristics are:

Purpose
:   Records that an SError exception has been consumed by an `ESB` instruction.

Configuration
:   If EL2 is not implemented, then VDISR is RES0 from Monitor mode when SCR.NS == 1.

    AArch32 System register VDISR bits [31:0] are architecturally mapped to AArch64 System register [VDISR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-16-VDISR-EL2--Virtual-Deferred-Interrupt-Status-Register--EL2-?lang=en#reg_aarch64_vdisr_el2)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented and FEAT\_RAS is implemented. Otherwise, direct accesses to VDISR are UNDEFINED.

Attributes
:   VDISR is a 32-bit register.

###### Field descriptions

When TTBCR.EAE == '0':
:   ![](images/6757-G8.6.20-VDISR-Virtual-Deferred-Interrupt-Status-Register-img01.svg)

A, bit [31]
:   Set to 1 when an `ESB` instruction defers a virtual SError exception.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bits [30:16]
:   Reserved, RES0.

AET, bits [15:14]
:   The value copied from [VDFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-19-VDFSR--Virtual-SError-Exception-Syndrome-Register?lang=en#reg_aarch32_vdfsr).AET.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bit [13]
:   Reserved, RES0.

ExT, bit [12]
:   The value copied from [VDFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-19-VDFSR--Virtual-SError-Exception-Syndrome-Register?lang=en#reg_aarch32_vdfsr).ExT.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bit [11]
:   Reserved, RES0.

FS, bits [10, 3:0]
:   Fault status code. Set to `0b10110` when an `ESB` instruction defers a virtual SError exception.

###### Accessing VDISR

Direct reads and writes of VDFSR are UNDEFINED if EL3 is implemented and using AArch32 in all Secure privileged modes other than Monitor mode.

An indirect write to VDISR made by an `ESB` instruction does not require an explicit synchronization operation for the value that is written to be observed by a direct read of [DISR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-1-DISR--Deferred-Interrupt-Status-Register?lang=en#reg_aarch32_disr) occurring in program order after the `ESB` instruction.

If EL2 is not implemented, then VDISR is RES0 from Monitor mode when [SCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-126-SCR--Secure-Configuration-Register?lang=en#reg_aarch32_scr).NS == 1.

Accesses to this register use the following encodings in the System register encoding space:
