##### F5.1.164 RORS (register)

Rotate Right, setting flags (register) provides the value of the contents of a register rotated by a variable number of bits, and updates the condition flags based on the result. The bits that are rotated off the right end are inserted into the vacated bit positions on the left. The variable number of bits is read from the bottom byte of a register.

This is an alias of [MOV, MOVS (register-shifted register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-114-MOV--MOVS--register-shifted-register-?lang=en#isa_mov_rr). This means:

- The encodings in this description are named to match the encodings of [MOV, MOVS (register-shifted register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-114-MOV--MOVS--register-shifted-register-?lang=en#isa_mov_rr).
- The description of [MOV, MOVS (register-shifted register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-114-MOV--MOVS--register-shifted-register-?lang=en#isa_mov_rr) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-164-RORS--register-?lang=en#isa_rors_mov_rr_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-164-RORS--register-?lang=en#isa_rors_mov_rr_iclass_t1) and [T2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-164-RORS--register-?lang=en#isa_rors_mov_rr_iclass_t2)).

###### A1

![](images/5781-F5.1.164-RORS-register-img01.svg)

###### Encoding for the Flag setting variant

```
RORS{<c>}{<q>}  {<Rd>, }<Rm>, <Rs>
```

is equivalent to

```
MOVS{<c>}{<q>}  <Rd>, <Rm>, ROR <Rs>
```

and is always the preferred disassembly.

###### T1

![](images/5781-F5.1.164-RORS-register-img02.svg)

###### Encoding for the Rotate right variant

```
RORS{<q>}  {<Rdm>, }<Rdm>, <Rs>
```

is equivalent to

```
MOVS{<q>}  <Rdm>, <Rdm>, ROR <Rs>
```

and is the preferred disassembly when `!InITBlock()`.

###### T2

![](images/5781-F5.1.164-RORS-register-img03.svg)

###### Encoding for the Flag setting variant

```
RORS{<c>}{<q>}  {<Rd>, }<Rm>, <Rs>
```

```
RORS.W  {<Rd>, }<Rm>, <Rs> // (!InITBlock() && (UInt(Rd) < 8 && Rd == Rm && UInt(Rs) < 8))
```

is equivalent to

```
MOVS{<c>}{<q>}  <Rd>, <Rm>, ROR <Rs>
```

and is always the preferred disassembly.

<Rd>
:   ​

    Is the general-purpose destination register, encoded in the “Rd” field.

<Rm>
:   ​

    Is the first general-purpose source register, encoded in the “Rm” field.

<Rs>
:   ​

    Is the second general-purpose source register holding a rotate amount in its bottom 8 bits, encoded in the “Rs” field.

<Rdm>
:   ​

    Is the first general-purpose source register and the destination register, encoded in the “Rdm” field.
