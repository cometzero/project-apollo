I XFDFY
:   All of the following controls can ensure that memory locations are not both writable and executable:

    - For privileged accesses in all translation regimes, PrivWXN.
    - For unprivileged accesses in the EL1&0 and EL2&0 translation regimes, UnprivWXN.

I KWYWX
:   [UnprivRead](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdterm_unprivread), [UnprivWrite](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdterm_unprivwrite), [UnprivGCS](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdterm_unprivgcs), [UnprivExecute](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdterm_unprivexecute), and [UnprivWXN](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdterm_unprivwxn) do not apply to the EL2 and EL3 translation regimes.

R VBBBJ
:   If stage 1 translation is disabled, then stage 1 permits all data accesses, instruction executions, and GCS accesses.

I MTSDS
:   If stage 1 translation is enabled, then stage 1 permissions are determined by all of the following:

    - Stage 1 Base permissions. For more information, see [Stage 1 Base permissions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdsec_stage_1_base_permissions).
    - Stage 1 Overlay permissions. For more information, see [Stage 1 Overlay permissions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdsec_stage_1_overlay_permissions).

###### D8.4.1.1 Stage 1 Base permissions

I PJNLQ
:   Stage 1 Base permissions can be determined by one of the following:

    - Stage 1 Direct permissions. For more information, see [Stage 1 Direct permissions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdsec_stage_1_direct_permissions).
    - Stage 1 Indirect permissions. For more information, see [Stage 1 Indirect permissions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-4-Memory-access-control/-D8-4-1-Stage-1-permissions?lang=en#mdsec_stage_1_indirect_permissions).

I SXTJD
:   If [FEAT\_S1PIE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_s1pie) is not implemented, then stage 1 Direct permissions are used.

I VYHZC
:   If stage 1 translation uses VMSAv8-64, then the choice between Direct and Indirect permissions is determined by one of the following:

    - If the Exception level is not EL3, then [TCR2\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#tcr2_elx).PIE.
    - If the Exception level is EL3, then [TCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-195-TCR-EL3--Translation-Control-Register--EL3-?lang=en#reg_aarch64_tcr_el3).PIE.

I BSXJT
:   Stage 1 Direct permissions are not supported by VMSAv9-128. If stage 1 translation uses VMSAv9-128, then it uses Indirect permissions and the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of the PIE field is 1.
