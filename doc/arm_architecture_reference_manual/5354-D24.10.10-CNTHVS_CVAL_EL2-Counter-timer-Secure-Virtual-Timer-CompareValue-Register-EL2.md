# ​D24.10.10 CNTHVS_CVAL_EL2, Counter-timer Secure Virtual Timer CompareValue Register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-10-CNTHVS-CVAL-EL2--Counter-timer-Secure-Virtual-Timer-CompareValue-Register--EL2->

##### D24.10.10 CNTHVS\_CVAL\_EL2, Counter-timer Secure Virtual Timer CompareValue Register (EL2)

The CNTHVS\_CVAL\_EL2 characteristics are:

Purpose
:   Holds the compare value for the Secure EL2 virtual timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch64 System register CNTHVS\_CVAL\_EL2 bits [63:0] are architecturally mapped to AArch32 System register [CNTHVS\_CVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-13-CNTHVS-CVAL--Counter-timer-Secure-Virtual-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch32_cnthvs_cval)[63:0].

    This register is present only when FEAT\_SEL2 is implemented, FEAT\_VHE is implemented, and FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTHVS\_CVAL\_EL2 are UNDEFINED.

Attributes
:   CNTHVS\_CVAL\_EL2 is a 64-bit register.

###### Field descriptions

![](images/5354-D24.10.10-CNTHVS_CVAL_EL2-Counter-timer-Secure-Virtual-Timer-CompareValue-Register-EL2-img01.svg)

CompareValue, bits [63:0]
:   Holds the Secure EL2 virtual timer CompareValue.

    When [CNTHVS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-9-CNTHVS-CTL-EL2--Counter-timer-Secure-Virtual-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthvs_ctl_el2).ENABLE is 1, and TimerConditionMet is TRUE for the Secure EL2 virtual timer, the timer condition is met and all of the following are true:

    - [CNTHVS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-9-CNTHVS-CTL-EL2--Counter-timer-Secure-Virtual-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthvs_ctl_el2).ISTATUS is set to 1.
    - If [CNTHVS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-9-CNTHVS-CTL-EL2--Counter-timer-Secure-Virtual-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthvs_ctl_el2).IMASK is 0, an interrupt is generated.

    TimerConditionMet is defined by [‘Operation of the CompareValue views of the timers’](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-2-The-AArch64-view-of-the-Generic-Timer/-D12-2-4-Timers?lang=en#chddaeaj).

    The CompareValue view of the timer acts like a 64-bit upcounter timer.

    When [CNTHVS\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-9-CNTHVS-CTL-EL2--Counter-timer-Secure-Virtual-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthvs_ctl_el2).ENABLE is 0, the timer condition is not met, but [CNTVCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register?lang=en#reg_aarch64_cntvct_el0) continues to count.

    If the Generic counter is implemented at a size less than 64 bits, then this field is permitted to be implemented at the same width as the counter, and the upper bits are RES0.

    The value of this field is treated as zero-extended in all counter calculations.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
