##### B1.3.1 Accessing PSTATE fields at EL0

At EL0 using AArch64 state, [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1) fields can be accessed using Special-purpose registers that can be directly read using the [MRS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-287-MRS?lang=en#isa_mrs) instruction and directly written using the [MSR (register)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-289-MSR--register-?lang=en#isa_msr_reg) instructions. [Table B1-1](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE/-B1-3-1-Accessing-PSTATE-fields-at-EL0?lang=en#tbl_chddhdjd) shows the Special-purpose registers that access the [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1) fields that hold AArch64 state when the PE is at EL0 using AArch64. All other [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1) fields do not have direct read and write access at EL0.

Access to the [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).{D, A, I, F} fields at EL0 using AArch64 state depends on [SCTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-174-SCTLR-EL1--System-Control-Register--EL1-?lang=en#reg_aarch64_sctlr_el1).UMA.

Software can more efficiently change [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).{SM, ZA} by using [SMSTART](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-376-SMSTART?lang=en#isa_smstart_msr_imm) and [SMSTOP](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-377-SMSTOP?lang=en#isa_smstop_msr_imm) instructions.

Writes to the [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1) fields have side-effects on various aspects of the PE operation. All of these side-effects, are guaranteed:

- Not to be visible to earlier instructions in the execution stream.
- To be visible to later instructions in the execution stream.
