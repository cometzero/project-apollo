##### J1.4.107 IsRange3Counter

```
// IsRange3Counter()
// =================
// Returns TRUE if the counter is in the third range.
func IsRange3Counter(n : integer) => boolean
begin
    return PMUCounterRange_R3 == GetPMUCounterRange(n);
end;
```
