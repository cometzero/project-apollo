##### `0x83EA`, N3\_MEM1\_RD, Access to type 1 memory at distance 3, demand access, read

The counter counts each demand read counted by [N3\_MEM\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E2--N3-MEM-RD--Access-to-memory-at-distance-3--demand-access--read?lang=en#event_n3_mem_rd) to a first memory type at distance 3.

The definition of memory types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system. See also [N1\_MEM1\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E8--N1-MEM1-RD--Access-to-type-1-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem1_rd).
