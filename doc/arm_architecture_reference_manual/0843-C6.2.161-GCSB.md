##### C6.2.161 GCSB

Guarded Control Stack barrier

This instruction generates a GCSB effect.

If [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) is not implemented, this instruction executes as a `NOP`.
