# ​G8.2.114 MPIDR, Multiprocessor Affinity Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register>

##### G8.2.114 MPIDR, Multiprocessor Affinity Register

The MPIDR characteristics are:

Purpose
:   In a multiprocessor system, provides an additional PE identification mechanism.

Configuration
:   In a uniprocessor system, Arm recommends that each Aff<n> field of this register returns a value of 0.

    AArch32 System register MPIDR bits [31:0] are architecturally mapped to AArch64 System register [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to MPIDR are UNDEFINED.

Attributes
:   MPIDR is a 32-bit register.

Aff2, bits [23:16]
:   Affinity level 2. See the description of Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

Aff1, bits [15:8]
:   Affinity level 1. See the description of Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

Aff0, bits [7:0]
:   Affinity level 0. The value of the [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).{Aff2, Aff1, Aff0} or [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1).{Aff3, Aff2, Aff1, Aff0} set of fields of each PE must be unique within the system as a whole.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
