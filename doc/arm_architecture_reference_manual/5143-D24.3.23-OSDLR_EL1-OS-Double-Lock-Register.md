# ​D24.3.23 OSDLR_EL1, OS Double Lock Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-23-OSDLR-EL1--OS-Double-Lock-Register>

##### D24.3.23 OSDLR\_EL1, OS Double Lock Register

The OSDLR\_EL1 characteristics are:

Purpose
:   Used to control the OS Double Lock.

Configuration
:   AArch64 System register OSDLR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [DBGOSDLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-20-DBGOSDLR--Debug-OS-Double-Lock-Register?lang=en#reg_aarch32_dbgosdlr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to OSDLR\_EL1 are UNDEFINED.

Attributes
:   OSDLR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5143-D24.3.23-OSDLR_EL1-OS-Double-Lock-Register-img01.svg)

Bits [63:1]
:   Reserved, RES0.

DLK, bit [0]
:   When FEAT\_DoubleLock is implemented:
    :   OS Double Lock control bit.
