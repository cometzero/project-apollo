##### J1.2.31 IsAddressLinkingBreakpoint

```
// IsAddressLinkingBreakpoint()
// ============================
// Returns TRUE if DBGBCR_EL1(n) supports being configured as an Address matching breakpoint with
// linking enabled.
func IsAddressLinkingBreakpoint(n : integer) => boolean
begin
    return n < NumAddressLinkingBreakpointsImplemented();
end;
```
