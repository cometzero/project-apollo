# ​J1.2.418 AArch64_EncodeAsyncErrorSyndrome

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-418-AArch64-EncodeAsyncErrorSyndrome>

##### J1.2.418 AArch64\_EncodeAsyncErrorSyndrome

```
// AArch64_EncodeAsyncErrorSyndrome()
// ==================================
// Return the encoding for specified ErrorState for an SError exception taken
// to AArch64 state.
func AArch64_EncodeAsyncErrorSyndrome(errorstate : ErrorState) => bits(3)
begin
    case errorstate of
        when ErrorState_UC  => return ‘000’;
        when ErrorState_UEU => return ‘001’;
        when ErrorState_UEO => return ‘010’;
        when ErrorState_UER => return ‘011’;
        when ErrorState_CE  => return ‘110’;
        otherwise => unreachable;
    end;
end;
```
