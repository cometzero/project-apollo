# ​G1.10.1 Pseudocode description of general-purpose register and PC operations

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-10-AArch32-general-purpose-registers--the-PC--and-the-Special-purpose-registers/-G1-10-1-Pseudocode-description-of-general-purpose-register-and-PC-operations>

##### G1.10.1 Pseudocode description of general-purpose register and PC operations

The following pseudocode gives access to the general-purpose registers and the PC. These registers are an array, [`_R`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-500--R?lang=en#asl_shared_functions_registers__r), indexed by parameter `n`. This array is common to AArch32 and AArch64 operation and therefore contains 31 64-bit registers. [`_PC`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-499--PC?lang=en#asl_shared_functions_registers__pc) is the Program Counter, and its definition is common to AArch32 and AArch64 operation and therefore its size is 64-bit.

[`LookUpRIndex`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-129-LookUpRIndex?lang=en#asl_func_lookuprindex_2)`()` looks up the index value, `n`, for the specified register number and PE mode, using [`RBankSelect`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-136-RBankSelect?lang=en#asl_func_rbankselect_8)`()` to evaluates the result.

[`_R`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-500--R?lang=en#asl_shared_functions_registers__r) accesses the specified general-purpose register in the current PE mode, using [`Rmode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-139-Rmode?lang=en#asl_accessor_rmode_2)`()` to access the register, accessing [`_R`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-500--R?lang=en#asl_shared_functions_registers__r) if necessary. [`SP`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-452-SP?lang=en#asl_accessor_sp_1) accesses the stack pointer, [`LR`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-127-LR?lang=en#asl_accessor_lr_0) accesses the link register, and [`PC32`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-131-PC32?lang=en#asl_func_pc32_0) accesses the Program Counter. Each function has a non-assignment form for register reads and an assignment form for register writes, other than [`PC32`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-131-PC32?lang=en#asl_func_pc32_0), which has only a non-assignment form.

[`BranchTo`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-486-BranchTo?lang=en#asl_func_branchto_4)`()` performs a branch to the specified address.

The [`_R`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-500--R?lang=en#asl_shared_functions_registers__r) [`_PC`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-499--PC?lang=en#asl_shared_functions_registers__pc), [`LR`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-127-LR?lang=en#asl_accessor_lr_0), [`PC32`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-131-PC32?lang=en#asl_func_pc32_0), [`SP`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-452-SP?lang=en#asl_accessor_sp_1), [`LookUpRIndex`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-129-LookUpRIndex?lang=en#asl_func_lookuprindex_2)`()`, [`RBankSelect`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-136-RBankSelect?lang=en#asl_func_rbankselect_8)`()`, and [`BranchTo`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-486-BranchTo?lang=en#asl_func_branchto_4)`()` functions are defined in [A-profile Architecture Pseudocode](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode?lang=en#chap_pseudocode).
