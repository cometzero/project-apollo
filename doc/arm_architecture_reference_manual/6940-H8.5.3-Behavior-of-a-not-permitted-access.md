# ​H8.5.3 Behavior of a not permitted access

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-5-External-debug-interface-register-access-permissions/-H8-5-3-Behavior-of-a-not-permitted-access>

##### H8.5.3 Behavior of a not permitted access

For an external debug interface access by a Debug Access Port, the Debug Access Port receives the error response and must signal this to the external debugger. For an ADIv5 implementation of a Debug Access Port, the error sets a sticky error flag in the Debug Access Port that the debugger can poll, and that suppresses further accesses until it is explicitly cleared.

When an error is returned because external access is disabled, and this is the highest priority error condition, a sticky error flag in [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) is indirectly written to 1 as a side-effect of the access:

- For a debug register access when [`AllowExternalDebugAccess`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-12-AllowExternalDebugAccess?lang=en#asl_func_allowexternaldebugaccess_1)`()` == FALSE, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SDAD is indirectly written to 1.
- For Performance Monitor register access when [`AllowExternalPMUAccess`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-14-AllowExternalPMUAccess?lang=en#asl_func_allowexternalpmuaccess_1)`()` == FALSE, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPMAD is indirectly written to 1.

The indirect write might not occur for a memory-mapped access to the external debug interface. For more information, see [Register access permissions for memory-mapped accesses](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-4-Memory-mapped-accesses-to-the-external-debug-interface/-H8-4-1-Register-access-permissions-for-memory-mapped-accesses?lang=en#ciheihgc).

If no error is returned, or the error is returned because of a higher priority error condition, the flag in [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) is unchanged.

See also [Behavior of a not permitted memory-mapped access](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-4-Memory-mapped-accesses-to-the-external-debug-interface/-H8-4-1-Register-access-permissions-for-memory-mapped-accesses?lang=en#cihgdega).

For more information, see *Arm® Debug Interface Architecture Specification*.
