# ​D24.2.30 CCSIDR2_EL1, Current Cache Size ID Register 2

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-30-CCSIDR2-EL1--Current-Cache-Size-ID-Register-2>

##### D24.2.30 CCSIDR2\_EL1, Current Cache Size ID Register 2

The CCSIDR2\_EL1 characteristics are:

Purpose
:   Provides the information about the architecture of the currently selected cache from bits[63:32] of [CCSIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-31-CCSIDR-EL1--Current-Cache-Size-ID-Register?lang=en#reg_aarch64_ccsidr_el1).

Configuration
:   In an implementation which does not support AArch32 at EL1, it is IMPLEMENTATION DEFINED whether reading this register gives an UNKNOWN value or is UNDEFINED.

    The implementation includes one CCSIDR2\_EL1 for each cache that it can access. [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1) selects which Cache Size ID Register is accessible.

    AArch64 System register CCSIDR2\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [CCSIDR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-25-CCSIDR2--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch32_ccsidr2)[31:0].

    This register is present only when FEAT\_CCIDX is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to CCSIDR2\_EL1 are UNDEFINED.

Attributes
:   CCSIDR2\_EL1 is a 64-bit register.

###### Field descriptions

![](images/4922-D24.2.30-CCSIDR2_EL1-Current-Cache-Size-ID-Register-2-img01.svg)

Bits [63:24]
:   Reserved, RES0.

NumSets, bits [23:0]
:   (Number of sets in cache) - 1, therefore a value of 0 indicates 1 set in the cache. The number of sets does not have to be a power of 2.

###### Accessing CCSIDR2\_EL1

If [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1).{TnD, Level, InD} is programmed to a cache level that is not implemented, then on a read of the CCSIDR2\_EL1 the behavior is CONSTRAINED UNPREDICTABLE, and can be one of the following:

- The CCSIDR2\_EL1 read is treated as NOP.
- The CCSIDR2\_EL1 read is UNDEFINED. If [FEAT\_IDST](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_idst) is implemented, this is permitted to be reported with EC syndrome value `0x18`.
- The CCSIDR2\_EL1 read returns an UNKNOWN value.
