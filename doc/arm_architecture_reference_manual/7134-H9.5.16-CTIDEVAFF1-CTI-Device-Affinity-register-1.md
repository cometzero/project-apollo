# ​H9.5.16 CTIDEVAFF1, CTI Device Affinity register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-16-CTIDEVAFF1--CTI-Device-Affinity-register-1>

##### H9.5.16 CTIDEVAFF1, CTI Device Affinity register 1

The CTIDEVAFF1 characteristics are:

Purpose
:   Copy of the high half of the PE [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1) register that allows a debugger to determine which PE in a multiprocessor system the CTI component relates to.

Configuration
:   CTIDEVAFF1 is in the Debug power domain

    If the CTI is CTIv1, this register is OPTIONAL. If the CTI is CTIv2, this register is mandatory.

    Arm recommends that the CTI is CTIv2.

    In an Armv8.5 compliant implementation, the CTI must be CTIv2.

    If this register is implemented, then [CTIDEVAFF0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-15-CTIDEVAFF0--CTI-Device-Affinity-register-0?lang=en#reg_ext_ctidevaff0) must also be implemented. If the CTI of a PE does not implement the CTI Device Affinity registers, the CTI block of the external debug memory map must be located 64KB above the debug registers in the external debug interface.

Attributes
:   CTIDEVAFF1 is a 32-bit register.

###### Field descriptions

![](images/7134-H9.5.16-CTIDEVAFF1-CTI-Device-Affinity-register-1-img01.svg)

Bits [31:8]
:   Reserved, RES0.

Aff3, bits [7:0]
:   Affinity level 3. See the description of [CTIDEVAFF0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-15-CTIDEVAFF0--CTI-Device-Affinity-register-0?lang=en#reg_ext_ctidevaff0).Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
