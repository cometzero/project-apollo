# ​C5.2.29 TCO, Tag Check Override

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-29-TCO--Tag-Check-Override>

##### C5.2.29 TCO, Tag Check Override

The TCO characteristics are:

Purpose
:   When FEAT\_MTE is implemented, this register allows tag checks to be disabled globally.

    When [FEAT\_MTE2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-6-The-Armv8-5-architecture-extension?lang=en#feat_feat_mte2) is not implemented, it is IMPLEMENTATION DEFINED if accesses to this register access PSTATE.TCO or are RAZ/WI.

Configuration
:   This register is a Special-purpose register.

    This register is present only when FEAT\_MTE is implemented. Otherwise, direct accesses to TCO are UNDEFINED.

Attributes
:   TCO is a 64-bit register.

###### Field descriptions

![](images/0446-C5.2.29-TCO-Tag-Check-Override-img01.svg)

Bits [63:26]
:   Reserved, RES0.

TCO, bit [25]
:   Allows memory tag checks to be globally disabled.
