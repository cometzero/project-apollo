##### `0x8470`, FP\_SP\_MIN\_SPEC, Floating-point operation speculatively executed, smallest type is single-precision floating-point

The counter counts each floating-point operation counted by [FP\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8010--FP-SPEC--Floating-point-operation-speculatively-executed--including-SIMD?lang=en#event_fp_spec) due to an instruction where the smallest type was single-precision floating-point.
