# ​G8.2.36 CSSELR, Cache Size Selection Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-36-CSSELR--Cache-Size-Selection-Register>

##### G8.2.36 CSSELR, Cache Size Selection Register

The CSSELR characteristics are:

Purpose
:   Selects the current Cache Size ID Register, [CCSIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-24-CCSIDR--Current-Cache-Size-ID-Register?lang=en#reg_aarch32_ccsidr), by specifying the required cache level and the cache type, which is either instruction cache or data cache.

    If [FEAT\_CCIDX](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_ccidx) is implemented, CSSELR also selects the current [CCSIDR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-25-CCSIDR2--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch32_ccsidr2).

Configuration
:   AArch32 System register CSSELR bits [31:0] are architecturally mapped to AArch64 System register [CSSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-40-CSSELR-EL1--Cache-Size-Selection-Register?lang=en#reg_aarch64_csselr_el1)[31:0].

    This register is banked between CSSELR and CSSELR\_S and CSSELR\_NS.

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to CSSELR are UNDEFINED.

Attributes
:   CSSELR is a 32-bit register.

    This register has the following instances:

    - CSSELR, when EL3 is not implemented or FEAT\_AA64 is implemented.
    - CSSELR\_S, when FEAT\_AA32EL3 is implemented.
    - CSSELR\_NS, when FEAT\_AA32EL3 is implemented.
