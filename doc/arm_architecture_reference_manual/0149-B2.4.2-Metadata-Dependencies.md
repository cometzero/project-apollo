##### B2.4.2 Metadata Dependencies

I YRYHC
:   The execution of the following instructions create ordering relations for the purposes of the Arm memory model:

    - [`IRG`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-177-IRG?lang=en#isa_irg).
    - [`PACDA`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-303-PACDA--PACDZA?lang=en#isa_pacda).
    - [`PACDB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-304-PACDB--PACDZB?lang=en#isa_pacdb).
    - [`AUTDA`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-23-AUTDA--AUTDZA?lang=en#isa_autda).
    - [`AUTDB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-24-AUTDB--AUTDZB?lang=en#isa_autdb)

R TVHSL
:   If [FEAT\_MTE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-6-The-Armv8-5-architecture-extension?lang=en#feat_feat_mte) is implemented, the execution of an [`IRG Xd,Xn,Xm`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-177-IRG?lang=en#isa_irg) instruction creates:

    - A [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xn to Register Write Effect of Xd.
    - If Allocation Tag Access is not prevented for the current Exception level, a [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xm to Register Write Effect of Xd.

R MSWTM
:   If [FEAT\_PAuth](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_pauth) is implemented, the execution of a [`PACDA Xd,Xn`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-303-PACDA--PACDZA?lang=en#isa_pacda) instruction creates:

    - A [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xd to Register Write Effect of Xd.
    - If authentication using the [APDAKey\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-10-Pointer-authentication/-D8-10-2-PAC-generation-and-verification-keys?lang=en#chdggfbgb1) key is enabled, a [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xn to Register Write Effect of Xd.

R JMNSC
:   If [FEAT\_FPAC](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_fpac) is implemented, the execution of a [`PACDB Xd,Xn`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-304-PACDB--PACDZB?lang=en#isa_pacdb) instruction creates:

    - A [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xd to Register Write Effect of Xd.
    - If authentication using the [APDBKey\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-10-Pointer-authentication/-D8-10-2-PAC-generation-and-verification-keys?lang=en#chdjacjhe5) key is enabled, a [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xn to Register Write Effect of Xd.

R XYRJT
:   If [FEAT\_FPAC](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_fpac) is implemented, the execution of an [`AUTDA Xd,Xn`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-23-AUTDA--AUTDZA?lang=en#isa_autda) instruction creates:

    - If authentication using the [APDAKey\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-10-Pointer-authentication/-D8-10-2-PAC-generation-and-verification-keys?lang=en#chdggfbgb1) key is enabled, a [Pick dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_pick_dependency_through_registers_and_memory) from the Register Read Effect of Xn to Register Write Effect of Xd.
    - A [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xd to Register Write Effect of Xd.

R SPBZX
:   If [FEAT\_FPAC](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_fpac) is implemented, the execution of an [`AUTDB Xd,Xn`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-24-AUTDB--AUTDZB?lang=en#isa_autdb) instruction creates:

    - If authentication using the [APDBKey\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-10-Pointer-authentication/-D8-10-2-PAC-generation-and-verification-keys?lang=en#chdjacjhe5) key is enabled, a [Pick dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_pick_dependency_through_registers_and_memory) from the Register Read Effect of Xn to Register Write Effect of Xd.
    - A [Dependency through registers and memory](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model/-B2-3-6-Dependency-relations?lang=en#mm_dependency_through_registers_and_memory) from the Register Read Effect of Xd to Register Write Effect of Xd.
