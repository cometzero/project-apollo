##### C9.2.170 MOV (tile to vector, single)

Move ZA tile slice to Z vector

This instruction operates on individual horizontal or vertical slices within a named ZA tile of the specified element size. The slice number within the tile is selected by the sum of the slice index register and immediate offset, modulo the number of such elements in a vector. The immediate offset is in the range 0 to the number of elements in a 128-bit vector segment minus 1. Inactive elements in the destination vector remain unmodified.

This is an alias of [MOVA (tile to vector, single)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza). This means:

- The encodings in this description are named to match the encodings of [MOVA (tile to vector, single)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza).
- The description of [MOVA (tile to vector, single)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

It has encodings from 5 classes: [8-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-170-MOV--tile-to-vector--single-?lang=en#isa_mov_mova_z_p_rza_iclass_8_bit), [16-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-170-MOV--tile-to-vector--single-?lang=en#isa_mov_mova_z_p_rza_iclass_16_bit), [32-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-170-MOV--tile-to-vector--single-?lang=en#isa_mov_mova_z_p_rza_iclass_32_bit), [64-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-170-MOV--tile-to-vector--single-?lang=en#isa_mov_mova_z_p_rza_iclass_64_bit), and [128-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-170-MOV--tile-to-vector--single-?lang=en#isa_mov_mova_z_p_rza_iclass_128_bit)

```
MOV  <Zd>.B, <Pg>/M, ZA0<HV>.B[<Ws>, <offs>]
```

is equivalent to

```
MOVA  <Zd>.B, <Pg>/M, ZA0<HV>.B[<Ws>, <offs>]
```

and is always the preferred disassembly.

<Ws>
:   ​

    Is the 32-bit name of the slice index register W12-W15, encoded as “Rs” plus 12.

<offs>
:   ​

    For the “8-bit” variant: is the slice index offset, in the range 0 to 15, encoded in the “off4” field.

    ​

    For the “16-bit” variant: is the slice index offset, in the range 0 to 7, encoded in the “off3” field.

    ​

    For the “32-bit” variant: is the slice index offset, in the range 0 to 3, encoded in the “off2” field.

    ​

    For the “64-bit” variant: is the slice index offset, in the range 0 to 1, encoded in the “o1” field.

    ​

    For the “128-bit” variant: is the slice index offset, with implicit value 0.

<ZAn>
:   ​

    For the “16-bit” variant: is the name of the ZA tile ZA0-ZA1 to be accessed, encoded in the “ZAn” field.

    ​

    For the “32-bit” variant: is the name of the ZA tile ZA0-ZA3 to be accessed, encoded in the “ZAn” field.

    ​

    For the “64-bit” variant: is the name of the ZA tile ZA0-ZA7 to be accessed, encoded in the “ZAn” field.

    ​

    For the “128-bit” variant: is the name of the ZA tile ZA0-ZA15 to be accessed, encoded in the “ZAn” field.
