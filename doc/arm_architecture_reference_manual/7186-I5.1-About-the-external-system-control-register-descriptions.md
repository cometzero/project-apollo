# ​I5.1 About the external system control register descriptions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-1-About-the-external-system-control-register-descriptions>

#### I5.1 About the external system control register descriptions

This chapter describes the external system control registers other than the external debug registers. That is, it describes:

An external view of the Performance Monitors registers
:   Arm recommends that implementations provide access to the Performance Monitors registers through the OPTIONAL External debug interface, and provide the OPTIONAL memory-mapped interface to this interface:

    - [External Performance Monitors registers summary](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-2-External-Performance-Monitors-registers-summary?lang=en#cihgadbi) lists the registers that are accessible in this view of the Performance Monitors, and describes their memory map.
    - [Performance Monitors external register descriptions](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions?lang=en#external_pmu_registers) describes each of the memory-mapped registers.

    [Recommended External Interface to the Performance Monitors](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I3-Recommended-External-Interface-to-the-Performance-Monitors?lang=en#cegdjdjd) describes the recommended interface to these registers.

    > #### Note
    >
    > [The Performance Monitors Extension](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension?lang=en#babgefcf) describes the Performance Monitors. The following sections describe the System register interfaces to the Performance Monitors:
    >
    > - [Performance Monitors registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers?lang=en#aarch64_performance_monitors_registers), for accesses from an Exception level that is using AArch64.
    > - [Performance Monitors registers](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers?lang=en#aarch32_performance_monitors_registers), for accesses from an Exception level that is using AArch32.

An external view of the Activity Monitors Extension registers
:   An implementation which supports the Activity Monitors Extension may support an optional external memory-mapped interface to the Activity Monitors Extension registers.

    - [External Activity Monitors Extension registers summary](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-4-External-Activity-Monitors-Extension-registers-summary?lang=en#cjaedcgj) lists the registers that are accessible in this view of the Performance Monitors, and describes their memory map.
    - [Activity Monitors external register descriptions](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions?lang=en#external_amu_registers) describes each of the memory-mapped registers.

    [Recommended External Interface to the Activity Monitors](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I4-Recommended-External-Interface-to-the-Activity-Monitors?lang=en#recextiact) describes the recommended interface to these registers.

    > #### Note
    >
    > [The Activity Monitors Extension](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D16-The-Activity-Monitors-Extension?lang=en#babhbbif) describes the Activity Monitors. The following sections describe the System register interfaces to the Activity Monitors:
    >
    > - [Activity Monitors registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers?lang=en#aarch64_activity_monitors_registers), for accesses from an Exception level that is using AArch64.
    > - [Activity Monitors registers](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers?lang=en#aarch32_activity_monitors_registers), for accesses from an Exception level that is using AArch32.

The registers for the system level Generic Timer component
:   Any implementation that includes the Generic Timer must include the memory-mapped system level component described in [System Level Implementation of the Generic Timer](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer?lang=en#cegiiegb). In this chapter:

    - [Generic Timer memory-mapped registers overview](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-6-Generic-Timer-memory-mapped-registers-overview?lang=en#cihgjhhh) gives an overview of the registers, referring to [System Level Implementation of the Generic Timer](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer?lang=en#cegiiegb) for more information.
    - [Generic Timer memory-mapped register descriptions](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions?lang=en#ext_generic_timer_registers) describes each of the memory-mapped registers.

    > #### Note
    >
    > [The Generic Timer in AArch64 state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state?lang=en#cchggdgb) describes the Generic Timer component that is accessible using the System registers. The following sections describe the System register interfaces to that component:
    >
    > - [Generic Timer registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers?lang=en#aarch64_generic_timer_registers), for accesses from an Exception level that is using AArch64.
    > - [Generic Timer registers](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers?lang=en#aarch32_generic_timer_registers), for accesses from an Exception level that is using AArch32.
