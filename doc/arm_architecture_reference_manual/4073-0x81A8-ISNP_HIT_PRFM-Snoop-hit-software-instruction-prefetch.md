##### `0x81A8`, ISNP\_HIT\_PRFM, Snoop hit, software instruction prefetch

The counter counts each snoop generated by the PE in response to an instruction prefetch instruction counted by [ISNP\_HIT\_PRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8290--ISNP-HIT-PRF--Snoop-hit--instruction-prefetch?lang=en#event_isnp_hit_prf) that hits in a cache outside of the cache hierarchy of this PE.

The event is counted by the PE generating the snoop, not the PE being snooped.
