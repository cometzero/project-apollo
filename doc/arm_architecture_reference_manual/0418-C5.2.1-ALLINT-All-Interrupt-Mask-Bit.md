# ​C5.2.1 ALLINT, All Interrupt Mask Bit

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-1-ALLINT--All-Interrupt-Mask-Bit>

##### C5.2.1 ALLINT, All Interrupt Mask Bit

The ALLINT characteristics are:

Purpose
:   Allows access to the all interrupt mask bit.

Configuration
:   This register is a Special-purpose register.

    This register is present only when FEAT\_NMI is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to ALLINT are UNDEFINED.

Attributes
:   ALLINT is a 64-bit register.

###### Field descriptions

![](images/0418-C5.2.1-ALLINT-All-Interrupt-Mask-Bit-img01.svg)

Bits [63:14]
:   Reserved, RES0.

ALLINT, bit [13]
:   All interrupt mask. An interrupt is controlled by PSTATE.ALLINT when all of the following apply:

    - [SCTLR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#sctlr_elx).NMI is 1.
    - The interrupt is targeted at ELx.
    - Execution is at ELx.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bits [12:0]
:   Reserved, RES0.
