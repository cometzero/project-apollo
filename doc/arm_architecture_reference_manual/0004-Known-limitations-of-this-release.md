# Known limitations of this release

Source: <https://developer.arm.com/documentation/ddi0487/mc/Preface/About-this-Manual/Known-limitations-of-this-release>

##### Known limitations of this release

Validation of this release has identified the following issues that Arm will address in future issues:

- The A64 Instruction Set Encoding is not yet included in the HTML version. It is currently only available in the PDF version.
- The pseudocode in [Architectural Pseudocode](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode?lang=en#part_pseudocode) conforms to the definitions of ASL1, which is described in *Arm® Architecture Specification Language (ASL) Reference* (ARM DDI 0626). Other content in this Manual will be updated to align with ASL1 in future releases.
- Some diagrams in the register descriptions chapter have long field names that split over several lines.

For a monthly updated list of known issues in this release, see the [Arm® Architecture Reference Manual for A-profile architecture, Known Issues](https://developer.arm.com/documentation/102105/latest).

For release notes corresponding to the most recent Register and Instruction XML release, see <https://developer.arm.com/Architectures/A-Profile%20Architecture#Downloads>.
