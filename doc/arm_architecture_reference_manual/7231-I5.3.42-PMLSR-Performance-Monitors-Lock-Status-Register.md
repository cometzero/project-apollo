# ​I5.3.42 PMLSR, Performance Monitors Lock Status Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-42-PMLSR--Performance-Monitors-Lock-Status-Register>

##### I5.3.42 PMLSR, Performance Monitors Lock Status Register

The PMLSR characteristics are:

Purpose
:   Indicates the current status of the software lock for Performance Monitors registers.

    The optional Software Lock provides a lock to prevent memory-mapped writes to the Performance Monitors registers. Use of this lock mechanism reduces the risk of accidental damage to the contents of the Performance Monitors registers. It does not, and cannot, prevent all accidental or malicious damage.

Configuration
:   If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, Software Lock is not implemented by the architecturally-defined debug components of the PE in the Core power domain.

    If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, this register is in the Debug power domain.

    Software uses [PMLAR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-41-PMLAR--Performance-Monitors-Lock-Access-Register?lang=en#reg_pmu_pmlar) to set or clear the lock, and PMLSR to check the current status of the lock.

    This register is present only when FEAT\_PMUv3\_EXT is implemented and FEAT\_PMUv3 is implemented. Otherwise, direct accesses to PMLSR are RES0.

Attributes
:   PMLSR is a 32-bit register.

###### Field descriptions

![](images/7231-I5.3.42-PMLSR-Performance-Monitors-Lock-Status-Register-img01.svg)

Bits [31:3]
:   Reserved, RES0.

nTT, bit [2]
:   Not thirty-two bit access required.

    Reads as `0b0`

    Access to this field is RO.

:   When PMU Software Lock is implemented and FEAT\_DoPD is not implemented:
    :   Software Lock status for this component. For an access to LSR that is not a memory-mapped access, or when Software Lock is not implemented, this field is RES0.

###### Accessing PMLSR

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT is implemented
:   Accessible at offset `0xFB4` from PMU

    - When FEAT\_DoPD is implemented and !IsCorePowered(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RO.
