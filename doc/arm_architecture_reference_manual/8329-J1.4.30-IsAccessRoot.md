##### J1.4.30 IsAccessRoot

```
// IsAccessRoot()
// ==============
// Returns TRUE when an access is Root
func IsAccessRoot(addrdesc : AddressDescriptor) => boolean
begin
    return addrdesc.paddress.paspace == PAS_Root;
end;
```
