##### J1.4.29 IsAccessRealm

```
// IsAccessRealm()
// ===============
// Returns TRUE when an access is Realm
func IsAccessRealm(addrdesc : AddressDescriptor) => boolean
begin
    return addrdesc.paddress.paspace == PAS_Realm;
end;
```
