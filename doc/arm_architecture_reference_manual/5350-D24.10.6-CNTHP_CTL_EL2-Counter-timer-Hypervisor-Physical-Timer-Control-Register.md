# ​D24.10.6 CNTHP_CTL_EL2, Counter-timer Hypervisor Physical Timer Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register>

##### D24.10.6 CNTHP\_CTL\_EL2, Counter-timer Hypervisor Physical Timer Control Register

The CNTHP\_CTL\_EL2 characteristics are:

Purpose
:   Control register for the EL2 physical timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch64 System register CNTHP\_CTL\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [CNTHP\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-3-CNTHP-CTL--Counter-timer-Hyp-Physical-Timer-Control-register?lang=en#reg_aarch32_cnthp_ctl)[31:0].

    This register is present only when (HaveEL(EL3) || (((!HaveEL(EL3)) && HaveEL(EL2)) && (!IsFeatureImplemented(FEAT\_SEL2)))) && IsFeatureImplemented(FEAT\_AA64). Otherwise, direct accesses to CNTHP\_CTL\_EL2 are UNDEFINED.

Attributes
:   CNTHP\_CTL\_EL2 is a 64-bit register.

    When the value of the ENABLE bit is 1, ISTATUS indicates whether the timer condition is met. ISTATUS takes no account of the value of the IMASK bit. If the value of ISTATUS is 1 and the value of IMASK is 0 then the timer interrupt is asserted.

    When the value of the ENABLE bit is 0, the ISTATUS field is UNKNOWN.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    Access to this field is RO.

    > #### Note
    >
    > Disabling the output signal might be a power-saving option.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing CNTHP\_CTL\_EL2

When the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, without explicit synchronization, accesses from EL2 using the accessor name `CNTHP_CTL_EL2` or `CNTP_CTL_EL0` are not guaranteed to be ordered with respect to accesses using the other accessor name.
