# ​G8.2.1 ACTLR, Auxiliary Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-1-ACTLR--Auxiliary-Control-Register>

##### G8.2.1 ACTLR, Auxiliary Control Register

The ACTLR characteristics are:

Purpose
:   Provides IMPLEMENTATION DEFINED configuration and control options for execution at EL1 and EL0.

Configuration
:   Some bits might define global configuration settings, and be common to the Secure and Non-secure instances of the register.

    AArch32 System register ACTLR bits [31:0] are architecturally mapped to AArch64 System register [ACTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-2-ACTLR-EL1--Auxiliary-Control-Register--EL1-?lang=en#reg_aarch64_actlr_el1)[31:0].

    This register is banked between ACTLR and ACTLR\_S and ACTLR\_NS.

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ACTLR are UNDEFINED.

Attributes
:   ACTLR is a 32-bit register.

    This register has the following instances:

    - ACTLR, when EL3 is not implemented or FEAT\_AA64 is implemented.
    - ACTLR\_S, when FEAT\_AA32EL3 is implemented.
    - ACTLR\_NS, when FEAT\_AA32EL3 is implemented.

###### Field descriptions

![](images/6492-G8.2.1-ACTLR-Auxiliary-Control-Register-img01.svg)

IMPLEMENTATION DEFINED, bits [31:0]
:   IMPLEMENTATION DEFINED.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    if SCR().NS == '0' then
        R(t) = ACTLR_S();
