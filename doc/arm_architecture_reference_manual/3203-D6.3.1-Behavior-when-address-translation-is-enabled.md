# ​D6.3.1 Behavior when address translation is enabled

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-1-Behavior-when-address-translation-is-enabled>

##### D6.3.1 Behavior when address translation is enabled

R XRNCQ
:   If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).nVM is 0, then the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9), [*Limit pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3), and [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) are virtual addresses in the stage 1 translation regime of the owning translation regime.

R CMDTG
:   If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).nVM is 0, other than as described in this section, then the stage 1 translation process for translating virtual addresses and checking for [MMU faults](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-15-Memory-aborts?lang=en#aa64_mmu_fault) is identical to that for any other virtual address in the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr).

R NPFBJ
:   The effect of [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).PAN is not applied to the stage 1 Base permissions.

R BTSXD
:   The effects of [FEAT\_S1POE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_s1poe) stage 1 Overlay permissions and [POR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#por_elx) are not applied to the memory access.

I GKBYK
:   If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).nVM is 0, then [RCMDTG](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-1-Behavior-when-address-translation-is-enabled?lang=en#cmdtg) means all of the following apply:

    - The virtual addresses are translated to stage 1 output addresses by stage 1 translation, and checked for stage 1 [MMU faults](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-15-Memory-aborts?lang=en#aa64_mmu_fault). The stage 1 output addresses are:

      - Physical address in the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_ss) if the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr) has no stage 2 translation.
      - Intermediate physical addresses (IPAs) in the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_ss) if the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr) has stage 2 translations.
    - If stage 1 translation is enabled for the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr), the memory type and, as applicable, Cacheability, Shareability, and Device type attributes, for stage 1 output addresses are defined by the translation table entries for the virtual address being written to.
    - If stage 1 translation is disabled for the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr), the memory type of the stage 1 output addresses is Device-nGnRnE, unless overridden by stage 2 controls.
    - If [SCTLR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#sctlr_elx).C is 0 for the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr) and stage 1 translation is enabled, then all accesses to Normal memory are Non-cacheable.
    - [TRBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-6-TRBPTR-EL1--Trace-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_trbptr_el1)[63:56] are ignored by address translation if the respective TBI bit is 1.

R SJFRQ
:   When the Trace Buffer Unit is enabled and collection is not stopped, the Trace Buffer Unit might cause speculative translations for the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr), including when the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr) is out-of-context.

I QXJZX
:   [RSJFRQ](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-1-Behavior-when-address-translation-is-enabled?lang=en#sjfrq) means that, when the Trace Buffer Unit is enabled and the [owning Exception level](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_el) is a lower Exception level, then the Trace Buffer Unit might make memory accesses to translation table entries from the translation regime of the [owning Exception level](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_el), using the settings of the System registers associated with that translation regime.

    If the PE is not executing in the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_ss), or the PE is executing at EL3 and [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).{NSE, NS} does not indicate the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_ss), then the translation regime of the [owning Exception level](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_el) might not be the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_tr).

    These memory accesses might be observed by other observers, to the extent that those accesses are required to be observed as determined by the Shareability and Cacheability of those translation table entries.

    This is an exception to the rules in the section [Speculative memory accesses from out-of-context translation regimes](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-1-Address-translation/-D8-1-5-Out-of-context-translation-regimes?lang=en#mdsec_speculative_memory_accesses_from_out_of_context_translation_regimes).

    See also [Context switching](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K10-Software-Usage-Examples/-K10-5-Use-of-the-Embedded-Trace-and-Trace-Buffer-Extensions/-K10-5-9-Context-switching?lang=en#mdsec_sw_usage_ctx_sw).
