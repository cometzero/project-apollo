##### F5.1.18 B

Branch causes a branch to a target address.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-18-B?lang=en#isa_b_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-18-B?lang=en#isa_b_iclass_t1), [T2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-18-B?lang=en#isa_b_iclass_t2), [T3](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-18-B?lang=en#isa_b_iclass_t3), and [T4](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-18-B?lang=en#isa_b_iclass_t4)).

###### A1

![](images/5635-F5.1.18-B-img01.svg)

###### Encoding

```
B{<c>}{<q>}  <label>
```

###### Decode for this encoding

```
let imm32 : bits(32) = SignExtend{}(imm24::‘00’);
```

###### T1

![](images/5635-F5.1.18-B-img02.svg)

###### Encoding

```
B<c>{<q>}  <label> // (Not permitted in IT block)
```

###### Decode for this encoding

```
if cond == ‘1110’ then See(“UDF”); end;
if cond == ‘1111’ then See(“SVC”); end;
let imm32 : bits(32) = SignExtend{}(imm8::‘0’);
if InITBlock() then UnpredictableProcedure(); end;
```

###### T2

![](images/5635-F5.1.18-B-img03.svg)

###### Encoding

```
B{<c>}{<q>}  <label> // (Outside or last in IT block)
```

###### Decode for this encoding

```
let imm32 : bits(32) = SignExtend{}(imm11::‘0’);
if InITBlock() && !LastInITBlock() then UnpredictableProcedure(); end;
```

###### T3

![](images/5635-F5.1.18-B-img04.svg)

###### Encoding

```
B<c>.W  <label> // (Not permitted in IT block, and <label> can be represented in T1)
```

```
B<c>{<q>}  <label> // (Not permitted in IT block)
```

###### Decode for this encoding

```
if cond[3:1] == ‘111’ then See(“Related encodings”); end;
let imm32 : bits(32) = SignExtend{}(S::J2::J1::imm6::imm11::‘0’);
if InITBlock() then UnpredictableProcedure(); end;
```

###### T4

![](images/5635-F5.1.18-B-img05.svg)

###### Encoding

```
B{<c>}{<q>}  <label>
```

```
B{<c>}.W  <label> // (<label> can be represented in T2)
```

###### Decode for this encoding

```
let I1 : bit = NOT(J1 XOR S);
let I2 : bit = NOT(J2 XOR S);
let imm32 : bits(32) = SignExtend{}(S::I1::I2::imm10::imm11::‘0’);
if InITBlock() && !LastInITBlock() then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

Related encodings: [Branches and miscellaneous control](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F3-T32-Instruction-Set-Encoding/-F3-1-T32-instruction-set-encoding/-F3-1-16-Branches-and-miscellaneous-control?lang=en#t32_encoding_index_bcrtrl).

###### Assembler Symbols

<c>
:   ​
    ​

    For the “A1”, “T2”, and “T4” variants: see [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

    ​

    For the “T1” and “T3” variants: see [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf). Must not be `AL` or omitted.

<q>
:   ​
    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<label>
:   ​

    For the “A1” variant: the label of the instruction that is to be branched to. The assembler calculates the required value of the offset from the PC value of the `B` instruction to this label, then selects an encoding that sets `imm32` to that offset.

    Permitted offsets are multiples of 4 in the range –33554432 to 33554428.

    ​

    For the “T1” variant: the label of the instruction that is to be branched to. The assembler calculates the required value of the offset from the PC value of the `B` instruction to this label, then selects an encoding that sets `imm32` to that offset. Permitted offsets are even numbers in the range –256 to 254.

    ​

    For the “T2” variant: the label of the instruction that is to be branched to. The assembler calculates the required value of the offset from the PC value of the `B` instruction to this label, then selects an encoding that sets `imm32` to that offset. Permitted offsets are even numbers in the range –2048 to 2046.

    ​

    For the “T3” variant: the label of the instruction that is to be branched to. The assembler calculates the required value of the offset from the PC value of the `B` instruction to this label, then selects an encoding that sets `imm32` to that offset.

    Permitted offsets are even numbers in the range –1048576 to 1048574.

    ​

    For the “T4” variant: the label of the instruction that is to be branched to. The assembler calculates the required value of the offset from the PC value of the `B` instruction to this label, then selects an encoding that sets `imm32` to that offset.

    Permitted offsets are even numbers in the range –16777216 to 16777214.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    BranchWritePC(PC32() + imm32, BranchType_DIR);
end;
```
