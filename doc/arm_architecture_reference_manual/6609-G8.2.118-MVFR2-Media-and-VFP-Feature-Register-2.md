# ​G8.2.118 MVFR2, Media and VFP Feature Register 2

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-118-MVFR2--Media-and-VFP-Feature-Register-2>

##### G8.2.118 MVFR2, Media and VFP Feature Register 2

The MVFR2 characteristics are:

Purpose
:   Describes the features provided by the AArch32 Advanced SIMD and floating-point implementation.

    Must be interpreted with [MVFR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-116-MVFR0--Media-and-VFP-Feature-Register-0?lang=en#reg_aarch32_mvfr0) and [MVFR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-117-MVFR1--Media-and-VFP-Feature-Register-1?lang=en#reg_aarch32_mvfr1).

    For general information about the interpretation of the ID registers see [‘Principles of the ID scheme for fields in ID registers’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-1-About-the-AArch32-System-registers/-G8-1-3-Principles-of-the-ID-scheme-for-fields-in-ID-registers?lang=en#chdidagf).

Configuration
:   Implemented only if the implementation includes Advanced SIMD and floating-point instructions.

    AArch32 System register MVFR2 bits [31:0] are architecturally mapped to AArch64 System register [MVFR2\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-140-MVFR2-EL1--AArch32-Media-and-VFP-Feature-Register-2?lang=en#reg_aarch64_mvfr2_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to MVFR2 are UNDEFINED.

Attributes
:   MVFR2 is a 32-bit register.

Bits [31:8]
:   Reserved, RES0.

:   Indicates whether the floating-point implementation provides support for miscellaneous VFP features.
