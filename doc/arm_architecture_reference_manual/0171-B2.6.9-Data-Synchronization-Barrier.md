##### B2.6.9 Data Synchronization Barrier

A [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) instruction is a memory barrier that ensures that memory accesses that occur before the [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) instruction have completed before the completion of the [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) instruction. In doing this, it acts as a stronger barrier than a [`DMB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-150-DMB?lang=en#isa_dmb) and all ordering that is created by a [`DMB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-150-DMB?lang=en#isa_dmb) with specific options is also generated by a [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) with the same options.

Execution of a [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) instruction:

- At EL2 ensures that any memory accesses caused by [Speculative](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#chdjdihi) translation table walks from the EL1&0 translation regime have been observed.
- At EL3 ensures that any memory accesses caused by speculative translation table walks from the EL2, EL1&0 or EL2&0 translation regimes have been observed.

For more information, see [Out-of-context translation regimes](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-1-Address-translation/-D8-1-5-Out-of-context-translation-regimes?lang=en#mdsec_out_of_context_translation_regimes).

###### B2.6.9.1 Maintenance scope of the data synchronization barrier operations

A [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) instruction that applies to both reads and writes takes an argument that specifies its maintenance scope. The maintenance scope indicates the subset of TLB invalidate (TLBI) instructions, TLB invalidate pair (TLBIP) instructions, and Instruction cache maintenance (IC) instructions that are covered by this [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb), for one of:

- Outer Shareable domain.
- Inner Shareable domain.
- Non-shareable domain.

When a [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) instruction that applies to both reads and writes is used to ensure completion of TLB maintenance instructions or Instruction cache (IC) instructions, all of the following apply:

- A [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) `NSH` is sufficient to ensure completion of TLB maintenance instructions or IC instructions that apply to a single PE.
- A [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) `ISH` is sufficient to ensure completion of TLB maintenance instructions or IC instructions that apply to PEs in the same Inner Shareable domain.
- A [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) `OSH` is sufficient to ensure completion of TLB maintenance instructions that apply to PEs in the same Outer Shareable domain.
