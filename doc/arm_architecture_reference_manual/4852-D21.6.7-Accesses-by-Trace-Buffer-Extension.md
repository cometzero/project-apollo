##### D21.6.7 Accesses by Trace Buffer Extension

I MNMXW
:   A PE with [FEAT\_TRBE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-1-The-Armv9-0-architecture-extension?lang=en#feat_feat_trbe) can be configured to record trace data into a trace buffer in memory. The MPAM information used for these accesses depends on the operating mode of the Trace Buffer Unit. For more information, see:

    - [Accesses by Trace Buffer Extension](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-6-Effect-of-access-type-on-MPAM-information/-D21-6-7-Accesses-by-Trace-Buffer-Extension?lang=en#mpam_accesses_by_trace_buffer_extension).
    - [External mode and MPAM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode/-D6-4-5-External-mode-and-MPAM?lang=en#trbe_mpam).
