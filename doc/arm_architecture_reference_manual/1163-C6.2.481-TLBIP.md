# ​C6.2.481 TLBIP

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-481-TLBIP>

##### C6.2.481 TLBIP

TLB invalidate pair operation.

This is an alias of [SYSP](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-477-SYSP?lang=en#isa_sysp). This means:

- The encodings in this description are named to match the encodings of [SYSP](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-477-SYSP?lang=en#isa_sysp).
- The description of [SYSP](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-477-SYSP?lang=en#isa_sysp) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### System

###### (FEAT\_SYSINSTR128)

![](images/1163-C6.2.481-TLBIP-img01.svg)

###### Encoding

```
TLBIP  <tlbip_op>{, <Xt1>, <Xt2>}
```

is equivalent to

```
SYSP  #<op1>, <Cn>, <Cm>, #<op2>{, <Xt1>, <Xt2>}
```

and is the preferred disassembly when `SysOp128(op1, CRn, CRm, op2) == Sys_TLBIP`.
