##### G5.12.4 Summary of register updates on faults taken to PL1 modes

For faults that generate exceptions that are taken to a PL1 mode, [Table G5-29](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-12-Exception-reporting-in-a-VMSAv8-32-implementation/-G5-12-4-Summary-of-register-updates-on-faults-taken-to-PL1-modes?lang=en#tbl_beijegbj) shows the registers affected by each fault. In this table:

- Yes indicates that the register is updated.
- UNK indicates that the fault makes the register value UNKNOWN.
- A null entry, -, indicates that the fault does not affect the register.

For faults that update the [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr) using the Short-descriptor format FSR encodings, [Table G5-30](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-12-Exception-reporting-in-a-VMSAv8-32-implementation/-G5-12-4-Summary-of-register-updates-on-faults-taken-to-PL1-modes?lang=en#tbl_beigfefj) shows whether [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr).Domain is valid.

See [Fault address reporting on synchronous External aborts](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-12-Exception-reporting-in-a-VMSAv8-32-implementation/-G5-12-1-About-exception-reporting?lang=en#caceibbf).

b. When using the Long-descriptor translation table format, there is not a specific fault code for a fault on an instruction cache maintenance instruction. For more information, see [Data Abort on an instruction cache or branch predictor maintenance instruction by VA](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-12-Exception-reporting-in-a-VMSAv8-32-implementation/-G5-12-2-Reporting-exceptions-taken-to-PL1-modes?lang=en#beifdgga).

c. The two lines of this entry show the alternative ways of reporting the fault when using the Short-descriptor translation table format. It is IMPLEMENTATION DEFINED which methods is used, see [Data Abort on an instruction cache or branch predictor maintenance instruction by VA](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-12-Exception-reporting-in-a-VMSAv8-32-implementation/-G5-12-2-Reporting-exceptions-taken-to-PL1-modes?lang=en#beifdgga).

d. Generates a Prefetch Abort exception.

e. Generates a Data Abort exception.
