Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-481-MUL--indexed->

##### C8.2.481 MUL (indexed)

Multiply by indexed element

This instruction multiplies all integer elements within each 128-bit segment of the first source vector by the specified element in the corresponding second source vector segment. The results are placed in the corresponding elements of the destination vector.

The elements within the second source vector are specified using an immediate index that selects the same element position within each 128-bit vector segment. The index range is from 0 to one less than the number of elements per 128-bit segment. This instruction is unpredicated.

It has encodings from 3 classes: [16-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-481-MUL--indexed-?lang=en#isa_mul_z_zzi_iclass_16_bit), [32-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-481-MUL--indexed-?lang=en#isa_mul_z_zzi_iclass_32_bit), and [64-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-481-MUL--indexed-?lang=en#isa_mul_z_zzi_iclass_64_bit)

###### Assembler Symbols

<Zd>
:   ​

    Is the name of the destination scalable vector register, encoded in the “Zd” field.

<Zn>
:   ​

    Is the name of the first source scalable vector register, encoded in the “Zn” field.

<Zm>
:   ​

    For the “16-bit” and “32-bit” variants: is the name of the second source scalable vector register Z0-Z7, encoded in the “Zm” field.

    ​

    For the “64-bit” variant: is the name of the second source scalable vector register Z0-Z15, encoded in the “Zm” field.

<imm>
:   ​

    For the “16-bit” variant: is the element index, in the range 0 to 7, encoded in the “i3h:i3l” fields.

    ​

    For the “32-bit” variant: is the element index, in the range 0 to 3, encoded in the “i2” field.

    ​

    For the “64-bit” variant: is the element index, in the range 0 to 1, encoded in the “i1” field.

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let elements : integer = VL DIV esize;
let eltspersegment : integer = 128 DIV esize;
let operand1 : bits(VL) = Z{}(n);
let operand2 : bits(VL) = Z{}(m);
var result : bits(VL);
for e = 0 to elements-1 do
    let segmentbase : integer = e - (e MOD eltspersegment);
    let s : integer = segmentbase + index;
    let element1 : integer = UInt(operand1[e*:esize]);
    let element2 : integer = UInt(operand2[s*:esize]);
    let res : integer = element1 * element2;
    result[e*:esize] = res[esize-1:0];
end;
Z{VL}(d) = result;
```
