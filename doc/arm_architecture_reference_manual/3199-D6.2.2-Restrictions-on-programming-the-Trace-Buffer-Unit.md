##### D6.2.2 Restrictions on programming the Trace Buffer Unit

R MSPSD
:   A [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) value is out-of-range if any of the following are true:

    - The [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is less-than the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9), treating both pointers as unsigned integers.
    - The [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is greater-than-or-equal-to the [*Limit pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3), treating both pointers as unsigned integers.
    - Bits [63:56] of the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) are not equal to bits [63:56] of the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9).
    - Bits [63:56] of the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) are not equal to bits [63:56] of the [*Limit pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3).

    Note: [RMSPSD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer/-D6-2-2-Restrictions-on-programming-the-Trace-Buffer-Unit?lang=en#mspsd) means the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is out-of-range if the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) is not less-than the [*Limit pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3) or bits [63:56] of the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) are not equal to bits [63:56] of the [*Limit pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3).

R XXZHM
:   A [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) or *Trigger Counter* value is misaligned if it is not a multiple of an IMPLEMENTATION DEFINED alignment specified by [TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-2-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_aarch64_trbidr_el1).Align.

R HXZZM
:   A [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) or *Trigger Counter* value is a valid restart value if it was previously initialized with a value that was not out-of-range and not misaligned and later read from the applicable register when all of the following are true:

    - The Trace Buffer Unit is disabled.
    - All trace operations are complete. See [RNSFRQ](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-6-Synchronization-and-the-Trace-Buffer-Unit/-D6-6-1-Trace-Synchronization-event?lang=en#nsfrq) for the definition of complete.
    - No External abort has been reported to the Trace Buffer Unit. See [The External abort is reported to the Trace Buffer Unit](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management/-D6-5-5-External-aborts?lang=en#external_abort_reported_tbu).
    - No write by the Trace Buffer Unit has generated an Alignment fault.
    - No write by the Trace Buffer Unit has generated an asynchronous SError exception.

R XZWXQ
:   A [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) or *Trigger Counter* value is a fault value if it was previously initialized with a value that was not out-of-range and not misaligned or a value that was a valid restart value, and later read from the applicable register when all of the following are true:

    - The Trace Buffer Unit is disabled.
    - All trace operations are complete. See [RNSFRQ](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-6-Synchronization-and-the-Trace-Buffer-Unit/-D6-6-1-Trace-Synchronization-event?lang=en#nsfrq) for the definition of complete.
    - One of the following is true:

      - An External abort has been reported to the Trace Buffer Unit. See [The External abort is reported to the Trace Buffer Unit](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management/-D6-5-5-External-aborts?lang=en#external_abort_reported_tbu).
      - A write by the Trace Buffer Unit has generated an Alignment fault.
      - A write by the Trace Buffer Unit has generated an asynchronous SError exception.

I CRSGP
:   An [MMU fault](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-15-Memory-aborts?lang=en#aa64_mmu_fault) does not generate a fault value. If software is able to fix the fault, then the Trace Buffer Unit can restart using the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) and *Trigger Counter* values.

    However, following an MMU fault:

    - [RYMVZL](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#ymvzl) means the Trace Buffer Unit *discards* trace because [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1). That is, trace will be lost.
    - [RBQTGW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management/-D6-5-3-Trigger-event?lang=en#bqtgw) means that the *Trigger Counter* might be incorrect if a *Detected Trigger* has occurred.

    See also [SGTLCY](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management/-D6-5-4-Faults?lang=en#gtlcy).

I SFTPM
:   Following a trace buffer management event, or on a context switch, the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) and *Trigger Counter* might be misaligned. If [TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-2-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_aarch64_trbidr_el1).Align is nonzero, software should treat bits [*M*:0] as SBZP when writing to the applicable register, where *M* is ([TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-2-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_aarch64_trbidr_el1).Align-1) in each of the following situations:

    - When first creating a trace buffer, software sets bits [*M*:0] to zero, meaning the registers are set to an aligned value.
    - On a context switch, the definitions of a restart value and fault value mean software does not have to validate or modify the value read from hardware.

    A [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) restart value or fault value will not be out-of-range.

I VRFQC
:   A fault value is for error handling purposes only. Software must not cause the Trace Buffer Unit to become enabled and *running* with the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) having a fault value.

    Software context switching the Trace Buffer Unit will avoid this issue because the trace buffer management event sets [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).S to 1, meaning the Trace Buffer Unit will not become *running* following the context switch.

R JWWWM
:   If the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is written by a direct write with a misaligned value that is not a restart value and not a fault value, the value returned by a subsequent direct read of the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is UNKNOWN.

R MGZWR
:   If the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) has an out-of-range value, or a misaligned value that is not a restart value when the Trace Buffer Unit attempts to write to the trace buffer, then any of the following might occur:

    - If the value is out-of-range, the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) might be wrapped before or after the write, and the [TRB\_WRAP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x400C--TRB-WRAP--Trace-buffer-current-write-pointer-wrapped?lang=en#event_trb_wrap) event might be generated.
    - If the value is misaligned, the write might generate an Alignment fault.
    - The Trace Buffer Unit might write the trace data to any address in memory that is writable by a privileged access in the owning translation regime. These addresses are:

      - For Self-hosted mode:

        - Virtual addresses in the owning translation regime if the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).nVM is 0.
        - Intermediate physical addresses in the owning Security state if the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).nVM is 1 and the owning translation regime has stage 2 translations.
        - Physical addresses in the owning Security state if the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).nVM is 1, and either the owning translation regime has no stage 2 translation or stage 2 translation is disabled.
      - For External mode, any addresses in the physical address space specified by [TRBMAR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-4-TRBMAR-EL1--Trace-Buffer-Memory-Attribute-Register?lang=en#reg_aarch64_trbmar_el1).PAS.
    - The write might generate a trace buffer management event and the [TRB\_WRAP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x400C--TRB-WRAP--Trace-buffer-current-write-pointer-wrapped?lang=en#event_trb_wrap) event might be generated:

      - If [FEAT\_TRBE\_EXC](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_trbe_exc) is not implemented, a buffer management event for an UNKNOWN reason:

        - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-7-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register--EL1-?lang=en#reg_aarch64_trbsr_el1).S is either set to 1 or unchanged.
        - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-7-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register--EL1-?lang=en#reg_aarch64_trbsr_el1).WRAP is either set to 1 or unchanged.
        - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-7-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register--EL1-?lang=en#reg_aarch64_trbsr_el1).EC is set to an UNKNOWN value.
        - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-7-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register--EL1-?lang=en#reg_aarch64_trbsr_el1).MSS is set to an UNKNOWN value.
      - If [FEAT\_TRBE\_EXC](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_trbe_exc) is implemented, a buffer management event for one of the following reasons:

        - A Buffer full buffer management event.
        - A Buffer wrap buffer management event.
        - An Access not allowed buffer management event.
        - Any MMU fault buffer management event.

        The management event is recorded as described by [RBNQRP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#bnqrp).
    - All trace data is silently discarded without being written to memory.
    - The Trace Buffer Unit behaves as if the trace buffer is disabled.

R CPDDM
:   If the *Trigger Counter* is written by a direct write with a misaligned value that is not a restart value, then all of the following apply:

    - If the value is not a fault value, the value returned by a subsequent direct read of the *Trigger Counter* register is UNKNOWN.
    - The generation of a *Trigger Event* while the Trace Buffer Unit remains enabled and *running* is UNPREDICTABLE.

I YSXXN
:   [RXXZHM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer/-D6-2-2-Restrictions-on-programming-the-Trace-Buffer-Unit?lang=en#xxzhm) and [RCPDDM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer/-D6-2-2-Restrictions-on-programming-the-Trace-Buffer-Unit?lang=en#cpddm) mean an implementation that always keeps the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) and/or *Trigger Counter* aligned to the IMPLEMENTATION DEFINED alignment specified by [TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-2-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_aarch64_trbidr_el1).Align, where [TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-2-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_aarch64_trbidr_el1).Align is greater-than-zero (byte alignment), can implement bits [*M*:0] of the applicable register(s) as RAZ/WI bits, where *M* is ([TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-2-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_aarch64_trbidr_el1).Align-1).

    [RHXZZM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer/-D6-2-2-Restrictions-on-programming-the-Trace-Buffer-Unit?lang=en#hxzzm) allows an implementation where an External abort is reported to the Trace Buffer Unit and handled synchronously to implement [TRBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-6-TRBPTR-EL1--Trace-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_trbptr_el1)[*M*:*N*], where *N* is IMPLEMENTATION SPECIFIC and typically determined by the minimum memory access granule, as read/write bits for the purpose of reporting an External abort fault address, but otherwise ignore the value in these bits. If *N>0*, bits [(*N-1)*:0] can be implemented as RAZ/WI.

R DJMDD
:   When the following conditions apply, the PE might ignore a direct or external write to any of certain Trace Buffer Unit registers, other than a direct write or external write to [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1) that clears the conditions:

    - [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).E is 1, and either [FEAT\_TRBE\_EXT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_trbe_ext) is not implemented or the Trace Buffer Unit is using Self-hosted mode.
