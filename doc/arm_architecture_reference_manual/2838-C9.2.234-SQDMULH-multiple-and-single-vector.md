# ​C9.2.234 SQDMULH (multiple and single vector)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-234-SQDMULH--multiple-and-single-vector->

##### C9.2.234 SQDMULH (multiple and single vector)

Multi-vector signed saturating doubling multiply high by vector

This instruction multiplies the signed elements of the two or four first source vectors by the corresponding elements of the second source vector, and then doubles the result and destructively places the most significant half of the result in the corresponding elements of the two or four first source vectors. Each result element is saturated to the N-bit element’s signed integer range -2(N-1) to (2(N-1))-1.

This instruction is unpredicated.

It has encodings from 2 classes: [Two registers](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-234-SQDMULH--multiple-and-single-vector-?lang=en#isa_sqdmulh_mz_zzv_iclass_two_registers) and [Four registers](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-234-SQDMULH--multiple-and-single-vector-?lang=en#isa_sqdmulh_mz_zzv_iclass_four_registers)

<Zdn2>
:   ​

    Is the name of the second scalable vector register of the destination and first source multi-vector group, encoded as “Zdn” times 2 plus 1.

<Zm>
:   ​

    Is the name of the second source scalable vector register Z0-Z15, encoded in the “Zm” field.

<Zdn4>
:   ​

    Is the name of the fourth scalable vector register of the destination and first source multi-vector group, encoded as “Zdn” times 4 plus 3.

###### Operation

```
CheckStreamingSVEEnabled();
let VL : integer{} = CurrentVL();
let elements : integer = VL DIV esize;
var results : array [[4]] of bits(VL);
for r = 0 to nreg-1 do
    let operand1 : bits(VL) = Z{}(dn+r);
    let operand2 : bits(VL) = Z{}(m);
    for e = 0 to elements-1 do
        let element1 : integer = SInt(operand1[e*:esize]);
        let element2 : integer = SInt(operand2[e*:esize]);
        let res : integer = 2 * element1 * element2;
        results[[r]][e*:esize] = SignedSat{esize}(res >> esize);
    end;
end;
for r = 0 to nreg-1 do
    Z{VL}(dn+r) = results[[r]];
end;
```
