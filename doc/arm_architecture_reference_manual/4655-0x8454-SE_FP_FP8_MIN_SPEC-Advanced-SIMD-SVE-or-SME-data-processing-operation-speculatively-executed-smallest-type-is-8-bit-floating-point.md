##### `0x8454`, SE\_FP\_FP8\_MIN\_SPEC, Advanced SIMD, SVE, or SME data processing operation speculatively executed, smallest type is 8-bit floating-point

The counter counts each Advanced SIMD, SVE, or SME data processing operation counted by [FP\_FP8\_MIN\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8474--FP-FP8-MIN-SPEC--Floating-point-operation-speculatively-executed--smallest-type-is-8-bit-floating-point?lang=en#event_fp_fp8_min_spec) due to an instruction where the smallest type was 8-bit floating-point.
