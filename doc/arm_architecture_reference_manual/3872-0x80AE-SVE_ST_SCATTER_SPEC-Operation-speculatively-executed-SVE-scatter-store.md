##### `0x80AE`, SVE\_ST\_SCATTER\_SPEC, Operation speculatively executed, SVE scatter-store

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) operation that writes to memory counted by [SVE\_LDST\_NONCONTIG\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x80AC--SVE-LDST-NONCONTIG-SPEC--Operation-speculatively-executed--SVE-non-contiguous-load--store--or-prefetch?lang=en#event_sve_ldst_noncontig_spec) due to an SVE non-contiguous scatter-store instruction.
