# ​D24.6.2 AMCG1IDR_EL0, Activity Monitors Counter Group 1 Identification Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-2-AMCG1IDR-EL0--Activity-Monitors-Counter-Group-1-Identification-Register>

##### D24.6.2 AMCG1IDR\_EL0, Activity Monitors Counter Group 1 Identification Register

The AMCG1IDR\_EL0 characteristics are:

Purpose
:   Defines which auxiliary counters are implemented, and which of them have a corresponding virtual offset register, [AMEVCNTVOFF1<n>\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-12-AMEVCNTVOFF1-n--EL2--Activity-Monitors-Event-Counter-Virtual-Offset-Registers-1--n---0---15?lang=en#reg_aarch64_amevcntvoff1n_el2) implemented.

Configuration
:   This register is present only when FEAT\_AMUv1p1 is implemented. Otherwise, direct accesses to AMCG1IDR\_EL0 are UNDEFINED.

Attributes
:   AMCG1IDR\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5280-D24.6.2-AMCG1IDR_EL0-Activity-Monitors-Counter-Group-1-Identification-Register-img01.svg)

Bits [63:32]
:   Reserved, RES0.

AMEVCNTOFF1<n>\_EL2 , bits [n+16], for n = 15 to 0
:   Indicates which implemented auxiliary counters have a corresponding virtual offset register, [AMEVCNTVOFF1<n>\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-12-AMEVCNTVOFF1-n--EL2--Activity-Monitors-Event-Counter-Virtual-Offset-Registers-1--n---0---15?lang=en#reg_aarch64_amevcntvoff1n_el2) implemented.
