##### `0x81CE`, L3D\_CACHE\_HIT\_RW, Level 3 data cache demand access hit

The counter counts each demand access counted by [L3D\_CACHE\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8150--L3D-CACHE-RW--Level-3-data-cache-demand-access?lang=en#event_l3d_cache_rw) that hits in the Level 3 data or unified cache.
