# ​G1.15.5 The Illegal Execution state exception

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-5-The-Illegal-Execution-state-exception>

##### G1.15.5 The Illegal Execution state exception

When the value of the [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL bit is 1, any attempt to execute an instruction generates an Illegal Execution state exception. In AArch32 state, the [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL bit can be set to 1 by one of the following:

- An illegal return, as described in [Illegal return events from AArch32 state](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-3-Illegal-return-events-from-AArch32-state?lang=en#chdddjdb).
- An illegal change to [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).M, as described in [Illegal changes to PSTATE.M](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-3-Illegal-changes-to-PSTATE-M?lang=en#chddfige).
- A legal return that sets [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL to 1, as described in [Legal returns that set PSTATE.IL to 1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-4-Legal-returns-that-set-PSTATE-IL-to-1?lang=en#chddaedf).

An Illegal Execution state exception is taken in the same way as an Undefined Instruction exception in the current Exception level. If the current Exception level is EL2 using AArch32 state, the [HSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-74-HSR--Hyp-Syndrome-Register?lang=en#reg_aarch32_hsr) provides additional syndrome information for the exception, see [Use of the HSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-12-Exception-reporting-in-a-VMSAv8-32-implementation/-G5-12-5-Reporting-exceptions-taken-to-Hyp-mode?lang=en#beidbeag).

An Illegal Execution state exception has priority over any other Undefined Instruction exception that might arise from instruction execution.

> #### Note
>
> This section only describes the handling of an Illegal Execution state exception that is taken to an Exception level that is using AArch32 state.

On taking any exception to an Exception level that is using AArch32 state:

1. The value of the [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL bit is 1 and this is copied to the [SPSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#cegceeii).IL bit for the PE mode to which the exception is taken.
2. The [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL bit is cleared to 0.

> #### Note
>
> This means that it is not possible for software to observe the value of [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL.

###### G1.15.5.1 Pseudocode description of exception return

The [`AArch32_ExceptionReturn`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-144-AArch32-ExceptionReturn?lang=en#asl_func_aarch32_exceptionreturn_2)`()` function transfers the return address to the PC and restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) to its saved value.

This function uses the function [`SetPSTATEFromPSR`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-640-SetPSTATEFromPSR?lang=en#asl_func_setpstatefrompsr_3)`()`.

The [`IllegalExceptionReturn`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-613-IllegalExceptionReturn?lang=en#asl_func_illegalexceptionreturn_2)`()` function checks for an Illegal Execution state exception.

[A-profile Architecture Pseudocode](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode?lang=en#chap_pseudocode) includes the definitions of these functions.
