# ​D20.4.4 Target Exception level for External abort and SError exceptions taken to AArch64 state

##### D20.4.4 Target Exception level for External abort and SError exceptions taken to AArch64 state

D FWSVH
:   This section is included for completeness. It repeats the definitions from this Manual and so is *non-normative*.

    These definitions also apply to synchronous External abort exceptions and SError exceptions taken from AArch32 state to AArch64 state.

I NRZXZ
:   The default target Exception level for synchronous External abort exceptions taken to AArch64 state is:

    - EL1, if taken from EL0 or EL1.
    - EL2, if taken from EL2.
    - EL3, if taken from EL3.

    The default target Exception level for SError exceptions taken to AArch64 state is EL1.

    However:

    - If EL3 is implemented and [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).EA is `0b1`, then the target Exception level for all SError exceptions and synchronous External abort exceptions is EL3.
    - Otherwise, if EL2 is implemented and enabled in the current Security state, then:

      - If [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).AMO is `0b1` or [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE is `0b1`, then the target Exception level for SError exceptions is EL2.
      - If [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TEA is `0b1` or [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE is `0b1`, then the target Exception level for synchronous External abort exceptions taken from EL0 and EL1 is EL2.

    When executing in AArch64 state at a higher Exception level than the target Exception level for SError exceptions, SError exceptions are implicitly masked and not taken.
