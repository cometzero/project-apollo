##### I5.3.47 PMPCSCTL, PC Sample-based Profiling Control Register

The PMPCSCTL characteristics are:

Purpose
:   Controls the PC Sample-based Profiling feature.

Configuration
:   PMPCSCTL is in the Core power domain.

    This register is present only when FEAT\_PCSRv8p9 is implemented and FEAT\_PMUv3\_EXT is implemented. Otherwise, direct accesses to PMPCSCTL are RES0.

Attributes
:   PMPCSCTL is a 64-bit register.

Bits [63:5]
:   Reserved, RES0.

SS, bit [4]
:   When FEAT\_PMUv3\_SS is implemented:
    :   Sample on Snapshot.

        Controls whether the following registers are sampled on a PMU snapshot Capture event:

        - If [FEAT\_PMUv3\_EXT32](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pmuv3_ext32) is implemented: [PMCID1SR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-13-PMCID1SR--CONTEXTIDR-EL1-Sample-Register?lang=en#reg_pmu_pmcid1sr), [PMCID2SR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-14-PMCID2SR--CONTEXTIDR-EL2-Sample-Register?lang=en#reg_pmu_pmcid2sr), [PMPCSR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-48-PMPCSR--Program-Counter-Sample-Register?lang=en#reg_pmu_pmpcsr), and [PMVIDSR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-60-PMVIDSR--VMID-Sample-Register?lang=en#reg_pmu_pmvidsr).

###### Accessing PMPCSCTL

Accesses to this register use the following encodings:

When FEAT\_PCSRv8p9 is implemented
:   Accessible at offset `0xE50` from PMU

    - When DoubleLockStatus() or !IsCorePowered(), accesses to this register generate an error response.
    - When (((!IsFeatureImplemented(FEAT\_PMUv3\_EXTPMN)) || (!IsMostSecureAccess(addrdesc))) || (PMCCR().OSLO == ‘0’)) && OSLockStatus(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RW.
