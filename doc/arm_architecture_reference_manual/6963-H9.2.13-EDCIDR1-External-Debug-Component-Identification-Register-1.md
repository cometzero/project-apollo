##### H9.2.13 EDCIDR1, External Debug Component Identification Register 1

The EDCIDR1 characteristics are:

Purpose
:   Provides information to identify an external debug component.

    For more information, see [‘About the Component Identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-5-About-the-Component-Identification-scheme?lang=en#babbfiid).

Configuration
:   When FEAT\_DoPD is implemented, EDCIDR1 is in the Core power domain. Otherwise, EDCIDR1 is in the Debug power domain

Attributes
:   EDCIDR1 is a 32-bit register.

###### Field descriptions

Bits [31:8]
:   Reserved, RES0.

CLASS, bits [7:4]
:   When FEAT\_ED\_PIDR is implemented:
    :   Component class.

        This field reads as `0x9`.

        Access to this field is RO.

    Otherwise:
    :   Reserved, RAZ.

PRMBL\_1, bits [3:0]
:   When FEAT\_ED\_PIDR is implemented:
    :   Preamble.

        Reads as `0b0000`

        Access to this field is RO.

    Otherwise:
    :   Reserved, RAZ.
