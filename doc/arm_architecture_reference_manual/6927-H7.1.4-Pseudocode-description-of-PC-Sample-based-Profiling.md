##### H7.1.4 Pseudocode description of PC Sample-based Profiling

When [FEAT\_PCSRv8](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pcsrv8) is implemented, the functionality is described by the pseudocode functions:

- [`CreatePCSample`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-124-CreatePCSample?lang=en#asl_func_createpcsample_0)`()`, which populates a variable of type [`PCSample`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-126-PCSample?lang=en#asl_type_pcsample).
- [`Read_EDPCSRlo`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-127-Read-EDPCSRlo?lang=en#asl_func_read_edpcsrlo_1)`()`, which writes a PC sample to the [EDPCSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-35-EDPCSR--External-Debug-Program-Counter-Sample-Register?lang=en#reg_ext_edpcsr) and associated registers.

When [FEAT\_PCSRv8p2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pcsrv8p2) is implemented, the functionality is described by the pseudocode functions:

- [`CreatePCSample`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-124-CreatePCSample?lang=en#asl_func_createpcsample_0)`()`, which populates a variable of type [`PCSample`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-126-PCSample?lang=en#asl_type_pcsample).
- [`Read_PMPCSR`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-128-Read-PMPCSR?lang=en#asl_func_read_pmpcsr_1)`()`, which writes a PC Sample to the [PMPCSR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-48-PMPCSR--Program-Counter-Sample-Register?lang=en#reg_pmu_pmpcsr) and associated registers.
