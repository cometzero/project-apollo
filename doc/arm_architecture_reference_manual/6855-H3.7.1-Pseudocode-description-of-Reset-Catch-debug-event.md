##### H3.7.1 Pseudocode description of Reset Catch debug event

The [`CheckResetCatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-83-CheckResetCatch?lang=en#asl_func_checkresetcatch_0)`()` function is called after reset before executing any instruction.

The [`CheckPendingResetCatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-82-CheckPendingResetCatch?lang=en#asl_func_checkpendingresetcatch_0)`()` function is called before an instruction is executed. If a Reset Catch is pending, it generates the Reset Catch debug event.
