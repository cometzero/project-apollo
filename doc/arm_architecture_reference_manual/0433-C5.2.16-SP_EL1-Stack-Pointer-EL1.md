# ​C5.2.16 SP_EL1, Stack Pointer (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-16-SP-EL1--Stack-Pointer--EL1->

##### C5.2.16 SP\_EL1, Stack Pointer (EL1)

The SP\_EL1 characteristics are:

Purpose
:   Holds the stack pointer associated with EL1. The value of [SPSel](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-19-SPSel--Stack-Pointer-Select?lang=en#reg_aarch64_spsel).SP determines the current stack pointer.

Configuration
:   This register is a Special-purpose register.

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to SP\_EL1 are UNDEFINED.

Attributes
:   SP\_EL1 is a 64-bit register.

###### Field descriptions

![](images/0433-C5.2.16-SP_EL1-Stack-Pointer-EL1-img01.svg)

StackPointer, bits [63:0]
:   Stack pointer.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing SP\_EL1

This accessibility information only applies to accesses using the MRS or MSR instructions.

When the value of [SPSel](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-19-SPSel--Stack-Pointer-Select?lang=en#reg_aarch64_spsel).SP is 1, this register is also accessible at EL1 as the current stack pointer.

> #### Note
>
> When the value of [SPSel](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-19-SPSel--Stack-Pointer-Select?lang=en#reg_aarch64_spsel).SP is 0, [SP\_EL0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-15-SP-EL0--Stack-Pointer--EL0-?lang=en#reg_aarch64_sp_el0) is used as the current stack pointer at all Exception levels.

elsif PSTATE.EL == EL0 then
    Undefined();
elsif PSTATE.EL == EL1 then
    if EffectiveHCR_EL2_NVx() IN {'1x1'} then
        X{64}(t) = NVMem(0x240);
    elsif EffectiveHCR_EL2_NVx() IN {'xx1'} then
        AArch64_SystemAccessTrap(EL2, 0x18);
    else
        Undefined();
    end;
elsif PSTATE.EL == EL2 then
    X{64}(t) = SP_EL1();
elsif PSTATE.EL == EL3 then
    X{64}(t) = SP_EL1();
end;
