R DXFFN
:   When the trace unit becomes enabled, the trace unit transitions from the Idle state to the Enabling state.

R ZFPHC
:   The trace unit transitions from the Enabling state to the Running state in a finite amount of time.

R TZSRP
:   When the trace unit becomes disabled, the trace unit transitions from the Running state to the Unstable state.

R CZHWF
:   The trace unit transitions from the Unstable state to the Stable state in a finite amount of time.

R BPTKT
:   While the trace unit is in the Stable and Idle states, the states of the following fields do not change other than by direct writes or external writes:

    - [TRCVICTLR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-75-TRCVICTLR--Trace-ViewInst-Main-Control-Register?lang=en#reg_ext_trcvictlr).SSSTATUS.
    - [TRCSEQSTR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-66-TRCSEQSTR--Trace-Sequencer-State-Register?lang=en#reg_ext_trcseqstr).STATE.
    - [TRCCNTVR<n>](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-18-TRCCNTVR-n---Trace-Counter-Value-Register--n---n---0---3?lang=en#reg_ext_trccntvrn).VALUE.
    - [TRCSSCSR<n>](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-68-TRCSSCSR-n---Trace-Single-shot-Comparator-Control-Status-Register--n---n---0---7?lang=en#reg_ext_trcsscsrn).STATUS.
    - [TRCRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-63-TRCRSR--Trace-Resources-Status-Register?lang=en#reg_ext_trcrsr).EVENT.
    - [TRCRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-63-TRCRSR--Trace-Resources-Status-Register?lang=en#reg_ext_trcrsr).EXTIN.
    - [TRCRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-63-TRCRSR--Trace-Resources-Status-Register?lang=en#reg_ext_trcrsr).TA.

I TDLZL
:   The trace unit programmers’ model state can be safely read when in any of the Stable or Idle states.

R TRZCP
:   When the trace unit becomes fully idle and both of the following are true, the trace unit transitions from the Stable state to the Idle state:

    - The trace unit is drained of any trace.
    - With the exception of the programming interfaces, all external interfaces on the trace unit are quiescent.

R RWYQD
:   While the trace unit is not in the Idle state, direct writes and external writes to the trace unit registers are CONSTRAINED UNPREDICTABLE, except for the following registers:

    - [TRCPRGCTLR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-60-TRCPRGCTLR--Trace-Programming-Control-Register?lang=en#reg_ext_trcprgctlr).
    - [TRCCLAIMSET](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-15-TRCCLAIMSET--Trace-Claim-Tag-Set-Register?lang=en#reg_ext_trcclaimset).
    - [TRCCLAIMCLR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-14-TRCCLAIMCLR--Trace-Claim-Tag-Clear-Register?lang=en#reg_ext_trcclaimclr).

    This CONSTRAINED UNPREDICTABLE behavior is one of the following:

    - The write is ignored.
    - The register takes an UNKNOWN value.

    The trace byte stream might also be corrupted and analysis of the byte stream might be impossible.

R MDZDN
:   While the trace unit is not in the Idle or Running states, changing the value of [TRCPRGCTLR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-60-TRCPRGCTLR--Trace-Programming-Control-Register?lang=en#reg_ext_trcprgctlr).EN is CONSTRAINED UNPREDICTABLE.

    This CONSTRAINED UNPREDICTABLE behavior is one of the following:

    - The write is ignored.
    - The register takes an UNKNOWN value.
