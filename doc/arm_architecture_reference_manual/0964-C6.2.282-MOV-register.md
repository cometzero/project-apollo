##### C6.2.282 MOV (register)

Move register value

This instruction copies the value in a source register to the destination register.

This is an alias of [ORR (shifted register)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-302-ORR--shifted-register-?lang=en#isa_orr_log_shift). This means:

- The encodings in this description are named to match the encodings of [ORR (shifted register)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-302-ORR--shifted-register-?lang=en#isa_orr_log_shift).
- The description of [ORR (shifted register)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-302-ORR--shifted-register-?lang=en#isa_orr_log_shift) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the 32-bit variant

Applies when `(sf == 0)`

```
MOV  <Wd>, <Wm>
```

is equivalent to

```
ORR  <Wd>, WZR, <Wm>
```

and is always the preferred disassembly.

###### Encoding for the 64-bit variant

Applies when `(sf == 1)`

```
MOV  <Xd>, <Xm>
```

is equivalent to

```
ORR  <Xd>, XZR, <Xm>
```

and is always the preferred disassembly.

###### Assembler Symbols

<Wd>
:   ​

    Is the 32-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Wm>
:   ​

    Is the 32-bit name of the general-purpose source register, encoded in the “Rm” field.

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Xm>
:   ​

    Is the 64-bit name of the general-purpose source register, encoded in the “Rm” field.
