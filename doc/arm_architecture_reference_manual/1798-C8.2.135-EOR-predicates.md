##### C8.2.135 EOR (predicates)

Bitwise exclusive-OR predicates

This instruction performs a bitwise exclusive-OR between the active elements of the first source predicate and the corresponding elements of the second source predicate, and places the results in the corresponding elements of the destination predicate. Inactive elements in the destination predicate register are set to zero. This instruction does not set the condition flags.

This instruction is used by the alias [NOT (predicate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-489-NOT--predicate-?lang=en#isa_not_eor_p_p_pp).

###### Encoding

```
EOR  <Pd>.B, <Pg>/Z, <Pn>.B, <Pm>.B
```

```
if !IsFeatureImplemented(FEAT_SVE) && !IsFeatureImplemented(FEAT_SME) then
```

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let elements : integer = VL DIV esize;
let mask : bits(PL) = P{}(g);
let operand1 : bits(PL) = P{}(n);
let operand2 : bits(PL) = P{}(m);
var result : bits(PL);
let psize : integer{} = esize DIV 8;
for e = 0 to elements-1 do
    let element1 : bit = PredicateElement{PL}(operand1, e, esize);
    let element2 : bit = PredicateElement{PL}(operand2, e, esize);
    if ActivePredicateElement{PL}(mask, e, esize) then
        result[e*:psize] = ZeroExtend{psize}(element1 XOR element2);
    else
        result[e*:psize] = ZeroExtend{psize}(‘0’);
    end;
end;
if setflags then
    PSTATE.[N,Z,C,V] = PredTest{PL}(mask, result, esize);
end;
P{PL}(d) = result;
```
