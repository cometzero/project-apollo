# ​D21.7.3 Trap controls to trap accesses to MPAM System registers

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-7-Virtualization-support/-D21-7-3-Trap-controls-to-trap-accesses-to-MPAM-System-registers>

##### D21.7.3 Trap controls to trap accesses to MPAM System registers

I TKRWM
:   The MPAM architecture provides trap controls for all the following:

    - EL1 accesses to [MPAM0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-1-MPAM0-EL1--MPAM0-Register--EL1-?lang=en#reg_aarch64_mpam0_el1), [MPAM1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-2-MPAM1-EL1--MPAM1-Register--EL1-?lang=en#reg_aarch64_mpam1_el1), and [MPAMSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-14-MPAMSM-EL1--MPAM-Streaming-Mode-Register?lang=en#reg_aarch64_mpamsm_el1), to trap these to EL2. See the trap controls [MPAM2\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-3-MPAM2-EL2--MPAM2-Register--EL2-?lang=en#reg_aarch64_mpam2_el2).{TRAPMPAM0EL1, TRAPMPAM1EL1, EnMPAMSM} respectively.
    - EL1 accesses to [MPAMBW0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-5-MPAMBW0-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL0-?lang=en#reg_aarch64_mpambw0_el1), [MPAMBW1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-6-MPAMBW1-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambw1_el1), and [MPAMBWSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-11-MPAMBWSM-EL1--MPAM-Streaming-Mode-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambwsm_el1), to trap these to EL2. See the trap controls [MPAMBW2\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-7-MPAMBW2-EL2--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL2-?lang=en#reg_aarch64_mpambw2_el2).{nTRAP\_MPAMBW0\_EL1, nTRAP\_MPAMBW1\_EL1, nTRAP\_MPAMBWSM\_EL1} respectively.
    - EL2 and EL1 accesses to MPAM System registers, to trap these to EL3. See [MPAM3\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-4-MPAM3-EL3--MPAM3-Register--EL3-?lang=en#reg_aarch64_mpam3_el3).TRAPLOWER and [MPAMBW3\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-8-MPAMBW3-EL3--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL3-?lang=en#reg_aarch64_mpambw3_el3).nTRAPLOWER.

I SQQYN
:   Accesses to all the following are not subject to any traps:

    - MPAM1\_EL12.
    - [MPAM1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-2-MPAM1-EL1--MPAM1-Register--EL1-?lang=en#reg_aarch64_mpam1_el1) when the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1.

    See [Interaction with FEAT\_VHE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-7-Virtualization-support/-D21-7-6-Interaction-with-FEAT-VHE?lang=en#mpam_interaction_with_feat_vhe).
