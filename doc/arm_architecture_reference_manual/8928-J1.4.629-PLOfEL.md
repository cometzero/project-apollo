##### J1.4.629 PLOfEL

```
// PLOfEL()
// ========
func PLOfEL(el : bits(2)) => PrivilegeLevel
begin
    case el of
        when EL3 =>  return if !HaveAArch64() then PL1 else PL3;
        when EL2 =>  return PL2;
        when EL1 =>  return PL1;
        when EL0 =>  return PL0;
    end;
end;
```
