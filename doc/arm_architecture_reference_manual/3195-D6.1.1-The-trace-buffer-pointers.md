# ​D6.1.1 The trace buffer pointers

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers>

##### D6.1.1 The trace buffer pointers

R WKBRT
:   The trace buffer is defined by three trace buffer pointer addresses:

    - The *Base pointer*.
    - The *Limit pointer*.
    - The *current write pointer*.

R FVPBS
:   The trace buffer starts at the [Base pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) and extends to the [Limit pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3). The location at the [Base pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) is included in the trace buffer. The location at the [Limit pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3) is not included in the trace buffer.

R XBLPK
:   The [Base pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) and [Limit pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3) must be aligned by software to the smallest implemented translation granule size.

R VHNTF
:   For each byte of trace that the Trace Buffer Unit *accepts* and writes to the trace buffer at the address in the [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5), one of the following applies:

    - If the [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is not equal to the [Limit pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3) minus one, then the [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is incremented by one.
    - If the [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is equal to the [Limit pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3) minus one, then all of the following occur:

      - The [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is wrapped by setting it to the [Base pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9).
      - A trace buffer management event might be generated. See [Trace buffer management](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#mdsec_trace_buffer_management).
      - [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).WRAP is set to 1, where ELx is the value in the *Other event* column of [Table D6-7](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#tbl_tracebuffereventother). The other fields in [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) and the other [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) registers are unchanged if no trace buffer management event is generated.
      - The [TRB\_WRAP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x400C--TRB-WRAP--Trace-buffer-current-write-pointer-wrapped?lang=en#event_trb_wrap) event is generated.

R BGBCJ
:   The [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is not incremented when [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1).

R VMVJH
:   The required alignment of the [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is IMPLEMENTATION DEFINED.

I BTSCF
:   The Trace Buffer Unit can write trace data to memory in quantized units. The behavior is as if the bytes are written sequentially.

R JMPCB
:   The [Base pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) is ([TRBBASER\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-1-TRBBASER-EL1--Trace-Buffer-Base-Address-Register?lang=en#reg_aarch64_trbbaser_el1).BASE `<<` 12). Bits [11:0] of the [Base pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) are zero.

R LLBBS
:   The [Limit pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3) is ([TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).LIMIT `<<` 12). Bits [11:0] of the [Limit pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3) are zero.

R KXRTY
:   The [current write pointer](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is [TRBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-6-TRBPTR-EL1--Trace-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_trbptr_el1).PTR[63:0].

R PBGNS
:   The *Trigger Counter* is [TRBTRG\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-10-TRBTRG-EL1--Trace-Buffer-Trigger-Counter-Register?lang=en#reg_aarch64_trbtrg_el1).TRG.
