# ​C5.9.3 GCSPOPX, Guarded Control Stack Pop exception return record

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-9-A64-System-instructions-for-the-Guarded-Control-Stack/-C5-9-3-GCSPOPX--Guarded-Control-Stack-Pop-exception-return-record>

##### C5.9.3 GCSPOPX, Guarded Control Stack Pop exception return record

The GCSPOPX characteristics are:

Purpose
:   Loads a GCS exception return record from the location indicated by the current GCS pointer register, checks that the record is a GCS exception return record, and increments the current GCS pointer register by the size of a GCS exception return record.

Configuration
:   This system instruction is present only when FEAT\_GCS is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to GCSPOPX are UNDEFINED.

Attributes
:   GCSPOPX is a 64-bit System instruction.

###### Field descriptions

This instruction has no applicable fields.

The value in the register specified by <Xt> is ignored.

###### Executing GCSPOPX

Rt should be encoded as `0b11111`. If the Rt field is not set to `0b11111`, it is CONSTRAINED UNPREDICTABLE whether:

- The instruction is UNDEFINED.
- The instruction behaves as if the Rt field is set to `0b11111`.

This system instruction is an alias of the SYS instruction.
