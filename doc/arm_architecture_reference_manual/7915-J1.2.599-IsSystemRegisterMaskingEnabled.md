# ​J1.2.599 IsSystemRegisterMaskingEnabled

##### J1.2.599 IsSystemRegisterMaskingEnabled

```
// IsSystemRegisterMaskingEnabled()
// ================================
// Returns TRUE if access to the MASK registers introduced by FEAT_SRMASK is enabled and the
// values in the register are not treated as 0.
func IsSystemRegisterMaskingEnabled(el : bits(2)) => boolean
begin
    assert IsFeatureImplemented(FEAT_SRMASK) && el IN {EL1, EL2};
    if HaveEL(EL3) && SCR_EL3().SRMASKEn == ‘0’ then
        return FALSE;
    end;
    return el == EL2 || !EL2Enabled() || (IsHCRXEL2Enabled() && HCRX_EL2().SRMASKEn == ‘1’);
end;
```
