##### F1.9.3 Advanced SIMD instruction modifiers

The `<modifier>` field provides additional variants of some instructions. [Table F1-10](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-9-Additional-information-about-Advanced-SIMD-and-floating-point-instructions/-F1-9-3-Advanced-SIMD-instruction-modifiers?lang=en#tbl_cjacgei1) provides definitions of the modifiers. Modifiers are not available for every instruction.
