##### `0x83BD`, N2\_CACHE3\_HIT\_PRFM, Cache type 3 at distance 2 software prefetch hit

The counter counts each software prefetch counted by [N2\_CACHE\_HIT\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83A5--N2-CACHE-HIT-PRFM--Cache-at-distance-2--software-prefetch-hit?lang=en#event_n2_cache_hit_prfm) due to a software prefetch accessing a third cache type at distance 2.

The definition of cache types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
