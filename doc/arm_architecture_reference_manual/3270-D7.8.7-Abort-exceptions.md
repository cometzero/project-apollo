# ​D7.8.7 Abort exceptions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D7-The-AArch64-System-Level-Memory-Model/-D7-8-Pseudocode-description-of-general-memory-System-instructions/-D7-8-7-Abort-exceptions>

##### D7.8.7 Abort exceptions

The [`AArch64_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-132-AArch64-Abort?lang=en#asl_func_aarch64_abort_1)`()` function generates either a Data Abort or an Instruction Abort exception by calling [`AArch64_DataAbort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-135-AArch64-DataAbort?lang=en#asl_func_aarch64_dataabort_1)`()` or [`AArch64_InstructionAbort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-137-AArch64-InstructionAbort?lang=en#asl_func_aarch64_instructionabort_1)`()`. It also can generate a debug exception for debug related faults, see [AArch64 Self-hosted Debug](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug?lang=en#bcgefacd).

The [`AArch64_DataAbort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-135-AArch64-DataAbort?lang=en#asl_func_aarch64_dataabort_1)`()` function generates a Data Abort exception, routes the exception to EL2 or EL3, and records the information required for the Exception Syndrome registers, [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx). See [ISS encoding for an exception from a Data Abort](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-44-ESR-EL1--Exception-Syndrome-Register--EL1-?lang=en#fieldset_aarch64_esr_el1_fieldset_0_iss_an_exception_from_a_data_abort). A second stage abort might also record the intermediate physical address, IPA, but this depends on the type of the abort.

For a synchronous abort, [`AArch64_DataAbort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-135-AArch64-DataAbort?lang=en#asl_func_aarch64_dataabort_1)`()` also sets the FAR to the VA of the abort.

The [`AArch64_InstructionAbort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-137-AArch64-InstructionAbort?lang=en#asl_func_aarch64_instructionabort_1)`()` function generates an Instruction Abort exception, routes the exception to EL2 or EL3, and records the information required for the Exception Syndrome registers, [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx), see [ISS encoding for an exception from an Instruction Abort](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-44-ESR-EL1--Exception-Syndrome-Register--EL1-?lang=en#fieldset_aarch64_esr_el1_fieldset_0_iss_an_exception_from_an_instruction_abort). A second stage abort might also record the intermediate physical address, IPA, but this depends on the type of the abort.

For a synchronous abort, [`AArch64_InstructionAbort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-137-AArch64-InstructionAbort?lang=en#asl_func_aarch64_instructionabort_1)`()` also sets the FAR to the VA of the abort.

The [`FaultRecord`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-427-FaultRecord?lang=en#asl_type_faultrecord) type describes a fault. Functions that check for faults return a record of this type appropriate to the type of fault.

The function [`NoFault`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-766-NoFault?lang=en#asl_func_nofault_0)`()` returns a null record that indicates no fault. The [`IsFault`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-159-IsFault?lang=en#asl_func_isfault_1)`()` function tests whether a [`FaultRecord`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-427-FaultRecord?lang=en#asl_type_faultrecord) contains a fault.
