# ​G8.5.4 AMCNTENCLR1, Activity Monitors Count Enable Clear Register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-4-AMCNTENCLR1--Activity-Monitors-Count-Enable-Clear-Register-1>

##### G8.5.4 AMCNTENCLR1, Activity Monitors Count Enable Clear Register 1

The AMCNTENCLR1 characteristics are:

Purpose
:   Disable control bits for the auxiliary activity monitors event counters, [AMEVCNTR1<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-9-AMEVCNTR1-n---Activity-Monitors-Event-Counter-Registers-1--n---0---15?lang=en#reg_aarch32_amevcntr1n).

Configuration
:   AArch32 System register AMCNTENCLR1 bits [31:0] are architecturally mapped to AArch64 System register [AMCNTENCLR1\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-5-AMCNTENCLR1-EL0--Activity-Monitors-Count-Enable-Clear-Register-1?lang=en#reg_aarch64_amcntenclr1_el0)[31:0].

    AArch32 System register AMCNTENCLR1 bits [31:0] are architecturally mapped to External register [AMCNTENCLR1](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-10-AMCNTENCLR1--Activity-Monitors-Count-Enable-Clear-Register-1?lang=en#reg_amu_amcntenclr1)[31:0].

    AArch32 System register AMCNTENCLR1 bits [31:0] are architecturally mapped to External register [AMCNTENSET1](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-13-AMCNTENSET1--Activity-Monitors-Count-Enable-Set-Register-1?lang=en#reg_amu_amcntenset1)[31:0].

    This register is present only when FEAT\_AMUv1 is implemented and FEAT\_AA32 is implemented. Otherwise, direct accesses to AMCNTENCLR1 are UNDEFINED.

Attributes
:   AMCNTENCLR1 is a 32-bit register.

    The reset behavior of this field is:

    - On a AMU reset, this field resets to the expression `0x00000000`.

    Accessing this field has the following behavior:

    - When n >= UInt(AMCGCR.CG1NC), access to this field is RAZ/WI.
    - When !IsG1ActivityMonitorImplemented(n), access to this field is RAZ/WI.
    - Otherwise, access to this field is W1C.

###### Accessing AMCNTENCLR1

If there are no auxiliary monitor event counters implemented, reads and writes of AMCNTENCLR1 are UNDEFINED.

> #### Note
>
> There are no implemented auxiliary activity monitor event counters when [AMCFGR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-1-AMCFGR--Activity-Monitors-Configuration-Register?lang=en#reg_aarch32_amcfgr).NCG == `0b0000`.
