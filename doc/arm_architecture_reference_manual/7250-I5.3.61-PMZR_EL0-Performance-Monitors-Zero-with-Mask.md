# ​I5.3.61 PMZR_EL0, Performance Monitors Zero with Mask

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-61-PMZR-EL0--Performance-Monitors-Zero-with-Mask>

##### I5.3.61 PMZR\_EL0, Performance Monitors Zero with Mask

The PMZR\_EL0 characteristics are:

Purpose
:   Zero the set of counters specified by the mask written to PMZR\_EL0.

Configuration
:   PMZR\_EL0 is in the Core power domain.

    When FEAT\_PMUv3\_EXT is implemented and FEAT\_PMUv3p9 is implemented, External register PMZR\_EL0 bits [63:0] are architecturally mapped to AArch64 System register [PMZR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-28-PMZR-EL0--Performance-Monitors-Zero-with-Mask?lang=en#reg_aarch64_pmzr_el0)[63:0].

    This register is present only when FEAT\_PMUv3\_EXT is implemented and FEAT\_PMUv3p9 is implemented.

Attributes
:   PMZR\_EL0 is a 64-bit register.

    Accessing this field has the following behavior:

    - When m >= NUM\_PMU\_COUNTERS, access to this field is RAZ/WI.
    - Access to this field is RAZ/WI if all of the following are true:
      - FEAT\_PMUv3\_EXTPMN is implemented
      - m >= UInt(EffectiveEPMN())

    - When SoftwareLockStatus(addrdesc), access to this field is RAZ/WI.
    - Otherwise, access to this field is WO/RAZ.

###### Accessing PMZR\_EL0

When [FEAT\_PMUv3\_EXT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pmuv3_ext) is implemented and [FEAT\_PMUv3p9](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_pmuv3p9) is not implemented, then this location might be used for [PMSWINC\_EL0](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-58-PMSWINC-EL0--Performance-Monitors-Software-Increment-Register?lang=en#reg_pmu_pmswinc_el0). If [PMSWINC\_EL0](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-58-PMSWINC-EL0--Performance-Monitors-Software-Increment-Register?lang=en#reg_pmu_pmswinc_el0) is not implemented, then accesses to this location are RES0.

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT is implemented and FEAT\_PMUv3p9 is implemented
:   Accessible at offset `0xCA0` from PMU

    - When DoubleLockStatus(), or !IsCorePowered(), or !AllowExternalPMUAccess(addrdesc), accesses to this register generate an error response.
    - When (((!IsFeatureImplemented(FEAT\_PMUv3\_EXTPMN)) || (!IsMostSecureAccess(addrdesc))) || (PMCCR().OSLO == ‘0’)) && OSLockStatus(), accesses to this register generate an error response.
    - When SoftwareLockStatus(addrdesc), accesses to this register are WI.
    - Otherwise, accesses to this register are WO.
