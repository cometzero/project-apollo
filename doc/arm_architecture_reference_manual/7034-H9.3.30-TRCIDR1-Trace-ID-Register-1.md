##### H9.3.30 TRCIDR1, Trace ID Register 1

The TRCIDR1 characteristics are:

Purpose
:   Returns the tracing capabilities of the trace unit.

Configuration
:   External register TRCIDR1 bits [31:0] are architecturally mapped to AArch64 System register [TRCIDR1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-32-TRCIDR1--Trace-ID-Register-1?lang=en#reg_aarch64_trcidr1)[31:0].

    This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCIDR1 are RES0.

Attributes
:   TRCIDR1 is a 32-bit register.

###### Field descriptions

![](images/7034-H9.3.30-TRCIDR1-Trace-ID-Register-1-img01.svg)

DESIGNER, bits [31:24]
:   Indicates which company designed the trace unit. The permitted values of this field are the same as [MIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-136-MIDR-EL1--Main-ID-Register?lang=en#reg_aarch64_midr_el1).Implementer.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

Bits [23:16]
:   Reserved, RES0.

Bits [15:12]
:   Reserved, RES1.

TRCARCHMAJ, bits [11:8]
:   Major architecture version.

REVISION, bits [3:0]
:   Implementation revision.

    Returns an IMPLEMENTATION DEFINED value that identifies the revision of the trace unit.

    Arm deprecates any use of this field and recommends that implementations set this field to zero.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
