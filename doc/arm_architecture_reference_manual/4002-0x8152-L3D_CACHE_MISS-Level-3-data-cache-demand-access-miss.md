# ​0x8152, L3D_CACHE_MISS, Level 3 data cache demand access miss

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8152--L3D-CACHE-MISS--Level-3-data-cache-demand-access-miss>

##### `0x8152`, L3D\_CACHE\_MISS, Level 3 data cache demand access miss

The counter counts each demand access counted by [L3D\_CACHE\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8150--L3D-CACHE-RW--Level-3-data-cache-demand-access?lang=en#event_l3d_cache_rw) that misses in the Level 1 to Level 3 data or unified caches, causing an access to outside of the Level 1 to Level 3 caches of this PE.
