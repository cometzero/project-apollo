##### `0x814F`, L2I\_CACHE\_REFILL\_PRFM, Level 2 instruction cache refill, software prefetch

The counter counts each access counted by [L2I\_CACHE\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x814B--L2I-CACHE-PRFM--Level-2-instruction-cache-software-prefetch?lang=en#event_l2i_cache_prfm) that causes a refill of the Level 2 instruction or unified cache, or any Level 1 data, instruction, or unified cache of this PE, from outside of those caches.
