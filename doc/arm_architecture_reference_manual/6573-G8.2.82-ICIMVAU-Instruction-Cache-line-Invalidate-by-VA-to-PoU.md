# ​G8.2.82 ICIMVAU, Instruction Cache line Invalidate by VA to PoU

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-82-ICIMVAU--Instruction-Cache-line-Invalidate-by-VA-to-PoU>

##### G8.2.82 ICIMVAU, Instruction Cache line Invalidate by VA to PoU

The ICIMVAU characteristics are:

Purpose
:   Invalidate instruction cache line by virtual address to PoU.

Configuration
:   AArch32 System instruction ICIMVAU bits [31:0] performs the same function as bits [31:0].

    This system instruction is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ICIMVAU are UNDEFINED.

Attributes
:   ICIMVAU is a 32-bit System instruction.

###### Field descriptions

![](images/6573-G8.2.82-ICIMVAU-Instruction-Cache-line-Invalidate-by-VA-to-PoU-img01.svg)

VA, bits [31:0]
:   Virtual address to use. No alignment restrictions apply to this VA.

###### Executing ICIMVAU

Execution of this instruction might require an address translation from VA to PA, and that translation might fault.

For more information about faults, see [‘Permission fault’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-11-VMSAv8-32-memory-aborts/-G5-11-1-Types-of-MMU-faults?lang=en#chdijgii).

For more information about data cache maintenance instructions, see [’AArch32 instruction cache maintenance instructions (IC\*)’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G4-The-AArch32-System-Level-Memory-Model/-G4-4-AArch32-cache-and-branch-predictor-support/-G4-4-7-AArch32-cache-and-branch-predictor-maintenance-instructions?lang=en#beiddehe).
