##### J1.2.647 AArch64\_IASize

```
// AArch64_IASize()
// ================
// Retrieve the number of bits containing the input address
func AArch64_IASize(txsz : bits(6)) => AddressSize
begin
    return (64 - UInt(txsz)) as AddressSize;
end;
```
