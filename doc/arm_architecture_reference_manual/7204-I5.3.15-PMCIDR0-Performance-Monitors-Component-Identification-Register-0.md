# ​I5.3.15 PMCIDR0, Performance Monitors Component Identification Register 0

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-15-PMCIDR0--Performance-Monitors-Component-Identification-Register-0>

##### I5.3.15 PMCIDR0, Performance Monitors Component Identification Register 0

The PMCIDR0 characteristics are:

Purpose
:   Provides information to identify a Performance Monitor component.

    For more information, see [‘About the Component Identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-5-About-the-Component-Identification-scheme?lang=en#babbfiid).

Configuration
:   If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, this register is in the Core power domain. If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, this register is in the Debug power domain.

    This register is present only when FEAT\_PMUv3\_EXT is implemented. Otherwise, direct accesses to PMCIDR0 are RES0.

Attributes
:   PMCIDR0 is a 32-bit register.

###### Field descriptions

![](images/7204-I5.3.15-PMCIDR0-Performance-Monitors-Component-Identification-Register-0-img01.svg)

Bits [31:8]
:   Reserved, RES0.

PRMBL\_0, bits [7:0]
:   When FEAT\_PMU\_PIDR is implemented:
    :   Preamble.

        Reads as `0x0D`

        Access to this field is RO.

    Otherwise:
    :   Reserved, RAZ.

###### Accessing PMCIDR0

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT is implemented
:   Accessible at offset `0xFF0` from PMU

    - When FEAT\_DoPD is implemented and !IsCorePowered(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RO.
