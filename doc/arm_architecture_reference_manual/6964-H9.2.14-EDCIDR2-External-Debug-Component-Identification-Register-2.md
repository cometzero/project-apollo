##### H9.2.14 EDCIDR2, External Debug Component Identification Register 2

The EDCIDR2 characteristics are:

Purpose
:   Provides information to identify an external debug component.

    For more information, see [‘About the Component Identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-5-About-the-Component-Identification-scheme?lang=en#babbfiid).

Configuration
:   When FEAT\_DoPD is implemented, EDCIDR2 is in the Core power domain. Otherwise, EDCIDR2 is in the Debug power domain

Attributes
:   EDCIDR2 is a 32-bit register.

###### Field descriptions

![](images/6964-H9.2.14-EDCIDR2-External-Debug-Component-Identification-Register-2-img01.svg)

Bits [31:8]
:   Reserved, RES0.

PRMBL\_2, bits [7:0]
:   When FEAT\_ED\_PIDR is implemented:
    :   Preamble.

        Reads as `0x05`

        Access to this field is RO.

    Otherwise:
    :   Reserved, RAZ.
