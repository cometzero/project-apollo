# ​D24.2.2 ACTLR_EL1, Auxiliary Control Register (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-2-ACTLR-EL1--Auxiliary-Control-Register--EL1->

##### D24.2.2 ACTLR\_EL1, Auxiliary Control Register (EL1)

The ACTLR\_EL1 characteristics are:

Purpose
:   Provides IMPLEMENTATION DEFINED configuration and control options for execution at EL1 and EL0.

    > #### Note
    >
    > Arm recommends the contents of this register have no effect on the PE when the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is {1, 1}, and instead the configuration and control fields are provided by the [ACTLR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-3-ACTLR-EL2--Auxiliary-Control-Register--EL2-?lang=en#reg_aarch64_actlr_el2) register. This avoids the need for software to manage the contents of these register when switching between a Guest OS and a Host OS.

Configuration
:   AArch64 System register ACTLR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [ACTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-1-ACTLR--Auxiliary-Control-Register?lang=en#reg_aarch32_actlr)[31:0].

    AArch64 System register ACTLR\_EL1 bits [63:32] are architecturally mapped to AArch32 System register [ACTLR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-2-ACTLR2--Auxiliary-Control-Register-2?lang=en#reg_aarch32_actlr2)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to ACTLR\_EL1 are UNDEFINED.

Attributes
:   ACTLR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/4894-D24.2.2-ACTLR_EL1-Auxiliary-Control-Register-EL1-img01.svg)

IMPLEMENTATION DEFINED, bits [63:0]
:   IMPLEMENTATION DEFINED.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing ACTLR\_EL1

If the IMPLEMENTATION DEFINED ACTLR\_EL12 accessor is implemented, the following behaviors are also implemented:

- MRS/MSR to ACTLR\_EL1 from EL2 when the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1 accesses [ACTLR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-3-ACTLR-EL2--Auxiliary-Control-Register--EL2-?lang=en#reg_aarch64_actlr_el2).
- MRS/MSR to ACTLR\_EL1 from EL1 when the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{NV2, NV1, NV} is {1,0,1} accesses ACTLR\_EL1 directly and is not transformed to a memory access.
- MRS/MSR to ACTLRALIAS\_EL1 behaves in the same way as ACTLR\_EL1.

If FEAT\_SRMASK is implemented, MSR to [ACTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-2-ACTLR-EL1--Auxiliary-Control-Register--EL1-?lang=en#reg_aarch64_actlr_el1) at EL1 are masked by [ACTLRMASK\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-5-ACTLRMASK-EL1--Auxiliary-Control-Masking-Register--EL1-?lang=en#reg_aarch64_actlrmask_el1).

        AArch64_SystemAccessTrap(EL2, 0x18);
    elsif EL2Enabled() && IsFeatureImplemented(FEAT_FGT2) && (!HaveEL(EL3) || SCR_EL3().FGTEn2 == '1') && HFGRTR2_EL2().ACTLR_EL1 == '1' then
        AArch64_SystemAccessTrap(EL2, 0x18);
    elsif EffectiveHCR_EL2_NVx() IN {'1x1'} && (!ImpDefBool("IMPLEMENTED_ACTLR_ELx accessor behavior") || EffectiveHCR_EL2_NVx() == '111') then
        X{64}(t) = NVMem(0x118);
    else
        X{64}(t) = ACTLR_EL1();
    end;
elsif PSTATE.EL == EL2 then
    if ImpDefBool("IMPLEMENTED_ACTLR_ELx accessor behavior") && ELIsInHost(EL2) then
        X{64}(t) = ACTLR_EL2();
    else
        X{64}(t) = ACTLR_EL1();
    end;
elsif PSTATE.EL == EL3 then
    X{64}(t) = ACTLR_EL1();
end;
