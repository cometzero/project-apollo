##### C6.2.279 MOV (inverted wide immediate)

Move inverted wide immediate value

This instruction moves an inverted 16-bit immediate value to a register.

This is an alias of [MOVN](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-284-MOVN?lang=en#isa_movn). This means:

- The encodings in this description are named to match the encodings of [MOVN](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-284-MOVN?lang=en#isa_movn).
- The description of [MOVN](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-284-MOVN?lang=en#isa_movn) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the 32-bit variant

Applies when `(sf == 0 && hw == 0x)`

```
MOV  <Wd>, #<imm>
```

is equivalent to

```
MOVN  <Wd>, #<imm16>, LSL  #<shift>
```

and is the preferred disassembly when `!(IsZero(imm16) && hw != '00') && !IsOnes(imm16)`.

###### Encoding for the 64-bit variant

Applies when `(sf == 1)`

```
MOV  <Xd>, #<imm>
```

is equivalent to

```
MOVN  <Xd>, #<imm16>, LSL  #<shift>
```

and is the preferred disassembly when `!(IsZero(imm16) && hw != '00')`.

###### Assembler Symbols

<Wd>
:   ​

    Is the 32-bit name of the general-purpose destination register, encoded in the “Rd” field.

<imm>
:   ​

    For the “32-bit” variant: is a 32-bit immediate, the bitwise inverse of which can be encoded in “imm16:hw”, but excluding `0xFFFF0000` and `0x0000FFFF`.

    ​

    For the “64-bit” variant: is a 64-bit immediate, the bitwise inverse of which can be encoded in “imm16:hw”.

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.
