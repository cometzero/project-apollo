# ​H2.2.7 Summary of actions from debug events

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-7-Summary-of-actions-from-debug-events>

##### H2.2.7 Summary of actions from debug events

[Table H2-1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-7-Summary-of-actions-from-debug-events?lang=en#tbl_babeifif) shows the Software and Halting debug events. In [Table H2-1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-7-Summary-of-actions-from-debug-events?lang=en#tbl_babeifif), the columns have the following meaning:

Debug event type
:   This means the type of debug event where:

    Other software
    :   Means one of:

        - [Software Step exceptions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-11-Software-Step-exceptions?lang=en#bcgiidaj).
        - [Breakpoint Instruction exceptions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-7-Breakpoint-Instruction-exceptions?lang=en#bcgiehag).
        - [Vector Catch exceptions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-10-Vector-Catch-exceptions?lang=en#bcgjgbcc) for AArch64 state or [Vector Catch exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G2-AArch32-Self-hosted-Debug/-G2-10-Vector-Catch-exceptions?lang=en#g2bcgjgbcc) for AArch32 state.

    Other Halting
    :   Means one of the following:

        - [Halting Step debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events?lang=en#babfcjha).
        - [External Debug Request debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-5-External-Debug-Request-debug-event?lang=en#babgjjbd).
        - [Reset Catch debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-7-Reset-Catch-debug-events?lang=en#babhbbeg).
        - [OS Unlock Catch debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-6-OS-Unlock-Catch-debug-event?lang=en#babcchic).

    Other debug events are referred to explicitly.

Authentication
:   This means halting is allowed by the IMPLEMENTATION DEFINED external authentication interface. It is the result of one of the following pseudocode functions:

    In Non-secure state
    :   [`ExternalInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-18-ExternalInvasiveDebugEnabled?lang=en#asl_func_externalinvasivedebugenabled_0)`()`.

    In Secure state
    :   [`ExternalSecureInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-25-ExternalSecureInvasiveDebugEnabled?lang=en#asl_func_externalsecureinvasivedebugenabled_0)`()`.

    In Realm state
    :   [`ExternalRealmInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-21-ExternalRealmInvasiveDebugEnabled?lang=en#asl_func_externalrealminvasivedebugenabled_0)`()`.

    In Root state
    :   [`ExternalRootInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-23-ExternalRootInvasiveDebugEnabled?lang=en#asl_func_externalrootinvasivedebugenabled_0)`()`.

DLK
:   This indicates whether [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) is implemented and locked, [`DoubleLockStatus`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-5-DoubleLockStatus?lang=en#asl_func_doublelockstatus_0)`()` == TRUE.

OSLK
:   This is the value of [OSLSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babeabbd).OSLK. It indicates whether the OS Lock is locked.

HDE
:   This is the value of [EDSCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-48-EDSCR--External-Debug-Status-and-Control-Register?lang=en#reg_ext_edscr).HDE. It indicates whether Halting debug is enabled.

The letter X in [Table H2-1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-7-Summary-of-actions-from-debug-events?lang=en#tbl_babeifif) indicates that the value can be either 0 or 1.
