# ​I5.3.27 PMDEVID, Performance Monitors Device ID register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-27-PMDEVID--Performance-Monitors-Device-ID-register>

##### I5.3.27 PMDEVID, Performance Monitors Device ID register

The PMDEVID characteristics are:

Purpose
:   Provides information about features of the Performance Monitors implementation.

Configuration
:   If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, this register is in the Core power domain. If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, this register is in the Debug power domain.

    This register is present only when (Armv8.2 or FEAT\_PCSRv8p2 is implemented) and FEAT\_PMUv3\_EXT is implemented. Otherwise, direct accesses to PMDEVID are RES0.

Attributes
:   PMDEVID is a 32-bit register.

    Access to this field is RO.

###### Accessing PMDEVID

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT is implemented and (Armv8.2 or FEAT\_PCSRv8p2 is implemented)
:   Accessible at offset `0xFC8` from PMU

    - When FEAT\_DoPD is implemented and !IsCorePowered(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RO.
