# ​C8.2.266 FRSQRTE

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-266-FRSQRTE>

##### C8.2.266 FRSQRTE

Floating-point reciprocal square root estimate (unpredicated)

This instruction finds the approximate reciprocal square root of each active floating-point element of the source vector, and places the results in the corresponding elements of the destination vector. This instruction is unpredicated.

###### SVE

###### (FEAT\_SVE || FEAT\_SME)

![](images/1929-C8.2.266-FRSQRTE-img01.svg)

###### Encoding

```
FRSQRTE  <Zd>.<T>, <Zn>.<T>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SVE) && !IsFeatureImplemented(FEAT_SME) then
    EndOfDecode(Decode_UNDEF);
end;
if size == ‘00’ then EndOfDecode(Decode_UNDEF); end;
let esize : integer{} = 8 << UInt(size);
let n : integer = UInt(Zn);
let d : integer = UInt(Zd);
```

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let elements : integer = VL DIV esize;
let operand : bits(VL) = Z{}(n);
var result : bits(VL);
for e = 0 to elements-1 do
    let element : bits(esize) = operand[e*:esize];
    result[e*:esize] = FPRSqrtEstimate{esize}(element, FPCR());
end;
Z{VL}(d) = result;
```
