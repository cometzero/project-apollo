# ​G8.2.3 ADFSR, Auxiliary Data Fault Status Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-3-ADFSR--Auxiliary-Data-Fault-Status-Register>

##### G8.2.3 ADFSR, Auxiliary Data Fault Status Register

The ADFSR characteristics are:

Purpose
:   Provides additional IMPLEMENTATION DEFINED fault status information for Data Abort exceptions taken to EL1 modes, and EL3 modes when EL3 is implemented and is using AArch32.

Configuration
:   AArch32 System register ADFSR bits [31:0] are architecturally mapped to AArch64 System register [AFSR0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-7-AFSR0-EL1--Auxiliary-Fault-Status-Register-0--EL1-?lang=en#reg_aarch64_afsr0_el1)[31:0].

    This register is banked between ADFSR and ADFSR\_S and ADFSR\_NS.

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ADFSR are UNDEFINED.

Attributes
:   ADFSR is a 32-bit register.

    This register has the following instances:

    - ADFSR, when EL3 is not implemented or FEAT\_AA64 is implemented.
    - ADFSR\_S, when FEAT\_AA32EL3 is implemented.
    - ADFSR\_NS, when FEAT\_AA32EL3 is implemented.

###### Field descriptions

![](images/6494-G8.2.3-ADFSR-Auxiliary-Data-Fault-Status-Register-img01.svg)

IMPLEMENTATION DEFINED, bits [31:0]
:   IMPLEMENTATION DEFINED.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
