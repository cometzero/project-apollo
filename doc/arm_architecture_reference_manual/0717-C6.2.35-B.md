# ​C6.2.35 B

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-35-B>

##### C6.2.35 B

Branch

This instruction branches unconditionally to a label at a PC-relative offset. This instruction provides a hint that this is not a subroutine call or return.

![](images/0717-C6.2.35-B-img01.svg)

###### Encoding

```
B  <label>
```

###### Decode for this encoding

```
let offset : bits(64) = SignExtend{}(imm26::‘00’);
```

###### Assembler Symbols

<label>
:   ​

    Is the program label to be unconditionally branched to. Its offset from the address of this instruction, in the range +/-128MB, is encoded as “imm26” times 4.

###### Operation

```
let branch_conditional : boolean = FALSE;
BranchTo{64}(PC64() + offset, BranchType_DIR, branch_conditional);
```
