# ​D20.4.1 PE error state recording in the exception syndrome

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-1-PE-error-state-recording-in-the-exception-syndrome>

##### D20.4.1 PE error state recording in the exception syndrome

R WPKYM
:   When an asynchronous SError exception is taken to AArch64 state, the PE records the [PE error state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions?lang=en#mdterm_pe_error_state) in the [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx) exception syndrome register as the applicable one of:

    - [Uncontainable (UC)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_uncontainable_pe_error).
    - [Unrecoverable state (UEU)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_unrecoverable_pe_error).
    - [Recoverable state (UER)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_recoverable_pe_error).
    - [Restartable state (UEO)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_restartable_pe_error).
    - [Corrected (CE)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_corrected_pe_error).
    - [Uncategorized error](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_uncategorized_pe_error).
    - [IMPLEMENTATION DEFINED syndrome](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_impdef_pe_error).

I SDDLL
:   When an asynchronous SError exception is taken to AArch64 state:

    - [Uncategorized error](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_uncategorized_pe_error) is recorded by setting [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).ISS to zero. This includes setting [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).IDS and [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).DFSC to zero.
    - [IMPLEMENTATION DEFINED syndrome](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_impdef_pe_error) is recorded by setting [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).IDS to `0b1`. The remainder of the [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).ISS syndrome is IMPLEMENTATION DEFINED.

    Other values for the [PE error state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions?lang=en#mdterm_pe_error_state) are recorded in [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).AET, by setting [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).IDS to `0b0` and [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).DFSC to the applicable nonzero fault status code, indicating [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).AET is valid.

R ZSKKG
:   If [FEAT\_RASv2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_rasv2) is implemented and any of the following are true, then an error exception is taken as an SError exception:

    - The error has been silently propagated by the PE.
    - The PE determines that software is not able to recover execution from the preferred return address of the exception.

R FKHHF
:   When a synchronous External abort exception is taken to AArch64 state, the PE records the [PE error state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions?lang=en#mdterm_pe_error_state) in [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).SET as the applicable one of the following:

    - If [FEAT\_RASv2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_rasv2) is not implemented, [Uncontainable (UC)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_uncontainable_pe_error).
    - [Recoverable state (UER)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_recoverable_pe_error).
    - [Restartable state (UEO)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_restartable_pe_error).

    Other values for the [PE error state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions?lang=en#mdterm_pe_error_state) are not supported by synchronous External abort exceptions taken to AArch64 state.

R PWKBL
:   When an asynchronous SError exception is taken to AArch32 state, the PE records the [PE error state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions?lang=en#mdterm_pe_error_state) in [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr).AET or [HSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-74-HSR--Hyp-Syndrome-Register?lang=en#reg_aarch32_hsr).AET as appropriate, as the applicable one of:

    - [Uncontainable (UC)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_uncontainable_pe_error).
    - [Unrecoverable state (UEU)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_unrecoverable_pe_error).
    - [Recoverable state (UER)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_recoverable_pe_error).
    - [Restartable state (UEO)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions/-D20-4-2-PE-error-state-classification?lang=en#mdterm_restartable_pe_error).

    Other values for the [PE error state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-4-Taking-error-exceptions?lang=en#mdterm_pe_error_state) are not supported by asynchronous SError exceptions taken to AArch32 state.
