##### H2.2.1 Halting allowed and halting prohibited

Halting can be either allowed or prohibited:

- Halting is always prohibited in Debug state.
- Halting is always prohibited when [`DoubleLockStatus`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-5-DoubleLockStatus?lang=en#asl_func_doublelockstatus_0)`()` == TRUE.

  - This means that [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) is implemented and OS Double lock is locked.
- Halting is also controlled by the IMPLEMENTATION DEFINED authentication interface, and is prohibited when all of the following apply:

  - The PE is in Non-secure state and [`ExternalInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-18-ExternalInvasiveDebugEnabled?lang=en#asl_func_externalinvasivedebugenabled_0)`()` == FALSE.
  - The PE is in Secure state and [`ExternalSecureInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-25-ExternalSecureInvasiveDebugEnabled?lang=en#asl_func_externalsecureinvasivedebugenabled_0)`()` == FALSE.
  - The PE is in Realm state and [`ExternalRealmInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-21-ExternalRealmInvasiveDebugEnabled?lang=en#asl_func_externalrealminvasivedebugenabled_0)`()` == FALSE.
  - The PE is in Root state and [`ExternalRootInvasiveDebugEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-23-ExternalRootInvasiveDebugEnabled?lang=en#asl_func_externalrootinvasivedebugenabled_0)`()` == FALSE.
- Otherwise, halting is allowed.
