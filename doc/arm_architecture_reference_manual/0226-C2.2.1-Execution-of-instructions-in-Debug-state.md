# ​C2.2.1 Execution of instructions in Debug state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C2-About-the-A64-Instruction-Descriptions/-C2-2-General-information-about-the-A64-instruction-descriptions/-C2-2-1-Execution-of-instructions-in-Debug-state>

##### C2.2.1 Execution of instructions in Debug state

In general, except for the instructions described in [Debug state](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-1-Branches--Exception-generating--and-System-instructions/-C3-1-5-Exception-generation-and-return?lang=en#chdihech), the A64 instruction descriptions do not indicate any differences in the behavior of the instruction if it is executed in Debug state. For this information, see [Executing instructions in Debug state](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-4-Behavior-in-Debug-state/-H2-4-2-Executing-instructions-in-Debug-state?lang=en#babhejjg).

> #### Note
>
> For many instructions, execution is unchanged in Debug state. [Executing instructions in Debug state](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-4-Behavior-in-Debug-state/-H2-4-2-Executing-instructions-in-Debug-state?lang=en#babhejjg) identifies these instructions.
