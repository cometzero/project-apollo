# ​D15.1 About the System Performance Monitors

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D15-The-System-Performance-Monitors-Extension/-D15-1-About-the-System-Performance-Monitors>

#### D15.1 About the System Performance Monitors

R XVHSR
:   A *System PMU* is a PMU other than the PMU implemented by a PE that is accessible to that PE. For more information on the PMU, see [The Performance Monitors Extension](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension?lang=en#babgefcf).

R KGSQX
:   A System PMU might be accessible to other PEs in the system.

I XDHVC
:   The System Performance Monitors Extension is an OPTIONAL feature of an implementation. The architecture does not require that System PMUs are implemented using [FEAT\_SPMU](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_spmu). Arm recommends that System PMUs are implemented using [FEAT\_SPMU](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_spmu) or *The CoreSight PMU Architecture*. [FEAT\_SPMU](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_spmu) and *The CoreSight PMU Architecture* share a conceptual model for performance monitors.

I DDTRR
:   The System Performance Monitors Extension supports up to 32 System PMUs.

I NYCYF
:   The basic form of a System PMU is:

    - A number of 64-bit event counters, [SPMEVCNTR<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-39-SPMEVCNTR-n--EL0--System-Performance-Monitors-Event-Count-Register--n---0---63?lang=en#reg_aarch64_spmevcntrn_el0). Each System PMU can support up to 64 event counters.
    - It is IMPLEMENTATION DEFINED whether the event counted by each event counter is fixed or programmable. Event configuration registers, [SPMEVTYPER<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-42-SPMEVTYPER-n--EL0--System-Performance-Monitors-Event-Type-Register--n---0---63?lang=en#reg_aarch64_spmevtypern_el0), [SPMEVFILTR<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-41-SPMEVFILTR-n--EL0--System-Performance-Monitors-Event-Filter-Control-Register--n---0---63?lang=en#reg_aarch64_spmevfiltrn_el0), and [SPMEVFILT2R<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-40-SPMEVFILT2R-n--EL0--System-Performance-Monitors-Event-Filter-Control-Register-2--n---0---63?lang=en#reg_aarch64_spmevfilt2rn_el0) are provided for this.
    - Controls for:

      - Enabling and resetting counters, in the System PMU control register [SPMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-36-SPMCR-EL0--System-Performance-Monitor-Control-Register?lang=en#reg_aarch64_spmcr_el0).
      - If [FEAT\_SPMU2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-6-The-Armv9-5-architecture-extension?lang=en#feat_feat_spmu2) is implemented, setting individual counters to zero, in [SPMZR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-51-SPMZR-EL0--System-Performance-Monitors-Zero-with-Mask?lang=en#reg_aarch64_spmzr_el0).
      - Count enable set and clear registers, [SPMCNTENSET\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-35-SPMCNTENSET-EL0--System-Performance-Monitors-Count-Enable-Set-Register?lang=en#reg_aarch64_spmcntenset_el0) and [SPMCNTENCLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-34-SPMCNTENCLR-EL0--System-Performance-Monitors-Count-Enable-Clear-Register?lang=en#reg_aarch64_spmcntenclr_el0), respectively.
      - Counter overflow set and clear registers, [SPMOVSSET\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-47-SPMOVSSET-EL0--System-Performance-Monitors-Overflow-Flag-Status-Set-Register?lang=en#reg_aarch64_spmovsset_el0) and [SPMOVSCLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-46-SPMOVSCLR-EL0--System-Performance-Monitors-Overflow-Flag-Status-Clear-Register?lang=en#reg_aarch64_spmovsclr_el0), respectively.
      - Interrupt enable set and clear registers, [SPMINTENSET\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-45-SPMINTENSET-EL1--System-Performance-Monitors-Interrupt-Enable-Set-Register?lang=en#reg_aarch64_spmintenset_el1) and [SPMINTENCLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-44-SPMINTENCLR-EL1--System-Performance-Monitors-Interrupt-Enable-Clear-Register?lang=en#reg_aarch64_spmintenclr_el1), respectively.
      - System PMU access control registers [SPMACCESSR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-31-SPMACCESSR-EL3--System-Performance-Monitors-Access-Register--EL3-?lang=en#reg_aarch64_spmaccessr_el3), [SPMACCESSR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-30-SPMACCESSR-EL2--System-Performance-Monitors-Access-Register--EL2-?lang=en#reg_aarch64_spmaccessr_el2), and [SPMACCESSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-29-SPMACCESSR-EL1--System-Performance-Monitors-Access-Register--EL1-?lang=en#reg_aarch64_spmaccessr_el1).
      - If Secure EL1 is implemented, an OPTIONAL Secure state observability control register [SPMSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-49-SPMSCR-EL1--System-Performance-Monitors-Secure-Control-Register?lang=en#reg_aarch64_spmscr_el1).
      - If [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is implemented, an OPTIONAL Root and Realm state observability control register [SPMROOTCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-48-SPMROOTCR-EL3--System-Performance-Monitors-Root-and-Realm-Control-Register?lang=en#reg_aarch64_spmrootcr_el3).
    - Read-only identification registers:

      - Implementation and architecture identification registers, [SPMIIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-43-SPMIIDR-EL1--System-PMU-Implementation-Identification-Register?lang=en#reg_aarch64_spmiidr_el1) and [SPMDEVARCH\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-38-SPMDEVARCH-EL1--System-Performance-Monitors-Device-Architecture-Register?lang=en#reg_aarch64_spmdevarch_el1), respectively.
      - If the System PMU is accessible to other PEs in the system, then affinity register [SPMDEVAFF\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-37-SPMDEVAFF-EL1--System-Performance-Monitors-Device-Affinity-Register?lang=en#reg_aarch64_spmdevaff_el1).
      - Implementation configuration register [SPMCFGR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-32-SPMCFGR-EL1--System-Performance-Monitors-Configuration-Register?lang=en#reg_aarch64_spmcfgr_el1).
      - If the System PMU implements more than one Counter Group, then Counter Group configuration registers [SPMCGCR<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-33-SPMCGCR-n--EL1--System-PMU-Counter-Group-Configuration-Registers--n---0---1?lang=en#reg_aarch64_spmcgcrn_el1).
