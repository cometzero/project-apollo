# ​D21.1.2 MPAM information bundles

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-1-About-MPAM/-D21-1-2-MPAM-information-bundles>

##### D21.1.2 MPAM information bundles

R BDJXQ
:   MPAM Requesters label every request to the memory system with an *MPAM information bundle*, comprising:

    - Two items that together identify a single partition:

      - A number called the [Partition Identifier (PARTID)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-?lang=en#mpam_partition_identifiers).
      - The [PARTID space](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-2-PARTID-spaces?lang=en#mpam_partid_spaces), for example Secure or Non-secure physical PARTID space.

      Each PARTID space defines a set of PARTIDs.

      Each PARTID corresponds to one partition.
    - A [Performance Monitoring Group (PMG)](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-4-Performance-Monitoring-Groups--PMGs-?lang=en#mpam_pmg).
