##### I2.3.1 The CNTCTLBase frame

The [CNTCTLBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-1-The-CNTCTLBase-frame?lang=en#tbl_bgbihgid) frame contains:

- An identification register for the features of the memory-mapped counter and timer implementation.
- Access controls for each [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) frame.
- A virtual offset register for frames that implement a virtual timer.

a. Access security restrictions in an implementation with multiple Security states. See the individual register descriptions and [CNTNSAR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-9-CNTNSAR--Counter-timer-Non-secure-Access-Register?lang=en#reg_ext_cntnsar) for details on the restrictions. In an implementation that supports only a single Security state all registers are accessible as shown in the *Type* column.

b. These registers are also defined in the System register interface to the Generic Timer, and therefore are also described in [Generic Timer registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers?lang=en#aarch64_generic_timer_registers) and [Generic Timer registers](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers?lang=en#aarch32_generic_timer_registers). The bit assignments of the registers are identical in the System register interface and in the memory-mapped system level interface.

c. Implemented for each value of *N* from 0 to 7 for which a [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) frame is implemented.

d. For more information, see the register descriptions.

e. Address is reserved, RAZ/WI if register not implemented.

All implementations of the Generic Timer include the virtual counter. Therefore, conceptually, all implementations include the [CNTVOFF](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-18-CNTVOFF--Counter-timer-Virtual-Offset?lang=en#reg_ext_cntvoff) register that defines the virtual offset between the physical count and the virtual count. If a memory-mapped Generic Timer component does not distinguish between real time and virtual time, then it can implement [CNTVOFF](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-18-CNTVOFF--Counter-timer-Virtual-Offset?lang=en#reg_ext_cntvoff) as RAZ/WI. Otherwise [CNTVOFF](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-18-CNTVOFF--Counter-timer-Virtual-Offset?lang=en#reg_ext_cntvoff) is an RW register, and Arm strongly recommends that the system only permits access to [CNTVOFF](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-18-CNTVOFF--Counter-timer-Virtual-Offset?lang=en#reg_ext_cntvoff) from EL2 or higher.
