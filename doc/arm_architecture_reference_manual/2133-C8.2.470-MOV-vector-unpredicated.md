##### C8.2.470 MOV (vector, unpredicated)

Move vector register (unpredicated)

This instruction copies the contents of the source vector register to the destination vector register. This instruction is unpredicated.

This is an alias of [ORR (vectors, unpredicated)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-499-ORR--vectors--unpredicated-?lang=en#isa_orr_z_zz). This means:

- The encodings in this description are named to match the encodings of [ORR (vectors, unpredicated)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-499-ORR--vectors--unpredicated-?lang=en#isa_orr_z_zz).
- The description of [ORR (vectors, unpredicated)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-499-ORR--vectors--unpredicated-?lang=en#isa_orr_z_zz) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
MOV  <Zd>.D, <Zn>.D
```

is equivalent to

```
ORR  <Zd>.D, <Zn>.D, <Zn>.D
```

and is the preferred disassembly when `Zn == Zm`.

###### Assembler Symbols

<Zd>
:   ​

    Is the name of the destination scalable vector register, encoded in the “Zd” field.

<Zn>
:   ​

    Is the name of the source scalable vector register, encoded in the “Zn” field.
