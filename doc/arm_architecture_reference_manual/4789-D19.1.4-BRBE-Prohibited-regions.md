# ​D19.1.4 BRBE Prohibited regions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-4-BRBE-Prohibited-regions>

##### D19.1.4 BRBE Prohibited regions

I NVWPM
:   An executable program might contain regions of code that are prohibited to generate [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record), and these regions are called BRBE Prohibited regions. These regions are usually associated with a different Security state or Exception level.

I DMPQZ
:   BRBE Prohibited regions are controlled by the following:

    - [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).E0BRE.
    - [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).E1BRE.
    - [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).E0HBRE.
    - [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).E2BRE.
    - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SBRBE.

I HPZWM
:   While executing outside a BRBE Prohibited region, [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) might not be generated because the Branch Record Buffer Extension has a number of filtering functions.

R FHGJN
:   Execution in AArch32 state is a BRBE Prohibited region.

R LPYBQ
:   Execution in Debug state is a BRBE Prohibited region.

R JWWFY
:   When [FEAT\_BRBEv1p1](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-4-The-Armv9-3-architecture-extension?lang=en#feat_feat_brbev1p1) and EL3 are implemented:

    - When [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).{E3BREC, E3BREW} is {`0b0`, `0b1`} or [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).{E3BREC, E3BREW} is {`0b1`, `0b0`}, self-hosted EL3 branch recording is enabled.
    - When [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).{E3BREC, E3BREW} is {`0b0`, `0b0`} or [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).{E3BREC, E3BREW} is {`0b1`, `0b1`}, self-hosted EL3 branch recording is disabled.

R GLKGW
:   Execution at EL3 is a BRBE Prohibited region when any of the following are true:

    - [FEAT\_BRBEv1p1](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-4-The-Armv9-3-architecture-extension?lang=en#feat_feat_brbev1p1) is not implemented.
    - Self-hosted EL3 branch recording is disabled.

R SFZQD
:   Execution at EL2 is a BRBE Prohibited region when any of the following are true:

    - [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).E2BRE is 0.
    - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SBRBE is `0b00`.
    - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SBRBE is `0b01` and the PE is in Secure state.

R YPHYG
:   Execution at EL1 is a BRBE Prohibited region when any of the following are true:

    - [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).E1BRE is 0.
    - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SBRBE is `0b00`.
    - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SBRBE is `0b01` and the PE is in Secure state.

R DBPCP
:   Execution at EL0 is a BRBE Prohibited region when any of the following are true:

    - EL2 is disabled in the current Security state or [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE is 0, and [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).E0BRE is 0.
    - EL2 is enabled in the current Security state and [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE is 1, and [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).E0HBRE is 0.
    - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SBRBE is `0b00`.
    - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SBRBE is `0b01` and the PE is in Secure state.

R YGGSC
:   While the PE is executing code from a BRBE Prohibited region, no data is captured in [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) that might provide information about execution in the BRBE Prohibited region.
