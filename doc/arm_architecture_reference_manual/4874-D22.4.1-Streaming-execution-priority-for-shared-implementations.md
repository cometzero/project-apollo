# ​D22.4.1 Streaming execution priority for shared implementations

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D22-The-Scalable-Matrix-Extension/-D22-4-Streaming-execution-priority/-D22-4-1-Streaming-execution-priority-for-shared-implementations>

##### D22.4.1 Streaming execution priority for shared implementations

I YYRZQ
:   Execution of certain instructions by a PE in *Streaming SVE mode* might experience a performance dependency on other PEs in the system that are also executing instructions in *Streaming SVE mode*. For example, this might occur when an SMCU is shared between PEs.

I WPQVV
:   The architecture provides a mechanism to control the streaming execution priority of a PE, in [SMPRI\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-187-SMPRI-EL1--Streaming-Mode-Priority-Register?lang=en#reg_aarch64_smpri_el1). The streaming execution priority of a PE is relative to the streaming execution priority of other PEs, when a performance dependency exists between PEs executing in *Streaming SVE mode*.

I KTYTD
:   An implementation that does not share SMCUs or has no performance dependency between PEs might not need to limit or prioritize execution of one PE relative to another.

I HQXBH
:   The streaming execution priority mechanism is optional.

D DGRTS
:   All PEs that share a given SMCU form a *Priority domain*.

D YQFWM
:   Different *Priority domains* represent unrelated SMCUs.

R WPVQK
:   All PEs in a *Priority domain* have the same value of [SMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-186-SMIDR-EL1--Streaming-Mode-Identification-Register?lang=en#reg_aarch64_smidr_el1).Affinity and [SMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-186-SMIDR-EL1--Streaming-Mode-Identification-Register?lang=en#reg_aarch64_smidr_el1).Affinity2.

R CVLSF
:   PEs in different *Priority domains* have different values of [SMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-186-SMIDR-EL1--Streaming-Mode-Identification-Register?lang=en#reg_aarch64_smidr_el1).Affinity or [SMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-186-SMIDR-EL1--Streaming-Mode-Identification-Register?lang=en#reg_aarch64_smidr_el1).Affinity2.

R GGDRC
:   The streaming execution priority in [SMPRI\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-187-SMPRI-EL1--Streaming-Mode-Priority-Register?lang=en#reg_aarch64_smpri_el1) affects execution of a PE relative to all other PEs in the same *Priority domain.*

R SBCRG
:   All SMCUs in the system have a consistent interpretation of the streaming execution priority values.

R RQXFC
:   The streaming execution priority mechanism affects the execution of instructions by a shared SMCU when the PE is in *Streaming SVE mode* and does not directly control the execution of other types of instruction.

I BLMYK
:   If system software does not support differentiation of streaming execution priority of threads, it is safe to use a value of 0 for all threads.

I YBQNW
:   The architecture considers *Priority domain* to be non-overlapping sets, meaning that in a shared-SMCU system, a PE is associated with at most one SMCU.

###### D22.4.1.1 Streaming execution context management

I PRNMJ
:   Arm expects that the SVE and SME instructions used by save, restore, and clear routines for the *Streaming SVE mode* SVE registers, the ZA storage, and the ZT0 register when [FEAT\_SME2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-4-The-Armv9-3-architecture-extension?lang=en#feat_feat_sme2) is implemented, are limited to using the following SME and SVE instructions:

    - SME [`LDR (array vector)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-157-LDR--array-vector-?lang=en#isa_ldr_za_ri) and [`STR (array vector)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-267-STR--array-vector-?lang=en#isa_str_za_ri) instructions.
    - SME2 [`LDR (table)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-158-LDR--table-?lang=en#isa_ldr_zt_br) and [`STR (table)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-268-STR--table-?lang=en#isa_str_zt_br) instructions.
    - SVE [`LDR (vector)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-437-LDR--vector-?lang=en#isa_ldr_z_bi) and [`STR (vector)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-777-STR--vector-?lang=en#isa_str_z_bi) instructions.
    - SVE [`LDR (predicate)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-436-LDR--predicate-?lang=en#isa_ldr_p_bi) and [`STR (predicate)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-776-STR--predicate-?lang=en#isa_str_p_bi) instructions.
    - SME [`ZERO (tiles)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-347-ZERO--tiles-?lang=en#isa_zero_za_i) instruction.
    - SME2 [`ZERO (table)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-348-ZERO--table-?lang=en#isa_zero_zt_i) instruction.
    - SVE [`DUP (immediate)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-128-DUP--immediate-?lang=en#isa_dup_z_i) instruction with zero immediate.
    - SVE [`PFALSE`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-504-PFALSE?lang=en#isa_pfalse_p) instruction.

    For implementations with a shared SMCU, PEs are expected to execute these instructions in a way that experiences a reduced effect of contention for the SMCU from other PEs, compared to other SME and SVE instructions executed in *Streaming SVE mode*.

###### D22.4.1.2 Streaming execution priority control

I RMDCP
:   The streaming execution priority is controlled by a 4-bit priority value. When the streaming execution priority mechanism is not supported, the priority value is ignored.

I FJQRG
:   A higher priority value corresponds to a higher streaming execution priority. Priority value `15` is the highest priority.

I QHKWP
:   The behavior of any given priority value relative to that of another PE is IMPLEMENTATION DEFINED.

###### D22.4.1.3 Streaming execution priority virtualization

I SQBCZ
:   The Effective streaming execution priority is either the value configured in [SMPRI\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-187-SMPRI-EL1--Streaming-Mode-Priority-Register?lang=en#reg_aarch64_smpri_el1) or, if EL2 is implemented and enabled in the current Security state, the value of [SMPRI\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-187-SMPRI-EL1--Streaming-Mode-Priority-Register?lang=en#reg_aarch64_smpri_el1) mapped into a new value by indexing the fields in [SMPRIMAP\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-188-SMPRIMAP-EL2--Streaming-Mode-Priority-Mapping-Register?lang=en#reg_aarch64_smprimap_el2). This choice is affected by the current Exception level, and the [HCRX\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-62-HCRX-EL2--Extended-Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcrx_el2).SMPME configuration.
