##### `0x007F`, CSDB\_SPEC, Barrier speculatively executed, CSDB

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) control speculation barrier instruction.

When FEAT\_PMUv3p8 is not implemented, this is an IMPLEMENTATION DEFINED event.
