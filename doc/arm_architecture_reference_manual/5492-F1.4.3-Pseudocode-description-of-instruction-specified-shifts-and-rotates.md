##### F1.4.3 Pseudocode description of instruction-specified shifts and rotates

The pseudocode enumeration [`SRType`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-76-SRType?lang=en#asl_type_srtype) `{}` defines the shift types. Shift and rotate instruction decode is described by the pseudocode function:

- [`DecodeImmShift`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-72-DecodeImmShift?lang=en#asl_func_decodeimmshift_2)`()` for a constant shift.
- [`DecodeRegShift`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-73-DecodeRegShift?lang=en#asl_func_decoderegshift_1)`()` for a register controlled shift.

Shift and rotate operations are made by the pseudocode function [`Shift`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-77-Shift?lang=en#asl_func_shift_5)`()`.
