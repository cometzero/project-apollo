# ​D6.5.2 Buffer full and buffer wrap events

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management/-D6-5-2-Buffer-full-and-buffer-wrap-events>

##### D6.5.2 Buffer full and buffer wrap events

R MBSHC
:   If the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is wrapped to the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) and the trace buffer mode is Fill mode, then all of the following occur:

    - A trace buffer management event is generated. This sets [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).IRQ to 1.
    - [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).WRAP is set to 1.
    - The [TRB\_WRAP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x400C--TRB-WRAP--Trace-buffer-current-write-pointer-wrapped?lang=en#event_trb_wrap) event is generated.
    - If [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).S is 0, then all of the following occur:

      - [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).S is set to 1, [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1).
      - [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).EC is set to `0x00`, other buffer management event.
      - [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).BSC is set to `0b000001`, buffer filled.

    ELx is defined by [RBNQRP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#bnqrp). See also [Table D6-7](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#tbl_tracebuffereventother). The other fields in [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) and the other [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) registers are unchanged.

    After the trace buffer management event, the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) will point to the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9).

R VBDJZ
:   If the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is wrapped to the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) and the trace buffer mode is Wrap mode, then all of the following occur:

    - A trace buffer management event is generated. This sets [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).IRQ to 1.
    - [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).WRAP is set to 1.
    - The [TRB\_WRAP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x400C--TRB-WRAP--Trace-buffer-current-write-pointer-wrapped?lang=en#event_trb_wrap) event is generated.

    Because [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).S is unchanged, trace continues to be collected and written to the trace buffer.

    ELx is defined by [RBNQRP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#bnqrp). See also [Table D6-7](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#tbl_tracebuffereventother). The other fields in [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) and the other [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) registers are unchanged.

R GDSTS
:   If the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is wrapped to the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9) and the trace buffer mode is Circular Buffer mode, then all of the following occur:

    - [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx).WRAP is set to 1, where ELx is the value in the *Other event* column of [Table D6-7](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-5-Trace-buffer-management?lang=en#tbl_tracebuffereventother). The other fields in [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) and the other [TRBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#trbsr_elx) registers are unchanged.
    - The [TRB\_WRAP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x400C--TRB-WRAP--Trace-buffer-current-write-pointer-wrapped?lang=en#event_trb_wrap) event is generated.

I VCDNP
:   If [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1), the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is not updated, meaning the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) is never wrapped when [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1).

S HKNBM
:   Software can configure the PMU to count the TRB\_WRAP event and monitor how many times the [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) has wrapped, particularly in Circular Buffer mode or Wrap mode.

I JSQPH
:   See also [Controlling generation of trace buffer management events](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K10-Software-Usage-Examples/-K10-5-Use-of-the-Embedded-Trace-and-Trace-Buffer-Extensions/-K10-5-10-Controlling-generation-of-trace-buffer-management-events?lang=en#mdsec_sw_usage_watermark).
