# ​G1.17.14 Additional pseudocode functions for exception handling

##### G1.17.14 Additional pseudocode functions for exception handling

The [`AArch32_EnterMonitorMode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-50-AArch32-EnterMonitorMode?lang=en#asl_func_aarch32_entermonitormode_3)`()` pseudocode function changes the PE mode to Monitor mode, with the required state changes.

The [`AArch32_EnterHypMode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-48-AArch32-EnterHypMode?lang=en#asl_func_aarch32_enterhypmode_3)`()` pseudocode function changes the PE mode to Hyp mode, with the required state changes.

The [`AArch32_EnterMode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-49-AArch32-EnterMode?lang=en#asl_func_aarch32_entermode_4)`()` pseudocode function changes the PE mode to a PL1 mode, with the required state changes. It is used for all exceptions that are not routed to Hyp mode or Monitor mode.

The [`AArch32_EnterMonitorMode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-50-AArch32-EnterMonitorMode?lang=en#asl_func_aarch32_entermonitormode_3)`()`, [`AArch32_EnterHypMode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-48-AArch32-EnterHypMode?lang=en#asl_func_aarch32_enterhypmode_3)`()`, and [`AArch32_EnterMode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-49-AArch32-EnterMode?lang=en#asl_func_aarch32_entermode_4)`()` functions are described in [A-profile Architecture Pseudocode](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode?lang=en#chap_pseudocode).
