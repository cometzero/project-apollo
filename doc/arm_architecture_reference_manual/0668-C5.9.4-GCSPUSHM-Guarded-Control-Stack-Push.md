# ​C5.9.4 GCSPUSHM, Guarded Control Stack Push

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-9-A64-System-instructions-for-the-Guarded-Control-Stack/-C5-9-4-GCSPUSHM--Guarded-Control-Stack-Push>

##### C5.9.4 GCSPUSHM, Guarded Control Stack Push

The GCSPUSHM characteristics are:

Purpose
:   Decrements the current GCS pointer register by the size of a GCS procedure return record and stores an entry to the Guarded Control Stack.

Configuration
:   This system instruction is present only when FEAT\_GCS is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to GCSPUSHM are UNDEFINED.

Attributes
:   GCSPUSHM is a 64-bit System instruction.

###### Field descriptions

![](images/0668-C5.9.4-GCSPUSHM-Guarded-Control-Stack-Push-img01.svg)

Input, bits [63:0]
:   Input value for GCS procedure return record.

###### Executing GCSPUSHM

This system instruction is an alias of the SYS instruction.

Accesses to this instruction use the following encodings in the System instruction encoding space:
