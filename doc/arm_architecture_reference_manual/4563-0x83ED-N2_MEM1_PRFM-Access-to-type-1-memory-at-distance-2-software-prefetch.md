##### `0x83ED`, N2\_MEM1\_PRFM, Access to type 1 memory at distance 2, software prefetch

The counter counts each software prefetch counted by [N2\_MEM\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E5--N2-MEM-PRFM--Access-to-memory-at-distance-2--software-prefetch?lang=en#event_n2_mem_prfm) to a first memory type at distance 2.

The definition of memory types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
