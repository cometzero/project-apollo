##### H9.5.36 CTIPIDR6, CTI Peripheral Identification Register 6

The CTIPIDR6 characteristics are:

Purpose
:   Provides information to identify a CTI component.

    For more information, see [‘About the Peripheral identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-4-About-the-Peripheral-identification-scheme?lang=en#babdfhah).

Configuration
:   CTIPIDR6 is in the Debug power domain

    This register is present only when FEAT\_CTI\_PIDR is implemented. Otherwise, direct accesses to CTIPIDR6 are RES0.

Attributes
:   CTIPIDR6 is a 32-bit register.

###### Field descriptions

![](images/7154-H9.5.36-CTIPIDR6-CTI-Peripheral-Identification-Register-6-img01.svg)

Bits [31:0]
:   Reserved, RES0.
