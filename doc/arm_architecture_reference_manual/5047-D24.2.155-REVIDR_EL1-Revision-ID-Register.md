# ​D24.2.155 REVIDR_EL1, Revision ID Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-155-REVIDR-EL1--Revision-ID-Register>

##### D24.2.155 REVIDR\_EL1, Revision ID Register

The REVIDR\_EL1 characteristics are:

Purpose
:   Provides implementation-specific minor revision information.

Configuration
:   If REVIDR\_EL1 has the same value as [MIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-136-MIDR-EL1--Main-ID-Register?lang=en#reg_aarch64_midr_el1), then its contents have no significance.

    AArch64 System register REVIDR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [REVIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-123-REVIDR--Revision-ID-Register?lang=en#reg_aarch32_revidr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to REVIDR\_EL1 are UNDEFINED.

Attributes
:   REVIDR\_EL1 is a 64-bit register.
