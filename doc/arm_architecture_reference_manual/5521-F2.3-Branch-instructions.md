a. These instructions do not exist in the A32 instruction set.

b. The range is determined by the instruction set of the BLX instruction, not of the instruction it branches to.

Branches to loaded and calculated addresses can be performed by `LDR`, `LDM` and data-processing instructions. For details, see [Load/store instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-6-Load-store-instructions?lang=en#chddedcg), [Load/store multiple instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-7-Load-store-multiple-instructions?lang=en#chdbgfhi), [Standard data-processing instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-4-Data-processing-instructions/-F2-4-1-Standard-data-processing-instructions?lang=en#babbgegh), and [Shift instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-4-Data-processing-instructions/-F2-4-2-Shift-instructions?lang=en#babjdibb).

In addition to the branch instructions shown in [Table F2-1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-3-Branch-instructions?lang=en#tbl_cfhfafjd):

- In the A32 instruction set, a data-processing instruction that targets the PC behaves as a branch instruction. For more information, see [Data-processing instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-4-Data-processing-instructions?lang=en#chddfdce).
- In the T32 and A32 instruction sets, a load instruction that targets the PC behaves as a branch instruction. For more information, see [Load/store instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-6-Load-store-instructions?lang=en#chddedcg).
