##### `0x8215`, L2D\_CACHE\_HITM\_RD, Level 2 data cache demand access hit modified, read

The counter counts each cache access counted by [L2D\_CACHE\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81C5--L2D-CACHE-HIT-RD--Level-2-data-cache-demand-access-hit--read?lang=en#event_l2d_cache_hit_rd) that accesses a previously modified cache location.
