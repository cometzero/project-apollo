# ​G8.2.110 JOSCR, Jazelle OS Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-110-JOSCR--Jazelle-OS-Control-Register>

##### G8.2.110 JOSCR, Jazelle OS Control Register

The JOSCR characteristics are:

Purpose
:   A Jazelle register, which provides operating system control of the Jazelle Extension.

Configuration
:   This register is present only when FEAT\_AA32 is implemented. Otherwise, direct accesses to JOSCR are UNDEFINED.

Attributes
:   JOSCR is a 32-bit register.

###### Field descriptions

![](images/6601-G8.2.110-JOSCR-Jazelle-OS-Control-Register-img01.svg)

Bits [31:0]
:   Reserved, RAZ/WI.
