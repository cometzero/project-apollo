# ​F5.1.262 TSB

##### F5.1.262 TSB

Trace Synchronization Barrier. This instruction is a barrier that synchronizes the trace operations of instructions, see [Trace Synchronization Barrier (TSB)](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-3-Definition-of-the-memory-model/-E2-3-5-Memory-barriers?lang=en#cjahfcid).

If [FEAT\_TRF](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_trf) is not implemented, this instruction executes as a `NOP`.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-262-TSB?lang=en#isa_tsb_a32_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-262-TSB?lang=en#isa_tsb_a32_iclass_t1)).

###### A1

###### (FEAT\_TRF)

![](images/5879-F5.1.262-TSB-img01.svg)

###### Encoding

```
TSB{<c>}{<q>}  CSYNC
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_TRF) then ExecuteAsNOP(); end;
if cond != ‘1110’ then UnpredictableProcedure(); end; // TSB must be encoded with AL condition
```

###### CONSTRAINED UNPREDICTABLE behavior

If `cond != '1110'`, then one of the following behaviors must occur:

- The instruction is UNDEFINED.
- The instruction executes as `NOP`.
- The instruction executes unconditionally.
- The instruction executes conditionally.

###### T1

###### (FEAT\_TRF)

![](images/5879-F5.1.262-TSB-img02.svg)

###### Encoding

```
TSB{<c>}{<q>}  CSYNC
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_TRF) then ExecuteAsNOP(); end;
if InITBlock() then UnpredictableProcedure(); end;
```

###### CONSTRAINED UNPREDICTABLE behavior

If `InITBlock()`, then one of the following behaviors must occur:

- The instruction is UNDEFINED.
- The instruction executes as `NOP`.
- The instruction executes unconditionally.
- The instruction executes conditionally.
