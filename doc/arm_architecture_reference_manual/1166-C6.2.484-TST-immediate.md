##### C6.2.484 TST (immediate)

Test bits (immediate)

This instruction performs a bitwise AND between a register value and an immediate value, and discards the results. It updates the condition flags based on the result.

This is an alias of [ANDS (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-16-ANDS--immediate-?lang=en#isa_ands_log_imm). This means:

- The encodings in this description are named to match the encodings of [ANDS (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-16-ANDS--immediate-?lang=en#isa_ands_log_imm).
- The description of [ANDS (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-16-ANDS--immediate-?lang=en#isa_ands_log_imm) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the 32-bit variant

Applies when `(sf == 0 && N == 0)`

```
TST  <Wn>, #<imm>
```

is equivalent to

```
ANDS  WZR, <Wn>, #<imm>
```

and is always the preferred disassembly.

###### Encoding for the 64-bit variant

Applies when `(sf == 1)`

```
TST  <Xn>, #<imm>
```

is equivalent to

```
ANDS  XZR, <Xn>, #<imm>
```

and is always the preferred disassembly.

###### Assembler Symbols

<Wn>
:   ​

    Is the 32-bit name of the general-purpose source register, encoded in the “Rn” field.

<imm>
:   ​

    Is the bitmask immediate. For encoding information, see [Logical (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-5-Data-processing---immediate/-C3-5-3-Logical--immediate-?lang=en#chdbgeib).

<Xn>
:   ​

    Is the 64-bit name of the general-purpose source register, encoded in the “Rn” field.
