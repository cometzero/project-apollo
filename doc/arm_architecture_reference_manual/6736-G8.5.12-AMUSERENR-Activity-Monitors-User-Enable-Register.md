# ​G8.5.12 AMUSERENR, Activity Monitors User Enable Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-12-AMUSERENR--Activity-Monitors-User-Enable-Register>

##### G8.5.12 AMUSERENR, Activity Monitors User Enable Register

The AMUSERENR characteristics are:

Purpose
:   Global user enable register for the activity monitors. Enables or disables EL0 access to the activity monitors. AMUSERENR is applicable to both the architected and the auxiliary counter groups.

Configuration
:   AArch32 System register AMUSERENR bits [31:0] are architecturally mapped to AArch64 System register [AMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-15-AMUSERENR-EL0--Activity-Monitors-User-Enable-Register?lang=en#reg_aarch64_amuserenr_el0)[31:0].

    This register is present only when FEAT\_AMUv1 is implemented and FEAT\_AA32 is implemented. Otherwise, direct accesses to AMUSERENR are UNDEFINED.

Attributes
:   AMUSERENR is a 32-bit register.

###### Field descriptions

![](images/6736-G8.5.12-AMUSERENR-Activity-Monitors-User-Enable-Register-img01.svg)

Bits [31:1]
:   Reserved, RES0.

EN, bit [0]
:   Traps EL0 accesses to the activity monitors registers to EL1.

    > #### Note
    >
    > - AMUSERENR can always be read at EL0 and is not governed by this bit.
    >
    > > #### Note

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
