# ​J1.2.705 AArch64_BlockDescSupported

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-705-AArch64-BlockDescSupported>

##### J1.2.705 AArch64\_BlockDescSupported

```
// AArch64_BlockDescSupported()
// ============================
// Determine whether a block descriptor is valid for the given granule size
// and level
func AArch64_BlockDescSupported(d128 : bit, ds : bit, tgx : TGx, level : integer) => boolean
begin
    case tgx of
        when TGx_4KB => return ((level == 0 && (ds == ‘1’ || d128 == ‘1’)) ||
                                level == 1 ||
                                level == 2);
        when TGx_16KB => return ((level == 1 && (ds == ‘1’ || d128 == ‘1’)) ||
                                  level == 2);
        when TGx_64KB => return ((level == 1 && (d128 == ‘1’ || AArch64_PAMax() >= 52)) ||
                                  level == 2);
    end;
    return FALSE;
end;
```
