# ​G8.7.5 CNTHP_TVAL, Counter-timer Hyp Physical Timer TimerValue register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-5-CNTHP-TVAL--Counter-timer-Hyp-Physical-Timer-TimerValue-register>

##### G8.7.5 CNTHP\_TVAL, Counter-timer Hyp Physical Timer TimerValue register

The CNTHP\_TVAL characteristics are:

Purpose
:   Holds the timer value for the Hyp mode physical timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch32 System register CNTHP\_TVAL bits [31:0] are architecturally mapped to AArch64 System register [CNTHP\_TVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-8-CNTHP-TVAL-EL2--Counter-timer-Physical-Timer-TimerValue-Register--EL2-?lang=en#reg_aarch64_cnthp_tval_el2)[31:0].

    This register is banked between CNTHP\_TVAL and CNTHP\_TVAL\_S and CNTHP\_TVAL\_NS.

    This register is present only when FEAT\_AA32 is implemented. Otherwise, direct accesses to CNTHP\_TVAL are UNDEFINED.

Attributes
:   CNTHP\_TVAL is a 32-bit register.

    This register has the following instances:

    - CNTHP\_TVAL, when EL3 is not implemented or FEAT\_AA64 is implemented.
    - CNTHP\_TVAL\_S, when FEAT\_AA32EL3 is implemented.
    - CNTHP\_TVAL\_NS, when FEAT\_AA32EL3 is implemented.

###### Field descriptions

![](images/6763-G8.7.5-CNTHP_TVAL-Counter-timer-Hyp-Physical-Timer-TimerValue-register-img01.svg)

TimerValue, bits [31:0]
:   The TimerValue view of the EL2 physical timer.

    On a read of this register:

    - If [CNTHP\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-3-CNTHP-CTL--Counter-timer-Hyp-Physical-Timer-Control-register?lang=en#reg_aarch32_cnthp_ctl).ENABLE is 0, the value returned is UNKNOWN.
    - If [CNTHP\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-3-CNTHP-CTL--Counter-timer-Hyp-Physical-Timer-Control-register?lang=en#reg_aarch32_cnthp_ctl).ENABLE is 1, the value returned is ([CNTHP\_CVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-4-CNTHP-CVAL--Counter-timer-Hyp-Physical-CompareValue-register?lang=en#reg_aarch32_cnthp_cval) - [CNTPCT](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-19-CNTPCT--Counter-timer-Physical-Count-register?lang=en#reg_aarch32_cntpct)).

    On a write of this register, [CNTHP\_CVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-4-CNTHP-CVAL--Counter-timer-Hyp-Physical-CompareValue-register?lang=en#reg_aarch32_cnthp_cval) is set to ([CNTPCT](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-19-CNTPCT--Counter-timer-Physical-Count-register?lang=en#reg_aarch32_cntpct) + TimerValue), where TimerValue is treated as a signed 32-bit integer.

    When [CNTHP\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-3-CNTHP-CTL--Counter-timer-Hyp-Physical-Timer-Control-register?lang=en#reg_aarch32_cnthp_ctl).ENABLE is 1, the timer condition is met when ([CNTPCT](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-19-CNTPCT--Counter-timer-Physical-Count-register?lang=en#reg_aarch32_cntpct) - [CNTHP\_CVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-4-CNTHP-CVAL--Counter-timer-Hyp-Physical-CompareValue-register?lang=en#reg_aarch32_cnthp_cval)) is greater than or equal to zero. This means that TimerValue acts like a 32-bit downcounter timer. When the timer condition is met:

    - [CNTHP\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-3-CNTHP-CTL--Counter-timer-Hyp-Physical-Timer-Control-register?lang=en#reg_aarch32_cnthp_ctl).ISTATUS is set to 1.
    - If [CNTHP\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-3-CNTHP-CTL--Counter-timer-Hyp-Physical-Timer-Control-register?lang=en#reg_aarch32_cnthp_ctl).IMASK is 0, an interrupt is generated.

    When [CNTHP\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-3-CNTHP-CTL--Counter-timer-Hyp-Physical-Timer-Control-register?lang=en#reg_aarch32_cnthp_ctl).ENABLE is 0, the TimerValue cannot be read but continues to decrement. When the timer is enabled, the TimerValue represents the elapsed time whether that time was spent enabled or disabled.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
