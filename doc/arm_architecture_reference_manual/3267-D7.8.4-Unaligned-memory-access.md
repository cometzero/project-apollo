##### D7.8.4 Unaligned memory access

The [`Mem`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-307-Mem?lang=en#asl_accessor_mem_3)`{size}()` accessor make accesses of the required type. If an access is not architecturally defined to be atomic, `Mem()` synthesizes accesses from multiple calls to [`AArch64_MemSingle`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-295-AArch64-MemSingle?lang=en#asl_accessor_aarch64_memsingle_4)`{}()`. It also reverses the byte order if the access is big-endian.
