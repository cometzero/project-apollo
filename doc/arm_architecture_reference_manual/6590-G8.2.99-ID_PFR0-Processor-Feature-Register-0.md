# ​G8.2.99 ID_PFR0, Processor Feature Register 0

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-99-ID-PFR0--Processor-Feature-Register-0>

##### G8.2.99 ID\_PFR0, Processor Feature Register 0

The ID\_PFR0 characteristics are:

Purpose
:   Gives top-level information about the instruction sets and other features supported by the PE in AArch32 state.

    Must be interpreted with [ID\_PFR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-100-ID-PFR1--Processor-Feature-Register-1?lang=en#reg_aarch32_id_pfr1).

    For general information about the interpretation of the ID registers, see [‘Principles of the ID scheme for fields in ID registers’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-1-About-the-AArch32-System-registers/-G8-1-3-Principles-of-the-ID-scheme-for-fields-in-ID-registers?lang=en#chdidagf).

Configuration
:   AArch32 System register ID\_PFR0 bits [31:0] are architecturally mapped to AArch64 System register [ID\_PFR0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-113-ID-PFR0-EL1--AArch32-Processor-Feature-Register-0?lang=en#reg_aarch64_id_pfr0_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ID\_PFR0 are UNDEFINED.

Attributes
:   ID\_PFR0 is a 32-bit register.
