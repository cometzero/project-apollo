# ​D24.10.7 CNTHP_CVAL_EL2, Counter-timer Physical Timer CompareValue Register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-7-CNTHP-CVAL-EL2--Counter-timer-Physical-Timer-CompareValue-Register--EL2->

##### D24.10.7 CNTHP\_CVAL\_EL2, Counter-timer Physical Timer CompareValue Register (EL2)

The CNTHP\_CVAL\_EL2 characteristics are:

Purpose
:   Holds the compare value for the EL2 physical timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch64 System register CNTHP\_CVAL\_EL2 bits [63:0] are architecturally mapped to AArch32 System register [CNTHP\_CVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-4-CNTHP-CVAL--Counter-timer-Hyp-Physical-CompareValue-register?lang=en#reg_aarch32_cnthp_cval)[63:0].

    This register is present only when (HaveEL(EL3) || (((!HaveEL(EL3)) && HaveEL(EL2)) && (!IsFeatureImplemented(FEAT\_SEL2)))) && IsFeatureImplemented(FEAT\_AA64). Otherwise, direct accesses to CNTHP\_CVAL\_EL2 are UNDEFINED.

Attributes
:   CNTHP\_CVAL\_EL2 is a 64-bit register.

###### Field descriptions

![](images/5351-D24.10.7-CNTHP_CVAL_EL2-Counter-timer-Physical-Timer-CompareValue-Register-EL2-img01.svg)

CompareValue, bits [63:0]
:   Holds the EL2 physical timer CompareValue.

    When [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ENABLE is 1, and TimerConditionMet is TRUE for the EL2 physical timer, the timer condition is met and all of the following are true:

    - [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ISTATUS is set to 1.
    - If [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).IMASK is 0, an interrupt is generated.

    TimerConditionMet is defined by [‘Operation of the CompareValue views of the timers’](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-2-The-AArch64-view-of-the-Generic-Timer/-D12-2-4-Timers?lang=en#chddaeaj).

    The CompareValue view of the timer acts like a 64-bit upcounter timer.

    When [CNTHP\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-6-CNTHP-CTL-EL2--Counter-timer-Hypervisor-Physical-Timer-Control-Register?lang=en#reg_aarch64_cnthp_ctl_el2).ENABLE is 0, the timer condition is not met, but [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) continues to count.

    If the Generic counter is implemented at a size less than 64 bits, then this field is permitted to be implemented at the same width as the counter, and the upper bits are RES0.

    The value of this field is treated as zero-extended in all counter calculations.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing CNTHP\_CVAL\_EL2

When the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, without explicit synchronization, accesses from EL2 using the accessor name `CNTHP_CVAL_EL2` or `CNTP_CVAL_EL0` are not guaranteed to be ordered with respect to accesses using the other accessor name.
