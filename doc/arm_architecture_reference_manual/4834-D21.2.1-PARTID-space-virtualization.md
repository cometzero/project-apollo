##### D21.2.1 PARTID space virtualization

I CCVLY
:   In an MPAM PE, if EL2 is implemented and enabled in the current Security state, and [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).HAS\_HCR indicates that the MPAM virtualization option is implemented, execution at EL0 and EL1 might produce a *virtual PARTID space*, that is translated to a *physical PARTID space*. For details, see [PARTID virtualization](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-/-D21-3-1-PARTID-virtualization?lang=en#mpam_partid_virtualization).
