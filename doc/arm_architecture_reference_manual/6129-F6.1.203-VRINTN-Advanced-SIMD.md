# ​F6.1.203 VRINTN (Advanced SIMD)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-203-VRINTN--Advanced-SIMD->

##### F6.1.203 VRINTN (Advanced SIMD)

Vector Round floating-point to integer to Nearest rounds a vector of floating-point values to integral floating-point values of the same size using the Round to Nearest rounding mode. A zero input gives a zero result with the same sign, an infinite input gives an infinite result with the same sign, and a NaN is propagated as for normal arithmetic.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-203-VRINTN--Advanced-SIMD-?lang=en#isa_vrintn_asimd_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-203-VRINTN--Advanced-SIMD-?lang=en#isa_vrintn_asimd_iclass_t1)).

###### A1

![](images/6129-F6.1.203-VRINTN-Advanced-SIMD-img01.svg)

###### Encoding for the 64-bit SIMD vector variant

Applies when `(Q == 0)`

```
VRINTN{<q>}.<dt>  <Dd>, <Dm>
```

###### Encoding for the 128-bit SIMD vector variant

Applies when `(Q == 1)`

```
VRINTN{<q>}.<dt>  <Qd>, <Qm>
```

###### Decode for all variants of this encoding

```
if op[2] != op[0] then See(“Related encodings”); end;
if Q == ‘1’ && (Vd[0] == ‘1’ || Vm[0] == ‘1’) then Undefined(); end;
if (size == ‘01’ && !IsFeatureImplemented(FEAT_FP16)) || size IN {‘00’, ‘11’} then Undefined(); end;
// Rounding encoded differently from other VCVT and VRINT instructions
let rounding : FPRounding = FPDecodeRM(op[2]::NOT(op[1]));
let exact : boolean = FALSE;
let esize : integer{} = 8 << UInt(size);
let elements : integer = 64 DIV esize;
let d : integer = UInt(D::Vd);
let m : integer = UInt(M::Vm);
let regs : integer = if Q == ‘0’ then 1 else 2;
```

let exact : boolean = FALSE;

###### CONSTRAINED UNPREDICTABLE behavior

If `InITBlock()`, then one of the following behaviors must occur:

- The instruction is UNDEFINED.
- The instruction executes as if it passes the Condition code check.
- The instruction executes as NOP. This means it behaves as if it fails the Condition code check.

Related encodings: See [Advanced SIMD two registers misc](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F3-T32-Instruction-Set-Encoding/-F3-1-T32-instruction-set-encoding/-F3-1-9-Advanced-SIMD-two-registers--or-three-registers-of-different-lengths?lang=en#t32_encoding_index_simd_2r_misc) for the T32 instruction set, or [Advanced SIMD two registers misc](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F4-A32-Instruction-Set-Encoding/-F4-1-A32-instruction-set-encoding/-F4-1-21-Advanced-SIMD-two-registers--or-three-registers-of-different-lengths?lang=en#a32_encoding_index_simd2reg_misc) for the A32 instruction set.

###### Operation

```
EncodingSpecificOperations();
CheckAdvSIMDEnabled();
let fpcr : FPCR_Type = StandardFPCR();
for r = 0 to regs-1 do
    for e = 0 to elements-1 do
        let operand1 : bits(esize) = D(m+r)[e*:esize];
        let result : bits(esize) = FPRoundInt{}(operand1, fpcr, rounding, exact);
        D(d+r)[e*:esize] = result;
    end;
end;
```
