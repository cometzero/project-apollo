# ​D11.3 Procedure returns

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns>

#### D11.3 Procedure returns

G BSBZN
:   [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) provides means to protect procedure return addresses.

G QLGCM
:   [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) provides means to record call stacks.

R MSYQB
:   A procedure return address push operation performs the following:

    1. Stores a doubleword to the virtual address defined by the current GCS pointer register minus the size of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record).
    2. Decrements the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr) by the size of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record).

R LWRMC
:   A procedure return address pop and compare operation performs the following:

    1. Loads a doubleword from the virtual address defined by the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr).
    2. The value in the record is compared with the value in the branch target register:

       - If the values are the same, increments the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr) by the size of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record).
       - If the values are not the same, a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception) is generated.

R BMMYF
:   A procedure return address pop operation performs the following:

    1. Loads a doubleword from the virtual address defined by the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr).
    2. Increments the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr) by the size of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record).

R QHNWF
:   The Guarded Control Stack at ELx has Return value checking enabled if [GCSCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#gcscr_elx).RVCHKEN is 1. x is any of 1, 2, 3.

    The Guarded Control Stack at EL0 has [Return value checking enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_return_value_checking_enabled) if [GCSCRE0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-11-Guarded-Control-Stack-registers/-D24-11-4-GCSCRE0-EL1--Guarded-Control-Stack-Control-Register--EL0-?lang=en#reg_aarch64_gcscre0_el1).RVCHKEN is 1.

R ZNPXD
:   The Guarded Control Stack at ELx has Return value checking disabled at ELx if the Guarded Control Stack at ELx does not have [Return value checking enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_return_value_checking_enabled).

I NLMNQ
:   If the Guarded Control Stack at ELx has [Return value checking disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_return_value_checking_disabled), this means the address present in the target register of a procedure return instruction is ignored and the top entry on the Guarded Control Stack is popped and used as the target address.

    For example, for a [`RET`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-338-RET?lang=en#isa_ret) instruction that uses the LR as the intended target address register, the value in LR is ignored.

I GNXCT
:   Irrespective of whether address tagging for instruction addresses is enabled or not, all 64 bits are compared in the compare operation of the [procedure return address pop and compare operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_procedure_return_address_pop_compare_operation).

I XFKQN
:   Guarded Control Stacks are defined as full-descending stacks and there are no controls provided to operate the Guarded Control Stacks as empty-descending stacks or ascending stacks.

D VKRDG
