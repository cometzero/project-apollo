##### H9.2.37 EDPIDR0, External Debug Peripheral Identification Register 0

The EDPIDR0 characteristics are:

Purpose
:   Provides information to identify an external debug component.

    For more information, see [‘About the Peripheral identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-4-About-the-Peripheral-identification-scheme?lang=en#babdfhah).

Configuration
:   When FEAT\_DoPD is implemented, EDPIDR0 is in the Core power domain. Otherwise, EDPIDR0 is in the Debug power domain

    This register is present only when FEAT\_ED\_PIDR is implemented. Otherwise, direct accesses to EDPIDR0 are RES0.

Attributes
:   EDPIDR0 is a 32-bit register.

###### Field descriptions

![](images/6987-H9.2.37-EDPIDR0-External-Debug-Peripheral-Identification-Register-0-img01.svg)

Bits [31:8]
:   Reserved, RES0.

PART\_0, bits [7:0]
:   Part number, which is selected by the designer of the component and stored as follows:

    - For a component with a 12-bit part number:
      - [EDPIDR1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-38-EDPIDR1--External-Debug-Peripheral-Identification-Register-1?lang=en#reg_ext_edpidr1).PART\_1 contains part number bits [11:8].
      - [EDPIDR0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-37-EDPIDR0--External-Debug-Peripheral-Identification-Register-0?lang=en#reg_ext_edpidr0).PART\_0 contains part number bits [7:0].
    - For a component with a 16-bit part number:
      - [EDPIDR1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-38-EDPIDR1--External-Debug-Peripheral-Identification-Register-1?lang=en#reg_ext_edpidr1).PART\_1 contains part number bits [15:12].
      - [EDPIDR0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-37-EDPIDR0--External-Debug-Peripheral-Identification-Register-0?lang=en#reg_ext_edpidr0).PART\_0 contains part number bits [11:4].
      - [EDPIDR2](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-39-EDPIDR2--External-Debug-Peripheral-Identification-Register-2?lang=en#reg_ext_edpidr2).REVISION contains part number bits [3:0].

    When a 12-bit part number is used, [EDPIDR2](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-39-EDPIDR2--External-Debug-Peripheral-Identification-Register-2?lang=en#reg_ext_edpidr2).REVISION indicates revision information.

    The choice of using a 12-bit part number or 16-bit part number is specific to the designer of the component.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
