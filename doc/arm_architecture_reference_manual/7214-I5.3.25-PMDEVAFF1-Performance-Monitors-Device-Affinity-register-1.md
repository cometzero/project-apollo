# ​I5.3.25 PMDEVAFF1, Performance Monitors Device Affinity register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-25-PMDEVAFF1--Performance-Monitors-Device-Affinity-register-1>

##### I5.3.25 PMDEVAFF1, Performance Monitors Device Affinity register 1

The PMDEVAFF1 characteristics are:

Purpose
:   Copy of the high half of the PE [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1) register that allows a debugger to determine which PE in a multiprocessor system the Performance Monitor component relates to.

Configuration
:   If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, this register is in the Core power domain. If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, this register is in the Debug power domain.

    This register is present only when FEAT\_PMUv3\_EXT32 is implemented.

Attributes
:   PMDEVAFF1 is a 32-bit register.

###### Field descriptions

![](images/7214-I5.3.25-PMDEVAFF1-Performance-Monitors-Device-Affinity-register-1-img01.svg)

Bits [31:8]
:   Reserved, RES0.

Aff3, bits [7:0]
:   Affinity level 3. See the description of [PMDEVAFF0](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-24-PMDEVAFF0--Performance-Monitors-Device-Affinity-register-0?lang=en#reg_pmu_pmdevaff0).Aff0 for more information.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

###### Accessing PMDEVAFF1

If [FEAT\_PMUv3\_EXT64](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-9-The-Armv8-8-architecture-extension?lang=en#feat_feat_pmuv3_ext64) is implemented, then the same content is present in the same location, and can be accessed using PMDEVAFF[63:32].

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT32 is implemented
:   Accessible at offset `0xFAC` from PMU

    - When FEAT\_DoPD is implemented and !IsCorePowered(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RO.
