##### H9.3.21 TRCDEVARCH, Trace Device Architecture Register

The TRCDEVARCH characteristics are:

Purpose
:   Provides discovery information for the component.

    For additional information, see the CoreSight Architecture Specification.

Configuration
:   External register TRCDEVARCH bits [31:0] are architecturally mapped to AArch64 System register [TRCDEVARCH](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-26-TRCDEVARCH--Trace-Device-Architecture-Register?lang=en#reg_aarch64_trcdevarch)[31:0].

    This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCDEVARCH are RES0.

Attributes
:   TRCDEVARCH is a 32-bit register.

###### Field descriptions

![](images/7025-H9.3.21-TRCDEVARCH-Trace-Device-Architecture-Register-img01.svg)

ARCHITECT, bits [31:21]
:   Defines the architect of the component. For Trace, this is Arm Limited.

    Bits [31:28] are the JEP106 continuation code, `0b0100`.

    Bits [27:21] are the JEP106 identification code, `0b0111011`.

    Reads as `0b01000111011`

    Access to this field is RO.

PRESENT, bit [20]
:   DEVARCH presence. Indicates that the TRCDEVARCH register provides architecture information.

    Reads as `0b1`

    Access to this field is RO.

REVISION, bits [19:16]
:   Revision. Defines the architecture revision of the component.

    The value of this field is an IMPLEMENTATION DEFINED choice of:
