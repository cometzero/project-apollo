##### `0x82A1`, INST\_FETCH\_RD, Instruction memory access, demand fetch

The counter counts each fetch counted by [INST\_FETCH](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8124--INST-FETCH--Instruction-memory-access?lang=en#event_inst_fetch) that is a demand [Instruction memory access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cachjjbe).

This includes any fetch made for a speculative instruction.
