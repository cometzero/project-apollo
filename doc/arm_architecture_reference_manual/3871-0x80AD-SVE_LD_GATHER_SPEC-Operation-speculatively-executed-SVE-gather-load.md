##### `0x80AD`, SVE\_LD\_GATHER\_SPEC, Operation speculatively executed, SVE gather-load

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) operation that reads from memory counted by [SVE\_LDST\_NONCONTIG\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x80AC--SVE-LDST-NONCONTIG-SPEC--Operation-speculatively-executed--SVE-non-contiguous-load--store--or-prefetch?lang=en#event_sve_ldst_noncontig_spec) due to an SVE non-contiguous gather-load instruction.
