Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-10-Alternate-BFloat16-behaviors>

##### A1.5.10 Alternate BFloat16 behaviors

The behaviors in this section apply to the following instructions:

- Advanced SIMD&FP: `BFCVT`, `BFCVTN`, `BFCVTN2`, `BFMLALB`, `BFMLALT`.
- SVE: `BFCVT`, `BFCVTNT`, `BFMLALB`, `BFMLALT`, `BFMLSLB`, `BFMLSLT`.
- SME: `BFCVT` (single-precision to BFloat16), `BFCVTN`.

[Table A1-6](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-4-Summary-of-BFloat16-instruction-behaviors?lang=en#tbl_babcbhidb1) and [Table A1-7](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-4-Summary-of-BFloat16-instruction-behaviors?lang=en#tbl_babggbdfh3) describe when these instructions are legal.

When [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).AH is 1, the instructions:

- Produce the expected IEEE 754 default result but do not update the [FPSR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-10-FPSR--Floating-point-Status-Register?lang=en#reg_aarch64_fpsr) cumulative exception flag bits.
- Disable trapped floating-point exceptions, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{IDE, IXE, UFE, OFE, DZE, IOE} are all 0.
- Use Round to Nearest Even, ignoring [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).RMode.
- Flush denormalized inputs and outputs to zero, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{FZ, FIZ} is {1, 1}.
