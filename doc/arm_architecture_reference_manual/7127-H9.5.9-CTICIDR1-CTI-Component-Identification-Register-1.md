##### H9.5.9 CTICIDR1, CTI Component Identification Register 1

The CTICIDR1 characteristics are:

Purpose
:   Provides information to identify a CTI component.

    For more information, see [‘About the Component Identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-5-About-the-Component-Identification-scheme?lang=en#babbfiid).

Configuration
:   CTICIDR1 is in the Debug power domain

Attributes
:   CTICIDR1 is a 32-bit register.

###### Field descriptions

![](images/7127-H9.5.9-CTICIDR1-CTI-Component-Identification-Register-1-img01.svg)

Bits [31:8]
:   Reserved, RES0.

CLASS, bits [7:4]
:   When FEAT\_CTI\_PIDR is implemented:
    :   Component class.

        This field reads as `0x9`.

        Access to this field is RO.

    Otherwise:
    :   Reserved, RAZ.

PRMBL\_1, bits [3:0]
:   When FEAT\_CTI\_PIDR is implemented:
    :   Preamble.

        Reads as `0b0000`

        Access to this field is RO.

    Otherwise:
    :   Reserved, RAZ.
