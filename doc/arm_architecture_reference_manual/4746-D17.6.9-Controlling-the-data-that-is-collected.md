# ​D17.6.9 Controlling the data that is collected

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-6-The-profiling-data/-D17-6-9-Controlling-the-data-that-is-collected>

##### D17.6.9 Controlling the data that is collected

Certain data in sample records is collected only if permitted by one or both of EL1 and EL2. This is to restrict exposure of data to a lower Exception level or to Non-secure state.

[CONTEXTIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-33-CONTEXTIDR-EL1--Context-ID-Register--EL1-?lang=en#reg_aarch64_contextidr_el1) is collected only if [PMSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-8-PMSCR-EL1--Statistical-Profiling-Control-Register--EL1-?lang=en#reg_aarch64_pmscr_el1).CX is set to 1, the PE is executing at EL1 or EL0 and any of the following are true when an operation is sampled:

- EL2 is not implemented.
- [FEAT\_SEL2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_sel2) is implemented and EL2 is disabled for the current Security state.
- The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE is 0.

[CONTEXTIDR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-34-CONTEXTIDR-EL2--Context-ID-Register--EL2-?lang=en#reg_aarch64_contextidr_el2) is collected only if the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMSCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-9-PMSCR-EL2--Statistical-Profiling-Control-Register--EL2-?lang=en#reg_aarch64_pmscr_el2).CX is 1 and EL2 is implemented and enabled for the current Security state.

This is described in the pseudocode functions [`CollectContextIDR1`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-51-CollectContextIDR1?lang=en#asl_func_collectcontextidr1_0)`()` and [`CollectContextIDR2`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-52-CollectContextIDR2?lang=en#asl_func_collectcontextidr2_0)`()`.

Timestamps are collected only if one of the following is true:

- [PMSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-8-PMSCR-EL1--Statistical-Profiling-Control-Register--EL1-?lang=en#reg_aarch64_pmscr_el1).TS is set to 1 and the Profiling Buffer is owned by EL1.
- [PMSCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-9-PMSCR-EL2--Statistical-Profiling-Control-Register--EL2-?lang=en#reg_aarch64_pmscr_el2).TS is set to 1 and the Profiling Buffer is owned by EL2.

The timestamp is a choice between:

- Physical time, which is defined by the physical count value returned by [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()`.
- If [FEAT\_ECV](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_ecv) is implemented, offset physical time, which is defined as the value of [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()` minus a physical offset.
- Virtual time, which is defined as the value of [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()` minus a virtual offset.

[Table D17-3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-6-The-profiling-data/-D17-6-9-Controlling-the-data-that-is-collected?lang=en#tbl_babbejai) summarizes the choice of value for the Timestamp packet when [FEAT\_ECV](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_ecv) is implemented and [`StatisticalProfilingEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-125-StatisticalProfilingEnabled?lang=en#asl_func_statisticalprofilingenabled_1)`()` is TRUE. In [Table D17-3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-6-The-profiling-data/-D17-6-9-Controlling-the-data-that-is-collected?lang=en#tbl_babbejai):

Owning EL
:   This is the Exception level that owns the Profiling Buffer. This is returned by the function [`ProfilingBufferOwner`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-66-ProfilingBufferOwner?lang=en#asl_func_profilingbufferowner_0)`()`. If EL2 is disabled in the current Security state, this is always EL1.

EL2 enabled
:   This is TRUE when EL2 is enabled in the current Security state. When EL2 is disabled in the current Security state, this is FALSE.

Virtual offset
:   The virtual offset is treated as zero if a read of [CNTVCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register?lang=en#reg_aarch64_cntvct_el0) at the current Exception level would treat the virtual offset as zero. Therefore if any of the following are true, the virtual offset is zero:

    - EL2 is not implemented.
    - The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, and the sampled operation was executed at EL2.
    - The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is {1, 1}, and the sampled operation was executed at EL0.

    Otherwise the virtual offset is the value of [CNTVOFF\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-27-CNTVOFF-EL2--Counter-timer-Virtual-Offset-Register?lang=en#reg_aarch64_cntvoff_el2).

Physical offset
:   If any of the following are true, the physical offset is zero:

    - EL2 is not implemented.
    - [FEAT\_ECV\_POFF](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_ecv_poff) is not implemented.
    - [CNTHCTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-2-CNTHCTL-EL2--Counter-timer-Hypervisor-Control-Register?lang=en#reg_aarch64_cnthctl_el2).ECV is 0.
    - EL3 is implemented and [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).ECVEn is 0.

    Otherwise the physical offset is the value of [CNTPOFF\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-18-CNTPOFF-EL2--Counter-timer-Physical-Offset-Register?lang=en#reg_aarch64_cntpoff_el2).

If EL2 is not implemented, see the register descriptions of [PMSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-8-PMSCR-EL1--Statistical-Profiling-Control-Register--EL1-?lang=en#reg_aarch64_pmscr_el1).PCT and [PMSCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-9-PMSCR-EL2--Statistical-Profiling-Control-Register--EL2-?lang=en#reg_aarch64_pmscr_el2).PCT for details of their behavior. This behavior is described by the pseudocode function [`CollectTimeStamp`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-54-CollectTimeStamp?lang=en#asl_func_collecttimestamp_0)`()`.

Physical data addresses are collected only if one of the following is true:

- The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-8-PMSCR-EL1--Statistical-Profiling-Control-Register--EL1-?lang=en#reg_aarch64_pmscr_el1).PA is 1, the Effective value of [PMSCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-9-PMSCR-EL2--Statistical-Profiling-Control-Register--EL2-?lang=en#reg_aarch64_pmscr_el2).PA is 1, and the Profiling Buffer is owned by EL1.
- The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMSCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-9-PMSCR-EL2--Statistical-Profiling-Control-Register--EL2-?lang=en#reg_aarch64_pmscr_el2).PA is 1 and the Profiling Buffer is owned by EL2.

If EL2 is not implemented or is disabled for the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_ss), then the Effective value of [PMSCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-9-PMSCR-EL2--Statistical-Profiling-Control-Register--EL2-?lang=en#reg_aarch64_pmscr_el2).PA is 1.
