##### D5.3.47 Q with count Packet

Purpose
:   Indicates that some instructions have executed.

Configurations
:   All.

###### Field descriptions

:   Continuation Bit.

    The encoding for this field is Unary code.

:   The number of instructions executed.

    The encoding for this field is unsigned LE128n.
