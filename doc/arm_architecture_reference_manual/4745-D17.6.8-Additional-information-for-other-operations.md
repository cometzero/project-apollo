##### D17.6.8 Additional information for other operations

For a sampled operation that does not use any of the [Operation Type packet](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D18-Statistical-Profiling-Extension-Sample-Record-Specification/-D18-2-Alphabetical-list-of-Statistical-Profiling-Extension-packets/-D18-2-7-Operation-Type-packet?lang=en#packet_spe_operation_type_packet) formats defined in the previous sections, it will use the Other format [Operation Type packet](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D18-Statistical-Profiling-Extension-Sample-Record-Specification/-D18-2-Alphabetical-list-of-Statistical-Profiling-Extension-packets/-D18-2-7-Operation-Type-packet?lang=en#packet_spe_operation_type_packet). This indicates:

- Whether the instruction was conditional or not. See [Additional information for each profiled conditional instruction](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-6-The-profiling-data/-D17-6-5-Additional-information-for-each-profiled-conditional-instruction?lang=en#babeifjfa0).
- If [FEAT\_SPE\_FPF](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-6-The-Armv9-5-architecture-extension?lang=en#feat_feat_spe_fpf) is implemented, whether the operation is Advanced SIMD or scalar.
- If [FEAT\_SPE\_FPF](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-6-The-Armv9-5-architecture-extension?lang=en#feat_feat_spe_fpf) is implemented, whether the operation is floating-point or not floating-point.

For cache maintenance operations by virtual address, cache prefetch other than SVE cache prefetch, or address translation instructions, the profiling operation:

- Generates an Other format [Operation Type packet](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D18-Statistical-Profiling-Extension-Sample-Record-Specification/-D18-2-Alphabetical-list-of-Statistical-Profiling-Extension-packets/-D18-2-7-Operation-Type-packet?lang=en#packet_spe_operation_type_packet).
- Captures an IMPLEMENTATION DEFINED subset of the information captured for a load instruction. See [Additional information for each profiled memory access operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-6-The-profiling-data/-D17-6-4-Additional-information-for-each-profiled-memory-access-operation?lang=en#cacchejc).
- Is not treated as a load or a store when filtering based on operation type. See [Filtering sample records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-5-Filtering-sample-records?lang=en#chdbdddi).
