# ​D2.9.2 Accessing watchpoint System registers

##### D2.9.2 Accessing watchpoint System registers

R MLRFY
:   The rules in [Accessing breakpoint System registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-8-Breakpoint-exceptions/-D2-8-2-Accessing-breakpoint-System-registers?lang=en#babdceabe8) that apply to [MDSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-21-MDSELR-EL1--Breakpoint-and-Watchpoint-Selection-Register?lang=en#reg_aarch64_mdselr_el1).BANK when accessing breakpoint registers also apply to watchpoint registers. See [RMLTYN](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-8-Breakpoint-exceptions/-D2-8-2-Accessing-breakpoint-System-registers?lang=en#mltyn), [RJGQGB](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-8-Breakpoint-exceptions/-D2-8-2-Accessing-breakpoint-System-registers?lang=en#jgqgb), and [IHMNFZ](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-8-Breakpoint-exceptions/-D2-8-2-Accessing-breakpoint-System-registers?lang=en#hmnfz).

R YKKCH
:   The `MRS` and `MSR` System register names for accessing breakpoint control registers [DBGWCR<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-11-DBGWCR-n--EL1--Debug-Watchpoint-Control-Registers--n---0---63?lang=en#reg_aarch64_dbgwcrn_el1) and breakpoint value registers [DBGWVR<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-12-DBGWVR-n--EL1--Debug-Watchpoint-Value-Registers--n---0---63?lang=en#reg_aarch64_dbgwvrn_el1) are mapped to physical registers as follows:

    - The register names DBGWCR0\_EL1 through DBGWCR15\_EL1 are mapped to the physical registers DBGWCR<BANK×16+0>\_EL1 through DBGWCR<BANK×16+15>\_EL1.
    - The register names DBGWVR0\_EL1 through DBGWVR15\_EL1 are mapped to the physical registers DBGWVR<BANK×16+0>\_EL1 through DBGWVR<BANK×16+15>\_EL1.

I XMTTT
:   `MSR` and `MRS` instructions using the watchpoint System register names in [RYKKCH](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-9-Watchpoint-exceptions/-D2-9-2-Accessing-watchpoint-System-registers?lang=en#ykkch) make indirect reads of [MDSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-21-MDSELR-EL1--Breakpoint-and-Watchpoint-Selection-Register?lang=en#reg_aarch64_mdselr_el1).BANK. This means that direct writes to [MDSELR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-21-MDSELR-EL1--Breakpoint-and-Watchpoint-Selection-Register?lang=en#reg_aarch64_mdselr_el1).BANK must be explicitly synchronized before a direct read or direct write using any of these System register names.
