##### `0x8098`, SVE\_LDST\_ZREG\_SPEC, Operation speculatively executed, SVE load or store vector register

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) SVE vector register load or store operation due to any of the following instructions:

- SVE: LDR (vector) or STR (vector).
