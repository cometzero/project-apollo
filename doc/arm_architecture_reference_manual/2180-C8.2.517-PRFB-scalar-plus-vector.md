# ​C8.2.517 PRFB (scalar plus vector)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-517-PRFB--scalar-plus-vector->

##### C8.2.517 PRFB (scalar plus vector)

Gather prefetch bytes (scalar plus vector)

This instruction performs a gather prefetch of bytes from the active memory addresses generated by a 64-bit scalar base plus vector index. The index values are optionally sign-extended or zero-extended from 32 to 64 bits. Inactive addresses are not prefetched from memory.

The `<prfop>` operand specifies the prefetch hint as follows:

- Access type:
  - PLD for prefetch for load.
  - PST for prefetch for store.
- Target cache level:
  - L1 for Level 1 cache.
  - L2 for Level 2 cache.
  - L3 for Level 3 cache.
- Policy:
  - KEEP for retained or temporal prefetch, allocated in the cache normally.
  - STRM for streaming or non-temporal prefetch, for data that is used only once.

This instruction is illegal when executed in Streaming SVE mode, unless FEAT\_SME\_FA64 is implemented and enabled.

It has encodings from 3 classes: [32-bit scaled offset](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-517-PRFB--scalar-plus-vector-?lang=en#isa_prfb_i_p_bz_iclass_32_bit_scaled_offset), [32-bit unpacked scaled offset](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-517-PRFB--scalar-plus-vector-?lang=en#isa_prfb_i_p_bz_iclass_32_bit_unpacked_scaled_offset), and [64-bit scaled offset](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-517-PRFB--scalar-plus-vector-?lang=en#isa_prfb_i_p_bz_iclass_64_bit_scaled_offset)

###### Operation

```
CheckNonStreamingSVEEnabled();
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let elements : integer = VL DIV esize;
let mask : bits(PL) = P{}(g);
var base : bits(64);
var offset : bits(VL);
if AnyActiveElement{PL}(mask, esize) then
    base = if n == 31 then SP{64}() else X{64}(n);
    offset = Z{VL}(m);
end;
for e = 0 to elements-1 do
    if ActivePredicateElement{PL}(mask, e, esize) then
        let offselt : bits(offs_size) = offset[e*:esize][offs_size-1:0];
        let off : integer = if offs_unsigned then UInt(offselt) else SInt(offselt);
        let addr : bits(64) = base + (off << scale);
        Hint_Prefetch(addr, pref_hint, level, stream);
    end;
end;
```
