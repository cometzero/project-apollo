# ​J1.2.663 AArch64_PermissionOverlaysApplied

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-663-AArch64-PermissionOverlaysApplied>

##### J1.2.663 AArch64\_PermissionOverlaysApplied

```
// AArch64_PermissionOverlaysApplied()
// ===================================
// Returns TRUE if Permission overlays are applied for the given access type.
func AArch64_PermissionsOverlaysApplied(acctype : AccessType) => boolean
begin
    case acctype of
        when AccessType_SPE        => return FALSE;
        when AccessType_TRBE       => return FALSE;
        otherwise                  => return TRUE;
    end;
end;
```
