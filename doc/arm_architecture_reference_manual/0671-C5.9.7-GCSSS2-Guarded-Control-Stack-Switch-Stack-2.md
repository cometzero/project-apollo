# ​C5.9.7 GCSSS2, Guarded Control Stack Switch Stack 2

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-9-A64-System-instructions-for-the-Guarded-Control-Stack/-C5-9-7-GCSSS2--Guarded-Control-Stack-Switch-Stack-2>

##### C5.9.7 GCSSS2, Guarded Control Stack Switch Stack 2

The GCSSS2 characteristics are:

Purpose
:   Validates that the most recent entry of the Guarded Control Stack that is getting switched to contains an In-progress GCS cap record, stores a Valid GCS cap record to the Guarded Control Stack that is getting switched from, and sets Xt to the address of that Valid GCS cap record.

Configuration
:   This system instruction is present only when FEAT\_GCS is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to GCSSS2 are UNDEFINED.

Attributes
:   GCSSS2 is a 64-bit System instruction.

###### Field descriptions

![](images/0671-C5.9.7-GCSSS2-Guarded-Control-Stack-Switch-Stack-2-img01.svg)

OA, bits [63:0]
:   Outgoing address, for the outgoing Guarded Control Stack.

###### Executing GCSSS2

This system instruction is an alias of the SYSL instruction.

Accesses to this instruction use the following encodings in the System instruction encoding space:
