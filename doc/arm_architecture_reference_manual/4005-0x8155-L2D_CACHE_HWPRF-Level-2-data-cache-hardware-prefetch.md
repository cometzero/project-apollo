##### `0x8155`, L2D\_CACHE\_HWPRF, Level 2 data cache hardware prefetch

The counter counts each access counted by [L2D\_CACHE\_PRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8285--L2D-CACHE-PRF--Level-2-data-cache--prefetch-hit?lang=en#event_l2d_cache_prf) that is due to a hardware prefetch.

The hardware prefetch is generated by a hardware prefetcher at the Level 2 data or unified cache.
