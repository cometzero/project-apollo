# ​G8.4.19 PMXEVCNTR, Performance Monitors Selected Event Count Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-19-PMXEVCNTR--Performance-Monitors-Selected-Event-Count-Register>

##### G8.4.19 PMXEVCNTR, Performance Monitors Selected Event Count Register

The PMXEVCNTR characteristics are:

Purpose
:   Reads or writes the value of the selected event counter, [PMEVCNTR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-10-PMEVCNTR-n---Performance-Monitors-Event-Count-Registers--n---0---30?lang=en#reg_aarch32_pmevcntrn). [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL determines which event counter is selected.

Configuration
:   AArch32 System register PMXEVCNTR bits [31:0] are architecturally mapped to AArch64 System register [PMXEVCNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-26-PMXEVCNTR-EL0--Performance-Monitors-Selected-Event-Count-Register?lang=en#reg_aarch64_pmxevcntr_el0)[31:0].

    This register is present only when FEAT\_AA32 is implemented and FEAT\_PMUv3 is implemented. Otherwise, direct accesses to PMXEVCNTR are UNDEFINED.

Attributes
:   PMXEVCNTR is a 32-bit register.

###### Field descriptions

![](images/6722-G8.4.19-PMXEVCNTR-Performance-Monitors-Selected-Event-Count-Register-img01.svg)

PMEVCNTR<n>, bits [31:0]
:   Value of the selected event counter, [PMEVCNTR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-10-PMEVCNTR-n---Performance-Monitors-Event-Count-Registers--n---0---30?lang=en#reg_aarch32_pmevcntrn), where n is the value stored in [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL.

    If [FEAT\_PMUv3p5](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-6-The-Armv8-5-architecture-extension?lang=en#feat_feat_pmuv3p5) is implemented, the event counter is 64 bits and only the least-significant part of the event counter is accessible in AArch32 state:

    - Reads from PMXEVCNTR return bits [31:0] of the counter.
    - Writes to PMXEVCNTR update bits [31:0] and leave bits [63:32] unchanged.
    - There is no means to access bits [63:32] directly from AArch32 state.
    - If the implementation does not support AArch64, bits [63:32] are not required to be implemented.

    If [FEAT\_PMUv3p5](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-6-The-Armv8-5-architecture-extension?lang=en#feat_feat_pmuv3p5) is not implemented, the event counter is 32 bits.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing PMXEVCNTR

If [FEAT\_FGT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_fgt) is implemented and [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is greater than or equal to the number of accessible event counters, then the behavior of permitted reads and writes of [PMXEVCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-19-PMXEVCNTR--Performance-Monitors-Selected-Event-Count-Register?lang=en#reg_aarch32_pmxevcntr) is as follows:

- If [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is greater than or equal to the Effective value of [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPMN, the access is UNDEFINED.
- Otherwise, the access is trapped to EL2.

If [FEAT\_FGT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_fgt) is not implemented and [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is greater than or equal to the number of accessible event counters, then reads and writes of [PMXEVCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-19-PMXEVCNTR--Performance-Monitors-Selected-Event-Count-Register?lang=en#reg_aarch32_pmxevcntr) are CONSTRAINED UNPREDICTABLE, and the following behaviors are permitted:

- Accesses to the register are UNDEFINED.
- Accesses to the register behave as RAZ/WI.
- Accesses to the register execute as a NOP
- Accesses to the register behave as if [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL has an UNKNOWN value less than the number of event counters accessible at the current Exception level and Security state.
- If EL2 is implemented and enabled in the current Security state, and [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is less than the number of implemented event counters, accesses from EL1 or permitted accesses from EL0 are trapped to EL2.

Permitted reads and writes of PMXEVCNTR are RAZ/WI if all of the following are true:

- FEAT\_PMUv3p9 is implemented.
- EL0 is the current Exception level.
- EL1 is using AArch64.
- [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).UEN is 1.
- [PMUACR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-24-PMUACR-EL1--Performance-Monitors-User-Access-Control-Register?lang=en#reg_aarch64_pmuacr_el1).P<UInt([PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL)> is 0.

Permitted writes of PMXEVCNTR are ignored if all of the following are true:

- FEAT\_PMUv3p9 is implemented.
- EL0 is the current Exception level.
- EL1 is using AArch64.
- [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).{UEN,ER} is {1,1}.

> #### Note
>
> In EL0, an access is permitted if it is enabled by [PMUSERENR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-18-PMUSERENR--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch32_pmuserenr).{ER,EN} or [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).{UEN,ER,EN}.
>
> If EL2 is implemented and enabled in the current Security state, at EL0 and EL1:
>
> - If EL2 is using AArch32, [HDCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-32-HDCR--Hyp-Debug-Control-Register?lang=en#reg_aarch32_hdcr).HPMN identifies the number of accessible event counters.
> - If EL2 is using AArch64, [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN identifies the number of accessible event counters.
>
> Otherwise, the number of accessible event counters is determined by the Effective value of [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPMN. For more information, see [HDCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-32-HDCR--Hyp-Debug-Control-Register?lang=en#reg_aarch32_hdcr).HPMN, [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN and [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPMN.
