# ​K1.1.29 Out of range values of the Set/Way/Index fields in cache maintenance instructions

##### K1.1.29 Out of range values of the Set/Way/Index fields in cache maintenance instructions

In the cache maintenance by set/way instructions [DCCISW](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-40-DCCISW--Data-Cache-line-Clean-and-Invalidate-by-Set-Way?lang=en#reg_aarch32_dccisw), [DCCSW](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-43-DCCSW--Data-Cache-line-Clean-by-Set-Way?lang=en#reg_aarch32_dccsw), and [DCISW](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-45-DCISW--Data-Cache-line-Invalidate-by-Set-Way?lang=en#reg_aarch32_dcisw), if any set/way/index argument is larger than the value supported by the implementation, then the behavior is CONSTRAINED UNPREDICTABLE and one of the following occurs:

- The instruction is UNDEFINED.
- The instruction performs cache maintenance on one of:

  - No cache lines.
  - A single arbitrary cache line.
  - Multiple arbitrary cache lines.

> #### Note
>
> This CONSTRAINED UNPREDICTABLE behavior applies, also, to the A64 cache maintenance by set/way instructions [DC CISW](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-3-A64-System-instructions-for-cache-maintenance/-C5-3-20-DC-CISW--Data-or-unified-Cache-line-Clean-and-Invalidate-by-Set-Way?lang=en#reg_aarch64_dc_cisw), [DC CSW](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-3-A64-System-instructions-for-cache-maintenance/-C5-3-24-DC-CSW--Data-or-unified-Cache-line-Clean-by-Set-Way?lang=en#reg_aarch64_dc_csw), and [DC ISW](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-3-A64-System-instructions-for-cache-maintenance/-C5-3-36-DC-ISW--Data-or-unified-Cache-line-Invalidate-by-Set-Way?lang=en#reg_aarch64_dc_isw).
