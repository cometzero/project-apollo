##### H9.3.46 TRCITEEDCR, Instrumentation Trace Extension External Debug Control Register

The TRCITEEDCR characteristics are:

Purpose
:   Controls instrumentation trace filtering.

Configuration
:   External register TRCITEEDCR bits [31:0] are architecturally mapped to AArch64 System register [TRCITEEDCR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-49-TRCITEEDCR--Instrumentation-Trace-Extension-External-Debug-Control-Register?lang=en#reg_aarch64_trciteedcr)[31:0].

    This register is present only when FEAT\_ETE is implemented, FEAT\_TRC\_EXT is implemented, and FEAT\_ITE is implemented. Otherwise, direct accesses to TRCITEEDCR are RES0.

Attributes
:   TRCITEEDCR is a 32-bit register.
