# ​C5.2.30 UAO, User Access Override

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-30-UAO--User-Access-Override>

##### C5.2.30 UAO, User Access Override

The UAO characteristics are:

Purpose
:   Allows access to the User Access Override bit.

Configuration
:   This register is a Special-purpose register.

    This register is present only when FEAT\_UAO is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to UAO are UNDEFINED.

Attributes
:   UAO is a 64-bit register.

###### Field descriptions

![](images/0447-C5.2.30-UAO-User-Access-Override-img01.svg)

Bits [63:24]
:   Reserved, RES0.

UAO, bit [23]
:   User Access Override.

    The Effective value of PSTATE.UAO is 0 when execution is at EL0.

    The Effective value of PSTATE.UAO is 1 when any of the following is true:

    - Execution is at EL1, and [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{NV, NV1} is {1, 1}.
    - Execution is at EL2, and the Effective value of HCR\_EL2.{E2H, TGE} is not {1, 1}.
    - Execution is at EL3.

Bits [22:0]
:   Reserved, RES0.

###### Accessing UAO

For more information about the operation of the MSR (immediate) accessor, see [‘MSR (immediate)’](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-288-MSR--immediate-?lang=en#isa_msr_imm).
