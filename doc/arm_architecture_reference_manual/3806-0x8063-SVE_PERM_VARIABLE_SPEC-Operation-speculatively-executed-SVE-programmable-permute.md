##### `0x8063`, SVE\_PERM\_VARIABLE\_SPEC, Operation speculatively executed, SVE programmable permute

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) variable vector permute operation due to any of the following instructions:

- SVE: CLASTA, CLASTB, COMPACT, LASTA, LASTB, SPLICE, or TBL.
- SVE2: EXPAND.
