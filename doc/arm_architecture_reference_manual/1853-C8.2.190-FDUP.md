##### C8.2.190 FDUP

Broadcast floating-point immediate to vector elements (unpredicated)

This instruction unconditionally broadcasts the floating-point immediate into each element of the destination vector. This instruction is unpredicated.

This instruction is used by the alias [FMOV (immediate, unpredicated)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-246-FMOV--immediate--unpredicated-?lang=en#isa_fmov_fdup_z_i).

###### Encoding

```
FDUP  <Zd>.<T>, #<const>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SVE) && !IsFeatureImplemented(FEAT_SME) then
    EndOfDecode(Decode_UNDEF);
end;
if size == ‘00’ then EndOfDecode(Decode_UNDEF); end;
let esize : integer{} = 8 << UInt(size);
let d : integer = UInt(Zd);
let imm : bits(esize) = VFPExpandImm{}(imm8);
```

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let elements : integer = VL DIV esize;
var result : bits(VL);
for e = 0 to elements-1 do
    result[e*:esize] = imm;
end;
Z{VL}(d) = result;
```
