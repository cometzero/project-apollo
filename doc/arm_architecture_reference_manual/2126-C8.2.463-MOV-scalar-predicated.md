##### C8.2.463 MOV (scalar, predicated)

Move general-purpose register to vector elements (predicated)

This instruction moves the general-purpose scalar source register to each Active element in the destination vector. Inactive elements in the destination vector register remain unmodified.

This is an alias of [CPY (scalar)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-121-CPY--scalar-?lang=en#isa_cpy_z_p_r). This means:

- The encodings in this description are named to match the encodings of [CPY (scalar)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-121-CPY--scalar-?lang=en#isa_cpy_z_p_r).
- The description of [CPY (scalar)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-121-CPY--scalar-?lang=en#isa_cpy_z_p_r) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
MOV  <Zd>.<T>, <Pg>/M, <R><n|SP>
```

is equivalent to

```
CPY  <Zd>.<T>, <Pg>/M, <R><n|SP>
```

and is always the preferred disassembly.
