##### `0x821F`, LL\_CACHE\_HITM\_RW, Last level cache demand access hit modified

The counter counts each cache access counted by [LL\_CACHE\_HIT\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81CF--LL-CACHE-HIT-RW--Last-level-cache-demand-access-hit?lang=en#event_ll_cache_hit_rw) that accesses a previously modified cache location.
