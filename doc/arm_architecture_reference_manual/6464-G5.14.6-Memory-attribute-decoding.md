# ​G5.14.6 Memory attribute decoding

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-14-Pseudocode-description-of-VMSAv8-32-memory-system-operations/-G5-14-6-Memory-attribute-decoding>

##### G5.14.6 Memory attribute decoding

If a stage of translation is enabled, Fetched Leaf descriptors encode memory attributes assigned to the output of translation. Stage 1 Long-descriptor format memory attributes are decoded by the function [`S1DecodeMemAttrs`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-754-S1DecodeMemAttrs?lang=en#asl_func_s1decodememattrs_3)`()`. Likewise, stage 2 memory attributes are decoded by the function [`S2DecodeMemAttrs`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-760-S2DecodeMemAttrs?lang=en#asl_func_s2decodememattrs_3)`()` followed by combining stage 1 and stage 2 attributes by the function [`S2CombineS1MemAttrs`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-757-S2CombineS1MemAttrs?lang=en#asl_func_s2combines1memattrs_3)`()`. A separate set of functions are used to assign memory attributes to the output of Short-descriptor format. [`AArch32_DefaultTEXDecode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-183-AArch32-DefaultTEXDecode?lang=en#asl_func_aarch32_defaulttexdecode_4)`()` is used when TEX remapping is disabled, otherwise [`AArch32_RemappedTEXDecode`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-185-AArch32-RemappedTEXDecode?lang=en#asl_func_aarch32_remappedtexdecode_5)`()` defines output memory attributes.
