###### D2.11.9.1 Exception syndrome information

On taking a Software Step exception, the PE optionally records information about the exception in the Exception Syndrome Register ([ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx)) at the Exception level the exception is taken to. See [ISS encoding for an exception from a Software Step exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-44-ESR-EL1--Exception-Syndrome-Register--EL1-?lang=en#fieldset_aarch64_esr_el1_fieldset_0_iss_an_exception_from_a_software_step_exception) for more information.

If no syndrome is recorded, then [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).{ISV, EX} are set to {0,0}.

If no instruction was stepped because software step entered the active-pending state from the inactive state without passing through the active-not-pending state, then no syndrome can be recorded.

When a syndrome is recorded:

- [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).ISV is set to 1, to indicate that [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).EX is valid.
- If the instruction stepped was a Load-Exclusive instruction, then [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).EX is set to 1. Otherwise [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).EX is set to 0.

> #### Note
>
> A Load-Exclusive instruction is any one of the following:
>
> - In the A64 instruction set, any instruction that has a mnemonic starting with either `LDX` or `LDAX`.
> - In the T32 and A32 instruction sets, any instruction that has a mnemonic starting with either `LDREX` or `LDAEX`.

Arm deprecates software use of [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).{ISV, EX}. ###### D2.11.9.2 Preferred return address

The preferred return of a Software Step exception is the address of the instruction that was not executed because the PE took the Software Step exception instead.
