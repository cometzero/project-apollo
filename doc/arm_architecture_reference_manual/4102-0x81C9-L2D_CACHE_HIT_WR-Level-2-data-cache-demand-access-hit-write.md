##### `0x81C9`, L2D\_CACHE\_HIT\_WR, Level 2 data cache demand access hit, write

The counter counts each demand write counted by [L2D\_CACHE\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0051--L2D-CACHE-WR--Level-2-data-cache-access--write?lang=en#event_l2d_cache_wr) that hits in the Level 2 data or unified cache.
