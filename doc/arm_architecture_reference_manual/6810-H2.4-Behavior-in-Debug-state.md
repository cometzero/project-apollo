#### H2.4 Behavior in Debug state

Instructions are executed in Debug state from the Instruction Transfer Register, ITR. The debugger controls which instructions are executed in Debug state by writing the instructions to the External Debug Instruction Transfer register, [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr).

The Execution state of the PE determines which instruction set is executed:

- If the PE is in AArch64 state it executes A64 instructions.
- If the PE is in AArch32 state it executes T32 instructions:

  - For a 32-bit T32 instruction, [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr)[15:0] specifies the first halfword and [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr)[31:16] specifies the second halfword.
  - For a 16-bit T32 instruction, [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr)[15:0] contains the instruction and [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr)[31:16] is ignored. All 16-bit T32 instructions are UNPREDICTABLE in Debug state.

The PE does not execute A32 instructions in Debug state.

Some instructions are available only in Debug state. See [Debug state operations, DCPS, DRPS, MRS, MSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-4-Behavior-in-Debug-state/-H2-4-6-Debug-state-operations--DCPS--DRPS--MRS--MSR?lang=en#babigjhg). In Non-debug state these instructions are UNDEFINED.
