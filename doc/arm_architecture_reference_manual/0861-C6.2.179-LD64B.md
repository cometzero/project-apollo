##### C6.2.179 LD64B

Single-copy atomic 64-byte load

This instruction derives an address from a base register value, loads eight 64-bit doublewords from a memory location, and writes them to consecutive registers. The load starts at register `Xt`, with the data being read as `X(t+7)::X(t+6)::X(t+5)::X(t+4)::X(t+3)::X(t+2)::X(t+1)::Xt = Data[511:0]`. The data is loaded atomically and is required to be 64-byte aligned.

It is IMPLEMENTATION DEFINED which memory locations support this instruction. A memory location that supports `LD64B` also supports `ST64B`.

For more information, including about the memory types accessible and how the accesses are performed, see [Single-copy atomic 64-byte load/store](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-2-Loads-and-stores/-C3-2-8-Single-copy-atomic-64-byte-load-store?lang=en#cjacafah).

###### Encoding

```
LD64B  <Xt>, [<Xn|SP> {, #0}]
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_LS64) then EndOfDecode(Decode_UNDEF); end;
if Rt[4:3] == ‘11’ || Rt[0] == ‘1’ then EndOfDecode(Decode_UNDEF); end;
let withstatus : boolean = FALSE;
let t : integer{} = UInt(Rt);
let n : integer{} = UInt(Rn);
let tagchecked : boolean = n != 31;
```

For information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc), and particularly [LD64B](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors/-K1-2-AArch64-CONSTRAINED-UNPREDICTABLE-behaviors/-K1-2-17-CONSTRAINED-UNPREDICTABLE-behavior-for-A64-instructions?lang=en#ceghbhefj4).

###### Assembler Symbols

<Xt>
:   ​

    Is the 64-bit name of the first general-purpose register to be transferred, encoded in the “Rt” field.

<Xn|SP>
:   ​

    Is the 64-bit name of the general-purpose base register or stack pointer, encoded in the “Rn” field.

###### Operation

```
CheckLDST64BEnabled();
var data : bits(512);
var address : bits(64);
var value : bits(64);
let accdesc : AccessDescriptor = CreateAccDescLS64(MemOp_LOAD, withstatus, tagchecked);
if n == 31 then
    CheckSPAlignment();
    address = SP{64}();
else
    address = X{64}(n);
end;
data = MemLoad64B(address, accdesc);
for i = 0 to 7 do
    value = data[63+64*i : 64*i];
    if BigEndian(accdesc.acctype) then value = BigEndianReverse{64}(value); end;
    X{64}(t+i) = value;
end;
```
