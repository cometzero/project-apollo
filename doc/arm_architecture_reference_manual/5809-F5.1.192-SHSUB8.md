##### F5.1.192 SHSUB8

Signed Halving Subtract 8 performs four signed 8-bit integer subtractions, halves the results, and writes the results to the destination register.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-192-SHSUB8?lang=en#isa_shsub8_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-192-SHSUB8?lang=en#isa_shsub8_iclass_t1)).

###### Encoding

```
SHSUB8{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
if d == 15 || n == 15 || m == 15 then UnpredictableProcedure(); end;
```

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let diff1 : integer = SInt(R(n)[7:0]) - SInt(R(m)[7:0]);
    let diff2 : integer = SInt(R(n)[15:8]) - SInt(R(m)[15:8]);
    let diff3 : integer = SInt(R(n)[23:16]) - SInt(R(m)[23:16]);
    let diff4 : integer = SInt(R(n)[31:24]) - SInt(R(m)[31:24]);
    R(d)[7:0]   = diff1[8:1];
    R(d)[15:8]  = diff2[8:1];
    R(d)[23:16] = diff3[8:1];
    R(d)[31:24] = diff4[8:1];
end;
```
