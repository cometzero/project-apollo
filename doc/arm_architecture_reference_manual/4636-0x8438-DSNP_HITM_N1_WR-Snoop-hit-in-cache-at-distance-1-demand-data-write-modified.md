##### `0x8438`, DSNP\_HITM\_N1\_WR, Snoop hit in cache at distance 1, demand data write, modified

The counter counts each snoop generated by the PE in response to a demand [Memory-write operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caccfcjj) counted by [DSNP\_HIT\_N1\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8408--DSNP-HIT-N1-WR--Snoop-hit-in-cache-at-distance-1--demand-data-write?lang=en#event_dsnp_hit_n1_wr) that accesses a previously modified cache location.
