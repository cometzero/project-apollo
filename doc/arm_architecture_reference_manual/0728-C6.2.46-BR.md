# ​C6.2.46 BR

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-46-BR>

##### C6.2.46 BR

Branch to register

This instruction branches unconditionally to an address in a register. This instruction provides a hint that this is not a subroutine call or return.

![](images/0728-C6.2.46-BR-img01.svg)

###### Encoding

```
BR  <Xn>
```

###### Decode for this encoding

```
let n : integer{} = UInt(Rn);
```

###### Assembler Symbols

<Xn>
:   ​

    Is the 64-bit name of the general-purpose register holding the address to be branched to, encoded in the “Rn” field.

###### Operation

```
let target : bits(64) = X{}(n);
// Value in BTypeNext will be used to set PSTATE.BTYPE
if InGuardedPage then
    if n == 16 || n == 17 then
        BTypeNext = ‘01’;
    else
        BTypeNext = ‘11’;
    end;
else
    BTypeNext = ‘01’;
end;
let branch_conditional : boolean = FALSE;
BranchTo{64}(target, BranchType_INDIR, branch_conditional);
```
