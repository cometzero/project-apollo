# ​D24.2.200 TFSR_EL3, Tag Fault Status Register (EL3)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-200-TFSR-EL3--Tag-Fault-Status-Register--EL3->

##### D24.2.200 TFSR\_EL3, Tag Fault Status Register (EL3)

The TFSR\_EL3 characteristics are:

Purpose
:   Holds accumulated Tag Check Faults occurring at EL3 that are not taken precisely.

Configuration
:   This register is present only when FEAT\_MTE\_ASYNC is implemented or FEAT\_MTE2 is implemented. Otherwise, direct accesses to TFSR\_EL3 are UNDEFINED.

Attributes
:   TFSR\_EL3 is a 64-bit register.

###### Field descriptions

When FEAT\_MTE\_ASYNC is not implemented:
:   ![](images/5092-D24.2.200-TFSR_EL3-Tag-Fault-Status-Register-EL3-img01.svg)

Bits [63:0]
:   Reserved, RAZ.

Otherwise:
:   ![](images/5092-D24.2.200-TFSR_EL3-Tag-Fault-Status-Register-EL3-img02.svg)

Bits [63:1]
:   Reserved, RES0.

TF0, bit [0]
:   Tag Check Fault. Asynchronously set to 1 when a Tag Check Fault using a virtual address with bit[55] == ‘0’ occurs.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
