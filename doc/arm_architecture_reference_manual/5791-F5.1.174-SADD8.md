##### F5.1.174 SADD8

Signed Add 8 performs four 8-bit signed integer additions, and writes the results to the destination register. It sets [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).GE according to the results of the additions.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-174-SADD8?lang=en#isa_sadd8_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-174-SADD8?lang=en#isa_sadd8_iclass_t1)).

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let sum1 : integer = SInt(R(n)[7:0]) + SInt(R(m)[7:0]);
    let sum2 : integer = SInt(R(n)[15:8]) + SInt(R(m)[15:8]);
    let sum3 : integer = SInt(R(n)[23:16]) + SInt(R(m)[23:16]);
    let sum4 : integer = SInt(R(n)[31:24]) + SInt(R(m)[31:24]);
    R(d)[7:0]   = sum1[7:0];
    R(d)[15:8]  = sum2[7:0];
    R(d)[23:16] = sum3[7:0];
    R(d)[31:24] = sum4[7:0];
    PSTATE.GE[0]  = if sum1 >= 0 then ‘1’ else ‘0’;
    PSTATE.GE[1]  = if sum2 >= 0 then ‘1’ else ‘0’;
    PSTATE.GE[2]  = if sum3 >= 0 then ‘1’ else ‘0’;
    PSTATE.GE[3]  = if sum4 >= 0 then ‘1’ else ‘0’;
end;
```
