##### H6.6.4 Debug registers to save over powerdown

[Table H6-2](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H6-Debug-Reset-and-Powerdown-Support/-H6-6-Debug-OS-Save-and-Restore-sequences/-H6-6-4-Debug-registers-to-save-over-powerdown?lang=en#tbl_chddhhbf) shows the different requirements for self-hosted debug over powerdown and external debug over powerdown:

- The column labeled Self-hosted lists registers that software must preserve over powerdown so that it can support self-hosted debug over powerdown. This does not require use of the OS Save and Restore mechanism.
- The column labeled External lists registers that software must preserve over powerdown so that it can support external debug over powerdown. This requires use of the OS Save and Restore mechanism:

  - Some external debug registers are not normally accessible to software executing on the PE. Additional debug registers are provided that give software the required access to save and restore these external debug registers when [OSLSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babeabbd).OSLK is locked. These registers include [OSECCR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babdgbbd), [OSDTRRX](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babchgee), and [OSDTRTX](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babhiecg).
- Some registers might only present in some implementations, or might not be accessible at all Exception levels or in Non-secure state. [DBGVCR32\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-10-DBGVCR32-EL2--Debug-Vector-Catch-Register?lang=en#reg_aarch64_dbgvcr32_el2) and [SDER32\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-30-SDER32-EL3--AArch32-Secure-Debug-Enable-Register?lang=en#reg_aarch64_sder32_el3) are only required to support AArch32.
