I FCDFK
:   [FEAT\_CHK](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_chk) provides [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) with the following properties:

    - [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) is allocated from the Hint instruction space, to allow it to be used on any PE, regardless of whether [FEAT\_CHK](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_chk) is implemented.
    - [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) takes a value as an input where one or more bits of the input value is set to 1 to test whether the requested feature is enabled, and if the feature is enabled the relevant bit is cleared to 0. Otherwise, the bit is unchanged.
    - When [FEAT\_CHK](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_chk) is not implemented, the input value is unchanged, indicating the requested feature is not enabled.
    - [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) returns the state of [`GCSEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-253-GCSEnabled?lang=en#asl_func_gcsenabled_1)`()`.

I QMQXS
:   Since the [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) instruction is in the Hint instruction encoding space, it is effectively implemented on all PEs that support AArch64. However, the [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) instruction only returns a result value that is different from the input value when any of the features that are identified by the [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) are implemented.

R VXBTN
:   An example of how [`CHKFEAT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-85-CHKFEAT?lang=en#isa_chkfeat) can be used in an implementation independent manner is shown below.

    > Example D1-1 Example code for using CHKFEAT
    >
    > ```
    >     MOV X16, #0x1           ; X16 has bit [0] set to select GCS
    >     CHKFEAT X16             ; Updates X16 with the status of GCS
    >     TBNZ X16, #0, skipgcs   ; Skip over GCS code if GCS is not enabled
    >
    >     ...                     ; GCS related code
    >
    > skipgcs:
    > ```
