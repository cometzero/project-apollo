# ​D24.2.218 VMPIDR_EL2, Virtualization Multiprocessor ID Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-218-VMPIDR-EL2--Virtualization-Multiprocessor-ID-Register>

##### D24.2.218 VMPIDR\_EL2, Virtualization Multiprocessor ID Register

The VMPIDR\_EL2 characteristics are:

Purpose
:   Holds the value of the Virtualization Multiprocessor ID. This is the value returned by EL1 reads of MPIDR\_EL1, which in a multiprocessor system, provides an additional PE identification system.

Configuration
:   If EL2 is not implemented, reads of this register return the value of the [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1) and writes to the register are ignored.

    This register has no effect if EL2 is not enabled in the current Security state.

    AArch64 System register VMPIDR\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [VMPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-170-VMPIDR--Virtualization-Multiprocessor-ID-Register?lang=en#reg_aarch32_vmpidr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to VMPIDR\_EL2 are UNDEFINED.

Attributes
:   VMPIDR\_EL2 is a 64-bit register.

###### Field descriptions

![](images/5110-D24.2.218-VMPIDR_EL2-Virtualization-Multiprocessor-ID-Register-img01.svg)

Bits [63:40]
:   Reserved, RES0.

Aff3, bits [39:32]
:   Affinity level 3. See the description of VMPIDR\_EL2.Aff0 for more information.

    Aff3 is not supported in AArch32 state.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bit [31]
:   Reserved, RES1.

U, bit [30]
:   Indicates a Uniprocessor system, as distinct from PE 0 in a multiprocessor system.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
