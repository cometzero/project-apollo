# ​G8.2.104 ISR, Interrupt Status Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-104-ISR--Interrupt-Status-Register>

##### G8.2.104 ISR, Interrupt Status Register

The ISR characteristics are:

Purpose
:   Shows the pending status of the IRQ and FIQ interrupts and the SError exceptions.

Configuration
:   AArch32 System register ISR bits [31:0] are architecturally mapped to AArch64 System register [ISR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-117-ISR-EL1--Interrupt-Status-Register?lang=en#reg_aarch64_isr_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ISR are UNDEFINED.

Attributes
:   ISR is a 32-bit register.

    If all of the following apply then this field shows the pending status of virtual SError exceptions:

    - EL2 is implemented and enabled in the current Security state.
    - Any of the following apply:
      - EL2 is using AArch64 and [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).AMO is 1.
      - EL2 is using AArch64, [FEAT\_DoubleFault2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_doublefault2) is implemented, and the Effective value of [HCRX\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-62-HCRX-EL2--Extended-Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcrx_el2).TMEA is 1.
      - EL2 is using AArch32 and [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).AMO is 1.
    - The PE is executing at EL1.

    Otherwise, this field shows the pending status of physical SError exceptions.

    If the SError exception is edge-triggered, this field is cleared to zero when the physical SError exception is taken.
