Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-48-TRCLSR--Trace-Lock-Status-Register>

##### H9.3.48 TRCLSR, Trace Lock Status Register

The TRCLSR characteristics are:

Purpose
:   Indicates whether the Software Lock is implemented, and the current status of the Software Lock.

    For additional information, see the CoreSight Architecture Specification.

Configuration
:   This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCLSR are RES0.

Attributes
:   TRCLSR is a 32-bit register.

###### Field descriptions

![](images/7052-H9.3.48-TRCLSR-Trace-Lock-Status-Register-img01.svg)

Bits [31:3]
:   Reserved, RES0.

nTT, bit [2]
:   Software lock size.

    Reads as `0b0`

    Access to this field is RO.

SLK, bit [1]
:   The current Software Lock status.
