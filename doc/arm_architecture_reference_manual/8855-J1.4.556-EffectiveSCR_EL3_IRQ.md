##### J1.4.556 EffectiveSCR\_EL3\_IRQ

```
// EffectiveSCR_EL3_IRQ()
// ======================
// Returns the Effective value of SCR_EL3().IRQ.
readonly func EffectiveSCR_EL3_IRQ() => bit
begin
    if !HaveEL(EL3) || ELUsingAArch32(EL3) then
        return ‘0’;
    end;
    return SCR_EL3().IRQ;
end;
```
