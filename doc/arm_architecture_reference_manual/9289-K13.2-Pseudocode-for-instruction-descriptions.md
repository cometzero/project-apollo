#### K13.2 Pseudocode for instruction descriptions

Each instruction description includes pseudocode that provides a precise description of what the instruction does, subject to the limitations described in [General limitations of Arm pseudocode](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K13-Arm-Pseudocode-Definition/-K13-1-About-the-Arm-pseudocode/-K13-1-1-General-limitations-of-Arm-pseudocode?lang=en#chdhbjah) and [Limitations of the instruction pseudocode](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-1-Format-of-instruction-descriptions/-F1-1-5-Pseudocode-describing-how-the-instruction-operates?lang=en#ciaghejg).

In the instruction pseudocode, instruction fields are referred to by the names shown in the encoding diagram for the instruction. [Instruction encoding diagrams and instruction pseudocode](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-1-Format-of-instruction-descriptions/-F1-1-5-Pseudocode-describing-how-the-instruction-operates?lang=en#ciagbaig) gives more information about the pseudocode provided for each instruction.
