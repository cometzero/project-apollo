# ​D22.2 SME traps and exceptions

#### D22.2 SME traps and exceptions

I QZNRN
:   This section provides additional details for SME-related exceptions. For a list of exception priorities, see [RZFGJP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-4-Exceptions/-D1-4-5-Synchronous-exception-types?lang=en#zfgjp).

R JZTCQ
:   If [FEAT\_SME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_sme) is not implemented, then SME and SME2 instructions are UNDEFINED.

R GTKQD
:   If [FEAT\_SME2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-4-The-Armv9-3-architecture-extension?lang=en#feat_feat_sme2) is not implemented, then SME2 instructions are UNDEFINED.

R PLYVH
:   If any of the following is true, an SVE instruction is UNDEFINED:

    - [FEAT\_SME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_sme) is not implemented and [FEAT\_SVE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_sve) is not implemented.
    - [FEAT\_SVE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_sve) is not implemented and the instruction is illegal when the PE is in *Streaming SVE mode.*

D DMBHW
:   The *SME-related instructions* are:

    - SME data-processing instructions.
    - `SMSTART` and `SMSTOP` instructions.
    - AArch64 `MRS` and `MSR` instructions which directly access any of the [SVCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-28-SVCR--Streaming-Vector-Control-Register?lang=en#reg_aarch64_svcr), [SMCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-183-SMCR-EL1--SME-Control-Register--EL1-?lang=en#reg_aarch64_smcr_el1), [SMCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-184-SMCR-EL2--SME-Control-Register--EL2-?lang=en#reg_aarch64_smcr_el2), or [SMCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-185-SMCR-EL3--SME-Control-Register--EL3-?lang=en#reg_aarch64_smcr_el3) registers.

I BLTMB
:   The [CPACR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-35-CPACR-EL1--Architectural-Feature-Access-Control-Register?lang=en#reg_aarch64_cpacr_el1).SMEN, [CPTR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-37-CPTR-EL2--Architectural-Feature-Trap-Register--EL2-?lang=en#reg_aarch64_cptr_el2).{SMEN, TSM}, [CPTR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-38-CPTR-EL3--Architectural-Feature-Trap-Register--EL3-?lang=en#reg_aarch64_cptr_el3).ESM trap and enable controls apply to all SME-related instructions.

I RGBVJ
:   The [SMCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#smcr_elx).EZT0 enable controls apply to the following SME2 instructions that access the ZT0 register:

    - [`LDR (table)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-158-LDR--table-?lang=en#isa_ldr_zt_br).
    - `LUTI2`, `LUTI4`.
    - `MOVT`.
    - [`STR (table)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-268-STR--table-?lang=en#isa_str_zt_br).
    - [`ZERO (table)`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-348-ZERO--table-?lang=en#isa_zero_zt_i).

I XKMKY
:   [FEAT\_SME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_sme) adds an SME exception syndrome in [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx) to identify instructions that are trapped because of any of:

    - The SME trap controls in [CPACR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-35-CPACR-EL1--Architectural-Feature-Access-Control-Register?lang=en#reg_aarch64_cpacr_el1), [CPTR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-37-CPTR-EL2--Architectural-Feature-Trap-Register--EL2-?lang=en#reg_aarch64_cptr_el2), and [CPTR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-38-CPTR-EL3--Architectural-Feature-Trap-Register--EL3-?lang=en#reg_aarch64_cptr_el3).
    - The SME2 trap controls [SMCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#smcr_elx).EZT0.
    - The PSTATE.SM and PSTATE.ZA modes.

R GGLFV
:   When an SVE `MOVPRFX` instruction predictably prefixes an SVE instruction that is *illegal* due to the current value of PSTATE.SM or PSTATE.ZA, then the execution of either of the instructions generates an exception due to SME functionality, consistent with the behaviors defined by [RRWVTR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-4-Exceptions/-D1-4-2-Exception-entry?lang=en#rwvtr).
