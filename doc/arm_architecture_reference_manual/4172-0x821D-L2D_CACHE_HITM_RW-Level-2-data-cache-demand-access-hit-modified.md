##### `0x821D`, L2D\_CACHE\_HITM\_RW, Level 2 data cache demand access hit modified

The counter counts each cache access counted by [L2D\_CACHE\_HIT\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81CD--L2D-CACHE-HIT-RW--Level-2-data-cache-demand-access-hit?lang=en#event_l2d_cache_hit_rw) that accesses a previously modified cache location.
