# ​D17.7.4 Restrictions on the current write pointer

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-4-Restrictions-on-the-current-write-pointer>

##### D17.7.4 Restrictions on the current write pointer

This section describes the software rules on setting the current write pointer, [PMBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-4-PMBPTR-EL1--Profiling-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_pmbptr_el1). The rules in this section do not apply when Discard mode is enabled. See [Discard mode](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-5-Filtering-sample-records/-D17-5-5-Discard-mode?lang=en#discard_mode).

R PGGHS
:   If software violates the restrictions in [RHXSYK](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-4-Restrictions-on-the-current-write-pointer?lang=en#hxsyk) and [RHLXGD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-4-Restrictions-on-the-current-write-pointer?lang=en#hlxgd), then the behavior is CONSTRAINED UNPREDICTABLE, and the PE might do any of the following at any point after profiling is [enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-4-Enabling-profiling?lang=en#spe_profiling_enabled):

    - The value of [PMBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-4-PMBPTR-EL1--Profiling-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_pmbptr_el1) becomes UNKNOWN.
    - Write sample records to any address in memory that is writable by a privileged access in the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr). These addresses are:

      - Virtual addresses in the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr), if the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).nVM is 0.
      - Intermediate physical addresses in the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_ss), if the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).nVM is 1, and the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr) has stage 2 translations.
      - Physical addresses in the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_ss), if the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).nVM is 1, and either the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr) has no stage 2 translation or stage 2 translation is disabled.
    - Generate a Profiling Buffer management event, with or without indicating data loss, for one of the following reasons:

      - A Buffer full buffer management event. See [Buffer full event](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-8-Profiling-Buffer-management/-D17-8-2-Buffer-full-event?lang=en#chdifiih).
      - An Access not allowed buffer management event. See [Access not allowed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-8-Profiling-Buffer-management/-D17-8-5-Access-not-allowed?lang=en#cacgebgeg0).
      - Any MMU Fault. See [Faults and watchpoints](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-8-Profiling-Buffer-management/-D17-8-3-Faults-and-watchpoints?lang=en#chdghbbg).
      - An IMPLEMENTATION DEFINED buffer management event. See [Implementation defined reason](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-8-Profiling-Buffer-management/-D17-8-6-Implementation-defined-reason?lang=en#cacbbbhad5).

      If [FEAT\_SPE\_EXC](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_spe_exc) is implemented, then the management event is recorded as described by [RHJXHT](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-8-Profiling-Buffer-management?lang=en#hjxht).
    - Silently discard all profiling data without writing it to memory.
    - Behave as if profiling is disabled.
    - Generate the [SAMPLE\_BUFFER\_FULL](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8123--SAMPLE-BUFFER-FULL--Profiling-Buffer-full?lang=en#event_sample_buffer_full) PMU event.

R HXSYK
:   When profiling becomes [enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-4-Enabling-profiling?lang=en#spe_profiling_enabled), all the following must be true:

    - The current write pointer must be at least one sample record size below the write limit pointer. That is:

      `UInt`([PMBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-4-PMBPTR-EL1--Profiling-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_pmbptr_el1).PTR) <= `UInt`([PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).LIMIT:`Zeros`(12)) - 2PMSIDR\_EL1.MaxSize.
    - [PMBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-4-PMBPTR-EL1--Profiling-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_pmbptr_el1).PTR[63:56] must equal [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).LIMIT[63:56].

    If profiling becomes [enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-4-Enabling-profiling?lang=en#spe_profiling_enabled) due to a Context synchronization event, then these conditions apply for the values of these System registers after the Context synchronization event.

R HLXGD
:   When the Profiling Buffer is first configured, [PMBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-4-PMBPTR-EL1--Profiling-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_pmbptr_el1).PTR must be aligned to [PMBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-1-PMBIDR-EL1--Profiling-Buffer-ID-Register?lang=en#reg_aarch64_pmbidr_el1).Align. That is, if [PMBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-1-PMBIDR-EL1--Profiling-Buffer-ID-Register?lang=en#reg_aarch64_pmbidr_el1).Align is nonzero, [PMBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-4-PMBPTR-EL1--Profiling-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_pmbptr_el1).PTR [`UInt`([PMBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-1-PMBIDR-EL1--Profiling-Buffer-ID-Register?lang=en#reg_aarch64_pmbidr_el1).Align)-1:0] must be all zeros.

    However, the current write pointer and write limit pointer can usually be restored to the saved write pointer and saved write limit pointer values that were in the System registers when profiling was [disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-4-Enabling-profiling?lang=en#spe_profiling_disabled), providing a [`PSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-319-PSB?lang=en#isa_psb) and a Context synchronization event were executed before reading the System registers.

    Following a management event and executing a [`PSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-319-PSB?lang=en#isa_psb) and a Context synchronization event:

    - If [PMBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#pmbsr_elx).{EA, DL} are not {0, 0}, indicating an External abort and/or data loss occurred, then profiling cannot be restarted using the saved write pointer and saved write limit pointer.
    - Otherwise, if [PMBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#pmbsr_elx).S is 0, indicating no Profiling Buffer management event was signaled, then profiling can be restarted from the saved write pointer and saved write limit pointer.
    - Otherwise, if software clears [PMBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#pmbsr_elx).S to 0 before restarting profiling, then the following apply:

      - If the Profiling Buffer management event was caused by an [MMU fault](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-15-Memory-aborts?lang=en#aa64_mmu_fault), then profiling can be restarted from the saved write pointer.

        > #### Note
        >
        > If the [MMU fault](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-15-Memory-aborts?lang=en#aa64_mmu_fault) has not been corrected, then the SPU will generate a [MMU fault](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-15-Memory-aborts?lang=en#aa64_mmu_fault) Profiling Buffer management event when it next tries to write a sample record.
      - If the Profiling Buffer management event was caused by a buffer full event, then profiling cannot be restarted from the saved write pointer and saved limit pointer, as the saved write pointer will not be at least one sample record below the saved limit pointer. However, software can extend the Profiling Buffer by changing [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1), and then profiling can be restarted from the saved write pointer.
    - Otherwise, profiling is restarted with [PMBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#pmbsr_elx).S set to 1, meaning profiling is [stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-4-Enabling-profiling?lang=en#profiling_stopped) and there are no constraints on the values of the current write pointer and write limit pointer.

    If software restarts profiling with a new current write pointer and new write limit pointer, then the restrictions on the current write pointer when first enabling profiling apply.

    ELx is defined by [RHJXHT](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-8-Profiling-Buffer-management?lang=en#hjxht).

    For more information, see [Synchronization and Statistical Profiling](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-9-Synchronization-and-Statistical-Profiling?lang=en#chdedead) and [Profiling Buffer management](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-8-Profiling-Buffer-management?lang=en#chdggbge).
