# ​E1.3.9 Controls of Advanced SIMD operation that do not apply to floating-point operation

##### E1.3.9 Controls of Advanced SIMD operation that do not apply to floating-point operation

Earlier architectures permitted implementation of either, both, or neither of the Advanced SIMD and floating-point additions to the base instruction set, and provided some controls that applied to the Advanced SIMD functionality but not to the floating-point functionality. From the introduction of Armv8, Advanced SIMD functionality cannot be separated from floating-point functionality, but in AArch32 state these controls function as they did in earlier architectures. This means they apply only to the following instructions and instruction encodings:

- All instructions with encodings defined in:

  - [Advanced SIMD data-processing](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F3-T32-Instruction-Set-Encoding/-F3-1-T32-instruction-set-encoding/-F3-1-8-Advanced-SIMD-data-processing?lang=en#t32_encoding_index_simddp), for the T32 instruction set.
  - [Advanced SIMD data-processing](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F4-A32-Instruction-Set-Encoding/-F4-1-A32-instruction-set-encoding/-F4-1-20-Advanced-SIMD-data-processing?lang=en#a32_encoding_index_advsimddp), for the A32 instruction set.
- All instructions with encodings defined in:

  - [Advanced SIMD element or structure load/store](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F3-T32-Instruction-Set-Encoding/-F3-1-T32-instruction-set-encoding/-F3-1-18-Advanced-SIMD-element-or-structure-load-store?lang=en#t32_encoding_index_vldst), for the T32 instruction set.
  - [Advanced SIMD element or structure load/store](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F4-A32-Instruction-Set-Encoding/-F4-1-A32-instruction-set-encoding/-F4-1-24-Advanced-SIMD-element-or-structure-load-store?lang=en#a32_encoding_index_advsimdls), for the A32 instruction set.
- The form of the `VDUP` instruction described in [VDUP (general-purpose register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-81-VDUP--general-purpose-register-?lang=en#isa_vdup_r).
- The byte and halfword forms of the VMOV instructions described in each of:

  - [VMOV (general-purpose register to scalar)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-136-VMOV--general-purpose-register-to-scalar-?lang=en#isa_vmov_rs).
  - [VMOV (scalar to general-purpose register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-138-VMOV--scalar-to-general-purpose-register-?lang=en#isa_vmov_sr).

The controls of this functionality are:

- The [CPACR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-33-CPACR--Architectural-Feature-Access-Control-Register?lang=en#reg_aarch32_cpacr).ASEDIS field.
- The [HCPTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-64-HCPTR--Hyp-Architectural-Feature-Trap-Register?lang=en#reg_aarch32_hcptr).TASE field.

In an implementation that supports Advanced SIMD functionality, support for each of these controls is optional:

- If the [CPACR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-33-CPACR--Architectural-Feature-Access-Control-Register?lang=en#reg_aarch32_cpacr).ASEDIS control is not supported then the [CPACR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-33-CPACR--Architectural-Feature-Access-Control-Register?lang=en#reg_aarch32_cpacr).ASEDIS field is RAZ/WI. This is equivalent to the control permitting the execution of Advanced SIMD instructions at EL1 and EL0.
- If the [HCPTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-64-HCPTR--Hyp-Architectural-Feature-Trap-Register?lang=en#reg_aarch32_hcptr).TASE control is not supported then the [HCPTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-64-HCPTR--Hyp-Architectural-Feature-Trap-Register?lang=en#reg_aarch32_hcptr).TASE field is RAZ/WI. This means the [HCPTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-64-HCPTR--Hyp-Architectural-Feature-Trap-Register?lang=en#reg_aarch32_hcptr) does not provide a control that can trap Non-secure execution of Advanced SIMD instructions to Hyp mode.
