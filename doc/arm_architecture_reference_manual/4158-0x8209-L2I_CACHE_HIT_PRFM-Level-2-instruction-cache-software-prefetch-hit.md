##### `0x8209`, L2I\_CACHE\_HIT\_PRFM, Level 2 instruction cache software prefetch hit

The counter counts each software prefetch counted by [L2I\_CACHE\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x814B--L2I-CACHE-PRFM--Level-2-instruction-cache-software-prefetch?lang=en#event_l2i_cache_prfm) that hits in the Level 2 instruction or unified cache.
