#### K13.1 About the Arm pseudocode

The Arm pseudocode provides precise descriptions of some areas of the Arm architecture. This includes description of the decoding and operation of all valid instructions. [Pseudocode for instruction descriptions](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K13-Arm-Pseudocode-Definition/-K13-2-Pseudocode-for-instruction-descriptions?lang=en#chdbhcjb) gives general information about this instruction pseudocode, including its limitations.
