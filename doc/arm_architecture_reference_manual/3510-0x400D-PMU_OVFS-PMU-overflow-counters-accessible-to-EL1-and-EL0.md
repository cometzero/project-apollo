# ​0x400D, PMU_OVFS, PMU overflow, counters accessible to EL1 and EL0

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x400D--PMU-OVFS--PMU-overflow--counters-accessible-to-EL1-and-EL0>

##### `0x400D`, PMU\_OVFS, PMU overflow, counters accessible to EL1 and EL0

The counter counts each unsigned overflow of a PMU counter due to any of the following:

- An event is counted by an event counter <n> and all of the following are true:
  - [PMINTENSET\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-17-PMINTENSET-EL1--Performance-Monitors-Interrupt-Enable-Set-Register?lang=en#reg_aarch64_pmintenset_el1)[n] is 1.
  - One of the following is true:
    - Counting the event causes unsigned overflow of [PMEVCNTR<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-10-PMEVCNTR-n--EL0--Performance-Monitors-Event-Count-Registers--n---0---30?lang=en#reg_aarch64_pmevcntrn_el0)[31:0], and either FEAT\_PMUv3p5 is not implemented or [PMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-8-PMCR-EL0--Performance-Monitors-Control-Register?lang=en#reg_aarch64_pmcr_el0).LP is 0.
    - Counting the event causes unsigned overflow of [PMEVCNTR<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-10-PMEVCNTR-n--EL0--Performance-Monitors-Event-Count-Registers--n---0---30?lang=en#reg_aarch64_pmevcntrn_el0)[63:0], FEAT\_PMUv3p5 is implemented, and [PMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-8-PMCR-EL0--Performance-Monitors-Control-Register?lang=en#reg_aarch64_pmcr_el0).LP is 1.
  - The event counter <n> is in the first range.
- A cycle is counted by [PMCCNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-2-PMCCNTR-EL0--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch64_pmccntr_el0), [PMINTENSET\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-17-PMINTENSET-EL1--Performance-Monitors-Interrupt-Enable-Set-Register?lang=en#reg_aarch64_pmintenset_el1)[31] is 1, and one of the following is true:
  - Counting the cycle causes unsigned overflow of [PMCCNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-2-PMCCNTR-EL0--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch64_pmccntr_el0)[31:0] and [PMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-8-PMCR-EL0--Performance-Monitors-Control-Register?lang=en#reg_aarch64_pmcr_el0).LC is 0.
  - Counting the cycle causes unsigned overflow of [PMCCNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-2-PMCCNTR-EL0--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch64_pmccntr_el0)[63:0] and [PMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-8-PMCR-EL0--Performance-Monitors-Control-Register?lang=en#reg_aarch64_pmcr_el0).LC is 1.
- FEAT\_PMUv3\_ICNTR is implemented, an instruction is counted by [PMICNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-14-PMICNTR-EL0--Performance-Monitors-Instruction-Counter-Register?lang=en#reg_aarch64_pmicntr_el0), [PMINTENSET\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-17-PMINTENSET-EL1--Performance-Monitors-Interrupt-Enable-Set-Register?lang=en#reg_aarch64_pmintenset_el1).F0 is 1, and counting the instruction causes unsigned overflow of [PMICNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-14-PMICNTR-EL0--Performance-Monitors-Instruction-Counter-Register?lang=en#reg_aarch64_pmicntr_el0)[63:0].

This event cannot be counted by the PMU. PMCEID0\_EL0[45] reads as 0.
