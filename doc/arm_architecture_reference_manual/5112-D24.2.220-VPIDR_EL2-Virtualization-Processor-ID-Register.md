# ​D24.2.220 VPIDR_EL2, Virtualization Processor ID Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-220-VPIDR-EL2--Virtualization-Processor-ID-Register>

##### D24.2.220 VPIDR\_EL2, Virtualization Processor ID Register

The VPIDR\_EL2 characteristics are:

Purpose
:   Holds the value of the Virtualization Processor ID. This is the value returned by EL1 reads of [MIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-136-MIDR-EL1--Main-ID-Register?lang=en#reg_aarch64_midr_el1).

Configuration
:   If EL2 is not implemented, reads of this register return the value of the [MIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-136-MIDR-EL1--Main-ID-Register?lang=en#reg_aarch64_midr_el1) and writes to the register are ignored.

    This register has no effect if EL2 is not enabled in the current Security state.

    AArch64 System register VPIDR\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [VPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-171-VPIDR--Virtualization-Processor-ID-Register?lang=en#reg_aarch32_vpidr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to VPIDR\_EL2 are UNDEFINED.

Attributes
:   VPIDR\_EL2 is a 64-bit register.
