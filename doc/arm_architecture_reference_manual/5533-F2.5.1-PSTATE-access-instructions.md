# ​F2.5.1 PSTATE access instructions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-5-PSTATE-and-banked-register-access-instructions/-F2-5-1-PSTATE-access-instructions>

##### F2.5.1 PSTATE access instructions

PSTATE holds process state information, see [Process state, PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch). In AArch32 state:

- At EL1 or higher, [PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch) is accessible using the *Current Program Status Register* ([CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-1-Accessing-PSTATE-fields?lang=en#cihjbhja)).
- At EL0, a subset of the [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-1-Accessing-PSTATE-fields?lang=en#cihjbhja) is accessible as the *Application Program Status Register* ([APSR](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cjagbhbh)).
- On taking an exception, the contents of the [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-1-Accessing-PSTATE-fields?lang=en#cihjbhja) are copied to the *Saved Program Status Register* ([SPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-10-AArch32-general-purpose-registers--the-PC--and-the-Special-purpose-registers/-G1-10-2-Saved-Program-Status-Registers--SPSRs-?lang=en#chddaabb)) of the mode from which the exception is taken.

The `MRS` and `MSR` instructions move the contents of the [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE/-G1-11-1-Accessing-PSTATE-fields?lang=en#cihjbhja), [APSR](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cjagbhbh), or the [SPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-10-AArch32-general-purpose-registers--the-PC--and-the-Special-purpose-registers/-G1-10-2-Saved-Program-Status-Registers--SPSRs-?lang=en#chddaabb) of the current mode to or from a general-purpose register, see:

- [MRS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-287-MRS?lang=en#isa_mrs).
- [MSR (immediate)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-121-MSR--immediate-?lang=en#isa_msr_i).
- [MSR (register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-122-MSR--register-?lang=en#isa_msr_r).

When executed at EL0, `MRS` and `MSR` instructions can only access the [APSR](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cjagbhbh).

The [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) Condition flags, [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).{N, Z, C, V} are set by the execution of data-processing instructions, and can control the execution of conditional instructions. However, software can set the Condition flags explicitly using the `MSR` instruction, and can read the current state of the Condition flags explicitly using the `MRS` instruction.

In addition, at EL1 or higher, software can use the `CPS` instruction to change the [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).M field and the [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).{A, I, F} interrupt mask bits, see [CPS, CPSID, CPSIE](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-39-CPS--CPSID--CPSIE?lang=en#isa_cps).
