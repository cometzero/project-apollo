#### D11.9 Guarded Control Stack exceptions

D WWXWR
:   [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) provides the GCS Data Check exception to report data mismatches in the comparison operations related to the Guarded Control Stack.

I QXRVB
:   For the comparison operations related to the Guarded Control Stack, see [RPCQXX](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-4-Exception-returns/-D11-4-1-Pushing-and-popping-exception-return-state?lang=en#pcqxx), [RLWRMC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#lwrmc), and [RQHSGP](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-7-Guarded-Control-Stack-switching?lang=en#qhsgp).

D PRYMV
:   [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) provides the EXLOCK Exception to report any exceptions due to an incompatible value in PSTATE.EXLOCK.

I RVKKZ
:   For a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception), an [EXLOCK Exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_exlock_exception), a trap on a [`GCSSTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-169-GCSSTR?lang=en#isa_gcsstr) instruction, or a trap on a [`GCSSTTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-170-GCSSTTR?lang=en#isa_gcssttr) instruction, the syndrome information is captured in [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).

I WLNVC
:   PMU events [EXC\_DABORT](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0084--EXC-DABORT--Exception-taken--Data-Abort-or-SError?lang=en#event_exc_dabort) and [EXC\_TRAP\_DABORT](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x008C--EXC-TRAP-DABORT--Exception-taken--Data-Abort-or-SError-not-Taken-locally?lang=en#event_exc_trap_dabort) count occurrences of a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception).

I PHRFN
:   Traps on the [`GCSSTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-169-GCSSTR?lang=en#isa_gcsstr) and [`GCSSTTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-170-GCSSTTR?lang=en#isa_gcssttr) instructions are counted by the [EXC\_UNDEF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0081--EXC-UNDEF--Exception-taken--other-synchronous?lang=en#event_exc_undef) and [EXC\_TRAP\_OTHER](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x008D--EXC-TRAP-OTHER--Exception-taken--other-traps-not-Taken-locally?lang=en#event_exc_trap_other) PMU events.

I YLMVR
:   An [EXLOCK Exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_exlock_exception) is counted by the [EXC\_UNDEF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0081--EXC-UNDEF--Exception-taken--other-synchronous?lang=en#event_exc_undef) and [EXC\_TRAP\_OTHER](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x008D--EXC-TRAP-OTHER--Exception-taken--other-traps-not-Taken-locally?lang=en#event_exc_trap_other) PMU events, according to the existing definitions of those PMU events.
