###### C2.2.3.1 Operation of modified immediate constants, floating-point instructions

For an A64 floating-point instruction that uses a modified immediate constant, the operation described by the [`VFPExpandImm`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-365-VFPExpandImm?lang=en#asl_func_vfpexpandimm_2)`()` pseudocode function returns the value of the immediate constant.
