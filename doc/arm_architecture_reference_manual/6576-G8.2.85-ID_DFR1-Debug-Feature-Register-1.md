# ​G8.2.85 ID_DFR1, Debug Feature Register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-85-ID-DFR1--Debug-Feature-Register-1>

##### G8.2.85 ID\_DFR1, Debug Feature Register 1

The ID\_DFR1 characteristics are:

Purpose
:   Provides top-level information about the debug system in AArch32.

    For general information about the interpretation of the ID registers, see [‘Principles of the ID scheme for fields in ID registers’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-1-About-the-AArch32-System-registers/-G8-1-3-Principles-of-the-ID-scheme-for-fields-in-ID-registers?lang=en#chdidagf).

Configuration
:   > #### Note
    >
    > Prior to the introduction of the features described by this register, this register was unnamed and reserved, RES0 from EL1, EL2, and EL3.

    AArch32 System register ID\_DFR1 bits [31:0] are architecturally mapped to AArch64 System register [ID\_DFR1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-99-ID-DFR1-EL1--AArch32-Debug-Feature-Register-1?lang=en#reg_aarch64_id_dfr1_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ID\_DFR1 are UNDEFINED.

Attributes
:   ID\_DFR1 is a 32-bit register.
