# ​C5.2 Special-purpose registers

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers>

#### C5.2 Special-purpose registers

This section describes the following Special-purpose registers:

- [ALLINT](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-1-ALLINT--All-Interrupt-Mask-Bit?lang=en#reg_aarch64_allint), that holds the [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).ALLINT bit.
- [CurrentEL](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-2-CurrentEL--Current-Exception-Level?lang=en#reg_aarch64_currentel), that holds [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).EL, and that software can read to determine the current Exception level.
- [DAIF](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-3-DAIF--Interrupt-Mask-Bits?lang=en#reg_aarch64_daif), that holds the current [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).{D, A, I, F} interrupt mask bits.
- [DIT](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-4-DIT--Data-Independent-Timing?lang=en#reg_aarch64_dit), that holds the [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).DIT bit.
- [ELR\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-5-ELR-EL1--Exception-Link-Register--EL1-?lang=en#reg_aarch64_elr_el1), that holds the address to return to for an exception return from EL1.
- [ELR\_EL2](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-6-ELR-EL2--Exception-Link-Register--EL2-?lang=en#reg_aarch64_elr_el2), that holds the address to return to for an exception return from EL2.
- [ELR\_EL3](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-7-ELR-EL3--Exception-Link-Register--EL3-?lang=en#reg_aarch64_elr_el3), that holds the address to return to for an exception return from EL3.
- [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr), that provides control of floating-point operation.
- [FPMR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-9-FPMR--Floating-point-Mode-Register?lang=en#reg_aarch64_fpmr), that controls behaviors of the FP8 instructions.
- [FPSR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-10-FPSR--Floating-point-Status-Register?lang=en#reg_aarch64_fpsr), that provides floating-point status information.
- [NZCV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-11-NZCV--Condition-Flags?lang=en#reg_aarch64_nzcv), that holds the [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).{N, Z, C, V} condition flags.
- [PAN](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-12-PAN--Privileged-Access-Never?lang=en#reg_aarch64_pan), that holds the [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).PAN state bit.
- [PM](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-13-PM--Profiling-Exception-Mask?lang=en#reg_aarch64_pm), that provides access to the Profiling exception mask bit.
- [RGSR\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-14-RGSR-EL1--Random-Allocation-Tag-Seed-Register-?lang=en#reg_aarch64_rgsr_el1), that seeds Random Allocation Tags.
- [SP\_EL0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-15-SP-EL0--Stack-Pointer--EL0-?lang=en#reg_aarch64_sp_el0), that holds the stack pointer for EL0.
- [SP\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-16-SP-EL1--Stack-Pointer--EL1-?lang=en#reg_aarch64_sp_el1), that holds the stack pointer for EL1.
- [SP\_EL2](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-17-SP-EL2--Stack-Pointer--EL2-?lang=en#reg_aarch64_sp_el2), that holds the stack pointer for EL2.
- [SP\_EL3](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-18-SP-EL3--Stack-Pointer--EL3-?lang=en#reg_aarch64_sp_el3), that holds the stack pointer for EL3.
- [SPSel](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-19-SPSel--Stack-Pointer-Select?lang=en#reg_aarch64_spsel), that holds [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).SP, that at EL1 or higher selects the current SP.
- [SPSR\_abt](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-20-SPSR-abt--Saved-Program-Status-Register--Abort-mode-?lang=en#reg_aarch64_spsr_abt), that holds process state on taking an exception to AArch32 Abort mode.
- [SPSR\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-21-SPSR-EL1--Saved-Program-Status-Register--EL1-?lang=en#reg_aarch64_spsr_el1), that holds process state on taking an exception to AArch64 EL1.
- [SPSR\_EL2](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-22-SPSR-EL2--Saved-Program-Status-Register--EL2-?lang=en#reg_aarch64_spsr_el2), that holds process state on taking an exception to AArch64 EL2.
- [SPSR\_EL3](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-23-SPSR-EL3--Saved-Program-Status-Register--EL3-?lang=en#reg_aarch64_spsr_el3), that holds process state on taking an exception to AArch64 EL3.
- [SPSR\_fiq](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-24-SPSR-fiq--Saved-Program-Status-Register--FIQ-mode-?lang=en#reg_aarch64_spsr_fiq), that holds process state on taking an exception to AArch32 FIQ mode.
- [SPSR\_irq](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-25-SPSR-irq--Saved-Program-Status-Register--IRQ-mode-?lang=en#reg_aarch64_spsr_irq), that holds process state on taking an exception to AArch32 IRQ mode.
- [SPSR\_und](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-26-SPSR-und--Saved-Program-Status-Register--Undefined-mode-?lang=en#reg_aarch64_spsr_und), that holds process state on taking an exception to AArch32 Undefined mode.
- [SSBS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-27-SSBS--Speculative-Store-Bypass-Safe?lang=en#reg_aarch64_ssbs), that holds the [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).SSBS bit.
- [SVCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-28-SVCR--Streaming-Vector-Control-Register?lang=en#reg_aarch64_svcr), controls Streaming SVE mode and SME behavior.
- [TCO](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-29-TCO--Tag-Check-Override?lang=en#reg_aarch64_tco), that holds the [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).TCO bit.
- [UAO](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-30-UAO--User-Access-Override?lang=en#reg_aarch64_uao), that holds the [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).UAO bit.

The following registers are also Special-purpose registers:

- [DLR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-13-DLR-EL0--Debug-Link-Register?lang=en#reg_aarch64_dlr_el0), that holds the address to return to for a return from Debug state.
- [DSPSR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-14-DSPSR-EL0--Debug-Saved-Program-Status-Register?lang=en#reg_aarch64_dspsr_el0), that holds process state on entry to Debug state.
