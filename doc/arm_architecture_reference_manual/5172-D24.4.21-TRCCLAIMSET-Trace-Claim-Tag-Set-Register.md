# ​D24.4.21 TRCCLAIMSET, Trace Claim Tag Set Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-21-TRCCLAIMSET--Trace-Claim-Tag-Set-Register>

##### D24.4.21 TRCCLAIMSET, Trace Claim Tag Set Register

The TRCCLAIMSET characteristics are:

Purpose
:   In conjunction with [TRCCLAIMCLR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-20-TRCCLAIMCLR--Trace-Claim-Tag-Clear-Register?lang=en#reg_aarch64_trcclaimclr), provides Claim Tag bits that can be separately set and cleared to indicate whether functionality is in use by a debug agent.

    For additional information, see the CoreSight Architecture Specification.

Configuration
:   The number of claim tag bits implemented is IMPLEMENTATION DEFINED. Arm recommends that implementations support a minimum of four claim tag bits, that is, SET[3:0] reads as `0b1111`.

    AArch64 System register TRCCLAIMSET bits [63:0] are architecturally mapped to AArch64 System register [TRCCLAIMCLR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-20-TRCCLAIMCLR--Trace-Claim-Tag-Clear-Register?lang=en#reg_aarch64_trcclaimclr)[63:0].

    AArch64 System register TRCCLAIMSET bits [31:0] are architecturally mapped to External register [TRCCLAIMSET](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-15-TRCCLAIMSET--Trace-Claim-Tag-Set-Register?lang=en#reg_ext_trcclaimset)[31:0].

    AArch64 System register TRCCLAIMSET bits [31:0] are architecturally mapped to External register [TRCCLAIMCLR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-14-TRCCLAIMCLR--Trace-Claim-Tag-Clear-Register?lang=en#reg_ext_trcclaimclr)[31:0].

    This register is present only when FEAT\_ETE is implemented and System register access to the trace unit registers is implemented. Otherwise, direct accesses to TRCCLAIMSET are UNDEFINED.

Attributes
:   TRCCLAIMSET is a 64-bit register.

###### Field descriptions

![](images/5172-D24.4.21-TRCCLAIMSET-Trace-Claim-Tag-Set-Register-img01.svg)

Bits [63:32]
:   Reserved, RES0.

SET[<m>] , bits [m], for m = 31 to 0
:   Claim Tag Set. Indicates whether Claim Tag bit <m> is implemented, and is used to set Claim Tag bit <m> to 1.

    Accessing this field has the following behavior:

    - When m >= NUM\_TRC\_CLAIM\_TAGS, access to this field is RAZ/WI.
    - Otherwise, access to this field is RAO/W1S.
