# ​D17.7 The Profiling Buffer

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer>

#### D17.7 The Profiling Buffer

I LSYJL
:   When the SPU is not in Discard mode, profile data is collected in a memory *Profiling Buffer*. The Profiling Buffer is defined by:

    - [PMBPTR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-4-PMBPTR-EL1--Profiling-Buffer-Write-Pointer-Register?lang=en#reg_aarch64_pmbptr_el1), the current write pointer.
    - [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1), the write limit pointer.

R KLGPG
:   The Profiling Buffer starts at the current write pointer and extends to the current limit pointer minus one. The write limit pointer must be aligned to the smallest implemented translation granule size. The alignment of the current write pointer is IMPLEMENTATION DEFINED.

I JXFJK
:   If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).nVM is 0, then address translation for the Profiling buffer in the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr) is enabled. See [Behavior when address translation is enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-1-Behavior-when-address-translation-is-enabled?lang=en#spe_address_translation_is_enabled).

    If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).nVM is 1, then address translation for the Profiling buffer in the [owning translation regime](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_tr) is disabled. See [Behavior when address translation is disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-2-Behavior-when-address-translation-is-disabled?lang=en#spe_address_translation_is_disabled).

R PSLVX
:   If [FEAT\_SPE\_nVM](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_spe_nvm) is not implemented or all of the following apply, then the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-2-PMBLIMITR-EL1--Profiling-Buffer-Limit-Address-Register?lang=en#reg_aarch64_pmblimitr_el1).nVM is 0:

    - EL2 is implemented and enabled in the [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_ss).
    - The [owning Exception level](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D17-The-Statistical-Profiling-Extension/-D17-7-The-Profiling-Buffer/-D17-7-5-The-owning-translation-regime?lang=en#spe_owning_el) is EL1.
    - The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [PMSCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-9-PMSCR-EL2--Statistical-Profiling-Control-Register--EL2-?lang=en#reg_aarch64_pmscr_el2).EnVM is 0.
