# ​D8.14.1 Behavior when HCR_EL2.NV is 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-14-Nested-virtualization/-D8-14-1-Behavior-when-HCR-EL2-NV-is-1>

##### D8.14.1 Behavior when HCR\_EL2.NV is 1

I ZMLPV
:   Nested Virtualization traps functionality that is permitted at EL2 and would be UNDEFINED at EL1 if [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).NV was 0.

I TZTZL
:   If [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).NV is 1 and the current Exception level is EL1, then all of the following apply:

    - If a read access or write access from EL1 to one of the following System registers or Special-purpose registers occurs and that access is not UNDEFINED at EL2 in the current Security state and not trapped to EL3 by a higher priority trap, then that access is trapped to EL2 and reported using EC syndrome value `0x18` in [ESR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-45-ESR-EL2--Exception-Syndrome-Register--EL2-?lang=en#reg_aarch64_esr_el2):

      - Any System register accessed using `MRS` or `MSR` named \*\_EL2, except all of the following:

        - [SP\_EL2](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-17-SP-EL2--Stack-Pointer--EL2-?lang=en#reg_aarch64_sp_el2).
        - [MECIDR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-134-MECIDR-EL2--MEC-Identification-Register?lang=en#reg_aarch64_mecidr_el2), [MECID\_A0\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-129-MECID-A0-EL2--Alternate-MECID-for-EL2-and-EL2-0-translation-regimes?lang=en#reg_aarch64_mecid_a0_el2), [MECID\_A1\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-130-MECID-A1-EL2--Alternate-MECID-for-EL2-0-translation-regimes-?lang=en#reg_aarch64_mecid_a1_el2), [MECID\_P0\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-131-MECID-P0-EL2--Primary-MECID-for-EL2-and-EL2-0-translation-regimes?lang=en#reg_aarch64_mecid_p0_el2), and [MECID\_P1\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-132-MECID-P1-EL2--Primary-MECID-for-EL2-0-translation-regimes?lang=en#reg_aarch64_mecid_p1_el2).
        - [VMECID\_A\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-216-VMECID-A-EL2--Alternate-MECID-for-EL1-0-stage-2-translation-regime?lang=en#reg_aarch64_vmecid_a_el2) and [VMECID\_P\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-217-VMECID-P-EL2--Primary-MECID-for-EL1-0-stage-2-translation-regime?lang=en#reg_aarch64_vmecid_p_el2).
      - Any System register accessed using `MRS` or `MSR` named \*\_EL12.
      - Any System register accessed using `MRS` or `MSR` named \*\_EL02.
      - Special-purpose registers [SPSR\_irq](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-25-SPSR-irq--Saved-Program-Status-Register--IRQ-mode-?lang=en#reg_aarch64_spsr_irq), [SPSR\_abt](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-20-SPSR-abt--Saved-Program-Status-Register--Abort-mode-?lang=en#reg_aarch64_spsr_abt), [SPSR\_und](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-26-SPSR-und--Saved-Program-Status-Register--Undefined-mode-?lang=en#reg_aarch64_spsr_und), and [SPSR\_fiq](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-24-SPSR-fiq--Saved-Program-Status-Register--FIQ-mode-?lang=en#reg_aarch64_spsr_fiq), accessed using `MRS` or `MSR`.
      - Special-purpose register [SP\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-16-SP-EL1--Stack-Pointer--EL1-?lang=en#reg_aarch64_sp_el1) accessed using the dedicated `MRS` or `MSR` instruction.
    - If one of the following instructions is executed from EL1, then the instruction is trapped to EL2 and reported using EC syndrome value `0x18` in [ESR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-45-ESR-EL2--Exception-Syndrome-Register--EL2-?lang=en#reg_aarch64_esr_el2):

      - Address Translation instructions that are accessible only from EL2 and above.
      - TLB maintenance instructions that are accessible only from EL2 and above.
    - If the `ERET`, `ERETAA`, or `ERETAB` instruction is executed from EL1, then the instruction is trapped to EL2 and reported using EC syndrome value `0x1A` in [ESR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-45-ESR-EL2--Exception-Syndrome-Register--EL2-?lang=en#reg_aarch64_esr_el2).
    - If EL3 is not implemented and the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TSC is 1, then when an [SMC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-372-SMC?lang=en#isa_smc) instruction is executed at EL1, all of the following apply:

      - The [SMC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-372-SMC?lang=en#isa_smc) instruction is trapped to EL2.
      - The exception is reported using EC syndrome value `0x17` in [ESR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-45-ESR-EL2--Exception-Syndrome-Register--EL2-?lang=en#reg_aarch64_esr_el2).

R GFLDX
:   If [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).NV is 1 and the current Exception level is EL1, then EL1 read accesses to the [CurrentEL](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-2-CurrentEL--Current-Exception-Level?lang=en#reg_aarch64_currentel) register return a value of `0x2` in bits[3:2].
