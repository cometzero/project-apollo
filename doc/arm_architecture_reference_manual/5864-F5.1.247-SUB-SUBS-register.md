# ​F5.1.247 SUB, SUBS (register)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-247-SUB--SUBS--register->

##### F5.1.247 SUB, SUBS (register)

Subtract (register) subtracts an optionally-shifted register value from a register value, and writes the result to the destination register.

If the destination register is not the PC, the SUBS variant of the instruction updates the condition flags based on the result.

The field descriptions for `<Rd>` identify the encodings where the PC is permitted as the destination register. However, when the destination register is the PC:

- The SUB variant of the instruction is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
- The SUBS variant of the instruction performs an exception return without the use of the stack. Arm deprecates use of this instruction. However, in this case:
  - The PE branches to the address written to the PC, and restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>.
  - The PE checks SPSR\_<current\_mode> for an illegal return event. See [Illegal return events from AArch32 state](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-3-Illegal-return-events-from-AArch32-state?lang=en#chdddjdb).
  - The instruction is UNDEFINED in Hyp mode.
  - The instruction is CONSTRAINED UNPREDICTABLE in User mode and System mode.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-247-SUB--SUBS--register-?lang=en#isa_sub_r_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-247-SUB--SUBS--register-?lang=en#isa_sub_r_iclass_t1) and [T2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-247-SUB--SUBS--register-?lang=en#isa_sub_r_iclass_t2)).

###### A1

![](images/5864-F5.1.247-SUB-SUBS-register-img01.svg)

###### Encoding for the SUB, rotate right with extend variant

Applies when `(S == 0 && imm5 == 00000 && stype == 11)`

```
SUB{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>, RRX
```

###### Encoding for the SUB, shift or rotate by value variant

Applies when `(S == 0 && !(imm5 == 00000 && stype == 11))`

```
SUB{<c>}{<q>}  {<Rd>, }<Rn>, <Rm> {, <shift> #<amount>}
```

###### Encoding for the SUBS, rotate right with extend variant

Applies when `(S == 1 && imm5 == 00000 && stype == 11)`

```
SUBS{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>, RRX
```

###### Encoding for the SUBS, shift or rotate by value variant

Applies when `(S == 1 && !(imm5 == 00000 && stype == 11))`

```
SUBS{<c>}{<q>}  {<Rd>, }<Rn>, <Rm> {, <shift> #<amount>}
```

###### Decode for all variants of this encoding

```
if Rn == ‘1101’ then See(“SUB (SP minus register)”); end;
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let setflags : boolean = (S == ‘1’);
let (shift_t, shift_n) : (SRType, integer) = DecodeImmShift(stype, imm5);
```

![](images/5864-F5.1.247-SUB-SUBS-register-img02.svg)

###### Encoding

```
SUB<c>{<q>}  <Rd>, <Rn>, <Rm> // (InITBlock())
```

```
SUBS{<q>}  {<Rd>, }<Rn>, <Rm> // (Outside IT block)
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let setflags : boolean = !InITBlock();
let shift_t : SRType = SRType_LSL;
let shift_n : integer = 0;
```

###### T2

![](images/5864-F5.1.247-SUB-SUBS-register-img03.svg)

###### Encoding for the SUB, rotate right with extend variant

Applies when `(S == 0 && imm3 == 000 && imm2 == 00 && stype == 11)`

```
SUB{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>, RRX
```

###### Encoding for the SUB, shift or rotate by value variant

Applies when `(S == 0 && !(imm3 == 000 && imm2 == 00 && stype == 11))`

```
SUB{<c>}{<q>}  {<Rd>, }<Rn>, <Rm> {, <shift> #<amount>}
```

```
SUB<c>.W  {<Rd>, }<Rn>, <Rm> // (Inside IT block, and <Rd>, <Rn>, <Rm> can be represented in T1)
```

###### Encoding for the SUBS, rotate right with extend variant

Applies when `(S == 1 && imm3 == 000 && Rd != 1111 && imm2 == 00 && stype == 11)`

```
SUBS{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>, RRX
```

###### Encoding for the SUBS, shift or rotate by value variant

Applies when `(S == 1 && Rd != 1111 && !(imm3 == 000 && imm2 == 00 && stype == 11))`

```
SUBS{<c>}{<q>}  {<Rd>, }<Rn>, <Rm> {, <shift> #<amount>}
```

```
SUBS.W  {<Rd>, }<Rn>, <Rm> // (Outside IT block, and <Rd>, <Rn>, <Rm> can be represented in T1)
```

###### Decode for all variants of this encoding

```
if Rd == ‘1111’ && S == ‘1’ then See(“CMP (register)”); end;
if Rn == ‘1101’ then See(“SUB (SP minus register)”); end;
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let setflags : boolean = (S == ‘1’);
let (shift_t, shift_n) : (SRType, integer) = DecodeImmShift(stype, imm3::imm2);
// Armv8-A removes UNPREDICTABLE for R13
if (d == 15 && !setflags) || n == 15 || m == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

<q>

<Rd>
:   ​

    For the “A1 SUB, rotate right with extend”, “A1 SUB, shift or rotate by value”, “A1 SUBS, rotate right with extend”, and “A1 SUBS, shift or rotate by value” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the same as `<Rn>`. Arm deprecates using the PC as the destination register, but if the PC is used:

    - For the SUB variant, the instruction is a branch to the address calculated by the operation. This is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
    - For the SUBS variant, the instruction performs an exception return, that restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>.

    ​

    For the “T1”, “T2 SUB, rotate right with extend”, “T2 SUB, shift or rotate by value”, “T2 SUBS, rotate right with extend”, and “T2 SUBS, shift or rotate by value” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the same as `<Rn>`.

<Rn>
:   ​

    For the “A1 SUB, rotate right with extend”, “A1 SUB, shift or rotate by value”, “A1 SUBS, rotate right with extend”, and “A1 SUBS, shift or rotate by value” variants: is the first general-purpose source register, encoded in the “Rn” field. The PC can be used, but this is deprecated. If the SP is used, see [SUB (SP minus register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-250-SUB--SUBS--SP-minus-register-?lang=en#isa_sub_sp_r).

    ​

    For the “T1” variant: is the first general-purpose source register, encoded in the “Rn” field.

    ​

    For the “T2 SUB, rotate right with extend”, “T2 SUB, shift or rotate by value”, “T2 SUBS, rotate right with extend”, and “T2 SUBS, shift or rotate by value” variants: is the first general-purpose source register, encoded in the “Rn” field. If the SP is used, see [SUB (SP minus register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-250-SUB--SUBS--SP-minus-register-?lang=en#isa_sub_sp_r).

<Rm>
:   ​

    For the “A1 SUB, rotate right with extend”, “A1 SUB, shift or rotate by value”, “A1 SUBS, rotate right with extend”, and “A1 SUBS, shift or rotate by value” variants: is the second general-purpose source register, encoded in the “Rm” field. The PC can be used, but this is deprecated.

    ​

    For the “T1”, “T2 SUB, rotate right with extend”, “T2 SUB, shift or rotate by value”, “T2 SUBS, rotate right with extend”, and “T2 SUBS, shift or rotate by value” variants: is the second general-purpose source register, encoded in the “Rm” field.

<amount>
:   ​

    For the “A1 SUB, shift or rotate by value” and “A1 SUBS, shift or rotate by value” variants: is the shift amount, in the range 1 to 31 (when <shift> = LSL or ROR) or 1 to 32 (when <shift> = LSR or ASR) encoded in the “imm5” field as <amount> modulo 32.

    ​

    For the “T2 SUB, shift or rotate by value” and “T2 SUBS, shift or rotate by value” variants: is the shift amount, in the range 1 to 31 (when <shift> = LSL or ROR) or 1 to 32 (when <shift> = LSR or ASR), encoded in the “imm3:imm2” field as <amount> modulo 32.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let shifted : bits(32) = Shift{}(R(m), shift_t, shift_n, PSTATE.C);
    let (result, nzcv) : (bits(32), bits(4)) = AddWithCarry{32}(R(n), NOT(shifted), ‘1’);
    if d == 15 then          // Can only occur for A32 encoding
        if setflags then
            ALUExceptionReturn(result);
        else
            ALUWritePC(result);
        end;
    else
        R(d) = result;
        if setflags then
            PSTATE.[N,Z,C,V] = nzcv;
        end;
    end;
end;
```

###### Operational Information

This instruction is a data-independent-time instruction as described in [About the DIT bit](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-5-About-the-DIT-bit?lang=en#beiidceg).
