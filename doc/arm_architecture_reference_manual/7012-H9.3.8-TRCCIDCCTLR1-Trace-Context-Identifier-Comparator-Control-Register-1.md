# ​H9.3.8 TRCCIDCCTLR1, Trace Context Identifier Comparator Control Register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-8-TRCCIDCCTLR1--Trace-Context-Identifier-Comparator-Control-Register-1>

##### H9.3.8 TRCCIDCCTLR1, Trace Context Identifier Comparator Control Register 1

The TRCCIDCCTLR1 characteristics are:

Purpose
:   Contains Context identifier mask values for the [TRCCIDCVR<n>](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-9-TRCCIDCVR-n---Trace-Context-Identifier-Comparator-Value-Registers--n---n---0---7?lang=en#reg_ext_trccidcvrn) registers, for n = 4 to 7.

Configuration
:   External register TRCCIDCCTLR1 bits [31:0] are architecturally mapped to AArch64 System register [TRCCIDCCTLR1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-18-TRCCIDCCTLR1--Trace-Context-Identifier-Comparator-Control-Register-1?lang=en#reg_aarch64_trccidcctlr1)[31:0].

    This register is present only when FEAT\_ETE is implemented, FEAT\_TRC\_EXT is implemented, UInt(TRCIDR4.NUMCIDC) > `0x4`, and UInt(TRCIDR2.CIDSIZE) > 0. Otherwise, direct accesses to TRCCIDCCTLR1 are RES0.

Attributes
:   TRCCIDCCTLR1 is a 32-bit register.

###### Field descriptions

:   When UInt(TRCIDR4.NUMCIDC) > 7:
    :   TRCCIDCVR7 mask control. Specifies the mask value that the trace unit applies to TRCCIDCVR7. Each bit in this field corresponds to a byte in TRCCIDCVR7.

###### Accessing TRCCIDCCTLR1

If software uses the [TRCCIDCVR<n>](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-9-TRCCIDCVR-n---Trace-Context-Identifier-Comparator-Value-Registers--n---n---0---7?lang=en#reg_ext_trccidcvrn) registers, for n = 4 to 7, then it must program this register.

If software sets a mask bit to 1 then it must program the relevant byte in [TRCCIDCVR<n>](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-9-TRCCIDCVR-n---Trace-Context-Identifier-Comparator-Value-Registers--n---n---0---7?lang=en#reg_ext_trccidcvrn) to `0x00`.

If any bit is 1 and the relevant byte in [TRCCIDCVR<n>](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-9-TRCCIDCVR-n---Trace-Context-Identifier-Comparator-Value-Registers--n---n---0---7?lang=en#reg_ext_trccidcvrn) is not `0x00`, the behavior of the Context Identifier Comparator is CONSTRAINED UNPREDICTABLE. In this scenario the comparator might match unexpectedly or might not match.

If the trace unit is not in the Idle state it is CONSTRAINED UNPREDICTABLE whether writes to this register are ignored.
