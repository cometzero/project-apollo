##### G2.9.8 Pseudocode description of Watchpoint exceptions taken from AArch32 state

[`AArch32_WatchpointByteMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-16-AArch32-WatchpointByteMatch?lang=en#asl_func_aarch32_watchpointbytematch_2)`()` tests an individual byte accessed by an operation.

[`AArch32_StateMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-7-AArch32-StateMatch?lang=en#asl_func_aarch32_statematch_7)`()` tests the values in [DBGWCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-26-DBGWCR-n---Debug-Watchpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgwcrn).{HMC, SSC, PAC}, and if the watchpoint is Linked, also tests the Linked Context breakpoint that the watchpoint links to.

[`AArch32_WatchpointMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-17-AArch32-WatchpointMatch?lang=en#asl_func_aarch32_watchpointmatch_4)`()` tests the value in [DBGWVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-28-DBGWVR-n---Debug-Watchpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgwvrn).

[`AArch32_CheckWatchpoint`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-189-AArch32-CheckWatchpoint?lang=en#asl_func_aarch32_checkwatchpoint_4)`()` generates a [`FaultRecord`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-427-FaultRecord?lang=en#asl_type_faultrecord). A Watchpoint exception is taken if all of the following are true:

- [DBGDSCRext](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-14-DBGDSCRext--Debug-Status-and-Control-Register--External-View?lang=en#reg_aarch32_dbgdscrext).MDBGen is 1.
- Debug exceptions are enabled from the current Exception level and Security state. See [Enabling debug exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G2-AArch32-Self-hosted-Debug/-G2-3-The-debug-exception-enable-controls/-G2-3-1-Enabling-debug-exceptions?lang=en#beiecibb).
- All of the conditions required for Watchpoint exception generation are met. See [About Watchpoint exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G2-AArch32-Self-hosted-Debug/-G2-9-Watchpoint-exceptions/-G2-9-1-About-Watchpoint-exceptions?lang=en#g3bcgjjijb).

> #### Note
>
> [`AArch32_CheckWatchpoint`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-189-AArch32-CheckWatchpoint?lang=en#asl_func_aarch32_checkwatchpoint_4) might halt the PE and cause it to enter Debug state. External debug uses Debug state.

The [`AArch32_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-19-AArch32-Abort?lang=en#asl_func_aarch32_abort_1)`()` function processes the [`FaultRecord`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-427-FaultRecord?lang=en#asl_type_faultrecord) object returned by [`AArch32_CheckWatchpoint`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-189-AArch32-CheckWatchpoint?lang=en#asl_func_aarch32_checkwatchpoint_4)`()`, as described in [Abort exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G4-The-AArch32-System-Level-Memory-Model/-G4-8-Pseudocode-description-of-general-memory-System-instructions/-G4-8-7-Abort-exceptions?lang=en#beibdebj). If a Watchpoint exception is taken to AArch32 state, the [`AArch32_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-19-AArch32-Abort?lang=en#asl_func_aarch32_abort_1)`()` function generates a Data Abort exception.
