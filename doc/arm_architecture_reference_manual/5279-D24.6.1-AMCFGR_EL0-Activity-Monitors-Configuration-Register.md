# ​D24.6.1 AMCFGR_EL0, Activity Monitors Configuration Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-1-AMCFGR-EL0--Activity-Monitors-Configuration-Register>

##### D24.6.1 AMCFGR\_EL0, Activity Monitors Configuration Register

The AMCFGR\_EL0 characteristics are:

Purpose
:   Global configuration register for the activity monitors.

    Provides information on supported features, the number of counter groups implemented, the total number of activity monitor event counters implemented, and the size of the counters. AMCFGR\_EL0 is applicable to both the architected and the auxiliary counter groups.

Configuration
:   AArch64 System register AMCFGR\_EL0 bits [31:0] are architecturally mapped to AArch32 System register [AMCFGR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-1-AMCFGR--Activity-Monitors-Configuration-Register?lang=en#reg_aarch32_amcfgr)[31:0].

    When FEAT\_AMU\_EXT32 is implemented, AArch64 System register AMCFGR\_EL0 bits [31:0] are architecturally mapped to External register [AMCFGR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-1-AMCFGR--Activity-Monitors-Configuration-Register?lang=en#reg_amu_amcfgr)[31:0].

    When FEAT\_AMU\_EXT64 is implemented, AArch64 System register AMCFGR\_EL0 bits [63:0] are architecturally mapped to External register [AMCFGR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-1-AMCFGR--Activity-Monitors-Configuration-Register?lang=en#reg_amu_amcfgr)[63:0].

    This register is present only when FEAT\_AMUv1 is implemented. Otherwise, direct accesses to AMCFGR\_EL0 are UNDEFINED.

Attributes
:   AMCFGR\_EL0 is a 64-bit register.

Bits [23:14]
:   Reserved, RAZ.

SIZE, bits [13:8]
:   Defines the size of the activity monitor event counters, minus one.

    The counters are 64-bit, so the value of this field is `0b111111`.

    This field is used by software to determine the spacing of the counters in the memory-map. The counters are at doubleword-aligned addresses.

    Reads as `0b111111`

    Access to this field is RO.

N, bits [7:0]
:   Defines the number of activity monitor event counters implemented in all groups. One less than the sum of [AMCGCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-3-AMCGCR-EL0--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch64_amcgcr_el0).CG1NC and [AMCGCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-3-AMCGCR-EL0--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch64_amcgcr_el0).CG0NC.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
