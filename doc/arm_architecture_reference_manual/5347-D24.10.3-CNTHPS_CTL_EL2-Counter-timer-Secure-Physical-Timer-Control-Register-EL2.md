##### D24.10.3 CNTHPS\_CTL\_EL2, Counter-timer Secure Physical Timer Control Register (EL2)

The CNTHPS\_CTL\_EL2 characteristics are:

Purpose
:   Control register for the Secure EL2 physical timer.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch64 System register CNTHPS\_CTL\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [CNTHPS\_CTL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-6-CNTHPS-CTL--Counter-timer-Secure-Physical-Timer-Control-Register--EL2-?lang=en#reg_aarch32_cnthps_ctl)[31:0].

    This register is present only when FEAT\_SEL2 is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTHPS\_CTL\_EL2 are UNDEFINED.

Attributes
:   CNTHPS\_CTL\_EL2 is a 64-bit register.

    When the value of the CNTHPS\_CTL\_EL2.ENABLE bit is 1, ISTATUS indicates whether the timer condition is met. ISTATUS takes no account of the value of the IMASK bit. If the value of ISTATUS is 1 and the value of IMASK is 0 then the timer interrupt is asserted.

    When the value of the CNTHPS\_CTL\_EL2.ENABLE bit is 0, the ISTATUS field is UNKNOWN.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    Access to this field is RO.

    Setting this bit to 0 disables the timer output signal, but the timer value accessible from [CNTHPS\_TVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-5-CNTHPS-TVAL-EL2--Counter-timer-Secure-Physical-Timer-TimerValue-Register--EL2-?lang=en#reg_aarch64_cnthps_tval_el2) continues to count down.

    > #### Note
    >
    > Disabling the output signal might be a power-saving option.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
