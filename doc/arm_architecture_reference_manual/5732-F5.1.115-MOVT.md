##### F5.1.115 MOVT

Move Top writes an immediate value to the top halfword of the destination register. It does not affect the contents of the bottom halfword.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-115-MOVT?lang=en#isa_movt_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-115-MOVT?lang=en#isa_movt_iclass_t1)).

###### A1

![](images/5732-F5.1.115-MOVT-img01.svg)

###### Encoding

```
MOVT{<c>}{<q>}  <Rd>, #<imm16>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let imm16 : bits(16) = imm4::imm12;
if d == 15 then UnpredictableProcedure(); end;
```

###### T1

![](images/5732-F5.1.115-MOVT-img02.svg)

###### Encoding

```
MOVT{<c>}{<q>}  <Rd>, #<imm16>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let imm16 : bits(16) = imm4::i::imm3::imm8;
// Armv8-A removes UNPREDICTABLE for R13
if d == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

<Rd>
:   ​

    Is the general-purpose destination register, encoded in the “Rd” field.

<imm16>
:   ​

    For the “A1” variant: is a 16-bit unsigned immediate, in the range 0 to 65535, encoded in the “imm4:imm12” field.

    ​

    For the “T1” variant: is a 16-bit unsigned immediate, in the range 0 to 65535, encoded in the “imm4:i:imm3:imm8” field.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    R(d)[31:16] = imm16;
    // R[d]<15:0> unchanged
end;
```
