##### C7.2.19 BFMLALB, BFMLALT (vector)

BFloat16 multiply-add to single-precision (vector)

This instruction widens the even-numbered (bottom) or odd-numbered (top) 16-bit elements in the first and second source vectors from Bfloat16 to single-precision format. The instruction then multiplies and adds these values without intermediate rounding to the single-precision elements of the destination vector that overlap with the corresponding BFloat16 elements in the source vectors.

[ID\_AA64ISAR1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-84-ID-AA64ISAR1-EL1--AArch64-Instruction-Set-Attribute-Register-1?lang=en#reg_aarch64_id_aa64isar1_el1).BF16 indicates whether this instruction is supported.

###### Encoding

```
BFMLAL<bt>  <Vd>.4S, <Vn>.8H, <Vm>.8H
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_BF16) then EndOfDecode(Decode_UNDEF); end;
let d : integer{} = UInt(Rd);

let m : integer{} = UInt(Rm);
let elements : integer = 128 DIV 32;
let sel : integer = UInt(Q);
```

###### Operation

```
AArch64_CheckFPAdvSIMDEnabled();
let operand1 : bits(128) = V{}(n);
let operand2 : bits(128) = V{}(m);
let operand3 : bits(128) = V{}(d);
var result : bits(128);
for e = 0 to elements-1 do
    let element1 : bits(16) = operand1[(2 * e + sel)*:16];
    let element2 : bits(16) = operand2[(2 * e + sel)*:16];
    let addend : bits(32)   = operand3[e*:32];
    result[e*:32] = BFMulAddH(addend, element1, element2, FPCR());
end;
V{128}(d) = result;
```
