# ​0x832B, REMOTE_CACHE_HIT_PRFM, Remote cache software prefetch hit

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x832B--REMOTE-CACHE-HIT-PRFM--Remote-cache-software-prefetch-hit>

##### `0x832B`, REMOTE\_CACHE\_HIT\_PRFM, Remote cache software prefetch hit

The counter counts each cache hit on a remote device due to a software prefetch.
