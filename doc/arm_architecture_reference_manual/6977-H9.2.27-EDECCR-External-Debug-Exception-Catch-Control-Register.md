# ​H9.2.27 EDECCR, External Debug Exception Catch Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-27-EDECCR--External-Debug-Exception-Catch-Control-Register>

##### H9.2.27 EDECCR, External Debug Exception Catch Control Register

The EDECCR characteristics are:

Purpose
:   Controls Exception Catch debug events. For more information, see [‘Exception Catch debug event’](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-4-Exception-Catch-debug-event?lang=en#exception_catch_debug_event).

Configuration
:   EDECCR is in the Core power domain

    External register EDECCR bits [31:0] are architecturally mapped to AArch64 System register [OSECCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-26-OSECCR-EL1--OS-Lock-Exception-Catch-Control-Register?lang=en#reg_aarch64_oseccr_el1)[31:0].

    External register EDECCR bits [31:0] are architecturally mapped to AArch32 System register [DBGOSECCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-21-DBGOSECCR--Debug-OS-Lock-Exception-Catch-Control-Register?lang=en#reg_aarch32_dbgoseccr)[31:0].

Attributes
:   EDECCR is a 32-bit register.

:   Reserved, RES0.

:   When FEAT\_RME is implemented:
    :   Controls exception catch on exception return to Realm EL2 in conjunction with EDECCR.RLE2.
