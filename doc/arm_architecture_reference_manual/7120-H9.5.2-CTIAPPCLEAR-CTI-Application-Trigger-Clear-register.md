##### H9.5.2 CTIAPPCLEAR, CTI Application Trigger Clear register

The CTIAPPCLEAR characteristics are:

Purpose
:   Clears the application triggers.

Configuration
:   CTIAPPCLEAR is in the Debug power domain

    External register CTIAPPCLEAR bits [31:0] are architecturally mapped to External register [CTIAPPSET](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-4-CTIAPPSET--CTI-Application-Trigger-Set-register?lang=en#reg_ext_ctiappset)[31:0].

Attributes
:   CTIAPPCLEAR is a 32-bit register.

###### Field descriptions

APPCLEAR<x> , bits [x], for x = 31 to 0
:   Application trigger <x> disable.

    If the ECT does not support multicycle channel events, use of CTIAPPCLEAR is deprecated and the debugger must only use [CTIAPPPULSE](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-3-CTIAPPPULSE--CTI-Application-Pulse-register?lang=en#reg_ext_ctiapppulse).

    Accessing this field has the following behavior:

    - When x >= UInt(CTIDEVID.NUMCHAN), access to this field is RAZ/WI.
    - Otherwise, access to this field is RAZ/W1C.
