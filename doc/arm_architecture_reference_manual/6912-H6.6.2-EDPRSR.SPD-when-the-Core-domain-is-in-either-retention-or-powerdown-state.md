# ​H6.6.2 EDPRSR.SPD when the Core domain is in either retention or powerdown state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H6-Debug-Reset-and-Powerdown-Support/-H6-6-Debug-OS-Save-and-Restore-sequences/-H6-6-2-EDPRSR-SPD-when-the-Core-domain-is-in-either-retention-or-powerdown-state>

##### H6.6.2 EDPRSR.SPD when the Core domain is in either retention or powerdown state

If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, when the Core power domain is in either the retention or powerdown state, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPD is not cleared following a read of [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) and it is IMPLEMENTATION DEFINED whether:

- [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPD shows whether the state of the debug registers in the Core power domain has been lost since the last time that [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) was read. This means that:

  - When the Core power domain is in the powerdown state, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPD is RAO, this indicates that the state of the debug registers has been lost.
  - When the Core power domain is in the retention state, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPD indicates whether the state of the debug registers was lost before the Core power domain entered retention state.
- [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPD is RAZ, and:

  - On leaving the powerdown state, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPD is set to 1 which indicates that the state of the debug registers has been lost.
  - On leaving the retention state, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).SPD reverts the value it had on entering the retention state.

> #### Note
>
> If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, accesses to [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) return an error when the Core power domain is off or in a retention state.
