# ​D24.6.3 AMCGCR_EL0, Activity Monitors Counter Group Configuration Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-3-AMCGCR-EL0--Activity-Monitors-Counter-Group-Configuration-Register>

##### D24.6.3 AMCGCR\_EL0, Activity Monitors Counter Group Configuration Register

The AMCGCR\_EL0 characteristics are:

Purpose
:   Provides information on the number of activity monitor event counters implemented within each counter group.

Configuration
:   AArch64 System register AMCGCR\_EL0 bits [31:0] are architecturally mapped to AArch32 System register [AMCGCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-2-AMCGCR--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch32_amcgcr)[31:0].

    When FEAT\_AMU\_EXT32 is implemented, AArch64 System register AMCGCR\_EL0 bits [31:0] are architecturally mapped to External register [AMCGCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-2-AMCGCR--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_amu_amcgcr)[31:0].

    When FEAT\_AMU\_EXT64 is implemented, AArch64 System register AMCGCR\_EL0 bits [63:0] are architecturally mapped to External register [AMCGCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-2-AMCGCR--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_amu_amcgcr)[63:0].

    This register is present only when FEAT\_AMUv1 is implemented. Otherwise, direct accesses to AMCGCR\_EL0 are UNDEFINED.

Attributes
:   AMCGCR\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5281-D24.6.3-AMCGCR_EL0-Activity-Monitors-Counter-Group-Configuration-Register-img01.svg)

Bits [63:16]
:   Reserved, RES0.

CG1NC, bits [15:8]
:   Counter Group 1 Number of Counters. Highest index of the implemented counters in the auxiliary counter group, plus one. Zero indicates that there are no counters in the auxiliary counter group.

    If FEAT\_AMUv1p1 is implemented, then [AMCG1IDR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-2-AMCG1IDR-EL0--Activity-Monitors-Counter-Group-1-Identification-Register?lang=en#reg_aarch64_amcg1idr_el0) further defines which auxiliary counters are implemented, and the counters in the auxiliary counter group might be indexed non-contiguously.

CG0NC, bits [7:0]
:   Counter Group 0 Number of Counters. The number of counters in the architected counter group.

    Reads as `0x04`

    Access to this field is RO.
