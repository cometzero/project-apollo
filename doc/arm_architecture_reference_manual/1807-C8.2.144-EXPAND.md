# ​C8.2.144 EXPAND

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-144-EXPAND>

##### C8.2.144 EXPAND

Copy lower-numbered vector elements to Active elements

This instruction copies consecutive elements from the source vector to Active elements of the destination vector, in increasing order of element number. Inactive elements in the destination vector register are set to zero.

This instruction is illegal when executed in Streaming SVE mode, unless FEAT\_SME\_FA64 is implemented and enabled, or FEAT\_SME2p2 is implemented.

###### SVE2

###### (FEAT\_SVE2p2 || FEAT\_SME2p2)

![](images/1807-C8.2.144-EXPAND-img01.svg)

###### Encoding

```
EXPAND  <Zd>.<T>, <Pg>, <Zn>.<T>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SVE2p2) && !IsFeatureImplemented(FEAT_SME2p2) then
    EndOfDecode(Decode_UNDEF);
end;
let esize : integer{} = 8 << UInt(size);
let g : integer = UInt(Pg);
let n : integer = UInt(Zn);
let d : integer = UInt(Zd);
```

###### Operation

```
if IsFeatureImplemented(FEAT_SME2p2) then
    CheckSVEEnabled();
else
    CheckNonStreamingSVEEnabled();
end;
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let elements : integer = VL DIV esize;
let mask : bits(PL) = P{}(g);
let operand1 : bits(VL) = if AnyActiveElement{PL}(mask, esize) then Z{VL}(n) else Zeros{VL};
var result : bits(VL);
var x : integer = 0;
for e = 0 to elements-1 do
    if ActivePredicateElement{PL}(mask, e, esize) then
        result[e*:esize] = operand1[x*:esize];
        x = x + 1;
    else
        result[e*:esize] = Zeros{esize};
    end;
end;
Z{VL}(d) = result;
```
