##### C8.2.464 MOV (SIMD&FP scalar, predicated)

Move SIMD&FP scalar register to vector elements (predicated)

This instruction moves the SIMD & floating-point scalar source register to each Active element in the destination vector. Inactive elements in the destination vector register remain unmodified.

This is an alias of [CPY (SIMD&FP scalar)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-122-CPY--SIMD-FP-scalar-?lang=en#isa_cpy_z_p_v). This means:

- The encodings in this description are named to match the encodings of [CPY (SIMD&FP scalar)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-122-CPY--SIMD-FP-scalar-?lang=en#isa_cpy_z_p_v).
- The description of [CPY (SIMD&FP scalar)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-122-CPY--SIMD-FP-scalar-?lang=en#isa_cpy_z_p_v) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
MOV  <Zd>.<T>, <Pg>/M, <V><n>
```

is equivalent to

```
CPY  <Zd>.<T>, <Pg>/M, <V><n>
```

and is always the preferred disassembly.
