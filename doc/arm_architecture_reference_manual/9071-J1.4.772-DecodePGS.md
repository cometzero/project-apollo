##### J1.4.772 DecodePGS

```
// DecodePGS()
// ===========
func DecodePGS(pgs : bits(2)) => PGSe
begin
    case pgs of
        when ‘00’ => return PGS_4KB;
        when ‘10’ => return PGS_16KB;
        when ‘01’ => return PGS_64KB;
        otherwise => unreachable;
    end;
end;
```
