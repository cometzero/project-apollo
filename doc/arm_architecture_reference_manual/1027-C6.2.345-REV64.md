##### C6.2.345 REV64

Reverse bytes

This instruction reverses the byte order in a 64-bit general-purpose register.

When assembling for Armv8.2, an assembler must support this pseudo-instruction. It is OPTIONAL whether an assembler supports this pseudo-instruction when assembling for an architecture earlier than Armv8.2.

This is a pseudo-instruction of [REV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-342-REV?lang=en#isa_rev). This means:

- The encodings in this description are named to match the encodings of [REV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-342-REV?lang=en#isa_rev).
- The assembler syntax is used only for assembly, and is not used on disassembly.
- The description of [REV](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-342-REV?lang=en#isa_rev) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
REV64  <Xd>, <Xn>
```

is equivalent to

```
REV  <Xd>, <Xn>
```

###### Assembler Symbols

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Xn>
:   ​

    Is the 64-bit name of the general-purpose source register, encoded in the “Rn” field.
