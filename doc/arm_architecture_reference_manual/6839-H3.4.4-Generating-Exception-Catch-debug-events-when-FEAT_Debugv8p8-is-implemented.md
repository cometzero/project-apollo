# ​H3.4.4 Generating Exception Catch debug events when FEAT_Debugv8p8 is implemented

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-4-Exception-Catch-debug-event/-H3-4-4-Generating-Exception-Catch-debug-events-when-FEAT-Debugv8p8-is-implemented>

##### H3.4.4 Generating Exception Catch debug events when FEAT\_Debugv8p8 is implemented

Exception Catch debug events are generated as described in [Generating Exception Catch debug events when FEAT\_Debugv8p2 is not implemented](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-4-Exception-Catch-debug-event/-H3-4-2-Generating-Exception-Catch-debug-events-when-FEAT-Debugv8p2-is-not-implemented?lang=en#babbjbcaa0), except:

- An Exception Catch debug event is generated only on exception entry or return.
- When an Exception Catch debug event is generated after exception entry and halting is allowed at the target of the exception, the PE sets [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC to 1, and one of the following occurs:

  - The PE halts immediately. On entry to Debug state, [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC might be 0 or 1.
  - The PE might take an unmasked asynchronous exception, changing Exception level. This means that the PE might enter a state where halting is prohibited before the PE halts and enters Debug state.
- When an Exception Catch debug event is generated on exception return and halting is allowed at the target of the exception, [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC is unchanged.
- When [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC is 1 and halting is allowed, the PE halts and enters Debug state before completing any instruction.
- When [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC is 1 and halting is prohibited, an Exception Catch debug event is pending.
- [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC is cleared to 0 upon:

  - A write of 1 to [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC.
  - Exit from Debug state.

> #### Note
>
> If [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).EC is 1 and the PE executes a Context synchronizing exception return from a state where halting is prohibited to a state where halting is allowed, then the Exception Catch debug event is prioritized over any synchronous exception or synchronous debug event generated by the first instruction after the Context synchronization event, other than possibly a Halting Step debug event or a Software Step exception.
