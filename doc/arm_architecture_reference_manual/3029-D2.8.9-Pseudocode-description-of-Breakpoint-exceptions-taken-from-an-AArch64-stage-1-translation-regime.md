##### D2.8.9 Pseudocode description of Breakpoint exceptions taken from an AArch64 stage 1 translation regime

[`AArch64_BreakpointValueMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-26-AArch64-BreakpointValueMatch?lang=en#asl_func_aarch64_breakpointvaluematch_5)`()` tests the value in [DBGBVR<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-3-DBGBVR-n--EL1--Debug-Breakpoint-Value-Registers--n---0---63?lang=en#reg_aarch64_dbgbvrn_el1).

[`AArch64_StateMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-28-AArch64-StateMatch?lang=en#asl_func_aarch64_statematch_9)`()` tests the values in [DBGBCR<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-2-DBGBCR-n--EL1--Debug-Breakpoint-Control-Registers--n---0---63?lang=en#reg_aarch64_dbgbcrn_el1).{SSCE, SSC, HMC, PMC} and, if the breakpoint links to a breakpoint with linking enabled, also tests the Context matching breakpoint.

[`AArch64_BreakpointMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-25-AArch64-BreakpointMatch?lang=en#asl_func_aarch64_breakpointmatch_4)`()` tests a single breakpoint against the current instruction PC, combining state match and value match, and returns the breakpoint type and match info.

[`AArch64_CheckBreakpoint`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-641-AArch64-CheckBreakpoint?lang=en#asl_func_aarch64_checkbreakpoint_4)`()` evaluates all implemented instruction breakpoints for the current instruction and, if there is a match, causes the PE to enter Debug state or generate a Breakpoint exception.

[`AArch64_BreakpointException`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-153-AArch64-BreakpointException?lang=en#asl_func_aarch64_breakpointexception_1)`()` is called to generate a Breakpoint exception.

These functions are defined in [A-profile Architecture Pseudocode](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode?lang=en#chap_pseudocode).
