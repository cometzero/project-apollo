# ​D24.2.166 S2POR_EL1, Stage 2 Permission Overlay Register (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-166-S2POR-EL1--Stage-2-Permission-Overlay-Register--EL1->

##### D24.2.166 S2POR\_EL1, Stage 2 Permission Overlay Register (EL1)

The S2POR\_EL1 characteristics are:

Purpose
:   Stage 2 Permission Overlay Register for EL1&0 translation regime.

Configuration
:   This register is present only when FEAT\_S2POE is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to S2POR\_EL1 are UNDEFINED.

Attributes
:   S2POR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5058-D24.2.166-S2POR_EL1-Stage-2-Permission-Overlay-Register-EL1-img01.svg)

Perm<m> , bits [4m+3:4m], for m = 15 to 0
:   Configures stage 2 Overlay Permissions.

    This field is not permitted to be cached in a TLB.

    When stage 2 Permission Overlay mechanism is disabled, this register is ignored.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
