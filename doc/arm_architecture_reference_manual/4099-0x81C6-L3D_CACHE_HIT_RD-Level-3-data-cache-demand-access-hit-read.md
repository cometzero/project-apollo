##### `0x81C6`, L3D\_CACHE\_HIT\_RD, Level 3 data cache demand access hit, read

The counter counts each demand read counted by [L3D\_CACHE\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x00A0--L3D-CACHE-RD--Level-3-data-cache-access--read?lang=en#event_l3d_cache_rd) that hits in the Level 3 data or unified cache.
