# ​J1.2.505 FPTrigSSel

##### J1.2.505 FPTrigSSel

```
// FPTrigSSel()
// ============
func FPTrigSSel{N}(op1 : bits(N), op2 : bits(N)) => bits(N)
begin
    assert N IN {16,32,64};
    var result : bits(N);
    if op2[0] == ‘1’ then
        result = FPOne{N}(op2[1]);
    elsif op2[1] == ‘1’ then
        result = FPNeg{N}(op1, EffectiveFPCR());
    else
        result = op1;
    end;
    return result;
end;
```
