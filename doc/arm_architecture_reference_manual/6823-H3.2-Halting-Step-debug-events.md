#### H3.2 Halting Step debug events

Halting Step is a debug resource that a debugger can use to make the PE step through code one instruction at a time. This section describes the Halting Step debug events. It is divided into the following sections:

- [Overview of a Halting Step debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-1-Overview-of-a-Halting-Step-debug-event?lang=en#babjchhc).
- [The Halting Step state machine](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-2-The-Halting-Step-state-machine?lang=en#babfeafb).
- [Using Halting Step](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-3-Using-Halting-Step?lang=en#babfijbh).
- [Detailed Halting Step state machine behavior](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-4-Detailed-Halting-Step-state-machine-behavior?lang=en#babcfiia).
- [Synchronization and the Halting Step state machine](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-5-Synchronization-and-the-Halting-Step-state-machine?lang=en#babeeaea).
- [Stepping T32 IT instructions](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-6-Stepping-T32-IT-instructions?lang=en#babjefcd).
- [Disabling interrupts while stepping](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-7-Disabling-interrupts-while-stepping?lang=en#beifbidh).
- [Syndrome information on Halting Step](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-8-Syndrome-information-on-Halting-Step?lang=en#babejeje).
- [Pseudocode description of Halting Step debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-9-Pseudocode-description-of-Halting-Step-debug-events?lang=en#babibiji).

The architecture describes the behavior as a simple Halting Step state machine. See [The Halting Step state machine](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-2-The-Halting-Step-state-machine?lang=en#babfeafb).
