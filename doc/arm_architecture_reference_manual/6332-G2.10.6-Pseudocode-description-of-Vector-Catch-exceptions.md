##### G2.10.6 Pseudocode description of Vector Catch exceptions

The [`AArch32_VCRMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-2-AArch32-VCRMatch?lang=en#asl_func_aarch32_vcrmatch_1)`()` pseudocode function checks whether the instruction at `address` generates a Vector Catch exception. It therefore shows the address-matching form of vector catch.

The [`AArch32_CheckVectorCatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-188-AArch32-CheckVectorCatch?lang=en#asl_func_aarch32_checkvectorcatch_3)`()` pseudocode function uses [`AArch32_VCRMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-2-AArch32-VCRMatch?lang=en#asl_func_aarch32_vcrmatch_1)`()` to test whether the instruction generates a Vector Catch exception, and if [`AArch32_VCRMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-2-AArch32-VCRMatch?lang=en#asl_func_aarch32_vcrmatch_1)`()` returns TRUE it generates that event.

The [`AArch32_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-19-AArch32-Abort?lang=en#asl_func_aarch32_abort_1)`()` function processes the `FaultRecord` object returned by [`AArch32_CheckVectorCatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-188-AArch32-CheckVectorCatch?lang=en#asl_func_aarch32_checkvectorcatch_3)`()`, as described in [Abort exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G4-The-AArch32-System-Level-Memory-Model/-G4-8-Pseudocode-description-of-general-memory-System-instructions/-G4-8-7-Abort-exceptions?lang=en#beibdebj). If there is a Vector Catch exception, the [`AArch32_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-19-AArch32-Abort?lang=en#asl_func_aarch32_abort_1)`()` function generates a Prefetch Abort exception.
