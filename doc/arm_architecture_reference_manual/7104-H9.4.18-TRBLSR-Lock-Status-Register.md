##### H9.4.18 TRBLSR, Lock Status Register

The TRBLSR characteristics are:

Purpose
:   Indicates the Software Lock is not implemented.

    For additional information, see the CoreSight Architecture Specification.

Configuration
:   TRBLSR is in the Core power domain

    This register is present only when FEAT\_TRBE\_EXT is implemented. Otherwise, direct accesses to TRBLSR are RES0.

Attributes
:   TRBLSR is a 32-bit register.

###### Field descriptions

![](images/7104-H9.4.18-TRBLSR-Lock-Status-Register-img01.svg)

Bits [31:3]
:   Reserved, RES0.

Bits [2:1]
:   Reserved, RAZ.

    Not thirty-two bit. Describes the size of the [TRBLAR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-16-TRBLAR--Lock-Access-Register?lang=en#reg_ext_trblar) register.

    This field reads-as-zero.

SLI, bit [0]
:   Indicates the Software Lock is not implemented.

    The value of this field is an IMPLEMENTATION DEFINED choice of:
