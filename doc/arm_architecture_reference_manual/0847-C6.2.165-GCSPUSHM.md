##### C6.2.165 GCSPUSHM

Guarded Control Stack push

This instruction decrements the current GCS pointer register by the size of a GCS procedure return record and stores an entry to the Guarded Control Stack.

For more information, see [GCSPUSHM, Guarded Control Stack Push](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-9-A64-System-instructions-for-the-Guarded-Control-Stack/-C5-9-4-GCSPUSHM--Guarded-Control-Stack-Push?lang=en#reg_aarch64_gcspushm).

This is an alias of [SYS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-475-SYS?lang=en#isa_sys). This means:

- The encodings in this description are named to match the encodings of [SYS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-475-SYS?lang=en#isa_sys).
- The description of [SYS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-475-SYS?lang=en#isa_sys) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
GCSPUSHM  <Xt>
```

is equivalent to

```
SYS  #3, C7, C7, #0, <Xt>
```

and is always the preferred disassembly.

###### Assembler Symbols

<Xt>
:   ​

    Is the 64-bit name of the general-purpose source register, encoded in the “Rt” field.
