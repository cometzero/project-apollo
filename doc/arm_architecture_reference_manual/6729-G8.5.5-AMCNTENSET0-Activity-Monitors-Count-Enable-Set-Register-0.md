# ​G8.5.5 AMCNTENSET0, Activity Monitors Count Enable Set Register 0

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-5-AMCNTENSET0--Activity-Monitors-Count-Enable-Set-Register-0>

##### G8.5.5 AMCNTENSET0, Activity Monitors Count Enable Set Register 0

The AMCNTENSET0 characteristics are:

Purpose
:   Enable control bits for the architected activity monitors event counters, [AMEVCNTR0<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-8-AMEVCNTR0-n---Activity-Monitors-Event-Counter-Registers-0--n---0---3?lang=en#reg_aarch32_amevcntr0n).

Configuration
:   AArch32 System register AMCNTENSET0 bits [31:0] are architecturally mapped to AArch64 System register [AMCNTENSET0\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-6-AMCNTENSET0-EL0--Activity-Monitors-Count-Enable-Set-Register-0?lang=en#reg_aarch64_amcntenset0_el0)[31:0].

    AArch32 System register AMCNTENSET0 bits [31:0] are architecturally mapped to External register [AMCNTENSET0](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-12-AMCNTENSET0--Activity-Monitors-Count-Enable-Set-Register-0?lang=en#reg_amu_amcntenset0)[31:0].

    AArch32 System register AMCNTENSET0 bits [31:0] are architecturally mapped to External register [AMCNTENCLR0](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-9-AMCNTENCLR0--Activity-Monitors-Count-Enable-Clear-Register-0?lang=en#reg_amu_amcntenclr0)[31:0].

    This register is present only when FEAT\_AMUv1 is implemented and FEAT\_AA32 is implemented. Otherwise, direct accesses to AMCNTENSET0 are UNDEFINED.

Attributes
:   AMCNTENSET0 is a 32-bit register.

###### Field descriptions

![](images/6729-G8.5.5-AMCNTENSET0-Activity-Monitors-Count-Enable-Set-Register-0-img01.svg)

Bits [31:16]
:   Reserved, RES0.

Bits [15:4]
:   Reserved, RAZ/WI.

    This field is reserved for additional architected activity monitor event counters, which Arm might define in a future version of the Activity Monitors architecture.

P<n> , bits [n], for n = 3 to 0
:   Activity monitor event counter enable bit for [AMEVCNTR0<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-8-AMEVCNTR0-n---Activity-Monitors-Event-Counter-Registers-0--n---0---3?lang=en#reg_aarch32_amevcntr0n).

    > #### Note
    >
    > [AMCGCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-2-AMCGCR--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch32_amcgcr).CG0NC identifies the number of architected activity monitor event counters. In an implementation that includes FEAT\_AMUv1, the number of architected activity monitor event counters is 4.

    The reset behavior of this field is:

    - On a AMU reset, this field resets to the expression `0x00000000`.

    Accessing this field has the following behavior:

    - When n >= 4, access to this field is RAZ/WI.
    - Otherwise, access to this field is W1S.
