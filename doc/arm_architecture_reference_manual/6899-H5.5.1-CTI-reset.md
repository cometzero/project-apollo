# ​H5.5.1 CTI reset

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H5-The-Embedded-Cross-Trigger-Interface/-H5-5-CTI-registers-programmers--model/-H5-5-1-CTI-reset>

##### H5.5.1 CTI reset

An External Debug reset resets the CTI. See [External debug register resets](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-8-External-debug-register-resets?lang=en#cihcffcg) for details of CTI register resets. All CTI output triggers and output channels are deasserted on an External Debug reset.

> #### Note
>
> An indirect read of an output trigger might not observe the deasserted state until the processor is Cold reset. For more information, see [Synchronization of changes to the external debug registers](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-3-Synchronization-of-changes-to-the-external-debug-registers?lang=en#ciheghgh).
