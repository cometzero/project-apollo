##### D11.10.1 Guarded Control Stack data access behaviors

D NFPLW
:   A GCS Memory Read effect is a Memory Read effect produced by any of the following instructions:

    - A procedure return instruction; to read the data addressed by the current GCS pointer plus any applicable offset.
    - [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl); to read the data addressed by the current GCS pointer plus any applicable offset.
    - [`GCSSS2`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-168-GCSSS2?lang=en#isa_gcsss2_sysl); to read the data addressed by the current GCS pointer plus any applicable offset.
    - [`GCSPOPCX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-162-GCSPOPCX?lang=en#isa_gcspopcx_sys); to read the data addressed by the current GCS pointer plus any applicable offset.
    - [`GCSPOPX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-164-GCSPOPX?lang=en#isa_gcspopx_sys); to read the data addressed by the current GCS pointer plus any applicable offset.

    A GCS Memory Write effect is a Memory Write effect produced by any of the following:

    - A branch with link instruction; to write the data addressed by the current GCS pointer plus any applicable offset.
    - [`GCSSS2`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-168-GCSSS2?lang=en#isa_gcsss2_sysl); to write the data addressed by a calculation from the data read by the same [`GCSSS2`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-168-GCSSS2?lang=en#isa_gcsss2_sysl) instruction.
    - [`GCSPUSHM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-165-GCSPUSHM?lang=en#isa_gcspushm_sys); to write the data addressed by the current GCS pointer plus any applicable offset.
    - [`GCSPUSHX`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-166-GCSPUSHX?lang=en#isa_gcspushx_sys); to write the data addressed by the current GCS pointer plus any applicable offset.
    - [`GCSSTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-169-GCSSTR?lang=en#isa_gcsstr); to write the data addressed by the Xn|SP operand of the instruction, plus any applicable offset.
    - [`GCSSTTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-170-GCSSTTR?lang=en#isa_gcssttr); to write the data addressed by the Xn|SP operand of the instruction, plus any applicable offset.
    - An Overshooting GCS Memory effect; to write the data addressed by the current GCS pointer plus any applicable offset.

    A GCS Memory effect is one of the following:

    - A GCS Memory Read effect.
    - A GCS Memory Write effect.

R SJPKS
:   On execution of a GCS Memory effect that is a read access R1 to a Location M and is produced by any of the following instructions, without any exception caused by those instructions, a Memory Write effect is induced to the Location M and the write value is a CONSTRAINED UNPREDICTABLE choice of the following:

    - A value that is written to the same Location M, by a GCS Memory effect that is a write access W2 and all of the following are true:

      - W2 is in program order before R1.
      - There is no Memory Write effect W3 to the same Location M, that is not a GCS Memory effect, that exists in Coherence order after W2.
      - There is no write access W4 to the same Location M, and all of the following are true for W4:

        - W4 is a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access).
        - W4 is in program order after W2 and in program order before R1.
        - There is a [`GCSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-161-GCSB?lang=en#isa_gcsb) effect that appears in program order after W4 and appears in program order before R1.
    - A value that is written to the same Location M, by a Memory Write effect W2 that is not a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) and all of the following are true:

      - W2 is in program order before R1.
      - There is no write access W3 to the same Location M, that is not a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access), that exists in Coherence order after W2.
      - There is no write access W4 to the same Location M, and all of the following are true for W4:

        - W4 is a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access).
        - W4 is in program order after W2 and in program order before R1.
        - There is a [`GCSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-161-GCSB?lang=en#isa_gcsb) effect that appears in program order after W4 and appears in program order before R1.

    The induced Memory Write effect is not the same as the one generated by a store instruction or one generated by a Branch with Link instruction. For example, the Memory Write effect:

    - Does not cause any exceptions.
    - Does not cause the side effects due to the translation.
    - Does not affect the state of the local Exclusives monitor.
    - Is transparent to translations and watchpoints.

    The Memory Write effect is single-copy-atomic at doubleword granularity.

    The instructions that can produce the Memory Read effect R1 mentioned above are:

    > Example D11-1
    >
    > For example, the `LDR` instruction in the following sequence is permitted to read any one of the following values:
    >
    > - `0x300`, since this is the value of a permitted induced Memory Write effect due to being the value of the most recent Explicit Memory Write effect.
    > - `0x10C`, since this is the value of a permitted induced Memory Write effect due to being the value of a recent GCS Memory Write effect.
    > - `0x110`, since this is the value of a permitted induced Memory Write effect due to being the value of a recent GCS Memory Write effect.
    > - `0x114`, since this is the value of the most recent GCS Memory Write effect.
    > - `0x000`, which is a permitted [Overshooting GCS Memory effect](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-10-Guarded-Control-Stack-data-accesses/-D11-10-1-Guarded-Control-Stack-data-access-behaviors?lang=en#mdterm_overshooting_gcs_memory_effect) occurring after the final `RET` in the sequence.
    >
    >   ```
    >   PC     Instruction
    >   0x0F0   STR             ;store 0x200 to an address 0x1000
    >   0x0F4   GCSB DSYNC
    >   0x0F8   BL              ;store 0xFC to the address 0x1000
    >   0x200   RET             ;load from the address 0x1000
    >   0x0FC   GCSB DSYNC
    >   0x100   STR             ;store 0x300 to the address 0x1000
    >   0x104   GCSB DSYNC      ;make STR visible to subsequent load/stores from
    >                           ;BL/RET instructions
    >   0x108   BL              ;store 0x10C to the address 0x1000
    >   0x200   RET             ;load from the address 0x1000
    >   0x10C   BL              ;store 0x110 to the address 0x1000
    >   0x200   RET             ;load from the address 0x1000
    >   0x110   BL              ;store 0x114 to the address 0x1000
    >   0x200   RET             ;load from the address 0x1000
    >   0x114   GCSB DSYNC      ;make load/stores from BL/RET instructions visible
    >                           ;to subsequent LDR instructions
    >   0x118   LDR             ;load from the address 0x1000
    >   ```
    >
    > Note that the values `0x200` and `0xFC` are not permitted in this example, due to the presence of one or more of the `GCSB DSYNC` instructions which prevent these previously stored values being permitted as the value of an induced Memory Write effect that would be visible to the `LDR` instruction. In particular, the `GCSB DSYNC` instruction at PC `0x104` bounds the limits of which values are permitted.
