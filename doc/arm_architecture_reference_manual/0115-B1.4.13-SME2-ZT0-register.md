# ​B1.4.13 SME2 ZT0 register

##### B1.4.13 SME2 ZT0 register

R KHZMV
:   A PE with [FEAT\_SME2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-4-The-Armv9-3-architecture-extension?lang=en#feat_feat_sme2) has a 512-bit register, *ZT0*, to store a lookup table.

R WDJBC
:   The ZT0 register holds 8-bit, 16-bit, or 32-bit lookup table elements that are stored in the least significant bits of 32-bit table entries. The lowest numbered 32 bits in the register hold table entry 0.

R JQXLS
:   The ZT0 register lookup table can be accessed using fully packed 2-bit or 4-bit indices from a numbered portion of one source Z*n* SVE scalable vector register.

I BRRGG
:   When the ZT0 register lookup table is addressed by 2-bit indices, four different table elements (0-3) of a given element size can be accessed. When the lookup table is addressed by 4-bit indices, 16 different table elements (0-15) of a given element size can be accessed.

R JKYRB
:   The indexed 8-bit, 16-bit, or 32-bit table elements are read from the ZT0 register and packed into consecutive or strided elements of an SVE Z vector or Z multi-vector operand.
