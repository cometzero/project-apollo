# ​H6.6.3 EDPRSR.{DLK, R} and reset state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H6-Debug-Reset-and-Powerdown-Support/-H6-6-Debug-OS-Save-and-Restore-sequences/-H6-6-3-EDPRSR--DLK--R--and-reset-state>

##### H6.6.3 EDPRSR.{DLK, R} and reset state

If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, accesses to [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) return an error when the Core power domain is off or in a retention state, meaning successful reads of [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) always return 1 for [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).PU.

When [FEAT\_Debugv8p4](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_debugv8p4) is implemented, and whenever [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) is not implemented, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).DLK is always 0.

If [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) is not implemented, [`DoubleLockStatus`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-5-DoubleLockStatus?lang=en#asl_func_doublelockstatus_0)`()` always returns FALSE.

If [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) is implemented and enabled, the behavior of all registers and fields except [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).DLK is the same as their behavior if [FEAT\_Debugv8p4](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_debugv8p4) is not implemented.

If [FEAT\_Debugv8p4](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_debugv8p4) is implemented [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).DLK is always 0 and does not give any information about the OS Double Lock.

[EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).R is UNKNOWN when [`DoubleLockStatus`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-5-DoubleLockStatus?lang=en#asl_func_doublelockstatus_0)`()`== TRUE. [OSDLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-23-OSDLR-EL1--OS-Double-Lock-Register?lang=en#reg_aarch64_osdlr_el1).DLK is cleared to 0 by a reset. If the Core power domain is powered up and entered reset state with the OS Double Lock locked, it is CONSTRAINED UNPREDICTABLE whether a read of [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr) while the PE is in reset state returns:

- [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).{DLK, R, PU} == {1, UNKNOWN, 1} indicating that the OS Double Lock is locked. This is not permitted from Armv8.2.
- [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).{DLK, R, PU} == {0, 1, 1} indicating that the PE is in reset state.
- [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).{DLK, R, PU} == {UNKNOWN, UNKNOWN, 0} indicating that the registers in the Core power domain cannot be accessed because the OS Double Lock is locked.

If the PE was powered up and the OS Double Lock was unlocked when the PE was reset, then [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).{DLK, R, PU} reads as {0, 1, 1} while the PE is in reset state.

On leaving reset state, [EDPRSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-46-EDPRSR--External-Debug-Processor-Status-Register?lang=en#reg_ext_edprsr).{DLK, R} reads as {0, 0}.
