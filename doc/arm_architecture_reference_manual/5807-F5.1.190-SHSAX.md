##### F5.1.190 SHSAX

Signed Halving Subtract and Add with Exchange exchanges the two halfwords of the second operand, performs one signed 16-bit integer subtraction and one signed 16-bit addition, halves the results, and writes the results to the destination register.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-190-SHSAX?lang=en#isa_shsax_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-190-SHSAX?lang=en#isa_shsax_iclass_t1)).

###### Encoding

```
SHSAX{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
if d == 15 || n == 15 || m == 15 then UnpredictableProcedure(); end;
```

let d : integer = UInt(Rd);

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let sum : integer  = SInt(R(n)[15:0]) + SInt(R(m)[31:16]);
    let diff : integer = SInt(R(n)[31:16]) - SInt(R(m)[15:0]);
    R(d)[15:0]  = sum[16:1];
    R(d)[31:16] = diff[16:1];
end;
```
