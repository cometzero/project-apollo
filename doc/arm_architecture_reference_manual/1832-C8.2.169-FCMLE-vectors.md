##### C8.2.169 FCMLE (vectors)

Floating-point compare less than or equal to vector

This instruction compares active floating-point elements in the first source vector being less than or equal to the corresponding elements in the second source vector, and places the boolean results of the comparison in the corresponding elements of the destination predicate. Inactive elements in the destination predicate register are set to zero. This instruction does not set the condition flags.

This is a pseudo-instruction of [FCM<cc> (vectors)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-166-FCM-cc---vectors-?lang=en#isa_fcmeq_p_p_zz). This means:

- The encodings in this description are named to match the encodings of [FCM<cc> (vectors)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-166-FCM-cc---vectors-?lang=en#isa_fcmeq_p_p_zz).
- The assembler syntax is used only for assembly, and is not used on disassembly.
- The description of [FCM<cc> (vectors)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-166-FCM-cc---vectors-?lang=en#isa_fcmeq_p_p_zz) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
FCMLE  <Pd>.<T>, <Pg>/Z, <Zm>.<T>, <Zn>.<T>
```

is equivalent to

```
FCMGE  <Pd>.<T>, <Pg>/Z, <Zn>.<T>, <Zm>.<T>
```
