##### G5.13.3 Determining the PAR format

The [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) is a 64-bit register that supports both 32-bit and 64-bit [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) formats. This section describes how the [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) format is determined, for returning a result from each of the groups of address translation instructions. The returned result might be the translated address, or might indicate a fault on the translation, see [Handling of faults and aborts during an address translation instruction](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-13-Address-translation-instructions/-G5-13-4-Handling-of-faults-and-aborts-during-an-address-translation-instruction?lang=en#beiijafd).

[ATS1C\*\*](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-13-Address-translation-instructions/-G5-13-1-Address-translation-instruction-naming-and-operation-summary?lang=en#beihjgfi) instructions
:   Address translations for the current state. From modes other than Hyp mode:

    - [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).EAE determines whether the result is returned using the 32-bit or the 64-bit [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) format.
    - If the implementation includes EL3, the translation performed is for the current security state and, depending on that state:

      - The Secure or Non-secure [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).EAE determines the [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) format.
      - The result is returned to the Secure or Non-secure instance of the [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par)

    Instructions executed in Hyp mode always return a result to the Non-secure [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par), using the 64-bit format.

[ATS12NSO\*\*](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-13-Address-translation-instructions/-G5-13-1-Address-translation-instruction-naming-and-operation-summary?lang=en#beiieaic) instructions
:   Address translations for the Non-secure PL1 and EL0 modes. These instructions return a result using the 64-bit [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) format if at least one of the following is true:

    - The Non-secure [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).EAE bit is set to 1.
    - The implementation includes EL2, and the value of [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).VM is 1.

    Otherwise, the instruction returns a result using the 32-bit [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) format.

    Instructions executed in a Secure PL1 mode return a result to the Secure [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par). Instructions executed in Hyp mode return a result to the Non-secure [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par).

[ATS1H\*](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-13-Address-translation-instructions/-G5-13-1-Address-translation-instruction-naming-and-operation-summary?lang=en#beieeeji) instructions
:   Address translations from Hyp mode. These instructions always return a result using the 64-bit [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par) format.

    Instructions executed in Secure Monitor mode return a result to the Secure [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par). Instructions executed in Non-secure Hyp mode return a result to the Non-secure [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par).
