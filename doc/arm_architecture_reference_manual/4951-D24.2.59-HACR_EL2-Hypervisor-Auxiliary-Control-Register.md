# ​D24.2.59 HACR_EL2, Hypervisor Auxiliary Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-59-HACR-EL2--Hypervisor-Auxiliary-Control-Register>

##### D24.2.59 HACR\_EL2, Hypervisor Auxiliary Control Register

The HACR\_EL2 characteristics are:

Purpose
:   Controls trapping to EL2 of IMPLEMENTATION DEFINED aspects of EL1 or EL0 operation.

    > #### Note
    >
    > Arm recommends that the values in this register do not cause unnecessary traps to EL2 when the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} == {1, 1}.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    This register has no effect if EL2 is not enabled in the current Security state.

    AArch64 System register HACR\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [HACR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-57-HACR--Hyp-Auxiliary-Configuration-Register?lang=en#reg_aarch32_hacr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to HACR\_EL2 are UNDEFINED.

Attributes
:   HACR\_EL2 is a 64-bit register.

###### Field descriptions

![](images/4951-D24.2.59-HACR_EL2-Hypervisor-Auxiliary-Control-Register-img01.svg)

IMPLEMENTATION DEFINED, bits [63:0]
:   IMPLEMENTATION DEFINED.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

elsif PSTATE.EL == EL0 then
    Undefined();
elsif PSTATE.EL == EL1 then
    if EffectiveHCR_EL2_NVx() IN {'xx1'} then
        AArch64_SystemAccessTrap(EL2, 0x18);
    else
        Undefined();
    end;

    X{64}(t) = HACR_EL2();

    X{64}(t) = HACR_EL2();
end;
