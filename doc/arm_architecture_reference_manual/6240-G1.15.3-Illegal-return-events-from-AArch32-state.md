# ​G1.15.3 Illegal return events from AArch32 state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-3-Illegal-return-events-from-AArch32-state>

##### G1.15.3 Illegal return events from AArch32 state

Throughout this section:

Return
:   In AArch32 state, refers to any of:

    - Execution of any exception return instruction.
    - Execution of a `DRPS` instruction in Debug state.
    - Exit from Debug state.

    If an exception or debug return from an Exception level using AArch32 triggers an illegal exception return, then bit[1] of the PC is either:

    - Zero.
    - The value of bit[1] of the return address for the exception or debug return.

    The choice between these two alternatives is made by the implementation, and might differ from instance to instance of an illegal exception return.

    > #### Note
    >
    > This means software must support both alternatives.

Saved process state value
:   In AArch32 state, refers to any of:

    - The value held in the [SPSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#cegceeii) for any exception return other than an exception return made by executing an `RFE` instruction.
    - The value read from memory that is to be restored to [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) by the execution of an `RFE` instruction.
    - The value held in the [SPSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#cegceeii) for the execution of a `DRPS` instruction in Debug state.
    - The value held in the [DSPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-30-DSPSR--Debug-Saved-Program-Status-Register?lang=en#reg_aarch32_dspsr) for a Debug state exit.

Link address
:   In AArch32 state, refers to any of:

    - The address held in the link register for any exception return other than an exception return made by executing an `ERET`, `LDM`, or `RFE` instruction.
    - The address held in [ELR\_hyp](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-52-ELR-hyp--Exception-Link-Register--Hyp-mode-?lang=en#reg_aarch32_elr_hyp) for any exception return made by executing an `ERET` instruction.
    - The address read from memory that is to be restored to the PC by the execution of an `LDM` or `RFE` instruction.
    - The address held in the [DLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-29-DLR--Debug-Link-Register?lang=en#reg_aarch32_dlr) for Debug state exit.

Configured from reset
:   Indicates the state determined on powerup or reset by a configuration input signal, or by another IMPLEMENTATION DEFINED mechanism.

The architecture has a generic mechanism for handling exception or debug returns to a mode or state that is illegal. In AArch32 state, this can occur as a result of any of the following situations:

- A return where the Exception level being returned to is higher than the current Exception level.
- A return where the mode being returned to is not implemented. For example:

  - A return to Hyp mode when EL2 is not implemented.
  - A return to Monitor mode, when EL3 is either not implemented or using AArch64 state.
- A return to EL2 when:

  - EL3 is implemented and using AArch64, and the values of [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).{NS, EEL2} 0.
  - EL3 is implemented and using AArch32, and the value of the [SCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-126-SCR--Secure-Configuration-Register?lang=en#reg_aarch32_scr).NS bit is 0.
- A return to Non-secure EL1 when:

  - EL2 is implemented and using AArch64, and the value of the [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE bit is 1.
  - EL2 is implemented and using AArch32, and the value of the [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).TGE bit is 1.
- A return where the value of the saved process state M[4:0] field is not a valid AArch32 PE mode for the implementation. [Table G1-5](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-9-AArch32-state-PE-modes?lang=en#tbl_cihghdgi) shows the valid M[4:0] values for AArch32 PE modes.

In these cases:

- [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL is set to 1, to indicate an illegal return.
- [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).M is unchanged. This means the PE mode does not change.
- The SS bit is handled in the same way as any other exception or debug return, see [Software Step exceptions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-11-Software-Step-exceptions?lang=en#bcgiidaj).
- The following [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) bits are restored from the saved process state value:

  - The N, Z, C, V Condition flags.
  - The Q Overflow or saturation flag.
  - The GE Greater than or Equal flags.
  - The E Endianness mapping bit.
  - The A, I, F exception mask bits.
  - The DIT Data Independent Timing bit.
- The [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).{IT, T} bits are each either:

  - Set to 0.
  - Copied from the saved process state in the [SPSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#cegceeii) for the PE mode in which the exception is handled.

  The choice between these two options is determined by an implementation, and might vary dynamically within an implementation. Correspondingly software must regard the value as being an UNKNOWN choice between the two values.
- The PC is restored from the link address, unless the illegal return is the execution of a `DRPS` instruction in Debug state.

When the value of the [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).IL bit is 1, any attempt to execute any instruction results in an Illegal Execution state exception. See [The Illegal Execution state exception](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-5-The-Illegal-Execution-state-exception?lang=en#chdffbac).

All aspects of the illegal return, other than the effects described in this section, are the same as for a legal return.
