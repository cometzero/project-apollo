Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-19-CNTPS-CTL-EL1--Counter-timer-Physical-Secure-Timer-Control-Register>

##### D24.10.19 CNTPS\_CTL\_EL1, Counter-timer Physical Secure Timer Control Register

The CNTPS\_CTL\_EL1 characteristics are:

Purpose
:   Control register for the secure physical timer, usually accessible at EL3 but configurably accessible at EL1 in Secure state.

Configuration
:   This register is present only when EL3 is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTPS\_CTL\_EL1 are UNDEFINED.

Attributes
:   CNTPS\_CTL\_EL1 is a 64-bit register.

###### Field descriptions

:   Reserved, RES0.

    When the value of the ENABLE bit is 1, ISTATUS indicates whether the timer condition is met. ISTATUS takes no account of the value of the IMASK bit. If the value of ISTATUS is 1 and the value of IMASK is 0 then the timer interrupt is asserted.

    When the value of the ENABLE bit is 0, the ISTATUS field is UNKNOWN.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    Access to this field is RO.

:   Timer interrupt mask bit. Permitted values are:

    Setting this bit to 0 disables the timer output signal, but the timer value accessible from [CNTPS\_TVAL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-21-CNTPS-TVAL-EL1--Counter-timer-Physical-Secure-Timer-TimerValue-Register?lang=en#reg_aarch64_cntps_tval_el1) continues to count down.

    > #### Note
    >
    > Disabling the output signal might be a power-saving option.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    end;
