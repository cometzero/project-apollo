# ​D1.1.2 Security states

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-1-Exception-levels/-D1-1-2-Security-states>

##### D1.1.2 Security states

R WPBBJ
:   The architecture defines the following *Security states*:

    - Secure state.
    - Non-secure state.
    - If [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is implemented, also both of:

      - Realm state.
      - Root state.

I XKGPG
:   Execution in:

    - Secure state cannot be observed or modified by an agent associated with any of:

      - Non-secure state.
      - Realm state.
    - Realm state cannot be observed or modified by an agent associated with any of:

      - Non-secure state.
      - Secure state.
    - Root state cannot be observed or modified by an agent associated with any other Security state.

R NRXJT
:   The architecture defines the following *Physical Address* (PA) spaces:

    - Secure.
    - Non-secure.
    - If [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme) is implemented, also the following:

      - Realm.
      - Root.
      - If [FEAT\_RME\_GDI](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_rme_gdi) is implemented, also both of:

        - System Agent.
        - Non-secure Protected.

I RKGZF
:   Memory assigned to the:

    - Secure physical address space cannot be read or modified by an agent associated with any of:

      - Non-secure state.
      - Realm state.
    - Realm physical address space cannot be read or modified by an agent associated with any of:

      - Non-secure state.
      - Secure state.
    - Root physical address space cannot be read or modified by an agent associated with any other Security state.

I YFMYJ
:   For details on the System Agent and Non-secure Protected PA spaces, see [Granular Data Isolation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D9-The-Granule-Protection-Check-Mechanism/-D9-3-Granular-Data-Isolation?lang=en#mdsec_granular_data_isolation).

R ZFPTR
:   EL3 is always in:

    - Secure state in a PE without [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme).
    - Root state in a PE with [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme).

I HGPBB
:   The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).{NSE, NS} selects the Security state of EL2 and lower.

R SGMFG
:   In a PE with [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme), EL2 and lower cannot be in Root state.

R DVTDD
:   EL2 can only be in Secure state if, in addition to the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).{NSE, NS} selecting Secure state, both of the following are true:

    - [FEAT\_SEL2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_sel2) is implemented.
    - The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).EEL2 is `0b1`.
