# ​D9.8 Explicit PAS control

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D9-The-Granule-Protection-Check-Mechanism/-D9-8-Explicit-PAS-control>

#### D9.8 Explicit PAS control

I HHZGR
:   The [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction provides an architected mechanism for directly programming the PA space association for regions of memory that support memory-side dynamic PA space association. For example, this might be needed for memory expansion devices that maintain a local association between PA and PA space at cache-line granularity.

R LGVKV
:   If [FEAT\_RME\_GPC3](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_rme_gpc3) is implemented, then an [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) `Xt` instruction is defined, which can be used to set the PA space of specific memory locations that are sensitive to the instruction.

R XDGGD
:   It is IMPLEMENTATION DEFINED which regions of memory support the [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction. For regions that support the [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction, the following are also IMPLEMENTATION DEFINED:

    - The supported PA spaces.
    - The meaning of the Target Attributes field when it is nonzero.

R BGQNC
:   The granularity that an [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction applies to is an IMPLEMENTATION DEFINED naturally-aligned value that is at least 64 bytes.

I DQJHQ
:   If the Target Attributes field is nonzero then the instruction might indicate a granularity larger than 64B.

I CDCDK
:   Arm expects that if [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) is issued to a location that does not support the [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction, or to a location that cannot be associated with the indicated PA space, then the instruction has no effect on the location and does not generate an External abort.

R JYZRN
:   An [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction is permitted, but not required, to change the contents of the affected locations.

R JHVFK
:   An [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction has the same ordering behavior as VA-based cache maintenance instructions issued to the Outer Shareable shareability domain. See [Ordering and completion of data and instruction cache instructions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D7-The-AArch64-System-Level-Memory-Model/-D7-5-Cache-support/-D7-5-9-A64-Cache-maintenance-instructions?lang=en#chdieehg) for more information. This includes aspects relating to the minimum size of cache lines, indicated by [CTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-41-CTR-EL0--Cache-Type-Register?lang=en#reg_aarch64_ctr_el0).DminLine.

    Completion of a `DSB SY` guarantees that the effects of an [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction are observable by all observers inside and outside of the Outer Shareable shareability domain.

I VQTWW
:   The [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction is UNDEFINED at EL2 and below.

R NZVRX
:   The [`APAS`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-18-APAS?lang=en#isa_apas_sys) instruction is not subject to granule protection checks.
