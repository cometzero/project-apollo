##### `0x81AB`, ISNP\_HIT\_REMOTE\_PRFM, Snoop hit in remote cache, software instruction prefetch

The counter counts each snoop generated by the PE in response to an instruction prefetch instruction counted by [ISNP\_HIT\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81A8--ISNP-HIT-PRFM--Snoop-hit--software-instruction-prefetch?lang=en#event_isnp_hit_prfm) that hits in a cache on a remote device.

The event is counted by the PE generating the snoop, not the PE being snooped.
