# ​J1.2.491 FFR

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-491-FFR>

##### J1.2.491 FFR

```
// FFR - accessor
// ==============
accessor FFR{width}() <=> value : bits(width)
begin
    getter
        assert width == CurrentVL() DIV 8;
        return _FFR[width-1:0];
    end;
    setter
        assert width == CurrentVL() DIV 8;
        if ConstrainUnpredictableBool(Unpredictable_SVEZEROUPPER) then
            _FFR = ZeroExtend{MAX_PL}(value);
        else
            _FFR[width-1:0] = value;
        end;
    end;
end;
```
