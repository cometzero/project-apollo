##### C8.2.244 FMOV (zero, unpredicated)

Move floating-point +0.0 to vector elements (unpredicated)

This instruction unconditionally broadcasts the floating-point constant +0.0 into each element of the destination vector. This instruction is unpredicated.

This is a pseudo-instruction of [DUP (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-128-DUP--immediate-?lang=en#isa_dup_z_i). This means:

- The encodings in this description are named to match the encodings of [DUP (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-128-DUP--immediate-?lang=en#isa_dup_z_i).
- The assembler syntax is used only for assembly, and is not used on disassembly.
- The description of [DUP (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-128-DUP--immediate-?lang=en#isa_dup_z_i) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
FMOV  <Zd>.<T>, #0.0
```

is equivalent to

```
DUP  <Zd>.<T>, #0
```
