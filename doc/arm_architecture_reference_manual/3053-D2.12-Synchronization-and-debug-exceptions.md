#### D2.12 Synchronization and debug exceptions

The behavior of debug depends on all of the following:

- The state of the external debug authentication interface.
- Indirect reads of:

  - External debug registers.
  - System registers, including system debug registers.
  - Special-purpose registers.

If a change is made to any of these, the effect of that change on debug exception generation cannot be relied on until after a [Context Synchronization event](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babdjfhg) has occurred. Similarly, the effect of the change on the software step state machine cannot be relied on until after a [Context Synchronization event](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babdjfhg) has occurred.

For any instructions executed between the time when the change is made and the time when the next [Context Synchronization event](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babdjfhg) occurs, it is CONSTRAINED UNPREDICTABLE whether debug uses the state of the PE before the change, or the state of the PE after the change.

> Example D2-12 Example of synchronization and Breakpoint exception generation
>
> 1. Software changes [MDSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-20-MDSCR-EL1--Monitor-Debug-System-Control-Register?lang=en#reg_aarch64_mdscr_el1).MDE from 0 to 1.
> 2. An instruction is executed, that would cause a Breakpoint exception if self-hosted debug uses the state of the PE after the change.
> 3. A [Context Synchronization event](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babdjfhg) occurs.
>
> In this case, it is CONSTRAINED UNPREDICTABLE whether the instruction generates a Breakpoint exception.

> Example D2-13 Example of synchronization and debug exceptions generation
>
> 1. Software unlocks the OS Lock.
> 2. The PE executes some instructions.
> 3. A [Context Synchronization event](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babdjfhg) occurs.
>
> During the time when the PE is executing some instructions, step 2, it is CONSTRAINED UNPREDICTABLE whether debug exceptions other than Breakpoint Instruction exceptions can be generated.
