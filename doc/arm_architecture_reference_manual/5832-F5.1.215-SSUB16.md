##### F5.1.215 SSUB16

Signed Subtract 16 performs two 16-bit signed integer subtractions, and writes the results to the destination register. It sets [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).GE according to the results of the subtractions.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-215-SSUB16?lang=en#isa_ssub16_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-215-SSUB16?lang=en#isa_ssub16_iclass_t1)).

```
SSUB16{<c>}{<q>}  {<Rd>, }<Rn>, <Rm>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
if d == 15 || n == 15 || m == 15 then UnpredictableProcedure(); end;
```

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let diff1 : integer = SInt(R(n)[15:0]) - SInt(R(m)[15:0]);
    let diff2 : integer = SInt(R(n)[31:16]) - SInt(R(m)[31:16]);
    R(d)[15:0]  = diff1[15:0];
    R(d)[31:16] = diff2[15:0];
    PSTATE.GE[1:0] = if diff1 >= 0 then ‘11’ else ‘00’;
    PSTATE.GE[3:2] = if diff2 >= 0 then ‘11’ else ‘00’;
end;
```
