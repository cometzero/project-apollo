# ​D24.7.10 PMSDSFR_EL1, Sampling Data Source Filter Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-10-PMSDSFR-EL1--Sampling-Data-Source-Filter-Register>

##### D24.7.10 PMSDSFR\_EL1, Sampling Data Source Filter Register

The PMSDSFR\_EL1 characteristics are:

Purpose
:   Controls sample filtering by Data Source.

Configuration
:   This register is present only when FEAT\_SPE\_FDS is implemented. Otherwise, direct accesses to PMSDSFR\_EL1 are UNDEFINED.

Attributes
:   PMSDSFR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5304-D24.7.10-PMSDSFR_EL1-Sampling-Data-Source-Filter-Register-img01.svg)

S<m> , bits [m], for m = 63 to 0
:   S[<m>] is the Data Source filter for IMPLEMENTATION DEFINED Data Source <m>.
