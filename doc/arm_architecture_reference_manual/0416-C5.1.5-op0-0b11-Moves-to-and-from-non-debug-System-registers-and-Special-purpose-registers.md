# ​C5.1.5 op0 == 0b11, Moves to and from non-debug System registers and Special-purpose registers

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-1-The-System-instruction-class-encoding-space/-C5-1-5-op0----0b11--Moves-to-and-from-non-debug-System-registers-and-Special-purpose-registers>

##### C5.1.5 op0 == `0b11`, Moves to and from non-debug System registers and Special-purpose registers

The instructions that move data to and from non-debug System registers and Special-purpose registers are encoded with `op0` == `0b11`, except that some of this encoding space is reserved for IMPLEMENTATION DEFINED functionality. The encoding of these instructions is:

![](images/0416-C5.1.5-op0-0b11-Moves-to-and-from-non-debug-System-registers-and-Special-purpose-registers-img01.svg)

The value of `CRn` provides the next level of decode of these instructions, as follows:

`CRn` == { `0b0000`, `0b0001`, `0b0010`, `0b0011`, `0b0101`, `0b0110`, `0b0111`, `0b1001`, `0b1010`, `0b1100`, `0b1101`, `0b1110`}
:   See [Instructions for accessing non-debug System registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D23-AArch64-System-Register-Encoding/-D23-3-Moves-to-and-from-non-debug-System-registers--Special-purpose-registers/-D23-3-1-Instructions-for-accessing-non-debug-System-registers?lang=en#beijbefg).

`CRn` == { `0b0100`}
:   See [Instructions for accessing Special-purpose registers](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-1-The-System-instruction-class-encoding-space/-C5-1-5-op0----0b11--Moves-to-and-from-non-debug-System-registers-and-Special-purpose-registers?lang=en#cihdehgb).

`CRn` == { `0b1011`, `0b1111`}
:   See [Reserved encodings for IMPLEMENTATION DEFINED registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D23-AArch64-System-Register-Encoding/-D23-3-Moves-to-and-from-non-debug-System-registers--Special-purpose-registers/-D23-3-2-Reserved-encodings-for-IMPLEMENTATION-DEFINED-registers?lang=en#beicjbih).

###### C5.1.5.1 Instructions for accessing Special-purpose registers

The value of `CRn` provides the next level of decode of these instructions. Accesses to Special-purpose registers are identified by the `CRn` value being `0b0100`, with the exception of [RGSR\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-14-RGSR-EL1--Random-Allocation-Tag-Seed-Register-?lang=en#reg_aarch64_rgsr_el1).

The A64 instructions for accessing Special-purpose registers are:

```
    MSR <Special-purpose_register>, Xt    ; Write to Special-purpose register
    MRS Xt, <Special-purpose_register>    ; Read from Special-purpose register
```

Where `<Special-purpose_register>` is the register name, for example [SP\_EL0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-15-SP-EL0--Stack-Pointer--EL0-?lang=en#reg_aarch64_sp_el0).

The encoding for Special-purpose register accesses is:

![](images/0416-C5.1.5-op0-0b11-Moves-to-and-from-non-debug-System-registers-and-Special-purpose-registers-img02.svg)

For the encoding of RGSR\_EL1, see [RGSR\_EL1, Random Allocation Tag Seed Register](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-14-RGSR-EL1--Random-Allocation-Tag-Seed-Register-?lang=en#reg_aarch64_rgsr_el1).

The full list of Special-purpose registers is in [Table C5-9](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-1-The-System-instruction-class-encoding-space/-C5-1-5-op0----0b11--Moves-to-and-from-non-debug-System-registers-and-Special-purpose-registers?lang=en#tbl_aarch64_register_encoding_table_mrsmsr_op011_mrsmsr_crn0100). The characteristic of a Special-purpose register is that all direct and indirect reads and writes to the register appear to occur in program order relative to other instructions, without the need for any explicit synchronization.

[Table C5-9](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-1-The-System-instruction-class-encoding-space/-C5-1-5-op0----0b11--Moves-to-and-from-non-debug-System-registers-and-Special-purpose-registers?lang=en#tbl_aarch64_register_encoding_table_mrsmsr_op011_mrsmsr_crn0100) lists the encodings for `op1`, `CRm`, and `op2` fields for accesses to the Special-purpose registers in AArch64.
