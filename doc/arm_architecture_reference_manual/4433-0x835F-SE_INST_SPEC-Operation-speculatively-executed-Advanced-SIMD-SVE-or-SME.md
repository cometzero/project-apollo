##### `0x835F`, SE\_INST\_SPEC, Operation speculatively executed, Advanced SIMD, SVE, or SME

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) operation counted by [INST\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x001B--INST-SPEC--Operation-speculatively-executed?lang=en#event_inst_spec) that is classified as an Advanced SIMD, SVE, or SME operation.

See [ASE\_SVE\_INST\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8007--ASE-SVE-INST-SPEC--Operation-speculatively-executed--Advanced-SIMD-or-SVE?lang=en#event_ase_sve_inst_spec) and [SME\_INST\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x835E--SME-INST-SPEC--Operation-speculatively-executed--SME?lang=en#event_sme_inst_spec) for these classifications.
