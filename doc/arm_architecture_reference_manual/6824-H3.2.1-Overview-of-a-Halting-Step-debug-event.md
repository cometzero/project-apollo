# ​H3.2.1 Overview of a Halting Step debug event

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-1-Overview-of-a-Halting-Step-debug-event>

##### H3.2.1 Overview of a Halting Step debug event

The behavior of Halting Step is defined by a state machine, shown in [Figure H3-1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events/-H3-2-2-The-Halting-Step-state-machine?lang=en#fig_babedaea). A Halting Step debug event executes a single instruction and then returns control to the debugger. When the debugger software wants to execute a Halting Step:

1. With the PE in Debug state, the debugger activates Halting Step.
2. The debugger signals the PE to exit Debug state and return to the instruction that is to be stepped.
3. The PE executes that single instruction.
4. The PE enters Debug state before executing the next instruction.

However, an exception might be generated during this process. That is, one of the following occurs:

- A synchronous exception generated by the instruction being stepped.
- An asynchronous exception taken before or during the instruction being stepped, to the extent permitted by the definition of a precise exception, without completing execution of the instruction being stepped.
- An asynchronous exception taken after completing execution of the instruction being stepped, before the PE enters Debug state.

See also [Definition of a precise exception and imprecise exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-4-Exceptions/-D1-4-1-Exception-entry-terminology?lang=en#mdsec_definition_of_precise_exception_imprecise_exception).

Halting Step has its own enable control bit, [EDECR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-28-EDECR--External-Debug-Execution-Control-Register?lang=en#reg_ext_edecr).SS and [EDESR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-29-EDESR--External-Debug-Event-Status-Register?lang=en#reg_ext_edesr).SS.

> #### Note
>
> Because the Halting Step state machine states occur as a result of normal PE operation, the states can be described as both:
>
> - PE states.
> - Halting Step states.
