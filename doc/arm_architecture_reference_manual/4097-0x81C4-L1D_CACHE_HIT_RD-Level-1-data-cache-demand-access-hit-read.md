##### `0x81C4`, L1D\_CACHE\_HIT\_RD, Level 1 data cache demand access hit, read

The counter counts each demand read counted by [L1D\_CACHE\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0040--L1D-CACHE-RD--Level-1-data-cache-access--read?lang=en#event_l1d_cache_rd) that hits in the Level 1 data or unified cache.
