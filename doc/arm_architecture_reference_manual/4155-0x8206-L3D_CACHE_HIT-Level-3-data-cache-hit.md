##### `0x8206`, L3D\_CACHE\_HIT, Level 3 data cache hit

The counter counts each access counted by [L3D\_CACHE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x002B--L3D-CACHE--Level-3-data-cache-access?lang=en#event_l3d_cache) that hits in the Level 3 data or unified cache.
