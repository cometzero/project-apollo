##### C6.2.483 TSB

Trace synchronization barrier

This instruction is a barrier that synchronizes the trace operations of instructions, see [Trace Synchronization Barrier (TSB)](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-8-Trace-Synchronization-Barrier?lang=en#beijjegj). For information about the synchronization behavior when a `DSB` instruction follows a `TSB` instruction in program order, see:

- [Trace synchronization and memory barriers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-7-Trace-synchronization-and-memory-barriers?lang=en#chdbjjcgf6).
- [Synchronization in self-hosted trace](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D3-AArch64-Self-hosted-Trace/-D3-4-Synchronization-in-self-hosted-trace?lang=en#babehbgd).

If [FEAT\_TRF](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_trf) is not implemented, this instruction executes as a `NOP`.
