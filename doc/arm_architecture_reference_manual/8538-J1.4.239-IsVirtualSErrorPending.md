##### J1.4.239 IsVirtualSErrorPending

```
// IsVirtualSErrorPending()
// ========================
// Return TRUE if a virtual SError interrupt is pending.
func IsVirtualSErrorPending() => boolean
begin
    if ELUsingAArch32(EL2) then
        return HCR().VA == ‘1’;
    else
        return HCR_EL2().VSE == ‘1’;
    end;
end;
```
