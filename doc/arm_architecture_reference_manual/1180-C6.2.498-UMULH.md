# ​C6.2.498 UMULH

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-498-UMULH>

##### C6.2.498 UMULH

Unsigned multiply high

This instruction multiplies two 64-bit register values, and writes bits[127:64] of the 128-bit result to the 64-bit destination register.

![](images/1180-C6.2.498-UMULH-img01.svg)

###### Encoding

```
UMULH  <Xd>, <Xn>, <Xm>
```

###### Decode for this encoding

```
let d : integer{} = UInt(Rd);
let n : integer{} = UInt(Rn);
let m : integer{} = UInt(Rm);
```

###### Assembler Symbols

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Xn>
:   ​

    Is the 64-bit name of the first general-purpose source register holding the multiplicand, encoded in the “Rn” field.

<Xm>
:   ​

    Is the 64-bit name of the second general-purpose source register holding the multiplier, encoded in the “Rm” field.

###### Operation

```
let operand1 : bits(64) = X{}(n);
let operand2 : bits(64) = X{}(m);
let result : integer = UInt(operand1) * UInt(operand2);
X{64}(d) = result[127:64];
```

###### Operational Information

This instruction is a data-independent-time instruction as described in [About PSTATE.DIT](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-5-Software-control-features-and-EL0/-B1-5-6-About-PSTATE-DIT?lang=en#beiccddab3).
