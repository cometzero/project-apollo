##### C6.2.167 GCSSS1

Guarded Control Stack switch stack 1

This instruction validates that the stack being switched to contains a Valid GCS cap record, stores an In-progress GCS cap record to the stack that is being switched to, and sets the current GCS pointer register to the stack that is being switched to.

If the instruction generates a synchronous Data Abort exception, Watchpoint exception, GPC exception, or GCS Data Check exception, the value of [GCSPR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#gcspr_elx) for the current Exception level is restored to the value held in the register before the instruction was executed.

For more information, see [GCSSS1, Guarded Control Stack Switch Stack 1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-9-A64-System-instructions-for-the-Guarded-Control-Stack/-C5-9-6-GCSSS1--Guarded-Control-Stack-Switch-Stack-1?lang=en#reg_aarch64_gcsss1).

This is an alias of [SYS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-475-SYS?lang=en#isa_sys). This means:

- The encodings in this description are named to match the encodings of [SYS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-475-SYS?lang=en#isa_sys).
- The description of [SYS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-475-SYS?lang=en#isa_sys) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
GCSSS1  <Xt>
```

is equivalent to

```
SYS  #3, C7, C7, #2, <Xt>
```

and is always the preferred disassembly.

###### Assembler Symbols

<Xt>
:   ​

    Is the 64-bit name of the general-purpose source register, encoded in the “Rt” field.
