# ​J1.3.73 DecodeRegShift

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-73-DecodeRegShift>

##### J1.3.73 DecodeRegShift

```
// DecodeRegShift()
// ================
func DecodeRegShift(srtype : bits(2)) => SRType
begin
    var shift_t : SRType;
    case srtype of
        when ‘00’ =>  shift_t = SRType_LSL;
        when ‘01’ =>  shift_t = SRType_LSR;
        when ‘10’ =>  shift_t = SRType_ASR;
        when ‘11’ =>  shift_t = SRType_ROR;
    end;
    return shift_t;
end;
```
