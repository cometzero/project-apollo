##### `0x843A`, DSNP\_HITM\_N3\_WR, Snoop hit in cache at distance 3, demand data write, modified

The counter counts each snoop generated by the PE in response to a demand [Memory-write operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caccfcjj) counted by [DSNP\_HIT\_N3\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x840A--DSNP-HIT-N3-WR--Snoop-hit-in-cache-at-distance-3--demand-data-write?lang=en#event_dsnp_hit_n3_wr) that accesses a previously modified cache location.
