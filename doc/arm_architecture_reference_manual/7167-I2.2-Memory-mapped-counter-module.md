# ​I2.2 Memory-mapped counter module

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module>

#### I2.2 Memory-mapped counter module

The memory-mapped counter module provides top-level control of the system counter. The [CNTControlBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-3-Counter-module-control-and-status-register-summary?lang=en#tbl_chdbeaba) frame holds the registers for the memory-mapped counter, and provides:

- An RW control register, [CNTCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-2-CNTCR--Counter-Control-Register?lang=en#reg_ext_cntcr), that provides:

  - An enable bit for the system counter.
  - An enable bit for Halt-on-debug. For more information, see [Halt-on-debug](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-2-Halt-on-debug?lang=en#babeegie).
  - A field that can be written to request a change to the [Counter resolution](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-1-About-the-Generic-Timer/-D12-1-2-The-system-counter?lang=en#counter_resolution_aarch64). This mechanism means that, for example, if the [Counter resolution](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-1-About-the-Generic-Timer/-D12-1-2-The-system-counter?lang=en#counter_resolution_aarch64) is halved then the increment to the counter at each tick of the clock is doubled.

    For more information, see [Control of counter resolution and increment](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-1-Control-of-counter-resolution-and-increment?lang=en#cjhceedj).

  Writes to this register are rare.
- A RO status register, [CNTSR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-15-CNTSR--Counter-Status-Register?lang=en#reg_ext_cntsr), that provides:

  - A bit that indicates whether the system counter is halted because of an asserted Halt-on-debug signal.
  - A field that indicates whether a requested change to the [Counter resolution](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-1-About-the-Generic-Timer/-D12-1-2-The-system-counter?lang=en#counter_resolution_aarch64) has completed.
- Two contiguous 32-bit RW registers that hold the current system counter value, [CNTCV](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-3-CNTCV--Counter-Count-Value-register?lang=en#reg_ext_cntcv). If the system supports 64-bit atomic accesses, these two registers must be accessible by such accesses.

  The system counter must be disabled before writing to these registers, otherwise the effect of the write is UNPREDICTABLE.

  Writes to these registers are rare.
- A *Frequency modes table* of one or more 32-bit entries, where:

  - The first entry in the table defines the *base frequency* of the system counter. It is IMPLEMENTATION DEFINED whether the base frequency indicates the effective frequency of the counter, or the maximum [Counter resolution](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-1-About-the-Generic-Timer/-D12-1-2-The-system-counter?lang=en#counter_resolution_aarch64).

    Arm recommends that the base frequency indicates the maximum [Counter resolution](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-1-About-the-Generic-Timer/-D12-1-2-The-system-counter?lang=en#counter_resolution_aarch64).
  - Each subsequent entry in the table defines an alternative frequency of the system counter, that must be an exact divisor of the base frequency.

  A 32-bit zero entry immediately follows the last table entry.

  This table can be RO or RW. For more information, see [The Frequency modes table](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-1-Control-of-counter-resolution-and-increment?lang=en#babcdibi).

In an implementation with multiple physical address spaces, [CNTControlBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-3-Counter-module-control-and-status-register-summary?lang=en#tbl_chdbeaba) is only accessible by accesses from the most secure physical address space. For example, in a system with Secure and Non-secure memory maps, [CNTControlBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-3-Counter-module-control-and-status-register-summary?lang=en#tbl_chdbeaba) is only accessible by Secure accesses. For example, in a system with [FEAT\_RME](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_rme), [CNTControlBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-3-Counter-module-control-and-status-register-summary?lang=en#tbl_chdbeaba) is only accessible by Root accesses.

In addition, the [CNTReadBase](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-2-Memory-mapped-counter-module/-I2-2-3-Counter-module-control-and-status-register-summary?lang=en#tbl_babbbejj) frame includes a read-only copy of the system counter value, [CNTCV](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-3-CNTCV--Counter-Count-Value-register?lang=en#reg_ext_cntcv), as two contiguous 32-bit RO registers. If the system supports 64-bit atomic accesses, these two registers must be accessible by such accesses.
