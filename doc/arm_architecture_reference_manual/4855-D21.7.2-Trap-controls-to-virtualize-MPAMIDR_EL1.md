# ​D21.7.2 Trap controls to virtualize MPAMIDR_EL1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-7-Virtualization-support/-D21-7-2-Trap-controls-to-virtualize-MPAMIDR-EL1>

##### D21.7.2 Trap controls to virtualize MPAMIDR\_EL1

I LDNNY
:   An EL2 hypervisor is able to provide a virtual view of [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1) to an EL1 guest OS by using [MPAMHCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-12-MPAMHCR-EL2--MPAM-Hypervisor-Control-Register--EL2-?lang=en#reg_aarch64_mpamhcr_el2).TRAP\_MPAMIDR\_EL1, or [MPAM2\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-3-MPAM2-EL2--MPAM2-Register--EL2-?lang=en#reg_aarch64_mpam2_el2).TIDR if [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).HAS\_TIDR is 1, to trap EL1 accesses to [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1). The virtual view shows [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).PARTID\_MAX as the largest *virtual PARTID* that the EL2 hypervisor is providing for the EL1 guest OS to use.
