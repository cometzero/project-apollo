# ​C8.2.34 ASR (immediate, unpredicated)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-34-ASR--immediate--unpredicated->

##### C8.2.34 ASR (immediate, unpredicated)

Arithmetic shift right by immediate (unpredicated)

This instruction shifts right by immediate, preserving the sign bit, each element of the source vector, and places the results in the corresponding elements of the destination vector. The immediate shift amount is an unsigned value in the range 1 to number of bits per element. This instruction is unpredicated.

###### SVE

###### (FEAT\_SVE || FEAT\_SME)

![](images/1697-C8.2.34-ASR-immediate-unpredicated-img01.svg)

###### Encoding

```
ASR  <Zd>.<T>, <Zn>.<T>, #<const>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SVE) && !IsFeatureImplemented(FEAT_SME) then
    EndOfDecode(Decode_UNDEF);
end;
let tsize : bits(4) = tszh::tszl;
if tsize == ‘0000’ then EndOfDecode(Decode_UNDEF); end;
let esize : integer{} = 8 << HighestSetBitNZ(tsize);
let n : integer = UInt(Zn);
let d : integer = UInt(Zd);
let shift : integer = (2 * esize) - UInt(tsize::imm3);
```

<Zn>
:   ​

    Is the name of the source scalable vector register, encoded in the “Zn” field.

<const>
:   ​

    Is the immediate shift amount, in the range 1 to number of bits per element, encoded in “tszh:tszl:imm3”.

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let elements : integer = VL DIV esize;
let operand1 : bits(VL) = Z{}(n);
var result : bits(VL);
for e = 0 to elements-1 do
    let element1 : bits(esize) = operand1[e*:esize];
    result[e*:esize] = ASR(element1, shift);
end;
Z{VL}(d) = result;
```
