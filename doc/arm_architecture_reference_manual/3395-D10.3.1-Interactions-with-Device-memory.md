# ​D10.3.1 Interactions with Device memory

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D10-The-Memory-Tagging-Extension/-D10-3-Memory-region-tagging-types/-D10-3-1-Interactions-with-Device-memory>

##### D10.3.1 Interactions with Device memory

I NLXDF
:   If a memory region has the Device memory type, the memory region is not *Tagged*.

R WHXBY
:   A write of data by an [STZGM](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-455-STZGM?lang=en#isa_stzgm) instruction to any type of Device memory is CONSTRAINED UNPREDICTABLE between:

    - Zeroing the data at the specified locations.
    - Generating an Alignment Fault determined by the memory type.

R JMXVK
:   For a [DC GVA](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-3-A64-System-instructions-for-cache-maintenance/-C5-3-30-DC-GVA--Data-Cache-set-Allocation-Tag-by-VA?lang=en#reg_aarch64_dc_gva) instruction to any type of Device memory it is CONSTRAINED UNPREDICTABLE whether the instruction generates an Alignment Fault determined by the memory type.
