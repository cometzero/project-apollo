# ​D19.1.1 Branch records

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records>

##### D19.1.1 Branch records

I JBTBH
:   Each *Branch record* consists of 3 registers:

    - [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).
    - [BRBSRC<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-8-BRBSRC-n--EL1--Branch-Record-Buffer-Source-Address-Register--n---n---0---31?lang=en#reg_aarch64_brbsrcn_el1).
    - [BRBTGT<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-10-BRBTGT-n--EL1--Branch-Record-Buffer-Target-Address-Register--n---n---0---31?lang=en#reg_aarch64_brbtgtn_el1).

I GBCQW
:   Taken branch instructions, as defined by [Branches, Exception generating, and System instructions](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-1-Branches--Exception-generating--and-System-instructions?lang=en#cegbjhdb), generate a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record).

I LFVJR
:   Exceptions generate a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record).

R RPVXK
:   A *Half-source Branch record* has [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).VALID set to `0b10`.

R LPLYK
:   A *Half-target Branch record* has [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).VALID set to `0b01`.

R GSMRH
:   A *Full Branch record* has [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).VALID set to `0b11`.

R XRHTY
:   [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).VALID indicates the validity of a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record):

    - If [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).VALID is `0b00`, the [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is invalid.
    - Otherwise, the [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is valid.

R MLGCF
:   When a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is generated for any branch or exception which does not transition between a BRBE Prohibited region and a BRBE Non-prohibited region, the [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is a [*Full Branch record*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_full_branch_record).

    See [Branch records for exceptions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-5-Branch-records-for-exceptions?lang=en#mdsec_brb_exception_generation) and [Branch records for exception returns](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-6-Branch-records-for-exception-returns?lang=en#mdsec_brb_exception_rtn_generation) for more details on when a [Half-source Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_half_source_branch_record) or a [Half-target Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_half_target_branch_record) is generated.

I ZCHRF
:   When an Instruction Synchronization Barrier instruction causes a Context synchronization event which synchronizes an update to one or more System registers which are indirectly read when generating a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record), the synchronization of those register updates occurs before the registers are indirectly read. Such order is generally consistent with indirect reads of System registers performed by events which cause a Context synchronization event.

R ZHDCC
:   When an exception or exception return instruction causes a Context synchronization event which synchronizes an update to one or more System registers which are used to determine whether the source of the [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is from a BRBE Prohibited region, indirect reads of those System registers are permitted to occur before the Context synchronization event. Specifically, the registers indirectly read by [`BranchRecordAllowed`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-19-BranchRecordAllowed?lang=en#asl_func_branchrecordallowed_1)`()`. All other indirect reads of System registers used for creation of a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) occur after the Context synchronization event, including those for determining whether the [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is filtered or not, and those used for determining whether Branch recording is prohibited at the target.

R TWYWS
:   Where an operation such as an exception or exception return causes a Context synchronization event and that synchronizes a System register update which permits a BRBE freeze event to occur, and the same operation also changes the PE state to prevent a BRBE freeze event from occurring, it is IMPLEMENTATION SPECIFIC whether the BRBE freeze event occurs.

R CBHRY
:   The reason for the *Branch record* is captured in [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).TYPE.
