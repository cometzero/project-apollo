# ​H7.1.2 Registers implemented by the PC Sample-based Profiling Extension

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H7-The-PC-Sample-based-Profiling-Extension/-H7-1-About-the-PC-Sample-based-Profiling-Extension/-H7-1-2-Registers-implemented-by-the-PC-Sample-based-Profiling-Extension>

##### H7.1.2 Registers implemented by the PC Sample-based Profiling Extension

The PC Sample-based Profiling Extension is implemented by either [FEAT\_PCSRv8](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pcsrv8) or [FEAT\_PCSRv8p2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pcsrv8p2):

- If [FEAT\_PCSRv8](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pcsrv8) is implemented then the PC Sample-based Profiling Extension registers are implemented in the external debug register space. [EDDEVID1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-21-EDDEVID1--External-Debug-Device-ID-Register-1?lang=en#reg_ext_eddevid1).PCSample identifies when [FEAT\_PCSRv8](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pcsrv8) is implemented and which PC Sample-based Profiling Extension registers are implemented.
- If [FEAT\_PCSRv8p2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pcsrv8p2) is implemented then the PC Sample-based Profiling Extension registers are implemented in the Performance Monitors memory-mapped register space. [PMDEVID](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-27-PMDEVID--Performance-Monitors-Device-ID-register?lang=en#reg_pmu_pmdevid).PCSample identifies when [FEAT\_PCSRv8p2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pcsrv8p2) is implemented.

An implementation is not permitted to include both [FEAT\_PCSRv8](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pcsrv8) and [FEAT\_PCSRv8p2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pcsrv8p2). [FEAT\_PCSRv8](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pcsrv8) is not permitted from Armv8.2.

If [FEAT\_PCSRv8](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_pcsrv8) is implemented:

- The following external debug registers can be implemented:

  - [EDCIDSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-16-EDCIDSR--External-Debug-Context-ID-Sample-Register?lang=en#reg_ext_edcidsr).
  - [EDPCSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-35-EDPCSR--External-Debug-Program-Counter-Sample-Register?lang=en#reg_ext_edpcsr).
  - [EDVIDSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-50-EDVIDSR--External-Debug-Virtual-Context-Sample-Register?lang=en#reg_ext_edvidsr).

  See [External debug interface registers](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers/-H8-6-External-debug-interface-registers?lang=en#cihchffb).
- If [FEAT\_VHE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-2-The-Armv8-1-architecture-extension?lang=en#feat_feat_vhe) is implemented, [EDSCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-48-EDSCR--External-Debug-Status-and-Control-Register?lang=en#reg_ext_edscr).SC2 controls what PC Sample-based Profiling samples.

If [FEAT\_PCSRv8p2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pcsrv8p2) is implemented and the 64-bit external PMU programmers’ model extension is not implemented, the following PC Sample-based Profiling Extension registers can be implemented in the Performance Monitors memory-mapped register space:

- [PMCID1SR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-13-PMCID1SR--CONTEXTIDR-EL1-Sample-Register?lang=en#reg_pmu_pmcid1sr) and [PMCID2SR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-14-PMCID2SR--CONTEXTIDR-EL2-Sample-Register?lang=en#reg_pmu_pmcid2sr).
- [PMPCSR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-48-PMPCSR--Program-Counter-Sample-Register?lang=en#reg_pmu_pmpcsr).
- [PMVIDSR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-60-PMVIDSR--VMID-Sample-Register?lang=en#reg_pmu_pmvidsr).

When the 64-bit external PMU programmers’ model extension is implemented, the PC Sample-based Profiling Extension registers are:

- PMCCIDSR.
- [PMPCSR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-48-PMPCSR--Program-Counter-Sample-Register?lang=en#reg_pmu_pmpcsr).
- PMVCIDSR.

See [Performance Monitors external register views](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-2-External-Performance-Monitors-registers-summary/-I5-2-1-Performance-Monitors-external-register-views?lang=en#babfiifd).

If [FEAT\_PCSRv8p2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pcsrv8p2) is implemented but the Performance Monitors Extension is not implemented, then the PC Sample-based Profiling Extension registers are implemented in their own memory-mapped register space, within the area that is reserved for the Performance Monitors, see [Table H7-1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H7-The-PC-Sample-based-Profiling-Extension/-H7-1-About-the-PC-Sample-based-Profiling-Extension/-H7-1-2-Registers-implemented-by-the-PC-Sample-based-Profiling-Extension?lang=en#tbl_cegiajhb). If CoreSight compliance is required:

- The management registers are defined as in [Table K5-4](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-1-CoreSight-interface-register-map?lang=en#tbl_cacheccj).
- The support for PC Sample-based profiling is defined in the following registers:

  - [PMDEVTYPE](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-28-PMDEVTYPE--Performance-Monitors-Device-Type-register?lang=en#reg_pmu_pmdevtype).MAJOR has the value `0x0`.
  - [PMDEVARCH](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-26-PMDEVARCH--Performance-Monitors-Device-Architecture-register?lang=en#reg_pmu_pmdevarch).ARCHID has the value `0x0A10` or `0x0A20`.

For more information, see [PMDEVARCH](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-26-PMDEVARCH--Performance-Monitors-Device-Architecture-register?lang=en#reg_pmu_pmdevarch).
