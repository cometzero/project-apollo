##### `0x8193`, ISNP\_HIT\_REMOTE\_RD, Snoop hit in remote cache, demand instruction fetch

The counter counts each snoop generated by the PE in response to a demand [Instruction memory access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cachjjbe) counted by [ISNP\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8190--ISNP-HIT-RD--Snoop-hit--demand-instruction-fetch?lang=en#event_isnp_hit_rd) that hits in a cache on a remote device.

The event is counted by the PE generating the snoop, not the PE being snooped.
