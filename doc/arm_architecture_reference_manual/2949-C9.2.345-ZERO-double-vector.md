##### C9.2.345 ZERO (double-vector)

Zero ZA double-vector groups

This instruction zeroes one, two, or four ZA double-vector groups.

The double-vector group within all of, each half of, or each quarter of the ZA array is selected by the sum of the vector select register and offset range, modulo all, half, or quarter the number of ZA array vectors.

The `vector group` symbol, `VGx2` or `VGx4`, indicates that the ZA operand consists of two or four ZA double-vector groups respectively.

It has encodings from 3 classes: [One ZA double-vector](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-345-ZERO--double-vector-?lang=en#isa_zero_za2_ri_iclass_one_za_double_vector), [Two ZA double-vectors](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-345-ZERO--double-vector-?lang=en#isa_zero_za2_ri_iclass_two_za_double_vectors), and [Four ZA double-vectors](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-345-ZERO--double-vector-?lang=en#isa_zero_za2_ri_iclass_four_za_double_vectors)

###### Assembler Symbols

<Wv>
:   ​

    Is the 32-bit name of the vector select register W8-W11, encoded as “Rv” plus 8.

<offs1>
:   ​

    For the “One ZA double-vector” variant: is the first vector select offset, encoded as “off3” field times 2.

    ​

    For the “Four ZA double-vectors” and “Two ZA double-vectors” variants: is the first vector select offset, encoded as “off2” field times 2.

<offs2>
:   ​

    For the “One ZA double-vector” variant: is the second vector select offset, encoded as “off3” field times 2 plus 1.

    ​

    For the “Four ZA double-vectors” and “Two ZA double-vectors” variants: is the second vector select offset, encoded as “off2” field times 2 plus 1.

###### Operation

```
CheckStreamingSVEAndZAEnabled();
let VL : integer{} = CurrentVL();
let vectors : integer = VL DIV 8;
let vstride : integer = vectors DIV ngrp;
let vbase : bits(32) = X{}(v);
var vec : integer = (UInt(vbase) + offset) MOD vstride;
vec = vec - (vec MOD nvec);
for r = 0 to ngrp-1 do
    for i = 0 to nvec-1 do
        ZAvector{VL}(vec + i) = Zeros{VL};
    end;
    vec = vec + vstride;
end;
```
