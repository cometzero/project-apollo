# ​D24.3.30 SDER32_EL3, AArch32 Secure Debug Enable Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-30-SDER32-EL3--AArch32-Secure-Debug-Enable-Register>

##### D24.3.30 SDER32\_EL3, AArch32 Secure Debug Enable Register

The SDER32\_EL3 characteristics are:

Purpose
:   Allows access to the AArch32 register [SDER](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-36-SDER--Secure-Debug-Enable-Register?lang=en#reg_aarch32_sder) from AArch64 state only. Its value has no effect on execution in AArch64 state.

Configuration
:   When EL2 is implemented and FEAT\_SEL2 is implemented, AArch64 System register SDER32\_EL3 bits [63:0] are architecturally mapped to AArch64 System register [SDER32\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-29-SDER32-EL2--AArch32-Secure-Debug-Enable-Register?lang=en#reg_aarch64_sder32_el2)[63:0].

    AArch64 System register SDER32\_EL3 bits [31:0] are architecturally mapped to AArch32 System register [SDER](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-36-SDER--Secure-Debug-Enable-Register?lang=en#reg_aarch32_sder)[31:0].

    This register is present only when EL3 is implemented, FEAT\_AA32EL1 is implemented, and FEAT\_AA64 is implemented. Otherwise, direct accesses to SDER32\_EL3 are UNDEFINED.

Attributes
:   SDER32\_EL3 is a 64-bit register.

    When Secure EL1 is using AArch32, the forms of non-invasive debug affected by this control are:

    - The PC Sample-based Profiling Extension. See [About the PC Sample-based Profiling Extension](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H7-The-PC-Sample-based-Profiling-Extension/-H7-1-About-the-PC-Sample-based-Profiling-Extension?lang=en#babjgbhj).
    - When `SelfHostedTraceEnabled()` == FALSE, processor trace.
    - Performance Monitors.

    When Secure EL1 is using AArch64, this bit has no effect.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
