##### J1.4.790 GPTLevel1EntryValid

```
// GPTLevel1EntryValid()
// =====================
// Returns TRUE if the given level 1 gpt descriptor is valid, and FALSE otherwise.
func GPTLevel1EntryValid(gpt_entry : bits(64), pgs : PGSe) => boolean
begin
    case gpt_entry[3:0] of
        when GPT_Contig => return GPTContigDescriptorValid(gpt_entry, pgs);
        otherwise =>       return GPTGranulesDescriptorValid(gpt_entry);
    end;
end;
```
