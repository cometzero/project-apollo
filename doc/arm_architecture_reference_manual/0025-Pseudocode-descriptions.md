Source: <https://developer.arm.com/documentation/ddi0487/mc/Preface/Conventions/Pseudocode-descriptions>

##### Pseudocode descriptions

This Manual uses a form of pseudocode to provide precise descriptions of the specified functionality. This pseudocode is written in `monospace` font, and is described in [Arm Pseudocode Definition](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K13-Arm-Pseudocode-Definition?lang=en#babidfig).
