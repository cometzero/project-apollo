# ​D24.9.18 VSESR_EL2, Virtual SError Exception Syndrome Register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-18-VSESR-EL2--Virtual-SError-Exception-Syndrome-Register--EL2->

##### D24.9.18 VSESR\_EL2, Virtual SError Exception Syndrome Register (EL2)

The VSESR\_EL2 characteristics are:

Purpose
:   Provides the syndrome value reported to software on taking a virtual SError exception to EL1, or on executing an `ESB` instruction at EL1.

    When the virtual SError exception injected using [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).VSE is taken to EL1 using AArch64, then the syndrome value is reported in [ESR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-44-ESR-EL1--Exception-Syndrome-Register--EL1-?lang=en#reg_aarch64_esr_el1).

    When the virtual SError exception injected using [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).VSE is taken to EL1 using AArch32, then the syndrome value is reported in [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr).{AET, ExT} and the remainder of [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr) is set as defined by VMSAv8-32. For more information, see [The AArch32 Virtual Memory System Architecture](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture?lang=en#chdbceda).

    When the virtual SError exception injected using [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).VSE is deferred by an `ESB` instruction, then the syndrome value is written to [VDISR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-16-VDISR-EL2--Virtual-Deferred-Interrupt-Status-Register--EL2-?lang=en#reg_aarch64_vdisr_el2).

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    This register has no effect if EL2 is not enabled in the current Security state.

    AArch64 System register VSESR\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [VDFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-19-VDFSR--Virtual-SError-Exception-Syndrome-Register?lang=en#reg_aarch32_vdfsr)[31:0].

    This register is present only when FEAT\_RAS is implemented. Otherwise, direct accesses to VSESR\_EL2 are UNDEFINED.

Attributes
:   VSESR\_EL2 is a 64-bit register.

###### Field descriptions

When EL1 is using AArch32:
:   ![](images/5342-D24.9.18-VSESR_EL2-Virtual-SError-Exception-Syndrome-Register-EL2-img01.svg)

Bits [63:16]
:   Reserved, RES0.

AET, bits [15:14]
:   When a virtual SError exception is taken to EL1 using AArch32, [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr)[15:14] is set to VSESR\_EL2.AET.

    When a virtual SError exception is deferred by an `ESB` instruction, [VDISR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-16-VDISR-EL2--Virtual-Deferred-Interrupt-Status-Register--EL2-?lang=en#reg_aarch64_vdisr_el2)[15:14] is set to VSESR\_EL2.AET.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bit [13]
:   Reserved, RES0.

ExT, bit [12]
:   When a virtual SError exception is taken to EL1 using AArch32, [DFSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-47-DFSR--Data-Fault-Status-Register?lang=en#reg_aarch32_dfsr)[12] is set to VSESR\_EL2.ExT.

    When a virtual SError exception is deferred by an `ESB` instruction, [VDISR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-16-VDISR-EL2--Virtual-Deferred-Interrupt-Status-Register--EL2-?lang=en#reg_aarch64_vdisr_el2)[12] is set to VSESR\_EL2.ExT.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bits [11:0]
:   Reserved, RES0.

When EL1 is using AArch64:
:   ![](images/5342-D24.9.18-VSESR_EL2-Virtual-SError-Exception-Syndrome-Register-EL2-img02.svg)

Bits [63:25]
:   Reserved, RES0.

IDS, bit [24]
:   When a virtual SError exception is taken to EL1 using AArch64, [ESR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-44-ESR-EL1--Exception-Syndrome-Register--EL1-?lang=en#reg_aarch64_esr_el1)[24] is set to VSESR\_EL2.IDS.

    When a virtual SError exception is deferred by an `ESB` instruction, [VDISR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-16-VDISR-EL2--Virtual-Deferred-Interrupt-Status-Register--EL2-?lang=en#reg_aarch64_vdisr_el2)[24] is set to VSESR\_EL2.IDS.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

ISS, bits [23:0]
:   When a virtual SError exception is taken to EL1 using AArch64, [ESR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-44-ESR-EL1--Exception-Syndrome-Register--EL1-?lang=en#reg_aarch64_esr_el1)[23:0] is set to VSESR\_EL2.ISS.

    When a virtual SError exception is deferred by an `ESB` instruction, [VDISR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-16-VDISR-EL2--Virtual-Deferred-Interrupt-Status-Register--EL2-?lang=en#reg_aarch64_vdisr_el2)[23:0] is set to VSESR\_EL2.ISS.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
