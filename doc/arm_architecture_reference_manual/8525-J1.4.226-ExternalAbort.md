# ​J1.4.226 ExternalAbort

##### J1.4.226 ExternalAbort

```
// ExternalAbort()
// ===============
func ExternalAbort(fault : FaultRecord) recurselimit 1
begin
    if IsExternalSyncAbort(fault) then
        if UsingAArch32() then
            AArch32_Abort(fault);
        else
            AArch64_Abort(fault);
        end;
    else
        PendSErrorInterrupt(fault);
    end;
end;
```
