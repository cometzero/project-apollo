##### J1.4.584 EffectivelyAtEL0InHost

```
// EffectivelyAtEL0InHost()
// ====================
// Accesses from EL0 when the Effective value of HCR_EL2().[E2H, TGE] is {1, 1} will be trapped
// or Undefined.
func EffectivelyAtEL0InHost() => boolean
begin
    return (PSTATE.EL == EL0 && ELIsInHost(EL0));
end;
```
