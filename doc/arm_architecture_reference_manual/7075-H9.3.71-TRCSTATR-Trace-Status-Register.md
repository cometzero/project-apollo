##### H9.3.71 TRCSTATR, Trace Status Register

The TRCSTATR characteristics are:

Purpose
:   Returns the trace unit status.

Configuration
:   External register TRCSTATR bits [31:0] are architecturally mapped to AArch64 System register [TRCSTATR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-62-TRCSTATR--Trace-Status-Register?lang=en#reg_aarch64_trcstatr)[31:0].

    This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCSTATR are RES0.

Attributes
:   TRCSTATR is a 32-bit register.
