##### `0x8198`, DSNP\_HIT\_WR, Snoop hit, demand data write

The counter counts each snoop generated by the PE in response to a demand [Memory-write operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caccfcjj) counted by [DSNP\_HIT\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x819C--DSNP-HIT-RW--Snoop-hit--demand-data-access?lang=en#event_dsnp_hit_rw) that hits in a cache outside of the cache hierarchy of this PE.

The event is counted by the PE generating the snoop, not the PE being snooped.
