##### F6.1.15 SHA256SU0

SHA256 schedule update 0.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-15-SHA256SU0?lang=en#isa_sha256su0_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-15-SHA256SU0?lang=en#isa_sha256su0_iclass_t1)).

###### Assembler Symbols

<Qd>
:   ​

    Is the 128-bit name of the SIMD&FP destination register, encoded in the “D:Vd” field as <Qd>\*2.

<Qm>
:   ​

    Is the 128-bit name of the SIMD&FP source register, encoded in the “M:Vm” field as <Qm>\*2.

###### Operation

```
if ConditionPassed() then
    var result : bits(128);
    EncodingSpecificOperations();
    CheckCryptoEnabled32();
    let x : bits(128) = Q(d>>1);
    let y : bits(128) = Q(m>>1);
    let t : bits(128) = y[31:0] :: x[127:32];
    for e = 0 to 3 do
        var elt : bits(32) = t[e*:32];
        elt = ROR(elt, 7) XOR ROR(elt, 18) XOR LSR(elt, 3);
        result[e*:32] = elt + x[e*:32];
    end;
    Q(d>>1) = result;
end;
```
