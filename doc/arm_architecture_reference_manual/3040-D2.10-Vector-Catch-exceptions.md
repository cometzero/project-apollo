#### D2.10 Vector Catch exceptions

Vector Catch exceptions are not generated in AArch64 translation regimes.

> #### Note
>
> This means that they are never taken to EL1 using AArch64 and are supported only if at least EL1 using AArch32 is supported.

A debugger that is executing in EL2 using AArch64 can route Vector Catch exceptions to EL2 using AArch64. See [Routing debug exceptions](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-2-Routing-debug-exceptions?lang=en#d2beicggig).
