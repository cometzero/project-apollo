# ​D19.4.1 Invalidating the record buffer

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-4-Branch-record-buffer/-D19-4-1-Invalidating-the-record-buffer>

##### D19.4.1 Invalidating the record buffer

R LLHYN
:   Execution of `BRB IALL` causes all [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) to be invalidated.

R PFRNW
:   A [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record), **R**, is invalidated by the instruction `BRB IALL`, **W**, if all of the following are true:

    - **R** is caused by a branch operation or exception, **B**.
    - **B** is either:

      - In program order before a *Context synchronization event*, **CSE**.
      - Is the *Context synchronization event*.
    - **CSE** is in program order before **W**.

R LWPKR
:   A [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) **R** is not invalidated by the instruction `BRB IALL`, **W**, if all of the following are true:

    - **R** is caused by a branch operation or exception, **B**.
    - **B** is in program order after a *Context synchronization event*, **CSE**.
    - **CSE** is in program order after **W**.

R WMZKF
:   It is CONSTRAINED UNPREDICTABLE whether a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) **R** is invalidated by the instruction `BRB IALL`, **W**, if all of the following are true:

    - CSE1 is in program order before **W**.
    - **R** is caused by a branch operation or exception, **B**.
    - **B** is in program order after a *Context synchronization event*, CSE1
    - **B** is either:

      - In program order before a *Context synchronization event*, CSE2.
      - Is the *Context synchronization event*, CSE2.
    - CSE2 is in program order after **W** and there are no other CSEs between CSE1 and CSE2.

    If a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is invalidated, all older [Branch records](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) are invalidated.

R JSCWK
:   When a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) has been invalidated, it remains invalid until it is overwritten by any of the following:

    - A new [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is created.
    - A [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) is injected using the `BRB INJ` instruction.
