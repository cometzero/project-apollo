##### I2.3.2 The CNTBaseN and CNTEL0BaseN frames

Each [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) frame, or {[CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea), [CNTEL0BaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegecbbg)} pair of frames, provides a memory-mapped counter and timer, see:

- [The CNTBaseN frame](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegcjcac).
- [The CNTEL0BaseN frame](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegigjeg).
- [CNTCTLBase status and control fields for the CNTBaseN and CNTEL0BaseN frames](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegdfjag).

Whether a frame includes a virtual timer is IMPLEMENTATION DEFINED. If it does not, then memory at offsets `0x030`-`0x03C` is RAZ/WI. Except for [CNTEL0ACR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-4-CNTEL0ACR--Counter-timer-EL0-Access-Control-Register?lang=en#reg_ext_cntel0acr) and the [CounterID<n>](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-23-CounterID-n---Counter-ID-registers--n---0---11?lang=en#reg_ext_counteridn) registers, equivalent registers are also implemented in a System register interface to the timer component of a Generic Timer.

###### I2.3.2.2 The CNTEL0Base*N* frame

For any value of *N*, the layout of the registers in the CNTEL0Base*N* frame is identical to the [CNTBaseN](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer/-I2-3-Memory-mapped-timer-components/-I2-3-2-The-CNTBaseN-and-CNTEL0BaseN-frames?lang=en#cegedbea) frame, except that, in the CNTEL0Base*N* frame:

- [CNTVOFF](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-18-CNTVOFF--Counter-timer-Virtual-Offset?lang=en#reg_ext_cntvoff) is never visible, and the memory at `0x018`-`0x01C` is RAZ/WI.
- [CNTEL0ACR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-7-Generic-Timer-memory-mapped-register-descriptions/-I5-7-4-CNTEL0ACR--Counter-timer-EL0-Access-Control-Register?lang=en#reg_ext_cntel0acr) is never visible, and the memory at `0x014` is RAZ/WI.
