##### `0x8147`, L1I\_CACHE\_REFILL\_PRFM, Level 1 instruction cache refill, software prefetch

The counter counts each access counted by [L1I\_CACHE\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8143--L1I-CACHE-PRFM--Level-1-instruction-cache-software-prefetch?lang=en#event_l1i_cache_prfm) that causes a refill of the Level 1 instruction or unified cache from outside of the Level 1 instruction or unified cache.
