##### H9.3.40 TRCIDR7, Trace ID Register 7

The TRCIDR7 characteristics are:

Purpose
:   Returns the tracing capabilities of the trace unit.

Configuration
:   External register TRCIDR7 bits [31:0] are architecturally mapped to AArch64 System register [TRCIDR7](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-42-TRCIDR7--Trace-ID-Register-7?lang=en#reg_aarch64_trcidr7)[31:0].

    This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCIDR7 are RES0.

Attributes
:   TRCIDR7 is a 32-bit register.
