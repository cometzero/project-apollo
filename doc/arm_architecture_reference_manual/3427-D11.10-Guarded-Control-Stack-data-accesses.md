#### D11.10 Guarded Control Stack data accesses

R ZMNSV
:   A [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) that is not aligned to size of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record) generates an Alignment fault.

I RYLTG
:   If a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) causes an Alignment fault, the resulting fault is reported with the [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).EC code `0b100100` or `0b100101`.

R VDJXL
:   Unless otherwise specified, a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) is single-copy atomic at 64-bit granularity.

I BFHQY
:   For more information on atomicity, see [Requirements for single-copy atomicity](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-2-Atomicity-in-the-Arm-architecture/-B2-2-1-Requirements-for-single-copy-atomicity?lang=en#chddcbcc).

I KNXKG
:   A [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) might clear the state of the local Exclusives monitor if the local monitor is in the Exclusive Access state. For more information on the effects on the local monitor, see [Exclusive access instructions and Non-shareable memory locations](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-12-Synchronization-and-semaphores/-B2-12-1-Exclusive-access-instructions-and-Non-shareable-memory-locations?lang=en#chdhgdhh).

R FFJDX
:   When a [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) accesses a memory type that is not one of the following, it is CONSTRAINED UNPREDICTABLE whether:

    - A Data Abort for unsupported access, using [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx).DFSC value `0b110101`, is generated.

      - In this case, it is IMPLEMENTATION DEFINED whether the Data Abort is generated according to the memory type after all stages of translation, or at each stage of translation.
    - The access proceeds using the specified memory type.

    The memory types are:

    - Inner Shareable, Inner Write-Back, Outer Write-Back Normal memory.
    - Outer Shareable, Inner Write-Back, Outer Write-Back Normal memory.

S JBQRL
:   If translation or data caches are disabled, then [Guarded Control Stack data access](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_data_access) use Device or Normal Non-cacheable memory types respectively.

    To avoid use of mismatched memory attributes or generation of a Data Abort for an unsupported access, software should use the following sequence when disabling translation or data caches:

    1. Disable GCS using [GCSCR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#gcscr_elx) and [GCSCRE0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-11-Guarded-Control-Stack-registers/-D24-11-4-GCSCRE0-EL1--Guarded-Control-Stack-Control-Register--EL0-?lang=en#reg_aarch64_gcscre0_el1).
    2. [`GCSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-161-GCSB?lang=en#isa_gcsb).
    3. Disable translation and/or data caches.
