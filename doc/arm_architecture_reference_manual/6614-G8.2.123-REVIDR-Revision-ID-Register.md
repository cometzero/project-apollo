# ​G8.2.123 REVIDR, Revision ID Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-123-REVIDR--Revision-ID-Register>

##### G8.2.123 REVIDR, Revision ID Register

The REVIDR characteristics are:

Purpose
:   Provides implementation-specific minor revision information.

Configuration
:   If REVIDR has the same value as [MIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-113-MIDR--Main-ID-Register?lang=en#reg_aarch32_midr), then its contents have no significance.

    AArch32 System register REVIDR bits [31:0] are architecturally mapped to AArch64 System register [REVIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-155-REVIDR-EL1--Revision-ID-Register?lang=en#reg_aarch64_revidr_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to REVIDR are UNDEFINED.

Attributes
:   REVIDR is a 32-bit register.
