# ​J1.4.720 TRBE_TRBIDR_P_Read

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-720-TRBE-TRBIDR-P-Read>

##### J1.4.720 TRBE\_TRBIDR\_P\_Read

```
// TRBE_TRBIDR_P_Read()
// ====================
// Called when TRBIDR_EL1 is read, returns the value of TRBIDR_EL1.P
func TRBE_TRBIDR_P_Read() => bit
begin
    var owning_ss : SecurityState;
    var owning_el : bits(2);
    (owning_ss, owning_el) = TraceBufferOwner();
    // Reads as one if the Trace Buffer is owned by a higher Exception
    // Level or another Security state.
    if (UInt(owning_el) > UInt(PSTATE.EL) ||
          (PSTATE.EL != EL3 && owning_ss != CurrentSecurityState())) then
        return ‘1’;
    else
        return ‘0’;
    end;
end;
```
