##### `0x83B1`, N2\_CACHE2\_HIT\_RD, Cache type 2 at distance 2 demand access hit, read

The counter counts each demand read counted by [N2\_CACHE\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83A1--N2-CACHE-HIT-RD--Cache-at-distance-2--demand-access-hit--read?lang=en#event_n2_cache_hit_rd) due to a demand read accessing a second cache type at distance 2.

The definition of cache types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
