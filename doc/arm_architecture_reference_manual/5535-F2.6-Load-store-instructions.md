# ​F2.6 Load/store instructions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-6-Load-store-instructions>

#### F2.6 Load/store instructions

[Table F2-12](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-6-Load-store-instructions?lang=en#tbl_babdfaeg) summarizes the general-purpose register load/store instructions in the T32 and A32 instruction sets. Some of these instructions can also operate on the PC. See also:

- [Load/store multiple instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-7-Load-store-multiple-instructions?lang=en#chdbgfhi).
- [Synchronization and semaphores](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-10-Synchronization-and-semaphores?lang=en#cegdaeag), for more information about the Load-Exclusive and Store-Exclusive instructions.
- [Load-Acquire, Store-Release](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-3-Definition-of-the-memory-model/-E2-3-5-Memory-barriers?lang=en#aa32chdbdidf), for more information about the Load-Acquire/Store-Release and Load-Acquire Exclusive/Store-Release Exclusive instructions.
- [Advanced SIMD and floating-point load/store instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-11-Advanced-SIMD-and-floating-point-load-store-instructions?lang=en#babijbbi).

Load/store instructions have several options for addressing memory. For more information, see [Addressing modes](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F2-The-AArch32-Instruction-Sets-Overview/-F2-6-Load-store-instructions/-F2-6-6-Addressing-modes?lang=en#babdfjdh).
