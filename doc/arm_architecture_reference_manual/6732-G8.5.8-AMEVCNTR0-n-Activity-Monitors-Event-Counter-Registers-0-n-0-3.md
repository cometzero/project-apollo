# ​G8.5.8 AMEVCNTR0<n>, Activity Monitors Event Counter Registers 0, n = 0 - 3

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-8-AMEVCNTR0-n---Activity-Monitors-Event-Counter-Registers-0--n---0---3>

##### G8.5.8 AMEVCNTR0<n>, Activity Monitors Event Counter Registers 0, n = 0 - 3

The AMEVCNTR0<n> characteristics are:

Purpose
:   Provides access to the architected activity monitor event counters.

Configuration
:   AArch32 System register AMEVCNTR0<n> bits [63:0] are architecturally mapped to AArch64 System register [AMEVCNTR0<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-9-AMEVCNTR0-n--EL0--Activity-Monitors-Event-Counter-Registers-0--n---0---3?lang=en#reg_aarch64_amevcntr0n_el0)[63:0].

    AArch32 System register AMEVCNTR0<n> bits [63:0] are architecturally mapped to External register [AMEVCNTR0<n>](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-20-AMEVCNTR0-n---Activity-Monitors-Event-Counter-Registers-0--n---0---3?lang=en#reg_amu_amevcntr0n)[63:0].

    This register is present only when FEAT\_AMUv1 is implemented and FEAT\_AA32 is implemented. Otherwise, direct accesses to AMEVCNTR0<n> are UNDEFINED.

Attributes
:   AMEVCNTR0<n> is a 64-bit register.

###### Field descriptions

![](images/6732-G8.5.8-AMEVCNTR0-n-Activity-Monitors-Event-Counter-Registers-0-n-0-3-img01.svg)

ACNT, bits [63:0]
:   Architected activity monitor event counter n.

    Value of architected activity monitor event counter n, where n is the number of this register and is a number from 0 to 3.

    If FEAT\_AMUv1p1 is implemented, [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).AMVOFFEN is 1, [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).AMVOFFEN is 1, the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is not {1, 1}, and EL2 is using AArch64 and is implemented in the current Security state, access to these registers at EL0 or EL1 return (PCount<63:0> - [AMEVCNTVOFF0<n>\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-11-AMEVCNTVOFF0-n--EL2--Activity-Monitors-Event-Counter-Virtual-Offset-Registers-0--n---0---15?lang=en#reg_aarch64_amevcntvoff0n_el2)<63:0>).

    PCount is the physical count returned when AMEVCNTR0<n> is read from EL2 or EL3.

    If the counter is enabled, writes to this register have UNPREDICTABLE results.

    The reset behavior of this field is:

    - On a AMU reset, this field resets to the expression `0x0000000000000000`.

###### Accessing AMEVCNTR0<n>

If <n> is greater than or equal to the number of architected activity monitor event counters, reads and writes of AMEVCNTR0<n> are UNDEFINED.

> #### Note
>
> [AMCGCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-2-AMCGCR--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch32_amcgcr).CG0NC identifies the number of architected activity monitor event counters.
