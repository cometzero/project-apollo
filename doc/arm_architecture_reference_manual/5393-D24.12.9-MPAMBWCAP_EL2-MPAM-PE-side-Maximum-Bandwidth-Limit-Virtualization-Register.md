# ​D24.12.9 MPAMBWCAP_EL2, MPAM PE-side Maximum Bandwidth Limit Virtualization Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-9-MPAMBWCAP-EL2--MPAM-PE-side-Maximum-Bandwidth-Limit-Virtualization-Register>

##### D24.12.9 MPAMBWCAP\_EL2, MPAM PE-side Maximum Bandwidth Limit Virtualization Register

The MPAMBWCAP\_EL2 characteristics are:

Purpose
:   Allows software executing at EL2 to provide [MPAMBWCAP\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-9-MPAMBWCAP-EL2--MPAM-PE-side-Maximum-Bandwidth-Limit-Virtualization-Register?lang=en#reg_aarch64_mpambwcap_el2).CAP as an upper bound to [MPAMBW1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-6-MPAMBW1-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambw1_el1).MAX.

    If FEAT\_SME is implemented, the upper bound also applies to [MPAMBWSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-11-MPAMBWSM-EL1--MPAM-Streaming-Mode-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambwsm_el1).MAX when executing at EL1: the maximum bandwidth allowed for the PE is MIN([MPAMBWSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-11-MPAMBWSM-EL1--MPAM-Streaming-Mode-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambwsm_el1).MAX, [MPAMBWCAP\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-9-MPAMBWCAP-EL2--MPAM-PE-side-Maximum-Bandwidth-Limit-Virtualization-Register?lang=en#reg_aarch64_mpambwcap_el2).CAP).

    If the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H,TGE} is not {1,1}:

    - The upper bound also applies to [MPAMBW0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-5-MPAMBW0-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL0-?lang=en#reg_aarch64_mpambw0_el1).MAX: the maximum bandwidth allowed for the PE is MIN([MPAMBW0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-5-MPAMBW0-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL0-?lang=en#reg_aarch64_mpambw0_el1).MAX, [MPAMBWCAP\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-9-MPAMBWCAP-EL2--MPAM-PE-side-Maximum-Bandwidth-Limit-Virtualization-Register?lang=en#reg_aarch64_mpambwcap_el2).CAP).
    - If FEAT\_SME is implemented, the upper bound also applies to [MPAMBWSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-11-MPAMBWSM-EL1--MPAM-Streaming-Mode-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambwsm_el1).MAX when executing at EL0: the maximum bandwidth allowed for the PE is MIN([MPAMBWSM\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-11-MPAMBWSM-EL1--MPAM-Streaming-Mode-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambwsm_el1).MAX, [MPAMBWCAP\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-9-MPAMBWCAP-EL2--MPAM-PE-side-Maximum-Bandwidth-Limit-Virtualization-Register?lang=en#reg_aarch64_mpambwcap_el2).CAP).

    If [MPAMBWCAP\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-9-MPAMBWCAP-EL2--MPAM-PE-side-Maximum-Bandwidth-Limit-Virtualization-Register?lang=en#reg_aarch64_mpambwcap_el2).ENABLED is 1, a PARTID that has used more than min(CAP,MAX) is given no access to additional bandwidth.

Configuration
:   This register has no effect if EL2 is not enabled in the current Security state.

    This register is present only when FEAT\_MPAM\_PE\_BW\_CTRL is implemented, MPAMIDR\_EL1.HAS\_HCR == ‘1’, and FEAT\_AA64EL2 is implemented. Otherwise, direct accesses to MPAMBWCAP\_EL2 are UNDEFINED.

Attributes
:   MPAMBWCAP\_EL2 is a 64-bit register.
