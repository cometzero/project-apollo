# ​I5.3.26 PMDEVARCH, Performance Monitors Device Architecture register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-26-PMDEVARCH--Performance-Monitors-Device-Architecture-register>

##### I5.3.26 PMDEVARCH, Performance Monitors Device Architecture register

The PMDEVARCH characteristics are:

Purpose
:   Identifies the programmers’ model architecture of the Performance Monitor component.

Configuration
:   If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, this register is in the Core power domain. If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, this register is in the Debug power domain.

    This register is present only when FEAT\_PMUv3\_EXT is implemented. Otherwise, direct accesses to PMDEVARCH are RES0.

Attributes
:   PMDEVARCH is a 32-bit register.

###### Field descriptions

![](images/7215-I5.3.26-PMDEVARCH-Performance-Monitors-Device-Architecture-register-img01.svg)

ARCHITECT, bits [31:21]
:   Defines the architect of the component. For Performance Monitors, this is Arm Limited.

    Bits [31:28] are the JEP106 continuation code, `0b0100`.

    Bits [27:21] are the JEP106 identification code, `0b0111011`.

    Reads as `0b01000111011`

    Access to this field is RO.

PRESENT, bit [20]
:   DEVARCH presence. Indicates that the PMDEVARCH register provides architecture information.

    Reads as `0b1`

    Access to this field is RO.

REVISION, bits [19:16]
:   Defines the architecture revision. For architectures defined by Arm this is the minor revision.

    For Performance Monitors, the revision defined by Armv8 is `0x0`.

    All other values are reserved.

    Reads as `0b0000`

    Access to this field is RO.

ARCHVER, bits [15:12]
:   When UInt(PMU.PMDEVARCH.ARCHPART) == `0xA16` or UInt(PMU.PMDEVARCH.ARCHPART) == `0xA26`:
    :   Architecture Version. Defines the architecture version of the component.

    The values `0xA10` and `0xA20` indicate that FEAT\_PCSRv8p2 is implemented but the Performance Monitors Extension is not implemented.

    PMDEVARCH.ARCHVER and PMDEVARCH.ARCHPART are also defined as a single field, PMDEVARCH.ARCHID, so that PMDEVARCH.ARCHPART is PMDEVARCH.ARCHID[11:0].

    Access to this field is RO.

###### Accessing PMDEVARCH

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT is implemented
:   Accessible at offset `0xFBC` from PMU

    - When FEAT\_DoPD is implemented and !IsCorePowered(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RO.
