# ​I4.1 About the external interface to the Activity Monitors Extension registers

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I4-Recommended-External-Interface-to-the-Activity-Monitors/-I4-1-About-the-external-interface-to-the-Activity-Monitors-Extension-registers>

#### I4.1 About the external interface to the Activity Monitors Extension registers

If an implementation supports the Activity Monitors Extension, it can optionally support an external memory-mapped interface to the Activity Monitors Extension, [FEAT\_AMU\_EXT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_amu_ext). If the implementation supports [FEAT\_AMU\_EXT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_amu_ext), it may further optionally support CoreSight device registers and ID registers.

When [FEAT\_AMU\_EXT64](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_amu_ext64) is implemented, all AMU registers are 64-bit except the 32-bit CoreSight management registers, when implemented.

The base address of the memory-mapped view is aligned to a 4KB boundary, but is otherwise IMPLEMENTATION DEFINED. The address offsets for the memory-mapped view are given in [Table I5-159](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-4-External-Activity-Monitors-Extension-registers-summary/-I5-4-1-Activity-Monitors-external-register-views?lang=en#tbl_cjahaici).
