# ​D6.2 The trace buffer

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer>

#### D6.2 The trace buffer

R SDCKT
:   The Trace Buffer Unit uses one of the following:

    - If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D3-AArch64-Self-hosted-Trace/-D3-1-About-self-hosted-trace/-D3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#sh_trace_enabled), then Self-hosted mode. See [Trace buffer Self-hosted mode](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode?lang=en#trace_buffer_self_hosted_mode).
    - If [FEAT\_TRBE\_EXT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_trbe_ext) is implemented and self-hosted trace is [disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D3-AArch64-Self-hosted-Trace/-D3-1-About-self-hosted-trace/-D3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#sh_trace_disabled), then External mode. See [Trace buffer External mode](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode?lang=en#chdcegghi1).

R YCHKJ
:   If and only if one of the following is true, then the Trace Buffer Unit is enabled:

    - The Trace Buffer Unit is using Self-hosted mode and [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).E is 1.
    - The Trace Buffer Unit is using External mode and [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-3-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_aarch64_trblimitr_el1).XE is 1.

    Otherwise, the Trace Buffer Unit is disabled. See [Trace Buffer Unit disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer/-D6-2-1-Trace-Buffer-Unit-disabled?lang=en#mdsec_trbe_disabled).

    The pseudocode function [`TraceBufferEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-722-TraceBufferEnabled?lang=en#asl_func_tracebufferenabled_0)`()` describes this.

R BGLHT
:   If and only if all of the following are true, then the Trace Buffer Unit is *running*:

    - The Trace Buffer Unit is enabled.
    - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-7-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register--EL1-?lang=en#reg_aarch64_trbsr_el1).S is 0.
    - [FEAT\_TRBE\_EXC](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_trbe_exc) is not implemented, or self-hosted trace is [disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D3-AArch64-Self-hosted-Trace/-D3-1-About-self-hosted-trace/-D3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#sh_trace_disabled), or all of the following are true:

      - Any of the following are true:

        - EL2 is not implemented.
        - The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).{NS, EEL2} is {0, 0}.
        - [TRBSR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-8-TRBSR-EL2--Trace-Buffer-Syndrome-Register--EL2-?lang=en#reg_aarch64_trbsr_el2).S is 0.
        - EL3 is implemented and [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).TRBEE is `0b00`.
        - [TRFCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-74-TRFCR-EL2--Trace-Filter-Control-Register--EL2-?lang=en#reg_aarch64_trfcr_el2).EE is either `0b00` or `0b01`.
      - Any of the following are true:

        - EL3 is not implemented.
        - [TRBSR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-9-TRBSR-EL3--Trace-Buffer-Syndrome-Register--EL3-?lang=en#reg_aarch64_trbsr_el3).S is 0.
        - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).TRBEE is either `0b00` or `0b01`.

    The pseudocode function [`TraceBufferRunning`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-724-TraceBufferRunning?lang=en#asl_func_tracebufferrunning_0)`()` shows this.

R FRHXV
:   If and only if all of the following are true, then *collection is stopped*:

    - The Trace Buffer Unit is enabled.
    - The Trace Buffer Unit is not [running](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#trbe_running).

    The pseudocode function [`TraceBufferRunning`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-724-TraceBufferRunning?lang=en#asl_func_tracebufferrunning_0)`()` shows this.

    - The PE is executing in the trace buffer [owning Security state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-5-The-owning-translation-regime?lang=en#trbe_owning_ss).

    - Self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D3-AArch64-Self-hosted-Trace/-D3-1-About-self-hosted-trace/-D3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#sh_trace_enabled).

I JYSQZ
:   While the Trace Buffer Unit is enabled, it collects trace data from the trace unit and does one of the following:

    - *Accepts* the trace data and writes it to the trace buffer in memory.
    - *Discards* the trace data. The trace data is lost.
    - *Rejects* the trace data.

R YMYQX
:   When the Trace Buffer Unit is enabled and *running*, and the Trace Buffer Unit is able to accept the trace data, the Trace Buffer Unit *accepts* the trace data from the trace unit and writes it into the trace buffer.

R LNTVR
:   When the Trace Buffer Unit is enabled and *running*, and the Trace Buffer Unit is not able to accept the trace data, the Trace Buffer Unit *rejects* the trace data from the trace unit. The trace data might be retained by the trace unit until the Trace Buffer Unit *accepts* the trace data.

I SQYCT
:   For example, the Trace Buffer Unit might not be able to accept trace data while its internal buffers are full.

I TRCDR
:   If the Trace Buffer Unit *rejects* trace data and the trace unit is not able to retain the trace data, then the trace unit discards it and enters an Overflow state. Details of Overflow state and how the trace unit recovers from Overflow state are defined by the trace unit. See [Trace unit behavior on a trace unit buffer overflow](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D4-The-Embedded-Trace-Extension/-D4-5-About-the-ETE-trace-unit/-D4-5-4-Trace-unit-behavior-on-a-trace-unit-buffer-overflow?lang=en#mdsec_behavior_on_trace_unit_overflow).

R YMVZL
:   When the Trace Buffer Unit is enabled and [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1), the Trace Buffer Unit *discards* trace data from the trace unit. The trace data is lost.

R PHSKP
:   When used with a trace unit that implements [FEAT\_ETE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-1-The-Armv9-0-architecture-extension?lang=en#feat_feat_ete), the Trace Buffer Unit ignores the value of the ETE [TRCTRACEIDR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-64-TRCTRACEIDR--Trace-ID-Register?lang=en#reg_aarch64_trctraceidr) register.
