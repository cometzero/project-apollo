##### C8.2.245 FMOV (immediate, predicated)

Move floating-point immediate to vector elements (predicated)

This instruction moves a floating-point immediate into each Active element in the destination vector. Inactive elements in the destination vector register remain unmodified.

This is an alias of [FCPY](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-171-FCPY?lang=en#isa_fcpy_z_p_i). This means:

- The encodings in this description are named to match the encodings of [FCPY](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-171-FCPY?lang=en#isa_fcpy_z_p_i).
- The description of [FCPY](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-171-FCPY?lang=en#isa_fcpy_z_p_i) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
FMOV  <Zd>.<T>, <Pg>/M, #<const>
```

is equivalent to

```
FCPY  <Zd>.<T>, <Pg>/M, #<const>
```

and is always the preferred disassembly.

<Pg>
:   ​

    Is the name of the governing scalable predicate register, encoded in the “Pg” field.

<const>
:   ​

    Is a floating-point immediate value expressible as ±n÷16×2^r, where n and r are integers such that 16 ≤ n ≤ 31 and -3 ≤ r ≤ 4, i.e. a normalized binary floating-point encoding with 1 sign bit, 3-bit exponent, and 4-bit fractional part, encoded in the “imm8” field.
