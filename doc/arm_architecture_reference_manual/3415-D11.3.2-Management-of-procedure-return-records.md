# ​D11.3.2 Management of procedure return records

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns/-D11-3-2-Management-of-procedure-return-records>

##### D11.3.2 Management of procedure return records

G TSLPS
:   [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) provides means for software to add a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record) to a Guarded Control Stack.

I MLRYX
:   The [`GCSPUSHM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-165-GCSPUSHM?lang=en#isa_gcspushm_sys) instruction is provided to enable software to add a doubleword in the Guarded Control Stack.

I PYRNS
:   The [`GCSSTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-169-GCSSTR?lang=en#isa_gcsstr) and the [`GCSSTTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-170-GCSSTTR?lang=en#isa_gcssttr) instructions are provided to enable software to modify a doubleword in the Guarded Control Stack.

I ZBPNC
:   The [`GCSPUSHM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-165-GCSPUSHM?lang=en#isa_gcspushm_sys) instruction does not sign extend the value that is being stored. This is to maintain consistency with the [`GCSSTR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-169-GCSSTR?lang=en#isa_gcsstr) instruction behavior.

I PPGKD
:   The [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl) instruction is provided to adjust the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr). This instruction can be used in places where there is no return from subroutine instruction executed for a preceding branch with link instruction.

R QHJBM
:   While the Guarded Control Stack is [GCS Enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack/-D11-2-1-Enabling-the-Guarded-Control-Stack?lang=en#mdterm_gcs_enabled) at the current Exception level, the [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl) instruction performs the following operations:

    1. Load a doubleword from the address pointed by the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr).
    2. Check the [1:0] bits of the loaded value:

    - If the value does not equal `0b00`, a [GCS Data Check exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-9-Guarded-Control-Stack-exceptions?lang=en#mdterm_gcs_data_check_exception) is taken.
    - If the value equals `0b00`, the loaded value is written to the `Xn` register defined by [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl) and the [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr) is incremented by the size of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record).

R SXVRB
:   When the Guarded Control Stack is GCS [Disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack/-D11-2-1-Enabling-the-Guarded-Control-Stack?lang=en#mdterm_gcs_disabled) at the current Exception level, the [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl) instruction does not perform the load operation or the update to [current GCS pointer register](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_current_gcs_pr) and executes as a `NOP`.

I QLKKL
:   Arm strongly recommends software uses guard pages between Guarded Control Stacks to help detecting the following:

    - Malicious attacks that use [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl) instruction to subvert the [GCSPR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#gcspr_elx) value to an attacker defined value.
    - An underflow or an overflow of the Guarded Control Stack for any other reasons.
