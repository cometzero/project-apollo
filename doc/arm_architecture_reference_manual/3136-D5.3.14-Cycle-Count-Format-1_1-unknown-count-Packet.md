##### D5.3.14 Cycle Count Format 1\_1 unknown count Packet

Purpose
:   Indicates a *Cycle Count element*.

Configurations
:   All the following conditions must be met:

    - TRCIDR0.COMMOPT == `0b1.`
    - TRCIDR0.TRCCCI == `0b1.`
