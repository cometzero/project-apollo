# ​H4.5.4 DCC and ITR access in Debug state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses/-H4-5-4-DCC-and-ITR-access-in-Debug-state>

##### H4.5.4 DCC and ITR access in Debug state

In Debug state, stricter observability rules apply for instructions issued through the ITR, to maintain communication between a debugger and the PE, without requiring excessive explicit synchronization.

In Normal access mode, without explicit synchronization:

- A direct read or direct write of the DTR registers by an instruction written to [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr) must be observable to an external write or an external read in finite time:

  - A direct read of [DBGDTRRX](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babhhjid) must be observable to an external write of [DBGDTRRX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-6-DBGDTRRX-EL0--Debug-Data-Transfer-Register--Receive?lang=en#reg_ext_dbgdtrrx_el0).
  - A direct read of [DBGDTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-6-DBGDTR-EL0--Debug-Data-Transfer-Register--half-duplex?lang=en#reg_aarch64_dbgdtr_el0) must be observable to an external write of [DBGDTRRX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-6-DBGDTRRX-EL0--Debug-Data-Transfer-Register--Receive?lang=en#reg_ext_dbgdtrrx_el0) and [DBGDTRTX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-7-DBGDTRTX-EL0--Debug-Data-Transfer-Register--Transmit?lang=en#reg_ext_dbgdtrtx_el0).
  - A direct write of [DBGDTRTX](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babbccif) must be observable to an external read of [DBGDTRTX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-7-DBGDTRTX-EL0--Debug-Data-Transfer-Register--Transmit?lang=en#reg_ext_dbgdtrtx_el0).
  - A direct write of [DBGDTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-6-DBGDTR-EL0--Debug-Data-Transfer-Register--half-duplex?lang=en#reg_aarch64_dbgdtr_el0) must be observable to an external read of [DBGDTRRX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-6-DBGDTRRX-EL0--Debug-Data-Transfer-Register--Receive?lang=en#reg_ext_dbgdtrrx_el0) and [DBGDTRTX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-7-DBGDTRTX-EL0--Debug-Data-Transfer-Register--Transmit?lang=en#reg_ext_dbgdtrtx_el0).

  This includes the indirect write to the [DCC flags](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses?lang=en#babhgjij) that occurs atomically with the access as described in [DCC accesses in Non-debug state](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses/-H4-5-2-DCC-accesses-in-Non-debug-state?lang=en#babddagb).

  The subsequent external write or external read must observe either the old or the new values of both the DTR contents and [DCC flags](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses?lang=en#babhgjij). If the old values are observed, this typically results in overrun or underrun, assuming the old values of the [DCC flags](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses?lang=en#babhgjij) indicate an overrun or underrun condition, as would normally be the case.

  This means the debugger can observe the direct read or direct write without explicit synchronization and without explicitly testing the [DCC flags](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses?lang=en#babhgjij) in [EDSCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-48-EDSCR--External-Debug-Status-and-Control-Register?lang=en#reg_ext_edscr), because it can rely on overrun and underrun tests.
- External reads of [DBGDTRTX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-7-DBGDTRTX-EL0--Debug-Data-Transfer-Register--Transmit?lang=en#reg_ext_dbgdtrtx_el0) that do not underrun and external writes to [DBGDTRRX\_EL0](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-6-DBGDTRRX-EL0--Debug-Data-Transfer-Register--Receive?lang=en#reg_ext_dbgdtrrx_el0) that do not overrun must be observable to an instruction subsequently written to [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr) on completion of the first external access. This includes the indirect write to the [DCC flags](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses?lang=en#babhgjij).

  This means that without explicit synchronization and without the need to first check the [DCC flags](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses?lang=en#babhgjij) in [DCCSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babbdeib):

  - If the instruction is a direct read of [DBGDTRRX](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babhhjid), it observes the external write.
  - If the instruction is a direct write of [DBGDTRTX](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babbccif), it observes the external read.
- Writes to [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr) that do not overrun commit an instruction for execution immediately. The instruction must complete execution in finite time without requiring any further operation by the debugger.
- After an external write to the [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr), the [ITR flags](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-5-Synchronization-of-DCC-and-ITR-accesses?lang=en#babghdjj) that are updated as a side effect of that write must be observable by:

  - An external read of the [EDSCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-48-EDSCR--External-Debug-Status-and-Control-Register?lang=en#reg_ext_edscr) that follows the external write to the [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr).
  - When checking for overrun, another external write to the [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr) that follows the original external write to the [EDITR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-32-EDITR--External-Debug-Instruction-Transfer-Register?lang=en#reg_ext_editr).

In Memory access mode, these requirements shift to the instructions implicitly executed by external reads and external writes of the DTR registers, as described in [Memory access mode](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register/-H4-3-DCC-and-ITR-access-modes/-H4-3-2-Memory-access-mode?lang=en#babbghih).
