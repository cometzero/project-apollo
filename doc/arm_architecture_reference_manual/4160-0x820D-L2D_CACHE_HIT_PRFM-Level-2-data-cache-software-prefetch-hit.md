##### `0x820D`, L2D\_CACHE\_HIT\_PRFM, Level 2 data cache software prefetch hit

The counter counts each software prefetch counted by [L2D\_CACHE\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x814A--L2D-CACHE-PRFM--Level-2-data-cache-software-prefetch?lang=en#event_l2d_cache_prfm) that hits in the Level 2 data or unified cache.
