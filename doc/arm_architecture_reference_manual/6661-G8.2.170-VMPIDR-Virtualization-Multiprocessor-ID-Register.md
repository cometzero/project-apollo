# ​G8.2.170 VMPIDR, Virtualization Multiprocessor ID Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-170-VMPIDR--Virtualization-Multiprocessor-ID-Register>

##### G8.2.170 VMPIDR, Virtualization Multiprocessor ID Register

The VMPIDR characteristics are:

Purpose
:   Holds the value of the Virtualization Multiprocessor ID. This is the value returned by Non-secure EL1 reads of [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr), which in a multiprocessor system, provides an additional PE identification system.

Configuration
:   If EL2 is not implemented but EL3 is implemented, this register takes the value of the [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).

    AArch32 System register VMPIDR bits [31:0] are architecturally mapped to AArch64 System register [VMPIDR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-218-VMPIDR-EL2--Virtualization-Multiprocessor-ID-Register?lang=en#reg_aarch64_vmpidr_el2)[31:0].

    This register is present only when FEAT\_AA32EL2 is implemented. Otherwise, direct accesses to VMPIDR are UNDEFINED.

Attributes
:   VMPIDR is a 32-bit register.

    The reset behavior of this field is:

    - On a Warm reset:
      - When the highest implemented Exception level is EL3 or the highest implemented Exception level is EL2, this field resets to the value in [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).U.
      - Otherwise, this field resets to an architecturally UNKNOWN value.

Bits [29:25]
:   Reserved, RES0.

MT, bit [24]
:   Indicates whether the lowest level of affinity consists of logical PEs that are implemented using a multithreading type approach. See the description of Aff0 for more information about affinity levels.

      - Otherwise, this field resets to an architecturally UNKNOWN value.

Aff1, bits [15:8]
:   Affinity level 1. See the description of Aff0 for more information.

    The reset behavior of this field is:

    - On a Warm reset:
      - When the highest implemented Exception level is EL3 or the highest implemented Exception level is EL2, this field resets to the value in [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).Aff1.
      - Otherwise, this field resets to an architecturally UNKNOWN value.

Aff0, bits [7:0]
:   Affinity level 0. The value of the [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).{Aff2, Aff1, Aff0} or [MPIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-137-MPIDR-EL1--Multiprocessor-Affinity-Register?lang=en#reg_aarch64_mpidr_el1).{Aff3, Aff2, Aff1, Aff0} set of fields of each PE must be unique within the system as a whole.

    The reset behavior of this field is:

    - On a Warm reset:
      - When the highest implemented Exception level is EL3 or the highest implemented Exception level is EL2, this field resets to the value in [MPIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-114-MPIDR--Multiprocessor-Affinity-Register?lang=en#reg_aarch32_mpidr).Aff0.
      - Otherwise, this field resets to an architecturally UNKNOWN value.
