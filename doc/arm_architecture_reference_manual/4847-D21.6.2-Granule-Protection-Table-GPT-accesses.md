# ​D21.6.2 Granule Protection Table (GPT) accesses

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-6-Effect-of-access-type-on-MPAM-information/-D21-6-2-Granule-Protection-Table--GPT--accesses>

##### D21.6.2 Granule Protection Table (GPT) accesses

R MFSPP
:   In MPAM for RME, Granule Protection Table (GPT) accesses for:

    - Instruction fetches, use the same [PARTID space](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-2-PARTID-spaces?lang=en#mpam_partid_spaces), PARTID\_I, field, and PMG\_I field as their instruction fetch.
    - Data accesses, use the same PARTID space, PARTID\_D field, and PMG\_D field as their data access.
    - A translation table walk, use the same PARTID space, [PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-?lang=en#mpam_partition_identifiers), and [PMG](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-4-Performance-Monitoring-Groups--PMGs-?lang=en#mpam_pmg) as the translation table access.
