##### D21.2.3 Encoding PARTID spaces onto PARTID space signals

R VKVCD
:   The physical [PARTID space](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-2-PARTID-spaces?lang=en#mpam_partid_spaces) that an MPAM PE Requester sends as part of an [MPAM information bundle](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-1-About-MPAM/-D21-1-2-MPAM-information-bundles?lang=en#mpam_mpam_information_bundles) is sent by encoding it onto:

    - An **MPAM\_NS** signal if the MPAM PE does not implement RME.
    - An **MPAM\_SP** signal if the MPAM PE implements RME.

    In MPAM PEs without Secure state, **MPAM\_NS** encoding `0b0` or **MPAM\_SP** encoding `0b00` is reserved.

I MRBXT
:   SoCs can be constructed comprising Requester components that all support MPAM\_NS, that all support MPAM\_SP, or some that support MPAM\_NS and some that support MPAM\_SP.

I TWGKV
:   In MPAMv0p1, if [MPAM3\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-4-MPAM3-EL3--MPAM3-Register--EL3-?lang=en#reg_aarch64_mpam3_el3).FORCE\_NS is implemented as:

    - RAO/WI, Secure PARTIDs are not implemented, and the MPAM PE Requester always sends MPAM\_NS as 1 for both the Secure physical PARTID space and Non-secure physical PARTID space.
    - RW, then setting [MPAM3\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-4-MPAM3-EL3--MPAM3-Register--EL3-?lang=en#reg_aarch64_mpam3_el3).FORCE\_NS to 1 causes the MPAM PE Requester to always send MPAM\_NS as 1 for both the Secure physical PARTID space and Non-secure physical PARTID space.

    See [Effect of the MPAM3\_EL3.{SDEFLT, FORCE\_NS} controls on MPAM PE Secure state execution](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-5-Effect-of-the-MPAM3-EL3--SDEFLT--FORCE-NS--controls-on-PE-Secure-state-execution?lang=en#mpam_effect_mpam_el3_sdeflt_force_ns_on_pe_secure_state_execution).
