# ​F5.1.180 SBFX

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-180-SBFX>

##### F5.1.180 SBFX

Signed Bit Field Extract extracts any number of adjacent bits at any position from a register, sign-extends them to 32 bits, and writes the result to the destination register.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-180-SBFX?lang=en#isa_sbfx_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-180-SBFX?lang=en#isa_sbfx_iclass_t1)).

###### A1

![](images/5797-F5.1.180-SBFX-img01.svg)

###### Encoding

```
SBFX{<c>}{<q>}  <Rd>, <Rn>, #<lsb>, #<width>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let lsbit : integer{} = UInt(lsb);
let widthminus1 : integer{} = UInt(widthm1);
let msbit : integer{} = lsbit + widthminus1;
if d == 15 || n == 15 then UnpredictableProcedure(); end;
if msbit > 31 then UnpredictableProcedure(); end;
```

###### CONSTRAINED UNPREDICTABLE behavior

If `msbit > 31`, then one of the following behaviors must occur:

- The instruction is UNDEFINED.
- The instruction executes as `NOP`.
- The value in the destination register is UNKNOWN.

###### T1

![](images/5797-F5.1.180-SBFX-img02.svg)

###### Encoding

```
SBFX{<c>}{<q>}  <Rd>, <Rn>, #<lsb>, #<width>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let lsbit : integer{} = UInt(imm3::imm2);
let widthminus1 : integer{} = UInt(widthm1);
let msbit : integer{} = lsbit + widthminus1;
// Armv8-A removes UNPREDICTABLE for R13
if d == 15 || n == 15 then UnpredictableProcedure(); end;
if msbit > 31 then UnpredictableProcedure(); end;
```

###### CONSTRAINED UNPREDICTABLE behavior

If `msbit > 31`, then one of the following behaviors must occur:

- The instruction is UNDEFINED.
- The instruction executes as `NOP`.
- The value in the destination register is UNKNOWN.

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<Rd>
:   ​

    Is the general-purpose destination register, encoded in the “Rd” field.

<Rn>
:   ​

    Is the general-purpose source register, encoded in the “Rn” field.

<lsb>
:   ​

    For the “A1” variant: is the bit number of the least significant bit in the field, in the range 0 to 31, encoded in the “lsb” field.

    ​

    For the “T1” variant: is the bit number of the least significant bit in the field, in the range 0 to 31, encoded in the “imm3:imm2” field.

<width>
:   ​

    Is the width of the field, in the range 1 to 32-<lsb>, encoded in the “widthm1” field as <width>-1.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    R(d) = SignExtend{32}(R(n)[msbit:lsbit]);
end;
```
