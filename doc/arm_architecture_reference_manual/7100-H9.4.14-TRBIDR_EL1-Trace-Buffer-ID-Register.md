Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-14-TRBIDR-EL1--Trace-Buffer-ID-Register>

##### H9.4.14 TRBIDR\_EL1, Trace Buffer ID Register

The TRBIDR\_EL1 characteristics are:

Purpose
:   Describes constraints on using the Trace Buffer Unit to an external debugger.

Configuration
:   TRBIDR\_EL1 is in the Core power domain

    External register TRBIDR\_EL1 bits [63:0] are architecturally mapped to AArch64 System register [TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-2-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_aarch64_trbidr_el1)[63:0].

    This register is present only when FEAT\_TRBE\_EXT is implemented. Otherwise, direct accesses to TRBIDR\_EL1 are RES0.

Attributes
:   TRBIDR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/7100-H9.4.14-TRBIDR_EL1-Trace-Buffer-ID-Register-img01.svg)

Bits [63:48]
:   Reserved, RES0.

MaxBuffSize, bits [47:32]
:   Maximum supported trace buffer size. Reserved for software use.

    Reads as `0x0000`

    The only permitted value is `0x0000`, indicating there is no limit to the maximum buffer size.

    Access to this field is RO.

Bits [31:16]
:   Reserved, RES0.

MPAM, bits [15:12]
:   When FEAT\_TRBE\_EXT is implemented:
    :   [FEAT\_MPAMv0p1](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_mpamv0p1) or [FEAT\_MPAMv1p0](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-5-The-Armv8-4-architecture-extension?lang=en#feat_feat_mpamv1p0) extensions. Indicates Memory Partitioning and Monitoring (MPAM) support in the Trace Buffer Unit when using External mode.
