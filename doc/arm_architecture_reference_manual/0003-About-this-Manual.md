#### About this Manual

This Manual describes the Arm® A-profile architecture versions Armv8-A and Armv9-A.

This Manual is also available in HTML on the Arm Developer website, at <https://developer.arm.com/documentation/ddi0487/mc>. The HTML version is currently an early-access preview, provided for convenience only. In the event of any difference between this PDF and the HTML version, this PDF is the authoritative reference.

Download this PDF from <https://developer.arm.com/documentation/ddi0487/mc>.

*The Architecture Speaks* chatbot, available at <https://developer.arm.com/architecture/the-architecture-speaks>, aims to answer questions about the *Arm® Architecture Reference Manual for A-profile architecture*, and point users to sources within it that justify the answers.
