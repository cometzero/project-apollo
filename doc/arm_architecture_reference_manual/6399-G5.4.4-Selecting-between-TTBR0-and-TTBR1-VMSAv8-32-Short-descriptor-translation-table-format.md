##### G5.4.4 Selecting between TTBR0 and TTBR1, VMSAv8-32 Short-descriptor translation table format

As described in [Determining the translation table base address in the VMSAv8-32 translation regimes](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-3-Translation-tables/-G5-3-3-Determining-the-translation-table-base-address-in-the-VMSAv8-32-translation-regimes?lang=en#beigabed), two sets of translation tables can be defined for each of the PL1&0 stage 1 translations, and [TTBR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-167-TTBR0--Translation-Table-Base-Register-0?lang=en#reg_aarch32_ttbr0) and [TTBR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-168-TTBR1--Translation-Table-Base-Register-1?lang=en#reg_aarch32_ttbr1) hold the base addresses for the two sets of tables. When using the Short-descriptor translation table format, the value of [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).N indicates the number of most significant bits of the input VA that determine whether [TTBR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-167-TTBR0--Translation-Table-Base-Register-0?lang=en#reg_aarch32_ttbr0) or [TTBR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-168-TTBR1--Translation-Table-Base-Register-1?lang=en#reg_aarch32_ttbr1) holds the required translation table base address, as follows:

- If N == 0 then use [TTBR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-167-TTBR0--Translation-Table-Base-Register-0?lang=en#reg_aarch32_ttbr0). Setting [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).N to zero disables use of a second set of translation tables.
- If N > 0 then:

  - If bits[31:32-N] of the input VA are all zero, then use [TTBR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-167-TTBR0--Translation-Table-Base-Register-0?lang=en#reg_aarch32_ttbr0).
  - Otherwise use [TTBR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-168-TTBR1--Translation-Table-Base-Register-1?lang=en#reg_aarch32_ttbr1).

Whenever [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).N is nonzero, the size of the translation table addressed by [TTBR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-168-TTBR1--Translation-Table-Base-Register-1?lang=en#reg_aarch32_ttbr1) is 16KB.
