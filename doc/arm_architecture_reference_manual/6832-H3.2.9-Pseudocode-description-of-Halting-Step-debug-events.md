##### H3.2.9 Pseudocode description of Halting Step debug events

There are two pseudocode functions for Halting Step debug events:

- [`HSAdvance`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-87-HSAdvance?lang=en#asl_func_hsadvance_0)`()`. This is called after an instruction has executed and any exception generated by the instruction is taken, except for the case of an SMC exception, in which case it is called before the exception is taken. [`HSAdvance`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-87-HSAdvance?lang=en#asl_func_hsadvance_0)`()` affects the next instruction.
- [`CheckHaltingStep`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-77-CheckHaltingStep?lang=en#asl_func_checkhaltingstep_1)`()`. This is called before the next instruction is executed. If a step is pending, it generates the debug event.
