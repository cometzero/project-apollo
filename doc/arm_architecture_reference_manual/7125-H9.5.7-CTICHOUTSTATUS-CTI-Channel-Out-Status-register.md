##### H9.5.7 CTICHOUTSTATUS, CTI Channel Out Status register

The CTICHOUTSTATUS characteristics are:

Purpose
:   Provides the status of the ECT channel outputs from the CTI.

Configuration
:   CTICHOUTSTATUS is in the Debug power domain

Attributes
:   CTICHOUTSTATUS is a 32-bit register.

###### Field descriptions

![](images/7125-H9.5.7-CTICHOUTSTATUS-CTI-Channel-Out-Status-register-img01.svg)

CHOUT<n> , bits [n], for n = 31 to 0
:   Output channel <n> status.

    If the ECT channels do not support multicycle events, then it is IMPLEMENTATION DEFINED whether an output channel can be observed as active.

    > #### Note
    >
    > The value in CTICHOUTSTATUS is after gating by the channel gate. For more information, see [CTIGATE](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-5-Cross-Trigger-Interface-registers/-H9-5-23-CTIGATE--CTI-Channel-Gate-Enable-register?lang=en#reg_ext_ctigate).

    Accessing this field has the following behavior:

    - When n >= UInt(CTIDEVID.NUMCHAN), access to this field is RAZ/WI.
    - Otherwise, access to this field is RO.
