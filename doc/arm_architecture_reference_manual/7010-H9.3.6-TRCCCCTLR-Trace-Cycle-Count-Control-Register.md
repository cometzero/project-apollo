# ​H9.3.6 TRCCCCTLR, Trace Cycle Count Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-6-TRCCCCTLR--Trace-Cycle-Count-Control-Register>

##### H9.3.6 TRCCCCTLR, Trace Cycle Count Control Register

The TRCCCCTLR characteristics are:

Purpose
:   Set the threshold value for cycle counting.

Configuration
:   External register TRCCCCTLR bits [31:0] are architecturally mapped to AArch64 System register [TRCCCCTLR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-16-TRCCCCTLR--Trace-Cycle-Count-Control-Register?lang=en#reg_aarch64_trcccctlr)[31:0].

    This register is present only when FEAT\_ETE is implemented, FEAT\_TRC\_EXT is implemented, and TRCIDR0.TRCCCI == ‘1’. Otherwise, direct accesses to TRCCCCTLR are RES0.

Attributes
:   TRCCCCTLR is a 32-bit register.

###### Field descriptions

![](images/7010-H9.3.6-TRCCCCTLR-Trace-Cycle-Count-Control-Register-img01.svg)

Bits [31:12]
:   Reserved, RES0.

THRESHOLD, bits [11:0]
:   Sets the threshold value for instruction trace cycle counting.

    The minimum threshold value that can be programmed into THRESHOLD is given in [TRCIDR3](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-36-TRCIDR3--Trace-ID-Register-3?lang=en#reg_ext_trcidr3).CCITMIN. If the THRESHOLD value is smaller than the value in [TRCIDR3](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-36-TRCIDR3--Trace-ID-Register-3?lang=en#reg_ext_trcidr3).CCITMIN then the behavior is CONSTRAINED UNPREDICTABLE. That is, cycle counts might or might not be included in the trace and the cycle count threshold is not known.

    Writing a value of zero when [TRCCONFIGR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-19-TRCCONFIGR--Trace-Configuration-Register?lang=en#reg_ext_trcconfigr).CCI enables instruction trace cycle counting results in CONSTRAINED UNPREDICTABLE behavior. That is, cycle counts might or might not be included in the trace and the cycle count threshold is not known.

    The reset behavior of this field is:

    - On a Trace unit reset, this field resets to an architecturally UNKNOWN value.

###### Accessing TRCCCCTLR

Must be programmed if [TRCCONFIGR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-19-TRCCONFIGR--Trace-Configuration-Register?lang=en#reg_ext_trcconfigr).CCI == 1.

If the trace unit is not in the Idle state it is CONSTRAINED UNPREDICTABLE whether writes to this register are ignored.
