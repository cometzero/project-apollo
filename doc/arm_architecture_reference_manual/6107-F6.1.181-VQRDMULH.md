# ​F6.1.181 VQRDMULH

##### F6.1.181 VQRDMULH

Vector Saturating Rounding Doubling Multiply Returning High Half multiplies corresponding elements in two vectors, doubles the results, and places the most significant half of the final results in the destination vector. The results are rounded. For truncated results see [VQDMULH](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-175-VQDMULH?lang=en#isa_vqdmulh).

The second operand can be a scalar instead of a vector. For more information about scalars see [Advanced SIMD scalars](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-9-Additional-information-about-Advanced-SIMD-and-floating-point-instructions/-F1-9-9-Advanced-SIMD-scalars?lang=en#cjaibjhd).

If any of the results overflow, they are saturated. The cumulative saturation bit, [FPSCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-55-FPSCR--Floating-Point-Status-and-Control-Register?lang=en#reg_aarch32_fpscr).QC, is set if saturation occurs. For details see [Pseudocode details of saturation](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-2-Core-data-types-and-arithmetic-in-AArch32-state?lang=en#beihabgj).

Depending on settings in the [CPACR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-33-CPACR--Architectural-Feature-Access-Control-Register?lang=en#reg_aarch32_cpacr), [NSACR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-120-NSACR--Non-Secure-Access-Control-Register?lang=en#reg_aarch32_nsacr), and [HCPTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-64-HCPTR--Hyp-Architectural-Feature-Trap-Register?lang=en#reg_aarch32_hcptr) registers, and the Security state and PE mode in which the instruction is executed, an attempt to execute the instruction might be UNDEFINED, or trapped to Hyp mode. For more information see [Enabling Advanced SIMD and floating-point support](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-21-Advanced-SIMD-and-floating-point-support/-G1-21-2-Enabling-Advanced-SIMD-and-floating-point-support?lang=en#cihiddff).

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-181-VQRDMULH?lang=en#isa_vqrdmulh_iclass_a1) and [A2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-181-VQRDMULH?lang=en#isa_vqrdmulh_iclass_a2)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-181-VQRDMULH?lang=en#isa_vqrdmulh_iclass_t1) and [T2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F6-T32-and-A32-Advanced-SIMD-and-Floating-point-Instruction-Descriptions/-F6-1-Alphabetical-list-of-Advanced-SIMD-and-floating-point-instructions/-F6-1-181-VQRDMULH?lang=en#isa_vqrdmulh_iclass_t2)).

<Dd>
:   ​

    Is the 64-bit name of the SIMD&FP destination register, encoded in the “D:Vd” field.

<Dn>
:   ​

    Is the 64-bit name of the first SIMD&FP source register, encoded in the “N:Vn” field.

<Dm>
:   ​

    Is the 64-bit name of the second SIMD&FP source register, encoded in the “M:Vm” field.

<Qd>
:   ​

    Is the 128-bit name of the SIMD&FP destination register, encoded in the “D:Vd” field as <Qd>\*2.

<Qn>
:   ​

    Is the 128-bit name of the first SIMD&FP source register, encoded in the “N:Vn” field as <Qn>\*2.

<Qm>
:   ​

    Is the 128-bit name of the second SIMD&FP source register, encoded in the “M:Vm” field as <Qm>\*2.

<Dm[x]>
:   ​

    Is the 64-bit name of the second SIMD&FP source register holding the scalar. If `<dt>` is `S16`, `Dm` is restricted to D0-D7. `Dm` is encoded in “Vm<2:0>”, and `x` is encoded in “M:Vm<3>”. If `<dt>` is `S32`, `Dm` is restricted to D0-D15. `Dm` is encoded in “Vm”, and `x` is encoded in “M”.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    CheckAdvSIMDEnabled();
    var op2 : integer;
    let round : boolean = TRUE;
    if scalar_form then op2 = SInt(D(m)[index*:esize]); end;
    for r = 0 to regs-1 do
        for e = 0 to elements-1 do
            let op1 : integer = SInt(D(n+r)[e*:esize]);
            if !scalar_form then op2 = SInt(D(m+r)[e*:esize]); end;
            let rdmulh : integer = RShr(2*op1*op2, esize, round);
            let (result, sat) : (bits(esize), boolean) = SignedSatQ{esize}(rdmulh);
            D(d+r)[e*:esize] = result;
            if sat then FPSCR().QC = ‘1’; end;
        end;
    end;
end;
```
