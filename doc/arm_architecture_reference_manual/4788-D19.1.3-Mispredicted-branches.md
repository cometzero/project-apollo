# ​D19.1.3 Mispredicted branches

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-3-Mispredicted-branches>

##### D19.1.3 Mispredicted branches

I QHGFW
:   Each [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) generated for a branch instruction contains an indication of whether the branch was correctly or incorrectly predicted by the PE. Branch prediction behavior is IMPLEMENTATION DEFINED and this is an indication of whether such prediction succeeded, or not.

R XHWRB
:   For a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) of a branch instruction, one of the following occurs:

    - If EL2 is implemented and [BRBCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-2-BRBCR-EL2--Branch-Record-Buffer-Control-Register--EL2-?lang=en#reg_aarch64_brbcr_el2).MPRED is 0, then [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).MPRED is set to 0.
    - Else if [BRBCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-1-BRBCR-EL1--Branch-Record-Buffer-Control-Register--EL1-?lang=en#reg_aarch64_brbcr_el1).MPRED is 0, then [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).MPRED is set to 0.
    - Otherwise:

      - [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).MPRED is 0 for a correctly predicted branch.
      - [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).MPRED is 1 for an incorrectly predicted branch.

    Note: This applies even when EL2 is disabled in the current Security state.

R DHNPJ
:   For a [Branch record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D19-The-Branch-Record-Buffer-Extension/-D19-1-About-the-Branch-Record-Buffer-Extension/-D19-1-1-Branch-records?lang=en#brbe_branch_record) of an exception, [BRBINF<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-8-Branch-Record-Buffer-Extension-registers/-D24-8-6-BRBINF-n--EL1--Branch-Record-Buffer-Information-Register--n---n---0---31?lang=en#reg_aarch64_brbinfn_el1).MPRED has the value 0.

R LBRGV
:   An incorrectly predicted branch is when any of the following is true:

    - The direction of a conditional branch was incorrectly predicted at least once during the execution of the instruction.
    - The target of a branch was incorrectly predicted at least once during the execution of the instruction.
    - The branch was not predicted by a branch predictor.

R RDLQF
:   A correctly predicted branch is one that is not incorrectly predicted.
