# ​B1.4.7 About PSTATE.ZA

##### B1.4.7 About PSTATE.ZA

I HVKTL
:   [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).ZA enables ZA storage and, if [FEAT\_SME2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-4-The-Armv9-3-architecture-extension?lang=en#feat_feat_sme2) is implemented, the ZT0 register.

R JHMYL
:   When [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).ZA is 0, the contents of ZA storage and the ZT0 register are not valid, and SME and SME2 instructions that access them are *illegal*.

R SFWMY
:   When [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).ZA is 1, the contents of ZA storage and the ZT0 register are valid and are retained by hardware irrespective of whether the PE is in *Streaming SVE mode*, and:

    - SME `LDR` (array vector), `STR` (array vector), and `ZERO` (tiles) instructions that access ZA storage are legal.
    - SME2 `LDR` (table), `STR` (table), and `ZERO` (table) instructions that access the ZT0 register are legal.
    - When the PE is in Streaming SVE mode, all other SME and SME2 instructions that access ZA storage or the ZT0 register are legal.

R YRZRM
:   When [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).ZA is changed by any method from 0 to 1, all implemented bits of ZA storage and the ZT0 register are set to zero.

I LRDZR
:   When [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).ZA is changed from 1 to 0, there is no architecturally defined effect on ZA storage and the ZT0 register, because the contents of ZA storage and the ZT0 register cannot be observed when [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).ZA is 0.

I QWCJS
:   When [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).ZA is changed from 0 to 1, or from 1 to 0, there is no effect on the SVE scalable vector registers, SVE predicate registers, and [FPSR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-10-FPSR--Floating-point-Status-Register?lang=en#reg_aarch64_fpsr) if [PSTATE](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-3-Process-state--PSTATE?lang=en#beibiihah1).SM is not changed.
