# ​G5.6.2 About the PAN bit

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-6-Memory-access-control/-G5-6-2-About-the-PAN-bit>

##### G5.6.2 About the PAN bit

When the value of [PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch).PAN is 1, any privileged data access from PL1 or EL2 to a virtual memory address that is accessible at EL0 generates a Permission fault.

When the value of [PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch).PAN is 0, the translation system is the same as in Armv8.0.

A corresponding PAN bit is added to [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr) and [SPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-128-SPSR--Saved-Program-Status-Register?lang=en#reg_aarch32_spsr) for exception returns, and [DSPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-30-DSPSR--Debug-Saved-Program-Status-Register?lang=en#reg_aarch32_dspsr) for entry to and exit from Debug state.

A new SPAN bit is added to [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr) that controls whether the PAN state bit is set on taking an exception to EL1 from either Secure or Non-secure state, or to EL3 from Secure state when EL3 is using AArch32.

[CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN bit can be written using an `MSR` instruction at PL1 or higher. Data writes to [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN using an `MSR` instruction at EL0 are ignored. The value that is returned for an `MRS` instruction of [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr) from EL0 is UNKNOWN. In keeping with all other writes to the [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr), other than for instruction fetches, the effect of the PAN state bit does not need to be explicitly synchronized.

The PAN state bit has no effect on:

- Data Cache instructions.
- Address translation instructions, other than `ATS1CPRP` and `ATS1CPWP` when [FEAT\_PAN2](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_pan2) is implemented.
- Unprivileged instructions, `LDRBT`, `LDRHT`, `LDRT`, `LDRSBT`, `LDRSHT`, `STRBT`, `STRHT`, `STRT`, `STRSBT`, and `STRSHT`, unless the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is {1, 0}.
- Instruction accesses.
- Manager domains.

The PAN bit has no effect when the first stage of translation is disabled for the current translation regime or when the first stage of translation for the current translation regime does not describe the permissions for access at EL0.

If access is disabled, then the access will give rise to a stage 1 Permission fault.

On an exception taken from AArch32:

- [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN is copied to [SPSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#spsr_elx).PAN, when the target Exception level is AArch64.
- [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN is copied to [SPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-128-SPSR--Saved-Program-Status-Register?lang=en#reg_aarch32_spsr).PAN, when the target Exception level is AArch32.

On an exception return from AArch32 to AArch32, [SPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-128-SPSR--Saved-Program-Status-Register?lang=en#reg_aarch32_spsr).PAN is copied to [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN.

On entry to Debug state, [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN is copied to [DSPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-30-DSPSR--Debug-Saved-Program-Status-Register?lang=en#reg_aarch32_dspsr).PAN.

On exit from Debug state, [DSPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-30-DSPSR--Debug-Saved-Program-Status-Register?lang=en#reg_aarch32_dspsr).PAN is copied to [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN.

The [CPSR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-35-CPSR--Current-Program-Status-Register?lang=en#reg_aarch32_cpsr).PAN bit is not an Execution state bit.

> #### Note
>
> - In Non-debug state, in AArch32 state, software can use the `SETPAN #imm` instruction to modify [PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch).PAN.
> - In Debug state, in AArch32 state, a debugger can use the `ERET` instruction to perform a DRPS operation to modify [PSTATE](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-4-Process-state--PSTATE?lang=en#cegjcbch).PAN.
