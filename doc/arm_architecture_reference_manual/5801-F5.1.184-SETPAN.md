##### F5.1.184 SETPAN

Set Privileged Access Never writes a new value to [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).PAN.

This instruction is available only in privileged mode and it is a NOP when executed in User mode.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-184-SETPAN?lang=en#isa_setpan_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-184-SETPAN?lang=en#isa_setpan_iclass_t1)).

###### A1

###### (FEAT\_PAN)

![](images/5801-F5.1.184-SETPAN-img01.svg)

###### Encoding

```
SETPAN{<q>}  #<imm> // (Cannot be conditional)
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_PAN) then Undefined(); end;
let value : bit = imm1;
```

###### T1

###### (FEAT\_PAN)

![](images/5801-F5.1.184-SETPAN-img02.svg)

###### Encoding

```
SETPAN{<q>}  #<imm> // (Not permitted in IT block)
```

###### Decode for this encoding

```
if InITBlock() then UnpredictableProcedure(); end;
if !IsFeatureImplemented(FEAT_PAN) then Undefined(); end;
let value : bit = imm1;
```
