# ​H6.4.2 Powerup request mechanism if FEAT_DoPD is not implemented

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H6-Debug-Reset-and-Powerdown-Support/-H6-4-Powerup-request-mechanism/-H6-4-2-Powerup-request-mechanism-if-FEAT-DoPD-is-not-implemented>

##### H6.4.2 Powerup request mechanism if FEAT\_DoPD is not implemented

If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, the bit [EDPRCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-45-EDPRCR--External-Debug-Power-Reset-Control-Register?lang=en#reg_ext_edprcr).COREPURQ is the powerup request mechanism.

The control registers [DBGPRCR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babhfcgh).CORENPDRQ and [EDPRCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-45-EDPRCR--External-Debug-Power-Reset-Control-Register?lang=en#reg_ext_edprcr).COREPURQ provide an interface between the power controller and the PE. They typically map directly to signals in the recommended external debug interface.

On Cold reset, if [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, [DBGPRCR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babhfcgh).CORENPDRQ is set to the value of [EDPRCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-45-EDPRCR--External-Debug-Power-Reset-Control-Register?lang=en#reg_ext_edprcr).COREPURQ.
