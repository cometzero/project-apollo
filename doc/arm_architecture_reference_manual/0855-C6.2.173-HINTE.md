##### C6.2.173 HINTE

Hint instruction (extended)

This instruction is the extended instruction set space that is reserved for future architectural hint instructions. The encodings described here are not allocated in this revision of the architecture, and behave as NOPs. These encodings might be allocated to other hint functionality in future revisions of the architecture and therefore must not be used by software.

###### System

###### (FEAT\_HINTE)

![](images/0855-C6.2.173-HINTE-img01.svg)

###### Encoding

Applies when `(!(L == 0 && imm3 == 011 && Rt == 11111))`

```
HINTE  #<imm16>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_HINTE) then EndOfDecode(Decode_UNDEF); end;
```

###### Assembler Symbols

<imm16>
:   ​

    Is a 16-bit unsigned immediate, in the range 0 to 65535, excluding the values 12319 to 16383 in increments of 32, encoded in the “L:imm3:imm7:Rt” fields.

###### Operation

```
return; // Do nothing
```
