# ​J1.3.227 AArch32_S1ICacheEnabled

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-227-AArch32-S1ICacheEnabled>

##### J1.3.227 AArch32\_S1ICacheEnabled

```
// AArch32_S1ICacheEnabled()
// =========================
// Determine cacheability of stage 1 instruction fetches
func AArch32_S1ICacheEnabled(regime : Regime) => boolean
begin
    case regime of
        when Regime_EL30 => return SCTLR_S().I == ‘1’;
        when Regime_EL2  => return HSCTLR().I == ‘1’;
        when Regime_EL10 =>
            return (if HaveEL(EL3) && ELUsingAArch32(EL3) then SCTLR_NS().I else SCTLR().I) == ‘1’;
    end;
end;
```
