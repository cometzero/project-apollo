##### J1.4.31 IsAccessSecure

```
// IsAccessSecure()
// ================
// Returns TRUE when an access is Secure
func IsAccessSecure(addrdesc : AddressDescriptor) => boolean
begin
    return addrdesc.paddress.paspace == PAS_Secure;
end;
```
