###### E1.3.11.1 Generation of specific floating-point values

The following pseudocode functions generate specific floating-point values. The `sign` argument is `'0'` for the positive version and `'1'` for the negative version:

- [`FPInfinity`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-313-FPInfinity?lang=en#asl_func_fpinfinity_2)`()`.
- [`FPMaxNormal`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-317-FPMaxNormal?lang=en#asl_func_fpmaxnormal_2)`()`.
- [`FPZero`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-364-FPZero?lang=en#asl_func_fpzero_2)`()`.
- [`FPTwo`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-359-FPTwo?lang=en#asl_func_fptwo_2)`()`.
- [`FPThree`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-356-FPThree?lang=en#asl_func_fpthree_2)`()`.

###### E1.3.11.2 Floating-point negation and absolute value

The floating-point negation and absolute value operations affect only the sign bit. They do not treat NaN operands specially, nor denormalized number operands when flush-to-zero is selected.

The floating-point negation operation is described by the pseudocode function [`FPNeg`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-329-FPNeg?lang=en#asl_func_fpneg_3)`()`. The floating-point absolute value operation is described by the pseudocode function [`FPAbs`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-291-FPAbs?lang=en#asl_func_fpabs_3)`()`.

###### E1.3.11.3 Floating-point value unpacking

The [`FPUnpack`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-361-FPUnpack?lang=en#asl_func_fpunpack_4)`()` function determines the type of a floating-point number, defined by [`FPType`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-360-FPType?lang=en#asl_type_fptype) `{}`, and its numerical value. It also does flush-to-zero processing on input operands.

###### E1.3.11.4 Floating-point exception and NaN handling

The [`FPProcessException`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-335-FPProcessException?lang=en#asl_func_fpprocessexception_2)`()` procedure checks whether a floating-point exception is trapped, and handles it accordingly. The floating-point exception types are defined by [`FPExc`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-312-FPExc?lang=en#asl_type_fpexc) `{}`.

The [`FPProcessNaN`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-336-FPProcessNaN?lang=en#asl_func_fpprocessnan_5)`()` function processes a NaN operand, producing the correct result value and generating an Invalid Operation floating-point exception if necessary. The [`FPProcessNaNs`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-337-FPProcessNaNs?lang=en#asl_func_fpprocessnans_7)`()` function performs the standard NaN processing for a two-operand operation. The [`FPProcessNaNs3`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-338-FPProcessNaNs3?lang=en#asl_func_fpprocessnans3_9)`()` function performs the standard NaN processing for a three-operand operation.

###### E1.3.11.5 Floating-point rounding

The [`FPRound`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-343-FPRound?lang=en#asl_func_fpround_3)`()` function rounds and encodes a floating-point result to a specified destination format. This includes processing Overflow, Underflow and Inexact floating-point exceptions and performing flush-to-zero processing on result values.

###### E1.3.11.6 Selection of Arm standard floating-point arithmetic

The [`StandardFPCR`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-97-StandardFPCR?lang=en#asl_func_standardfpcr_0)`()` function returns the [FPSCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-55-FPSCR--Floating-Point-Status-and-Control-Register?lang=en#reg_aarch32_fpscr) value that selects Arm standard floating-point arithmetic. Most of the arithmetic functions have a Boolean `fpscr_controlled` argument that is `TRUE` for Floating-point operations and `FALSE` for Advanced SIMD operations, and that selects between using the real [FPSCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-55-FPSCR--Floating-Point-Status-and-Control-Register?lang=en#reg_aarch32_fpscr) value and this value.

###### E1.3.11.8 Floating-point maximum and minimum

The [`FPMax`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-316-FPMax?lang=en#asl_func_fpmax_6)`()` function returns the maximum of two floating-point numbers. ###### E1.3.11.9 Floating-point addition and subtraction

The [`FPAdd`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-294-FPAdd?lang=en#asl_func_fpadd_5)`()` function adds two floating-point numbers. The [`FPSub`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-354-FPSub?lang=en#asl_func_fpsub_5)`()` function subtracts one floating-point number from another floating-point number.

###### E1.3.11.10 Floating-point multiplication and division

The [`FPMul`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-322-FPMul?lang=en#asl_func_fpmul_4)`()` function multiplies two floating-point numbers. ###### E1.3.11.11 Floating-point fused multiply-add

The [`FPMulAdd`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-323-FPMulAdd?lang=en#asl_func_fpmuladd_6)`()` function performs a floating-point fused multiply-add.
