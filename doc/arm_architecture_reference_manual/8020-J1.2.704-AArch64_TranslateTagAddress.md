# ​J1.2.704 AArch64_TranslateTagAddress

##### J1.2.704 AArch64\_TranslateTagAddress

```
// AArch64_TranslateTagAddress()
// =============================
// Translate an address for accessing an Allocation Tag.
func AArch64_TranslateTagAddress(va : bits(64),
                                 accdesc_in : AccessDescriptor,
                                 aligned : boolean,
                                 size : integer) => (MemTagType, AddressDescriptor)
begin
    assert !accdesc_in.tagchecked;
    var accdesc : AccessDescriptor = accdesc_in;
    let taddrdesc : AddressDescriptor = AArch64_TranslateAddress(va, accdesc, aligned, size);
    return (taddrdesc.memattrs.tags, taddrdesc);
end;
```
