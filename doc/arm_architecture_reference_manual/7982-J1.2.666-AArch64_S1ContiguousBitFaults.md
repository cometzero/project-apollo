# ​J1.2.666 AArch64_S1ContiguousBitFaults

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-666-AArch64-S1ContiguousBitFaults>

##### J1.2.666 AArch64\_S1ContiguousBitFaults

```
// AArch64_S1ContiguousBitFaults()
// ===============================
// If contiguous bit is set, returns whether the translation size exceeds the
// stage 1 input address size and if the implementation generates a fault.
func AArch64_S1ContiguousBitFaults(walkparams : S1TTWParams, walkstate : TTWState) => boolean
begin
    // Input Address size
    let iasize : AddressSize = AArch64_IASize(walkparams.txsz);
    // Translation size
    let tsize : integer = TranslationSize(walkparams.d128, walkparams.tgx, walkstate.level);
    let csize : integer = ContiguousSize(walkparams.d128, walkparams.tgx, walkstate);
    return (tsize + csize > iasize &&
            ImpDefBool(“Translation fault on misprogrammed contiguous bit”));
end;
```
