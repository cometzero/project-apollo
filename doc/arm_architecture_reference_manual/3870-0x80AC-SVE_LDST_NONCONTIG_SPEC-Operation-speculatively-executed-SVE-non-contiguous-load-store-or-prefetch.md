##### `0x80AC`, SVE\_LDST\_NONCONTIG\_SPEC, Operation speculatively executed, SVE non-contiguous load, store, or prefetch

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) operation that reads from or writes to memory due to an SVE non-contiguous gather-load, scatter-store, or gather-prefetch instruction.
