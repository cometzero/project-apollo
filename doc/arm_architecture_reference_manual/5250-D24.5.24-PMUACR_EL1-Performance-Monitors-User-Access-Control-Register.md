# ​D24.5.24 PMUACR_EL1, Performance Monitors User Access Control Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-24-PMUACR-EL1--Performance-Monitors-User-Access-Control-Register>

##### D24.5.24 PMUACR\_EL1, Performance Monitors User Access Control Register

The PMUACR\_EL1 characteristics are:

Purpose
:   Enables or disables EL0 access to specific Performance Monitors.

Configuration
:   This register is present only when FEAT\_PMUv3p9 is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to PMUACR\_EL1 are UNDEFINED.

Attributes
:   PMUACR\_EL1 is a 64-bit register.

###### Field descriptions
