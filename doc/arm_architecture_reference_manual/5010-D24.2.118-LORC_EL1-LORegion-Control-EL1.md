# ​D24.2.118 LORC_EL1, LORegion Control (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-118-LORC-EL1--LORegion-Control--EL1->

##### D24.2.118 LORC\_EL1, LORegion Control (EL1)

The LORC\_EL1 characteristics are:

Purpose
:   Enables and disables LORegions, and selects the current LORegion descriptor.

Configuration
:   If no LORegion descriptors are supported by the PE, then this register is RES0.

    This register is present only when FEAT\_LOR is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to LORC\_EL1 are UNDEFINED.

Attributes
:   LORC\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5010-D24.2.118-LORC_EL1-LORegion-Control-EL1-img01.svg)

Bits [63:10]
:   Reserved, RES0.

DS, bits [9:2]
:   Descriptor Select. Selects the current LORegion descriptor accessed by [LORSA\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-122-LORSA-EL1--LORegion-Start-Address--EL1-?lang=en#reg_aarch64_lorsa_el1), [LOREA\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-119-LOREA-EL1--LORegion-End-Address--EL1-?lang=en#reg_aarch64_lorea_el1), and [LORN\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-121-LORN-EL1--LORegion-Number--EL1-?lang=en#reg_aarch64_lorn_el1).

    If this field points to an LORegion descriptor that is not supported by an implementation, then the registers [LORN\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-121-LORN-EL1--LORegion-Number--EL1-?lang=en#reg_aarch64_lorn_el1), [LOREA\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-119-LOREA-EL1--LORegion-End-Address--EL1-?lang=en#reg_aarch64_lorea_el1), and [LORSA\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-122-LORSA-EL1--LORegion-Start-Address--EL1-?lang=en#reg_aarch64_lorsa_el1) are RES0.

    The number of LORegion descriptors in IMPLEMENTATION DEFINED. The maximum number of LORegion descriptors supported is 256. If the number is less than 256, then bits[63:M+2] are RES0, where M is Log2(Number of LORegion descriptors supported by the implementation).

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bit [1]
:   Reserved, RES0.

EN, bit [0]
:   Enable. Indicates whether LORegions are enabled.
