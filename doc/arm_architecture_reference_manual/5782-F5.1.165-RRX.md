##### F5.1.165 RRX

Rotate Right with Extend provides the value of the contents of a register shifted right by one place, with the Carry flag shifted into bit[31].

This is an alias of [MOV, MOVS (register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-113-MOV--MOVS--register-?lang=en#isa_mov_r). This means:

- The encodings in this description are named to match the encodings of [MOV, MOVS (register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-113-MOV--MOVS--register-?lang=en#isa_mov_r).
- The description of [MOV, MOVS (register)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-113-MOV--MOVS--register-?lang=en#isa_mov_r) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-165-RRX?lang=en#isa_rrx_mov_r_iclass_a1)) and T32 ([T3](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-165-RRX?lang=en#isa_rrx_mov_r_iclass_t3)).

###### A1

![](images/5782-F5.1.165-RRX-img01.svg)

###### Encoding for the MOV, rotate right with extend variant

```
RRX{<c>}{<q>}  {<Rd>, }<Rm>
```

is equivalent to

```
MOV{<c>}{<q>}  <Rd>, <Rm>, RRX
```

and is always the preferred disassembly.

###### T3

###### Encoding for the MOV, rotate right with extend variant

```
RRX{<c>}{<q>}  {<Rd>, }<Rm>
```

is equivalent to

```
MOV{<c>}{<q>}  <Rd>, <Rm>, RRX
```

and is always the preferred disassembly.

<Rd>
:   ​

    For the “A1 MOV, rotate right with extend” variant: is the general-purpose destination register, encoded in the “Rd” field. Arm deprecates using the PC as the destination register, but if the PC is used, the instruction is a branch to the address calculated by the operation. This is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).

    ​

    For the “T3 MOV, rotate right with extend” variant: is the general-purpose destination register, encoded in the “Rd” field.

<Rm>
:   ​

    For the “A1 MOV, rotate right with extend” variant: is the general-purpose source register, encoded in the “Rm” field. The PC can be used, but this is deprecated.

    ​

    For the “T3 MOV, rotate right with extend” variant: is the general-purpose source register, encoded in the “Rm” field.
