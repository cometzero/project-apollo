##### G4.8.7 Abort exceptions

The function [`AArch32_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-19-AArch32-Abort?lang=en#asl_func_aarch32_abort_1)`()` generates a Data Abort exception or a Prefetch Abort exception by calling the [`AArch32_TakeDataAbortException`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-25-AArch32-TakeDataAbortException?lang=en#asl_func_aarch32_takedataabortexception_1)`()` or [`AArch32_TakePrefetchAbortException`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-26-AArch32-TakePrefetchAbortException?lang=en#asl_func_aarch32_takeprefetchabortexception_1)`()` function.

The [`FaultRecord`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-427-FaultRecord?lang=en#asl_type_faultrecord) type describes a fault. Functions that check for faults return a record of this type appropriate to the type of fault. [Pseudocode description of VMSAv8-32 memory system operations](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-14-Pseudocode-description-of-VMSAv8-32-memory-system-operations?lang=en#chdgcgdb) provides a number of wrappers to generate a FaultRecord.

The function [`NoFault`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-766-NoFault?lang=en#asl_func_nofault_0)`()` returns a null record that indicates no fault. The [`IsFault`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-159-IsFault?lang=en#asl_func_isfault_1)`()` function tests whether a FaultRecord contains a fault.
