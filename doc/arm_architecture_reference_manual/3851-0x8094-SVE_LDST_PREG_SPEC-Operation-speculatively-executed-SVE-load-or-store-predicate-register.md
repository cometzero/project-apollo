##### `0x8094`, SVE\_LDST\_PREG\_SPEC, Operation speculatively executed, SVE load or store predicate register

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) SVE predicate register load or store operation due to any of the following instructions:

- SVE: LDR (predicate) or STR (predicate).
