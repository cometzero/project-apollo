##### J1.4.123 SysRegZeroPMUCounters

```
// SysRegZeroPMUCounters()
// =======================
// Zero set of counters specified by the mask in ‘val’, for System register access.
// For a System register write to PMZR_EL0, ‘val’ is the value passed in X<t>.
func SysRegZeroPMUCounters(val : bits(64))
begin
    let masked_val : bits(64) = val AND GetPMUWriteMask(TRUE);
    ApplyPMUZeroMask(masked_val);
    return;
end;
```
