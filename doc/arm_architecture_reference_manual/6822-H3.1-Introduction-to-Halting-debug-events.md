# ​H3.1 Introduction to Halting debug events

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-1-Introduction-to-Halting-debug-events>

#### H3.1 Introduction to Halting debug events

External debug defines Halting debug events. The following Halting debug events are available from the introduction of Armv8:

- [Halting Step debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-2-Halting-Step-debug-events?lang=en#babfcjha).
- [Halt Instruction debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-3-Halt-Instruction-debug-event?lang=en#babebjgf).
- [Exception Catch debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-4-Exception-Catch-debug-event?lang=en#exception_catch_debug_event).
- [External Debug Request debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-5-External-Debug-Request-debug-event?lang=en#babgjjbd).
- [OS Unlock Catch debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-6-OS-Unlock-Catch-debug-event?lang=en#babcchic).
- [Reset Catch debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-7-Reset-Catch-debug-events?lang=en#babhbbeg).
- [Software Access debug event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-8-Software-Access-debug-event?lang=en#babcedie).

If halting is allowed, a Halting debug event halts the PE. The PE enters Debug state.

In addition, breakpoints and watchpoints might halt the PE if halting is allowed. See [Breakpoint and Watchpoint debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-3-Breakpoint-and-Watchpoint-debug-events?lang=en#babjijfb). Because breakpoints and watchpoints can generate an exception or halt the PE, Breakpoint and Watchpoint debug events are not classified as Halting debug events.

For a definition of Debug state, see [Debug State](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State?lang=en#babgfbeg). For a definition of halting allowed, see [Halting allowed and halting prohibited](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-1-Halting-allowed-and-halting-prohibited?lang=en#babiiffc).

[Debug state entry and debug event prioritization](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-5-Debug-state-entry-and-debug-event-prioritization?lang=en#babgehbh) describes the behavior when multiple debug events are generated by an instruction.

See also [Synchronization and Halting debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-9-Synchronization-and-Halting-debug-events?lang=en#babgeeca).
