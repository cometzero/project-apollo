# ​G8.2.94 ID_MMFR1, Memory Model Feature Register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-94-ID-MMFR1--Memory-Model-Feature-Register-1>

##### G8.2.94 ID\_MMFR1, Memory Model Feature Register 1

The ID\_MMFR1 characteristics are:

Purpose
:   Provides information about the implemented memory model and memory management support in AArch32 state.

    For general information about the interpretation of the ID registers see [‘Principles of the ID scheme for fields in ID registers’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-1-About-the-AArch32-System-registers/-G8-1-3-Principles-of-the-ID-scheme-for-fields-in-ID-registers?lang=en#chdidagf).

Configuration
:   AArch32 System register ID\_MMFR1 bits [31:0] are architecturally mapped to AArch64 System register [ID\_MMFR1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-108-ID-MMFR1-EL1--AArch32-Memory-Model-Feature-Register-1?lang=en#reg_aarch64_id_mmfr1_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ID\_MMFR1 are UNDEFINED.

Attributes
:   ID\_MMFR1 is a 32-bit register.
