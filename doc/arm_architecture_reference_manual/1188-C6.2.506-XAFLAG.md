##### C6.2.506 XAFLAG

Convert floating-point condition flags from external format to Arm format

This instruction converts the state of the PSTATE.{N,Z,C,V} flags from an alternative representation required by some software to a form representing the result of an Arm floating-point scalar compare instruction.

###### System

###### (FEAT\_FlagM2)

![](images/1188-C6.2.506-XAFLAG-img01.svg)

###### Encoding

```
XAFLAG
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_FlagM2) then EndOfDecode(Decode_UNDEF); end;
```

###### Operation

```
let n : bit = NOT(PSTATE.C) AND NOT(PSTATE.Z);
let z : bit = PSTATE.Z AND PSTATE.C;
let c : bit = PSTATE.C OR PSTATE.Z;
let v : bit = NOT(PSTATE.C) AND PSTATE.Z;
PSTATE.N = n;
PSTATE.Z = z;
PSTATE.C = c;
PSTATE.V = v;
```
