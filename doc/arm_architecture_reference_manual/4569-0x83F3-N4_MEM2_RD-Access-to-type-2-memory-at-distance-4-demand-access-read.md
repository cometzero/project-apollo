##### `0x83F3`, N4\_MEM2\_RD, Access to type 2 memory at distance 4, demand access, read

The counter counts each demand read counted by [N4\_MEM\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E3--N4-MEM-RD--Access-to-memory-at-distance-4--demand-access--read?lang=en#event_n4_mem_rd) to a second memory type at distance 4.

The definition of memory types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system. See also [N1\_MEM2\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83F0--N1-MEM2-RD--Access-to-type-2-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem2_rd).
