# ​D1.2.4 Saved Program Status Registers

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-2-Registers-for-instruction-processing-and-exception-handling/-D1-2-4-Saved-Program-Status-Registers>

##### D1.2.4 Saved Program Status Registers

R PJSSD
:   In AArch64 state, each implemented Exception level to which an exception can be taken has a Saved Program Status Register (SPSR). The following are the SPSRs:

    - For exceptions taken to EL1 using AArch64, [SPSR\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-21-SPSR-EL1--Saved-Program-Status-Register--EL1-?lang=en#reg_aarch64_spsr_el1).
    - For exceptions taken to EL2 using AArch64, [SPSR\_EL2](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-22-SPSR-EL2--Saved-Program-Status-Register--EL2-?lang=en#reg_aarch64_spsr_el2).
    - For exceptions taken to EL3 using AArch64, [SPSR\_EL3](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-23-SPSR-EL3--Saved-Program-Status-Register--EL3-?lang=en#reg_aarch64_spsr_el3).

I DVBPS
:   When a Warm reset is asserted, the SPSRs are reset to an architecturally UNKNOWN value.

    For more information, see [Process state, PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate).
