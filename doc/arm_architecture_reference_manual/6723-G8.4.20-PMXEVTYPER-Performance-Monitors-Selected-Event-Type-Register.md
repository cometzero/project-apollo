# ​G8.4.20 PMXEVTYPER, Performance Monitors Selected Event Type Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-20-PMXEVTYPER--Performance-Monitors-Selected-Event-Type-Register>

##### G8.4.20 PMXEVTYPER, Performance Monitors Selected Event Type Register

The PMXEVTYPER characteristics are:

Purpose
:   When [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL selects an event counter, this accesses a [PMEVTYPER<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-11-PMEVTYPER-n---Performance-Monitors-Event-Type-Registers--n---0---30?lang=en#reg_aarch32_pmevtypern) register. When [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL selects the cycle counter, this accesses [PMCCFILTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-1-PMCCFILTR--Performance-Monitors-Cycle-Count-Filter-Register?lang=en#reg_aarch32_pmccfiltr).

Configuration
:   AArch32 System register PMXEVTYPER bits [31:0] are architecturally mapped to AArch64 System register [PMXEVTYPER\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-27-PMXEVTYPER-EL0--Performance-Monitors-Selected-Event-Type-Register?lang=en#reg_aarch64_pmxevtyper_el0)[31:0].

    This register is present only when FEAT\_AA32 is implemented and FEAT\_PMUv3 is implemented. Otherwise, direct accesses to PMXEVTYPER are UNDEFINED.

Attributes
:   PMXEVTYPER is a 32-bit register.

###### Field descriptions

![](images/6723-G8.4.20-PMXEVTYPER-Performance-Monitors-Selected-Event-Type-Register-img01.svg)

ETR, bits [31:0]
:   Event type register or [PMCCFILTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-1-PMCCFILTR--Performance-Monitors-Cycle-Count-Filter-Register?lang=en#reg_aarch32_pmccfiltr).

    When [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL == 31, this register accesses [PMCCFILTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-1-PMCCFILTR--Performance-Monitors-Cycle-Count-Filter-Register?lang=en#reg_aarch32_pmccfiltr).

    Otherwise, this register accesses [PMEVTYPER<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-11-PMEVTYPER-n---Performance-Monitors-Event-Type-Registers--n---0---30?lang=en#reg_aarch32_pmevtypern) where n is the value in [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL.

###### Accessing PMXEVTYPER

If [FEAT\_FGT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_fgt) is implemented, and [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is not 31 and is greater than or equal to the number of accessible event counters, then the behavior of permitted reads and writes of [PMXEVTYPER](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-20-PMXEVTYPER--Performance-Monitors-Selected-Event-Type-Register?lang=en#reg_aarch32_pmxevtyper) is as follows:

- If [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is greater than or equal to the Effective value of [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPMN, the access is UNDEFINED.
- Otherwise, the access is trapped to EL2.

If [FEAT\_FGT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_fgt) is not implemented, and [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is not 31 and is greater than or equal to the number of accessible event counters, then reads and writes of [PMXEVTYPER](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-20-PMXEVTYPER--Performance-Monitors-Selected-Event-Type-Register?lang=en#reg_aarch32_pmxevtyper) are CONSTRAINED UNPREDICTABLE, and the following behaviors are permitted:

- Accesses to the register are UNDEFINED.
- Accesses to the register behave as RAZ/WI.
- Accesses to the register execute as a `NOP`
- Accesses to the register behave as if [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL has an UNKNOWN value less than the number of event counters accessible at the current Exception level and Security state.
- Accesses to the register behave as if [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is 31.
- If EL2 is implemented and enabled in the current Security state, and [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is less than the number of implemented event counters, accesses from EL1 or permitted accesses from EL0 are trapped to EL2.

Permitted reads and writes of PMXEVTYPER are RAZ/WI if all of the following are true:

- FEAT\_PMUv3p9 is implemented.
- EL0 is the current Exception level.
- EL1 is using AArch64.
- [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).UEN is 1.
- Any of the following are true:
  - [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is not ‘31’ and [PMUACR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-24-PMUACR-EL1--Performance-Monitors-User-Access-Control-Register?lang=en#reg_aarch64_pmuacr_el1).P<UInt([PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL)> is 0.
  - [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is ‘31’ and [PMUACR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-24-PMUACR-EL1--Performance-Monitors-User-Access-Control-Register?lang=en#reg_aarch64_pmuacr_el1).C is 0.

Permitted writes of PMXEVTYPER are ignored if all of the following are true:

- FEAT\_PMUv3p9 is implemented.
- EL0 is the current Exception level.
- EL1 is using AArch64.
- [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).UEN is 1.
- Any of the following are true:
  - [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is not 31 and [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).ER is 1.
  - [PMSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-16-PMSELR--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch32_pmselr).SEL is 31 and [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).CR is 1.

> #### Note
>
> In EL0, an access is permitted if it is enabled by [PMUSERENR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-18-PMUSERENR--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch32_pmuserenr).EN or [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).{UEN,EN}.
>
> If EL2 is implemented and enabled in the current Security state, at EL0 and EL1:
>
> - If EL2 is using AArch32, [HDCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-32-HDCR--Hyp-Debug-Control-Register?lang=en#reg_aarch32_hdcr).HPMN identifies the number of accessible event counters.
> - If EL2 is using AArch64, [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN identifies the number of accessible event counters.
>
> Otherwise, the number of accessible event counters is determined by the Effective value of PMCCR.EPMN. For more information, see [HDCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-32-HDCR--Hyp-Debug-Control-Register?lang=en#reg_aarch32_hdcr).HPMN, [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN and PMCCR.EPMN.
