# ​G5.14.3 Address translation

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-14-Pseudocode-description-of-VMSAv8-32-memory-system-operations/-G5-14-3-Address-translation>

##### G5.14.3 Address translation

[`AArch32_TranslateAddress`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-212-AArch32-TranslateAddress?lang=en#asl_func_aarch32_translateaddress_4)`()` acts as the entry point to VMSAv8-32 and performs the required address translation based on the provided parameters and System register configurations. The function returns an [`AddressDescriptor`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-801-AddressDescriptor?lang=en#asl_type_addressdescriptor) structure holding valid data for either of the following:

- Target memory address and attributes for a non-faulting translation.
- Fault details holding data to be populated in syndrome registers.

[`AArch32_FullTranslate`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-204-AArch32-FullTranslate?lang=en#asl_func_aarch32_fulltranslate_3)`()` selects the translation regime and performs first and potentially second stage of translation returning the physical address (PA) and attributes of target memory. [`AArch32_S1TranslateLD`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-208-AArch32-S1TranslateLD?lang=en#asl_func_aarch32_s1translateld_5)`()` carries out the first stage of translation when stage 1 is not disabled and Long-descriptor format is used, mapping the virtual address (VA) to the intermediate physical address (IPA) and carrying out permission checks. Alternatively [`AArch32_S1TranslateSD`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-209-AArch32-S1TranslateSD?lang=en#asl_func_aarch32_s1translatesd_5)`()` carries out the first stage of translation using the Short-descriptor format along with Domain checks and TEX memory attribute mapping. Otherwise, [`AArch32_S1DisabledOutput`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-206-AArch32-S1DisabledOutput?lang=en#asl_func_aarch32_s1disabledoutput_5)`()` assigns the appropriate memory attributes and flat maps the input address to the output address. [`AArch32_S2Translate`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-210-AArch32-S2Translate?lang=en#asl_func_aarch32_s2translate_4)`()` carries out stage 2 translation for Regime\_EL10 when enabled, mapping the IPA to the PA. Otherwise, the IPA is the PA.
