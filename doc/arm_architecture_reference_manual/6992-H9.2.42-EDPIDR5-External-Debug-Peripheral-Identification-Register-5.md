##### H9.2.42 EDPIDR5, External Debug Peripheral Identification Register 5

The EDPIDR5 characteristics are:

Purpose
:   Provides information to identify an external debug component.

    For more information, see [‘About the Peripheral identification scheme’](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance/-K5-4-4-About-the-Peripheral-identification-scheme?lang=en#babdfhah).

Configuration
:   When FEAT\_DoPD is implemented, EDPIDR5 is in the Core power domain. Otherwise, EDPIDR5 is in the Debug power domain

    This register is present only when FEAT\_ED\_PIDR is implemented. Otherwise, direct accesses to EDPIDR5 are RES0.

Attributes
:   EDPIDR5 is a 32-bit register.

###### Field descriptions

![](images/6992-H9.2.42-EDPIDR5-External-Debug-Peripheral-Identification-Register-5-img01.svg)

Bits [31:0]
:   Reserved, RES0.
