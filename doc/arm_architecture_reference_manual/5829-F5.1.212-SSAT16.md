##### F5.1.212 SSAT16

Signed Saturate 16 saturates two signed 16-bit values to a selected signed range.

This instruction sets [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).Q to 1 if the operation saturates.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-212-SSAT16?lang=en#isa_ssat16_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-212-SSAT16?lang=en#isa_ssat16_iclass_t1)).

###### Encoding

```
SSAT16{<c>}{<q>}  <Rd>, #<imm>, <Rn>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let saturate_to : integer{} = UInt(sat_imm)+1;
if d == 15 || n == 15 then UnpredictableProcedure(); end;
```

<Rd>
:   ​

    Is the general-purpose destination register, encoded in the “Rd” field.

<imm>
:   ​

    Is the bit position for saturation, in the range 1 to 16, encoded in the “sat\_imm” field as <imm>-1.

<Rn>
:   ​

    Is the general-purpose source register, encoded in the “Rn” field.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let (result1, sat1) : (bits(saturate_to), boolean) = SignedSatQ{saturate_to}(SInt(R(n)[15:0]));
    let (result2, sat2) : (bits(saturate_to), boolean) = SignedSatQ{saturate_to}(SInt(R(n)[31:16]));
    R(d)[15:0] = SignExtend{16}(result1);
    R(d)[31:16] = SignExtend{16}(result2);
    if sat1 || sat2 then
        PSTATE.Q = ‘1’;
    end;
end;
```
