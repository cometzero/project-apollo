##### D18.2.9 Timestamp packet

Purpose
:   The 64-bit timestamp value when the operation was sampled. The Timestamp packet must come at the end of the record. If the Timestamp packet is not present, an [End packet](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D18-Statistical-Profiling-Extension-Sample-Record-Specification/-D18-2-Alphabetical-list-of-Statistical-Profiling-Extension-packets/-D18-2-5-End-packet?lang=en#packet_spe_end_packet) must come at the end of the record.

Attributes
:   Multi-part packet comprising:

    - 8-bit header.
    - 64-bit payload.

###### Timestamp packet payload

Figure D18-39 Timestamp packet payload

![Timestamp packet payload](images/4783-D18.2.9-Timestamp-packet-img02.svg)

TS, bytes <7:0>
:   Timestamp value when the operation was sampled. The value depends on the result of [`CollectTimeStamp`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-54-CollectTimeStamp?lang=en#asl_func_collecttimestamp_0)`()`:

    - If `TimeStamp_Virtual`, the value of [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()` - [CNTVOFF\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-27-CNTVOFF-EL2--Counter-timer-Virtual-Offset-Register?lang=en#reg_aarch64_cntvoff_el2).
    - If `TimeStamp_Physical`, the value of [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()`.
    - If `TimeStamp_OffsetPhysical`, the value of [`PhysicalCountInt`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-631-PhysicalCountInt?lang=en#asl_func_physicalcountint_0)`()` - [CNTPOFF\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-18-CNTPOFF-EL2--Counter-timer-Physical-Offset-Register?lang=en#reg_aarch64_cntpoff_el2). Only supported when [FEAT\_ECV](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_ecv) is implemented.

    If [`CollectTimeStamp`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-54-CollectTimeStamp?lang=en#asl_func_collecttimestamp_0)`()` returns `TimeStamp_None`, then the Timestamp packet is not included and an [End packet](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D18-Statistical-Profiling-Extension-Sample-Record-Specification/-D18-2-Alphabetical-list-of-Statistical-Profiling-Extension-packets/-D18-2-5-End-packet?lang=en#packet_spe_end_packet) must come at the end of the record.

    However, if the Generic Timer System counter is disabled and [`CollectTimeStamp`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-54-CollectTimeStamp?lang=en#asl_func_collecttimestamp_0)`()` returns a value other than `TimeStamp_None`, then it is IMPLEMENTATION DEFINED which of the following occurs:

    - The Statistical Profiling Unit behaves as if [`CollectTimeStamp`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-54-CollectTimeStamp?lang=en#asl_func_collecttimestamp_0)`()` returns the value `TimeStamp_None`.
    - The value of this field in the record is UNKNOWN.

    > #### Note
    >
    > This set of behaviors is only permitted when the actual System counter is disabled, that is, when CNTEN.EN is `0b0`. It does not apply when the System counter is enabled but not accessible at the current Exception level.
