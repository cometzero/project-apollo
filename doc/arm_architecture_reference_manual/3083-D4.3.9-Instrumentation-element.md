# ​D4.3.9 Instrumentation element

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D4-The-Embedded-Trace-Extension/-D4-3-Trace-elements/-D4-3-9-Instrumentation-element>

##### D4.3.9 Instrumentation element

I ZLFFN
:   The *Instrumentation element* indicates execution of a [`TRCIT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) instruction.

R BXTXK
:   If Instrumentation tracing is prohibited, then no trace is generated by the [`TRCIT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) instruction, and [`TRCIT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) behaves as a `NOP`.

R JJZXW
:   If tracing is prohibited, then no ETE trace is generated by the [`TRCIT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) instruction, and [`TRCIT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) behaves as a `NOP`.

    `TraceAllowed()` defines when tracing is prohibited.

R BWHCS
:   If Instrumentation tracing is not prohibited and tracing is enabled and not prohibited, then execution of the [`TRCIT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) instruction requests an Instrumentation element to be generated in the ETE trace stream.

    `TraceInstrumentationAllowed()` defines when Instrumentation tracing is not prohibited.

R NHJLQ
:   When an Instrumentation element is requested, the Instrumentation element is generated if and only if the [`TRCIT`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) instruction is architecturally executed.

R VPFGH
:   If the Instrumentation element cannot be generated when required, then a trace unit buffer overflow occurs.

R CJRNL
:   Instrumentation elements are not discarded by Cancel elements.
