# ​G8.3.2 DBGBCR<n>, Debug Breakpoint Control Registers, n = 0 - 15

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-2-DBGBCR-n---Debug-Breakpoint-Control-Registers--n---0---15>

##### G8.3.2 DBGBCR<n>, Debug Breakpoint Control Registers, n = 0 - 15

The DBGBCR<n> characteristics are:

Purpose
:   Holds control information for a breakpoint. Forms breakpoint n together with value register [DBGBVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-3-DBGBVR-n---Debug-Breakpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgbvrn). If EL2 is implemented and this breakpoint supports Context matching, [DBGBVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-3-DBGBVR-n---Debug-Breakpoint-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgbvrn) can be associated with a Breakpoint Extended Value Register [DBGBXVR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-4-DBGBXVR-n---Debug-Breakpoint-Extended-Value-Registers--n---0---15?lang=en#reg_aarch32_dbgbxvrn) for VMID matching.

Configuration
:   If breakpoint n is not implemented then accesses to this register are UNDEFINED.

    AArch32 System register DBGBCR<n> bits [31:0] are architecturally mapped to AArch64 System register [DBGBCR<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-2-DBGBCR-n--EL1--Debug-Breakpoint-Control-Registers--n---0---63?lang=en#reg_aarch64_dbgbcrn_el1)[31:0].

    AArch32 System register DBGBCR<n> bits [31:0] are architecturally mapped to External register [DBGBCR<n>\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-2-DBGBCR-n--EL1--Debug-Breakpoint-Control-Registers--n---0---63?lang=en#reg_ext_dbgbcrn_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to DBGBCR<n> are UNDEFINED.

Attributes
:   DBGBCR<n> is a 32-bit register.

![](images/6667-G8.3.2-DBGBCR-n-Debug-Breakpoint-Control-Registers-n-0-15-img01.svg)

When the E field is zero, all the other fields in the register are ignored.

Bits [31:24]
:   Reserved, RES0.

BT, bits [23:20]
:   Breakpoint Type. Possible values are:
