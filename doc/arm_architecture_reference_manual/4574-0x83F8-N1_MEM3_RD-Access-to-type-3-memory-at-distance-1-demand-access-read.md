# ​0x83F8, N1_MEM3_RD, Access to type 3 memory at distance 1, demand access, read

##### `0x83F8`, N1\_MEM3\_RD, Access to type 3 memory at distance 1, demand access, read

The counter counts each demand read counted by [N1\_MEM\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E0--N1-MEM-RD--Access-to-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem_rd) to a third memory type at distance 1.

The definition of memory types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system. See also [N1\_MEM3\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83F8--N1-MEM3-RD--Access-to-type-3-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem3_rd).

For example, the third memory type might be high-bandwidth memory connected to a device. However, this must be the same for all devices in the system, such that, for example, [N1\_MEM3\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83F8--N1-MEM3-RD--Access-to-type-3-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem3_rd) refers to high-bandwidth memory for a PE at distance 1 from the memory, regardless of which device the PE is located on, and [N4\_MEM3\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83FB--N4-MEM3-RD--Access-to-type-3-memory-at-distance-4--demand-access--read?lang=en#event_n4_mem3_rd) refers to the same memory for any PE located at distance 4. This means that when a process counting the [N1\_MEM3\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83F8--N1-MEM3-RD--Access-to-type-3-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem3_rd) event migrates between PEs on different devices, its relative view of the third memory type remains unchanged, even if the distance changes.
