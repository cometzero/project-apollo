# ​D24.9.19 VSESR_EL3, Virtual SError Exception Syndrome Register (EL3)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-19-VSESR-EL3--Virtual-SError-Exception-Syndrome-Register--EL3->

##### D24.9.19 VSESR\_EL3, Virtual SError Exception Syndrome Register (EL3)

The VSESR\_EL3 characteristics are:

Purpose
:   Provides the syndrome value reported to software when the Effective value of [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is 1 on taking a delegated SError exception to EL2 or EL1, or on executing an `ESB` instruction at EL2 or EL1.

    When the delegated SError exception injected using [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is taken to EL2 using AArch64, then the syndrome value is reported in [ESR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-45-ESR-EL2--Exception-Syndrome-Register--EL2-?lang=en#reg_aarch64_esr_el2).

    When the delegated SError exception injected using [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is taken to EL1 using AArch64, then the syndrome value is reported in [ESR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-44-ESR-EL1--Exception-Syndrome-Register--EL1-?lang=en#reg_aarch64_esr_el1).

    When the delegated SError exception injected using [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is deferred by an `ESB` instruction, then the syndrome value is written to [VDISR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-17-VDISR-EL3--Virtual-Deferred-Interrupt-Status-Register--EL3-?lang=en#reg_aarch64_vdisr_el3).

Configuration
:   This register is present only when FEAT\_E3DSE is implemented. Otherwise, direct accesses to VSESR\_EL3 are UNDEFINED.

Attributes
:   VSESR\_EL3 is a 64-bit register.

###### Field descriptions

![](images/5343-D24.9.19-VSESR_EL3-Virtual-SError-Exception-Syndrome-Register-EL3-img01.svg)

Bits [63:25]
:   Reserved, RES0.

IDS, bit [24]
:   When a delegated SError exception triggered by [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is taken to EL2 or EL1 using AArch64, [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx)[24] is set to VSESR\_EL3.IDS.

    When a delegated SError exception triggered by [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is deferred by an `ESB` instruction, [VDISR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-17-VDISR-EL3--Virtual-Deferred-Interrupt-Status-Register--EL3-?lang=en#reg_aarch64_vdisr_el3)[24] is set to VSESR\_EL3.IDS.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

ISS, bits [23:0]
:   When a delegated SError exception triggered by [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is taken to EL2 or EL1 using AArch64, [ESR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#esr_elx)[23:0] is set to VSESR\_EL3.ISS.

    When a delegated SError exception triggered by [SCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-168-SCR-EL3--Secure-Configuration-Register?lang=en#reg_aarch64_scr_el3).DSE is deferred by an `ESB` instruction, [VDISR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-17-VDISR-EL3--Virtual-Deferred-Interrupt-Status-Register--EL3-?lang=en#reg_aarch64_vdisr_el3)[23:0] is set to VSESR\_EL3.ISS.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
