##### `0x821C`, L1D\_CACHE\_HITM\_RW, Level 1 data cache demand access hit modified

The counter counts each cache access counted by [L1D\_CACHE\_HIT\_RW](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81CC--L1D-CACHE-HIT-RW--Level-1-data-cache-demand-access-hit?lang=en#event_l1d_cache_hit_rw) that accesses a previously modified cache location.
