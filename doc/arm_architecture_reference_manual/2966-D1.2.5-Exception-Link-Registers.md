# ​D1.2.5 Exception Link Registers

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-2-Registers-for-instruction-processing-and-exception-handling/-D1-2-5-Exception-Link-Registers>

##### D1.2.5 Exception Link Registers

R JQBYN
:   Exception Link Registers hold preferred exception return addresses.

R VCLNF
:   In AArch64 state, each implemented Exception level to which an exception can be taken has an Exception Link Register (ELR). The following are the ELRs:

    - For exceptions taken to EL1, [ELR\_EL1](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-5-ELR-EL1--Exception-Link-Register--EL1-?lang=en#reg_aarch64_elr_el1).
    - For exceptions taken to EL2, [ELR\_EL2](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-6-ELR-EL2--Exception-Link-Register--EL2-?lang=en#reg_aarch64_elr_el2).
    - For exceptions taken to EL3, [ELR\_EL3](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-7-ELR-EL3--Exception-Link-Register--EL3-?lang=en#reg_aarch64_elr_el3).

I SHJSC
:   When a Warm reset is asserted, the ELRs are reset to an architecturally UNKNOWN value.

    For more information, see [Preferred exception return address](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-4-Exceptions/-D1-4-1-Exception-entry-terminology?lang=en#mdsec_preferred_exception_return_address).
