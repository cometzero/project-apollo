# ​D24.5.27 PMXEVTYPER_EL0, Performance Monitors Selected Event Type Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-27-PMXEVTYPER-EL0--Performance-Monitors-Selected-Event-Type-Register>

##### D24.5.27 PMXEVTYPER\_EL0, Performance Monitors Selected Event Type Register

The PMXEVTYPER\_EL0 characteristics are:

Purpose
:   When [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL selects an event counter, this accesses a [PMEVTYPER<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-12-PMEVTYPER-n--EL0--Performance-Monitors-Event-Type-Registers--n---0---30?lang=en#reg_aarch64_pmevtypern_el0) register. When [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL selects the cycle counter, this accesses [PMCCFILTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-1-PMCCFILTR-EL0--Performance-Monitors-Cycle-Count-Filter-Register?lang=en#reg_aarch64_pmccfiltr_el0).

Configuration
:   AArch64 System register PMXEVTYPER\_EL0 bits [31:0] are architecturally mapped to AArch32 System register [PMXEVTYPER](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-20-PMXEVTYPER--Performance-Monitors-Selected-Event-Type-Register?lang=en#reg_aarch32_pmxevtyper)[31:0].

    This register is present only when FEAT\_PMUv3 is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to PMXEVTYPER\_EL0 are UNDEFINED.

Attributes
:   PMXEVTYPER\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5253-D24.5.27-PMXEVTYPER_EL0-Performance-Monitors-Selected-Event-Type-Register-img01.svg)

EVTYPERn, bits [63:0]
:   When [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL == 31, this register accesses [PMCCFILTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-1-PMCCFILTR-EL0--Performance-Monitors-Cycle-Count-Filter-Register?lang=en#reg_aarch64_pmccfiltr_el0).

    Otherwise, this register accesses [PMEVTYPER<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-12-PMEVTYPER-n--EL0--Performance-Monitors-Event-Type-Registers--n---0---30?lang=en#reg_aarch64_pmevtypern_el0) where n is the value in [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing PMXEVTYPER\_EL0

If [FEAT\_FGT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_fgt) is implemented, and [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is not 31 and is greater than or equal to the number of accessible event counters, then the behavior of permitted reads and writes of [PMXEVTYPER\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-27-PMXEVTYPER-EL0--Performance-Monitors-Selected-Event-Type-Register?lang=en#reg_aarch64_pmxevtyper_el0) is as follows:

- If [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is greater than or equal to the Effective value of [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPMN, the access is UNDEFINED.
- Otherwise, the access is trapped to EL2.

If [FEAT\_FGT](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-7-The-Armv8-6-architecture-extension?lang=en#feat_feat_fgt) is not implemented, and [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is not 31 and is greater than or equal to the number of accessible event counters, then reads and writes of PMXEVTYPER\_EL0 are CONSTRAINED UNPREDICTABLE, and the following behaviors are permitted:

- Accesses to the register are UNDEFINED.
- Accesses to the register behave as RAZ/WI.
- Accesses to the register execute as a `NOP`.
- Accesses to the register behave as if [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL has an UNKNOWN value less than the number of event counters accessible at the current Exception level and Security state.
- Accesses to the register behave as if [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is 31.
- If EL2 is implemented and enabled in the current Security state, [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0) is less than the number of implemented event counters, accesses from EL1 or permitted accesses from EL0 are trapped to EL2.

Permitted reads and writes of PMXEVTYPER\_EL0 are RAZ/WI if all of the following are true:

- FEAT\_PMUv3p9 is implemented.
- EL0 is the current Exception level.
- [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).UEN is 1.
- Any of the following are true:
  - [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is not 31 and [PMUACR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-24-PMUACR-EL1--Performance-Monitors-User-Access-Control-Register?lang=en#reg_aarch64_pmuacr_el1).P<UInt([PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL)> is 0.
  - [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is 31 and [PMUACR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-24-PMUACR-EL1--Performance-Monitors-User-Access-Control-Register?lang=en#reg_aarch64_pmuacr_el1).C is 0.

Permitted writes of PMXEVTYPER\_EL0 are ignored if all of the following are true:

- FEAT\_PMUv3p9 is implemented.
- EL0 is the current Exception level.
- [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).UEN is 1.
- Any of the following are true:
  - [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is not 31 and [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).ER is 1.
  - [PMSELR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-21-PMSELR-EL0--Performance-Monitors-Event-Counter-Selection-Register?lang=en#reg_aarch64_pmselr_el0).SEL is 31 and [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).CR is 1.

> #### Note
>
> In EL0, an access is permitted if it is enabled by [PMUSERENR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-25-PMUSERENR-EL0--Performance-Monitors-User-Enable-Register?lang=en#reg_aarch64_pmuserenr_el0).{UEN,EN}.
>
> If EL2 is implemented and enabled in the current Security state, in EL1 and EL0, [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN identifies the number of accessible event counters.
>
> Otherwise, the number of accessible event counters is determined by the Effective value of [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPMN. For more information, see [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN and [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPMN.
