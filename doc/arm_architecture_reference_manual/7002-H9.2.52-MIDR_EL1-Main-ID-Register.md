Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-52-MIDR-EL1--Main-ID-Register>

##### H9.2.52 MIDR\_EL1, Main ID Register

The MIDR\_EL1 characteristics are:

Purpose
:   Provides identification information for the PE, including an implementer code for the device and a device ID number.

Configuration
:   The power domain of MIDR\_EL1 is IMPLEMENTATION DEFINED

    External register MIDR\_EL1 bits [31:0] are architecturally mapped to AArch64 System register [MIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-136-MIDR-EL1--Main-ID-Register?lang=en#reg_aarch64_midr_el1)[31:0].

    External register MIDR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [MIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-113-MIDR--Main-ID-Register?lang=en#reg_aarch32_midr)[31:0].

Attributes
:   MIDR\_EL1 is a 32-bit register.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

PartNum, bits [15:4]
:   Primary Part Number for the device.

    On processors implemented by Arm, if the top four bits of the primary part number are `0x0` or `0x7`, the variant and architecture are encoded differently.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

Revision, bits [3:0]
:   Revision number for the device.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.
