##### `0x8157`, LL\_CACHE\_HWPRF, Last level cache hardware prefetch

The counter counts each access counted by [LL\_CACHE\_PRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8287--LL-CACHE-PRF--Last-level-cache--prefetch-hit?lang=en#event_ll_cache_prf) that is due to a hardware prefetch.

The hardware prefetch is generated by a hardware prefetcher at the Last level cache.
