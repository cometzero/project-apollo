##### K10.4.2 Example data sharing use of the STSHH and PRFM IR instructions

[Example K10-2](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K10-Software-Usage-Examples/-K10-4-Use-of-the-FEAT-PCDPHINT-STSHH-and-PRFM-IR-hint-instructions/-K10-4-2-Example-data-sharing-use-of-the-STSHH-and-PRFM-IR-instructions?lang=en#ex_data_sharing_between_threads_example) shows a common pattern for data sharing between two threads:

> Example K10-2 Example of data sharing between two threads
>
> ```
> P0:             P1:
> STR <payload>   SEVL
> STLR <flag>     LOOP:
>                 WFE
>                 LDAXR <flag>
>                 CMP <flag>, <expected value>    ; Test to see if flag has been updated.
>                 B.NE LOOP                       ; Branch back to WFE and wait if flag not updated.
>                 LDR <payload>
>                 CLREX
> ```

With [`STSHH`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-424-STSHH?lang=en#isa_stshh) and [`PRFM IR` (immediate)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-315-PRFM--immediate-?lang=en#isa_prfm_imm), the following can be used instead:

> Example K10-3 Example usage of STSHH and PRFM IR in data sharing between threads
>
> ```
> P0:             P1:
> STSHH STRM      SEVL
> STR <payload>   LOOP:
> STSHH STRM      WFE
> STLR <flag>     LDAXR <flag>
>                 CMP <flag>, <expected value>    ; test to see if flag has been updated.
>                 B.EQ READY                      ; branch over the PRFM if the flag has been set.
>                 PRFM IR <payload>
>                 B.NE LOOP                       ; branch back to WFE and wait if flag not updated.
>                 READY:
>                 LDR <payload>
>                 CLREX
> ```

In [Example K10-3](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K10-Software-Usage-Examples/-K10-4-Use-of-the-FEAT-PCDPHINT-STSHH-and-PRFM-IR-hint-instructions/-K10-4-2-Example-data-sharing-use-of-the-STSHH-and-PRFM-IR-instructions?lang=en#ex_stshh_and_prfm_irimmediate_in_data_sharing_example_2), [`STSHH`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-424-STSHH?lang=en#isa_stshh) uses the STRM policy because the producing thread does not read from the locations, and there must be a consumption by another thread before the producing thread updates the locations again.
