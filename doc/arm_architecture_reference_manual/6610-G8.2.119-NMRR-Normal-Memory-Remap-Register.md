# ​G8.2.119 NMRR, Normal Memory Remap Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-119-NMRR--Normal-Memory-Remap-Register>

##### G8.2.119 NMRR, Normal Memory Remap Register

The NMRR characteristics are:

Purpose
:   Provides additional mapping controls for memory regions that are mapped as Normal memory by their entry in the [PRRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-122-PRRR--Primary-Region-Remap-Register?lang=en#reg_aarch32_prrr).

    Used in conjunction with the [PRRR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-122-PRRR--Primary-Region-Remap-Register?lang=en#reg_aarch32_prrr).

Configuration
:   [MAIR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-112-MAIR1--Memory-Attribute-Indirection-Register-1?lang=en#reg_aarch32_mair1) and NMRR are the same register, with a different view depending on the value of [TTBCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-165-TTBCR--Translation-Table-Base-Control-Register?lang=en#reg_aarch32_ttbcr).EAE:

    - When it is set to 0, the register is as described in NMRR.
    - When it is set to 1, the register is as described in [MAIR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-112-MAIR1--Memory-Attribute-Indirection-Register-1?lang=en#reg_aarch32_mair1).

    When EL3 is not implemented or EL3 is using AArch64, AArch32 System register NMRR bits [31:0] are architecturally mapped to AArch64 System register [MAIR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-126-MAIR-EL1--Memory-Attribute-Indirection-Register--EL1-?lang=en#reg_aarch64_mair_el1)[63:32].

    When EL3 is not implemented or EL3 is using AArch64, AArch32 System register NMRR bits [31:0] are architecturally mapped to AArch32 System register [MAIR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-112-MAIR1--Memory-Attribute-Indirection-Register-1?lang=en#reg_aarch32_mair1)[31:0].

    When EL3 is using AArch32, AArch32 System register NMRR bits [31:0] are architecturally mapped to AArch32 System register [MAIR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-112-MAIR1--Memory-Attribute-Indirection-Register-1?lang=en#reg_aarch32_mair1)[31:0].

    When EL3 is using AArch32, AArch32 System register NMRR bits [31:0] are architecturally mapped to AArch32 System register [MAIR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-112-MAIR1--Memory-Attribute-Indirection-Register-1?lang=en#reg_aarch32_mair1)[31:0].

    This register is banked between NMRR and NMRR\_S and NMRR\_NS.

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to NMRR are UNDEFINED.

Attributes
:   NMRR is a 32-bit register.

    This register has the following instances:

    - NMRR, when EL3 is not implemented or FEAT\_AA64 is implemented.
    - NMRR\_S, when FEAT\_AA32EL3 is implemented.
    - NMRR\_NS, when FEAT\_AA32EL3 is implemented.
