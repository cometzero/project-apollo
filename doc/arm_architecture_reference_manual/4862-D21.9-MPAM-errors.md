# ​D21.9 MPAM errors

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-9-MPAM-errors>

#### D21.9 MPAM errors

R DHSBM
:   An MPAM error is detected when a memory read, memory write, instruction fetch, or translation table walk results in one of:

    - The [PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-?lang=en#mpam_partition_identifiers) is *out-of-range*. Either:

      - The PARTID is a physical PARTID and it exceeds [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).PARTID\_MAX.
      - The PARTID is *treated as virtual* and it exceeds (4 x [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).VPMR\_MAX) + 3.
    - The PARTID is treated as virtual and the corresponding [MPAMVPMV\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-23-MPAMVPMV-EL2--MPAM-Virtual-Partition-Mapping-Valid-Register?lang=en#reg_aarch64_mpamvpmv_el2).VPM\_V<m> valid flag indicates that a valid mapping does not exist.
    - The PMG is out-of-range. The PMG exceeds [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).PMG\_MAX.

I DWCRN
:   In some implementations, some MPAM errors might never occur. For example, an implementation with only w bits of PARTID and [MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).PARTID\_MAX as (2w - 1), and that truncates PARTID values with nonzero bits higher than w - 1, can never have a physical PARTID out-of-range error.

    See also:

    - [PARTID virtualization](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-/-D21-3-1-PARTID-virtualization?lang=en#mpam_partid_virtualization), for the definitions of *out-of-range* and *treated as virtual*.
