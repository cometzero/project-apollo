##### `0x81CA`, L3D\_CACHE\_HIT\_WR, Level 3 data cache demand access hit, write

The counter counts each demand write counted by [L3D\_CACHE\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x00A1--L3D-CACHE-WR--Level-3-data-cache-access--write?lang=en#event_l3d_cache_wr) that hits in the Level 3 data or unified cache.
