# ​C5.1.1 Principles of the System instruction class encoding

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-1-The-System-instruction-class-encoding-space/-C5-1-1-Principles-of-the-System-instruction-class-encoding>

##### C5.1.1 Principles of the System instruction class encoding

An encoding in the System instruction space is identified by a set of arguments,{`op0`, `op1`, `CRn`, `CRm`, `op2`}. These form an encoding hierarchy, where:

`op0`
:   Defines the top-level division of the encoding space, see [System instruction class encoding overview](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-1-The-System-instruction-class-encoding-space/-C5-1-2-System-instruction-class-encoding-overview?lang=en#beijieie).

`op1`
:   Except for encodings allocated to [`HINTE`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-173-HINTE?lang=en#isa_hinte) if [FEAT\_HINTE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-7-The-Armv9-6-architecture-extension?lang=en#feat_feat_hinte) is implemented, `op1` identifies the lowest Exception level at which the encoding is accessible, as follows:

    Accessible at EL0
    :   `op1` has the value `0b011`.

    Accessible at EL1
    :   `op1` has the value `0b000`, `0b001`, or `0b010`. The value is the same as the `op1` value used to access the equivalent AArch32 register.

    Accessible at Secure EL1
    :   `op1` has the value `0b111`.

    Accessible at EL2
    :   `op1` has the value `0b100` or `0b101`. The value `0b101` is used for the EL12 encodings that access EL1 System registers used when [FEAT\_VHE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-2-The-Armv8-1-architecture-extension?lang=en#feat_feat_vhe) is implemented and the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1.

    Accessible at EL3
    :   `op1` has the value `0b110`.

Arm strongly recommends that implementers adopt this use of `op1` when using the IMPLEMENTATION DEFINED regions of the encoding space described in [Reserved encodings for IMPLEMENTATION DEFINED registers](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D23-AArch64-System-Register-Encoding/-D23-3-Moves-to-and-from-non-debug-System-registers--Special-purpose-registers/-D23-3-2-Reserved-encodings-for-IMPLEMENTATION-DEFINED-registers?lang=en#beicjbih).
