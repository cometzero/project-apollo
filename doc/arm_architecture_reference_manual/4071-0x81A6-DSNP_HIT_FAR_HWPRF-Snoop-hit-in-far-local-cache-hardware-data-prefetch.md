##### `0x81A6`, DSNP\_HIT\_FAR\_HWPRF, Snoop hit in far local cache, hardware data prefetch

The counter counts each snoop generated by a data hardware prefetch counted by [DSNP\_HIT\_HWPRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81A4--DSNP-HIT-HWPRF--Snoop-hit--hardware-data-prefetch?lang=en#event_dsnp_hit_hwprf) that hits in a cache outside the local PE cluster on the same device.

The event is counted by the PE generating the snoop, not the PE being snooped.
