##### `0x8284`, L1D\_CACHE\_PRF, Level 1 data cache, prefetch hit

The counter counts each access counted by [L1D\_CACHE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0004--L1D-CACHE--Level-1-data-cache-access?lang=en#event_l1d_cache) that is due to a prefetch instruction, or hardware prefetch.
