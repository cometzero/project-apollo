# ​D24.5.15 PMICNTSVR_EL1, Performance Monitors Instruction Count Saved Value Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-15-PMICNTSVR-EL1--Performance-Monitors-Instruction-Count-Saved-Value-Register>

##### D24.5.15 PMICNTSVR\_EL1, Performance Monitors Instruction Count Saved Value Register

The PMICNTSVR\_EL1 characteristics are:

Purpose
:   Captures the PMU Instruction counter, [PMICNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-14-PMICNTR-EL0--Performance-Monitors-Instruction-Counter-Register?lang=en#reg_aarch64_pmicntr_el0).

Configuration
:   AArch64 System register PMICNTSVR\_EL1 bits [63:0] are architecturally mapped to External register [PMICNTSVR\_EL1](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-35-PMICNTSVR-EL1--Performance-Monitors-Instruction-Count-Saved-Value-Register?lang=en#reg_pmu_pmicntsvr_el1)[63:0].

    This register is present only when FEAT\_PMUv3\_ICNTR is implemented, FEAT\_PMUv3\_SS is implemented, and FEAT\_AA64 is implemented. Otherwise, direct accesses to PMICNTSVR\_EL1 are UNDEFINED.

Attributes
:   PMICNTSVR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5241-D24.5.15-PMICNTSVR_EL1-Performance-Monitors-Instruction-Count-Saved-Value-Register-img01.svg)

ICNT, bits [63:0]
:   Sampled Instruction Count. The value of [PMICNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-14-PMICNTR-EL0--Performance-Monitors-Instruction-Counter-Register?lang=en#reg_aarch64_pmicntr_el0) at the last successful Capture event.

    The reset behavior of this field is:

    - On a Cold reset:
      - When FEAT\_PMUv3\_EXTPMN is implemented, this field resets to an architecturally UNKNOWN value.
    - On a Warm reset:
      - When FEAT\_PMUv3\_EXTPMN is not implemented, this field resets to an architecturally UNKNOWN value.
