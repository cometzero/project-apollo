##### J1.4.97 ExtRegZeroCycleCounter

```
// ExtRegZeroCycleCounter()
// ========================
// Called on an external PMU write to PMCR_EL0 that writes ‘1’ to PMCR_EL0.C.
func ExtRegZeroCycleCounter(addrdesc : AddressDescriptor)
begin
    var mask : bits(64) = Zeros{};
    mask[CYCLE_COUNTER_ID] = ‘1’;
    ExtRegZeroPMUCounters(mask, addrdesc);
end;
```
