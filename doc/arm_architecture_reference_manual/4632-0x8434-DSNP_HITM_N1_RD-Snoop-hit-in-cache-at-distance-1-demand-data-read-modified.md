##### `0x8434`, DSNP\_HITM\_N1\_RD, Snoop hit in cache at distance 1, demand data read, modified

The counter counts each snoop generated by the PE in response to a demand [Memory-read operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#caceiega) counted by [DSNP\_HIT\_N1\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8404--DSNP-HIT-N1-RD--Snoop-hit-in-cache-at-distance-1--demand-data-read?lang=en#event_dsnp_hit_n1_rd) that accesses a previously modified cache location.
