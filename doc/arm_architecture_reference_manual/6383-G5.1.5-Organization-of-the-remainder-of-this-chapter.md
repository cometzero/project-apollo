> #### Note
>
> The System registers in the (`coproc` == `0b1110`) encoding space provide the following functionality:
>
> - Self-hosted debug. These registers are described in [Debug System registers](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers?lang=en#aarch32_debug_system_registers).
> - The System register interface to a trace unit. These registers are not described in this manual.
> - Jazelle registers. These registers are summarized in [Legacy feature registers and system instructions](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-5-Functional-index-of-AArch32-registers-and-System-instructions/-K14-5-13-Legacy-feature-registers-and-system-instructions?lang=en#register_functional_index_aarch32_legacy).
>
> Therefore, there is no summary of these registers by functional groups.
