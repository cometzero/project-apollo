# ​C8.2.533 PTRUE (predicate as counter)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-533-PTRUE--predicate-as-counter->

##### C8.2.533 PTRUE (predicate as counter)

Initialize predicate-as-counter to all active

This instruction sets the destination predicate as all Active elements, using the predicate-as-counter encoding.

###### SVE2

###### (FEAT\_SME2 || FEAT\_SVE2p1)

![](images/2196-C8.2.533-PTRUE-predicate-as-counter-img01.svg)

###### Encoding

```
PTRUE  <PNd>.<T>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_SME2) && !IsFeatureImplemented(FEAT_SVE2p1) then
    EndOfDecode(Decode_UNDEF);
end;
let esize : integer{} = 8 << UInt(size);
let d : integer = UInt(‘1’::PNd);
```

###### Operation

```
if IsFeatureImplemented(FEAT_SVE2p1) then CheckSVEEnabled(); else CheckStreamingSVEEnabled(); end;
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let elements : integer = VL DIV esize;
let result : bits(PL) = EncodePredCount{}(esize, elements, elements, FALSE);
P{PL}(d) = result;
```
