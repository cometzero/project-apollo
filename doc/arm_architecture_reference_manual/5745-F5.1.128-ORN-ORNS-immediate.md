# ​F5.1.128 ORN, ORNS (immediate)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-128-ORN--ORNS--immediate->

##### F5.1.128 ORN, ORNS (immediate)

Bitwise OR NOT (immediate) performs a bitwise (inclusive) OR of a register value and the complement of an immediate value, and writes the result to the destination register. It can optionally update the condition flags based on the result.

![](images/5745-F5.1.128-ORN-ORNS-immediate-img01.svg)

###### Encoding for the Flag setting variant

Applies when `(S == 1)`

```
ORNS{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Encoding for the Not flag setting variant

Applies when `(S == 0)`

```
ORN{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Decode for all variants of this encoding

```
if Rn == ‘1111’ then See(“MVN (immediate)”); end;
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let setflags : boolean = (S == ‘1’);
let a32 : boolean = FALSE;
let imm : bits(12) = i::imm3::imm8;
// Armv8-A removes UNPREDICTABLE for R13
if d == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let (imm32, carry) : (bits(32), bit) = (if a32 then A32ExpandImm_C(imm, PSTATE.C)
                                                   else T32ExpandImm_C(imm, PSTATE.C));
    let result : bits(32) = R(n) OR NOT(imm32);
    R(d) = result;
    if setflags then
        PSTATE.N = result[31];
        PSTATE.Z = IsZeroBit{32}(result);
        PSTATE.C = carry;
        // PSTATE.V unchanged
    end;
end;
```
