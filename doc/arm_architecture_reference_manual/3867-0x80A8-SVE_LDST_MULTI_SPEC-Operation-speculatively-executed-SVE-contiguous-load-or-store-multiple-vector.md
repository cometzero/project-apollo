##### `0x80A8`, SVE\_LDST\_MULTI\_SPEC, Operation speculatively executed, SVE contiguous load or store multiple vector

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) operation that reads from or writes to memory due to an SVE multiple vector contiguous structure load or store instruction.
