# ​D20.3 Generating error exceptions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-3-Generating-error-exceptions>

#### D20.3 Generating error exceptions

R VJRKF
:   An Error exception is generated when a detected error is [signaled](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-7-Reliability--Availability--and-Serviceability/-A1-7-3-General-taxonomy-of-errors?lang=en#mdterm_ras_signal) to the PE as an [in-band error response](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-2-PE-error-handling/-D20-2-1-PE-error-detection?lang=en#mdterm_pe_in_band_error_response) to an architecturally-executed memory access or cache maintenance operation. This includes any explicit data access, instruction fetch, translation table walk, or hardware update to the translation tables made by an architecturally-executed instruction.

I PJHZS
:   An [Error exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-3-Generating-error-exceptions?lang=en#mdterm_error_exception) is taken as an asynchronous SError exception, a synchronous External Data Abort exception, or a synchronous External Instruction Abort exception.

R MBNBH
:   It is IMPLEMENTATION DEFINED whether an [Error exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-3-Generating-error-exceptions?lang=en#mdterm_error_exception) can be generated for an error that is consumed by hardware speculation or prefetching by a PE, but that is not committed to the architecturally visible state of the PE.

R SHKJB
:   It is IMPLEMENTATION DEFINED whether an [Error exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-3-Generating-error-exceptions?lang=en#mdterm_error_exception) can be generated for a detected error that is [deferred](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#glossdef_deferred_error).

R GVWJD
:   It is IMPLEMENTATION DEFINED whether an [Error exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-3-Generating-error-exceptions?lang=en#mdterm_error_exception) can be generated for a detected error that is [corrected](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#glossdef_corrected_error).

R FNVVJ
:   An [Error exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-3-Generating-error-exceptions?lang=en#mdterm_error_exception) can also be generated for IMPLEMENTATION DEFINED causes. An [Error exception](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-3-Generating-error-exceptions?lang=en#mdterm_error_exception) generated for an IMPLEMENTATION DEFINED cause is taken as an SError exception.

    > Example D20-11
    >
    > An error is detected and neither [corrected](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#glossdef_corrected_error) nor [deferred](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#glossdef_deferred_error) to the PE, and [signaled](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-7-Reliability--Availability--and-Serviceability/-A1-7-3-General-taxonomy-of-errors?lang=en#mdterm_ras_signal) to the PE by means other than an [in-band error response](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-2-PE-error-handling/-D20-2-1-PE-error-detection?lang=en#mdterm_pe_in_band_error_response), such as a wired SError exception pin. Asserting the SError exception pin causes the PE to generate an SError exception.

    > Example D20-12
    >
    > An error is detected by the PE in the [PE state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D20-RAS-PE-Architecture/-D20-2-PE-error-handling/-D20-2-2-PE-error-propagation?lang=en#mdterm_pe_state), or in the result of a calculation performed by the PE. The detected error generates an SError exception.
