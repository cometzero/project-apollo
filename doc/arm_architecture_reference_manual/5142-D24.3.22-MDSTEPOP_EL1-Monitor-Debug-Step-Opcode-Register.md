# ​D24.3.22 MDSTEPOP_EL1, Monitor Debug Step Opcode Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-22-MDSTEPOP-EL1--Monitor-Debug-Step-Opcode-Register>

##### D24.3.22 MDSTEPOP\_EL1, Monitor Debug Step Opcode Register

The MDSTEPOP\_EL1 characteristics are:

Purpose
:   Used to execute instructions while Software Step is in active-not-pending state.

Configuration
:   This register is present only when FEAT\_STEP2 is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to MDSTEPOP\_EL1 are UNDEFINED.

Attributes
:   MDSTEPOP\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5142-D24.3.22-MDSTEPOP_EL1-Monitor-Debug-Step-Opcode-Register-img01.svg)

Bits [63:32]
:   Reserved, RES0.

OPCODE, bits [31:0]
:   A64 instruction to be executed on the PE.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
