##### D13.5.1 Enabling PMU counters

I CFQVP
:   Counters are enabled by a combination of the *global enable control* for the counter and a counter enable control, [PMCNTENSET](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#cihcafde), as described in the following sections.

###### D13.5.1.1 Enabling the event counters

R KYBQW
:   The global enable controls for PMU event counters are defined as follows:

    - The [global enable control](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-5-Controlling-the-PMU-counters/-D13-5-1-Enabling-PMU-counters?lang=en#global_enable_control) for PMU event counters in the [third range](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-1-About-the-Performance-Monitors/-D13-1-1-Event-counter-ranges?lang=en#third_range_pmu) is [PMCCR](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-6-PMCCR--PMU-Configuration-Control-Register?lang=en#reg_pmu_pmccr).EPME.
    - The [global enable control](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-5-Controlling-the-PMU-counters/-D13-5-1-Enabling-PMU-counters?lang=en#global_enable_control) for PMU event counters in the [second range](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-1-About-the-Performance-Monitors/-D13-1-1-Event-counter-ranges?lang=en#second_range_pmu) is [HDCR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#cegfcbjc).HPME.
    - The [global enable control](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-5-Controlling-the-PMU-counters/-D13-5-1-Enabling-PMU-counters?lang=en#global_enable_control) for PMU event counters in the [first range](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-1-About-the-Performance-Monitors/-D13-1-1-Event-counter-ranges?lang=en#first_range_pmu) is [PMCR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#cihdfegb).E.
