##### `0x8444`, ASE\_FP\_FP8\_MIN\_SPEC, Advanced SIMD data processing operation speculatively executed, smallest type is 8-bit floating-point

The counter counts each Advanced SIMD data-processing operation counted by [ASE\_SVE\_FP\_FP8\_MIN\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x844C--ASE-SVE-FP-FP8-MIN-SPEC--Advanced-SIMD-data-processing-or-SVE-data-processing-operation-speculatively-executed--smallest-type-is-8-bit-floating-point?lang=en#event_ase_sve_fp_fp8_min_spec) due to an instruction where the smallest type was 8-bit floating-point.
