# ​J1.1 Standard library

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-1-Standard-library>

#### J1.1 Standard library

The pseudocode in this manual is written in the Architecture Specification Language (ASL). The ASL makes use of a standard library.

Implementations of the standard library functions can be found within the [herdtools7 github repository](https://github.com/herd/herdtools7/blob/master/asllib/libdir/stdlib.asl).

The standard library implements the following functions:

- `Abs(x: integer) => integer`
- `Abs(x: real) => real`
- `AlignDown{N}(x: bits(N), y: integer{1..N}) => bits(N)`
- `AlignDownP2(x: integer, p2: integer) => integer`
- `AlignDownP2{N}(x: bits(N), p2: integer{0..N}) => bits(N)`
- `AlignDownSize(x: integer, size: integer) => integer`
- `AlignDownSize{N}(x: bits(N), size: integer{1..2^N}) => bits(N)`
- `AlignUp{N}(x: bits(N), y: integer{1..N}) => bits(N)`
- `AlignUpP2(x: integer, p2: integer) => integer`
- `AlignUpP2{N}(x: bits(N), p2: integer{0..N}) => bits(N)`
- `AlignUpSize(x: integer, size: integer) => integer`
- `AlignUpSize{N}(x: bits(N), size: integer{1..2^N}) => bits(N)`
- `ASR_C{N}(x: bits(N), shift: integer) => (bits(N), bit)`
- `ASR{N}(x: bits(N), shift: integer) => bits(N)`
- `BitCount{N}(x: bits(N)) => integer{0..N}`
- `CeilLog2(a: integer) => integer`
- `CeilPow2(x : integer) => integer`
- `CountLeadingSignBits{N}(x: bits(N)) => integer{0..N-1}`
- `CountLeadingZeroBits{N}(x: bits(N)) => integer{0..N}`
- `Extend{N,M}(x: bits(M), unsigned: boolean) => bits(N)`
- `FloorLog2(a: integer) => integer`
- `FloorPow2(x : integer) => integer`
- `HighestSetBit{N}(x: bits(N)) => integer{-1..N-1}`
- `HighestSetBitNZ{N}(x: bits(N)) => integer{0..N-1}`
- `ILog2(value : real) => integer`
- `IsAlignedP2(x: integer, p2: integer) => boolean`
- `IsAlignedP2{N}(x: bits(N), p2: integer{0..N}) => boolean`
- `IsAlignedSize(x: integer, size: integer) => boolean`
- `IsAlignedSize{N}(x: bits(N), size: integer{1..2^N}) => boolean`
- `IsEven(a: integer) => boolean`
- `IsOdd(a: integer) => boolean`
- `IsOnes{N}(x: bits(N)) => boolean`
- `IsPow2(x : integer) => boolean`
- `IsZero{N}(x: bits(N)) => boolean`
- `Len{N}(x: bits(N)) => integer{N}`
- `LowestSetBit{N}(x: bits(N)) => integer{0..N}`
- `LowestSetBitNZ{N}(x: bits(N)) => integer{0..N-1}`
- `LSL_C{N}(x: bits(N), shift: integer) => (bits(N), bit)`
- `LSL{N}(x: bits(N), shift: integer) => bits(N)`
- `LSR_C{N}(x: bits(N), shift: integer) => (bits(N), bit)`
- `LSR{N}(x: bits(N), shift: integer) => bits(N)`
- `Max(a: integer, b: integer) => integer`
- `Max(a: real, b: real) => real`
- `Min(a: integer, b: integer) => integer`
- `Min(a: real, b: real) => real`
- `Ones{N}() => bits(N)`
- `Real(x: integer) => real`
- `Replicate{N,M}(x: bits(M)) => bits(N)`
- `ReplicateBit{N}(isZero: boolean) => bits(N)`
- `ROL_C{N}(x: bits(N), shift: integer) => (bits(N), bit)`
- `ROL{N}(x: bits(N), shift: integer) => bits(N)`
- `ROR_C{N}(x: bits(N), shift: integer) => (bits(N), bit)`
- `ROR{N}(x: bits(N), shift: integer) => bits(N)`
- `RoundDown(x: real) => integer`
- `RoundTowardsZero(x: real) => integer`
- `RoundUp(x: real) => integer`
- `SignExtend{N,M}(x: bits(M)) => bits(N)`
- `SInt{N} (x: bits(N))`
- `SqrtRounded(value : real, fracbits : integer) => real`
- `UInt{N} (x: bits(N)) => integer{0..2^N-1}`
- `ZeroExtend{N,M}(x: bits(M)) => bits(N)`
- `Zeros{N}() => bits(N)`
