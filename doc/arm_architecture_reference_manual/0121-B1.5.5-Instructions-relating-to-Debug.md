##### B1.5.5 Instructions relating to Debug

[Exception handling](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-5-Software-control-features-and-EL0/-B1-5-1-Exception-handling?lang=en#beidifii) refers to the `BRK` instruction, which generates a Breakpoint Instruction exception. In addition, in AArch64 state and AArch32 state, the `HLT` instruction causes the PE to halt execution and enter Debug state. This provides a mechanism for debugging software using a debugger that is external to the PE, see [About External Debug](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H1-About-External-Debug?lang=en#chdhghgi).

> #### Note
>
> In AArch32 state, previous versions of the architecture defined the `DBG` instruction, which could provide a hint to the debug system. This instruction executes as a `NOP`. Arm deprecates the use of the `DBG` instruction.
