# ​G8.2.18 ATS1CUW, Address Translate Stage 1 Current state Unprivileged Write

##### G8.2.18 ATS1CUW, Address Translate Stage 1 Current state Unprivileged Write

The ATS1CUW characteristics are:

Purpose
:   Performs stage 1 address translation as defined for PL0 and the current Security state, with permissions as if writing to the given virtual address.

Configuration
:   This system instruction is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ATS1CUW are UNDEFINED.

Attributes
:   ATS1CUW is a 32-bit System instruction.

###### Field descriptions

![](images/6509-G8.2.18-ATS1CUW-Address-Translate-Stage-1-Current-state-Unprivileged-Write-img01.svg)

IA, bits [31:0]
:   Input address for translation. The resulting address can be read from the [PAR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-121-PAR--Physical-Address-Register?lang=en#reg_aarch32_par).

    This System instruction takes a VA as input. If EL2 is implemented and enabled in the current Security state, the resulting address is the IPA that is the output address of the stage 1 translation. Otherwise, the resulting address is a PA.
