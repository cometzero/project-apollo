##### C6.2.280 MOV (wide immediate)

Move wide immediate value

This instruction moves a 16-bit immediate value to a register.

This is an alias of [MOVZ](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-285-MOVZ?lang=en#isa_movz). This means:

- The encodings in this description are named to match the encodings of [MOVZ](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-285-MOVZ?lang=en#isa_movz).
- The description of [MOVZ](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-285-MOVZ?lang=en#isa_movz) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the 32-bit variant

Applies when `(sf == 0 && hw == 0x)`

```
MOV  <Wd>, #<imm>
```

is equivalent to

```
MOVZ  <Wd>, #<imm16>, LSL  #<shift>
```

and is the preferred disassembly when `!(IsZero(imm16) && hw != '00')`.

###### Encoding for the 64-bit variant

Applies when `(sf == 1)`

```
MOV  <Xd>, #<imm>
```

is equivalent to

```
MOVZ  <Xd>, #<imm16>, LSL  #<shift>
```

and is the preferred disassembly when `!(IsZero(imm16) && hw != '00')`.

###### Assembler Symbols

<Wd>
:   ​

    Is the 32-bit name of the general-purpose destination register, encoded in the “Rd” field.

<imm>
:   ​

    For the “32-bit” variant: is a 32-bit immediate which can be encoded in “imm16:hw”.

    ​

    For the “64-bit” variant: is a 64-bit immediate which can be encoded in “imm16:hw”.

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.
