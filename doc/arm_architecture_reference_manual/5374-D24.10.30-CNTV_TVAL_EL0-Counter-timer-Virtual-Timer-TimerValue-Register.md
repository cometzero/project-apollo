# ​D24.10.30 CNTV_TVAL_EL0, Counter-timer Virtual Timer TimerValue Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-30-CNTV-TVAL-EL0--Counter-timer-Virtual-Timer-TimerValue-Register>

##### D24.10.30 CNTV\_TVAL\_EL0, Counter-timer Virtual Timer TimerValue Register

The CNTV\_TVAL\_EL0 characteristics are:

Purpose
:   Holds the timer value for the EL1 virtual timer.

Configuration
:   AArch64 System register CNTV\_TVAL\_EL0 bits [31:0] are architecturally mapped to AArch32 System register [CNTV\_TVAL](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-23-CNTV-TVAL--Counter-timer-Virtual-Timer-TimerValue-register?lang=en#reg_aarch32_cntv_tval)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTV\_TVAL\_EL0 are UNDEFINED.

Attributes
:   CNTV\_TVAL\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5374-D24.10.30-CNTV_TVAL_EL0-Counter-timer-Virtual-Timer-TimerValue-Register-img01.svg)

Bits [63:32]
:   Reserved, RES0.

TimerValue, bits [31:0]
:   The TimerValue view of the EL1 virtual timer.

    On a read of this register:

    - If [CNTV\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-28-CNTV-CTL-EL0--Counter-timer-Virtual-Timer-Control-Register?lang=en#reg_aarch64_cntv_ctl_el0).ENABLE is 0, the value returned is UNKNOWN.
    - If [CNTV\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-28-CNTV-CTL-EL0--Counter-timer-Virtual-Timer-Control-Register?lang=en#reg_aarch64_cntv_ctl_el0).ENABLE is 1, the value returned is ([CNTV\_CVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-29-CNTV-CVAL-EL0--Counter-timer-Virtual-Timer-CompareValue-Register?lang=en#reg_aarch64_cntv_cval_el0) - [CNTVCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register?lang=en#reg_aarch64_cntvct_el0)).

    On a write of this register, [CNTV\_CVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-29-CNTV-CVAL-EL0--Counter-timer-Virtual-Timer-CompareValue-Register?lang=en#reg_aarch64_cntv_cval_el0) is set to ([CNTVCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register?lang=en#reg_aarch64_cntvct_el0) + TimerValue), where TimerValue is treated as a signed 32-bit integer.

    When [CNTV\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-28-CNTV-CTL-EL0--Counter-timer-Virtual-Timer-Control-Register?lang=en#reg_aarch64_cntv_ctl_el0).ENABLE is 1, the timer condition is met when ([CNTVCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register?lang=en#reg_aarch64_cntvct_el0) - [CNTV\_CVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-29-CNTV-CVAL-EL0--Counter-timer-Virtual-Timer-CompareValue-Register?lang=en#reg_aarch64_cntv_cval_el0)) is greater than or equal to zero. This means that TimerValue acts like a 32-bit downcounter timer. When the timer condition is met:

    - [CNTV\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-28-CNTV-CTL-EL0--Counter-timer-Virtual-Timer-Control-Register?lang=en#reg_aarch64_cntv_ctl_el0).ISTATUS is set to 1.
    - If [CNTV\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-28-CNTV-CTL-EL0--Counter-timer-Virtual-Timer-Control-Register?lang=en#reg_aarch64_cntv_ctl_el0).IMASK is 0, an interrupt is generated.

    When [CNTV\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-28-CNTV-CTL-EL0--Counter-timer-Virtual-Timer-Control-Register?lang=en#reg_aarch64_cntv_ctl_el0).ENABLE is 0, the TimerValue cannot be read but continues to decrement. When the timer is enabled, the TimerValue represents the elapsed time whether that time was spent enabled or disabled.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing CNTV\_TVAL\_EL0
