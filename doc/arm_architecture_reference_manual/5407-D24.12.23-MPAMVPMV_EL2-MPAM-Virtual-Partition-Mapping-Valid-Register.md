# ​D24.12.23 MPAMVPMV_EL2, MPAM Virtual Partition Mapping Valid Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-23-MPAMVPMV-EL2--MPAM-Virtual-Partition-Mapping-Valid-Register>

##### D24.12.23 MPAMVPMV\_EL2, MPAM Virtual Partition Mapping Valid Register

The MPAMVPMV\_EL2 characteristics are:

Purpose
:   Valid bits for virtual PARTID mapping entries. Each bit m corresponds to virtual PARTID mapping entry m in the MPAMVPM<n>\_EL2 registers where n = m >> 2.

Configuration
:   This register has no effect if EL2 is not enabled in the current Security state.

    This register is present only when ((IsFeatureImplemented(FEAT\_MPAMv0p1) || IsFeatureImplemented(FEAT\_MPAMv1p0)) && IsFeatureImplemented(FEAT\_AA64EL2)) && ([MPAMIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-13-MPAMIDR-EL1--MPAM-ID-Register--EL1-?lang=en#reg_aarch64_mpamidr_el1).HAS\_HCR == ‘1’). Otherwise, direct accesses to MPAMVPMV\_EL2 are UNDEFINED.

Attributes
:   MPAMVPMV\_EL2 is a 64-bit register.

###### Field descriptions

![](images/5407-D24.12.23-MPAMVPMV_EL2-MPAM-Virtual-Partition-Mapping-Valid-Register-img01.svg)

Bits [63:32]
:   Reserved, RES0.

VPM\_V<m> , bits [m], for m = 31 to 0
:   Contains valid bit for virtual PARTID mapping entry corresponding to virtual PARTID<m>.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    When m >= ((UInt(MPAMIDR\_EL1.VPMR\_MAX) + 1) \* 4), access to this field is RES0.

    end;
