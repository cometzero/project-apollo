# ​D7.7.1 EL2 control of the maintenance scope of Data Synchronization Barrier instructions executed at EL0 or EL1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D7-The-AArch64-System-Level-Memory-Model/-D7-7-Memory-barrier-instructions/-D7-7-1-EL2-control-of-the-maintenance-scope-of-Data-Synchronization-Barrier-instructions-executed-at-EL0-or-EL1>

##### D7.7.1 EL2 control of the maintenance scope of Data Synchronization Barrier instructions executed at EL0 or EL1

In an implementation that includes EL2 enabled in the current Security state and that supports maintenance scope on [`DSB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb) instructions, the [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).BSU field can modify the required maintenance scope of an instruction that is executed at EL0 or EL1. [Table D7-9](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D7-The-AArch64-System-Level-Memory-Model/-D7-7-Memory-barrier-instructions/-D7-7-1-EL2-control-of-the-maintenance-scope-of-Data-Synchronization-Barrier-instructions-executed-at-EL0-or-EL1?lang=en#tbl_beibdbgh) shows the encoding of this field.
