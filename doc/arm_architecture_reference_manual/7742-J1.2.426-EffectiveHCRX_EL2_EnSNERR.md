# ​J1.2.426 EffectiveHCRX_EL2_EnSNERR

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-426-EffectiveHCRX-EL2-EnSNERR>

##### J1.2.426 EffectiveHCRX\_EL2\_EnSNERR

```
// EffectiveHCRX_EL2_EnSNERR()
// ===========================
// Return the Effective value of HCRX_EL2().EnSNERR
func EffectiveHCRX_EL2_EnSNERR() => bit
begin
    if !IsHCRXEL2Enabled() then return ‘0’; end;
    if ELIsInHost(EL0) then return ‘0’; end;
    if (IsFeatureImplemented(FEAT_ADERR) && GetADERRErrorMode() == ErrSignalMode_TiedToPeer &&
          HCRX_EL2().[EnSDERR, EnSNERR] == ‘01’) then
        return ‘0’;
    end;
    return HCRX_EL2().EnSNERR;
end;
```
