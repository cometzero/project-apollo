# ​G8.2.96 ID_MMFR3, Memory Model Feature Register 3

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-96-ID-MMFR3--Memory-Model-Feature-Register-3>

##### G8.2.96 ID\_MMFR3, Memory Model Feature Register 3

The ID\_MMFR3 characteristics are:

Purpose
:   Provides information about the implemented memory model and memory management support in AArch32 state.

    For general information about the interpretation of the ID registers see [‘Principles of the ID scheme for fields in ID registers’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-1-About-the-AArch32-System-registers/-G8-1-3-Principles-of-the-ID-scheme-for-fields-in-ID-registers?lang=en#chdidagf).

Configuration
:   AArch32 System register ID\_MMFR3 bits [31:0] are architecturally mapped to AArch64 System register [ID\_MMFR3\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-110-ID-MMFR3-EL1--AArch32-Memory-Model-Feature-Register-3?lang=en#reg_aarch64_id_mmfr3_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ID\_MMFR3 are UNDEFINED.

Attributes
:   ID\_MMFR3 is a 32-bit register.
