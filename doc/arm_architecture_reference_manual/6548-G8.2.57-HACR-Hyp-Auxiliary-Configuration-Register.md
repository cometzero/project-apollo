# ​G8.2.57 HACR, Hyp Auxiliary Configuration Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-57-HACR--Hyp-Auxiliary-Configuration-Register>

##### G8.2.57 HACR, Hyp Auxiliary Configuration Register

The HACR characteristics are:

Purpose
:   Controls trapping to Hyp mode of IMPLEMENTATION DEFINED aspects of Non-secure EL1 or EL0 operation.

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    AArch32 System register HACR bits [31:0] are architecturally mapped to AArch64 System register [HACR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-59-HACR-EL2--Hypervisor-Auxiliary-Control-Register?lang=en#reg_aarch64_hacr_el2)[31:0].

    This register is present only when FEAT\_AA32EL2 is implemented. Otherwise, direct accesses to HACR are UNDEFINED.

Attributes
:   HACR is a 32-bit register.

###### Field descriptions

![](images/6548-G8.2.57-HACR-Hyp-Auxiliary-Configuration-Register-img01.svg)

IMPLEMENTATION DEFINED, bits [31:0]
:   IMPLEMENTATION DEFINED.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    Undefined();
elsif PSTATE.EL == EL0 then
    Undefined();
elsif PSTATE.EL == EL1 then
    if EL2Enabled() && IsFeatureImplemented(FEAT_AA64EL2) && !ELUsingAArch32(EL2) && HSTR_EL2().T1 == '1' then
        AArch64_AArch32SystemAccessTrap(EL2, 0x03);
    elsif EL2Enabled() && IsFeatureImplemented(FEAT_AA32EL2) && ELUsingAArch32(EL2) && HSTR().T1 == '1' then
        AArch32_TakeHypTrapException(0x03);
    else
        Undefined();
    end;
elsif PSTATE.EL == EL2 then
    R(t) = HACR();
elsif PSTATE.EL == EL3 then
    if SCR().NS == '0' then
        Undefined();
    else
        R(t) = HACR();
    end;
end;
