##### `0x8081`, SVE\_LD\_SPEC, Operation speculatively executed, SVE load

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) operation that reads from memory counted by [SVE\_LDST\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8080--SVE-LDST-SPEC--Operation-speculatively-executed--SVE-load--store--or-prefetch?lang=en#event_sve_ldst_spec) due to an SVE load instruction.
