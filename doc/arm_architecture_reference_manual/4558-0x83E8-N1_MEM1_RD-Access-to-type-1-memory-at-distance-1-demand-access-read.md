# ​0x83E8, N1_MEM1_RD, Access to type 1 memory at distance 1, demand access, read

##### `0x83E8`, N1\_MEM1\_RD, Access to type 1 memory at distance 1, demand access, read

The counter counts each demand read counted by [N1\_MEM\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E0--N1-MEM-RD--Access-to-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem_rd) to a first memory type at distance 1.

The definition of memory types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system. See also [N1\_MEM1\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E8--N1-MEM1-RD--Access-to-type-1-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem1_rd).

For example, the first memory type might be commodity DRAM connected to a device. However, this must be the same for all devices in the system, such that, for example, [N1\_MEM1\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E8--N1-MEM1-RD--Access-to-type-1-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem1_rd) refers to commodity DRAM for a PE at distance 1 from the memory, regardless of which device the PE is located on, and [N4\_MEM1\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83EB--N4-MEM1-RD--Access-to-type-1-memory-at-distance-4--demand-access--read?lang=en#event_n4_mem1_rd) refers to the same memory for any PE located at distance 4. This means that when a process counting the [N1\_MEM1\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83E8--N1-MEM1-RD--Access-to-type-1-memory-at-distance-1--demand-access--read?lang=en#event_n1_mem1_rd) event migrates between PEs on different devices, its relative view of the first memory type remains unchanged, even if the distance changes.
