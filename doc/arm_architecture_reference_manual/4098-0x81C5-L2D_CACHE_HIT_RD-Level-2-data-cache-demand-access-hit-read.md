##### `0x81C5`, L2D\_CACHE\_HIT\_RD, Level 2 data cache demand access hit, read

The counter counts each demand read counted by [L2D\_CACHE\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0050--L2D-CACHE-RD--Level-2-data-cache-access--read?lang=en#event_l2d_cache_rd) that hits in the Level 2 data or unified cache.
