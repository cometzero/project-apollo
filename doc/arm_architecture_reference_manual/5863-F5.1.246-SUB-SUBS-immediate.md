# ​F5.1.246 SUB, SUBS (immediate)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-246-SUB--SUBS--immediate->

##### F5.1.246 SUB, SUBS (immediate)

Subtract (immediate) subtracts an immediate value from a register value, and writes the result to the destination register.

If the destination register is not the PC, the SUBS variant of the instruction updates the condition flags based on the result.

The field descriptions for `<Rd>` identify the encodings where the PC is permitted as the destination register. If the destination register is the PC:

- The SUB variant of the instruction is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
- The SUBS variant of the instruction performs an exception return without the use of the stack. In this case:
  - The PE branches to the address written to the PC, and restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>.
  - The PE checks SPSR\_<current\_mode> for an illegal return event. See [Illegal return events from AArch32 state](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-3-Illegal-return-events-from-AArch32-state?lang=en#chdddjdb).
  - The instruction is UNDEFINED in Hyp mode, except for encoding T5 with `<imm8>` set to zero, which is the encoding for the `ERET` instruction, see [ERET](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-157-ERET?lang=en#isa_eret).
  - The instruction is CONSTRAINED UNPREDICTABLE in User mode and System mode.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-246-SUB--SUBS--immediate-?lang=en#isa_sub_i_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-246-SUB--SUBS--immediate-?lang=en#isa_sub_i_iclass_t1), [T2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-246-SUB--SUBS--immediate-?lang=en#isa_sub_i_iclass_t2), [T3](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-246-SUB--SUBS--immediate-?lang=en#isa_sub_i_iclass_t3), [T4](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-246-SUB--SUBS--immediate-?lang=en#isa_sub_i_iclass_t4), and [T5](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-246-SUB--SUBS--immediate-?lang=en#isa_sub_i_iclass_t5)).

###### A1

![](images/5863-F5.1.246-SUB-SUBS-immediate-img01.svg)

###### Encoding for the SUB variant

Applies when `(S == 0 && Rn != 11x1)`

```
SUB{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Encoding for the SUBS variant

Applies when `(S == 1 && Rn != 1101)`

```
SUBS{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Decode for all variants of this encoding

```
if Rn == ‘1111’ && S == ‘0’ then See(“ADR”); end;
if Rn == ‘1101’ then See(“SUB (SP minus immediate)”); end;
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let setflags : boolean = (S == ‘1’);
let imm32 : bits(32) = A32ExpandImm(imm12);
```

###### T3

![](images/5863-F5.1.246-SUB-SUBS-immediate-img04.svg)

###### Encoding for the SUB variant

Applies when `(S == 0)`

```
SUB{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

```
SUB<c>.W  {<Rd>, }<Rn>, #<const> // (Inside IT block, and <Rd>, <Rn>, <const> can be represented in T1 or T2)
```

###### Encoding for the SUBS variant

Applies when `(S == 1 && Rd != 1111)`

```
SUBS{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

```
SUBS.W  {<Rd>, }<Rn>, #<const> // (Outside IT block, and <Rd>, <Rn>, <const> can be represented in T1 or T2)
```

###### Decode for all variants of this encoding

```
if Rd == ‘1111’ && S == ‘1’ then See(“CMP (immediate)”); end;
if Rn == ‘1101’ then See(“SUB (SP minus immediate)”); end;
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let setflags : boolean = (S == ‘1’);
let imm32 : bits(32) = T32ExpandImm(i::imm3::imm8);
// Armv8-A removes UNPREDICTABLE for R13
if (d == 15 && !setflags) || n == 15 then UnpredictableProcedure(); end;
```

###### T5

![](images/5863-F5.1.246-SUB-SUBS-immediate-img06.svg)

###### Encoding

Applies when `(!(Rn == 1110 && imm8 == 00000000))`

```
SUBS{<c>}{<q>}  PC, LR, #<imm8>
```

###### Decode for this encoding

```
if Rn == ‘1110’ && IsZero(imm8) then See(“ERET”); end;
let d : integer = 15;
let n : integer = UInt(Rn);
let setflags : boolean = TRUE;
let imm32 : bits(32) = ZeroExtend{}(imm8);
if n != 14 then UnpredictableProcedure(); end;
if InITBlock() && !LastInITBlock() then UnpredictableProcedure(); end;
```

###### Assembler Symbols

<c>
:   ​
    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<q>
:   ​
    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<Rd>
:   ​

    For the “A1 SUB” and “A1 SUBS” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the same as `<Rn>`. If the PC is used:

    - For the SUB variant, the instruction is a branch to the address calculated by the operation. This is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
    - For the SUBS variant, the instruction performs an exception return, that restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>. Arm deprecates use of this instruction unless `<Rn>` is the LR.

    ​

    For the “T1”, “T3 SUB”, “T3 SUBS”, and “T4” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the same as `<Rn>`.

<Rn>
:   ​

    For the “A1 SUB”, “A1 SUBS”, and “T4” variants: is the general-purpose source register, encoded in the “Rn” field. If the SP is used, see [SUB (SP minus immediate)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-249-SUB--SUBS--SP-minus-immediate-?lang=en#isa_sub_sp_i). If the PC is used, see [ADR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-12-ADR?lang=en#isa_adr).

    ​

    For the “T1” variant: is the general-purpose source register, encoded in the “Rn” field.

    ​

    For the “T3 SUB” and “T3 SUBS” variants: is the general-purpose source register, encoded in the “Rn” field. If the SP is used, see [SUB (SP minus immediate)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-249-SUB--SUBS--SP-minus-immediate-?lang=en#isa_sub_sp_i).

<const>
:   ​

    For the “A1 SUB” and “A1 SUBS” variants: an immediate value. See [Modified immediate constants in A32 instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-7-General-information-about-the-T32-and-A32-instruction-descriptions/-F1-7-7-Modified-immediate-constants-in-T32-and-A32-instructions?lang=en#babhdajf) for the range of values.

    ​

    For the “T3 SUB” and “T3 SUBS” variants: an immediate value. See [Modified immediate constants in T32 instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-7-General-information-about-the-T32-and-A32-instruction-descriptions/-F1-7-7-Modified-immediate-constants-in-T32-and-A32-instructions?lang=en#babghaga) for the range of values.

<imm3>
:   ​

    Is a 3-bit unsigned immediate, in the range 0 to 7, encoded in the “imm3” field.

<Rdn>
:   ​

    Is the general-purpose source and destination register, encoded in the “Rdn” field.

<imm8>
:   ​

    For the “T2” variant: is a 8-bit unsigned immediate, in the range 0 to 255, encoded in the “imm8” field.

    ​

    For the “T5” variant: is a 8-bit unsigned immediate, in the range 0 to 255, encoded in the “imm8” field. If `<Rn>` is the LR, and zero is used, see [ERET](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-157-ERET?lang=en#isa_eret).

<imm12>
:   ​

    Is a 12-bit unsigned immediate, in the range 0 to 4095, encoded in the “i:imm3:imm8” field.

    In the T32 instruction set, `MOVS{<c>}{<q>} PC, LR` is a pseudo-instruction for `SUBS{<c>}{<q>} PC, LR, #0`.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let (result, nzcv) : (bits(32), bits(4)) = AddWithCarry{32}(R(n), NOT(imm32), ‘1’);
    if d == 15 then
        if setflags then
            ALUExceptionReturn(result);
        else
            ALUWritePC(result);
        end;
    else
        R(d) = result;
        if setflags then
            PSTATE.[N,Z,C,V] = nzcv;
        end;
    end;
end;
```
