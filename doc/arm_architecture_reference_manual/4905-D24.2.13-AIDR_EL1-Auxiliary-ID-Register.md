# ​D24.2.13 AIDR_EL1, Auxiliary ID Register

##### D24.2.13 AIDR\_EL1, Auxiliary ID Register

The AIDR\_EL1 characteristics are:

Purpose
:   Provides IMPLEMENTATION DEFINED identification information.

    The value of this register must be interpreted in conjunction with the value of [MIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-136-MIDR-EL1--Main-ID-Register?lang=en#reg_aarch64_midr_el1).

Configuration
:   AArch64 System register AIDR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [AIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-4-AIDR--Auxiliary-ID-Register?lang=en#reg_aarch32_aidr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to AIDR\_EL1 are UNDEFINED.

Attributes
:   AIDR\_EL1 is a 64-bit register.
