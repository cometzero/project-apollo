##### `0x81AE`, ISNP\_HIT\_FAR\_HWPRF, Snoop hit in far local cache, hardware instruction prefetch

The counter counts each snoop generated by an instruction hardware prefetch counted by [ISNP\_HIT\_HWPRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81AC--ISNP-HIT-HWPRF--Snoop-hit--hardware-instruction-prefetch?lang=en#event_isnp_hit_hwprf) that hits in a cache outside the local PE cluster on the same device.

The event is counted by the PE generating the snoop, not the PE being snooped.
