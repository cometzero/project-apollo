# ​K1.1.28 CONSTRAINED UNPREDICTABLE behavior for T32 and A32 instruction encodings

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors/-K1-1-AArch32-CONSTRAINED-UNPREDICTABLE-behaviors/-K1-1-28-CONSTRAINED-UNPREDICTABLE-behavior-for-T32-and-A32-instruction-encodings>

##### K1.1.28 CONSTRAINED UNPREDICTABLE behavior for T32 and A32 instruction encodings

The T32 and A32 instruction sets include encodings that result in CONSTRAINED UNPREDICTABLE behavior when they are decoded.

###### K1.1.28.1 CONSTRAINED UNPREDICTABLE behavior of CRC32 instruction encodings

In the T32 and A32 instruction sets, there are encodings of the [CRC32](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-135-CRC32B--CRC32H--CRC32W--CRC32X?lang=en#isa_crc32) and [CRC32C](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-136-CRC32CB--CRC32CH--CRC32CW--CRC32CX?lang=en#isa_crc32c) instructions that result in CONSTRAINED UNPREDICTABLE behavior. These encodings are listed in the following places in the T32 and A32 instruction sets:

- [Cyclic Redundancy Check](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F4-A32-Instruction-Set-Encoding/-F4-1-A32-instruction-set-encoding/-F4-1-4-Miscellaneous?lang=en#a32_encoding_index_crc32) for the A32 instruction set, with `sz = 11`.
- [Data-processing (two source registers)](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F3-T32-Instruction-Set-Encoding/-F3-1-T32-instruction-set-encoding/-F3-1-20-Data-processing--register-?lang=en#t32_encoding_index_dpint_2r) for the T32 instruction set, with `op1 = 10x` and `op2 = 11`.

The CONSTRAINED UNPREDICTABLE behavior for these encodings is described in [CRC32](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-135-CRC32B--CRC32H--CRC32W--CRC32X?lang=en#isa_crc32) and [CRC32C](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-136-CRC32CB--CRC32CH--CRC32CW--CRC32CX?lang=en#isa_crc32c).

###### K1.1.28.2 CONSTRAINED UNPREDICTABLE behavior of other A32 instruction encodings

In the A32 instruction set, there are encodings that result in CONSTRAINED UNPREDICTABLE behavior. These encodings are listed in:

- [Miscellaneous](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F4-A32-Instruction-Set-Encoding/-F4-1-A32-instruction-set-encoding/-F4-1-19-Miscellaneous?lang=en#a32_encoding_index_uncondmisc).
- [Memory hints and barriers](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F4-A32-Instruction-Set-Encoding/-F4-1-A32-instruction-set-encoding/-F4-1-23-Memory-hints-and-barriers?lang=en#a32_encoding_index_uncondhints).
- [Barriers](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F4-A32-Instruction-Set-Encoding/-F4-1-A32-instruction-set-encoding/-F4-1-23-Memory-hints-and-barriers?lang=en#a32_encoding_index_barriers).

The CONSTRAINED UNPREDICTABLE behavior is that an implementation must treat the encodings in one of the following ways:

- The instruction encoding is UNDEFINED.
- The instruction encoding executes as a NOP.
