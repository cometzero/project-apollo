##### C8.2.243 FMOV (zero, predicated)

Move floating-point +0.0 to vector elements (predicated)

This instruction moves floating-point constant +0.0 to each Active element in the destination vector. Inactive elements in the destination vector register remain unmodified.

This is a pseudo-instruction of [CPY (immediate, merging)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-120-CPY--immediate--merging-?lang=en#isa_cpy_z_p_i). This means:

- The encodings in this description are named to match the encodings of [CPY (immediate, merging)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-120-CPY--immediate--merging-?lang=en#isa_cpy_z_p_i).
- The assembler syntax is used only for assembly, and is not used on disassembly.
- The description of [CPY (immediate, merging)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-120-CPY--immediate--merging-?lang=en#isa_cpy_z_p_i) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
FMOV  <Zd>.<T>, <Pg>/M, #0.0
```

is equivalent to

```
CPY  <Zd>.<T>, <Pg>/M, #0
```
