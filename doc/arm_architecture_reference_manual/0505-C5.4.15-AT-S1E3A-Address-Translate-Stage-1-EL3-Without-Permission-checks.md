##### C5.4.15 AT S1E3A, Address Translate Stage 1 EL3 Without Permission checks

The AT S1E3A characteristics are:

Purpose
:   Performs stage 1 address translation as defined for EL3, while ignoring permissions checks from the given virtual address.

Configuration
:   This system instruction is present only when FEAT\_ATS1A is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to AT S1E3A are UNDEFINED.

Attributes
:   AT S1E3A is a 64-bit System instruction.

###### Field descriptions

![](images/0505-C5.4.15-AT-S1E3A-Address-Translate-Stage-1-EL3-Without-Permission-checks-img01.svg)

IA, bits [63:0]
:   Input address for translation. The resulting address can be read from the [PAR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-141-PAR-EL1--Physical-Address-Register?lang=en#reg_aarch64_par_el1).

###### Executing AT S1E3A

This system instruction is an alias of the SYS instruction.
