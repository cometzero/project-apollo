##### `0x81A2`, DSNP\_HIT\_FAR\_PRFM, Snoop hit in far local cache, software data prefetch

The counter counts each snoop generated by the PE in response to a data prefetch instruction counted by [DSNP\_HIT\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x81A0--DSNP-HIT-PRFM--Snoop-hit--software-data-prefetch?lang=en#event_dsnp_hit_prfm) that hits in a cache outside the local PE cluster on the same device.

The event is counted by the PE generating the snoop, not the PE being snooped.
