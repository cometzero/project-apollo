# Part H, External Debug

Source: <https://developer.arm.com/documentation/ddi0487/mc/Preface/Using-this-Manual/Part-H--External-Debug>

##### Part H, External Debug

Part H describes the architecture for external debug. It contains the following chapters:

[About External Debug](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H1-About-External-Debug?lang=en#chdhghgi)
:   Read this for an introduction to external debug, and a definition of the scope of this part of the Manual.

[Debug State](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State?lang=en#babgfbeg)
:   Read this for a description of Debug state, which the PE might enter as the result of a Halting debug event.

[Halting Debug Events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events?lang=en#babcahie)
:   Read this for a description of the external debug events referred to as Halting debug events.

[The Debug Communication Channel and Instruction Transfer Register](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H4-The-Debug-Communication-Channel-and-Instruction-Transfer-Register?lang=en#babhhaae)
:   Read this for a description of the communication between a debugger and the PE debug logic using the Debug Communications Channel and the Instruction Transfer register.

[The Embedded Cross-Trigger Interface](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H5-The-Embedded-Cross-Trigger-Interface?lang=en#babbhgia)
:   Read this for a description of the Embedded Cross-Trigger Interface.

[Debug Reset and Powerdown Support](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H6-Debug-Reset-and-Powerdown-Support?lang=en#cihddafb)
:   Read this for a description of reset and powerdown support in the Debug architecture.

[The PC Sample-based Profiling Extension](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H7-The-PC-Sample-based-Profiling-Extension?lang=en#babdfdeb)
:   Read this for a description of the PC Sample-based Profiling Extension that is an OPTIONAL extension to an Armv8 or Armv9 implementation.

[About the External Debug Registers](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers?lang=en#cihcaddh)
:   Read this for some additional information about the external debug registers.

[External Debug Register Descriptions](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions?lang=en#autogen_registers_debug)
:   Read this for a description of each external debug register.
