##### H9.3.37 TRCIDR4, Trace ID Register 4

The TRCIDR4 characteristics are:

Purpose
:   Returns the tracing capabilities of the trace unit.

Configuration
:   External register TRCIDR4 bits [31:0] are architecturally mapped to AArch64 System register [TRCIDR4](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-39-TRCIDR4--Trace-ID-Register-4?lang=en#reg_aarch64_trcidr4)[31:0].

    This register is present only when FEAT\_ETE is implemented and FEAT\_TRC\_EXT is implemented. Otherwise, direct accesses to TRCIDR4 are RES0.

Attributes
:   TRCIDR4 is a 32-bit register.
