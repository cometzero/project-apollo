##### D5.3.38 Instrumentation Packet

Purpose
:   Indicates an Instrumentation element.

Configurations
:   When [FEAT\_ITE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_ite) is implemented.

###### Field descriptions

EL
:   Exception level at which the corresponding [TRCIT](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-482-TRCIT?lang=en#isa_trcit_sys) instruction was executed.

    The encoding for this field is POD.
