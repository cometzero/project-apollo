# ​B1.2.3 Pseudocode description of registers in AArch64 state

##### B1.2.3 Pseudocode description of registers in AArch64 state

The AArch64 pseudocode uses getter and setter accessor functions to read and write register files that are visible at EL0:

- The setter or assignment accessor, for example “`X{width}(num) = result`”, is used for register writes.
- The getter or non-assignment accessor, “`operand = X{width}(num)`”, is used for register reads.
- The *num* parameter specifies the register number to be accessed within the named register file, and *width* specifies the bit width of the register access.
- For the general-purpose register [`X`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-453-X?lang=en#asl_accessor_x_3)`{width}()` accessor, register number 31 accesses the zero register which reads as zero and ignores writes.
- For other register accessors, such as the SIMD&FP [`V`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-497-V?lang=en#asl_accessor_v_2)`{width}()` accessors, there is no special interpretation of the register number.

Other special AArch64 accessors include:

- The [`SP`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-452-SP?lang=en#asl_accessor_sp_1)`{width}()` accessors have no parameters and are used to read or write the currently selected 64-bit stack pointer at the current Exception level.
- The [`PC64`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-451-PC64?lang=en#asl_func_pc64_0)`{width}()` accessor has no argument list and is used to read the 64-bit Program Counter.
- The [`Vpart`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-498-Vpart?lang=en#asl_accessor_vpart_3)`{width}()` accessors are used to perform a partial read or write of an Advanced SIMD vector register, using an additional *part* parameter to select which half of the vector register to access.
- The [`Z`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-545-Z?lang=en#asl_accessor_z_2)`{width}()`, [`V`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-497-V?lang=en#asl_accessor_v_2)`{width}()`, and [`Vpart`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-498-Vpart?lang=en#asl_accessor_vpart_3)`{width}()` accessors read and write the same underlying vector register file.

Other register accessors are defined as required by other architectural features. See [A-profile Architecture Pseudocode](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode?lang=en#chap_pseudocode), sections aarch64/functions/registers/.
