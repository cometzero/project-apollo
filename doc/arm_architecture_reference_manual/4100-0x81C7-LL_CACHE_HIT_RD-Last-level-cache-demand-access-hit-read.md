##### `0x81C7`, LL\_CACHE\_HIT\_RD, Last level cache demand access hit, read

The counter counts each demand read counted by [LL\_CACHE\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0036--LL-CACHE-RD--Last-level-cache-access--read?lang=en#event_ll_cache_rd) that hits in the Last level cache.
