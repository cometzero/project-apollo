##### `0x81CB`, LL\_CACHE\_HIT\_WR, Last level cache demand access hit, write

The counter counts each demand write counted by [LL\_CACHE\_WR](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x829D--LL-CACHE-WR--Last-level-cache-access--write?lang=en#event_ll_cache_wr) that hits in the Last level cache.
