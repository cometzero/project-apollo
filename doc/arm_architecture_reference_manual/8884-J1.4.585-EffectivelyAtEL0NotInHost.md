##### J1.4.585 EffectivelyAtEL0NotInHost

```
// EffectivelyAtEL0NotInHost()
// =======================
// Accesses from EL0 when the Effective value of HCR_EL2().[E2H, TGE] is not {1, 1} will be
// trapped or Undefined.
func EffectivelyAtEL0NotInHost() => boolean
begin
    return (PSTATE.EL == EL0 && !ELIsInHost(EL0));
end;
```
