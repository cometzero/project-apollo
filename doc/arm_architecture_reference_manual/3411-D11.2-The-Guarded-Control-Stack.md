# ​D11.2 The Guarded Control Stack

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack>

#### D11.2 The Guarded Control Stack

G THDMB
:   [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) allows software to use a separate and protected stack for storing control flow information.

D KSDTT
:   The GCS pointer registers, [GCSPR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#gcspr_elx), are [GCSPR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-11-Guarded-Control-Stack-registers/-D24-11-5-GCSPR-EL0--Guarded-Control-Stack-Pointer-Register--EL0-?lang=en#reg_aarch64_gcspr_el0), [GCSPR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-11-Guarded-Control-Stack-registers/-D24-11-6-GCSPR-EL1--Guarded-Control-Stack-Pointer-Register--EL1-?lang=en#reg_aarch64_gcspr_el1), [GCSPR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-11-Guarded-Control-Stack-registers/-D24-11-7-GCSPR-EL2--Guarded-Control-Stack-Pointer-Register--EL2-?lang=en#reg_aarch64_gcspr_el2), [GCSPR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-11-Guarded-Control-Stack-registers/-D24-11-8-GCSPR-EL3--Guarded-Control-Stack-Pointer-Register--EL3-?lang=en#reg_aarch64_gcspr_el3).

R WYQWD
:   While executing at ELx, the Guarded Control Stack uses [GCSPR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#gcspr_elx) as the current GCS pointer register.

R WCVQY
:   All [GCSPR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#gcspr_elx) are 64 bits wide and hold a virtual address in the current translation regime.

D DWRNV
:   Each entry in the Guarded Control Stack is called a GCS record.

D NKMHW
:   A [GCS record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_record) is one of the following:

    - A GCS procedure return record.
    - A GCS exception return record.
    - A GCS cap record, which is one of the following:

      - Valid GCS cap record.
      - In-progress GCS cap record.
    - A GCS software record.

R KDDMV
:   The size of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record) is 8 bytes.

R DNKSM
:   Bits [1:0] of a [GCS procedure return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_pr_record) are set to `0b00`.

R KYFJK
:   The size of a [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record) is 32 bytes.

R ZBFYT
:   Bits [63:0] of the lowest-addressed doubleword of a [GCS exception return record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_er_record) are set to `0x0000_0000_0000_0009`.

R VNZWB
:   The size of a [GCS cap record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_cap_record) is 8 bytes.

R QFCRR
:   Bits [11:0] of a [Valid GCS cap record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_vc_record) are set to `0x001`.

R NCZGL
:   Bits [2:0] of a [In-progress GCS cap record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_ipc_record) are set to `0b101`.

R LYPBD
:   The size of a [GCS software record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_sw_record) is 8 bytes.

R ZXQBN
:   Bits [11:0] of a [GCS software record](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack?lang=en#mdterm_gcs_sw_record) are set to `0x011` and bits [63:12] can take any value..
