##### D17.3.3 Initializing the sample interval counters

When the PE moves from a state where profiling is disabled to a state where profiling is enabled:

- If [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1) is nonzero, then sampling restarts from the current values in [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1).
- If [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1) is zero, then it is loaded with an initial value. The behavior depends on [PMSIRR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-15-PMSIRR-EL1--Sampling-Interval-Reload-Register?lang=en#reg_aarch64_pmsirr_el1).RND and whether [FEAT\_SPE\_ERnd](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_spe_ernd) is implemented.

  - If [PMSIRR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-15-PMSIRR-EL1--Sampling-Interval-Reload-Register?lang=en#reg_aarch64_pmsirr_el1).RND is 0:

    - [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1).COUNT[31:8] is set to [PMSIRR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-15-PMSIRR-EL1--Sampling-Interval-Reload-Register?lang=en#reg_aarch64_pmsirr_el1).INTERVAL.
    - [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1).COUNT[7:0] is set to `0x00`.
  - If [PMSIRR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-15-PMSIRR-EL1--Sampling-Interval-Reload-Register?lang=en#reg_aarch64_pmsirr_el1).RND is 1 and [FEAT\_SPE\_ERnd](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_spe_ernd) is not implemented:

    - [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1).COUNT[31:8] is set to [PMSIRR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-15-PMSIRR-EL1--Sampling-Interval-Reload-Register?lang=en#reg_aarch64_pmsirr_el1).INTERVAL.
    - [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1).COUNT[7:0] is set to a random or pseudorandom value in the range `0x00` to `0xFF` inclusive.
  - If [PMSIRR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-15-PMSIRR-EL1--Sampling-Interval-Reload-Register?lang=en#reg_aarch64_pmsirr_el1).RND is 1 and [FEAT\_SPE\_ERnd](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-3-The-Armv8-2-architecture-extension?lang=en#feat_feat_spe_ernd) is implemented:

    - [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1).COUNT[31:8] is set to [PMSIRR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-15-PMSIRR-EL1--Sampling-Interval-Reload-Register?lang=en#reg_aarch64_pmsirr_el1).INTERVAL.
    - [PMSICR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-7-Statistical-Profiling-Extension-registers/-D24-7-13-PMSICR-EL1--Sampling-Interval-Counter-Register?lang=en#reg_aarch64_pmsicr_el1).COUNT[7:0] is set to `0x00`.
