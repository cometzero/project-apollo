# ​C6.2.152 DSB

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB>

##### C6.2.152 DSB

Data synchronization barrier

This instruction is a memory barrier that ensures the completion of memory accesses, see [Data Synchronization Barrier](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-9-Data-Synchronization-Barrier?lang=en#beicefjh).

This instruction is used by the aliases [PSSBB](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-320-PSSBB?lang=en#isa_pssbb_dsb) and [SSBB](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-381-SSBB?lang=en#isa_ssbb_dsb).

It has encodings from 2 classes: [Memory barrier](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb_iclass_memory_barrier) and [Memory nXS barrier](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-152-DSB?lang=en#isa_dsb_iclass_memory_nxs_barrier)

###### Memory barrier

![](images/0834-C6.2.152-DSB-img01.svg)

###### Encoding

```
DSB  (<option>|#<imm>)
```

###### Decode for this encoding

```
var nXS : boolean = FALSE;
var alias : DSBAlias;
case CRm of
    when ‘0000’ => alias = DSBAlias_SSBB;
    when ‘0100’ => alias = DSBAlias_PSSBB;
    otherwise   => alias = DSBAlias_DSB;
end;
var scope : MBMaintenanceScope;
var types : MBReqTypes;
case CRm[1:0] of
    when ‘00’ =>
        types = MBReqTypes_All;
        scope = MBMaintenanceScope_OuterShareable;
    when ‘01’ =>
        types = MBReqTypes_Reads;
        scope = MBMaintenanceScope_None;
    when ‘10’ =>
        types = MBReqTypes_Writes;
        scope = MBMaintenanceScope_None;
    when ‘11’ =>
        types = MBReqTypes_All;
        case CRm[3:2] of
            when ‘00’ => scope = MBMaintenanceScope_OuterShareable;
            when ‘01’ => scope = MBMaintenanceScope_Nonshareable;
            when ‘10’ => scope = MBMaintenanceScope_InnerShareable;
            when ‘11’ => scope = MBMaintenanceScope_OuterShareable;
        end;
end;
```

###### Memory nXS barrier

###### (FEAT\_XS)

![](images/0834-C6.2.152-DSB-img02.svg)

###### Encoding

```
DSB  <option>nXS
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_XS) then EndOfDecode(Decode_UNDEF); end;
let types : MBReqTypes = MBReqTypes_All;
var nXS : boolean = TRUE;
let alias : DSBAlias = DSBAlias_DSB;
var scope : MBMaintenanceScope;
case imm2 of
    when ‘00’ => scope = MBMaintenanceScope_OuterShareable;
    when ‘01’ => scope = MBMaintenanceScope_Nonshareable;
    when ‘10’ => scope = MBMaintenanceScope_InnerShareable;
    when ‘11’ => scope = MBMaintenanceScope_OuterShareable;
end;
```

###### Assembler Symbols

<option>
:   ​

    For the “Memory barrier” variant: specifies the limitation on the Memory Effects and maintenance operations ordered by the barrier operation, and is encoded in “CRm”.

    > #### Note
    >
    > The value `0b0000` is used to encode `SSBB` and the value `0b0100` is used to encode `PSSBB`.

    For more information on whether an access is before or after a barrier instruction, see [Data Synchronization Barrier (DSB)](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-9-Data-Synchronization-Barrier?lang=en#beicefjh).

###### Operation

```
case alias of
    when DSBAlias_SSBB =>
        SpeculativeStoreBypassBarrierToVA();
    when DSBAlias_PSSBB =>
        SpeculativeStoreBypassBarrierToPA();
    when DSBAlias_DSB =>
        if !nXS && IsFeatureImplemented(FEAT_XS) then
            nXS = PSTATE.EL IN {EL0, EL1} && IsHCRXEL2Enabled() && HCRX_EL2().FnXS == ‘1’;
        end;
        DataSynchronizationBarrier(scope, types, nXS);
    otherwise =>
        unreachable;
end;
```
