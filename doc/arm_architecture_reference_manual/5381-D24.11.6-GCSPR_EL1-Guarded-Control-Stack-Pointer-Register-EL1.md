# ​D24.11.6 GCSPR_EL1, Guarded Control Stack Pointer Register (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-11-Guarded-Control-Stack-registers/-D24-11-6-GCSPR-EL1--Guarded-Control-Stack-Pointer-Register--EL1->

##### D24.11.6 GCSPR\_EL1, Guarded Control Stack Pointer Register (EL1)

The GCSPR\_EL1 characteristics are:

Purpose
:   Contains the Guarded Control Stack Pointer at EL1.

Configuration
:   This register is present only when FEAT\_GCS is implemented. Otherwise, direct accesses to GCSPR\_EL1 are UNDEFINED.

Attributes
:   GCSPR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5381-D24.11.6-GCSPR_EL1-Guarded-Control-Stack-Pointer-Register-EL1-img01.svg)

PTR[63:3], bits [63:3]
:   EL1 Guarded Control Stack Pointer bits [63:3].

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

Bits [2:0]
:   Reserved, RES0.

###### Accessing GCSPR\_EL1

When the Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, without explicit synchronization, accesses from EL3 using the accessor name `GCSPR_EL1` or `GCSPR_EL12` are not guaranteed to be ordered with respect to accesses using the other accessor name.

Accesses to this register use the following encodings in the System register encoding space:

        if EL3SDDUndef() then
            Undefined();
        else
            AArch64_SystemAccessTrap(EL3, 0x18);
        end;
    elsif EffectiveHCR_EL2_NVx() IN {'111'} then
        X{64}(t) = NVMem(0x8C0);
    else
        X{64}(t) = GCSPR_EL1();
    end;
elsif PSTATE.EL == EL2 then
    if HaveEL(EL3) && SCR_EL3().GCSEn == '0' then
        if EL3SDDUndef() then
            Undefined();

            AArch64_SystemAccessTrap(EL3, 0x18);
        end;
    elsif ELIsInHost(EL2) then
        X{64}(t) = GCSPR_EL2();
    else
        X{64}(t) = GCSPR_EL1();
    end;

    X{64}(t) = GCSPR_EL1();
