# ​J1.2.729 AArch64_OAMax

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-729-AArch64-OAMax>

##### J1.2.729 AArch64\_OAMax

```
// AArch64_OAMax()
// ===============
// Returns the maximum number of bits capable of representing physical address
// based on the implemented features.
func AArch64_OAMax() => AddressSize
begin
    if IsFeatureImplemented(FEAT_D128) then return 56; end;
    if IsFeatureImplemented(FEAT_LPA2) then return 52; end;
    if IsFeatureImplemented(FEAT_LPA) then return 52; end;
    return 48;
end;
```
