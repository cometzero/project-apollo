##### C6.2.425 STSMAX, STSMAXL

Atomic signed maximum on word or doubleword, without return

This instruction atomically loads a 32-bit word or 64-bit doubleword from memory, compares it against the value held in a register, and stores the larger value back to memory, treating the values as signed numbers.

- `STSMAX` does not have release semantics.
- `STSMAXL` stores to memory with release semantics, as described in [Load-Acquire, Store-Release](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-10-Load-Acquire--Load-AcquirePC--and-Store-Release?lang=en#beihchef).

For information about addressing modes, see [Load/Store addressing modes](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C1-The-A64-Instruction-Set/-C1-3-Address-generation/-C1-3-3-Load-store-addressing-modes?lang=en#chdiiibb).

This is an alias of [LDSMAX, LDSMAXA, LDSMAXAL, LDSMAXL](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-235-LDSMAX--LDSMAXA--LDSMAXAL--LDSMAXL?lang=en#isa_ldsmax). This means:

- The encodings in this description are named to match the encodings of [LDSMAX, LDSMAXA, LDSMAXAL, LDSMAXL](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-235-LDSMAX--LDSMAXA--LDSMAXAL--LDSMAXL?lang=en#isa_ldsmax).
- The description of [LDSMAX, LDSMAXA, LDSMAXAL, LDSMAXL](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-235-LDSMAX--LDSMAXA--LDSMAXAL--LDSMAXL?lang=en#isa_ldsmax) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding for the 32-bit no memory ordering variant

Applies when `(size == 10 && R == 0)`

```
STSMAX  <Ws>, [<Xn|SP>]
```

is equivalent to

```
LDSMAX  <Ws>, <Wt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Encoding for the 32-bit release variant

Applies when `(size == 10 && R == 1)`

```
STSMAXL  <Ws>, [<Xn|SP>]
```

is equivalent to

```
LDSMAXL  <Ws>, <Wt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Encoding for the 64-bit no memory ordering variant

Applies when `(size == 11 && R == 0)`

```
STSMAX  <Xs>, [<Xn|SP>]
```

is equivalent to

```
LDSMAX  <Xs>, <Xt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Encoding for the 64-bit release variant

Applies when `(size == 11 && R == 1)`

```
STSMAXL  <Xs>, [<Xn|SP>]
```

is equivalent to

```
LDSMAXL  <Xs>, <Xt>, [<Xn|SP>]
```

and is always the preferred disassembly.

###### Assembler Symbols

<Ws>
:   ​

    Is the 32-bit name of the general-purpose register holding the data value to be operated on with the contents of the memory location, encoded in the “Rs” field.

<Xn|SP>
:   ​

    Is the 64-bit name of the general-purpose base register or stack pointer, encoded in the “Rn” field.

<Xs>
:   ​

    Is the 64-bit name of the general-purpose register holding the data value to be operated on with the contents of the memory location, encoded in the “Rs” field.
