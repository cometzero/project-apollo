# ​J1.4.122 SysRegZeroEventCounters

##### J1.4.122 SysRegZeroEventCounters

```
// SysRegZeroEventCounters()
// ==========================
// Zero all the event counters.
// Called on a System register write to PMCR_EL0 or PMCR that writes ‘1’ to PMCR_EL0.P or PMCR.P.
func SysRegZeroEventCounters()
begin
    // Although SysRegZeroPMUCounters implements the functionality for PMUACR_EL1
    // that is part of FEAT_PMUv3p9, it should be noted that writes to
    // PMCR_EL0 are not allowed at EL0 when PMUSERENR_EL0.UEN is 1, meaning
    // it is not relevant in this case.
    SysRegZeroPMUCounters(Zeros{33} :: Ones{31});
end;
```
