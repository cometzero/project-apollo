# ​I5.3.28 PMDEVTYPE, Performance Monitors Device Type register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-28-PMDEVTYPE--Performance-Monitors-Device-Type-register>

##### I5.3.28 PMDEVTYPE, Performance Monitors Device Type register

The PMDEVTYPE characteristics are:

Purpose
:   Indicates to a debugger that this component is part of a PE’s performance monitor interface.

Configuration
:   If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is implemented, this register is in the Core power domain. If [FEAT\_DoPD](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_dopd) is not implemented, this register is in the Debug power domain.

    This register is present only when FEAT\_PMUv3\_EXT is implemented and FEAT\_PMU\_PIDR is implemented. Otherwise, direct accesses to PMDEVTYPE are RES0.

Attributes
:   PMDEVTYPE is a 32-bit register.

###### Field descriptions

![](images/7217-I5.3.28-PMDEVTYPE-Performance-Monitors-Device-Type-register-img01.svg)

Bits [31:8]
:   Reserved, RES0.

SUB, bits [7:4]
:   Subtype. Indicates this is a component within a PE.

    Reads as `0b0001`

    Access to this field is RO.

MAJOR, bits [3:0]
:   Major type.

###### Accessing PMDEVTYPE

Accesses to this register use the following encodings:

When FEAT\_PMUv3\_EXT is implemented
:   Accessible at offset `0xFCC` from PMU

    - When FEAT\_DoPD is implemented and !IsCorePowered(), accesses to this register generate an error response.
    - Otherwise, accesses to this register are RO.
