# ​D24.10.21 CNTPS_TVAL_EL1, Counter-timer Physical Secure Timer TimerValue Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-21-CNTPS-TVAL-EL1--Counter-timer-Physical-Secure-Timer-TimerValue-Register>

##### D24.10.21 CNTPS\_TVAL\_EL1, Counter-timer Physical Secure Timer TimerValue Register

The CNTPS\_TVAL\_EL1 characteristics are:

Purpose
:   Holds the timer value for the secure physical timer, usually accessible at EL3 but configurably accessible at EL1 in Secure state.

Configuration
:   This register is present only when EL3 is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTPS\_TVAL\_EL1 are UNDEFINED.

Attributes
:   CNTPS\_TVAL\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5365-D24.10.21-CNTPS_TVAL_EL1-Counter-timer-Physical-Secure-Timer-TimerValue-Register-img01.svg)

Bits [63:32]
:   Reserved, RES0.

TimerValue, bits [31:0]
:   The TimerValue view of the secure physical timer.

    On a read of this register:

    - If [CNTPS\_CTL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-19-CNTPS-CTL-EL1--Counter-timer-Physical-Secure-Timer-Control-Register?lang=en#reg_aarch64_cntps_ctl_el1).ENABLE is 0, the value returned is UNKNOWN.
    - If [CNTPS\_CTL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-19-CNTPS-CTL-EL1--Counter-timer-Physical-Secure-Timer-Control-Register?lang=en#reg_aarch64_cntps_ctl_el1).ENABLE is 1, the value returned is ([CNTPS\_CVAL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-20-CNTPS-CVAL-EL1--Counter-timer-Physical-Secure-Timer-CompareValue-Register?lang=en#reg_aarch64_cntps_cval_el1) - [CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0)).

    On a write of this register, [CNTPS\_CVAL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-20-CNTPS-CVAL-EL1--Counter-timer-Physical-Secure-Timer-CompareValue-Register?lang=en#reg_aarch64_cntps_cval_el1) is set to ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) + TimerValue), where TimerValue is treated as a signed 32-bit integer.

    When [CNTPS\_CTL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-19-CNTPS-CTL-EL1--Counter-timer-Physical-Secure-Timer-Control-Register?lang=en#reg_aarch64_cntps_ctl_el1).ENABLE is 1, the timer condition is met when ([CNTPCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-17-CNTPCT-EL0--Counter-timer-Physical-Count-Register?lang=en#reg_aarch64_cntpct_el0) - [CNTPS\_CVAL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-20-CNTPS-CVAL-EL1--Counter-timer-Physical-Secure-Timer-CompareValue-Register?lang=en#reg_aarch64_cntps_cval_el1)) is greater than or equal to zero. This means that TimerValue acts like a 32-bit downcounter timer. When the timer condition is met:

    - [CNTPS\_CTL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-19-CNTPS-CTL-EL1--Counter-timer-Physical-Secure-Timer-Control-Register?lang=en#reg_aarch64_cntps_ctl_el1).ISTATUS is set to 1.
    - If [CNTPS\_CTL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-19-CNTPS-CTL-EL1--Counter-timer-Physical-Secure-Timer-Control-Register?lang=en#reg_aarch64_cntps_ctl_el1).IMASK is 0, an interrupt is generated.

    When [CNTPS\_CTL\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-19-CNTPS-CTL-EL1--Counter-timer-Physical-Secure-Timer-Control-Register?lang=en#reg_aarch64_cntps_ctl_el1).ENABLE is 0, the TimerValue cannot be read but continues to decrement. When the timer is enabled, the TimerValue represents the elapsed time whether that time was spent enabled or disabled.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
