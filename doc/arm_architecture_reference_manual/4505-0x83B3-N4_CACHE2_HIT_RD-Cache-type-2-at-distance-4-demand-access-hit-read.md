##### `0x83B3`, N4\_CACHE2\_HIT\_RD, Cache type 2 at distance 4 demand access hit, read

The counter counts each demand read counted by [N4\_CACHE\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83A3--N4-CACHE-HIT-RD--Cache-at-distance-4--demand-access-hit--read?lang=en#event_n4_cache_hit_rd) due to a demand read accessing a second cache type at distance 4.

The definition of cache types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
