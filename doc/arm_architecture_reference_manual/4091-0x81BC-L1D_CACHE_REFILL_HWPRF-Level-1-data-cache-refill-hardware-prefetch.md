##### `0x81BC`, L1D\_CACHE\_REFILL\_HWPRF, Level 1 data cache refill, hardware prefetch

The counter counts each hardware prefetch counted by [L1D\_CACHE\_HWPRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8154--L1D-CACHE-HWPRF--Level-1-data-cache-hardware-prefetch?lang=en#event_l1d_cache_hwprf) that causes a refill of the Level 1 data or unified cache from outside of the Level 1 data or unified cache.
