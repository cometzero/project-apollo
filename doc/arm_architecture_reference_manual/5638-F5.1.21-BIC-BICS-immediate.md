# ​F5.1.21 BIC, BICS (immediate)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-21-BIC--BICS--immediate->

##### F5.1.21 BIC, BICS (immediate)

Bitwise Bit Clear (immediate) performs a bitwise AND of a register value and the complement of an immediate value, and writes the result to the destination register.

If the destination register is not the PC, the BICS variant of the instruction updates the condition flags based on the result.

The field descriptions for `<Rd>` identify the encodings where the PC is permitted as the destination register. Arm deprecates any use of these encodings. However, when the destination register is the PC:

- The BIC variant of the instruction is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
- The BICS variant of the instruction performs an exception return without the use of the stack. In this case:
  - The PE branches to the address written to the PC, and restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>.
  - The PE checks SPSR\_<current\_mode> for an illegal return event. See [Illegal return events from AArch32 state](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-3-Illegal-return-events-from-AArch32-state?lang=en#chdddjdb).
  - The instruction is UNDEFINED in Hyp mode.
  - The instruction is CONSTRAINED UNPREDICTABLE in User mode and System mode.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-21-BIC--BICS--immediate-?lang=en#isa_bic_i_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-21-BIC--BICS--immediate-?lang=en#isa_bic_i_iclass_t1)).

###### A1

![](images/5638-F5.1.21-BIC-BICS-immediate-img01.svg)

###### Encoding for the BIC variant

Applies when `(S == 0)`

```
BIC{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Encoding for the BICS variant

Applies when `(S == 1)`

```
BICS{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Decode for all variants of this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let setflags : boolean = (S == ‘1’);
let a32 : boolean = TRUE;
let imm : bits(12) = imm12;
```

###### T1

![](images/5638-F5.1.21-BIC-BICS-immediate-img02.svg)

###### Encoding for the BIC variant

Applies when `(S == 0)`

```
BIC{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Encoding for the BICS variant

Applies when `(S == 1)`

```
BICS{<c>}{<q>}  {<Rd>, }<Rn>, #<const>
```

###### Decode for all variants of this encoding

```
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let setflags : boolean = (S == ‘1’);
let a32 : boolean = FALSE;
let imm : bits(12) = i::imm3::imm8;
// Armv8-A removes UNPREDICTABLE for R13
if d == 15 || n == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

<Rd>
:   ​

    For the “A1 BIC” and “A1 BICS” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the same as `<Rn>`. Arm deprecates using the PC as the destination register, but if the PC is used:

    - For the BIC variant, the instruction is a branch to the address calculated by the operation. This is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
    - For the BICS variant, the instruction performs an exception return, that restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>.

    ​

    For the “T1 BIC” and “T1 BICS” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the same as `<Rn>`.

<Rn>
:   ​

    For the “A1 BIC” and “A1 BICS” variants: is the general-purpose source register, encoded in the “Rn” field. The PC can be used, but this is deprecated.

    ​

    For the “T1 BIC” and “T1 BICS” variants: is the general-purpose source register, encoded in the “Rn” field.

<const>
:   ​

    For the “A1 BIC” and “A1 BICS” variants: an immediate value. See [Modified immediate constants in A32 instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-7-General-information-about-the-T32-and-A32-instruction-descriptions/-F1-7-7-Modified-immediate-constants-in-T32-and-A32-instructions?lang=en#babhdajf) for the range of values.

    ​

    For the “T1 BIC” and “T1 BICS” variants: an immediate value. See [Modified immediate constants in T32 instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-7-General-information-about-the-T32-and-A32-instruction-descriptions/-F1-7-7-Modified-immediate-constants-in-T32-and-A32-instructions?lang=en#babghaga) for the range of values.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let (imm32, carry) : (bits(32), bit) = (if a32 then A32ExpandImm_C(imm, PSTATE.C)
                                                   else T32ExpandImm_C(imm, PSTATE.C));
    let result : bits(32) = R(n) AND NOT(imm32);
    if d == 15 then          // Can only occur for A32 encoding
        if setflags then
            ALUExceptionReturn(result);
        else
            ALUWritePC(result);
        end;
    else
        R(d) = result;
        if setflags then
            PSTATE.N = result[31];
            PSTATE.Z = IsZeroBit{32}(result);
            PSTATE.C = carry;
            // PSTATE.V unchanged
        end;
    end;
end;
```

###### Operational Information

This instruction is a data-independent-time instruction as described in [About the DIT bit](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-5-About-the-DIT-bit?lang=en#beiidceg).
