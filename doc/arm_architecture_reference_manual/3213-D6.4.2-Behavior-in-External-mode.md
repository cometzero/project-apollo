# ​D6.4.2 Behavior in External mode

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode/-D6-4-2-Behavior-in-External-mode>

##### D6.4.2 Behavior in External mode

R DFCSS
:   The rules in this section apply only when the Trace Buffer Unit is enabled and using External mode.

R NHTSY
:   The [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9), [*Limit pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdfdibgj3), and [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) are physical addresses.

R XXFVW
:   [TRBMAR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-19-TRBMAR-EL1--Trace-Buffer-Memory-Attribute-Register?lang=en#reg_ext_trbmar_el1) defines the memory type, and, as applicable, Cacheability, Shareability, and Device type attributes, and the physical address space for the physical addresses.

R WNCWG
:   The IMPLEMENTATION DEFINED authentication interface controls which physical address spaces can be used.

R CMYYF
:   If the authentication interface prohibits invasive debug of the Security state corresponding to the physical address space selected by [TRBMAR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-19-TRBMAR-EL1--Trace-Buffer-Memory-Attribute-Register?lang=en#reg_ext_trbmar_el1).PAS, or [TRBMAR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-19-TRBMAR-EL1--Trace-Buffer-Memory-Attribute-Register?lang=en#reg_ext_trbmar_el1).PAS is set to a reserved value, then when the Trace Buffer Unit receives trace data from the trace unit, no trace is written to the trace buffer and all of the following occur:

    - A trace buffer management event is generated. This sets [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).IRQ to 1.
    - If [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).S is 0, then all of the following occur:

      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).S is set to 1, [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1).
      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).EC is set to `0x00`, other buffer management event.
      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).BSC is set to `0b000000`, *access not allowed*.
    - The other fields in [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1) are unchanged.

I PGLYR
:   The trace unit defines the trace prohibited regions.

    When the Trace Buffer Unit is using Self-hosted mode, EL3 is always a prohibited region. This is not the case when the Trace Buffer Unit is using External mode.

R WMPMV
:   A write of 1 to [TRBCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-7-TRBCR--Trace-Buffer-Control-Register?lang=en#reg_ext_trbcr).ManStop generates a trace unit flush, and on completion of the trace unit flush all of the following apply:

    - A trace buffer management event is generated. This sets [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).IRQ to 1.
    - If [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).S is 0, then all of the following occur:

      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).S is set to 1, [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1).
      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).EC is set to `0x00`, other buffer management event.
      - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).BSC is set to `0b000011`, *Manual Stop event*.
    - The other fields in [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1) are unchanged.

    After the trace buffer management event is generated:

    - The Trace Buffer Unit writes all trace data it has accepted from the trace unit to memory, adding padding data if necessary.
    - The [*current write pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdciahcf5) points to one of the following:

      - If the last trace byte written to the trace buffer was the last byte in the trace buffer, then the [*Base pointer*](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-1-About-the-Trace-Buffer-Extension/-D6-1-1-The-trace-buffer-pointers?lang=en#chdhagiii9).
      - Otherwise, the first byte after the last trace byte written to the trace buffer.

I YBKZD
:   Setting [TRBCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-7-TRBCR--Trace-Buffer-Control-Register?lang=en#reg_ext_trbcr).ManStop to 1 has the effects described in [RWMPMV](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode/-D6-4-2-Behavior-in-External-mode?lang=en#wmpmv) even if [collection is stopped](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-2-The-trace-buffer?lang=en#chdhegahh1). Other than a Trigger Event, other trace buffer management events do not guarantee a trace unit flush, and following any other management events, including a Trigger Event, setting [TRBCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-7-TRBCR--Trace-Buffer-Control-Register?lang=en#reg_ext_trbcr).ManStop to 1 is required to force the Trace Buffer Unit to write all trace data to memory.

I KMQKF
:   When stopping trace at the end of a trace session using External mode, software does the following:

    1. Stops and disables the trace unit.
    2. Sets [TRBCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-7-TRBCR--Trace-Buffer-Control-Register?lang=en#reg_ext_trbcr).ManStop to 1.
    3. Polls for [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).{DAT, S} = {0, 1}.
    4. Disables the Trace Buffer Unit.

    To ensure the Trace Buffer Unit writes are Complete, the software is required to issue a `DSB` instruction. This might require an external debugger to halt the PE to execute the instruction. See [Cross-halt trigger event](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H5-The-Embedded-Cross-Trigger-Interface/-H5-4-Description-and-allocation-of-CTI-triggers/-H5-4-3-Cross-halt-trigger-event?lang=en#chdfaide).

I BSXVZ
:   If [TRBPTR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-29-TRBPTR-EL1--Trace-Buffer-Write-Pointer-Register?lang=en#reg_ext_trbptr_el1)[63:(`OAMax`+1)] is nonzero when the Trace Buffer Unit attempts to write to the trace buffer, then one of the following occurs, and it is CONSTRAINED UNPREDICTABLE which:

    - A stage 1 Address Size fault is generated.
    - [TRBPTR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-29-TRBPTR-EL1--Trace-Buffer-Write-Pointer-Register?lang=en#reg_ext_trbptr_el1)[63:(`OAMax`+1)] are ignored and treated as zero.

    The value of `OAMax` is as defined by [RMXRFD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-3-Trace-buffer-Self-hosted-mode/-D6-3-2-Behavior-when-address-translation-is-disabled?lang=en#mxrfd).
