# ​D6.4.1 The external Trace Buffer debug component

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode/-D6-4-1-The-external-Trace-Buffer-debug-component>

##### D6.4.1 The external Trace Buffer debug component

R RGHMG
:   The external Trace Buffer debug component is defined by the external views of all of the following:

    - [TRBBASER\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-2-TRBBASER-EL1--Trace-Buffer-Base-Address-Register?lang=en#reg_ext_trbbaser_el1).
    - [TRBIDR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-14-TRBIDR-EL1--Trace-Buffer-ID-Register?lang=en#reg_ext_trbidr_el1).
    - [TRBLIMITR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-17-TRBLIMITR-EL1--Trace-Buffer-Limit-Address-Register?lang=en#reg_ext_trblimitr_el1).
    - [TRBMAR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-19-TRBMAR-EL1--Trace-Buffer-Memory-Attribute-Register?lang=en#reg_ext_trbmar_el1).
    - [TRBMPAM\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-20-TRBMPAM-EL1--Trace-Buffer-MPAM-Configuration-Register?lang=en#reg_ext_trbmpam_el1), if implemented.
    - [TRBPTR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-29-TRBPTR-EL1--Trace-Buffer-Write-Pointer-Register?lang=en#reg_ext_trbptr_el1).
    - [TRBSR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-30-TRBSR-EL1--Trace-Buffer-Status-syndrome-Register?lang=en#reg_ext_trbsr_el1).
    - [TRBTRG\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-4-External-Trace-Buffer-registers/-H9-4-31-TRBTRG-EL1--Trace-Buffer-Trigger-Counter-Register?lang=en#reg_ext_trbtrg_el1).
    - Trace Buffer Management Registers, if implemented.

    Where applicable, the external views are mapped to the equivalent System registers.

I LSZMG
:   The Trace Buffer Management Registers are those with offsets ranging from `0xF00` through `0xFFC`, as defined by [Management registers and CoreSight compliance](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K5-Recommended-External-Debug-Interface/-K5-4-Management-registers-and-CoreSight-compliance?lang=en#cihcdhda).

I QSMXY
:   The [external Trace Buffer debug component](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode/-D6-4-1-The-external-Trace-Buffer-debug-component?lang=en#mdterm_trbe_ext_view) is a separate component in the external debug interface.

I DCWTT
:   An external access to a *Trace Buffer Unit* register might return an error response if one or more of the following apply:

    Off
    :   The Core power domain is powered down or is in low-power state where the registers cannot be accessed.

    DLK
    :   [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) is implemented and [`DoubleLockStatus`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-5-DoubleLockStatus?lang=en#asl_func_doublelockstatus_0)`()` == TRUE. The OS Double Lock is locked.

        > #### Note
        >
        > The implementation of [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) in an Armv9 implementation is prohibited.

    OSLK
    :   [OSLSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-28-OSLSR-EL1--OS-Lock-Status-Register?lang=en#reg_aarch64_oslsr_el1).OSLK is `0b1`. The OS Lock is locked.

    ETBAD
    :   [`AllowExternalTraceBufferAccess`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-699-AllowExternalTraceBufferAccess?lang=en#asl_func_allowexternaltracebufferaccess_1) == FALSE for the access. The access is disabled by [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).ETBAD.

R MXBCY
:   For reserved accesses to the [external Trace Buffer debug component](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D6-The-Trace-Buffer-Extension/-D6-4-Trace-buffer-External-mode/-D6-4-1-The-external-Trace-Buffer-debug-component?lang=en#mdterm_trbe_ext_view):

    - If the Core power domain is powered down or is in a low-power state where the registers cannot be accessed, then the access returns an error response.
    - Otherwise:

      - For addresses in the range `0xF00` through `0xFFC`, the access is RES0H.
      - For all other addresses, if any of the following conditions apply, then the access is either RES0H or returns an error response:

        DLK
        :   [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) is implemented and [`DoubleLockStatus`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-5-DoubleLockStatus?lang=en#asl_func_doublelockstatus_0)`()` == TRUE. The OS Double Lock is locked.

            > #### Note
            >
            > The implementation of [FEAT\_DoubleLock](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-1-The-Armv8-0-architecture-extension?lang=en#feat_feat_doublelock) in an Armv9 implementation is prohibited.

        OSLK
        :   [OSLSR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-28-OSLSR-EL1--OS-Lock-Status-Register?lang=en#reg_aarch64_oslsr_el1).OSLK is `0b1`. The OS Lock is locked.

        ETBAD
        :   [`AllowExternalTraceBufferAccess`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-699-AllowExternalTraceBufferAccess?lang=en#asl_func_allowexternaltracebufferaccess_1) == FALSE for the access. The access is disabled by [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).ETBAD.

        Otherwise, the access is RES0H.

I RFYXF
:   For more information on reserved accesses, see [Access requirements for reserved and unallocated registers](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I1-Requirements-for-Memory-mapped-Components/-I1-3-Access-requirements-for-reserved-and-unallocated-registers?lang=en#cegbcacc).
