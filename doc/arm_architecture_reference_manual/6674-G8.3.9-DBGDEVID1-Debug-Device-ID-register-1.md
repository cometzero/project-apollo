# ​G8.3.9 DBGDEVID1, Debug Device ID register 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-9-DBGDEVID1--Debug-Device-ID-register-1>

##### G8.3.9 DBGDEVID1, Debug Device ID register 1

The DBGDEVID1 characteristics are:

Purpose
:   Adds to the information given by the [DBGDIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-11-DBGDIDR--Debug-ID-Register?lang=en#reg_aarch32_dbgdidr) by describing other features of the debug implementation.

Configuration
:   This register is required in all implementations.

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to DBGDEVID1 are UNDEFINED.

Attributes
:   DBGDEVID1 is a 32-bit register.

###### Field descriptions

![](images/6674-G8.3.9-DBGDEVID1-Debug-Device-ID-register-1-img01.svg)

Bits [31:4]
:   Reserved, RES0.

PCSROffset, bits [3:0]
:   This field indicates the offset applied to PC samples returned by reads of [EDPCSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-35-EDPCSR--External-Debug-Program-Counter-Sample-Register?lang=en#reg_ext_edpcsr).

    Access to this field is RO.
