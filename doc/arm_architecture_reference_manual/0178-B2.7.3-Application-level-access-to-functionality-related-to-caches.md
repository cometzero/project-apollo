# ​B2.7.3 Application level access to functionality related to caches

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-7-Caches-and-memory-hierarchy/-B2-7-3-Application-level-access-to-functionality-related-to-caches>

##### B2.7.3 Application level access to functionality related to caches

As indicated in [About the Application level programmers’ model](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-1-About-the-Application-level-programmers--model?lang=en#cfihcffg), the application level corresponds to execution at EL0. The architecture defines a set of cache maintenance instructions that software can use to manage cache coherency. Software executing at a higher Exception level can enable use of some of this functionality from EL0, as follows:

When the value of [SCTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-174-SCTLR-EL1--System-Control-Register--EL1-?lang=en#reg_aarch64_sctlr_el1).UCI is 1
:   Software executing at EL0 can access:

    - The data cache maintenance instructions, `DC CVAU`, `DC CVAC`, `DC CVAP`, `DC CVADP`, and `DC CIVAC`. See [The data cache maintenance instruction ( DC )](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D7-The-AArch64-System-Level-Memory-Model/-D7-5-Cache-support/-D7-5-9-A64-Cache-maintenance-instructions?lang=en#chdiihgc).
    - The instruction cache maintenance instruction `IC IVAU`. See [The instruction cache maintenance instruction ( IC )](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D7-The-AArch64-System-Level-Memory-Model/-D7-5-Cache-support/-D7-5-9-A64-Cache-maintenance-instructions?lang=en#chdehfaa).

    Attempted execution of these instructions might generate a Permission fault as described in [Permission fault](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-15-Memory-aborts/-D8-15-1-MMU-fault-types?lang=en#mdsec_permission_fault).

When the value of [SCTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-174-SCTLR-EL1--System-Control-Register--EL1-?lang=en#reg_aarch64_sctlr_el1).UCT is 1
:   Software executing at EL0 can access the cache type register. See [CTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-41-CTR-EL0--Cache-Type-Register?lang=en#reg_aarch64_ctr_el0).

When the value of [SCTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-174-SCTLR-EL1--System-Control-Register--EL1-?lang=en#reg_aarch64_sctlr_el1).DZE is 1
:   Software executing at EL0 can access the data cache zero instruction `DC ZVA`. See [Data cache zero instruction](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D7-The-AArch64-System-Level-Memory-Model/-D7-5-Cache-support/-D7-5-10-Data-cache-zero-instruction?lang=en#beiceaaj).

The [SCTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-174-SCTLR-EL1--System-Control-Register--EL1-?lang=en#reg_aarch64_sctlr_el1).{UCI, UCT, DZE} control fields are accessible only by software executing at EL1 or higher.

When the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is {1, 1}, the controls {UCI, UCT and DZE} are found in [SCTLR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-175-SCTLR-EL2--System-Control-Register--EL2-?lang=en#reg_aarch64_sctlr_el2).

This functionality is UNDEFINED at EL0 when the value of the corresponding [SCTLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-174-SCTLR-EL1--System-Control-Register--EL1-?lang=en#reg_aarch64_sctlr_el1) control field is 0.
