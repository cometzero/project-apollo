# ​I5.5.2 AMCGCR, Activity Monitors Counter Group Configuration Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-5-Activity-Monitors-external-register-descriptions/-I5-5-2-AMCGCR--Activity-Monitors-Counter-Group-Configuration-Register>

##### I5.5.2 AMCGCR, Activity Monitors Counter Group Configuration Register

The AMCGCR characteristics are:

Purpose
:   Provides information on the number of activity monitor event counters implemented within each counter group.

Configuration
:   It is IMPLEMENTATION DEFINED whether AMCGCR is implemented in the Core power domain or in the Debug power domain

    When FEAT\_AMU\_EXT32 is implemented, External register AMCGCR bits [31:0] are architecturally mapped to AArch64 System register [AMCGCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-3-AMCGCR-EL0--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch64_amcgcr_el0)[31:0].

    When FEAT\_AMU\_EXT64 is implemented, External register AMCGCR bits [63:0] are architecturally mapped to AArch64 System register [AMCGCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-3-AMCGCR-EL0--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch64_amcgcr_el0)[63:0].

    External register AMCGCR bits [31:0] are architecturally mapped to AArch32 System register [AMCGCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-5-Activity-Monitors-registers/-G8-5-2-AMCGCR--Activity-Monitors-Counter-Group-Configuration-Register?lang=en#reg_aarch32_amcgcr)[31:0].

    This register is present only when FEAT\_AMUv1 is implemented and FEAT\_AMU\_EXT is implemented. Otherwise, direct accesses to AMCGCR are RES0.

Attributes
:   AMCGCR is a:

    - 64-bit register when FEAT\_AMU\_EXT64 is implemented.
    - 32-bit register otherwise.

###### Field descriptions

When FEAT\_AMU\_EXT64 is implemented:
:   ![](images/7255-I5.5.2-AMCGCR-Activity-Monitors-Counter-Group-Configuration-Register-img01.svg)

Bits [63:16]
:   Reserved, RES0.

CG1NC, bits [15:8]
:   Counter Group 1 Number of Counters. Highest index of the implemented counters in the auxiliary counter group, plus one. Zero indicates that there are no counters in the auxiliary counter group.

    In an implementation that includes FEAT\_AMUv1, the permitted range of values is 0 to 16.

    If FEAT\_AMUv1p1 is implemented, then [AMCG1IDR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-2-AMCG1IDR-EL0--Activity-Monitors-Counter-Group-1-Identification-Register?lang=en#reg_aarch64_amcg1idr_el0) further defines which auxiliary counters are implemented, and the counters in the auxiliary counter group might be implemented non-contiguously.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

CG0NC, bits [7:0]
:   Counter Group 0 Number of Counters. The number of counters in the architected counter group.

    Reads as `0x04`

    Access to this field is RO.

Otherwise:
:   ![](images/7255-I5.5.2-AMCGCR-Activity-Monitors-Counter-Group-Configuration-Register-img02.svg)

Bits [31:16]
:   Reserved, RES0.

CG1NC, bits [15:8]
:   Counter Group 1 Number of Counters. Highest index of the implemented counters in the auxiliary counter group, plus one. Zero indicates that there are no counters in the auxiliary counter group.

    In an implementation that includes FEAT\_AMUv1, the permitted range of values is 0 to 16.

    If FEAT\_AMUv1p1 is implemented, then [AMCG1IDR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-6-Activity-Monitors-registers/-D24-6-2-AMCG1IDR-EL0--Activity-Monitors-Counter-Group-1-Identification-Register?lang=en#reg_aarch64_amcg1idr_el0) further defines which auxiliary counters are implemented, and the counters in the auxiliary counter group might be implemented non-contiguously.

    This field has an IMPLEMENTATION DEFINED value.

    Access to this field is RO.

CG0NC, bits [7:0]
:   Counter Group 0 Number of Counters. The number of counters in the architected counter group.

    Reads as `0x04`

    Access to this field is RO.

###### Accessing AMCGCR

Accesses to this register use the following encodings:

When FEAT\_AMU\_EXT64 is implemented
:   Accessible at offset `0xCE0` from AMU

    - When FEAT\_RME is implemented, FEAT\_AMU\_EXTACR is implemented, an access is Secure, and AMROOTCR().RA IN {‘001’, ‘000’}, accesses to this register are RAZ/WI.
    - When FEAT\_RME is implemented, FEAT\_AMU\_EXTACR is implemented, an access is Realm, and AMROOTCR().RA IN {‘010’, ‘000’}, accesses to this register are RAZ/WI.
    - When FEAT\_RME is implemented, FEAT\_AMU\_EXTACR is implemented, an access is Non-secure, and AMROOTCR().RA != ‘011’, accesses to this register are RAZ/WI.
    - When FEAT\_RME is not implemented, FEAT\_AMU\_EXTACR is implemented, an access is Non-secure, and AMSCR().NSRA == ‘0’, accesses to this register are RAZ/WI.
    - Otherwise, accesses to this register are RO.

When FEAT\_AMU\_EXT32 is implemented
:   Accessible at offset `0xCE0` from AMU

    - When FEAT\_RME is implemented, FEAT\_AMU\_EXTACR is implemented, an access is Secure, and AMROOTCR().RA IN {‘001’, ‘000’}, accesses to this register are RAZ/WI.
    - When FEAT\_RME is implemented, FEAT\_AMU\_EXTACR is implemented, an access is Realm, and AMROOTCR().RA IN {‘010’, ‘000’}, accesses to this register are RAZ/WI.
    - When FEAT\_RME is implemented, FEAT\_AMU\_EXTACR is implemented, an access is Non-secure, and AMROOTCR().RA != ‘011’, accesses to this register are RAZ/WI.
    - When FEAT\_RME is not implemented, FEAT\_AMU\_EXTACR is implemented, an access is Non-secure, and AMSCR().NSRA == ‘0’, accesses to this register are RAZ/WI.
    - Otherwise, accesses to this register are RO.
