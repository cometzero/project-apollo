##### G4.8.6 Access permission checking

The [`AArch32_S1LDHasPermissionsFault`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-192-AArch32-S1LDHasPermissionsFault?lang=en#asl_func_aarch32_s1ldhaspermissionsfault_6)`()`, [`AArch32_S1SDHasPermissionsFault`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-193-AArch32-S1SDHasPermissionsFault?lang=en#asl_func_aarch32_s1sdhaspermissionsfault_5)`()`, and [`AArch32_S2HasPermissionsFault`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-195-AArch32-S2HasPermissionsFault?lang=en#asl_func_aarch32_s2haspermissionsfault_4)`()` functions are used by the architecture to perform access permission checking based on attributes derived from the Translation Table descriptors.

The interpretation of access permission is shown in [Memory access control](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-6-Memory-access-control?lang=en#chdiggbh).
