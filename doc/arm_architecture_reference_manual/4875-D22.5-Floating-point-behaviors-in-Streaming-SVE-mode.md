#### D22.5 Floating-point behaviors in Streaming SVE mode

D DMPBW
:   Unless stated otherwise, the behaviors in this section apply when the PE is in Streaming SVE mode, to floating-point instructions that place their results in SIMD&FP registers or SVE scalable vector registers, except for:

    - SVE BFloat16 instructions `BFDOT` and `BFMMLA`, for which, see [BFloat16 behaviors for instructions that calculate sum-of-products](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-11-BFloat16-behaviors-for-instructions-that-calculate-sum-of-products?lang=en#babjjeica4).
    - FP8 instructions, for which, see [Summary of FP8 instruction behaviors](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-5-Summary-of-FP8-instruction-behaviors?lang=en#fp8_instruction_behaviors).

The instructions:

R PHDZL
:   - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{DN, FZ, RMode, FZ16, AH, FIZ}, unless specified otherwise in [Flushing denormalized numbers to zero](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-6-Flushing-denormalized-numbers-to-zero?lang=en#chdbdeij) or [Alternate BFloat16 behaviors](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-10-Alternate-BFloat16-behaviors?lang=en#babffgghg6).

R GTYSK
:   - Produce the expected IEEE 754 default result and update the [FPSR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-10-FPSR--Floating-point-Status-Register?lang=en#reg_aarch64_fpsr) cumulative exception flag bits, unless specified otherwise in [Alternate BFloat16 behaviors](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-10-Alternate-BFloat16-behaviors?lang=en#babffgghg6).

R FBFNT
:   - Disable trapped floating-point exceptions as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{IDE, IXE, UFE, OFE, DZE, IOE} are all 0, and treat the NEP element preserve control as if it is 0, if [FEAT\_SME\_FA64](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-3-The-Armv9-2-architecture-extension?lang=en#feat_feat_sme_fa64) is not implemented or not enabled at the current Exception level.
