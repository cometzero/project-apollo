# ​G8.3.5 DBGCLAIMCLR, Debug CLAIM Tag Clear register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-5-DBGCLAIMCLR--Debug-CLAIM-Tag-Clear-register>

##### G8.3.5 DBGCLAIMCLR, Debug CLAIM Tag Clear register

The DBGCLAIMCLR characteristics are:

Purpose
:   Used by software to read the values of the CLAIM tag bits, and to clear CLAIM tag bits to 0.

    The architecture does not define any functionality for the CLAIM tag bits.

    > #### Note
    >
    > CLAIM tags are typically used for communication between the debugger and target software.

    Used in conjunction with the [DBGCLAIMSET](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-6-DBGCLAIMSET--Debug-CLAIM-Tag-Set-register?lang=en#reg_aarch32_dbgclaimset) register.

Configuration
:   An implementation must include eight CLAIM tag bits.

    AArch32 System register DBGCLAIMCLR bits [31:0] are architecturally mapped to AArch64 System register [DBGCLAIMCLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-4-DBGCLAIMCLR-EL1--Debug-CLAIM-Tag-Clear-Register?lang=en#reg_aarch64_dbgclaimclr_el1)[31:0].

    AArch32 System register DBGCLAIMCLR bits [31:0] are architecturally mapped to AArch64 System register [DBGCLAIMSET\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-5-DBGCLAIMSET-EL1--Debug-CLAIM-Tag-Set-Register?lang=en#reg_aarch64_dbgclaimset_el1)[31:0].

    AArch32 System register DBGCLAIMCLR bits [31:0] are architecturally mapped to AArch32 System register [DBGCLAIMSET](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-6-DBGCLAIMSET--Debug-CLAIM-Tag-Set-register?lang=en#reg_aarch32_dbgclaimset)[31:0].

    AArch32 System register DBGCLAIMCLR bits [31:0] are architecturally mapped to External register [DBGCLAIMCLR\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-4-DBGCLAIMCLR-EL1--Debug-CLAIM-Tag-Clear-Register?lang=en#reg_ext_dbgclaimclr_el1)[31:0].

    AArch32 System register DBGCLAIMCLR bits [31:0] are architecturally mapped to External register [DBGCLAIMSET\_EL1](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-5-DBGCLAIMSET-EL1--Debug-CLAIM-Tag-Set-Register?lang=en#reg_ext_dbgclaimset_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to DBGCLAIMCLR are UNDEFINED.

Attributes
:   DBGCLAIMCLR is a 32-bit register.

###### Field descriptions

![](images/6670-G8.3.5-DBGCLAIMCLR-Debug-CLAIM-Tag-Clear-register-img01.svg)

Bits [31:8]
:   Reserved, RAZ/WI.

CLAIM<m> , bits [m], for m = 7 to 0
:   Claim Tag Clear. Indicates the current status of Claim Tag bit <m>, and is used to clear Claim Tag bit <m> to 0.

    The reset behavior of this field is:

    - On a Cold reset, this field resets to `'0'`.

    Access to this field is W1C.
