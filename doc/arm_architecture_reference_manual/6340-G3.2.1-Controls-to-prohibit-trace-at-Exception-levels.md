# ​G3.2.1 Controls to prohibit trace at Exception levels

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-2-Prohibited-regions-in-self-hosted-trace/-G3-2-1-Controls-to-prohibit-trace-at-Exception-levels>

##### G3.2.1 Controls to prohibit trace at Exception levels

If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), [TRFCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-37-TRFCR--Trace-Filter-Control-Register?lang=en#reg_aarch32_trfcr), [TRFCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-73-TRFCR-EL1--Trace-Filter-Control-Register--EL1-?lang=en#reg_aarch64_trfcr_el1), [TRFCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-74-TRFCR-EL2--Trace-Filter-Control-Register--EL2-?lang=en#reg_aarch64_trfcr_el2) and [HTRFCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-33-HTRFCR--Hyp-Trace-Filter-Control-Register?lang=en#reg_aarch32_htrfcr) control whether trace is prohibited at an Exception level. While self-hosted trace is [disabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_disabled), these registers are ignored.

If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), tracing is prohibited at EL0 if one of the following is true:

- The Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE == 0 and [TRFCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-73-TRFCR-EL1--Trace-Filter-Control-Register--EL1-?lang=en#reg_aarch64_trfcr_el1).E0TRE == 0.
- The Effective value of [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).TGE == 0 and [TRFCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-37-TRFCR--Trace-Filter-Control-Register?lang=en#reg_aarch32_trfcr).E0TRE == 0.
- The Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE == 1 and [TRFCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-74-TRFCR-EL2--Trace-Filter-Control-Register--EL2-?lang=en#reg_aarch64_trfcr_el2).E0HTRE == 0.

If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), tracing is prohibited at EL1 if [TRFCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-37-TRFCR--Trace-Filter-Control-Register?lang=en#reg_aarch32_trfcr).E1TRE == 0.

If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), tracing is prohibited at EL2 if [HTRFCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-33-HTRFCR--Hyp-Trace-Filter-Control-Register?lang=en#reg_aarch32_htrfcr).E2TRE == 0.

If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), tracing is prohibited at EL3 if one of the following is true:

- EL3 is in AArch64 state.
- EL3 is in AArch32 state and [TRFCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-37-TRFCR--Trace-Filter-Control-Register?lang=en#reg_aarch32_trfcr).E1TRE == 0.

The pseudocode [`TraceAllowed`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-735-TraceAllowed?lang=en#asl_func_traceallowed_1)`()` shows the preceding rules.

If [FEAT\_ETE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-1-The-Armv9-0-architecture-extension?lang=en#feat_feat_ete) is not implemented, when self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), no events are exported to the trace unit when tracing is prohibited.

If [FEAT\_ETE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-1-The-Armv9-0-architecture-extension?lang=en#feat_feat_ete) is not implemented, when self-hosted trace is [disabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_disabled), no events are exported to the trace unit when the PE is in Secure state and counting in Secure state is prohibited.

If [FEAT\_ETE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-1-The-Armv9-0-architecture-extension?lang=en#feat_feat_ete) is not implemented, when [PMCR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-8-PMCR-EL0--Performance-Monitors-Control-Register?lang=en#reg_aarch64_pmcr_el0).X==0 or [PMCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-9-PMCR--Performance-Monitors-Control-Register?lang=en#reg_aarch32_pmcr).X==0, no PMU events are exported to the trace unit.

If [FEAT\_ETE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-1-The-Armv9-0-architecture-extension?lang=en#feat_feat_ete) is implemented, see [External inputs](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D4-The-Embedded-Trace-Extension/-D4-6-Resource-operation/-D4-6-13-External-inputs?lang=en#mdsec_ste_external_inputs) for the rules governing export of events to the trace unit.

Otherwise, PMU events are exported to the trace unit.
