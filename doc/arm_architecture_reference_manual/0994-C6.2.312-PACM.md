##### C6.2.312 PACM

Pointer authentication modifier

This instruction is used to set the value of PSTATE.PACM to 1.

If [FEAT\_PAuth\_LR](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-6-The-Armv9-5-architecture-extension?lang=en#feat_feat_pauth_lr) is not implemented, this instruction behaves as a NOP.

###### System

###### (FEAT\_PAuth\_LR)

![](images/0994-C6.2.312-PACM-img01.svg)

###### Encoding

```
PACM
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_PAuth_LR) then EndOfDecode(Decode_NOP); end;
```

###### Operation

```
PSTATE.PACM = if IsPACMEnabled() then ‘1’ else ‘0’;
```
