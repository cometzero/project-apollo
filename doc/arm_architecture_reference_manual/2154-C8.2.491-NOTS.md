##### C8.2.491 NOTS

Bitwise invert predicate, setting the condition flags

This instruction performs a bitwise invert of each active element of the source predicate, and places the results in the corresponding elements of the destination predicate. Inactive elements in the destination predicate register are set to zero. This instruction sets the First (N), None (Z), and !Last (C) condition flags based on the predicate result, and sets the V flag to zero.

This is an alias of [EORS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-141-EORS?lang=en#isa_eors_p_p_pp). This means:

- The encodings in this description are named to match the encodings of [EORS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-141-EORS?lang=en#isa_eors_p_p_pp).
- The description of [EORS](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-141-EORS?lang=en#isa_eors_p_p_pp) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

###### Encoding

```
NOTS  <Pd>.B, <Pg>/Z, <Pn>.B
```

is equivalent to

```
EORS  <Pd>.B, <Pg>/Z, <Pn>.B, <Pg>.B
```

and is the preferred disassembly when `Pm == Pg`.
