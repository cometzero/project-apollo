##### C9.2.180 MOVA (tile to vector, single)

Move ZA tile slice to Z vector

This instruction operates on individual horizontal or vertical slices within a named ZA tile of the specified element size. The slice number within the tile is selected by the sum of the slice index register and immediate offset, modulo the number of such elements in a vector. The immediate offset is in the range 0 to the number of elements in a 128-bit vector segment minus 1.

Inactive elements in the destination vector remain unmodified.

This instruction is used by the alias [MOV (tile to vector, single)](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-170-MOV--tile-to-vector--single-?lang=en#isa_mov_mova_z_p_rza).

It has encodings from 5 classes: [8-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza_iclass_8_bit), [16-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza_iclass_16_bit), [32-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza_iclass_32_bit), [64-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza_iclass_64_bit), and [128-bit](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C9-SME-Instruction-Descriptions/-C9-2-Alphabetical-list-of-SME-instructions/-C9-2-180-MOVA--tile-to-vector--single-?lang=en#isa_mova_z_p_rza_iclass_128_bit)

###### Operation

```
CheckStreamingSVEAndZAEnabled();
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let dim : integer = VL DIV esize;
let mask : bits(PL) = P{}(g);
let index : bits(32) = X{}(s);
let slice : integer = (UInt(index) + offset) MOD dim;
let operand : bits(VL) = ZAslice{}(n, esize, vertical, slice);
var result : bits(VL) = Z{}(d);
for e = 0 to dim-1 do
    let element : bits(esize) = operand[e*:esize];
    if ActivePredicateElement{PL}(mask, e, esize) then
        result[e*:esize] = element;
    end;
end;
Z{VL}(d) = result;
```
