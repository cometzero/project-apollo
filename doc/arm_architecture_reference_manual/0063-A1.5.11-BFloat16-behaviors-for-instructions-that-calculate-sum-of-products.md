# ​A1.5.11 BFloat16 behaviors for instructions that calculate sum-of-products

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-11-BFloat16-behaviors-for-instructions-that-calculate-sum-of-products>

##### A1.5.11 BFloat16 behaviors for instructions that calculate sum-of-products

The behaviors in this section apply to the following instructions:

- Advanced SIMD: `BFDOT` and `BFMMLA`.
- SVE: `BFDOT` and `BFMMLA`.
- SME: `BFMOPA` (widening) and `BFMOPS` (widening), and SME2 `BFDOT` and `BFVDOT`.

[Table A1-6](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-4-Summary-of-BFloat16-instruction-behaviors?lang=en#tbl_babcbhidb1) and [Table A1-7](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-4-Summary-of-BFloat16-instruction-behaviors?lang=en#tbl_babggbdfh3) describe when these instructions are legal.

When [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).EBF is 0, the instructions:
:   - Perform unfused two-way sum-of-products for each pair of adjacent BFloat16 elements in the source vectors, with rounding of all intermediate products and sums.
    - Ignore [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).RMode and use non-IEEE 754 Round to Odd behavior. See [Round to Odd](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A1-Introduction-to-the-Arm-Architecture/-A1-5-Floating-point-support/-A1-5-8-Rounding?lang=en#babghbfgb5).
    - Flush denormalized inputs and outputs to zero, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{FZ, FIZ} is {1, 1}.
    - Disable alternative floating-point behaviors, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).AH is 0.

When [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).EBF is 1, the instructions:
:   - Perform a fused two-way sum-of-products for each pair of adjacent BFloat16 elements in the source vectors, without rounding of the intermediate products, but rounding the single-precision sum before addition to the single-precision accumulator element.
    - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).RMode, supporting all four IEEE 754 rounding modes.
    - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{FZ, FIZ}.
    - Honor [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).AH.

Regardless of the value of [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).EBF, the instructions:
:   - Produce the expected IEEE 754 single-precision default result but do not update the [FPSR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-10-FPSR--Floating-point-Status-Register?lang=en#reg_aarch64_fpsr) cumulative exception flag bits.
    - Disable trapped floating-point exceptions, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).{IDE, IXE, UFE, OFE, DZE, IOE} are all 0.
    - Generate an intermediate sum-of-products of the same infinity when there are infinite products all with the same sign.
    - Generate an intermediate sum-of-products that is a default NaN when any of the following are true:

      - Any multiplier input is a NaN.
      - Any product is infinity x 0.0.
      - Both products are infinity of differing signs.
    - Generate a default NaN, as if [FPCR](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-8-FPCR--Floating-point-Control-Register?lang=en#reg_aarch64_fpcr).DN is 1.
