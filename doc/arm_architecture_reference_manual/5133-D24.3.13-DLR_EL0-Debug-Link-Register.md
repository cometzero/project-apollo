# ​D24.3.13 DLR_EL0, Debug Link Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-13-DLR-EL0--Debug-Link-Register>

##### D24.3.13 DLR\_EL0, Debug Link Register

The DLR\_EL0 characteristics are:

Purpose
:   In Debug state, holds the address to restart from.

Configuration
:   This register is a Special-purpose register.

    AArch64 System register DLR\_EL0 bits [31:0] are architecturally mapped to AArch32 System register [DLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-29-DLR--Debug-Link-Register?lang=en#reg_aarch32_dlr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to DLR\_EL0 are UNDEFINED.

Attributes
:   DLR\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5133-D24.3.13-DLR_EL0-Debug-Link-Register-img01.svg)

ADDR, bits [63:0]
:   Restart address.
