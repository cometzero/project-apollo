##### G5.14.5 Short-descriptor Translation table walk

Short-Descriptor format is only supported for Regime\_EL10 and Regime\_EL30 (PL1&0) Stage 1 and a separate walk function is dedicated for that, [`AArch32_S1WalkSD`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-218-AArch32-S1WalkSD?lang=en#asl_func_aarch32_s1walksd_4)`()`. The limited number of parameters are collected in the walk function and would otherwise follow a similar flow to Long-descriptor formats of iteratively updating the walk state. The walk notably collects the domain and Short-descriptor format type which are unique to Short-descriptor formats. The descriptor type is decoded using [`AArch32_DecodeDescriptorTypeSD`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-215-AArch32-DecodeDescriptorTypeSD?lang=en#asl_func_aarch32_decodedescriptortypesd_2)`()`.

For a non-faulting walk, a valid final walk state is returned, otherwise a faulting walk could report one of the following at a specified level:

- Translation Fault.
- Address Size Fault.
- Access Flag Fault (when SCTLR.AFE is configured to support Access flags).
