# ​J1.2.724 AArch64_GetVARange

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-2-Pseudocode-for-AArch64-operation/-J1-2-724-AArch64-GetVARange>

##### J1.2.724 AArch64\_GetVARange

```
// AArch64_GetVARange()
// ====================
// Determines if the VA that is to be translated lies in LOWER or UPPER address range.
func AArch64_GetVARange(va : bits(64)) => VARange
begin
    if va[55] == ‘0’ then
        return VARange_LOWER;
    else
        return VARange_UPPER;
    end;
end;
```
