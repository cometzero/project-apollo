# ​C6.2.305 PACGA

##### C6.2.305 PACGA

Pointer Authentication Code, using generic key

This instruction calculates the Pointer Authentication Code for a 64-bit value in the first source register, using a modifier in the second source register, and the generic key. The calculated Pointer Authentication Code is written to the most significant 32 bits of the destination register, and the least significant 32 bits of the destination register are set to zero.

###### Integer

###### (FEAT\_PAuth)

![](images/0987-C6.2.305-PACGA-img01.svg)

###### Encoding

```
PACGA  <Xd>, <Xn>, <Xm|SP>
```

###### Decode for this encoding

```
if !IsFeatureImplemented(FEAT_PAuth) then EndOfDecode(Decode_UNDEF); end;
var source_is_sp : boolean = FALSE;
let d : integer = UInt(Rd);
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
if m == 31 then source_is_sp = TRUE; end;
```

###### Assembler Symbols

<Xd>
:   ​

    Is the 64-bit name of the general-purpose destination register, encoded in the “Rd” field.

<Xn>
:   ​

    Is the 64-bit name of the first general-purpose source register, encoded in the “Rn” field.

<Xm|SP>
:   ​

    Is the 64-bit name of the second general-purpose source register or stack pointer, encoded in the “Rm” field.

###### Operation

```
if source_is_sp then
    X{64}(d) = AddPACGA(X{64}(n), SP{64}());
else
    X{64}(d) = AddPACGA(X{64}(n), X{64}(m));
end;
```
