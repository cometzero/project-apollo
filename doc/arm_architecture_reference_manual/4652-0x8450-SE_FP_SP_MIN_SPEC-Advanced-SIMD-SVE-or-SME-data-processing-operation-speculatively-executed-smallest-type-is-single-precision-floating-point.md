##### `0x8450`, SE\_FP\_SP\_MIN\_SPEC, Advanced SIMD, SVE, or SME data processing operation speculatively executed, smallest type is single-precision floating-point

The counter counts each Advanced SIMD, SVE, or SME data processing operation counted by [FP\_SP\_MIN\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8470--FP-SP-MIN-SPEC--Floating-point-operation-speculatively-executed--smallest-type-is-single-precision-floating-point?lang=en#event_fp_sp_min_spec) due to an instruction where the smallest type was single-precision floating-point.
