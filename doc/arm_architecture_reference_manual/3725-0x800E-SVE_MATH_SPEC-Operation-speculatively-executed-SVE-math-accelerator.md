##### `0x800E`, SVE\_MATH\_SPEC, Operation speculatively executed, SVE math accelerator

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) math function operation due to any of the following instructions:

- SVE: FEXPA, FTMAD, FTSMUL, or FTSSEL.
