# ​F5.1.8 ADD, ADDS (SP plus immediate)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-8-ADD--ADDS--SP-plus-immediate->

##### F5.1.8 ADD, ADDS (SP plus immediate)

Add to SP (immediate) adds an immediate value to the SP value, and writes the result to the destination register.

If the destination register is not the PC, the ADDS variant of the instruction updates the condition flags based on the result.

The field descriptions for `<Rd>` identify the encodings where the PC is permitted as the destination register. However, when the destination register is the PC:

- The ADD variant of the instruction is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
- The ADDS variant of the instruction performs an exception return without the use of the stack. Arm deprecates use of this instruction. However, in this case:
  - The PE branches to the address written to the PC, and restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>.
  - The PE checks SPSR\_<current\_mode> for an illegal return event. See [Illegal return events from AArch32 state](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-15-Exception-return-to-an-Exception-level-using-AArch32/-G1-15-3-Illegal-return-events-from-AArch32-state?lang=en#chdddjdb).
  - The instruction is UNDEFINED in Hyp mode.
  - The instruction is CONSTRAINED UNPREDICTABLE in User mode and System mode.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-8-ADD--ADDS--SP-plus-immediate-?lang=en#isa_add_sp_i_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-8-ADD--ADDS--SP-plus-immediate-?lang=en#isa_add_sp_i_iclass_t1), [T2](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-8-ADD--ADDS--SP-plus-immediate-?lang=en#isa_add_sp_i_iclass_t2), [T3](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-8-ADD--ADDS--SP-plus-immediate-?lang=en#isa_add_sp_i_iclass_t3), and [T4](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-8-ADD--ADDS--SP-plus-immediate-?lang=en#isa_add_sp_i_iclass_t4)).

###### A1

![](images/5625-F5.1.8-ADD-ADDS-SP-plus-immediate-img01.svg)

###### Encoding for the ADD variant

Applies when `(S == 0)`

```
ADD{<c>}{<q>}  {<Rd>, }SP, #<const>
```

###### Encoding for the ADDS variant

Applies when `(S == 1)`

```
ADDS{<c>}{<q>}  {<Rd>, }SP, #<const>
```

###### Decode for all variants of this encoding

```
let d : integer = UInt(Rd);
let setflags : boolean = (S == ‘1’);
let imm32 : bits(32) = A32ExpandImm(imm12);
```

![](images/5625-F5.1.8-ADD-ADDS-SP-plus-immediate-img02.svg)

###### Encoding

```
ADD{<c>}{<q>}  <Rd>, SP, #<imm8>
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let setflags : boolean = FALSE;
let imm32 : bits(32) = ZeroExtend{}(imm8::‘00’);
```

![](images/5625-F5.1.8-ADD-ADDS-SP-plus-immediate-img03.svg)

###### Encoding

```
ADD{<c>}{<q>}  {SP, }SP, #<imm7>
```

###### Decode for this encoding

```
let d : integer = 13;
let setflags : boolean = FALSE;
let imm32 : bits(32) = ZeroExtend{}(imm7::‘00’);
```

###### T3

![](images/5625-F5.1.8-ADD-ADDS-SP-plus-immediate-img04.svg)

###### Encoding for the ADD variant

Applies when `(S == 0)`

```
ADD{<c>}{<q>}  {<Rd>, }SP, #<const>
```

```
ADD{<c>}.W  {<Rd>, }SP, #<const> // (<Rd>, <const> can be represented in T1 or T2)
```

###### Encoding for the ADDS variant

Applies when `(S == 1 && Rd != 1111)`

```
ADDS{<c>}{<q>}  {<Rd>, }SP, #<const>
```

###### Decode for all variants of this encoding

```
if Rd == ‘1111’ && S == ‘1’ then See(“CMN (immediate)”); end;
let d : integer = UInt(Rd);
let setflags : boolean = (S == ‘1’);
let imm32 : bits(32) = T32ExpandImm(i::imm3::imm8);
if d == 15 && !setflags then UnpredictableProcedure(); end;
```

###### T4

![](images/5625-F5.1.8-ADD-ADDS-SP-plus-immediate-img05.svg)

###### Encoding

```
ADD{<c>}{<q>}  {<Rd>, }SP, #<imm12> // (<imm12> cannot be represented in T1, T2, or T3)
```

```
ADDW{<c>}{<q>}  {<Rd>, }SP, #<imm12> // (<imm12> can be represented in T1, T2, or T3)
```

###### Decode for this encoding

```
let d : integer = UInt(Rd);
let setflags : boolean = FALSE;
let imm32 : bits(32) = ZeroExtend{}(i::imm3::imm8);
if d == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

###### Assembler Symbols

<c>
:   ​
    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<q>
:   ​
    ​

    See [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf).

<Rd>
:   ​

    For the “A1 ADD” and “A1 ADDS” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the SP. Arm deprecates using the PC as the destination register, but if the PC is used:

    - For the ADD variant, the instruction is a branch to the address calculated by the operation. This is an interworking branch, see [Pseudocode description of operations on the AArch32 general-purpose registers and the PC](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E1-The-AArch32-Application-Level-Programmers--Model/-E1-2-The-Application-level-programmers--model-in-AArch32-state/-E1-2-3-The-general-purpose-registers--and-the-PC--in-AArch32-state?lang=en#beicjfeh).
    - For the ADDS variant, the instruction performs an exception return, that restores [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc) from SPSR\_<current\_mode>.

    ​

    For the “T1” variant: is the general-purpose destination register, encoded in the “Rd” field.

    ​

    For the “T3 ADD”, “T3 ADDS”, and “T4” variants: is the general-purpose destination register, encoded in the “Rd” field. If omitted, this register is the SP.

<const>
:   ​

    For the “A1 ADD” and “A1 ADDS” variants: an immediate value. See [Modified immediate constants in A32 instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-7-General-information-about-the-T32-and-A32-instruction-descriptions/-F1-7-7-Modified-immediate-constants-in-T32-and-A32-instructions?lang=en#babhdajf) for the range of values.

    ​

    For the “T3 ADD” and “T3 ADDS” variants: an immediate value. See [Modified immediate constants in T32 instructions](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-7-General-information-about-the-T32-and-A32-instruction-descriptions/-F1-7-7-Modified-immediate-constants-in-T32-and-A32-instructions?lang=en#babghaga) for the range of values.

<imm8>
:   ​

    Is an unsigned immediate, a multiple of 4, in the range 0 to 1020, encoded in the “imm8” field as <imm8>/4.

SP
:   ​

    Is the stack pointer.

<imm7>
:   ​

    Is the unsigned immediate, a multiple of 4, in the range 0 to 508, encoded in the “imm7” field as <imm7>/4.

<imm12>
:   ​

    Is a 12-bit unsigned immediate, in the range 0 to 4095, encoded in the “i:imm3:imm8” field.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let (result, nzcv) : (bits(32), bits(4)) = AddWithCarry{32}(R(13), imm32, ‘0’);
    if d == 15 then          // Can only occur for A32 encoding
        if setflags then
            ALUExceptionReturn(result);
        else
            ALUWritePC(result);
        end;
    else
        R(d) = result;
        if setflags then
            PSTATE.[N,Z,C,V] = nzcv;
        end;
    end;
end;
```
