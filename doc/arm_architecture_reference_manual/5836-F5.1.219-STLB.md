##### F5.1.219 STLB

Store-Release Byte stores a byte from a register to memory. The instruction also has memory ordering semantics as described in [Load-Acquire, Store-Release](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-3-Definition-of-the-memory-model/-E2-3-5-Memory-barriers?lang=en#aa32chdbdidf).

For more information about support for shared memory see [Synchronization and semaphores](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-10-Synchronization-and-semaphores?lang=en#cegdaeag). For information about memory accesses see [Memory accesses](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-5-Memory-accesses?lang=en#chddjfjf).

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-219-STLB?lang=en#isa_stlb_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-219-STLB?lang=en#isa_stlb_iclass_t1)).

###### Encoding

```
STLB{<c>}{<q>}  <Rt>, [<Rn>]
```

###### Decode for this encoding

```
let t : integer = UInt(Rt);
let n : integer = UInt(Rn);
if t == 15 || n == 15 then UnpredictableProcedure(); end;
```

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let address : bits(32) = R(n);
    MemO{8}(address) = R(t)[7:0];
end;
```

###### Operational Information
