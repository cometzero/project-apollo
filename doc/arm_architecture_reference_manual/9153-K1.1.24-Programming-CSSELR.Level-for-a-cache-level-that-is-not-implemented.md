# ​K1.1.24 Programming CSSELR.Level for a cache level that is not implemented

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors/-K1-1-AArch32-CONSTRAINED-UNPREDICTABLE-behaviors/-K1-1-24-Programming-CSSELR-Level-for-a-cache-level-that-is-not-implemented>

##### K1.1.24 Programming CSSELR.Level for a cache level that is not implemented

If [CSSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-36-CSSELR--Cache-Size-Selection-Register?lang=en#reg_aarch32_csselr).Level is programmed to a cache level that is not implemented, then a read of [CSSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-36-CSSELR--Cache-Size-Selection-Register?lang=en#reg_aarch32_csselr) returns an UNKNOWN value in [CSSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-36-CSSELR--Cache-Size-Selection-Register?lang=en#reg_aarch32_csselr).Level.

If [CSSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-36-CSSELR--Cache-Size-Selection-Register?lang=en#reg_aarch32_csselr).Level is programmed to a cache level that is not implemented, then on a read of [CCSIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-24-CCSIDR--Current-Cache-Size-ID-Register?lang=en#reg_aarch32_ccsidr) an implementation must perform one of the following behaviors:

- The [CCSIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-24-CCSIDR--Current-Cache-Size-ID-Register?lang=en#reg_aarch32_ccsidr) read is treated as a NOP.
- The [CCSIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-24-CCSIDR--Current-Cache-Size-ID-Register?lang=en#reg_aarch32_ccsidr) read is UNDEFINED.
- The [CCSIDR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-24-CCSIDR--Current-Cache-Size-ID-Register?lang=en#reg_aarch32_ccsidr) read returns an UNKNOWN value.

When [FEAT\_CCIDX](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-4-The-Armv8-3-architecture-extension?lang=en#feat_feat_ccidx) is implemented, [CCSIDR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-25-CCSIDR2--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch32_ccsidr2) is implemented. If [CSSELR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-36-CSSELR--Cache-Size-Selection-Register?lang=en#reg_aarch32_csselr).Level is programmed to a cache level that is not implemented, then on a read of [CCSIDR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-25-CCSIDR2--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch32_ccsidr2) an implementation must perform one of the following behaviors:

- The [CCSIDR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-25-CCSIDR2--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch32_ccsidr2) read is treated as a NOP.
- The [CCSIDR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-25-CCSIDR2--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch32_ccsidr2) read is UNDEFINED.
- The [CCSIDR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-25-CCSIDR2--Current-Cache-Size-ID-Register-2?lang=en#reg_aarch32_ccsidr2) read returns an UNKNOWN value.
