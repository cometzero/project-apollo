Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-1-About-MPAM/-D21-1-7-AArch32-interoperability>

##### D21.1.7 AArch32 interoperability

I RSTCB
:   MPAM System registers are not accessible from AArch32 state. Therefore, a higher Exception level must set the PARTIDs and PMGs for any Exception level that uses AArch32 state.
