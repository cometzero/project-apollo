# ​F5.1.138 PLI (register)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-138-PLI--register->

##### F5.1.138 PLI (register)

Preload Instruction (register)

Preload Instruction signals the memory system that instruction memory accesses from a specified address are likely in the near future. The memory system can respond by taking actions that are expected to speed up the memory accesses when they do occur, such as pre-loading the cache line containing the specified address into the instruction cache.

The effect of a `PLI` instruction is IMPLEMENTATION DEFINED. For more information, see [Preloading caches](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-5-Caches-and-memory-hierarchy/-E2-5-4-Prefetching-into-cache?lang=en#cegjjfca).

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-138-PLI--register-?lang=en#isa_pli_r_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-138-PLI--register-?lang=en#isa_pli_r_iclass_t1)).

###### A1

![](images/5755-F5.1.138-PLI-register-img01.svg)

###### Encoding for the Rotate right with extend variant

Applies when `(imm5 == 00000 && stype == 11)`

```
PLI{<c>}{<q>}  [<Rn>, {+/-}<Rm> , RRX]
```

###### Encoding for the Shift or rotate by value variant

Applies when `(!(imm5 == 00000 && stype == 11))`

```
PLI{<c>}{<q>}  [<Rn>, {+/-}<Rm> {, <shift> #<amount>}]
```

###### Decode for all variants of this encoding

```
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let add : boolean = (U == ‘1’);
let (shift_t, shift_n) : (SRType, integer) = DecodeImmShift(stype, imm5);
if m == 15 then UnpredictableProcedure(); end;
```

###### T1

![](images/5755-F5.1.138-PLI-register-img02.svg)

###### Encoding

```
PLI{<c>}{<q>}  [<Rn>, {+}<Rm> {, LSL #<amount>}]
```

###### Decode for this encoding

```
if Rn == ‘1111’ then See(“PLI (immediate, literal)”); end;
let n : integer = UInt(Rn);
let m : integer = UInt(Rm);
let add : boolean = TRUE;
let shift_t : SRType = SRType_LSL;
let shift_n : integer = UInt(imm2);
// Armv8-A removes UNPREDICTABLE for R13
if m == 15 then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).

    For the “Rotate right with extend” and “Shift or rotate by value” variants: see [Standard assembler syntax fields](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F1-About-the-T32-and-A32-Instruction-Descriptions/-F1-2-Standard-assembler-syntax-fields?lang=en#babbefhf). `<c>` must be `AL` or omitted.

    ​

<amount>
:   ​

    For the “Shift or rotate by value” variant: is the shift amount, in the range 1 to 31 (when <shift> = LSL or ROR) or 1 to 32 (when <shift> = LSR or ASR) encoded in the “imm5” field as <amount> modulo 32.

    ​

    For the “T1” variant: is the shift amount, in the range 0 to 3, defaulting to 0 and encoded in the “imm2” field.

+
:   ​

    Specifies the index register is added to the base register.

###### Operation

```
if ConditionPassed() then
    EncodingSpecificOperations();
    let offset : bits(32) = Shift{}(R(m), shift_t, shift_n, PSTATE.C);
    let address : bits(32) = if add then (R(n) + offset) else (R(n) - offset);
    Hint_PreloadInstr(address);
end;
```
