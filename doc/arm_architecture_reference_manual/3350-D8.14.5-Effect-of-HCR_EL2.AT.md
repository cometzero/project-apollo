##### D8.14.5 Effect of HCR\_EL2.AT

I RBYYS
:   If [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).AT is 1, then all of the following are trapped to EL2 and reported using EC syndrome value `0x18` in [ESR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-45-ESR-EL2--Exception-Syndrome-Register--EL2-?lang=en#reg_aarch64_esr_el2):

    - Executing [`AT S1E0R`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-4-A64-System-instructions-for-address-translation/-C5-4-5-AT-S1E0R--Address-Translate-Stage-1-EL0-Read?lang=en#reg_aarch64_at_s1e0r) from EL1.
    - Executing [`AT S1E0W`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-4-A64-System-instructions-for-address-translation/-C5-4-6-AT-S1E0W--Address-Translate-Stage-1-EL0-Write?lang=en#reg_aarch64_at_s1e0w) from EL1.
    - Executing [`AT S1E1R`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-4-A64-System-instructions-for-address-translation/-C5-4-8-AT-S1E1R--Address-Translate-Stage-1-EL1-Read?lang=en#reg_aarch64_at_s1e1r) from EL1.
    - Executing [`AT S1E1W`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-4-A64-System-instructions-for-address-translation/-C5-4-10-AT-S1E1W--Address-Translate-Stage-1-EL1-Write?lang=en#reg_aarch64_at_s1e1w) from EL1.
    - Executing [`AT S1E1RP`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-4-A64-System-instructions-for-address-translation/-C5-4-9-AT-S1E1RP--Address-Translate-Stage-1-EL1-Read-PAN?lang=en#reg_aarch64_at_s1e1rp) from EL1.
    - Executing [`AT S1E1WP`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-4-A64-System-instructions-for-address-translation/-C5-4-11-AT-S1E1WP--Address-Translate-Stage-1-EL1-Write-PAN?lang=en#reg_aarch64_at_s1e1wp) from EL1.
    - If [FEAT\_ATS1A](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_ats1a) is implemented, executing [`AT S1E1A`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-4-A64-System-instructions-for-address-translation/-C5-4-7-AT-S1E1A--Address-Translate-Stage-1-EL1-Without-Permission-checks?lang=en#reg_aarch64_at_s1e1a) from EL1.
