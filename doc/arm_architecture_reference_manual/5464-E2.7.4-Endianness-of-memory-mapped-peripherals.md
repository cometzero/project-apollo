# ​E2.7.4 Endianness of memory-mapped peripherals

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-7-Endian-support/-E2-7-4-Endianness-of-memory-mapped-peripherals>

##### E2.7.4 Endianness of memory-mapped peripherals

All memory-mapped peripherals defined in the Arm architecture must be little-endian.

Peripherals to which this requirement applies include:

- Memory-mapped register interfaces to a debugger, or to a cross-trigger interface, see [About the External Debug Registers](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H8-About-the-External-Debug-Registers?lang=en#cihcaddh).
- The memory-mapped register interface to the system level implementation of the Generic Timer, see [System Level Implementation of the Generic Timer](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I2-System-Level-Implementation-of-the-Generic-Timer?lang=en#cegiiegb).
- A memory-mapped register interface to the Performance Monitors, see [Recommended External Interface to the Performance Monitors](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I3-Recommended-External-Interface-to-the-Performance-Monitors?lang=en#cegdjdjd).
- A memory-mapped register interface to the Activity Monitors, see [Recommended External Interface to the Activity Monitors](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I4-Recommended-External-Interface-to-the-Activity-Monitors?lang=en#recextiact).
- Memory-mapped register interfaces to an Arm Generic Interface Controller, see the *ARM® Generic Interrupt Controller Architecture Specification, GIC architecture version 3 and version 4.*
- The memory-mapped register interface to an Arm trace component. See, for example, the *Arm® Embedded Trace Macrocell Architecture Specification, ETMv4.*
