##### `0x83B7`, N4\_CACHE2\_HIT\_PRFM, Cache type 2 at distance 4 software prefetch hit

The counter counts each software prefetch counted by [N4\_CACHE\_HIT\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83A7--N4-CACHE-HIT-PRFM--Cache-at-distance-4--software-prefetch-hit?lang=en#event_n4_cache_hit_prfm) due to a software prefetch accessing a second cache type at distance 4.

The definition of cache types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
