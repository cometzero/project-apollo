##### `0x83B4`, N1\_CACHE2\_HIT\_PRFM, Cache type 2 at distance 1 software prefetch hit

The counter counts each software prefetch counted by [N1\_CACHE\_HIT\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83A4--N1-CACHE-HIT-PRFM--Cache-at-distance-1--software-prefetch-hit?lang=en#event_n1_cache_hit_prfm) due to a software prefetch accessing a second cache type at distance 1.

The definition of cache types in the system is IMPLEMENTATION DEFINED, but must be similar for all devices in the system.
