##### D24.4.60 TRCSSPCICR<n>, Trace Single-shot Processing Element Comparator Input Control Register <n>, n = 0 - 7

The TRCSSPCICR<n> characteristics are:

Purpose
:   Returns the status of the corresponding Single-shot Comparator Control.

Configuration
:   AArch64 System register TRCSSPCICR<n> bits [31:0] are architecturally mapped to External register [TRCSSPCICR<n>](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-3-External-trace-registers/-H9-3-69-TRCSSPCICR-n---Trace-Single-shot-Processing-Element-Comparator-Input-Control-Register--n---n---0---7?lang=en#reg_ext_trcsspcicrn)[31:0].

    This register is present only when FEAT\_ETE is implemented, System register access to the trace unit registers is implemented, and UInt(TRCIDR4.NUMPC) > 0. Otherwise, direct accesses to TRCSSPCICR<n> are UNDEFINED.

Attributes
:   TRCSSPCICR<n> is a 64-bit register.

###### Field descriptions

![](images/5211-D24.4.60-TRCSSPCICR-n-Trace-Single-shot-Processing-Element-Comparator-Input-Control-Register-n-n-0-7-img01.svg)

Bits [63:8]
:   Reserved, RES0.

PC[<m>] , bits [m], for m = 7 to 0
:   Selects one or more PE Comparator Inputs for Single-shot control.

    The reset behavior of this field is:

    - On a Trace unit reset, this field resets to an architecturally UNKNOWN value.

    Accessing this field has the following behavior:

    - When m >= UInt(TRCIDR4.NUMPC), access to this field is RES0.
    - When TRCSSCSR[m].PC != ‘1’, access to this field is RES0.

###### Accessing TRCSSPCICR<n>

Must be programmed if implemented and any [TRCRSCTLR<a>](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-53-TRCRSCTLR-n---Trace-Resource-Selection-Control-Register--n---n---2---31?lang=en#reg_aarch64_trcrsctlrn).GROUP == `0b0011` and [TRCRSCTLR<a>](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-53-TRCRSCTLR-n---Trace-Resource-Selection-Control-Register--n---n---2---31?lang=en#reg_aarch64_trcrsctlrn).SINGLE\_SHOT[n] == 1.

If the trace unit is not in the Idle state it is CONSTRAINED UNPREDICTABLE whether writes to this register are ignored.

Reads from this register might return an UNKNOWN value if the trace unit is not in either of the Idle or Stable states.

Accesses to this register use the following encodings in the System register encoding space:
