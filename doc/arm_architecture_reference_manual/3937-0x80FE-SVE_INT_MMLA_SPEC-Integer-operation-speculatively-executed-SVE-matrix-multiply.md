##### `0x80FE`, SVE\_INT\_MMLA\_SPEC, Integer operation speculatively executed, SVE matrix multiply

The counter counts each integer matrix multiply operation counted by [ASE\_SVE\_INT\_MMLA\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x80FF--ASE-SVE-INT-MMLA-SPEC--Integer-operation-speculatively-executed--Advanced-SIMD-or-SVE-matrix-multiply?lang=en#event_ase_sve_int_mmla_spec) due to any of the following instructions:

- SVE: SMMLA, UMMLA, or USMMLA.
