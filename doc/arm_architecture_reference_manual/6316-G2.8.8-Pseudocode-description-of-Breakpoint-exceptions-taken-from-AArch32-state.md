# ​G2.8.8 Pseudocode description of Breakpoint exceptions taken from AArch32 state

##### G2.8.8 Pseudocode description of Breakpoint exceptions taken from AArch32 state

[`AArch32_BreakpointValueMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-5-AArch32-BreakpointValueMatch?lang=en#asl_func_aarch32_breakpointvaluematch_3)`()` returns a pair of results:

- A result for Address Match and Context breakpoints.
- A result for Address Mismatch breakpoints.

[`AArch32_StateMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-7-AArch32-StateMatch?lang=en#asl_func_aarch32_statematch_7)`()` tests the values in [DBGBCR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-2-DBGBCR-n---Debug-Breakpoint-Control-Registers--n---0---15?lang=en#reg_aarch32_dbgbcrn).{SSC, HMC, PMC} and, if the breakpoint links to a Linked Context breakpoint, also tests the Linked Context breakpoint.

[`AArch32_BreakpointMatch`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-4-AArch32-BreakpointMatch?lang=en#asl_func_aarch32_breakpointmatch_4)`()` tests a committed instruction against all breakpoints.

[`AArch32_CheckBreakpoint`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-186-AArch32-CheckBreakpoint?lang=en#asl_func_aarch32_checkbreakpoint_4)`()` generates a [`FaultRecord`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-427-FaultRecord?lang=en#asl_type_faultrecord). A Breakpoint exception is taken if all of the following are true:

- [DBGDSCRext](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-14-DBGDSCRext--Debug-Status-and-Control-Register--External-View?lang=en#reg_aarch32_dbgdscrext).MDBGen is 1.
- Debug exceptions are enabled from the current Exception level and Security state. See [Enabling debug exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G2-AArch32-Self-hosted-Debug/-G2-3-The-debug-exception-enable-controls/-G2-3-1-Enabling-debug-exceptions?lang=en#beiecibb).
- All of the conditions required for Breakpoint exception generation are met. See [About Breakpoint exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G2-AArch32-Self-hosted-Debug/-G2-8-Breakpoint-exceptions/-G2-8-1-About-Breakpoint-exceptions?lang=en#bgbcjhdj).

> #### Note
>
> [`AArch32_CheckBreakpoint`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-186-AArch32-CheckBreakpoint?lang=en#asl_func_aarch32_checkbreakpoint_4)`()` might halt the PE and cause it to enter Debug state. External debug uses Debug state.

The [`AArch32_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-19-AArch32-Abort?lang=en#asl_func_aarch32_abort_1)`()` function processes the [`FaultRecord`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-427-FaultRecord?lang=en#asl_type_faultrecord) object returned by [`AArch32_CheckBreakpoint`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-186-AArch32-CheckBreakpoint?lang=en#asl_func_aarch32_checkbreakpoint_4)`()`, as described in [Abort exceptions](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G4-The-AArch32-System-Level-Memory-Model/-G4-8-Pseudocode-description-of-general-memory-System-instructions/-G4-8-7-Abort-exceptions?lang=en#beibdebj). When a Breakpoint exception is taken to AArch32 state, the [`AArch32_Abort`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-19-AArch32-Abort?lang=en#asl_func_aarch32_abort_1)`()` function generates a Prefetch Abort exception.
