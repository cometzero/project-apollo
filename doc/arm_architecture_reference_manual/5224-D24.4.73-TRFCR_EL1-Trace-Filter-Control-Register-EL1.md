# ​D24.4.73 TRFCR_EL1, Trace Filter Control Register (EL1)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-73-TRFCR-EL1--Trace-Filter-Control-Register--EL1->

##### D24.4.73 TRFCR\_EL1, Trace Filter Control Register (EL1)

The TRFCR\_EL1 characteristics are:

Purpose
:   Provides EL1 controls for Trace.

Configuration
:   AArch64 System register TRFCR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [TRFCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-37-TRFCR--Trace-Filter-Control-Register?lang=en#reg_aarch32_trfcr)[31:0].

    This register is present only when FEAT\_TRF is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to TRFCR\_EL1 are UNDEFINED.

Attributes
:   TRFCR\_EL1 is a 64-bit register.

###### Field descriptions

![](images/5224-D24.4.73-TRFCR_EL1-Trace-Filter-Control-Register-EL1-img01.svg)

Bits [63:12]
:   Reserved, RES0.

DnVM, bit [11]
:   When FEAT\_TRBEv1p1 is implemented and FEAT\_NV is implemented:
    :   Reserved for software use in nested virtualization. See also [TRFCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-4-Trace-registers/-D24-4-74-TRFCR-EL2--Trace-Filter-Control-Register--EL2-?lang=en#reg_aarch64_trfcr_el2).DnVM.

        The reset behavior of this field is:

        - On a Warm reset, this field resets to an architecturally UNKNOWN value.

    Otherwise:
    :   Reserved, RES0.

KE, bit [10]
:   When FEAT\_TRBE\_EXC is implemented:
    :   Kernel exception enable for TRBE Profiling exceptions taken to EL1.
