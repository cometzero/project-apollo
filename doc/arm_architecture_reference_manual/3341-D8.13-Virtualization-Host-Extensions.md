# ​D8.13 Virtualization Host Extensions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-13-Virtualization-Host-Extensions>

#### D8.13 Virtualization Host Extensions

I QJTJN
:   Virtualization Host Extensions provide enhanced support for a Type 2 virtualization solution, where there is a Host OS that is either more privileged than the hypervisor or is the hypervisor.

R SJSDF
:   All statements in this chapter require implementation of [FEAT\_VHE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-2-The-Armv8-1-architecture-extension?lang=en#feat_feat_vhe).

R CSTLG
:   If and only if an implementation includes EL2 using AArch64, then Virtualization Host Extensions, [FEAT\_VHE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-2-The-Armv8-1-architecture-extension?lang=en#feat_feat_vhe), can apply.

R GNLPT
:   [FEAT\_VHE](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-2-The-Armv8-1-architecture-extension?lang=en#feat_feat_vhe) adds all of the following state:

    - The [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H configuration bit.
    - The [CONTEXTIDR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-34-CONTEXTIDR-EL2--Context-ID-Register--EL2-?lang=en#reg_aarch64_contextidr_el2) register, which has the same format and contents as the [CONTEXTIDR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-33-CONTEXTIDR-EL1--Context-ID-Register--EL1-?lang=en#reg_aarch64_contextidr_el1) register.
    - The [TTBR1\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-212-TTBR1-EL2--Translation-Table-Base-Register-1--EL2-?lang=en#reg_aarch64_ttbr1_el2) register, which has the same format and contents as the [TTBR1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-211-TTBR1-EL1--Translation-Table-Base-Register-1--EL1-?lang=en#reg_aarch64_ttbr1_el1) register.
    - The [CNTHV\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-12-CNTHV-CTL-EL2--Counter-timer-Virtual-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthv_ctl_el2), [CNTHV\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-13-CNTHV-CVAL-EL2--Counter-timer-Virtual-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthv_cval_el2), and [CNTHV\_TVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-14-CNTHV-TVAL-EL2--Counter-timer-Virtual-Timer-TimerValue-Register--EL2-?lang=en#reg_aarch64_cnthv_tval_el2) registers, which have the same format and contents as the [CNTV\_CTL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-28-CNTV-CTL-EL0--Counter-timer-Virtual-Timer-Control-Register?lang=en#reg_aarch64_cntv_ctl_el0), [CNTV\_CVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-29-CNTV-CVAL-EL0--Counter-timer-Virtual-Timer-CompareValue-Register?lang=en#reg_aarch64_cntv_cval_el0), and [CNTV\_TVAL\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-30-CNTV-TVAL-EL0--Counter-timer-Virtual-Timer-TimerValue-Register?lang=en#reg_aarch64_cntv_tval_el0) registers, respectively.
    - An EL2 virtual timer with all of the following properties:

      - It is accessed using the [CNTHV\_CTL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-12-CNTHV-CTL-EL2--Counter-timer-Virtual-Timer-Control-Register--EL2-?lang=en#reg_aarch64_cnthv_ctl_el2), [CNTHV\_CVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-13-CNTHV-CVAL-EL2--Counter-timer-Virtual-Timer-CompareValue-Register--EL2-?lang=en#reg_aarch64_cnthv_cval_el2), and [CNTHV\_TVAL\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-14-CNTHV-TVAL-EL2--Counter-timer-Virtual-Timer-TimerValue-Register--EL2-?lang=en#reg_aarch64_cnthv_tval_el2) registers.
      - The virtual offset is treated as 0.
