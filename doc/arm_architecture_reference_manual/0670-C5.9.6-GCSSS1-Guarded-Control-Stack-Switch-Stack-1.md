# ​C5.9.6 GCSSS1, Guarded Control Stack Switch Stack 1

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-9-A64-System-instructions-for-the-Guarded-Control-Stack/-C5-9-6-GCSSS1--Guarded-Control-Stack-Switch-Stack-1>

##### C5.9.6 GCSSS1, Guarded Control Stack Switch Stack 1

The GCSSS1 characteristics are:

Purpose
:   Validates that the stack being switched to contains a Valid GCS cap record, stores an In-progress GCS cap record on to the stack that is getting switched to and sets the current GCS pointer register to the stack that is getting switched to.

Configuration
:   This system instruction is present only when FEAT\_GCS is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to GCSSS1 are UNDEFINED.

Attributes
:   GCSSS1 is a 64-bit System instruction.

###### Field descriptions

![](images/0670-C5.9.6-GCSSS1-Guarded-Control-Stack-Switch-Stack-1-img01.svg)

IA, bits [63:0]
:   Incoming address, for the incoming Guarded Control Stack.

###### Executing GCSSS1

This system instruction is an alias of the SYS instruction.

Accesses to this instruction use the following encodings in the System instruction encoding space:
