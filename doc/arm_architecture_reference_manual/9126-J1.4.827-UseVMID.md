##### J1.4.827 UseVMID

```
// UseVMID()
// =========
// Determine whether the translation context for the access requires VMID to match a TLB entry
func UseVMID(regime : Regime) => boolean
begin
    return regime == Regime_EL10 && EL2Enabled();
end;
```
