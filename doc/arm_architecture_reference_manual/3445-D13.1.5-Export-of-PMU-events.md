Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-1-About-the-Performance-Monitors/-D13-1-5-Export-of-PMU-events>

##### D13.1.5 Export of PMU events

It is IMPLEMENTATION DEFINED whether the implementation exports counter events to any other external monitoring agent to provide triggering information. The form of any exporting is also IMPLEMENTATION DEFINED. If implemented, this exporting is controlled by [PMCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-9-PMCR--Performance-Monitors-Control-Register?lang=en#reg_aarch32_pmcr).X.
