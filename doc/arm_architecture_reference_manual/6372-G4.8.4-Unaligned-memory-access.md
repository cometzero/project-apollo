##### G4.8.4 Unaligned memory access

See [Unaligned data access](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-6-Alignment-support/-E2-6-2-Unaligned-data-access?lang=en#chdijihg) for details of the [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).A and [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).A controls on the generation of alignment faults. The [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr) control applies to Normal memory accesses from Hyp mode, and the [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr) control applies to Normal memory accesses from all other modes.

The [`Mem_with_type`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-110-Mem-with-type?lang=en#asl_accessor_mem_with_type_3)`()` functions make an access of the required type. If that access is naturally aligned, each form of the function performs an atomic access by making a single call to [`AArch32_MemSingle`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-98-AArch32-MemSingle?lang=en#asl_accessor_aarch32_memsingle_4)`()`. If that access is not aligned but passes the [`IsAlignedSize`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-1-Standard-library?lang=en#asl_standard_library_isalignedsize)`()` checks, each form of the function synthesizes the required access from multiple calls to [`AArch32_MemSingle`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-3-Pseudocode-for-AArch32-operation/-J1-3-98-AArch32-MemSingle?lang=en#asl_accessor_aarch32_memsingle_4)`()`. It also reverses the byte order if the access is big-endian.
