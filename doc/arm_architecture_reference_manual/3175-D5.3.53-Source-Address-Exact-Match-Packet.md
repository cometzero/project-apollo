##### D5.3.53 Source Address Exact Match Packet

Purpose
:   Indicates the source address of a *P0 instruction*, and that the instruction was taken.

Configurations
:   All.

###### Field descriptions

QE
:   Instruction virtual address.

    The encoding for this field is POD.
