# ​F5.1.183 SETEND

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-183-SETEND>

##### F5.1.183 SETEND

Set Endianness writes a new value to [PSTATE](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G1-The-AArch32-System-Level-Programmers--Model/-G1-11-Process-state--PSTATE?lang=en#chdedfdc).E.

It has encodings from the following instruction sets: A32 ([A1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-183-SETEND?lang=en#isa_setend_iclass_a1)) and T32 ([T1](/documentation/ddi0487/mc/-Part-F-The-AArch32-Instruction-Sets/-Chapter-F5-T32-and-A32-Base-Instruction-Set-Instruction-Descriptions/-F5-1-Alphabetical-list-of-T32-and-A32-base-instruction-set-instructions/-F5-1-183-SETEND?lang=en#isa_setend_iclass_t1)).

###### A1

![](images/5800-F5.1.183-SETEND-img01.svg)

###### Encoding

```
SETEND{<q>}  <endian_specifier> // (Cannot be conditional)
```

###### Decode for this encoding

```
let set_bigend : boolean = (E == ‘1’);
```

###### T1

![](images/5800-F5.1.183-SETEND-img02.svg)

###### Encoding

```
SETEND{<q>}  <endian_specifier> // (Not permitted in IT block)
```

###### Decode for this encoding

```
let set_bigend : boolean = (E == ‘1’);
if InITBlock() then UnpredictableProcedure(); end;
```

For more information about the CONSTRAINED UNPREDICTABLE behavior of this instruction, see [Architectural Constraints on UNPREDICTABLE behaviors](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K1-Architectural-Constraints-on-UNPREDICTABLE-Behaviors?lang=en#cjaegdjc).
