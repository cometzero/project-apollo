# ​C6.2.158 ERETAA, ERETAB

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-158-ERETAA--ERETAB>

##### C6.2.158 ERETAA, ERETAB

Exception return, with pointer authentication

This instruction authenticates the address in ELR, using SP as the modifier and the specified key, restores [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate) from the SPSR for the current Exception level, and branches to the authenticated address.

Key A is used for `ERETAA`. Key B is used for `ERETAB`.

If the authentication passes, the PE continues execution at the target of the branch. For information on behavior if the authentication fails, see [Faulting on pointer authentication](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D8-The-AArch64-Virtual-Memory-System-Architecture/-D8-10-Pointer-authentication/-D8-10-5-Faulting-on-pointer-authentication?lang=en#mdsec_faulting_on_pointer_authentication).

The authenticated address is not written back to ELR.

The SPSR is checked for the current Exception level for an illegal return event. See [Illegal exception returns from AArch64 state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-4-Exceptions/-D1-4-4-Exception-return?lang=en#mdsec_illegal_exception_returns_from_aarch64_state).

`ERETAA` and `ERETAB` are UNDEFINED at EL0.

###### Decode for all variants of this encoding

```
if !IsFeatureImplemented(FEAT_PAuth) then EndOfDecode(Decode_UNDEF); end;
let pac : boolean = TRUE;
let use_key_a : boolean = (M == ‘0’);
let auth_then_branch : boolean = TRUE;
```

###### Operation

```
if PSTATE.EL == EL0 then Undefined(); end;
AArch64_CheckForERetTrap(pac, use_key_a);
var target : bits(64) = ELR_ELx();
let modifier : bits(64) = SP{}();
if use_key_a then
    target = AuthIA(target, modifier, auth_then_branch);
else
    target = AuthIB(target, modifier, auth_then_branch);
end;
AArch64_ExceptionReturn(target, SPSR_ELx());
```
