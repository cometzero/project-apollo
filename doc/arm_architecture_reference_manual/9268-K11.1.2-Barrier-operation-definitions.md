##### K11.1.2 Barrier operation definitions

:   See [Data Memory Barrier](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-2-Data-Memory-Barrier?lang=en#beiiecbh).

:   See [Data Synchronization Barrier](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-9-Data-Synchronization-Barrier?lang=en#beicefjh).

ISB
:   See [Instruction Synchronization Barrier](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-6-Memory-barriers/-B2-6-1-Instruction-Synchronization-Barrier?lang=en#beijadjc).

Observer, Completion
:   See [Ordering requirements defined by the formal concurrency model](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-3-Ordering-requirements-defined-by-the-formal-concurrency-model?lang=en#beifddeh).

    See [Completion and endpoint ordering](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B2-The-AArch64-Application-Level-Memory-Model/-B2-4-Additional-ordering-requirements-outside-of-the-scope-of-the-formal-concurrency-model/-B2-4-1-Completion-and-endpoint-ordering?lang=en#beibhdaa).

Program order
:   The order of instructions as they appear in an assembly language program. This appendix does not attempt to describe or define the legal transformations from a program written in a higher-level programming language, such as C or C++, into the machine language that can then be disassembled to give an equivalent assembly language program. Such transformations are a function of the semantics of the higher-level language and the capabilities and options on the compiler.
