# ​C3.10.33 Multi-vector predication

##### C3.10.33 Multi-vector predication

Multi-vector predication is required when using the [Contiguous multi-vector loads and stores](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-4-Loads-and-stores---SME--SME2--SVE2p1/-C3-4-2-Contiguous-multi-vector-loads-and-stores?lang=en#babiceghj5), and also reduces the number of predicate registers and predicate calculations in a loop.

The `WHILE` instructions generate a predicate-as-counter encoding. These instructions have an operand that indicates the number of vectors (2 or 4) to be controlled by this predicate, which determines:

- The maximum value that can be stored in the count.
- The number of elements that are considered *Active* when calculating the *Any Active element* and *Last Active element* SVE condition flags.

`CNTP` has an operand that indicates the limit of the number of elements to be counted. The limit corresponds to the total number of elements in either 2 or 4 vectors.

For more information, see [Predicate-as-counter](/documentation/ddi0487/mc/-Part-B-The-AArch64-Application-Level-Architecture/-Chapter-B1-The-AArch64-Application-Level-Programmers--Model/-B1-4-The-Scalable-Vector-and-Scalable-Matrix-Extensions--SVE---SME-/-B1-4-5-Vector-predication?lang=en#beifbhfcb3).
