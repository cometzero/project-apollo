# ​C6.2.316 PRFM (literal)

##### C6.2.316 PRFM (literal)

Prefetch memory (literal)

This instruction signals to the memory system that memory accesses to a location are likely to occur soon. The memory system can respond by taking actions that are expected to speed up the memory access when it does occur, such as making the cache line containing the specified address available at the level of cache specified by the instruction.

The address for memory accesses is calculated from the PC value and an immediate offset.

The `<prfop>` operand specifies the prefetch hint as follows:

- Access type:
  - PLD for prefetch for load.
  - PLI for prefetch for execute.
  - PST for prefetch for store.
- Target cache level:
  - L1 for Level 1 cache.
  - L2 for Level 2 cache.
  - L3 for Level 3 cache.
  - When FEAT\_PRFMSLC is implemented, SLC for system level cache.
- Policy:
  - KEEP for retained or temporal prefetch, allocated in the cache normally.
  - STRM for streaming or non-temporal prefetch, for data that is used only once.

The effect of a `PRFM` instruction is IMPLEMENTATION DEFINED. For more information, see [Prefetch memory](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C3-A64-Instruction-Set-Overview/-C3-2-Loads-and-stores/-C3-2-16-Prefetch-memory?lang=en#cegggide).

For information about addressing modes, see [Load/Store addressing modes](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C1-The-A64-Instruction-Set/-C1-3-Address-generation/-C1-3-3-Load-store-addressing-modes?lang=en#chdiiibb).

###### Encoding

```
PRFM  (<prfop>|#<imm5>), <label>
```

###### Decode for this encoding

```
let t : integer = UInt(Rt);
let offset : bits(64) = SignExtend{}(imm19::‘00’);
```

    For other encodings of the “Rt” field, use <imm5>.

<imm5>
:   ​

    Is the prefetch operation encoding as an immediate, in the range 0 to 31, encoded in the “Rt” field.

    This syntax is only for encodings that are not accessible using `<prfop>`.

<label>
:   ​

    Is the program label from which the data is to be loaded. Its offset from the address of this instruction, in the range +/-1MB, is encoded as “imm19” times 4.

###### Operation

```
let address : bits(64) = PC64() + offset;
let supports_ir : boolean = FALSE;
Prefetch(address, t[4:0], supports_ir);
```
