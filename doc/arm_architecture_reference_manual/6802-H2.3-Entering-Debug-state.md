# ​H2.3 Entering Debug state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-3-Entering-Debug-state>

#### H2.3 Entering Debug state

On entry to Debug state, the preferred restart address and [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate) are saved in [DLR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babjjiaj) and [DSPSR](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-1-Register-name-disambiguation-by-Execution-state?lang=en#babccghh). The PE remains in the mode and Security state from which it entered Debug state.

If [EDRCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-47-EDRCR--External-Debug-Reserve-Control-Register?lang=en#reg_ext_edrcr).CBRRQ has a value of 0, entry to Debug state is precise. If [EDRCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-47-EDRCR--External-Debug-Reserve-Control-Register?lang=en#reg_ext_edrcr).CBRRQ has a value of 1, then imprecise entry to Debug state is permitted.

If a Watchpoint debug event causes an entry to Debug state, the PE records all of the following:

- When [FEAT\_EDHSR](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_edhsr) is not implemented or the PE sets [EDHSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-30-EDHSR--External-Debug-Halting-Syndrome-Register?lang=en#reg_ext_edhsr).FnV to 0, the address of the access that generated the Watchpoint debug event is recorded in [EDWAR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-51-EDWAR--External-Debug-Watchpoint-Address-Register?lang=en#reg_ext_edwar).
- When [FEAT\_EDHSR](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_edhsr) is implemented, information about the access that generated the Watchpoint debug event is recorded in [EDHSR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-30-EDHSR--External-Debug-Halting-Syndrome-Register?lang=en#reg_ext_edhsr).

For more information, see:

- [Exception syndrome information, fault address information, and preferred return address](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D2-AArch64-Self-hosted-Debug/-D2-9-Watchpoint-exceptions/-D2-9-8-Exception-syndrome-information--fault-address-information--and-preferred-return-address?lang=en#bcgcfdcg) for a debug event taken from AArch64 state.
- [Exception syndrome information, fault address information, and preferred return address](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G2-AArch32-Self-hosted-Debug/-G2-9-Watchpoint-exceptions/-G2-9-7-Exception-syndrome-information--fault-address-information--and-preferred-return-address?lang=en#bcgdjedc) for a debug event taken from AArch32 state.

Other than the effect on [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate) and [EDSCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-48-EDSCR--External-Debug-Status-and-Control-Register?lang=en#reg_ext_edscr), entry to Debug state is not a [Context Synchronization event](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#babdjfhg). The effects of entry to Debug state on [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate) and [EDSCR](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H9-External-Debug-Register-Descriptions/-H9-2-External-debug-registers/-H9-2-48-EDSCR--External-Debug-Status-and-Control-Register?lang=en#reg_ext_edscr) are synchronized.
