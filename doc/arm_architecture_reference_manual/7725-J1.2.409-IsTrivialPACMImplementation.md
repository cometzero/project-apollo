##### J1.2.409 IsTrivialPACMImplementation

```
// IsTrivialPACMImplementation()
// =============================
// Returns TRUE if the PE has a trivial implementation of PACM.
func IsTrivialPACMImplementation() => boolean
begin
    return (IsFeatureImplemented(FEAT_PACIMP) &&
              ImpDefBool(“Trivial PSTATE.PACM implementation”));
end;
```
