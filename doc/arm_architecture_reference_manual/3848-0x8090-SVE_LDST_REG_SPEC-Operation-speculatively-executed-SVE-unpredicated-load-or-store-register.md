##### `0x8090`, SVE\_LDST\_REG\_SPEC, Operation speculatively executed, SVE unpredicated load or store register

The counter counts each [speculatively executed](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacijece) SVE register load or store operation due to any of the following instructions:

- SVE: LDR or STR.
