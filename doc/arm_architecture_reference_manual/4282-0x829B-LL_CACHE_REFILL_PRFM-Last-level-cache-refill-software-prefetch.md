##### `0x829B`, LL\_CACHE\_REFILL\_PRFM, Last level cache refill, software prefetch

The counter counts each access counted by [LL\_CACHE\_PRFM](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8299--LL-CACHE-PRFM--Last-level-cache-software-prefetch?lang=en#event_ll_cache_prfm) that causes a refill of the Last level cache, or any other data, instruction, or unified cache of this PE, from outside of those caches.
