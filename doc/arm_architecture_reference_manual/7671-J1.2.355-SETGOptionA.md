##### J1.2.355 SETGOptionA

```
// SETGOptionA()
// =============
// Returns TRUE if the implementation uses Option A for the
// SETG* instructions, and FALSE otherwise.
func SETGOptionA() => boolean
begin
    return ImpDefBool(“SETG* instructions use Option A”);
end;
```
