# ​D11.3.1 Procedure call and return instructions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns/-D11-3-1-Procedure-call-and-return-instructions>

##### D11.3.1 Procedure call and return instructions

G PYLXG
:   [FEAT\_GCS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-3-Armv9-A-architecture-extensions/-A2-3-5-The-Armv9-4-architecture-extension?lang=en#feat_feat_gcs) provides means to protect procedure return addresses without recompilation of functions or increasing the code footprint of functions.

R MXSDP
:   On executing any branch with link instruction, before branching to the target address, if the Guarded Control Stack is [PCR Enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack/-D11-2-1-Enabling-the-Guarded-Control-Stack?lang=en#mdterm_gcs_pcr_enabled) at the current Exception level then a [procedure return address push operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_procedure_return_address_push_operation) is generated. The data value for the store operation of the [procedure return address push operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_procedure_return_address_push_operation) is the value of LR which is created by the branch with link instruction.

R MMFFJ
:   The branch with link instructions are defined as:

    - [`BL`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-43-BL?lang=en#isa_bl).
    - [`BLR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-44-BLR?lang=en#isa_blr).
    - [`BLRAA, BLRAAZ, BLRAB, BLRABZ`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-45-BLRAA--BLRAAZ--BLRAB--BLRABZ?lang=en#isa_blra).

R QBJCD
:   On executing a procedure return instruction, before branching to the target address, if the Guarded Control Stack at the current Exception level is [PCR Enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-2-The-Guarded-Control-Stack/-D11-2-1-Enabling-the-Guarded-Control-Stack?lang=en#mdterm_gcs_pcr_enabled), one of the following operation is generated:

    - If the Guarded Control Stack at the current Exception level has [Return value checking enabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_return_value_checking_enabled), then a [procedure return address pop and compare operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_procedure_return_address_pop_compare_operation) is generated. The [procedure return address pop and compare operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_procedure_return_address_pop_compare_operation) has a lower priority than any authentication operation performed by the same instruction.
    - If the Guarded Control Stack at the current Exception level has [Return value checking disabled](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_gcs_return_value_checking_disabled), then a [procedure return address pop operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_procedure_return_address_pop_operation) is generated. The [procedure return address pop operation](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D11-The-Guarded-Control-Stack/-D11-3-Procedure-returns?lang=en#mdterm_procedure_return_address_pop_operation) has lower priority than any authentication operation performed by the same instruction. The popped value is used as the target address for branching to the next instruction.

R MRQPD
:   The procedure return instructions are defined as:

    - [`RET`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-338-RET?lang=en#isa_ret).
    - [`RETAA, RETAB`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-339-RETAA--RETAB?lang=en#isa_reta).
    - [`RETAASPPC, RETABSPPC`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-340-RETAASPPC--RETABSPPC?lang=en#isa_retasppc_imm).
    - [`RETAASPPCR, RETABSPPCR`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-341-RETAASPPCR--RETABSPPCR?lang=en#isa_retasppcr_reg).
