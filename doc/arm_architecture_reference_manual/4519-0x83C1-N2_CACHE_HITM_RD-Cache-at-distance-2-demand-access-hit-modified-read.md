##### `0x83C1`, N2\_CACHE\_HITM\_RD, Cache at distance 2, demand access hit modified, read

The counter counts each demand read counted by [N2\_CACHE\_HIT\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x83A1--N2-CACHE-HIT-RD--Cache-at-distance-2--demand-access-hit--read?lang=en#event_n2_cache_hit_rd) that accesses a previously modified location in a cache at distance 2.
