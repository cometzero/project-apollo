# ​D24.9.16 VDISR_EL2, Virtual Deferred Interrupt Status Register (EL2)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-16-VDISR-EL2--Virtual-Deferred-Interrupt-Status-Register--EL2->

##### D24.9.16 VDISR\_EL2, Virtual Deferred Interrupt Status Register (EL2)

The VDISR\_EL2 characteristics are:

Purpose
:   Records that a virtual SError exception has been consumed by an `ESB` instruction executed at EL1 or EL0.

    An indirect write to VDISR\_EL2 made by an `ESB` instruction does not require an explicit synchronization operation for the value written to be observed by a direct read of one of the following registers occurring in program order after the `ESB` instruction:

    - [DISR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-1-DISR-EL1--Deferred-Interrupt-Status-Register?lang=en#reg_aarch64_disr_el1).
    - [DISR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-1-DISR--Deferred-Interrupt-Status-Register?lang=en#reg_aarch32_disr).

Configuration
:   If EL2 is not implemented, this register is RES0 from EL3.

    This register has no effect if EL2 is not enabled in the current Security state.

    AArch64 System register VDISR\_EL2 bits [31:0] are architecturally mapped to AArch32 System register [VDISR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-20-VDISR--Virtual-Deferred-Interrupt-Status-Register?lang=en#reg_aarch32_vdisr)[31:0].

    This register is present only when FEAT\_RAS is implemented. Otherwise, direct accesses to VDISR\_EL2 are UNDEFINED.

Attributes
:   VDISR\_EL2 is a 64-bit register.

###### Accessing VDISR\_EL2

An indirect write to VDISR\_EL2 made by an `ESB` instruction does not require an explicit synchronization operation for the value that is written to be observed by a direct read of one of the following registers occurring in program order after the `ESB` instruction:

- [DISR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-9-RAS-registers/-D24-9-1-DISR-EL1--Deferred-Interrupt-Status-Register?lang=en#reg_aarch64_disr_el1).
- [DISR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-6-RAS-registers/-G8-6-1-DISR--Deferred-Interrupt-Status-Register?lang=en#reg_aarch32_disr).
