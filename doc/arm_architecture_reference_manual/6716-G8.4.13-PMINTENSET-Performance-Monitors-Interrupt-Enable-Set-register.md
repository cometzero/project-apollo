# ​G8.4.13 PMINTENSET, Performance Monitors Interrupt Enable Set register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-13-PMINTENSET--Performance-Monitors-Interrupt-Enable-Set-register>

##### G8.4.13 PMINTENSET, Performance Monitors Interrupt Enable Set register

The PMINTENSET characteristics are:

Purpose
:   Allows software to enable the generation of interrupt requests on overflows from the following counters:

    - The cycle counter [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr).
    - The event counters [PMEVCNTR<n>](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-10-PMEVCNTR-n---Performance-Monitors-Event-Count-Registers--n---0---30?lang=en#reg_aarch32_pmevcntrn).

    Reading from this register shows which overflow interrupt requests are enabled.

Configuration
:   AArch32 System register PMINTENSET bits [31:0] are architecturally mapped to AArch32 System register [PMINTENCLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-12-PMINTENCLR--Performance-Monitors-Interrupt-Enable-Clear-register?lang=en#reg_aarch32_pmintenclr)[31:0].

    AArch32 System register PMINTENSET bits [31:0] are architecturally mapped to AArch64 System register [PMINTENCLR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-16-PMINTENCLR-EL1--Performance-Monitors-Interrupt-Enable-Clear-Register?lang=en#reg_aarch64_pmintenclr_el1)[31:0].

    AArch32 System register PMINTENSET bits [31:0] are architecturally mapped to AArch64 System register [PMINTENSET\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-17-PMINTENSET-EL1--Performance-Monitors-Interrupt-Enable-Set-Register?lang=en#reg_aarch64_pmintenset_el1)[31:0].

    AArch32 System register PMINTENSET bits [31:0] are architecturally mapped to External register [PMINTENCLR\_EL1](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-38-PMINTENCLR-EL1--Performance-Monitors-Interrupt-Enable-Clear-Register?lang=en#reg_pmu_pmintenclr_el1)[31:0].

    AArch32 System register PMINTENSET bits [31:0] are architecturally mapped to External register [PMINTENSET\_EL1](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-39-PMINTENSET-EL1--Performance-Monitors-Interrupt-Enable-Set-Register?lang=en#reg_pmu_pmintenset_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented and FEAT\_PMUv3 is implemented. Otherwise, direct accesses to PMINTENSET are UNDEFINED.

Attributes
:   PMINTENSET is a 32-bit register.

###### Field descriptions

![](images/6716-G8.4.13-PMINTENSET-Performance-Monitors-Interrupt-Enable-Set-register-img01.svg)

C, bit [31]
:   Interrupt request or PMU Profiling exception on unsigned overflow of [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr) enable. On writes, allows software to enable the interrupt request or PMU Profiling exception on unsigned overflow of [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr). On reads, returns the interrupt request or PMU Profiling exception on unsigned overflow of [PMCCNTR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-4-Performance-Monitors-registers/-G8-4-2-PMCCNTR--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch32_pmccntr) enable status.

    The reset behavior of this field is:

    - On a Cold reset:
      - When FEAT\_PMUv3\_EXTPMN is implemented, this field resets to an architecturally UNKNOWN value.

      - When FEAT\_PMUv3\_EXTPMN is not implemented, this field resets to an architecturally UNKNOWN value.

    Access to this field is W1S.

    The reset behavior of this field is:

    - On a Cold reset:
      - When FEAT\_PMUv3\_EXTPMN is implemented, this field resets to an architecturally UNKNOWN value.
    - On a Warm reset:
      - When FEAT\_PMUv3\_EXTPMN is not implemented, this field resets to an architecturally UNKNOWN value.

    Accessing this field has the following behavior:

    - When m >= GetNumEventCountersAccessible(), access to this field is RAZ/WI.
    - Otherwise, access to this field is W1S.
