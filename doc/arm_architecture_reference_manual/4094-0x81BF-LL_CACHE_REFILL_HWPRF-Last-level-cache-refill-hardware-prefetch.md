##### `0x81BF`, LL\_CACHE\_REFILL\_HWPRF, Last level cache refill, hardware prefetch

The counter counts each hardware prefetch counted by [LL\_CACHE\_HWPRF](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8157--LL-CACHE-HWPRF--Last-level-cache-hardware-prefetch?lang=en#event_ll_cache_hwprf) that causes a refill of the Last level cache, or any other data, instruction, or unified cache of this PE, from outside of those caches.
