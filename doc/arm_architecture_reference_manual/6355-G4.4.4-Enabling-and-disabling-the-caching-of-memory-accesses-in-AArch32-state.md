# ​G4.4.4 Enabling and disabling the caching of memory accesses in AArch32 state

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G4-The-AArch32-System-Level-Memory-Model/-G4-4-AArch32-cache-and-branch-predictor-support/-G4-4-4-Enabling-and-disabling-the-caching-of-memory-accesses-in-AArch32-state>

##### G4.4.4 Enabling and disabling the caching of memory accesses in AArch32 state

Cacheability control fields can force all memory locations with the Normal memory type to be treated as Non-cacheable, regardless of their assigned Cacheability attribute. Independent controls are provided for each stage of address translation, with separate controls for:

- Data accesses. These controls also apply to accesses to the translation tables.
- Instruction accesses.

> #### Note
>
> These Cacheability controls replace the cache enable controls provided in previous versions of the Arm architecture.

In AArch32 state, the Cacheability control fields and their effects are as follows:

For the Non-secure PL1&0 translation regime
:   The Non-secure instance of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr) holds the EL1 controls that affect Cacheability:

    - When the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).C is 0:

      - All stage 1 translations for data accesses to Normal memory are Non-cacheable.
      - All accesses to the PL1&0 stage 1 translation tables are Non-cacheable.
    - When the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).I is 0:

      - All stage 1 translations for instruction accesses to Normal memory are Non-cacheable.
    - When the value of [HCR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-66-HCR2--Hyp-Configuration-Register-2?lang=en#reg_aarch32_hcr2).CD is 1:

      - All stage 2 translations for data accesses to Normal memory are Non-cacheable.
      - All accesses to the PL1&0 stage 2 translation tables are Non-cacheable.
    - When the value of [HCR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-66-HCR2--Hyp-Configuration-Register-2?lang=en#reg_aarch32_hcr2).ID is 1:

      - All stage 2 translations for instruction accesses to Normal memory are Non-cacheable.
    - When the value of [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).DC is 1, all Non-secure stage 1 translations and all accesses to the Non-secure EL1&0 stage 1 translation tables, are treated as accesses to Normal Non-shareable Inner Write-Back Cacheable Read-Allocate Write-Allocate, Outer Write-Back Cacheable Read-Allocate Write-Allocate memory, regardless of the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).C. This applies to translations for both data and instruction accesses.

    In addition, when the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).M is 0, indicating that the stage 1 translations are disabled for the translation regime, then if EL2 is using AArch32 and the value of [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).DC is 0 or if EL2 is using AArch64 and the value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).DC is 0, then:

    - If the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).I is 0, instruction accesses to Normal memory from stage 1 of the translation regime are Outer Shareable, Inner Non-cacheable, Outer Non-cacheable.
    - If the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).I is 1, instruction accesses to Normal memory from stage 1 of the translation regime are Outer Shareable, Inner Write-Through cacheable, Outer Write-Through cacheable.

    > #### Note
    >
    > - In Non-secure state, the stage 1 and stage 2 Cacheability attributes are combined as described in [Combining the Cacheability attribute](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G5-The-AArch32-Virtual-Memory-System-Architecture/-G5-7-Memory-region-attributes/-G5-7-5-EL2-control-of-Non-secure-memory-region-attributes?lang=en#chdbcgfa).
    > - The Non-secure [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).{C, I} and [HCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-65-HCR--Hyp-Configuration-Register?lang=en#reg_aarch32_hcr).DC fields have no effect on the Secure PL1&0 and EL2 translation regimes.
    > - The [HCR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-66-HCR2--Hyp-Configuration-Register-2?lang=en#reg_aarch32_hcr2).{ID, CD} fields affect only stage 2 of the Non-secure PL1&0 translation regime.
    > - In Non-secure state, the PL1&0 translation regime can be described as the Non-secure EL1&0 translation regime. This is consistent with the equivalent AArch64 descriptions.
    > - When [FEAT\_XS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_xs) is implemented [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).{C, I} and [HCR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-66-HCR2--Hyp-Configuration-Register-2?lang=en#reg_aarch32_hcr2).{ID, CD} fields have no effect on the value of the XS attribute.

For the Secure PL1&0 translation regime
:   The Secure instance of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr) holds the controls that determine Cacheability:

    - When the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).C is 0:

      - All data accesses to Normal memory using the Secure PL1&0 translation regime are Non-cacheable.
      - All accesses to the Secure PL1&0 translation tables are Non-cacheable.
    - When the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).I is 0:

      - All instruction accesses to Normal memory using the Secure PL1&0 translation regime are Non-cacheable.

    In addition, when the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).M is 0, indicating that stage 1 translations are disabled, then:

    - If the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).I is 0, instruction accesses to Normal memory from stage 1 of the translation regime are Outer Shareable, Inner Non-cacheable, Outer Non-cacheable.
    - If the value of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).I is 1, instruction accesses to Normal memory from stage 1 of the translation regime are Outer Shareable, Inner Write-Through cacheable, Outer Write-Through cacheable.

    > #### Note
    >
    > - The Secure [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).{I, C, M} fields have no effect on the Non-secure PL1&0 and EL2 translation regimes.
    > - When [FEAT\_XS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_xs) is implemented, the [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).{I, C} fields have no effect on the value of the XS attribute.

For the EL2 translation regime
:   - When the value of [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).C is 0:

      - All data accesses to Normal memory using the EL2 translation regime are Non-cacheable.
      - All accesses to the EL2 translation tables are Non-cacheable.
    - When the value of [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).I is 0:

      - All instruction accesses to Normal memory using the EL2 translation regime are Non-cacheable.

    In addition, when the value of [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).M is 0, indicating that stage 1 translations are disabled, then:

    - If the value of [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).I is 0, instruction accesses to Normal memory from stage 1 of the translation regime are Outer Shareable, Inner Non-cacheable, Outer Non-cacheable.
    - If the value of [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).I is 1, instruction accesses to Normal memory from stage 1 of the translation regime are Outer Shareable, Inner Write-Through cacheable, Outer Write-Through cacheable.

    > #### Note
    >
    > - The [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).{I, C, M} fields have no effect on the PL1&0 and EL3 translation regimes.
    > - When [FEAT\_XS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-8-The-Armv8-7-architecture-extension?lang=en#feat_feat_xs) is implemented, the [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).{I, C} fields have no effect on the value of the XS attribute.

The effect of the [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).C or [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).C and [HCR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-66-HCR2--Hyp-Configuration-Register-2?lang=en#reg_aarch32_hcr2).CD bits is reflected in the result of the address translation instructions in the PAR.

> #### Note
>
> - The requirements in this section mean the architecturally required effects of [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr).I and [HSCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-73-HSCTLR--Hyp-System-Control-Register?lang=en#reg_aarch32_hsctlr).I are limited to their effects on caching instruction accesses in unified caches.
> - This specification can give rise to different Cacheability attributes between instruction and data accesses to the same location. Where this occurs, the measures for mismatch memory attributes described in [Mismatched memory attributes](/documentation/ddi0487/mc/-Part-E-The-AArch32-Application-Level-Architecture/-Chapter-E2-The-AArch32-Application-Level-Memory-Model/-E2-9-Mismatched-memory-attributes?lang=en#cegddhaj) must be followed to manage the corresponding loss of coherency.
