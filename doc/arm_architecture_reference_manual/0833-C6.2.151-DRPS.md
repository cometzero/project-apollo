##### C6.2.151 DRPS

Debug restore PE state

This instruction restores [PSTATE](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-5-Process-state--PSTATE?lang=en#pstate) from the SPSR.

The SPSR is checked for the current Exception level for an illegal return event. See [Illegal exception returns from AArch64 state](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D1-The-AArch64-System-Level-Programmers--Model/-D1-4-Exceptions/-D1-4-4-Exception-return?lang=en#mdsec_illegal_exception_returns_from_aarch64_state).

This instruction is UNDEFINED in Non-debug state.

This instruction is UNDEFINED at EL0.

For more information on the operation of `DRPS`, see [DRPS](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-4-Behavior-in-Debug-state/-H2-4-6-Debug-state-operations--DCPS--DRPS--MRS--MSR?lang=en#babggbhh).
