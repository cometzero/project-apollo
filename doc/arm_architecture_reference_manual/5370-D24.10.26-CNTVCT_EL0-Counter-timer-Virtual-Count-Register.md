# ​D24.10.26 CNTVCT_EL0, Counter-timer Virtual Count Register

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register>

##### D24.10.26 CNTVCT\_EL0, Counter-timer Virtual Count Register

The CNTVCT\_EL0 characteristics are:

Purpose
:   Reads of [CNTVCT\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-26-CNTVCT-EL0--Counter-timer-Virtual-Count-Register?lang=en#reg_aarch64_cntvct_el0) return the 64-bit physical count value minus a virtual offset.

Configuration
:   All reads to the CNTVCT\_EL0 occur in program order relative to reads to [CNTVCTSS\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-10-Generic-Timer-registers/-D24-10-25-CNTVCTSS-EL0--Counter-timer-Self-Synchronized-Virtual-Count-Register?lang=en#reg_aarch64_cntvctss_el0) or CNTVCT\_EL0.

    AArch64 System register CNTVCT\_EL0 bits [63:0] are architecturally mapped to AArch32 System register [CNTVCT](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-7-Generic-Timer-registers/-G8-7-24-CNTVCT--Counter-timer-Virtual-Count-register?lang=en#reg_aarch32_cntvct)[63:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to CNTVCT\_EL0 are UNDEFINED.

Attributes
:   CNTVCT\_EL0 is a 64-bit register.

###### Field descriptions

![](images/5370-D24.10.26-CNTVCT_EL0-Counter-timer-Virtual-Count-Register-img01.svg)

VirtualCount, bits [63:0]
:   Virtual count value.

    When EL2 is implemented, if the access is not trapped, and any of the following are true, then reads of CNTVCT\_EL0 from EL0 and EL1 return (PhysicalCountInt<63:0> - CNTVOFF\_EL2<63:0>):

    - All of the following are true:
      - The Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is not {1, 1}.
      - CNTVCT\_EL0 is read from EL0.
    - All of the following are true:
      - The Effective value of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 0.
      - CNTVCT\_EL0 is read from EL2.
    - CNTVCT\_EL0 is read from EL1 or EL3.

    Otherwise reads of CNTVCT\_EL0 return PhysicalCountInt<63:0>.

    PhysicalCountInt is defined by [‘The Physical Counter’](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D12-The-Generic-Timer-in-AArch64-state/-D12-2-The-AArch64-view-of-the-Generic-Timer/-D12-2-1-The-physical-counter?lang=en#cjaggeai).

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.
