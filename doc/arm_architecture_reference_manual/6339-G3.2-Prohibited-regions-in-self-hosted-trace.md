# ​G3.2 Prohibited regions in self-hosted trace

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-2-Prohibited-regions-in-self-hosted-trace>

#### G3.2 Prohibited regions in self-hosted trace

Trace is not generated in prohibited regions. The pseudocode function [`TraceAllowed`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-735-TraceAllowed?lang=en#asl_func_traceallowed_1)`()` indicates whether tracing is allowed in the current Security state and Exception level.

The IMPLEMENTATION DEFINED debug authentication interface can allow an external agent to disable the self-hosted trace extension.

If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), tracing is prohibited in Secure state when [SDCR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-3-Debug-System-registers/-G8-3-35-SDCR--Secure-Debug-Control-Register?lang=en#reg_aarch32_sdcr).STE == 0.

If self-hosted trace is [enabled](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G3-AArch32-Self-hosted-Trace/-G3-1-About-self-hosted-trace/-G3-1-2-Register-controls-to-enable-self-hosted-trace?lang=en#aa32_sh_trace_enabled), tracing is prohibited in Realm state when [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).RLTE == 0.
