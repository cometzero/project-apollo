##### `0x845C`, SME\_FP\_FP8\_MIN\_SPEC, SME data processing operation speculatively executed, smallest type is 8-bit floating-point

The counter counts each SME data-processing operation counted by [SE\_FP\_FP8\_MIN\_SPEC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8454--SE-FP-FP8-MIN-SPEC--Advanced-SIMD--SVE--or-SME-data-processing-operation-speculatively-executed--smallest-type-is-8-bit-floating-point?lang=en#event_se_fp_fp8_min_spec) due to an instruction where the smallest type was 8-bit floating-point.
