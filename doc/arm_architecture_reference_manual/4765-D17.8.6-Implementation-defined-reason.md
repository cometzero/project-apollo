##### D17.8.6 Implementation defined reason

An implementation might include support for generating Profiling Buffer events for IMPLEMENTATION DEFINED reasons. These should normally be disabled unless enabled by IMPLEMENTATION DEFINED controls. The [PMBSR\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#pmbsr_elx).EC code `0x1F` is reserved for this purpose.
