#### H2.2 Halting the PE on debug events

For details of debug events, see [Introduction to Halting debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-1-Introduction-to-Halting-debug-events?lang=en#babdcjgd) and [Breakpoint and Watchpoint debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-3-Breakpoint-and-Watchpoint-debug-events?lang=en#babjijfb).

On a debug event, the PE must do one of the following:

- Enter Debug state.
- Pend the debug event.
- Generate a debug exception.
- Ignore the debug event.

This behavior depends on both:

- Whether halting is allowed by the current state of the debug authentication interface. See [Halting allowed and halting prohibited](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-1-Halting-allowed-and-halting-prohibited?lang=en#babiiffc).
- The type of debug event and the programming of the debug control registers.

  - See [Halting debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-2-Halting-debug-events?lang=en#babiidde) for all Halting debug events.
  - See [Breakpoint and Watchpoint debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-3-Breakpoint-and-Watchpoint-debug-events?lang=en#babjijfb) for Breakpoint and Watchpoint debug events.

See also [Other debug exceptions](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H2-Debug-State/-H2-2-Halting-the-PE-on-debug-events/-H2-2-4-Other-debug-exceptions?lang=en#babgjeei).

This means that behavior can be CONSTRAINED UNPREDICTABLE if the conditions change. See [Synchronization and Halting debug events](/documentation/ddi0487/mc/-Part-H-External-Debug/-Chapter-H3-Halting-Debug-Events/-H3-9-Synchronization-and-Halting-debug-events?lang=en#babgeeca).
