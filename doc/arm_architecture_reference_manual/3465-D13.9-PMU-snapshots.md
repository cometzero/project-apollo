# ​D13.9 PMU snapshots

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D13-The-Performance-Monitors-Extension/-D13-9-PMU-snapshots>

#### D13.9 PMU snapshots

I VZCDM
:   The PMU snapshot extension provides a mechanism to take a snapshot of the PMU state at a given cycle on request.

R SCLCQ
:   If all of the following are true, then a Capture event is generated:

    - [FEAT\_PMUv3\_SS](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_pmuv3_ss) is implemented.
    - Capture events are enabled.
    - Any of the following occur:

      - The value 1 is written to [PMSSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-22-PMSSCR-EL1--Performance-Monitors-Snapshot-Status-and-Capture-Register?lang=en#reg_aarch64_pmsscr_el1).SS.
      - The assertion of an IMPLEMENTATION DEFINED external snapshot request mechanism. This indirectly writes 1 to [PMSSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-22-PMSSCR-EL1--Performance-Monitors-Snapshot-Status-and-Capture-Register?lang=en#reg_aarch64_pmsscr_el1).SS.
    - The Core power domain is powered on.

R MFJWS
:   If Capture events are disabled, then [PMSSCR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-22-PMSSCR-EL1--Performance-Monitors-Snapshot-Status-and-Capture-Register?lang=en#reg_aarch64_pmsscr_el1).SS ignores writes.

R YWLFL
:   If any of the following are true, then Capture events are disabled:

    - EL3 is implemented and [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE is `0b00`.
    - All of the following are true:

      - EL3 is not implemented or [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE is `0b01`.
      - EL2 is implemented.
      - [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).PMSSE is `0b00`.

      This applies even when EL2 is disabled in the current Security state.
    - All of the following are true:

      - EL3 is not implemented or [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE is `0b01`.
      - EL2 is not implemented or [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).PMSSE is `0b01`. This applies even when EL2 is disabled in the current Security state.
      - [PMECR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-9-PMECR-EL1--Performance-Monitors-Extended-Control-Register--EL1-?lang=en#reg_aarch64_pmecr_el1).SSE is `0b00`.

    Otherwise, Capture events are enabled.

    The pseudocode function [`PMUCaptureEventEnabled`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-110-PMUCaptureEventEnabled?lang=en#asl_func_pmucaptureeventenabled_0)`()` shows this.

R TSYTY
:   If all of the following are true, then Capture events are allowed:

    - Capture events are enabled.
    - The OS Lock is unlocked.
    - Any of the following are true:

      - EL3 is implemented and [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE is `0b11`.
      - All of the following are true:

        - EL3 is not implemented or [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE is `0b01`.
        - EL2 is implemented.
        - [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).PMSSE is `0b11`.

        This applies even when EL2 is disabled in the current Security state.
      - All of the following are true:

        - EL3 is not implemented or [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE is `0b01`.
        - EL2 is not implemented or [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).PMSSE is `0b01`. This applies even when EL2 is disabled in the current Security state.
        - [PMECR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-9-PMECR-EL1--Performance-Monitors-Extended-Control-Register--EL1-?lang=en#reg_aarch64_pmecr_el1).SSE is `0b11`.
    - Either the PE is in Non-debug state or the PE allows Capture events in Debug state.

    Otherwise, Capture events are prohibited.

    It is IMPLEMENTATION DEFINED whether the PE allows Capture events in Debug state.

    The pseudocode function [`PMUCaptureEventAllowed`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-109-PMUCaptureEventAllowed?lang=en#asl_func_pmucaptureeventallowed_0)`()` shows this.

I WHYSQ
:   > #### Note
    >
    > When all of the following apply, an EL3 Secure or Root monitor switching to Secure state should set [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).PMSSE to `0b01`:
    >
    > - SCR\_EL3.EEL2 is 0, disabling EL2 in Secure state.
    > - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE is `0b01`, enabling use of PMU snapshot by lower Exception levels.
    > - [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).{MPMX, SPME} is not {0, 0}, meaning Secure state uses the PMU.
    >
    > This ensures that control over PMU snapshot moves to [PMECR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-9-PMECR-EL1--Performance-Monitors-Extended-Control-Register--EL1-?lang=en#reg_aarch64_pmecr_el1). In such a scenario, the EL3 monitor might have to rewrite other [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2) fields. For example setting [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).HPMN to PMCR\_EL0.N so that Secure EL1 has full control over the PMU counters. Alternatively, if Secure EL1 does not support PMU snapshot, then the EL3 monitor could set [MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).PMSSE or [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).PMSSE to `0b00`, and avoid also context switching [PMECR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-9-PMECR-EL1--Performance-Monitors-Extended-Control-Register--EL1-?lang=en#reg_aarch64_pmecr_el1).
    >
    > If Secure state is not using the PMU ([MDCR\_EL3](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-18-MDCR-EL3--Monitor-Debug-Configuration-Register--EL3-?lang=en#reg_aarch64_mdcr_el3).SPME is 0), then the EL3 monitor should leave [MDCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-3-Debug-System-registers/-D24-3-17-MDCR-EL2--Monitor-Debug-Configuration-Register--EL2-?lang=en#reg_aarch64_mdcr_el2).PMSSE and [PMECR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-9-PMECR-EL1--Performance-Monitors-Extended-Control-Register--EL1-?lang=en#reg_aarch64_pmecr_el1) unchanged, so that external snapshot requests can be serviced.

R VPZHN
:   If a Capture event occurs when allowed, then the PE writes all of the following snapshot registers:

    - Event counters [PMEVCNTR<n>\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-10-PMEVCNTR-n--EL0--Performance-Monitors-Event-Count-Registers--n---0---30?lang=en#reg_aarch64_pmevcntrn_el0) are written to [PMEVCNTSVR<n>\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-11-PMEVCNTSVR-n--EL1--Performance-Monitors-Event-Count-Saved-Value-Registers--n---0---30?lang=en#reg_aarch64_pmevcntsvrn_el1).
    - Cycle counter [PMCCNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-2-PMCCNTR-EL0--Performance-Monitors-Cycle-Count-Register?lang=en#reg_aarch64_pmccntr_el0) is written to [PMCCNTSVR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-3-PMCCNTSVR-EL1--Performance-Monitors-Cycle-Count-Saved-Value-Register?lang=en#reg_aarch64_pmccntsvr_el1).
    - If [FEAT\_PMUv3\_ICNTR](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_pmuv3_icntr) is implemented, instruction counter [PMICNTR\_EL0](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-14-PMICNTR-EL0--Performance-Monitors-Instruction-Counter-Register?lang=en#reg_aarch64_pmicntr_el0) is written to [PMICNTSVR\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-5-Performance-Monitors-registers/-D24-5-15-PMICNTSVR-EL1--Performance-Monitors-Instruction-Count-Saved-Value-Register?lang=en#reg_aarch64_pmicntsvr_el1).
    - If [FEAT\_PCSRv8p9](/documentation/ddi0487/mc/-Part-A-Arm-Architecture-Introduction-and-Overview/-Chapter-A2-A-profile-Architecture-Extensions/-A2-2-Armv8-A-architecture-extensions/-A2-2-10-The-Armv8-9-architecture-extension?lang=en#feat_feat_pcsrv8p9) is implemented and sampling on PMU snapshot Capture events is enabled by [PMPCSCTL](/documentation/ddi0487/mc/-Part-I-Memory-mapped-Components-of-the-Arm-Architecture/-Chapter-I5-External-System-Control-Register-Descriptions/-I5-3-Performance-Monitors-external-register-descriptions/-I5-3-47-PMPCSCTL--PC-Sample-based-Profiling-Control-Register?lang=en#reg_pmu_pmpcsctl).SS, then all of the following:

      - If PC sampling is allowed and the PE is in Non-debug state, then all of the following:

    >     ; Test PMSSCR_EL1.SS to check whether the Capture event has completed
