##### `0x8121`, MEM\_ACCESS\_RD\_PERCYC, Data memory reads in progress

The counter increments by the number of data memory reads counted by [MEM\_ACCESS\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0066--MEM-ACCESS-RD--Data-memory-access--read?lang=en#event_mem_access_rd) in progress on each [Processor cycle](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacgcfhh).

The ratio [MEM\_ACCESS\_RD\_PERCYC](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x8121--MEM-ACCESS-RD-PERCYC--Data-memory-reads-in-progress?lang=en#event_mem_access_rd_percyc) ÷ [MEM\_ACCESS\_RD](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-3-Common-event-numbers/-0x0066--MEM-ACCESS-RD--Data-memory-access--read?lang=en#event_mem_access_rd) is the mean duration of data memory reads in [Processor cycles](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D14-PMU-Event-Descriptions/-D14-1-Definitions/-D14-1-1-Definition-of-terms?lang=en#cacgcfhh).
