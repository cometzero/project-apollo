#### D11.8 GCS record for software use

I FVGLK

    - [`GCSPOPM`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-163-GCSPOPM?lang=en#isa_gcspopm_sysl).

    - [`GCSSS1`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-167-GCSSS1?lang=en#isa_gcsss1_sys).
    - [`GCSSS2`](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-168-GCSSS2?lang=en#isa_gcsss2_sysl).
