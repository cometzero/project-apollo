# ​G4.8.1 Memory data type definitions

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G4-The-AArch32-System-Level-Memory-Model/-G4-8-Pseudocode-description-of-general-memory-System-instructions/-G4-8-1-Memory-data-type-definitions>

##### G4.8.1 Memory data type definitions

This section lists the memory data types.

The memory data types are:

- Address descriptor, defined by the [`AddressDescriptor`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-801-AddressDescriptor?lang=en#asl_type_addressdescriptor) type.
- Full address, defined by the [`FullAddress`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-428-FullAddress?lang=en#asl_type_fulladdress) type.
- Memory attributes, defined by the [`MemoryAttributes`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-445-MemoryAttributes?lang=en#asl_type_memoryattributes) type.
- Memory type, defined by the [`MemType`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-443-MemType?lang=en#asl_type_memtype) enumeration.
- Device memory type, defined by the [`DeviceType`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-421-DeviceType?lang=en#asl_type_devicetype) enumeration.
- Normal memory attributes, defined by the [`MemAttrHints`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-441-MemAttrHints?lang=en#asl_type_memattrhints) type.
- Cacheability attributes, defined by the [`MemAttr_NC`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-383-Cacheability?lang=en#asl_global_memattr_nc), [`MemAttr_WT`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-383-Cacheability?lang=en#asl_global_memattr_wt), and [`MemAttr_WB`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-383-Cacheability?lang=en#asl_global_memattr_wb) constants.
- Allocation hints, defined by the [`MemHint_No`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-376-Allocation?lang=en#asl_global_memhint_no), [`MemHint_WA`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-376-Allocation?lang=en#asl_global_memhint_wa), [`MemHint_RA`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-376-Allocation?lang=en#asl_global_memhint_ra), and [`MemHint_RWA`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-376-Allocation?lang=en#asl_global_memhint_rwa) constants.
- Access permissions, defined by the [`Permissions`](/documentation/ddi0487/mc/-Part-J-Architectural-Pseudocode/-Chapter-J1-A-profile-Architecture-Pseudocode/-J1-4-Shared-pseudocode/-J1-4-448-Permissions?lang=en#asl_type_permissions) type.
