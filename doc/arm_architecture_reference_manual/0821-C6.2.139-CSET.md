# ​C6.2.139 CSET

##### C6.2.139 CSET

Conditional set

This instruction sets the destination register to 1 if the condition is TRUE, and otherwise sets it to 0.

This is an alias of [CSINC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-141-CSINC?lang=en#isa_csinc). This means:

- The encodings in this description are named to match the encodings of [CSINC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-141-CSINC?lang=en#isa_csinc).
- The description of [CSINC](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-141-CSINC?lang=en#isa_csinc) gives the operational pseudocode, any CONSTRAINED UNPREDICTABLE behavior, and any operational information for this instruction.

![](images/0821-C6.2.139-CSET-img01.svg)

###### Encoding for the 32-bit variant

Applies when `(sf == 0)`

```
CSET  <Wd>, <invcond>
```

is equivalent to

```
CSINC  <Wd>, WZR, WZR, <cond>
```

and is always the preferred disassembly.

###### Encoding for the 64-bit variant

Applies when `(sf == 1)`

```
CSET  <Xd>, <invcond>
```

is equivalent to

```
CSINC  <Xd>, XZR, XZR, <cond>
```

and is always the preferred disassembly.
