# ​D21.9.2 Behavior when a valid mapping does not exist for a PARTID that is treated as virtual

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-9-MPAM-errors/-D21-9-2-Behavior-when-a-valid-mapping-does-not-exist-for-a-PARTID-that-is-treated-as-virtual>

##### D21.9.2 Behavior when a valid mapping does not exist for a PARTID that is treated as virtual

R NHSJC
:   If a [PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-?lang=en#mpam_partition_identifiers) from an [MPAMn\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mpamn_elx).PARTID\_D or [MPAMn\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mpamn_elx).PARTID\_I field, or its replacement if that PARTID was *out-of-range*, is *treated as virtual*, and the corresponding [MPAMVPMV\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-23-MPAMVPMV-EL2--MPAM-Virtual-Partition-Mapping-Valid-Register?lang=en#reg_aarch64_mpamvpmv_el2).VPM\_V<m> valid flag indicates that a valid mapping does not exist, the mapping for the [Default virtual PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-/-D21-3-2-The-Default-PARTID?lang=en#mpam_default_partid) is used. If a valid mapping does not exist for the Default virtual PARTID, the [Default physical PARTID](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-/-D21-3-2-The-Default-PARTID?lang=en#mpam_default_partid) is sent.

I FYYSQ
:   See also:

    - [PARTID virtualization](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-/-D21-3-1-PARTID-virtualization?lang=en#mpam_partid_virtualization), for the definitions of *out-of-range* and *treated as virtual*.
