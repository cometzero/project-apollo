# ​C6.2.44 BLR

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C6-A64-Base-Instruction-Descriptions/-C6-2-Alphabetical-list-of-A64-base-instructions/-C6-2-44-BLR>

##### C6.2.44 BLR

Branch with link to register

This instruction calls a subroutine at an address in a register, setting register X30 to PC+4. This instruction provides a hint that this is a subroutine call.

![](images/0726-C6.2.44-BLR-img01.svg)

###### Encoding

```
BLR  <Xn>
```

###### Decode for this encoding

```
let n : integer{} = UInt(Rn);
```

###### Assembler Symbols

<Xn>
:   ​

    Is the 64-bit name of the general-purpose register holding the address to be branched to, encoded in the “Rn” field.

###### Operation

```
let target : bits(64) = X{}(n);
if IsFeatureImplemented(FEAT_GCS) && GCSPCREnabled(PSTATE.EL) then
    AddGCSRecord(PC64() + 4);
end;
// Value in BTypeNext will be used to set PSTATE.BTYPE
BTypeNext = ‘10’;
X{64}(30) = PC64() + 4;
let branch_conditional : boolean = FALSE;
BranchTo{64}(target, BranchType_INDCALL, branch_conditional);
```
