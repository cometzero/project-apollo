##### D24.2.174 SCTLR\_EL1, System Control Register (EL1)

The SCTLR\_EL1 characteristics are:

Purpose
:   Provides top-level control of the system, including its memory system, at EL1 and EL0.

Configuration
:   AArch64 System register SCTLR\_EL1 bits [31:0] are architecturally mapped to AArch32 System register [SCTLR](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-127-SCTLR--System-Control-Register?lang=en#reg_aarch32_sctlr)[31:0].

    This register is present only when FEAT\_AA64 is implemented. Otherwise, direct accesses to SCTLR\_EL1 are UNDEFINED.

Attributes
:   SCTLR\_EL1 is a 64-bit register.
