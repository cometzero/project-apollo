# ​J1.4.820 TGxGranuleBits

##### J1.4.820 TGxGranuleBits

```
// TGxGranuleBits()
// ================
// Retrieve the address size, in bits, of a granule
func TGxGranuleBits(tgx : TGx) => AddressSize
begin
    case tgx of
        when TGx_4KB =>  return 12;
        when TGx_16KB => return 14;
        when TGx_64KB => return 16;
    end;
end;
```
