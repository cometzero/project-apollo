# ​C5.2.18 SP_EL3, Stack Pointer (EL3)

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-18-SP-EL3--Stack-Pointer--EL3->

##### C5.2.18 SP\_EL3, Stack Pointer (EL3)

The SP\_EL3 characteristics are:

Purpose
:   Holds the stack pointer associated with EL3. The value of [SPSel](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-19-SPSel--Stack-Pointer-Select?lang=en#reg_aarch64_spsel).SP determines the current stack pointer.

Configuration
:   This register is a Special-purpose register.

    This register is present only when EL3 is implemented and FEAT\_AA64 is implemented. Otherwise, direct accesses to SP\_EL3 are UNDEFINED.

Attributes
:   SP\_EL3 is a 64-bit register.

###### Field descriptions

![](images/0435-C5.2.18-SP_EL3-Stack-Pointer-EL3-img01.svg)

StackPointer, bits [63:0]
:   Stack pointer.

    The reset behavior of this field is:

    - On a Warm reset, this field resets to an architecturally UNKNOWN value.

###### Accessing SP\_EL3

This register is not accessible using MRS and MSR instructions.

When the value of [SPSel](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-19-SPSel--Stack-Pointer-Select?lang=en#reg_aarch64_spsel).SP is 1, this register is accessible at EL3 as the current stack pointer.

> #### Note
>
> When the value of [SPSel](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-19-SPSel--Stack-Pointer-Select?lang=en#reg_aarch64_spsel).SP is 0, [SP\_EL0](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C5-The-A64-System-Instruction-Class/-C5-2-Special-purpose-registers/-C5-2-15-SP-EL0--Stack-Pointer--EL0-?lang=en#reg_aarch64_sp_el0) is used as the current stack pointer at all Exception levels.
