##### C8.2.795 TRN1, TRN2 (predicates)

Interleave even or odd elements from two predicates

This instruction interleaves alternating even or odd-numbered elements from the first and second source predicates, and places the values in the destination predicate. This instruction is unpredicated.

It has encodings from 2 classes: [Even](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-795-TRN1--TRN2--predicates-?lang=en#isa_trn1_p_pp_iclass_even) and [Odd](/documentation/ddi0487/mc/-Part-C-The-AArch64-Instruction-Set/-Chapter-C8-SVE-Instruction-Descriptions/-C8-2-Alphabetical-list-of-SVE-instructions/-C8-2-795-TRN1--TRN2--predicates-?lang=en#isa_trn1_p_pp_iclass_odd)

<Pn>
:   ​

    Is the name of the first source scalable predicate register, encoded in the “Pn” field.

:   ​

    Is the name of the second source scalable predicate register, encoded in the “Pm” field.

###### Operation

```
CheckSVEEnabled();
let VL : integer{} = CurrentVL();
let PL : integer{} = VL DIV 8;
let pairs : integer = VL DIV (esize * 2);
let operand1 : bits(PL) = P{}(n);
let operand2 : bits(PL) = P{}(m);
var result : bits(PL);
for p = 0 to pairs-1 do
    result[(2*p+0)*:(esize DIV 8)] = operand1[(2*p+part)*:(esize DIV 8)];
    result[(2*p+1)*:(esize DIV 8)] = operand2[(2*p+part)*:(esize DIV 8)];
end;
P{PL}(d) = result;
```
