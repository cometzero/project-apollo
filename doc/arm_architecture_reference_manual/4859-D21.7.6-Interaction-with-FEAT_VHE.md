I LVGCR
:   If the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H is 1, software executing at EL2 can use all of:

    - MPAM1\_EL12, to control [PARTIDs](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-3-Partition-Identifiers--PARTIDs-?lang=en#mpam_partition_identifiers) and [PMGs](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D21-MPAM-PE-Architecture/-D21-4-Performance-Monitoring-Groups--PMGs-?lang=en#mpam_pmg) for execution at EL1.
    - [MPAM1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-2-MPAM1-EL1--MPAM1-Register--EL1-?lang=en#reg_aarch64_mpam1_el1), to configure the MPAM controls that apply to execution at EL2.
    - MPAMBW1\_EL12, to configure a maximum limit on the bandwidth that EL1 requests use.
    - [MPAMBW1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-6-MPAMBW1-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambw1_el1), to configure a maximum limit on the bandwidth that EL2 requests use.

I FCMPY
:   The [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).E2H does not affect:

    - Use of the following registers by EL2 software:

      - [MPAM0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-1-MPAM0-EL1--MPAM0-Register--EL1-?lang=en#reg_aarch64_mpam0_el1), to control PARTIDs and PMGs used by applications running at EL0, or [MPAMBW0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-5-MPAMBW0-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL0-?lang=en#reg_aarch64_mpambw0_el1), to configure a maximum limit on the bandwidth that EL0 requests use. When running applications at EL0, EL2 software also sets [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).TGE to 1 to route exceptions from EL0 to EL2.
      - [MPAMHCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-12-MPAMHCR-EL2--MPAM-Hypervisor-Control-Register--EL2-?lang=en#reg_aarch64_mpamhcr_el2).
      - [MPAMVPMV\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-23-MPAMVPMV-EL2--MPAM-Virtual-Partition-Mapping-Valid-Register?lang=en#reg_aarch64_mpamvpmv_el2).
      - [MPAMVPMn\_ELx](/documentation/ddi0487/mc/-Part-K-Appendixes/-Appendix-K14-Registers-Index/-K14-1-Introduction-and-register-disambiguation/-K14-1-2-Register-name-disambiguation-by-Exception-level?lang=en#mpamvpmn_elx).
      - [MPAMBWCAP\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-9-MPAMBWCAP-EL2--MPAM-PE-side-Maximum-Bandwidth-Limit-Virtualization-Register?lang=en#reg_aarch64_mpambwcap_el2).
    - Use of the following registers by EL1 software:

      - [MPAM0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-1-MPAM0-EL1--MPAM0-Register--EL1-?lang=en#reg_aarch64_mpam0_el1), to control PARTIDs and PMGs used by applications running at EL0, and MPAM1\_EL1, to control PARTIDs and PMGs used by EL1 software.
      - [MPAMBW0\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-5-MPAMBW0-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL0-?lang=en#reg_aarch64_mpambw0_el1) and [MPAMBW1\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-12-MPAM-registers/-D24-12-6-MPAMBW1-EL1--MPAM-PE-side-Maximum-Bandwidth-Control-Register--EL1-?lang=en#reg_aarch64_mpambw1_el1), to configure maximum limits on the bandwidth that EL0 requests and EL1 requests use, respectively.

R XCQTJ
:   When the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is {1, 1}, the alternative PARTID space in EL0 is selected only if the alternative PARTID space is selected in EL2. When the [Effective value](/documentation/ddi0487/mc/-Part-K-Appendixes/Glossary?lang=en#effective_value) of [HCR\_EL2](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-61-HCR-EL2--Hypervisor-Configuration-Register?lang=en#reg_aarch64_hcr_el2).{E2H, TGE} is not {1, 1}, the alternative PARTID space in EL0 is selected only if the alternative PARTID space is selected in EL1.
