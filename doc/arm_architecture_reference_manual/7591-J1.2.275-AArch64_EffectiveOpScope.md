# ​J1.2.275 AArch64_EffectiveOpScope

##### J1.2.275 AArch64\_EffectiveOpScope

```
// AArch64_EffectiveOpScope()
// ==========================
func AArch64_EffectiveOpScope(opscope_in : CacheOpScope) => CacheOpScope
begin
    var opscope : CacheOpScope = opscope_in;
    if PSTATE.EL != EL1 then return opscope; end;
    if opscope == CacheOpScope_ALLU && EL2Enabled() && HCR_EL2().FB == ‘1’ then
        opscope = CacheOpScope_ALLUIS;
    end;
    return opscope;
end;
```
