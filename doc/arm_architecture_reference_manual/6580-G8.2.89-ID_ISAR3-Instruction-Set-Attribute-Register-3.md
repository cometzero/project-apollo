# ​G8.2.89 ID_ISAR3, Instruction Set Attribute Register 3

Source: <https://developer.arm.com/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-89-ID-ISAR3--Instruction-Set-Attribute-Register-3>

##### G8.2.89 ID\_ISAR3, Instruction Set Attribute Register 3

The ID\_ISAR3 characteristics are:

Purpose
:   Provides information about the instruction sets implemented by the PE in AArch32 state.

    Must be interpreted with [ID\_ISAR0](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-86-ID-ISAR0--Instruction-Set-Attribute-Register-0?lang=en#reg_aarch32_id_isar0), [ID\_ISAR1](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-87-ID-ISAR1--Instruction-Set-Attribute-Register-1?lang=en#reg_aarch32_id_isar1), [ID\_ISAR2](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-88-ID-ISAR2--Instruction-Set-Attribute-Register-2?lang=en#reg_aarch32_id_isar2), [ID\_ISAR4](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-90-ID-ISAR4--Instruction-Set-Attribute-Register-4?lang=en#reg_aarch32_id_isar4), and [ID\_ISAR5](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-2-General-system-control-registers/-G8-2-91-ID-ISAR5--Instruction-Set-Attribute-Register-5?lang=en#reg_aarch32_id_isar5).

    For general information about the interpretation of the ID registers see [‘Principles of the ID scheme for fields in ID registers’](/documentation/ddi0487/mc/-Part-G-The-AArch32-System-Level-Architecture/-Chapter-G8-AArch32-System-Register-Descriptions/-G8-1-About-the-AArch32-System-registers/-G8-1-3-Principles-of-the-ID-scheme-for-fields-in-ID-registers?lang=en#chdidagf).

Configuration
:   AArch32 System register ID\_ISAR3 bits [31:0] are architecturally mapped to AArch64 System register [ID\_ISAR3\_EL1](/documentation/ddi0487/mc/-Part-D-The-AArch64-System-Level-Architecture/-Chapter-D24-AArch64-System-Register-Descriptions/-D24-2-General-system-control-registers/-D24-2-103-ID-ISAR3-EL1--AArch32-Instruction-Set-Attribute-Register-3?lang=en#reg_aarch64_id_isar3_el1)[31:0].

    This register is present only when FEAT\_AA32EL1 is implemented. Otherwise, direct accesses to ID\_ISAR3 are UNDEFINED.

Attributes
:   ID\_ISAR3 is a 32-bit register.
