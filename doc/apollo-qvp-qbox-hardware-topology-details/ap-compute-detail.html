AP Compute 상세 토폴로지

ap_compute.lua · Cortex-A720AE 4 CPU · GICv3/ITS · SMMUv3 · PCIe · 메모리/주변장치

CPU 및 인터럽트

  • • CPU별 generic timer PPI는 QEMU ARMCPU가 소유
  • • GICv3 SPI/PPI 출력은 CPU IRQ/FIQ 입력으로 연결
  • • GPEX MSI는 ITS, legacy INTx는 SPI 300–303 사용

PCIe DMA 경로

  • • GPEX bus_master → LTI00 TBU → MMU-720AE → AP router
  • • SMMU event queue fault는 SPI 65로 전달

  • • address_map.lua의 AP view
  • • ap_compute.enable_ap_router()에서 실제 target socket 재바인딩
