# Wake Request AXI5-Stream interface

Source: <https://developer.arm.com/documentation/102666/0201/Components-in-GIC-720AE/Wake-Request/Wake-Request-AXI5-Stream-interface>

### Wake Request AXI5-Stream interface

The AXI5-Stream interface enables the Wake Request block to communicate with the Distributor.

The AXI5-Stream interface does not exert back-pressure.
