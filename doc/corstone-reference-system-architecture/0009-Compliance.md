# Compliance

Source: <https://developer.arm.com/documentation/102803/latest/Overview/Compliance>

### Compliance

The system architecture described in this document is designed to meet the following requirement:

- [Trusted Base System Architecture for Armv8-M](/documentation/102803/0000/Overview/Compliance/Trusted-Base-System-Architecture-for-Armv8-M?lang=en "The Arm Platform Security Architecture, Trusted Base System Architecture for Armv6-M, Armv7-M and Armv8-M 2.0 (TBSA-M) is part of Arm Platform Security Architecture (PSA).")

- **[Trusted Base System Architecture for Armv8-M](/documentation/102803/0000/Overview/Compliance/Trusted-Base-System-Architecture-for-Armv8-M?lang=en)**
   The Arm® Platform Security Architecture, Trusted Base System Architecture for Arm®v6-M, Arm®v7-M and Arm®v8-M 2.0 (TBSA-M) is part of Arm Platform Security Architecture (PSA).
