# CryptoCell Related Expansion interfaces

Source: <https://developer.arm.com/documentation/102803/latest/Interfaces/CryptoCell-Related-Expansion-interfaces>

### CryptoCell Related Expansion interfaces

The following section details interfaces that must exist when HASCRYPTO = 1.

- **[CryptoCell Lifecycle Indication interface](/documentation/102803/0000/Interfaces/CryptoCell-Related-Expansion-interfaces/CryptoCell-Lifecycle-Indication-interface?lang=en)**
   The CryptoCell Lifecycle Indication interface indicates the lifecycle state of the system through different stages of manufacture and deployment of the final product.
- **[CryptoCell Debug Control Enable interface](/documentation/102803/0000/Interfaces/CryptoCell-Related-Expansion-interfaces/CryptoCell-Debug-Control-Enable-interface?lang=en)**
   The CryptoCell Debug Control Enable interface provides signals that can be used to control the debug authentication signals at the top level of CRSAS Ma1 and other tests, debug and security-related functionality in SoC.
- **[CryptoCell Non-Volatile Memory interface](/documentation/102803/0000/Interfaces/CryptoCell-Related-Expansion-interfaces/CryptoCell-Non-Volatile-Memory-interface?lang=en)**
   The CryptoCell Non-Volatile Memory interface is the CryptoCell interface to the One-Time Programmable memory (OTP).
